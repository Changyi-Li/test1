### Production schedule cycles
In this box you enter the schedules to be included in the production schedule cycle during hourly planning or capacity via schedule.

#### Number
Here you see/select the schedule number that you want to include in the cycle.

#### Name
In this column you can see the name of the schedule. You cannot modify the name shown in this field.

#### From
Here you see the date from which the schedule will apply.

#### Calendar
Here you can select a calendar for the schedule cycle. Please note! A new row will inherit the calender from the row above.
Please note! Exceptions, if any, will override capacity via calendar.

#### Day in cycle
If you select a cycle that is more than 7 days long, you can decide on which day the cycle will start.
