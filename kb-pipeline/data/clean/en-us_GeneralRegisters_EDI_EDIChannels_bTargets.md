### Targets
In this table you add the targets needed for the EDI EDI is the acronym of Electronic Data Interchange. EDI is about exchanging electronic business documents with your business partners, e.g. customers and suppliers. The EDI concept can be wide and a bit unclear, and can many times be used about all types of documents which are sent electronically, even if it might be PDF files sent via e-mail or publishing business documents on a website. What we refer to as EDI – and what is traditionally meant by EDI – is structured business documents following given standards, electronically sent or received and which are compiled and interpreted automatically and that is integrated with the customer's/supplier's ERP system. channels. A target is a directory to which you export EDI files from Monitor ERP.
By using the buttons in the function menu you can add, insert, delete, and copy targets row by row. To each target you configure [settings](bTargetSettings.htm) in the box to the right. These settings depend on the selected Type of target.

#### Type
Here you determine if the target is a Directory, FTP, or SFTP.

#### Name
Here you enter the name of the target. This name appears in EDI channels and EDI configurations.

#### Consecutive number
Here you will see the next consecutive number in the file name. If variable for consecutive number is entered in the file name in the File name field under Directory settings, this field will be activated and you can change the consecutive number.

#### Log
By using the button Log ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you find a changelog for the target. Here you see who modified the information as well as when. You also see what has been changed, with the value before and after the change.

#### Test target (T)
By using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_test.png) in this column, a validation is made to make sure that the target has been correctly configured. The target must be validated in order to be used in a channel.

#### Test result (R)
If the validation succeeds, you see a green check mark ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/StatusFinished.png). If the validation fails for some reason, you see a warning symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png). A tooltip is shown when you hover over the symbol, displaying an explanation. If the validation succeeds you also see when the validation was made and by whom. If the settings for the target have been changed you see a pen symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/modified_image.png). A new validation must then be made by using the button in the T column.
