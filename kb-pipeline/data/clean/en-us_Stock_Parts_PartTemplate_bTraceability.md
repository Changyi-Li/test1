### Traceability
See explanation of the fields in the help topic for [Traceability](../PartRegister/bTraceability.htm) in the Part register procedure.

#### Traceability
With this setting you decide if parts in the template should be traceable. You can choose among traceability on Batch A batch is the set of components/products manufactured at the same time and made from the same original material., Serial number A serial number is a number that is used for traceability for parts on entity level., or Serial number (only withdrawal).

#### Create serial number at customer order
Here you decide if serial numbers on parts in the template should be created on customer order row. The available alternatives are No, At registration of order, and When reporting delivery. This can be used if you, for example, want to link a serial number to a product you are selling.

#### Assign number
If you have configured to create serial number at registration of order, you here determine if the serial number should be set Manually or From number series for parts in the template.

#### Allow automatic withdrawal
Here you can allow automatic stock withdrawals during different reporting items. This is made at part level. This can be configured for the alternatives Pick location, Cleared, Location, and Project.

#### Apply

#### Linking of serial number
For manufactured parts with Serial number traceability where the material is also traceable, the material has to be linked to each individual serial number. Here you choose when in the manufacturing reporting this linking should be made.
