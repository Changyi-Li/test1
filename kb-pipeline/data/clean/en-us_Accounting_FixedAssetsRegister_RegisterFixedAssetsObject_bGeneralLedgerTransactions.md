### General ledger transactions
In this box you see the general ledger transactions for the fixed asset. All transactions containing the number of the fixed asset in question in the general ledger postings, will be shown. These are transactions referring to acquisitions, depreciation, etc. The table is sorted with the oldest record at the top of the table. You can use the button Only asset accounts ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_goto_critical_op.png) to filter the transactions to only show posting rows referring to assets. This is done with the purpose of quickly being able to see the transactions which affect the value of the fixed asset. Assets here refer to accounts which in the chart of accounts are configured as the account type Assets.
At the bottom you see totals of the debit and the credit columns.
