### Part
In this box you see information about each part in the delivery schedule. You also see if the part status is Ok after the import ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/StatusFinished.png). You can compare the part in Monitor ERP with the part from the import file to make sure that the part number, name, and unit correspond. In the column called Aggregated quantity from calls you see the total quantity for the part. You also see dock, dock description, and storage.
Here you adjust the business transaction if errors occur on part rows, for example if one or several parts cannot be matched. You then see an error symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/error.png) or a warning symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png) in the part status column and in the column where the problem exists. When you hover over the symbol, a tooltip displays the error in text form. On the row you can then choose part and use the button Action ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) to choose to add another part identity or customer link.
If an error symbol or a warning symbol should be displayed when a part cannot be matched is determined by the setting Import principle for business transactions in the EDI EDI is the acronym of Electronic Data Interchange. EDI is about exchanging electronic business documents with your business partners, e.g. customers and suppliers. The EDI concept can be wide and a bit unclear, and can many times be used about all types of documents which are sent electronically, even if it might be PDF files sent via e-mail or publishing business documents on a website. What we refer to as EDI – and what is traditionally meant by EDI – is structured business documents following given standards, electronically sent or received and which are compiled and interpreted automatically and that is integrated with the customer's/supplier's ERP system. behavior to which the customer is linked. If the setting has been configured to Only complete business transactions, an error symbol will be displayed. If the setting has been configured to Allow parts of business transactions, a warning symbol will be displayed.
If a part from the import file does not match with a part in Monitor ERP, you can choose to ignore the part by checking the Ignore part checkbox on the row. It is also possible that there are parts in the delivery schedule that should not be matched for some reason. This must be done manually if you have configured the setting to Only complete business transactions. When you check the box, a warning symbol on the row will disappear. The row status on the transaction then displays an information symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_information.png). If you have configured the setting to Allow parts of business transactions, the box will be automatically checked. Then a warning symbol is shown instead. By clicking the ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_package.png) button, you can add the ignored part to Skip lists for parts ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_package.png). This part is then skipped in future imports.
If a unit is incorrect on a part from the import file and/or if it is missing in Monitor ERP, this can also be shown with an error symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/error.png) or a warning symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png). This is determined by the setting Check of unit on part row in the EDI behavior to which the customer is linked. If the part's unit is missing from the import file, the part's default unit in Monitor ERP will be used. You cannot adjust the unit here. This must be added to the part in the part register (usage on Customer order).
On the function menu there is a button called Go to procedure ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png). By using this you can go to related procedures with the affected part already loaded.
You can unpin the box and use it as a floating window. This is done by using the button Floating ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_float_window.png) (Ctrl + U). This way the table will be larger and you get a better overview of the parts.
