## Register users after test conversion
Here we describe the actions that need to be taken regarding users and user rights after a test conversion from Monitor G4 to Monitor ERP. This is the first step to get started with trying out the system and perform tests. When installing the first test conversion, one test company is set up per actual/live company.
> The measures described should be carried out by the company's ERP manager (the person responsible for Monitor). If you have any questions, you can contact the Monitor Support Center by phone on +46 650 766 03 or at support@monitorerp.com. Please note! The user rights are not converted from G4. These must be registered in G5. However, it is possible to synchronize user rights between two different G5 databases. For this you need the help of your Monitor consultant. This is done in connection to the second test conversion and also after the actual conversion.

#### Log in to the test company
When a first conversion has been made, the users are converted and are automatically registered in G5.
Then it is time to assign user rights for the users in the test company where all tests and trials should take place. This should be done for all users who initially should test run G5.
- Start by launching Monitor ERP from your computer and click the small black arrow ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_expand_row.png) (1) to show the test companies.
- Then select the test company (2) to log in. If there are multiple test companies select the one called "manual copy".
- Enter the user name ADMIN and you administration password, same as in G4 (3).
![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/SettingUpUsers1.png)![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/SettingUpUsers2.png)

#### Users
Go to the General registers module (1) and open the Users procedure (2).
![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/SettingUpUsers3.png)
The Settings tab
- Under the Settings tab you find Password (1) and a link to Windows account (2), if any, already converted from the users in G4.
- Activate the Activate login to Monitor Mobile setting (3) for the users that should have access to Monitor Mobile on the computer or as an app on their mobile/tablet.
![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/SettingUpUsers4.png)
The Roles/User rights tab
Under the Roles/User rights tab you configure user rights for the user.
To get access to test everything in the system, you can start by assigning all user rights to one user by Adding a role (1), and selecting the role called ERP manager (2).
> Read more and watch a short film about how to configure user rightsby clicking this link: [Roles](../../GeneralRegisters/UserPersonnel/Users/bRoles.htm).Monitor ERP
![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/SettingUpUsers5.png)
> In distinction from the original database, users in the test company can log in without being linked to a license.

#### User list
To make a list of all users who have been assigned user rights, you can use the User list procedure. Use for example the Roles list type (1). Click Load (2) to load the users to the list.
![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/SettingUpUsers6.png)
