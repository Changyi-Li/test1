### List
In this list you can see and complement the terms which should apply for the simulation.

#### Include
With this checkbox you decide which parts to include in the simulation.

#### Configuration
If it is a part which is possible to configure you use the button Possible to configure ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/Button_Configuration_Available.png) on the row to access the configuration window. When you confirm the configuration it will be saved to the simulated order and then the button Configured ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/Button_Configuration_Done.png) will be shown on the row.

#### Terms
The terms Quantity, Finish date, Order number, Customer, and Variant code, which you might have configured under Settings under the Selection tab, can also be changed here in the list and run the simulation with other values.
If you make any changes you have to run the simulation using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_run.png) on the toolbar.
