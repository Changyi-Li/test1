### The Annual volume list
In this list type you can enter planned annual volume for work centers.
In the list you can manually update the same fields as are found in the [Annual volume](../WorkCenterRegister/bAnnualVolume.htm) box in the work center register. The different fields work in the same way as in that procedure.
For this list you can under the Selection tab enter which cost factors you wish to use for the cost calculation.
For regular work centers you can edit setup time, unit time, total time, and man-hours. For subcontract work centers, it is possible to edit the costs. Mark the rows in the Save column when you are done you save in the procedure.
