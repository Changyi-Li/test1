### List – Pick list

#### Include
This checkbox determines whether or not the material on the row should be included in the pick list. It is checked by default if you have activated the setting Pre-select '”Include” under the Selection tab.
When you save in the procedure, the pick lists which you have marked to inlcude, will be shown under the Document tab. This tab is not active until you save.

#### Order number
Here you can see the manufacturing order number.

#### Manufactured part
Here you see the main part of the manufacturing order.

#### B (Basic type)
Here you see the part's basic type. Tools are shown with a symbol and a tooltip for the symbol lets you know which basic type it is.

#### The material's part number
In this column you see the material's part number which is included in the manufactured part.

#### Name
Here you see the name of the material.

#### Requirement date
Here you can see the date when the requirement of the material occurs.

#### Main location
Here you can see the main location of the material.

#### Available balance
In this column you can see the available balance of the material, that is, the current balance in all the locations minus previously cleared quantity minus remaining quantity on previous rows. This balance can be displayed with two to six decimals.

#### Remaining quantity
In this column you see the remaining quantity that will be used by the material on the order. This quantity can be displayed with two to six decimals.
