### List types
In Monitor ERP finished list types are included to be used for different purposes in the list procedures.
For each list type there is also a standard set of selection rows from different registers and in many cases there is also a standard set of presentations. For many of the list types there there are also different settings.
In a list procedure you start by selecting list type and presentation, if any. Then you select data records and you might also want to make changes in the settings, before you load the list of the data records.
You can also save own default list types and presentations by using the [Default values](DefaultValues.htm) feature which is found on the toolbar of the procedure.
