### 文件设置

#### 格式
In this field you enter which type of export to be made.It can be SIE type 4E, SIE type 4I, or other export formats defined in the Settings for export/import procedure.

#### 文件路径
在此字段中，输入你已创建导出文件的文件夹的路径。你可以将文件保存在本地驱动器或网络驱动器上。如果你网络驱动器，还应输入UNC路径。强制的在此输入文件路径。

#### 文件名称
在此字段输入你导出的名称。强制的在此输入文件名称。
SIE4I文件的文件名称应为 .si，而 SIE4E文件扩展名应为 .se。
