### Settings

#### Show approved rows
With this setting you can decide if already approved order rows should be shown in the list.

#### Signer
With this setting you select for which signer you want to display purchase orders to approve. The logged-in user is selected by default. This field is only activated if the logged-in user is a signer of purchase orders. This is configured in the General approval settings procedure. If you leave this field empty it means that all purchase orders will be displayed.
