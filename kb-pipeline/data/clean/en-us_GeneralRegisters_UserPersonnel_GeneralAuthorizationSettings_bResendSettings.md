### Resend settings
Here you can choose which type of changes that will trigger the purchase order to be sent for approval again.
> If a new row is added to the purchase order or if the amount of the purchase order changes to an amount over the authorization limit, the purchase order will always sent to be authorized again.

#### Resend purchase order for approval
- Amount decreased – This option means the purchase order will be resent if the amount is decreased. If the amount is changed from EUR 1000 to EUR 999, the order row will be resent for approval.
- Quantity changed – With this option, a row will be sent for approval again if the ordered quantity of the row has been changed. Example: If the approved row had 100 units ordered, and then it was altered to 99 or 101, the row will be resent for approval. This setting will only take the ordered quantity on the row into consideration.
- Part changed – If the part on the order has been changed, the order will be sent for approval again.
- Currency changed – If there is an approved/authorized purchase order row with a currency, and that currency is changed – the order will be sent for approval again.
- Supplier changed – If there is an approved/authorized purchase order for a specific supplier and that supplier is changed – the order will be sent for approval again.
- Row added – (Total and quantity for the approved order remains the same.) If an additional order row is added to the purchase order and the initial order rows, the order will be resent for approval. Row type 4 will not be resent for approval.
- Row deleted – If a row has been deleted, the purchase order will be resent for approval.
- Date changed – If a date is changed (moved forward or backward), the purchase order will be resent for approval.
