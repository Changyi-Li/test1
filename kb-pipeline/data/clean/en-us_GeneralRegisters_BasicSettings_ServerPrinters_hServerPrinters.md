### Header row

#### Number
Here you enter a number for the server printer using a maximum of 20 characters. If you create a new server printer and leave this field empty and save, the next available number from the number series will be used. This number is loaded from the Number series procedure.

#### Name
Here you see/enter the name of the server printer. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Printer type
Here you select which printer type to use. The following printer types can be selected:
- Locally installed printer
- E-mail based printer (must first be registered in the Settings for Cloud printer procedure).
- PrintNode printer (must first be registered in the Settings for Cloud printer procedure).
