### Other part identities

#### Use other part identity
This setting determines if other part identity should be used to identify parts in the production company. The function is used if the same parts have different part numbers in the sales company and production company respectively. In that case you cannot use the Synchronize parts procedure.
One way is to select a code in the sales company for other part identity using the setting below. The same code is added to Other part identities in the part register for the parts in the production company. In the Identity field you enter the sales company's part number. The part identity must also be set as Active.
Another way is to add a code for other part identity to the parts in the part register in the sales company. You then use the production company's part number as identity.
A third way is to add a code for other part identity to the parts in the part register in both the sales company and production company. You then use shared numbers as identity. You can for example use business specific part numbers as identity.

#### Code for other part identity
If you have activated the setting above, here you select which other part identity you want to use. You can use a specific code for this. This code must first be added to the table with other part identities in the Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Part procedure.
