### Settings – Selection
Result

#### Show backordered rows
With this checkbox you determine if order rows that have remaining quantity will be shown.
This setting is only available for the list type Delivery note, delivered.

#### Also show invoiced deliveries
With this setting you decide if invoiced deliveries (invoices with status 9) should be shown in the list. If you activate this setting it means all deliveries will be loaded to the list.
This setting is not available for the list types Product description including certificate and Part contents – Delivery.

#### Show delivery notes not yet reported
When this setting is activated, it is possible to print delivery notes for pick lists that have not yet been delivery reported. On a delivery note that has not yet been delivery reported, the delivered quantity is show as 0 (zero).

#### Pre-select "Include"
This setting determines whether or not the “Include” box should be checked by default for all rows in the list/result.
The selected rows will be included for printout under the Documents tab.
Printout

#### Printout date
The date that is shown on the document as the date of the printout. Today's date is shown by default. By using the available calendar, you can select another date.
This setting is not available for the list types Transport label, sales and Product description including certificate .

#### Number of copies
Here you select the number of copies that should be printed. The number of copies selected by default in this field is determined by the document setting Default number of copies for Delivery note, delivered. If more than 1 copy is printed it will say "COPY" on all documents following the first printout.
This setting is not available for the list types Transport label, sales and Product description including certificate.
EDI

#### "No" by default for EDI export
This is only available in systems with the EDI EDI is the acronym of Electronic Data Interchange. EDI is about exchanging electronic business documents with your business partners, e.g. customers and suppliers. The EDI concept can be wide and a bit unclear, and can many times be used about all types of documents which are sent electronically, even if it might be PDF files sent via e-mail or publishing business documents on a website. What we refer to as EDI – and what is traditionally meant by EDI – is structured business documents following given standards, electronically sent or received and which are compiled and interpreted automatically and that is integrated with the customer's/supplier's ERP system. option. When this setting is activated it means the column for EDI export in the Result box by default will be set to No. This setting can be of use in order to avoid unintentional EDI export when you list the results, for example when you want to reprint a document.
