### Scheduling
In this box you schedule the actions Posting of logs and Approve log journal. For posting of logs it is possible to enter a date from when to post. You can decide if the scheduling of posting of logs and/or approve log journal, should be active or not. By using the button Run posting ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_run.png) you can manually run the posting of all logs or approve log journal for all logs.
The row marked here also determine what is shown in the box to the right.
