## Logged in users
In this procedure you can see which users are currently logged in or have sessions at rest in the system. This applies to the company you are working in.
These records are displayed in a list where you can delete rows in order to end logins/sessions. The purpose of this is to allow system administrators (during system maintenance, updates, etc.) to end logins for users who have forgotten to log out.
At the very bottom of the window you see the total number of user sessions as well as the number of active user sessions.
