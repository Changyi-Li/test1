### Orders to approve
In this box you see the purchase orders that have been sent for approval and have status 0 (Awaiting manual approval).
In the Handling column you see different symbols for each purchase order. New orders that the user should handle (approve or reject) are displayed with an arrow symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/ActiveRow.png). When at least one order row has been approved or rejected, and there are order rows left to handle, you see a symbol with an orange star ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/orange_snowflake.png). When all order rows are approved, a green check mark is displayed ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/StatusFinished.png). If all order rows are rejected, a red cross is displayed ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_reject.png). If an order has been re-sent for approval after changes have been made, the changes are shown in orange italics.
On each row in the list you also find the columns order number, signer, supplier number, order amount, and created by.
In the Order rows box to the right, you see the order rows that should be approved or rejected for the selected purchase order.
