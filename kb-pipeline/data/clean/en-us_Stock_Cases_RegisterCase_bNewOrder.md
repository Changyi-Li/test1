### New order
By clicking the Create new order button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_new.png) on the function menu, a dialog window will open where you can quickly create and link a new manufacturing order or maintenance order to the case. This order will function as a replacement order for the part in the case (if it, for example, should be replaced). The part in the case will be default for the order, but this can be changed to any of the other parts contained in the case. You enter, among other things, a quantity, priority, and finish date for the order. The earliest possible finish date is shown for the quantity you have entered. It is also possible to use a function to check delivery times.
There is also a checkbox where you can choose to open the registration procedure of the order (in cases when you need to continue working on the order there). When you click the Save button in the dialog, the order is created and is opened in its registration procedure (if you chose to activate that checkbox).
By using the Add order to case button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_row.png) you can link an already registered manufacturing order or maintenance order.
On a row that you add you also find a button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) which you use to show additional information about the order. For the row you can select if material cost, subcontracting cost, and processing cost, should be charged on the order. If none of the CMThe contribution margin (CM) is the difference between the standard price and the sales price., CS, and CP checkboxes are marked on the row, nothing will be charged the customer/supplier for the correction.
A linked order also affects the planned and reported costs of the case.
By clicking the Delete order from case button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_delete_row.png) you can disconnect/unlink an order from the case.
By clicking the Go to procedure button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png), you can via the link go to the registration procedure for the order on the row in question.
