### Period

#### Start date
Here you select the date which is the starting point of the cash flow forecast. Today's date is entered by default, but it is also possible to select a future date.

#### Time scale
Here you select the time scale to use in the forecast; day, week, or month. The default option is week.

#### Number of days per period
If you have selected day as the Time scale to use, you can here enter the number of days per period in the forecast. The default option is 1 day.

#### Number of periods
Here you enter the number of periods in the forecast, that is, how many periods that will be displayed (excluding overdue periods). The default option here is 12 periods.

#### Period for horizon
With this setting you determine if a row with the period Horizon should be added at in end of the list. On that row you will see the total of all payments that have payment dates after the final period. If the setting is not checked, you will only see rows that have payment dates up to and including the final period.

#### Period for unconfirmed delivery
This setting determines if quote rows and order rows, that are missing a planned delivery date, will be included in the list. But since the system cannot place them in chronological order in the forecast, the value of these rows will be a total at the end of the list with the period Unconfirmed del.
