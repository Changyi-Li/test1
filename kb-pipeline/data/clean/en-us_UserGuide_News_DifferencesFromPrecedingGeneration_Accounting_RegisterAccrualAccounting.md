### Register accrual accounting
- The field Type has been added for accrual accounting. The available types are Supplier invoice, Voucher, Reversal voucher, and Current accounting.
- In G5, the procedure also has links to Register vouchers. Posting made in the Register Vouchers procedure can be accrual accounted in this procedure. The procedure can also be used to reverse vouchers in another accounting period, for example during work with annual financial statement. The latter function takes place when the system automatically creates accrual accounting of the type Reversal voucher.
- The coding/posting window is no longer hidden under a button, but is shown all the time in the lower section of the window.
- Instead of start period you will in G5 enter a start date for the accrual accounting. End date is also shown. A system setting determines if release should be done on the final day of the month or day in the month when the accrual accounting was started.
- In the Period allocation window you can see for each released month, which voucher number was generated and its voucher date. It is also possible to go to the voucher by using a link.
- The function for reactivating accrual accounting has been removed. Instead it is possible to extend/prolong accrual accounting.
- A new field has been added showing voucher number and voucher date for the record which is the basis for the accrual accounting, for example the supplier invoice.
