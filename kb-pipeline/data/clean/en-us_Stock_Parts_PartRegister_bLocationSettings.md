### Location settings

#### Stock update
With this setting you decide if the part should be stock updated. Parts of the type Purchased or Manufactured are stock updated by default. Parts of the type Fictitious or Service are not stock updated.
You can uncheck this setting if, for example, your consumables (such as screws and screw nuts) are refilled by your supplier. You can also uncheck this setting for parts whose balance you are monitoring manually. This is normally parts which are not consumed in the manufacturing.
Parts with traceability must be stock updated, and this setting is locked and activated. But if the part is a tool (for example a fixture) based on a part template with the Reusable basic type, it is possible to deactivate the stock update.
If you deactivate stock update on a part that has clearances, a dialog is shown where you will be asked to confirm that the stock update should be deactivated. The dialog shows which orders contain the part.

#### Random stock location
With this setting you decide if random stock location should be applied for the part. Random stock location is not activated by not default for new parts. If random stock location is activated this means that if the balance of the location becomes zero (0), the location will be deleted for the part. This is done automatically when you report withdrawals from the stock which empty the location.
> Locations with the following settings will not be removed from the part: Arrival location Pick location Pick location per work center

#### Location selection
Here you can apply a location selection for the current part. A location selection means that you can only arrival report the part to a location name which is included in the location selection in question. You register location selections in the Location selection procedure.
Next to the field you see the location selection name.
In the Location list procedure, list type Location selection – Part, you can apply a location selection for several parts at a time.
