### Other terms
Here you can enter different types of Other terms for the posting method. To be able to post the transaction via the current posting method, the entered terms must be fulfilled. Please note! It is important that the terms have been correctly registered. Any incorrectly entered terms might lead to the transaction not being posted or being incorrectly posted.
In the Other terms box you can determine different postings depending on, for example, Warehouse, Product group, Order type, and so on.

#### Based on
In this column you decide what the posting method should be based on. The following options are available:
- Product group
- Part code
- Part category
- Part number
- Order number (Manufacturing order number, Purchase order number, or Customer order number, depending to which log the posting method applies)
- Order types
- Location
- Warehouse (For all logs except manufacturing order log)
- Customer category
- Customer group
- Customer type
- Customer district
- Supplier category
- Supplier group
- Supplier type
- Supplier district
- Cause code
- Case number
- Case type
- Customer order category
- Purchase order category
- Project
- Project type
- Department on work center
- Department on employee
- Warehouse on order (Only for manufacturing order log)
- Warehouse on reporting (Only for manufacturing order log)
- Type of cost
