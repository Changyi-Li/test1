### D2 Describe the problem

#### Rejection code
Here you enter the rejection code provided by the customer in the claim. Rejection codes are handled in the Rejection codes/Error codes procedure.

#### No. of rejections
Here you enter the number of rejections that the case refers to.

#### Rejection description
In this field you can enter a rejection description and a translation of it. By clicking the button Insert phrase ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_phrase.png) it is possible to insert different phrases which are registered in the Phrases procedure.By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Serial number
In this field you select the serial number for the product which the claim concerns, if the customer/supplier can specify it. A validation will be made against the customer/supplier and you will get a warning if the serial number is not linked.

#### Batch number
In this field you select/see the batch number to which the nonconforming part belonged at arrival reporting. It is also possible to enter a batch number that is not registered. This field is only available for the case type Supplier nonconformity.

#### Part
Here you can enter the part number of the product which the claim concerns. You can either enter it or it is automatically filled in if you enter the serial number. If the part has an active revision, this is automatically filled in in the field below. However, it is possible to edit the revision if the claim refers to a previous revision.

#### Name
Here you see the part name.

#### Revision
Here you can enter the part's revision which the cases concerns. The revision is set to the part's active revision when the part number is entered.

#### Internal comment
Here you can enter an internal comment regarding the case. It can be shown on the internal nonconformity report via settings for the document. The text is also visible e.g. in the Case list procedure. The files you link here cannot be printed automatically.

#### External comment
Here you can enter an external comment for the case. It can be shown on the case documents via case form settings. The text is also visible e.g. in the Case list procedure. The files you link here are possible to choose for automatic printout.
