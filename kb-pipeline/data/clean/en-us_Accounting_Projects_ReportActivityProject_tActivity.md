### Activities

#### Time to report
Here you can enter the hours you wish to report. It is also possible to report minus hours (a negative value).

#### Remaining time
When you report time, the remaining time will be calculated as: the existing remaining time minus the time you are reporting right now.

#### Status
Here you select the status of the activity: Not started, Started, and Finished.

#### Reference
In this column you will be default see the reference who is linked to the person responsible for the activity. Here you can select another reference registered in the system or you can type another name. In the next column you access information about the reference by clicking the button.

#### Date
Here you enter the date on which you want to save the reporting item. By default the date is loaded from the settings made under the Selection tab.

#### Internal comment
Here you can enter a comment which will be saved on the consecutive number of the reporting. The text can also be shown in different procedures and lists.

#### External comment
This text can be printed on different documents using the Show external comment setting for the documents in the Document settings procedure. The text can also be shown in different procedures and lists.

#### Files
It is possible to link files to the consecutive number of the reporting.
By using the ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_file_link.png) button, you can see and link files to the report’s consecutive number. Files for external use are printed automatically with the documents if the file has Automatic printout selected.
> Please note that file paths must be registered in the Paths procedure in order to enable files to be linked.

#### Planned start date
In this column you can see the start date for the activity (the planned start date).

#### Planned finish date
In this column you can see the finish date for the activity (the planned finish date).

#### Cost type
If the activity is linked to a cost type, then that cost type will be shown here. You can select among the cost types set as Cost and they must also have the option Direct reporting selected in the field Result is loaded from (in the basic data).

#### Actual finish date
If the status is set to Finished, then today's date will be suggested in this field. It is possible to edit.

#### Performed by
The user who changes the status to Finished is entered in this column by default, but you can change the user to another user in the user register. However, it is only possible to select among the users with the setting Can be set as responsible for activity or with the user right Report activity for any user.

#### Last reporting
In this column you enter the date when the most recent reporting was made on the activity.

#### Log
Under the button in this column you can view a log of previous reporting items for the activity.
More information

#### Activity comment
Here you see the comment for the activity. It is only possible to see the comment.

#### Files
Here you see linked files for the activity. It is only possible to see the files.

#### Employee
Here you can enter an employee by typing in an employee number. This is automatically suggested based on references, if an employee is entered there.

#### Department
Here you can enter a department for the employee in question. This is automatically suggested if a department already is entered for the selected employee.

#### Work center
From the work center register you can enter a work center which is linked to the activity.

#### Activity number
In this field you see the number of the activity.

#### Amount
If the activity is linked to a cost type then the total cost is shown for the reporting you perform. This total cost is calculated by multiplying the reported hours with the cost per hour which is registered on the cost type.

#### Phase
If the activity is a part of a phase then you will here see the phase number. In the following columns you see the name of the phase and who is responsible for the phase.
