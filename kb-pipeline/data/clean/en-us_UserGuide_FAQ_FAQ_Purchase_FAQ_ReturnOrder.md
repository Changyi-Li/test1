### FAQ – Return order
How do I register return orders (purchase)?
A return order can only be created for arrival reported purchase order rows of row type 1.
In the Register return order procedure you can select by different terms such as supplier, order number, and part, to load the order/orders you want to return.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/FAQ/FAQ_ReturnOrder1.png)](../../../../Resources/Images/FAQ/FAQ_ReturnOrder1.png)
If you loaded the list without making a selection, you can in the Supplier box select to which supplier you want to make a return. You can select several order rows from either the same order or from multiple different orders, to use on one and the same return order. Mark which order rows should be returned and enter the quantity to return.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/FAQ/FAQ_ReturnOrder2.png)](../../../../Resources/Images/FAQ/FAQ_ReturnOrder2.png)
When you save, a return order is created. If the purchase orders you selected have different currencies, one return order will be created for each currency.
From the Result tab you can create a shipment to use the regular shipping agents.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/FAQ/FAQ_ReturnOrder3.png)](../../../../Resources/Images/FAQ/FAQ_ReturnOrder3.png)
On the return order you find information on each order row, about which original order that is being returned .
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/FAQ/FAQ_ReturnOrder4.png)](../../../../Resources/Images/FAQ/FAQ_ReturnOrder4.png)
On each original order row there is information letting you know a return order has been created with a quantity and if it is returned.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/FAQ/FAQ_ReturnOrder5.png)](../../../../Resources/Images/FAQ/FAQ_ReturnOrder5.png)
The parts that are to be returned should be returned via the Report arrival procedure.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/FAQ/FAQ_ReturnOrder6.png)](../../../../Resources/Images/FAQ/FAQ_ReturnOrder6.png)
> You cannot add parts to a return order but you can change the quantity. Please note! It is a negative quantity that will be shown as being returned. The material must be in stock for you to be able to make a return. The balance does not show which material is connected to a specific order. If a part has cleared material, the pick list may have to be deleted before you can register a return.
Under the Documents tab you can print a delivery note as well as a transport label. When needed, you can also print pro forma invoice.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/FAQ/FAQ_ReturnOrder7.png)](../../../../Resources/Images/FAQ/FAQ_ReturnOrder7.png)
You can register return orders from the Register case procedure. You will then be linked to the Register return order procedure with the case number in question already loaded, as well as the purchase order number. In the Register case procedure you will then have a link to the return order when you have saved the return order.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/FAQ/FAQ_ReturnOrder8.png)](../../../../Resources/Images/FAQ/FAQ_ReturnOrder8.png)
