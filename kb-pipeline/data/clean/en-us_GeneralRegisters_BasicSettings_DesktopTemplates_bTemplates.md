### Desktop templates
In the section to the left you add, delete, or copy existing desktop configurations that will work as desktop templates for the user.
For new configurations you must enter a name. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts. By using the button called Availability ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you can select for which users, groups, and roles the configuration should be available.
In the mid-section you will find a grid that represents the desktop surface in the client. In the section to the right you will find all desktop components.
You select the desktop components you want to use in the configuration by dragging and dropping them on the grid. Each component you drag onto the grid becomes a panel which you can move around on the grid. You can also change the size of the panel. The components can have different sizes, from 1 × 1 up to covering the entire desktop. There are settings for the different component types regarding minimum and maximum sizes. Change the size within these limits by dragging a corner of the component. Each component has a button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_settings.png) where you can make settings for the component. Using the x button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_close.png) you delete the component from the configuration.
