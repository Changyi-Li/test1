### Planned absence
This box is available if you for the setting Time recording have selected the option Attendance/Work. You also need to select the option According to schedule cycle for the setting Schedule management for the box to become available.
Here you can enter planned absence for the person.
For recurring planned absence such as e.g. parental leave every Monday for an optional time interval, then you can instead use the button called Recurring absence ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_to_calendar.png) to add the absence in the table.

#### Code
In this column you enter the absence code. These codes must first be registered in the procedure Basic dataWith "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Attendance. The name of the code is inserted automatically. You will see the name of the absence code to the right.

#### Part of day
Check this box if the absence should only apply for a part of the day. It then becomes possible to enter a time interval in addition to the date interval in the From and To fields.

#### From and To
Here you enter the date from which the absence should apply and in the To column you enter the final date of the absence. If the absence applies for part of day, you can also enter the time of the day when the absence starts and ends.

#### Authorized
If the absence is authorized by signer, you check this checkbox.
