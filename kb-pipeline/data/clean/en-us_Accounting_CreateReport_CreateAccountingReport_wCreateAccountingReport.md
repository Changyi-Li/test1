## Create accounting report
In this procedure you create/design customized reports for the accounting.
A few finished standard reports are included in the system from the start. These reports can be used straight away and be printed in the Print accounting report procedure.
It is not possible to modify or delete the standard reports included in the system, but you can use them as templates for new reports which you adapt to your company's needs. In the toolbar of the procedure there is a Save as button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_save_as.png) (Ctrl + Shift + S). This is the function you should use to save an existing report as template for a new report. There are also buttons which you use to export ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_export.png)and import ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_import.png) report definitions to/from file (with the extension .mrd).
You can also create new empty reports and design them just as you please. Then you first enter a new report number in the Number field. The number must be 100 or greater.
The procedure is divided into three tabs:
1. The General tab. It describes general information about the report, for example, orientation, margins, and configuration of the report header, see below.
2. The Columns tab. It describes the columns and their settings.
3. The Sections tab. It describes the sections and their settings.

DevExpress Report Designer
Monitor ERP is delivered with a third party program used to design and edit the report header of the reports you have created/designed. This program is called DevExpress Report Designer and is available under the button Edit document configuration ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_xtrareport_designer.png) next to the field Report configuration – Header.
