### Order inflow
In this view you can analyze the company’s order inflow for a selected period of time. The view contains the following boxes: Countries, Customers, and Parts. There is also the box called Order inflow, it shows the order inflow in a chart.
The order inflow is primarily loaded from the log on customer order rows which is created when an order row is created, modified, and deleted. In addition to data in this log, data from customer order rows, customer order header, customer, and part, is also loaded. The date refers to the log date in the above mentioned log. This means the view shows what you have sold and how much money it concerns. And the view is also updated when orders become replanned or deleted.
The order inflow data corresponds to the Order inflow procedure with the following selections and settings:

#### Selection rows
- Order type – Basic type – displays 0 and 2.
- Customer order row – Row status – displays 1, 2, 3, 4 (that is, all alternatives are marked).

#### Settings
- Include orders from – set to Customer order.
- Show called order rows – activated.
> The order inflow in BI does NOT show preliminary customer orders or stock orders.
