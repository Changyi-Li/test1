### Maintenance templates
Here you can add the maintenance templates that you want to include in the maintenance plan. The maintenance templates first have to be registered in the procedure Basic date – Maintenance.

#### Code
Here you see/select the code of the maintenance template which should be included in the maintenance plan.
When you have selected a maintenance template, settings from that template will be displayed in the next columns on the row. You can, when needed, override most of the maintenance template’s settings for the specific maintenance plan. This applies to the following settings: Start, Frequency, Minimum tolerance, Maximum tolerance, Form code, Use BOM and routing from, and Variant code.
Read more about the settings in the [Maintenance templates](../BasicDataMaintenance/tMaintenanceTemplate.htm) section in the online help function for the Basic dataWith "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Maintenance procedure.

#### Order type
Here you can select an order type for maintenance to link to the maintenance plan. Maintenance orders that are created from the Planned maintenance procedure will be assigned the order type selected in the maintenance plan. You register order types in the Order types procedure.
