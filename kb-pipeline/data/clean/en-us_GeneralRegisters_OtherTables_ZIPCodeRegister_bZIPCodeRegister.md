### The Zip code table
In this table you add and modify existing rows with zip codes in the selected country.
You can import zip codes from a text file. [Read more](wZIPCodeRegister.htm).

#### Zip code
Here you enter the zip code as it is written in the selected country using a maximum of 10 characters.

#### City/Province
Here you enter the city or province to which the zip code belongs using a maximum of 50 characters.

#### State/Region
Here you enter the state or region to which the zip code belongs using a maximum of 25 characters.
> Please note! The maximum total (combined) length of the City/Province and State/Region fields is 50 characters.
