### The System signer table
In this table you add the users who should be system authorizers for all of the employees. By default, all rights/settings are activated for a user you add.
You can also delete users who no longer should be system signers. If you deleted a user from the user register, and that user at the time is registered here as a system signer, the user in question will automatically be deleted from here.

#### User name
The users you can select among here to be system signers are the users registered in the Users procedure. In the description field to the right you see the description of the user. In systems with the Warehouse option you see users from all warehouses in the LookupThe Lookup feature is a powerful search tool which allows you to search and load information from large registers. You open the Lookup feature by clicking on the dropdown button or by using F4 on your keyboard. feature.

#### Adjust attendance
With this checkbox you determine if the system signer in question is allowed to adjust attendance recording items.

#### Adjust work
With this checkbox you determine if the system signer is allowed to adjust work recording items.

#### Authorize
With this checkbox you decide if the system signer is allowed to authorize attendance recording items. If you mark this checkbox it means the system signer becomes Secondary signer for all of the employees. A signer can also be Main signer, that is, the one who should primarily authorize attendance for employees. A main signer can only be added per person in the personnel records.
