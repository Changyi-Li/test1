## Packing rules
In this procedure you can create packing rules for packaging parts on delivery rows. These rules are used when reporting delivery via pick lists.
Packaging parts can be linked to the parts you sell. You set this up in the Part register procedure. If you apply packing using the Pack for delivery procedure, you can also add packaging parts to a package structure for pick lists prior to delivery.
By using packing rules, you can:
- Decide if and how the packaging parts should be added as delivery rows, if it should be determined by linked packaging parts in the part register or by packaging parts in package structures. You link package rules to selected customers or order types.
- Configure if multiple delivery notes should be allowed per pick list or if this should result in a warning. If it is not allowed in a packing rule, and the setting to apply comprehensive delivery note is not activated for the linked customer, a warning will be displayed in the delivery procedures.
- Configure a check to see if packaging part rows are completely missing in pick lists when delivery reporting via pick list. You can decide if this check should provide a warning or mark the row as "error" in the delivery reporting.
> Please note! Packing rules are intended for reporting delivery in list type Via pick list. If you report delivery using the list type called Free selection or if you do not apply packing rules, the packaging part linked to the part in the Part register will always be added as a delivery row on a sub-level to the part on the order row.
