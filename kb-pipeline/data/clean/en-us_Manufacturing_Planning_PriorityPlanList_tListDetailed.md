### The Detailed list
The list is loaded and displayed based on the selection and settings you have chosen. As in all lists in Monitor ERP, you can drag and drop in order to change the column to group by.
The detailed list contains mainly the same columns as the [priority plan](../PriorityPlanning/bPriorityPlan.htm) in the Priority planning procedure. Please see the description of the columns in the help function for that procedure. The columns that are specific for this list are described below.

#### Recording status (Rec. s.)
Here you see the operation's recording status as a text. This column is only available if the Time recording option is installed. The recording status is assigned when the recording takes place in the Recording terminal. If the operation does not have a recording status, the column will be empty.

#### Status (node)
Here you see the part's (the node's) order status in text. A part node's different order statuses are the same as the statuses for manufacturing orders.

#### Instruction
Here you see the instruction for the operation. This is loaded from the BOM and routing.

#### Files
Here you see linked files for the operation. This is loaded from the BOM and routing.

#### Employee name
Here you see the name of the operator who recorded on the operation in the Recording terminal procedure.

#### Employee number
Here you see the employee number of the operator. This column and the column before are only available if the Time recording option is installed.
