### Phrases
In the table under this tab you translate document phrases. You can modify existing translations in the selected document group and you can enter your own translations for all phrases if you have created a new document group.
There are several hundred phrases to the documents. These phrases are used as headings etc. for the documents. Certain phrases are also used as headings/subject texts in e-mail messages for the documents that can be sent by e-mail.
By using the button called Reset all phrases for this document group to original ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_cancel.png) on the the function menu, you reset all modified phrases, if any, for the selected group (language) to the original phrase.
> Please note! When updating Monitor ERP, these phrases will not be updated since you might have changed the phrases according to our own needs. If a Monitor update would update the phrases, the modifications made by you would be overwritten.

#### What to consider if the document group was not available as language at time of installation
If you have a system which was installed before Monitor ERP System AB was delivering a certain language, this language will not automatically appear as available document phrases, even though it is now delivered in the system. The language can be selected as document group, but all of the document phrases will be in English. This is done to prevent the new language from overwriting any changes you have made yourself in the document phrases.
By using the button called Reset all phrases for this document group to original ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_cancel.png) on the function menu, all document phrases for the newly translated language will be loaded and are shown in the phrase table of that language.

#### Phrase number
Here you see the phrase number.

#### Phrase
In this column you see the original phrase in the language of the user.

#### Phrase (the document group)
In this column you modify and/or enter your translations of the phrases.

#### Modified
If you have modified a phrase, the checkbox in this column will be marked. This way you can clearly see which phrases which have been modified. It also makes it possible to filter by using the column filter in the heading, to show only the modified phrases.
