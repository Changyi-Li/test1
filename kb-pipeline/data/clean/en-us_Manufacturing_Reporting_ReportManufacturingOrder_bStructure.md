### Structure
This box displays the structure map for a registered manufacturing order. Here you can move between nodes in the structure.
By selecting a part node in the structure, you will see information about the part's operations and its included material in the lists in the Operations and Material boxes. You can report the operations of the part in a list.
If you select an operation node in the structure, you will find detailed information about that particular operation in the Operations box. The operation can then be reported in detail. In the Material box you only see the material of the selected operation.
If it is a subcontract, you can from the selected operation in the structure map use a link to go to the Report arrival procedure.
You can move around in the structure using the cursor or the arrow keys ↓ and ↑ on your keyboard.

#### Expand and minimize
By using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_expand_collapse.png) you can expand and minimize all the nodes in the structure.

#### Type
The second column displays a symbol representing the part type of the part and for operation you can see a general symbol.

#### Part number
In the third column you can see the part number and the name of the main part and included parts. For operations you will see the operation number and operation name here.
