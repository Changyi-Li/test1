### BI – Purchase
- Essentially the same functionality as in G4 but with the difference that the BI (business intelligence) is an incorporated part of the program. In G5 you configure settings for when data mining for the BI should take place (Settings for BI procedure). This was externally configured for G4.
- The filtering in G5 is done in every direction, that is, if you mark a part you see information about this part in the other boxes, for example Suppliers and Countries (the map).
- So far only the purchase statistics view is available, but new views will be added by and by. You can create own views in the backstage of the procedure.
