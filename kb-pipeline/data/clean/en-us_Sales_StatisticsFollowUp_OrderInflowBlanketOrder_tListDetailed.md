### The Detailed list
The list is loaded and displayed based on the selection and settings you have chosen. As in all lists in Monitor ERP, you can drag and drop in order to change the column to group by.
The list shows detailed information about the value of each individual order row plus a total of the value for the selected grouping.
If quantity, price, discount, or setup price, has been updated on a blanket order row, you will see when, via a log date, and what has been modified. This is why the same order row can appear several times in the list.
If a blanket order row has been deleted, it will still be shown in the list. However, you will see an additional row with the corresponding quantity, price, discount, and setup price, but with negative values, which means the result of the row is zero.
