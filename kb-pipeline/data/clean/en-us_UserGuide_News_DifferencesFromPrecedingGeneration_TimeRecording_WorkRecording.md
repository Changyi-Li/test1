### Work recording
In general terms the work recording functions in the same way as in G4, but there are a few differences.

#### Personnel records
- It is now possible to select, per employee, if you should be able to enter report numbers in Start work, or if you only want to allow the employee to work in accordance to his/her priority plan.
- The field for time horizon has been removed from the personnel records and is now entered per work center.

#### Recording terminal
- For employees with the setting Only change, it is now optional if you want to start your new work item first or first finish the work which is in progress. Both these steps have to be done before you save the reporting but now you can do it in the order you choose.
- When you start work there are different buttons for Indirect and Direct work. The operator always use the button Start work and then there are different tabs for Indirect and Direct work. The setting in the personnel records decide which of the tabs will become the default tab.
- In G5 you can in advance enter that you will work with setup time for an operation. Therefore there are two buttons for applying in the mode where you start direct work: one button to start setup and one button to start unit time. To change from setup time to unit time you use the button End setup in the view which shows your work in progress in the same way as you reported/ended setup time in G4.
- There is a new type of work centers called Pool. If you choose to start a work item in a pool work center you will also have to enter which one of the linked work centers that the work item should actually run in. It is not possible report time directly for a pool work center.
