### VAT reports
This tab is available for the list type Reprint – VAT report and opens when you load the list. In the left section you see the selected VAT reports. By marking a report in the result list you open the selected report and can view it in the right section.

#### Cancel
With the the Cancel checkbox (C) in the list you decide if the report should be canceled. Mark the checkbox and save the procedure if you want to cancel the VAT report. When the VAT report has been canceled you can load the VAT report again for the same period. When canceling, a reversal voucher is automatically created which reverses the initial VAT report.
