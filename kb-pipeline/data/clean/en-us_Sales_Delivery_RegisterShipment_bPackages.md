### Packages
In this box, you add one row for each package that should be included in the shipment.
By clicking the Add new row at the end button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_row.png) (F5) on the function menu, you can add package rows.
By using the Delete selected row button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_delete_row.png) (F6) you can delete package rows. You cannot delete merged package rows. To be able to delete such rows, you will first have to split the package rows.
By using the Split row button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_copy_row.png) (Ctrl + Shift + C) you can copy the marked package row to create a new package row.
By clicking the Calculate volume and loading meters button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_calculate.png) you can calculate the package row's Volume (Length x Width x Height) and Loading meters The unit "loading meter" is used for parts that are difficult to stow or pack (e.g. cannot be packed on pallets). You enter the longest measure (in meters) of the space which the packaged part takes up when you stow it. (Length x Width / 2.4).
By using the Merge packages button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_streamline.png) you merge identical package rows.
By using the Split packages button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_auto_withdrawal_material.png) you can split already merged package rows.
With the Generate package numbers button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_run.png), you can generate new values in the Package number field. This can be used when, e.g., manually creating package rows in Register shipment.
The Delete button can be used to delete multiple rows at the same time.
Here you can enter the following information for a package row:
- Quantity – Here you enter how many packages per row should be added.
- Package type Package type describes what kind of package that is used, such as "pallet" for EU pallets, "box" for cardboard boxes etc. – Here you select among the types registered under the [Package type](../../../Stock/Parts/BasicDataPart/tPackageType.htm) tab in the Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Part procedure.
- Code – A package type code is loaded here by default for the package type, if such information exists for the package type. Otherwise you can enter a code here. Here there is a validation to make sure the package type code exists for the shipping agent.
- Goods type Goods type describes what kind of part it is, for example machine parts, electronics, etc. Goods type is printed on shipping documents. – Here you select among the types registered under the [Goods type](../../../Stock/Parts/BasicDataPart/tGoodsType.htm) tab in the procedure above or you enter a goods type on your own. When a shipment is created from the source of information called Pick list A pick list is a list of parts/products which should be picked from stock for a manufacturing order or a customer order. with package structure, the goods type is loaded from the package level (if that has been entered in Pack for delivery).
- Gross weight, Volume, Loading meters, Length, Width, and Height – Here you can enter the space needed for the package (that is, the size of the package). Volume and Loading meters can be calculated by using a button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_calculate.png) on the function menu.
- Goods label – Here you can enter the goods label with which the shipment should be labeled; a text or a reference number. The goods label is shown on delivery documents. Can contain a maximum of 50 characters.
- Package number – every package row in Register shipment is assigned a consecutive number. This consecutive number will then be used to link the shipping agent's package number to the shipment’s package rows when the shipment is exported to nShift Delivery.
- Shipping agent’s package number – under this button you will find the shipping agent's package number when you are using the integration with nShift Delivery.
