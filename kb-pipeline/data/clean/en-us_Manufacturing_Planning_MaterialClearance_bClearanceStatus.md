### Clearance status
In this box you find (depending on the selected list type) orders with main parts, orders with all included parts, orders with all included parts and operations. All orders are shown on rows in one to four sections, depending the result of the clearance.
The following sections exist: 1) With all standard material available, 2) With some material available, and 4) No material available. In sections 1-3, the Clear checkbox might be checked, depending on how you have configured the setting Suggest how parts should be cleared under the Selection tab.

#### Clear
When you save, the clearance will be saved for the records where the checkbox in this column is checked.

#### Material cleared previously (C)
In this column you will see a C if the record on the row is already fully cleared. If the record is partially cleared previously, you will see a P here.

#### Order number
Here you see the number of the manufacturing order that is being cleared. If there is material for the order in more than one section, the order number is displayed in bold font.

#### Exclude from clearance (E)
If you check this checkbox, the row will be excluded from clearance. The purpose of this is to instead let the material become available for clearance of orders in the sections 2 and 3. In that case you need to do a new clearance run using the button Re-do clearance ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_run.png) or by pressing Ctrl + R, after you have excluded one or multiple rows from clearance.

#### More info
Under the More info ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) button you will see detailed information about the record on the row.
