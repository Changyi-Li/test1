### Rows
In this box you find information about the order rows.
Show all row values ![](https://help.monitorerp.cn/CN-MONITOR_G5/G5_Sales_SV/Content/Resources/Images/button_show_hidden.png)This setting is checked by default. It means that all order rows' fields that are possible to update will be shown in the Values box. If you deactivate the button, only the marked row's values will be shown in the Values box.

#### Position
In this column you see the position number of the order row.

#### Part number
Here you see the part number of the order row.

#### Name
Here you see/enter the name of the part.
