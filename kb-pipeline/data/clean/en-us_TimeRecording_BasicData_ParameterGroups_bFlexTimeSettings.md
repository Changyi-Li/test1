### Flex time settings

#### Flex time
With this checkbox you determine if flex time should be allowed for the parameter group. The other settings in this box are only available if Flex time is checked. The Flex time setting also controls if the setting Overtime in flex zone is available in the Overtime box.

#### Time bank for flex time
Here you select the time bank to which the accumulated flex time should be added.

#### Negative flex included in daily working hours
With this checkbox you decide if negative flex time should be included in the daily working hours. If this setting is activated it means a person belonging to this parameter group has the right to overtime directly after the end of the schedule regardless of negative flex or positive flex during the person's other recording for the day.

#### Salary type positive flex and negative flex
Here you select salary types for positive flex and for negative flex. It is not possible to select the same salary type for both these flex types.
