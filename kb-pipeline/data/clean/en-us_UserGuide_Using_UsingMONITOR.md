# Using Monitor
This part of the online help function is continuously documented as functions are developed in Monitor ERP.
Here you find descriptions of different major features and how to use them in Monitor ERP. For example how to check delivery times, use traceability, etc. But also how to perform calculations, valuations, planning, etc.
> These descriptions are based, where appropriate, on the standard use of Monitor ERP. This does not mean your company has to use Monitor ERP according to the descriptions – these should be seen as examples.
