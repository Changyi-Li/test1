### Opening balance
- The procedure is easier to grasp in G5 than in G4. All opening balances are shown in a table with rows. Adjustments can be made directly in the table.
- Function to load all balance accounts in the table in order to enter only amounts for OB, not account.
- OB can be entered in external currency for an actual currency field instead of via quantity as in G4.
- When loading OB you can see the result of this before you save.
