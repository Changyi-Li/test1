### Pre-calculation
When pre-calculating a configured part there are two methods to choose from: With configuration and without configuration.

#### With configuration
If you have certain standard options which are included in the part's basic price, the pre-calculation is most of the times done with configuration and a default template. Then you select Complete in the Configuration field in the settings for the pre-calculation.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/TrainingMaterial/ConfiguratorPreCalculation1.png)](../../../../Resources/Images/TrainingMaterial/ConfiguratorPreCalculation1.png)
When you have loaded the list with the part, you get to configure the part under the Configured button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/Button_Configuration_Available.png). When the part has a configuration, the button is shown with an orange puzzle piece ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/Button_Configuration_Done.png).
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/TrainingMaterial/ConfiguratorPreCalculation2.png)](../../../../Resources/Images/TrainingMaterial/ConfiguratorPreCalculation2.png)
You then start the pre-calculation as usual by clicking the button Start calculation ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_run.png) on the toolbar of the procedure.

#### Without configuration
If you instead have entered a price for each option, including the standard options, a pre-calculation is in most cases made without configuration. Then you select No in the Configuration field in the settings for the pre-calculation.
You directly start the calculation after you have loaded the list, provided that you do not want to change any other information in the list prior to the calculation.
