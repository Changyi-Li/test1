### Selected parts
This is the upper list under the Manual mode tab. Here you see the parts you have found by searching. In this list you select for which parts a quantity should be moved. This is done by either checking the Move all box or by entering a Quantity to move.

#### Batch
If the part on the location has a batch number, this is shown here.

#### Serial number
If the part on the location has a serial number, this is shown here.

#### Last arrival date
Here you see the stock location's last arrival date.

#### Move all
If you check this box, the entire available quantity will be moved from the location.

#### Qty to move
Here you can enter a quantity to move from the location.

#### Unit
If the part has multiple units, you can here select the unit in which the quantity should be moved. The part's standard unit is selected by default.

#### Available balance
Here you see the part's available balance.

#### From type
Here you see a symbol illustrating which type of location you are moving the quantity from. There is also a tooltip letting you know the type.

#### Location
Here you see the part's location.

#### Delete location when balance is zero
The checkbox can be marked for part that do NOT have random stock location. If random stock location is activated, the location automatically disappears if the balance of the location becomes 0 (zero). This means you have the opportunity to achieve the same thing for part that do NOT have random stock location.

#### Best-before date
If the part has a batch in the location with a best-before date, this column is displayed where you can see that date.

#### Priority
Here you see the priority of the location form which you are moving the quantity.

#### From warehouse
In this column you see in which warehouse the quantity to move from is available. This column is displayed if the Warehouse option is installed.

#### Charge number
If the part on the location has a charge number, this is shown here.
