### View
Under this heading you can configure different settings for what to show in the lists.

#### View level
With this setting you decide if Material, Operations, and Tools, or a combination of these, should be shown in the Consists of and Included in list. The tools alternative is available if the Tools & Maintenance option is installed. Please note! Operations cannot be displayed in the Included in list.

#### Fully expanded
If you activate this setting, the lists will be fully expanded by default.

#### Only parts with structure
This setting determines whether only parts with structure will be shown in the Consists of list.

#### Only unique material
This setting determines if an "included in" analysis will be made of each material in the structure map. This can be done in order to see whether the material is also included in other BOM and routings. If the material is not included in other BOM and routings, it will be displayed in the Consists of list as a material unique for the main part.
This setting can be useful in cases where the main part shall be phased out, in order to see the included material that will be directly affected. In such cases, you might wish to avoid having an unnecessary large stock of the included material.

#### Operation instruction
With this setting you determine whether or not the operation instruction should be displayed on the printout.

#### No. of levels
Here you decide how many structure levels of the parts should be shown in the list. The default here is 25 levels.
