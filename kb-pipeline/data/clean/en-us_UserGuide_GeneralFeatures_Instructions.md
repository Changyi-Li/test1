### Instruction
Under Instruction in the backstage of the procedure it is possible for appointed users to write instructions, as a help to other users on how to apply the procedure in your specific company.
With the setting Allow modification of procedure instructions in the Users procedure you can decide which users should be allowed to write new instructions and to modify existing instructions. If this setting is activated it means the user has access to Instruction in the backstage of the procedure, otherwise this section is not shown.
The text editor available to write instructions in works in the same way as the text editor found in other parts of the system, for example the text editor on additional text rows. Here you can also format text, insert hyperlinks and images.
When you write or modify an instruction it will automatically be saved in the background. The Instruction button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_instruction.png) (Ctrl + Shift + I) becomes activated on the toolbar of the procedure when you start writing an instruction. Using this button the users can then read the instruction. For a user the button appears for the first time in an orange color ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_instruction_unread.png) which indicates that there is a new or modified instruction. When the instruction has been read the color of the button shifts into black. If the instruction is then modified, the button will turn orange again.
