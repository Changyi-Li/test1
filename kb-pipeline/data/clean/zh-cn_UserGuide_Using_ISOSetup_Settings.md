### 设置
订单使用 ISO付款所需的不同设置 Monitor ERP概述如下。
在里面 银行设置 按通用登记程序你激活了您公司使用由的银行。
激活银行​
1. 打开 银行激活 标签页。
2. 默认下，你将在这里看到系统所针对的国家 / 地区（由国家 / 地区/包装确定）。不过，你可以选择其他国家 / 地区。
3.   
你可以在这里选择使用哪家银行。这决定了哪些激活文件格式将显示在到右边的框中。
4.   
在下面 激活文件格式 你可以看到系统中已激活的付款格式。该列表显示系统中处于激活的全部格式的合计，仅不你到右边的行（即一你已选中为激活）。当你已激活银行后，你会查询该银行的格式可用于选择的电子付款方式下 付款方式 标签页，然后在 导出 / 导入设置 程序。
文件的导出和导入设置在 导出 / 导入设置 在通用登记中。
导出设置
1. 打开 导出 标签页。
2. 选择 付款文件 在导出类型下。
3. 选择一个 付款格式。
4. 输入付款文件的路径 路径。
5. 在下面 文件名称，文件的名称作为带有变量的模板预先填充。这 ％吨 变量将事务列表的编号插入到文件名称中。这 ％X 变量将今天的日期插入到文件名称中。当你将鼠标悬停在该字段上时，将出现一个工具提示，其中包含对变量的解释。
6. 输入一个 审核人标识。你可以从您的银行获得此信息。
7. 输入 协议编号。你可以从您的银行获得此信息。
8. 合并付款 默认已选择，Danske 银行（瑞典）和北欧银行（芬兰）除外。这控制付款是否合并。如果时间向同一供应商已发送多个发票，则可以将它们合并为付款文件中的一合计。对于Danske 银行 （瑞典）和北欧银行 （芬兰），你可以选择 使用批量付款。
9. 保存。
你配置在 银行设置 付款方式标签页下的程序。
导入设置
1. 打开 导入 标签页。
2. 选择 确认对外付款 在导入类型下。
3. 你可以输入已保存付款文件的目录路径 路径。
4. 保存。
银行设置
1. 打开 付款方式 标签页。
2. 在表格中添加代码ISO，并输入名称。
3. 选择 电子付款 在付款类型下。
4. 检查下面的方框 激活的。
5. 在银行信息框中输入 付款格式 和 确认格式。
6. 选择 事务列表 ISO (标准) 在事务列表框中。
7. 保存。
根据你使用的银行，银行账号的已登记方式略有不同 银行账号 程序。对于具有更多具体设置的银行，您可以找到低于指导。
银行设置– 瑞典银行
在表格中连续输入清算和帐号，中间否空格或标点符号。 发件人账号BBAN 字段。
如果清算编号以8开头，你必须输入15位数字。
如果清算编号组成帐号少于 15 个字符，请在清算编号和帐号在中间输入零。
如果清算编号以7开头，你必须输入11位数字。
全部已发送至瑞典银行的付款都可以在单个文件中发出，尽管建议将欧元和其它货币区分单独的文件。
银行设置– 北欧银行
由于北欧银行使用货币口袋，因此你必须输入以下银行账号的链接： 付款方式 标签页。这是在 链接到银行账号 / 簿记科目 盒子。
供应商登记
确保已在供应商处输入正确的付款方式 付款 框中 供应商登记。如果需要，请单击 导出设置 按钮来为特定供应商设定例外。
你可以通过选择批次更新供应商的付款方式 付款 在格式中 供应商列表 程序。使用 查询 & 替换 快速、轻松地更新记录。
