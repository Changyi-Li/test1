## Production schedules
In this procedure you handle schedules for work centers. Production schedules are used to define the capacity for a work center by entering when during the day there is capacity available. If the work center applies hourly planning, you should use this type of schedules instead of entering a basic time. These schedules are used as components when creating production schedule cycles.
