### Recording terminal

#### Only recording with card
Here you determine if recording must be done using card number or code in all recording terminals and the . For each person you then enter a card number or an optional code. This is made by using button Card number in the Personnel records – Time recording procedure.
If this system setting is set to Yes, you can make exceptions from recording with card number on a specific recording terminal. This is done by adding this recording terminal's users in the Terminal settings procedure and there deactivate the setting Only card.
Conversely it is also possible to set recording with card as mandatory on a specific recording terminal if this setting is set to No. This is done by adding this recording terminal's users in the Terminal settings procedure and there activate the Only card setting.

#### Number of seconds before clearing of recording terminal
This system setting determines how many seconds should pass before the recording terminal will be purged automatically and return to its basic mode. This is useful if for example a person has left the terminal in recording mode. If for example a person has logged in to the terminal to see information about his/her latest recording and then forgets to clear the terminal by using the button Clear ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_delete.png).
