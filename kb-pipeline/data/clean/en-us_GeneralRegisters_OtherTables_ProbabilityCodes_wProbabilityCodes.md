## Probability codes
In this procedure you register probability codes that should be used in the system. When you start up the system for the first time, there are no registered probability codes.
You can also delete an existing probability code. A validation is then made against the quote register to make sure that the probability code is not used in any quotes or customers. If so, you cannot delete the probability code.
The purpose of probability codes is to indicate the probability of a possible customer to become an actual customer, or a quote to become a customer order.
