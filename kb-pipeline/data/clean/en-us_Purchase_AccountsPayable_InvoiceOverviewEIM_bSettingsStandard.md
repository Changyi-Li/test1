### Settings – Standard

#### Status
With this setting you decide which invoices should be included in the list. This is based on in what stage of the flow the invoice is at the moment (invoice status). If you select to include Filed, a column containing the final recording date will be shown in the list.

#### Include
This setting is available only if the alternative Sent for authorization has been checked in the previous setting. With this setting you select if you want to include the signer who right now has the invoice, has had the invoice, and/or will receive the invoice.
If you, in addition to the status Sent for authorization, also have selected some of the other status alternatives in the drop-down menu Status, then all invoices with this status will be displayed regardless of what you select in Include. The selection made in this setting only affects invoices with status Sent for authorization.
Invoices that have not been attended and for which parallel authorization has been activated, are shown on separate rows for all included signers in the list.

#### Handling time more than
This setting can be used as a filter in order to load invoices that have been waiting for authorization for a long period of time. If you for example enter 7 days in this field, you will in the list only see invoices that have been awaiting authorization for a week or longer. By default 0 (zero) is selected in this field.
