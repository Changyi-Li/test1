## Settings for incoming e-mail
In this procedure you can add e-mail accounts linked to an Exchange or IMAP e-mail server. The purpose is to be able to load incoming e-mail messages from external e-mail servers.
For each e-mail account you can select one or multiple record types or functions in Monitor ERP that the e-mail account should apply to.
You also find a function button used to validate the selected e-mail address.
