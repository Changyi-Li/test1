### The Project exceptions list
Here you can exempt users from default settings for cost types in the Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Project procedure.
Under Part for invoicing, you can determine whether another part should be selected by default on invoice bases based on the employee’s reports. If no exception is registered, the part shown under Default part will be used.
Under Hourly cost, you can enter whether another hourly cost should be used when the user creates reports linked to the cost type.
