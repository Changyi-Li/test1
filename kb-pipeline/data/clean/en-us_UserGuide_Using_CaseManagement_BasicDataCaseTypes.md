### Basic data for different case types
In the procedure Basic dataWith "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Case you can enter default basic data for different case types, such as customer nonconformity or supplier nonconformity. There are four basic types predefined in Monitor ERP, and these can in turn form the basis for their own case types.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/TrainingMaterial/BasicData_Case1.png)](../../../../Resources/Images/TrainingMaterial/BasicData_Case1.png)
The four basic types are:
- Customer nonconformity – claims received from customers regarding nonconformities.
- Supplier nonconformity – claims made to suppliers, for nonconformities found for example during receiving inspection.
- Internal nonconformity – internal claims, adjustment operations or substitute orders.
- 8D Investigation report – if you use the 8D (Eight Disciplines Problem Solving) method, you can choose this basic type for your cases.
You can create as many own phases and activities as you please. This is done under the tabs called Phases and Activities. The phases and activities are used to describe a predetermined or default work flow or procedure for managing the different nonconformity events that can occur.
You can also create an optional number of own costs under the Costs tab. These costs are used for the later follow-up of costs relating to poor quality. There are three cost types predefined in the system and these are used to load costs from operations or manufacturing orders for a case. These cost types are not shown under the Costs tab.
