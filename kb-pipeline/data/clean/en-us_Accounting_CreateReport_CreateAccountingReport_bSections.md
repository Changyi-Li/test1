### Sections
In this box you add the section rows which should exist in the report. The section rows can be added in a structure map, with rows for headings, accounts, and totals.
Using the function buttons you can – in addition to adding, inserting, and deleting – also insert underlying rows/sub-sections as well as copy rows of the level which is marked.
A section can e.g. consist of a row containing a heading text in the header plus a total of the entire section in the footer. Such rows show a folder symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/gridFolderImage.png). In the section, underlying rows are included with data filter on account and dimensions and sub-totals, if any, on each row. Such rows show a data symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/gridDataImage.png). You create the configuration of each row in a section in the Settings box.

#### ID
In this column you see an ID for the section row in question in the report.

#### Name
Here you see/enter an explanatory name for the section row. This text is only shown here and not in the report.

#### Translations
By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.
