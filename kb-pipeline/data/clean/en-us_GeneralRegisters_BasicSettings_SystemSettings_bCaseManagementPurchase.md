### Case management

#### Create case/supplier nonconformity at rejection on purchase order
This system setting determines if a case must be created, should be possible to create, or should not be created at rejection on purchase order during receiving inspection.

#### Default case type
This system setting determines which case type should be set as default if a case is created at rejection on purchase order. The selectable case types are the ones registered for the basic type Supplier nonconformity in the Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Case procedure.
