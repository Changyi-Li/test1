### 服务
在此标签页下，你可以添加已选择货代将用于的货运服务。
也可以使用按钮待复制现有的服务 复制行 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_copy_row.png) 功能菜单上的（Ctrl + 班次 + 当前日程表图表 ）。任何附加服务也将被复制。

#### 服务
在输入你的内部的名称。

#### 代码
在输入你服务的货运代理的代码。

#### 货运模板
你在此处输入你链接到该服务的货运模板。货运模板必须第一个在 模板 标签页。
Pacsoft Online、 nShift 交付 、LogTrade的设置：
如果货代链接至以下任何导出插件，则存在这些设置： Pacsoft 在线， nShift 交付， 或者 日志交易。如果货代链接至 nShift Web-TA，在模板标签页下有具体的设置。

#### 集成打印机队列
应用至 日志交易。在输入你用于打印的打印机队列的名称。

#### 选项
通过使用 附加服务 按钮 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_more_info.png) 你可以在货运服务中添加附加服务，这些服务应该可以在使用该货运服务的货运中选择。你还可以将附加服务设置为 默认。然后它将自动已添加货运中。当你已添加了附加服务时，此符号 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_more_info_have_data.png) 将显示于按钮上。
如果货代连接到 nShift Web-TA，你可以通过 nShift Web-TA科目中的不同“模板”选择附加服务。你模板在​ 模板 标签页。然后你货运模板链接到每个相应的 nShift Web-TA货运服务。

#### 发件人 ID
你可以在此处输入发件人的标识编号。你也可以将此字段空。对于新建的货运服务，默认输入 0（0）。

#### 使用发件人 ID
- 如果你已激活此设置，则文件(API调用) 中的发件人名称、地址和联系信息字段将被清空。
- 如果你已激活此设置，则意味着nShift 交付将基于“快速标识”（发件人 ID ）使用发件人。
- 如果你不已激活此设置， nShift 交付将使用文件表格的发件人的名称和地址。

#### 发送人 / 仓库
如果你使用 仓库 选项，你可以通过点击 发送人 / 仓库 按钮 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_more_info.png) 输入每仓库的发件人标识 。这然后覆盖前道一个字段中输入的通用发件人标识 。

#### 合并货运
你可以在此决定是否将默认使用此货运服务的货运已添加到合并货运中。该字段被称为 合并货运 默认设置为 是的 在货运中。还有 合并 key 在货运你可以使用客户号或今天的日期。这是由系统设置决定的 合并货运。

#### 在 nShift 中补充 / 打印
应用至 nShift 交付。在这里，你可以决定是否默认在 nShift 中补充或已打印此货运服务中的货运。
也可以针对特定货运已激活/未激活该设置 登记货运 只要货运不已收到状态4 （已导出），就可以程序。
此设置意味着你将货运导出至 nShift，然后你可以在 nShift 的网址上从您的科目中补充它们并打印货运文档。在 nShift 中，这些货运被称为“存储的印刷品”。
订单使这些货运在 Monitor ERP 中完成，你应该在 更新货运状态 程序激活已已打印货运的已排程负荷。然后， 在 Monitor会补充货运，例如货运代理的货运号、货代包装号，并将状态从 4（已导出）已更新为 5（已预定 / 已打印）。在该程序中，你还可以载入货运列表来检查它们是否完成。

#### 卖家地址
在这里，你可以决定在使用此货运服务时你也要在货运中导出卖家地址。

#### 销售员 ID
应用至 nShift 交付。如果你使用卖家地址，则会已导出此标识 。该标识用于在nShift中将地址与发件人匹配。

#### 使用销售员 ID
- 如果你已激活此设置，卖家的名称、地址和联系信息字段将在文件（API调用）中被清空。
- 如果你已激活此设置，则意味着nShift 交付将基于“快速标识”（销售员 ID ）使用销售员。
- 如果你不已激活此设置， nShift 交付将使用文件表格卖家的名称和地址。

#### 买家地址
在这里，你可以决定在使用此货运服务时你也要在货运中导出买家地址。

#### 运费付款人地址
你可以在此决定你在使用此货运服务时也在货运中导出运费付款人地址。
