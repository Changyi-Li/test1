### Result
With the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) you can go to the Pack for delivery procedure when you have created the pick list.
With the Show cover packaging button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_show_hidden.png) you can decide if cover packaging should be shown. Cover packaging can make it hard to get an overview of the structure of the packages which require label.

#### Include
With this checkbox you decide if Pick list A pick list is a list of parts/products which should be picked from stock for a manufacturing order or a customer order. or Transport label, sales should be included in the printout. You print by clicking on the Print button in the toolbar of the procedure.
After the printout you approve it by using this button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/StatusFinished.png). If the list type called Pick list by order is selected and the Update the customer order status to "Picking in progress" setting is activated under the Selection tab, the status on the order will be updated to 4 (Picking in progress) when you approve the printout. For the Picking plan list type the status of the order is updated to 4 (Picking in progress) when you create and save the pick list in the procedure. If the list type called Picking in progress is selected and you reprint it, no update of the status will take place.
Click the button Cancel ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_cancel.png) if you want to undo the printout or if something went wrong during the printout, for example a paper jam in the printer.
You can also print the "transport label, sales" at a later time in the Print delivery documents procedure.

#### EDI export
This column is shown if Export principle for dispatch advice has been set to Export at delivery planning in the EDI EDI is the acronym of Electronic Data Interchange. EDI is about exchanging electronic business documents with your business partners, e.g. customers and suppliers. The EDI concept can be wide and a bit unclear, and can many times be used about all types of documents which are sent electronically, even if it might be PDF files sent via e-mail or publishing business documents on a website. What we refer to as EDI – and what is traditionally meant by EDI – is structured business documents following given standards, electronically sent or received and which are compiled and interpreted automatically and that is integrated with the customer's/supplier's ERP system. behavior to which the customer on the order is linked. Here you can then choose if the dispatch advice should be exported via EDI in connection with approving the printout of the pick list.

#### Quantity/package
If you have chosen to print the document "Transport label, sales" you can here change the quantity per package to be shown on the transport label.

#### Number of copies
Here you select the number of copies that should be printed of the Transport label, the Pick list – Ready for delivery, or the Pick list – By order. The default value here is 1. If you want a different default quantity, this is configured in the Document settings procedure.

#### Printed when
Applies to the list types Picking plan and Pick list by order. Date it was printed.

#### Printed by
Applies to the list types Picking plan and Pick list by order. Who printed the list.
