### Print supplier invoice journal
- The journal is now a document which can be redesigned using the new document concept in G5.
- Makes sure that the period is open at an earlier stage than what was done in G4.
- More information in the journal, for example amount in external currency and displaying voucher date on each row when using detailed integration.
- You can go to the Register supplier invoice procedure from the journal.
- It is possible to adjust certain data in the coding/posting prior to approval.
- Here you can print journals for preliminary recorded and final recorded supplier invoices with postings. The journals can be reviewed and approved in order to then be transferred to the accounting. In G4, the journals ended up in the Load Vouchers procedure.
- It is now possible to reprint old journals (ledgers).
- Always a separate journal type for cancellation of supplier invoices. In G4 this was dependent of a system setting.
- Clearer function to manually steer the journal to optional voucher date in the selection. Can also be done using detailed integration.
