## System settings
In this procedure you will find system settings that apply to all procedures in the entire company.
The system settings are divided into one tab per module. Under these tabs, the system settings are then divided into different sections within different areas.
When you start the Monitor ERP for the first time, you will find a number of basic settings for system settings that cannot be left empty. If Monitor ERP has been converted from Monitor G4, the system settings will be inherited (in case the setting also exists in Monitor ERP).
Prior to the actual startup of your MONITOR system (before go-live), you should review the system settings and change them if needed.
> Save and close all other procedures when changing the system settings. Many system settings require that the procedures are restarted in order for them to apply/be visible.
Next to a system setting that has been changed you will see this button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png). When clicking this button, you see who has changed the setting, date and time of the change, and which changes have been made.
> The button Go to field ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_search.png) (Ctrl + G) on the toolbar is very useful. Here you can search for a specific setting.
