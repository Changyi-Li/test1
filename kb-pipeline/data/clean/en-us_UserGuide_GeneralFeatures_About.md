### About
Under About in the backstage of the desktop you for example find information regarding version number and build for Monitor ERP.
Here you also find a link to the changelog for the version in question. In the changelog you find information about new features and changes included in the version.
Synchronize
Once every 24 hours, an automatic synchronization is made with Monitor's distribution server regarding the system configuration. This synchronization activates user licenses, options, or adaptations which you have acquired. Above the button you see when the synchronization was most recently made.
If you immediately need access to what you just purchased (for example an additional user license), you can click the Synchronize button to manually run the synchronization, and you don't have to wait for the next automatic synchronization.
> The Synchronize button is only available to users who have the role of ERP manager.
