### Settings for Cloud printer

#### Sender e-mail
E-mail based print server. Here you enter the e-mail address that should be used as sender when when the print jobs should be sent as e-mail.

#### User name in Exchange account for sender
E-mail based print server. Here you enter the user name for the Exchange account that should be used when the print jobs should be sent as e-mail.

#### Password to Exchange account for sender
E-mail based print server. Here you enter the password for the Exchange account that should be used when the print jobs should be sent as e-mail.

#### PrintNode API key
Here you enter the API key required to communicate with PrintNode.
You can read more about PrintNode [here](https://www.printnode.com/).
