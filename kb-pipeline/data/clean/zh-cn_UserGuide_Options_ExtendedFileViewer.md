# 扩展的文件阅读器
扩展的文件阅读器选项 Monitor ERP 当你将外部文件链接到数据库中的记录时，它提供对多个不同文件类型的支持。该选项支持常用的图纸格式、图片格式以及不同的 MS 办公室文档格式。
通过使用扩展的文件阅读器，你可以在查看窗口中以原始格式预览全部已链接的外部文件。如果没有扩展的文件阅读器，你仅视图PDF文件。
你还可以使用查看窗口中已链接的外部文件的“自动打印”功能。这在处理PDF文件以外的其它文件时使用。
处理链接至记录的外部文件 Monitor ERP 简化如下：
- 直接以原始格式链接文件，而无需创建文件的 PDF份数然后链接这些副本。
- 当原始文件是已更新或已变更时，不重新链接文件的副本。
