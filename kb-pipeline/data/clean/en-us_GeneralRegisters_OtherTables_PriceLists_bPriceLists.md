### The Price lists table

#### Price list
This is a consecutive number for the row. It cannot be changed.

#### Name
The name of the price list. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Currency
A price list is always linked to a currency code. Here you select the currency code that applies to the new price list. Currencies are registered in the Currencies procedure

#### Change currency
By using the button Change currency ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_change_record.png) you can change the currency for an existing price list. In the dialog box that opens, the box "Convert to sales price" is checked by default for parts quotes, and orders that use this price list. However, you can choose not to convert the prices by unchecking this box.
