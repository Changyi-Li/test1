### Material reporting
In this mode you report material for a work item in progress.
The material reporting mode can also be shown when you start a work item, if it has been configured that material should be withdrawn during start of work. If withdrawal of material should take place at start of work, is generally determined by the system setting Suggest withdrawal of material at start of operation. But you can override this with a setting on the work center. If it is not configured to withdraw material at start of work, you report the material at the end of work.
By using the Suggest remaining button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_suggest_rest.png) on the function menu, the remaining quantity will be suggested for all materials. Then you first get the opportunity to select for which operations this should be done.
With the button Only show material with remaining qty ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_preview.png) you can hide the rows with zero remaining quantity.
By clicking the button Show all locations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_form_viewing.png) you can see all locations for the materials. You also see the locations which are not suggested for withdrawal. You can then expand the material rows to see all the locations.
If you are allowed to perform material withdrawal, you can also use the button Add new row at the end ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_row.png) (F5) on the function menu, to add part rows with extra material and report these. With the button Delete selected row ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_delete_row.png) (F6) you can also delete part rows you have added.
If you have not selected that remaining material should be suggested, you can in the field Quantity to report manually enter quantity to report of the material. You can enter the quantity from the operation row, which is used to suggest the corresponding quantity for all materials linked to that operation. Another option is to enter a quantity on a part row or on location rows under the part, to report only that specific material. Operation rows appear in italics. Part rows are shown in bold font.
In the field Remaining quantity you can change the remaining quantity on part rows.
The information shown on the rows corresponds to the information shown on material rows when stopping work.
When material reporting a work item in progress, the work time is not stopped. The work item remains as "in progress" after the material reporting.
Batch record orders using the same tools
The same tool will be withdrawn to all operations in a batch which are using the tool. The withdrawal takes place via automatic reporting at the first partial reporting or via the Material reporting window, depending on the configuration of the system settings. The tools are automatically returned when you stop work. If there is a remaining quantity on the operation at the time of the return, the remaining quantity on the tool will be reset to make it possible to withdraw it again when the order is started again.
Please note! The add to batch function cannot be used yet. Manual withdrawal and return in other procedures is not supported if operations will be batch recorded.
