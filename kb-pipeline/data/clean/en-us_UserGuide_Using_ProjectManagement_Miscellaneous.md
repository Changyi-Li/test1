### Other procedures in the project accounting

#### Project list
In this procedure you can create a list of existing projects. The list contains basic information about each project. Most of this information can be updated in the list.

#### Direct project reporting
In this procedure you can register cost, income, or time used for a project. Costs and time that are otherwise difficult to find or register can be entered here. You can also report income for the project.

#### Report activity – Project
Here you can report project activities in a list, per user.

#### Activity list – Project
Here you can follow-up on and monitor all project activities. You can also view a log containing all reporting items in total per department, project, etc. for a selected period of time.

#### Project follow-up
Here you find a number of different list types used to follow-up on multiple projects at the same time. With these list types you select which information to load and on what level of detail.

#### Time check
Here you can create detailed reports focusing on hours that are linked to more than one project.

#### Time check
Here you can create detailed reports focusing on hours that are linked to more than one project.

#### Revenue calculation
In this procedure you perform revenue calculation for projects with the revenue calculation method called Percentage of completion method.

#### Print revenue calculation journal
After you have saved the revenue calculation you have to print the journal to transfer the values to the accounting.

#### Calculate material cost
In this procedure you can calculate and adjust material costs for projects. This can be useful in cases where not all parts that have been purchased for a project have been used in the project, or the remaining parts that have been purchased for a project have been used in another project.

#### Print material cost calculation journal
In this procedure you can print journals for material cost calculations by project. After you have saved the material cost calculation you have to print the journal to transfer the values to the accounting. New records are added in this procedure as write-downs or write-ups are saved in the Calculate material cost procedure. Once the journal has been approved, you can see the voucher with the increased/reduced cost in the project.

#### Release invoice basis – Project
In this procedure you can release invoice bases from project reporting. The invoice bases are based on reports and additions that are registered via Direct project reporting, Recording terminal, or the TimeCard option.
