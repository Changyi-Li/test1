# 安装准备 Monitor ERP 网络服务器
> 低于描述的措施应由您的 IT部门或 IT供应商执行由。如果你有任何疑问，你通过电话联系人MONITOR支持中心：+46 650 766 03 或通过Email： 支持
Monitor ERP Web服务器可以安装在程序服务器（ MONITOR服务器）上，也可以安装在 DMZ 中的单独计算机上。如果 Web 客户端仅在网络中本地使用，则方式在MONITOR服务器上安装。如果 Web 客户端也需要在网络外使用，则方式在 DMZ 中的单独计算机上安装。对于此安装，你还需要计算机的 SSL认证，请参见低于。
无论使用何种方式安装Web服务器，你都需要在安装的计算机上拥有一个具有本地管理员权限的 Windows科目。安装过程中 Monitor ERP 网络服务器,你可以选择一个科目来运行与安装连接的 安装服务.然后你应该选择这个科目。你可以使用与运行程序服务器（MONITOR服务器）的服务相同的科目。

## SSL认证
1. 为将功能Web服务器的服务器采购SSL认证。这应该是发出自的认证。认证可以为计算机的 DNS名称颁发（例如“MONITOR.yourcompany.com”），也可以为整个域颁发（即所谓的通配符认证“*.yourcompany.com”）。
2. 当你收到认证文件时，请将其安装在将功能Web服务器的服务器上。必须使用与您的认证链接至的私钥来安装认证文件，仓储费用周三然后在安装​​程中连接该认证。

## 防火墙配置
低于表描述了如何为MONITORWeb服务器已配置防火墙。结束，说明了完成环境中的网络，两者包括程序服务器（MONITOR服务器）、Web服务器*、分配服务器**、Windows 客户端和 Web 客户端。在此图中，你可以看到使用了哪些端口以及流量的方向。
> * 安装程序服务器（MONITOR服务器）时，已配置了防火墙以用于 Windows 客户端、程序服务器和分配服务器在中间的通信。这意味着你可以跳过低于表中的那些组件。
> **分配服务器提供以下更新 Monitor ERP、选项和许可。这些服务器由 Monitor ERP 系统有限公司 并可用于欧洲和中国地区。DNS 名称是 cdn-eur-01.monitorerp.com 和 cdn-chn-01.monitorerp.cn。目前每地区有一服务器节点（节点号01）。很快将已添加服务器节点号02（DNS名称 cdn-eur-02.monitorerp.com 和 cdn-chn-02.monitorerp.cn 分别）。

### 网络防火墙
| 协议 | 端口 | 方向 | 功能 |
|---|---|---|---|
| TCP | 7710 | DMZ → LAN | 用于更新网络服务器。 |
| TCP | 8001 | DMZ → LAN | 由 Web服务器使用由与程序服务器（MONITOR服务器）进行通信。 |
| TCP | 8714 | 局域网 → DMZ | 用于更新网络服务器。 |
| TCP | 443/80 | 互联网 → DMZ | 用于Web 客户端和 Web服务器在中间的全部通信。端口443用于SSL；否则使用端口80。 |
| TCP | 443/80 | 局域网 → 互联网 | 用于程序服务器和分配服务器在中间的全部通信。用于程序服务器和客户端与外部的服务的全部通信。端口443用于SSL；否则使用端口80。例如，外部的服务包括货币更新服务和货运服务。 |

### 程序服务器（MONITOR服务器）中的 Windows 防火墙
| 协议 | 端口 | 方向 | 功能 |
|---|---|---|---|
| TCP | 7710 | 入站出站 | 用于更新Windows 客户端。 |
| TCP | 8001 | 入站出站 | 由 Windows 客户端和 Web服务器使用由与程序服务器通信。 |
| UDP | 8002 | 入站出站 | 使用由自动查询程序服务器。 |

### Web服务器中的 Windows 防火墙
| 协议 | 端口 | 方向 | 功能 |
|---|---|---|---|
| TCP | 7710 | 出站 | 用于更新网络服务器。 |
| TCP | 8001 | 出站 | 由 Web服务器使用由与程序服务器（MONITOR服务器）进行通信。 |
| TCP | 443/80 | 入站 | 用于Web客户端和Web服务器在中间的通信。端口443用于SSL；否则使用端口80。 |
| TCP | 8714 | 入站 | 由程序服务器（MONITOR服务器）使用由向 Web服务器传送更新。 |
