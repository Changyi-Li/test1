### Database file to upload
In this box you choose which backup of the actual database you want to upload.
If it is an SQL Anywhere database, you start the upload with the Upload database button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_upload.png) on the toolbar of the procedure after you configured the settings below.
If it is an SQL Server database, you need to upload the file manually, via the link you have received from the Monitor Support Center. Or you may have to contact your IT department or ERP manager.

#### Most recent backup
If you choose this alternative, the copy of the database created at the latest scheduled backup will be uploaded.

#### Run backup now and upload this copy
If you choose this alternative, the copy of the database created now will be uploaded. By using this alternative you have the most recent copy of the database.
