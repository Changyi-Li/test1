### Settings
Settings for the different list types. If the list type is affected by the setting it is shown in parenthesis after the setting name.

#### Show columns
Detailed. This is a setting for adding extra columns to show in the list. One or more can be added.
- Currency information – Columns are shown for the posted amount in the external currency and exchange rate.
- Quantity – A column is displayed for quantity.
- VAT code – A column is displayed for VAT code.

#### Show deleted rows
Detailed and Total. With this checkbox you decide if deleted rows should be shown in the list.

#### Show
Detailed and Total. Here you decide if recorded vouchers and/or preliminary vouchers should be shown in the list.

#### Record all
Preliminary vouchers With this checkbox you decide if Record should be checked by default on all rows in the list.
