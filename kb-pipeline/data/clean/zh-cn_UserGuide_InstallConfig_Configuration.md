# 配置
在线帮助的此章节主要面向系统管理员。
配置涉及培训前以及 ERP系统上线后要采取的措施 Monitor ERP。
ERP系统由数据库服务器和程序服务器组成，你安装在计算机上，应该是 Monitor ERP 服务器。采购ERP系统被用于一个 Windows客户端，该客户端应单独安装在运行ERP系统的计算机上。该 ERP系统还有网络客户端。网络客户端可以在常规的网络浏览器中运行，也可以作为 Android 和 IOS 的应用程序运行。该应用程序可用在 Google Play 和 Apple App Store 上下载。为了能够使用该应用程序和 Web客户端 Monitor ERP 必须安装 Web服务器并且还必须已配置防火墙。这些安装的描述以及如何配置防火墙可在与安装程序一起已交货的单独文档中可用。
服务器程序是已更新 Monitor ERP 安装经理。程序 Monitor ERP 服务器已安装。服务器程序已更新之后， Windows 客户端在第一个时间已开始时会自动已更新。
安装之后， Monitor ERP 由系统管理员, ERP 经理及已审核员工共同已配置.你需要创建公司数据库的已排程备份。阅读更多 [创建并日程表备份](CreateScheduleBackup.htm) 章节。
你还应该基于公司使用系统的方式仔细检查、核实甚至更改不同的默认系统设置。还应已登记不同的基础数据。当公司从MONITOR G4 转换时，这项工作也必须在一定程度上进行。还可以从另一个 ERP系统导入基础数据（组件、组件余额、客户、供应商）。这些导入直接在 Monitor ERP。这项工作通常在安装之后但在系统你培训之前开始。
基础数据的例子是用户，然后应该为用户已分配与用户权限链接至的角色。需要这样做，仓储费用员工成员登录 Monitor ERP 并访问不同的程序。基础数据还有组件、 BOM 与工艺路线、工作中心、客户、供应商、日程表、过账维度等。可以从另一个 ERP系统或电子表格程序已导入具有余额、库位、批次号和供应商的组件。了解有关基础数据和设置的更多工作，阅读更多 [基础数据和设置](../Using/RegisterBasicData/BasicDataSettings.htm) 话题。
当基础数据已已登记并且所有设置都已控制后，系统管理员还应创建一或更多测试数据库，然后在系统培训时使用它们。阅读更多 [创建测试数据库](CreateTestDatabases.htm) 章节。
