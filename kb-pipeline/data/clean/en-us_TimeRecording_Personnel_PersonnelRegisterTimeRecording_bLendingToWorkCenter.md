### Lending to work center
In this box it is possible to – per date – lend the person to other work centers of the type Manual work and Machine. The work centers to which the person can be lent, must have been added as allowed work center in the box Settings for Start work.
If the work center to which the person is lent is of the type Machine, a warning is shown ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png) but it is still possible to lend the person to such a work center.
It is also possible to lend the person to their own work center, for example if the person will have a different availability on a certain day or days.

#### Date
Here you select the date for the lending.

#### Work center
In this column you select the work center to which the person should be lent.

#### Availability
Availability in percent for lending of the person. Default availability is the same as the work center's availability factor, unless the work center has availability entered in the box Settings for Start work. In that case, this availability will be used as default.

#### Availability factor
Here you see the work center's availability factor.
