### Connections
The name of this box is the same as the name of the connection. Here you configure settings for the connection.

#### Type
Here you see the connection type.

#### Local host name
Here you see/enter the DNS name of the local company's (the sales company's) application server (Monitor ERP server). If the local company and remote company are located on the same application server, you can use the default localhost as local host name and remote host name below.

#### Port
The TCP/IP port that should be used in the connection of the local company's application server. The default port is 8001 and this shall not be changed.

#### Remote host name
Here you see/enter the DNS name of the remote company's (the production company’s) application server (Monitor ERP server). This is also called remote server.

#### Port
The TCP/IP port that should be used in the connection of the remote company's application server. The default port is 8001 and this shall not be changed.

#### Remote company
Here you select the remote company for this connection. Start by clicking the button called Load company from remote server ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_refresh.png) to see the companies on the remote server and to be able to select one of those companies as remote company.
