### Parts
With the button Copy records to Clipboard ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_copy.png) you can copy records to Clipboard for part.
In this box you can link parts to the project. There are different purposes for linking parts to projects:
- Manufactured parts for development of a new product which you wish to keep together or follow using project.
- Manufactured customer-specific parts where manufacturing, sales, etc. should be kept together using project.
- Parts that are machines or tools for which you report maintenance and that you want to follow up on using projects.
- Lifetime analysis of standard parts which should be followed up on using project during the part's entire lifetime.
When a part is linked to a project, the system will automatically link manufacturing orders and postings to the project. For customer orders/purchase orders the project posting will automatically be made, that is, you do not have to enter project in the posting table or in the order header. For manufacturing orders, the project number will automatically be used on the manufacturing order if the part is linked to a project.
It is also possible to link a project to a part in the Part register. A part can only be linked to one project.
