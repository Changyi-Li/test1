### Backstage in procedures
Each procedure has a backstage with different functions depending on the type of procedure.
![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/Backstage_procedure.png)
Button to backstage in Customer register.
| Function | Explanation |
|---|---|
| [Side panel](SideBar.htm) | Here you select which components to show in the side panel. |
| [Links](../GeneralFeatures/Links.htm) | Here you copy hyperlinks to this procedure and record. |
| [Instruction](../GeneralFeatures/Instructions.htm) | Here you can create your own instructions for the procedure in question. |
| [Selection rows](../GeneralFeatures/SelectionRows.htm) | Here you choose which selection rows to show under the Selection tab. |
| [Presentations](../GeneralFeatures/Presentations.htm) | Here you can create own presentations for different list types. |
| [Settings](../GeneralFeatures/BISettings.htm) | Here you can configure settings in BI procedures. |
| [Format templates](../GeneralFeatures/FormatTemplates.htm) | Here you can create your own (custom) format templates for import of data from text files in import procedures. |
