### Result
This box shows a list containing the customer orders for which it is possible to print delivery documents, out of the orders you selected. At the very bottom you will see a total of how many documents are checked to be included.

#### Include
In this column you determine which orders you wish to include in the printout. The order that is marked can be seen in the Preview box.
What other information can be seen in the box is determined by the selected list type.
Delivery note, delivered
With this list type you can see the customer’s name and order number in the Result box. This list type displays the Document variant as selected above. The Files button is available if there are any linked documents. In the window opened by the button, you can see all documents which will be included when printing. The column EDI EDI is the acronym of Electronic Data Interchange. EDI is about exchanging electronic business documents with your business partners, e.g. customers and suppliers. The EDI concept can be wide and a bit unclear, and can many times be used about all types of documents which are sent electronically, even if it might be PDF files sent via e-mail or publishing business documents on a website. What we refer to as EDI – and what is traditionally meant by EDI – is structured business documents following given standards, electronically sent or received and which are compiled and interpreted automatically and that is integrated with the customer's/supplier's ERP system. export is shown is shown if Export principle for dispatch advice has been set to Export at delivery planning in the EDI behavior to which the customer on the order is linked. Here you can then choose if the dispatch advice should be exported via EDI in connection with printing of the delivery note.
Transport label
Here you see which transport label is selected according to the Transport label setting above. This can be changed per row.
Document variant
Here you see which document variant is selected in the setting called Document variant according to above. This can be changed per row.
Product description incl. certificate
With this list type you can see order number, part number, serial number/batch number, traceability level, and if there is a certificate or not.
Show duplicates in traceability structure
If you have activated the document setting called Show traceability structure for the Product description incl. certificate, it means the traceability structure will have doubled parts on the first levels (Level 0 and Level 1). With this setting you decide if the duplicates should be shown on the document.
