### Window
By clicking the Window button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/DesktopLayoutImage.png) on the titile bar you access additional buttons you can use to handle and arrange the windows for all procedures you have opened. You can minimize, reset the windows, or close all procedures. The buttons have the following symbols and shortcut keys:
- ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/DesktopLayoutDivided.png) – Side by side (Alt + S)
- ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/DesktopLayoutOverlap.png) – Overlapping (Alt + O)
- ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/DesktopLayoutMinimize.png) – Minimize all (Alt + M)
- ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/DesktopLayoutRevert.png) – Reset all (Alt + R)
- ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/DesktopLayoutCloseAll.png) – Close all procedures (Alt + C)
