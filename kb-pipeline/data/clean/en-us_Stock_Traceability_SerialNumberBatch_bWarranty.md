### Warranty
In this box you enter information regarding the warranty of the product. You can also update the information on several serial numbers/batch numbers at a time by using the list type Warranty in the Serial number A serial number is a number that is used for traceability for parts on entity level. list procedure.

#### The product is covered by warranty
With this checkbox you decide if the product is included in any type of warranty. You must activate this setting in order for the other fields in the box to become available.

#### Warranty starts
Here you enter/see when the warranty starts.

#### Warranty time
Here you enter/see for how long the warranty lasts. This is entered in number of months.

#### Warranty expires
Here you enter/see when the warranty expires.

#### Meter reading for warranty
Here you enter/see the meter reading in kilometer when the warranty will expire. The value is displayed in red if the corresponding value for Distance in the Reading box is greater. This means that the warranty has expired.

#### Operation time for warranty
Here you enter/see the operation time in hours when the warranty will expire. The value is displayed in red if the corresponding value for operation time in the Reading box is greater. This means that the warranty has expired.

#### Number of cycles for warranty
Here you enter/see the number of cycles when the warranty will expire. The value is displayed in red if the corresponding value for Number of cycles in the Reading box is greater. This means that the warranty has expired.

#### Warranty commitment
By using this button you can enter/see what the warranty covers.
