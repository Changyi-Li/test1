### Group recording

#### Group recording
Here you are able to clock multiple employees in at the same time e.g., if you were having a meeting. You need to have the Adjust work user right to use this function.
When you start a group recording, all of the employees that you clock in are loaded into a list and you need to enter a Group name and choose an Indirect code for the group recording.
If the employee is not permitted to use the indirect code, a validation message is shown where you can manually change the code for the employee or uncheck the employee. Once you have confirmed the group recording, all work in progress that the employees are checked in on is given the status Pending and the selected indirect code is started.
Once the group recording is finished, the work changes back to the pending work. An employee cannot be included in multiple group recordings.
If an employee changes work manually during the group recording, this person leaves the group and cannot change back to the pending work until the group recording finishes.
When clocking out for lunch etc., employees remain in the group recording and will continue in the group recording when clocking in again.
If the group recording finishes while someone is clocked out, the recording changes automatically back to the pending work.
If it is not possible to change back to the pending work, for example if someone has released the pending work and marked it as complete, the employee will instead be clocked in with the indirect code that has been entered in the system setting Indirect work code to start when releasing order-bound work.
