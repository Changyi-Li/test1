### Reminders
In this box you can, per signer, configure if the signer shall receive reminders of invoices to authorize and final code. You can also choose if the reminders should be sent via e-mail. Each signer can also configure these setting in the desktop backstage.
The reminders appears as a desktop alert at the bottom right corner on the screen. The tasks to authorize and final record are displayed in the Message center on the title bar in Monitor ERP, and in the desktop component Tasks – EIM.

#### Supplier invoice to authorize
Check this box if a reminder should be sent to the signer about supplier invoices to authorize.

#### Supplier invoice to final record
Check this box if a reminder should be sent to the signer about supplier invoices to final code.

#### Supplier invoice to link
(Only in systems with EIM Workflow) Check this box if a reminder should be sent to the signer about supplier invoices to link to the purchase order.

#### Send reminder via e-mail
Check this box if you also want to send the reminders via e-mail to the signer, including a link to the Windows client and the Mobile client. The signer's language setting determines the language in the e-mail message.
For this function you must also activate the service Reminder via e-mail and configure settings under the Scheduling tab. For a link to be included in the message, it is required that the user has the setting called Allow login to mobile client activated. You find this setting under the Security tab in the Users procedure.
