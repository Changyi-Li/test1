### Settings – Selection
Result

#### Days of grace
This is the number of extra days after the due date of an invoice, which the customer has got to make the payment of the invoice before any reminder will be sent. The default value of days of grace is determined by the system setting Days of grace The term days of grace (or grace period) is used at requirements planning in order to calculate rescheduling of actual orders that cover the requirement but that are too late in time, instead of suggesting a new order. for payment reminders. The payment reminder date above takes the number of days of grace entered here, into consideration. For example, if the due date is June 17th, 2016 and the days of grace are 7 days, then the invoice will be included in the reminder list if the due date is June 25th or later.

#### Number of days between payment reminders
Here you enter how many days that should be applied between the reminders. This setting is only significant for the payment reminders that come after the first reminder, since it is the days between reminders that are intended. The default number here is determined by the system setting Days of grace between payment reminders.

#### Invoice types
With this setting you determine which invoices will be included in the list. You can select among: debit invoices, interest invoices, credit invoices, on account invoices, and zero invoices.

#### Include to reminder number
Here you select which reminder number that should be included in the list. If you enter 1, only payment reminder number 1 will be printed. If you enter 2, then payment reminder numbers 1 and 2 will be printed. The default number in this field is determined by the system setting Number of payment reminders to apply.

#### Include payment reminders with negative total amount
With this checkbox you determine if the payment reminders which have a negative total amount of all concerned invoices, should be included in the result. That is, if the value of the credit invoices exceeds the value of the debit invoices.
Printout

#### Payment reminder date
List type Payment reminder. In this field you select the date to be shown on the documents as Reminder date. This is the date that will be used as the basis for the report. For example, an unpaid invoice due on May 26th, 2016 will be included in the list if the reminder date is set to May 27th, 2016 or later. This applies provided that the number of days of grace is zero. Today's date is selected by default.

#### Number of copies
Here you select the number of copies that should be printed. The default value here is 1. If more than 1 copy is printed it will say "COPY" on all documents following the first printout. This feature can be turned off with the setting Mark as copy for each document in the Document settings procedure.
The default number of copies is loaded from the settings for payment reminder and statement in the Document settings procedure.

#### Our reference
Here you enter your own reference that will be shown on the documents.

#### Customer's reference
If the payment reminder or the statement is sent to a specific customer, you can here enter which reference at the customer should be stated on the document. This field is a text field. If you leave this field empty, the reference marked as default in the customer register will be printed on the document.

#### Print to printer when e-mailing reminder
This setting determine if the reminders also should be printed to printer when they are sent via e-mail. This is useful if you want to save the reminders in a binder. This setting can be configured to be default by using the system setting with the same name.

#### Number of copies
If the setting above has been activated, this setting will be activated as well. Here you enter the default number of copies that should be printed to printer when sending reminders via e-mail. This number of copies can be set by default in the field below the system setting mentioned above.

#### Show accrued penalty interest
List type Payment reminder and Statement. With this setting you determine whether or not the accrued penalty interest should be displayed on the printout. If this setting is activated you will see the total accrued amount for the customer and the interest on which the amount is based.

#### Enclose invoice copies
With this setting you decide if invoice copies should be sent together with the payment reminder.

#### Mark as reprint
This setting is only available if you have activated the setting described above. Here you decide if the invoice copies should be marked as reprint.
