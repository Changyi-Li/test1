### Print accounting report
- Creating and printing reports have been divided into two procedures. In this procedure you print the reports created in the Create accounting report.
- You select by date instead of period. This makes it possible to print reports for any period of time down to per day. You can also select over year-ends.
- When selecting it is possible to use the functions to exclude, add row, and Clipboard of accounts.
- Reports can be translated and shown in any of your translated languages.
- In a report it is possible to drilldown from a balance to see the transactions which the balance is based on (general ledger). Numbers you can drill down from are shown with a blue underline. You can drill down via a separate window or in the same window by using the Ctrl key. You can perform further drilldown from the general ledger view to individual vouchers.
- There is support to show charts in reports. It is possible to show an unlimited number of charts. You select type of chart and its contents when you created the report in the Create accounting report procedure You can also decide if only charts should be shown in the report.
- The function for export to Excel is improved in comparison to in G4.
- You can print reports in the external currency based on the historical exchange rate. In addition, the currency and rate are shown in the header of the accounting report.
