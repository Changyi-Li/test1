### Cost/Income
Under this tab you see the planned and actual (reported) costs, as well as the income for each customer order row. A total is displayed in the table footer. This tab is not available until an order row is delivered or if it has a linked manufacturing order/purchase order which has been reported. Only the order rows that have a delivered quantity or actual costs, will be shown as rows under this tab. Only row types 1 or 2 is shown.
The calculation takes place by running a post-calculation on each of the manufacturing orders linked to the customer order row. During this calculation, both planned costs and actual costs will be loaded. If a linked purchase order exists, this will instead be used in the calculation. If there are no linked manufacturing orders/purchase orders, then the standard price on the customer order row will be used, otherwise the standard price is loaded from the part in the Part register. Please note! Costs and prices are shown for the entire quantity, not each. All amounts are displayed in the company currency.
