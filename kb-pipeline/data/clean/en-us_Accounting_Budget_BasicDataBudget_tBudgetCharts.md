### Budget charts
Under this tab you register different budget charts to be handled in the system. The budget charts you register here will be placed in the same register as the ones from the Budget charts procedure in the General registers module. Budget charts which are in use cannot be deleted.
In the upper table under the tab you enter the code of the budget chart and for how many months it applies. The number of months is reflected in the bottom table where you enter the percentage distribution. You can enter a percentage distribution with a maximum of four decimals. Please note! Budget charts used in the accounting budgets must have the same number of months as the accounting year.
You can manually enter a percentage for each month. Please note! The total of all months' percentage distribution must be 100%. If you wish to create an even distribution you can use the button called Create even distribution ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_auto_withdrawal_material.png) that you find in the bottom table. An even distribution will then be created automatically based on the entered number of periods.
