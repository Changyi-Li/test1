### Work in progress
If you have a work item in progress or work on standby, you will in the box Work in progress find the following functions.
If you check the box Include for a work item in progress, then the respective button in the box becomes available, under the conditions stated below.

#### Start setup
With this button you start a setup work item in the selected direct work in progress. The setup time is started and the unit time is stopped. You use this button if you need to add more setup time to a work in progress. You confirm it via a dialog box. This button is only available if the work in progress in question is a direct work in progress.

#### End setup
With this button you end setup work in progress. The setup time is stopped and the unit time starts for the selected work item. You confirm it via a dialog box. This button is only available if the work in progress in question is a setup work item in progress.

#### Partial report
With this button you change to the mode where you can partial report work in progress. The button is available for direct/indirect work in progress, as well as for project activities in progress.

#### Material reporting
With this button you change to the mode where you can perform material reporting for work in progress. This button is only available if the work item in question is a direct work in progress and the person is allowed to report material. Read more about [Material reporting](bMaterialReporting.htm).

#### Release standby
With this button you release the work on standby (after answering a control question) to the priority plan and thereby making it available for other operators to start. This button is only available if the work item in question is on standby.

#### Shop packet
By clicking the button Shop packet ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you can manually perform direct printouts of shop packet and transport label for the selected work in progress. It is the same function as is available in the [Direct work](bStartDirectWork.htm) mode.

#### Stop work
With the Stop work button you change to the mode where you can stop (finish) work in progress. The button is displayed in the Recording section if you have at least one work item in progress.

#### Include
By checking the Include checkbox you can pre-select a certain work in progress to stop, before you click the Stop work button above. Otherwise you can always select the work item to stop afterwards, in the mode where you stop work in progress.

#### Other information shown in the table:
Type refers to the recording type. Here you see a symbol representing which type of work it is: setup work ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/StatusOpStarted_15x15.png), direct work ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/gridDirectImage.png), indirect work ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/gridIndirectImage.png), or project activity ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_project.png). Here you also see a symbol if a work item is standby ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/StatusOpPaused.png).
B means batch recording and in this column you will see a symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/gridPileImage.png) if it is a batch recording.
The Last activity button (Last act.) shows the date and time when an activity was last reported for the work item or the project activity in question, for example, a partial reporting.
Project activities show project number, project name, activity number, and activity name in purple color.
The rest of the information in the table is the same as in the stop work mode. Read more about [Stop work](bStopWork.htm).
