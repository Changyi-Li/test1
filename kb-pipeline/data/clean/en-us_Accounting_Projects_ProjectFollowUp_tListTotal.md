### The Total list
In this list type you can perform financial follow-up of the project regarding costs and income from saved values. You can load data for reports shown in total by – for example – project, cost type, customer, main project, etc. When you load data to the list it is possible to load new calculated values (setting under the Selection tab). Otherwise you will only see the previously saved values.
In the list you can use the drilldown function to see the detailed information.
