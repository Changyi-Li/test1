### Schedule chart
Here you see a chart over the schedule with blocks symbolizing work time and flex time in different colors. Working time is shown in a light blue color. Positive flex time is shown in a green color and negative flex time is shown in a red color. Flex for breaks is shown in a yellow color. Break time is shown with no color. Overtime schedule is shown in a red color.
A time axis shows the schedule's start time and end time for working hours and flex time on the day. If you hover the mouse pointer over the chart, you will see the salary types in a tooltip.
