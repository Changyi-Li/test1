### Manufacturing order
- Register manufacturing order – here you register a new order, and can also also modify an existing order. You can also print directly from here by order. An order receives status 1 when it is registered and it gets status 2 after it has been printed. It is possible to print a transport label prior to reporting, and it is sent along with the goods in the flow.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/TrainingMaterial/ManufacturingOrder.png)](../../../../../Resources/Images/TrainingMaterial/ManufacturingOrder.png)
- Print manufacturing order– After registering a manufacturing order, you can print it directly in the above mentioned procedure. But you can also choose to print several orders at a time in this procedure. The orders then receive status 2.
> Monitor tip! Use Manufacturing order information (F11) to quickly find out the status of a manufacturing order. Use Order list – Manufacturing to see the entire manufacturing order backlog. Use Subcontract documents/Shipped to print several orders on the same document to the same subcontractor. In the procedure called Document templates – Manufacturing order you can affect the look of the order documents.
