### Monitor-to-Monitor
In the section E-mail accounts you find e-mail accounts (inboxes) registered in the Settings for incoming e-mail procedure that are of the Monitor-to-Monitor type. For an e-mail account to be shown it must also be available to the user. This is configured in the same procedure.
In the section Types you determine which types of Monitor-to-Monitor e-mail messages should be shown to the user in the desktop component called Inbox Monitor-to-Monitor.
E-mail accounts

#### Show
Here you determine if the e-mail account should be included in the desktop component called Inbox Monitor-to-Monitor. If no e-mail account is selected here, the user will not see any e-mails at all in the start page component.

#### E-mail
The e-mail address that applies to the e-mail account.
Types
Monitor-to-Monitor e-mail messages contain one PDF attachment and one XML attachment. The XML attachment contains data that makes it possible to e.g. create customer orders/invoices from the attachment. The PDF attachment shows the actual order/invoice in a viewing window.

#### Show
Here you determine which types of Monitor-to-Monitor e-mails should be displayed in the inbox.

#### Type
The type of Monitor-to-Monitor e-mail message. All types available at present are: Customer order, Invoice, Purchase order, Case, and Sales forecast.
