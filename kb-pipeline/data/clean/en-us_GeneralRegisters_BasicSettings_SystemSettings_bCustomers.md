### Customers

#### Show extra information about customer's references
This system setting determines if it should be possible to enter extra information on customer's references in the customer register. If you have activated this system setting, then three columns will be added to the references. The columns are called Extra 1, Extra 2, and Extra 3.

#### Status "Pending" as default on invoice basis for new customers
With this setting you decide whether new customers have the Invoice is pending setting activated by default under Other invoice settings. Pending can also be set per order. This means that the invoice basis will be set to status pending awaiting approval to be invoiced. Then the status is changed to For invoicing.

#### Attach XML file by default for new customers
Here you determine if all alternatives should be selected by default for new customers under the Attach XML file. The XML files are used in Monitor-to-Monitor.

#### Default delivery rule on partial delivery for new customer
This system setting determines which levels of partial delivery should be allowed for new customers. Partial delivery can be allowed for orders, order rows, or not at all.

#### Default rounding for new customer
Here you determine if the setting Rounding should be configured for new customers under Other invoice settings in the customer register.

#### Default factoring for new customer
Here you determine if the Factoring setting should be activated for new customers. This setting is found in the Customer register under Other invoice settings.
