### Location settings

#### Stock update
With this setting you decide if parts in the template should be stock updated. If the part template has the part type Purchased or Manufactured, you should select Yes in this setting. If the part template has the part type Fictitious or Service, you should select No in this setting. If the part template has traceability on batch or any of the serial number options, the setting should be set to Yes.

#### Random stock location
With this setting you decide if parts in the template should apply random stock location.
