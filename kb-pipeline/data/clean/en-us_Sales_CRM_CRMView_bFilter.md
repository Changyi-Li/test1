### Filter
In this box you filter the CRM information that you wish to see, by using different filter terms. The main term to filter by, is seller. If you make changes in the filter, you must use the button Reload data ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_refresh.png) (Ctrl + R) to make the filter changes apply in the boxes.

#### Seller
Here you select which sales person's information should be shown. If the logged in user is linked to a seller, this seller is shown by default.

#### Only seller’s customers
Here you determine if only records (activities, quotes, customer orders, and invoices) that are registered on the seller’s customers, will be shown. That is, the customers for which the seller is selected under the CRM tab in the Customer register. The following alternatives exist:
- Own records – With this alternative you include records linked to the seller in question.
- Other’s records – With this alternative you include records linked to other sellers.
- All records – With this alternative you include both the seller’s own records and other’s records.

#### Time horizon
You can filter which records to show, based on date. With this filter you will not see records that are further ahead in the future than the entered date.

#### Customer status
You can filter which customer's records to show, based on customer status.

#### Country
You can choose to only show records with the selected country in the mailing address. If you do not select any country here, then all records will be shown.

#### District
You can select to only show records for customers belonging to the selected district. If you do not select a district here, then all records will be shown.

#### Responsible for customer
You can select to only show records for the person who is the one responsible for the customer. If you do not select a person responsible for the customer here, all records will be shown.

#### Type
You can select to only show records for a certain customer type. If you do not select a customer type here, all records will be shown.

#### Reseller
You can select to only show records belonging to a certain reseller. If you do not select a reseller here, all records will be shown.
