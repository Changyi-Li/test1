### 批次号
组件批次号的编号序列。可以使用不同的格式已创建这些编号序列。
使用哪个编号序列取决于 分组条款 及其间隔 从 – 到。一个组件可以有多个不同的编号序列作为批次号。如果仓储费用，分组条款 组件号 最有重量。然后 组件代码 最后 产品组。如果同一个分组条款内有多个编号序列，然后行的订单决定将使用哪个编号序列。
有两个通用编号序列参考，一用于采购，一用于生产。如果你不编号序列，可以后退这查询数字系列。当你第一个时间开始该程序时，这些编号序列就被用于在系统中。他们的编号很高，仓储费用他们结束会在编号序列列表的最后。你不能删除这些行，但你更改这些序列中的后续编号。采购的默认格式为 <orderno>-<pos>，生产的默认格式为 <orderno>。然而，这些格式是可以已变更的。

#### 名称
你可以在此处写一段描述性文本作为名称。你使用公司语言输入名称文本，并以用户的语言显示。
使用按钮 翻译 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_translate.png)s 你可以将文本翻译为系统中已登记的不同激活语言。阅读更多内容 [语言管理](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) 用于可翻译文本。

#### 报告类型
你在此选择编号序列的报告类型。可用的选项包括 采购 和 生产。这决定了在报告采购订单到货已报告时或已报告工单已完成时是否应根据编号序列创建批次号。

#### 分组条款
分组条款决定了编号序列应该在何处使用。你可以从以下选项中选择： 组件号， 组件代码， 和 产品组。
使用哪个编号序列取决于分组条款及其限制。理论上，一个组件可以被多个编号序列包含。然后，组件号的分组将是主要的，其次是组件代码，第三是产品组。如果多个编号序列与相同的分组条款匹配，则适用编号序列中的顺序（此处表格中位于具有相同分组条款的行顶部的行）。

#### 从和到
在这些字段中，你可以输入应用至该编号序列的已选择分组条款的间隔。

#### 后续编号
在输入你下一个创建自编号序列中创建编号时应使用的编号。已允许的最大编号是 2,147,483,647。

#### 格式
你在此字段中输入一或多个标签，用于描述编号序列的结构和目录。可用标签低于：在序列号的编号序列中，你至少必须在字段中包括标签<代码> 。在批次号的编号序列中，如果你，你可以将该字段空。这意味着在报告时可以人工的输入任何批次号。
| 标签 | 描述 |
|---|---|
| <代码> | 编号序列中的后续编号。 |
| <代码:NN> | 编号序列中的后续编号，加上“填充”的零。NN 是零 + 数字的位置编号，最多可用为编号序列提供 19 个位置。NN 可以从 0 到 19。例如，如果编号序列中的后续编号是“1234”，并且你输入< 代码:19>，后续编号将是“0000000000000001234”。如果你< 输入 : 代码>，后续编号将是“0000001234”。如果你< 输入 : 代码>，后续编号将是“1234”。 |
| <年> | 年，包含四位数字，例如“2016”。 |
| <年> | 年，包含两位数字，例如“16”。 |
| <図> | 月，其中“01”表示一月。 |
| <交货日期> | 月中的日，例如“22”。 |
| <HH> | 小时。 |
| <毫米> | 分钟。 |
| <ss> | 第二。 |
| <周> | 周数，包含两位数字，例如01-53。 |
| <组件> | 组件号。 |
| <修订> | 客户订单或工单上零件的版本。 |
| <订单号> | 采购订单、工单或客户订单上的订单号。 |
| <位置> | 采购订单或客户订单上的订单行位置。 |
| <节点> | 工单中最大数量的组件或协同工艺中的组件的节点号。 |
| <编号> | 部分交货编号。将每个部分交货增加+1，订单获得具有批次可追溯性的组件的唯一批次号。该标签可用于建议从采购订单和工单至仓库的批次号。<编号>标签为采购订单行或工单组件的每报告提供唯一的计数器。你必须将此标签与至少另一个标签组合才能创建批次号，例如 <orderno>-< 组件>-< 编号>。 |
编号序列可以由不同的标签组成，这些标签之间用可选字符分隔，见低于的例如。
组合编号序列的例子：
<代码>/< 修订 > 结果是诸如“10001/A”、“10002/A”之类的数字。
<代码>:<yy>-<MM>-< 交货日期> 结果是数字，例如“10001：16-02-19”，“10002：16-02-19”。
> 请注意！标签区分区分大小写。
