### Settings (Setup time)
There are settings available for the list types Setup time – Detailed and Setup time – Total.

#### Only operations with reported setup time
If you activate this setting, the list will only include operations that have reported setup time.

#### Calculate with planned setup time for operations with only unit time
This setting corresponds to the setting [Calculate with planned setup time](../../Calculations/PostCalculation/bOperations.htm) in the Post-calculation procedure.
