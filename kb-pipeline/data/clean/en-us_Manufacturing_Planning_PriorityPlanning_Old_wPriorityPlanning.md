## Priority planning – Former layout
In this procedure you can replan the priority of operations for a work center. Only operations with remaining quantity are displayed in the priority plan.
When a manufacturing order is registered, it is roughly planned based on the planned start date. You might wish to run the operations in a different order, e.g. to run certain operations in succession if they are using the same material.
What can I do in the procedure?
- Change work center for operations.
- Reschedule operations based on a new finish date, and perform material clearance for operations.
- For specific operations in the priority plan, you can update:
- Priority
- Delegate work
- Instructions
- Linked files
- Time calculation
- Show in priority plan
- Multiple operators
- In the lead time chart you can reschedule operations visually by using the "drag and drop” function. Or you can enter a date for planned start time and planned finish time for the operations.
> Rescheduling of operations in the priority plan or lead time chart might affect the entire manufacturing order, so it has to be replanned. In that case you will be asked if you wish to replan the entire manufacturing order as well.
In the procedure Priority plan list you can replan the priority of operations for several work centers at the same time.
