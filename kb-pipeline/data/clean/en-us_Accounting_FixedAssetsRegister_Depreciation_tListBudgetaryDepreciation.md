### The Budgetary depreciation list
Using this list type, you can simulate depreciation e.g., for the next accounting year, to help with budgetary planning.
> The result is based on your system settings for the fixed assets register.
The list is divided into two parts, the list and the Posting box. In the list there is an overview of the fixed asset objects where you can e.g., view field assets groups, depreciation time, acquisition value, and the budgetary depreciation based on the selected date interval. You can drag and drop a column heading at the top of the list to group the list in this column.
In the Posting box you can view the calculated posting based on the option you have chosen:
-   
Per period – shows posting rows for all fixed asset objects in the list grouped per period.
-   
Total – shows posting rows for all fixed assets objects in the list grouped by the entire period (the date interval you have selected under Settings under the Selection tab).
-   
Per object – shows posting rows for the fixed assets objects you have selected in the list grouped by the entire period (the date interval you have selected under Settings under the Selection tab).
Based on what you have selected under Settings under the Selection tab, the posting rows will show account, dimensions, amount, and amount in debit and credit.
By using the Generate budget button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_accounting_budget.png) in the function menu in the Posting box, you are able to create a budget based on the budgetary depreciation. If a budget already exists, the values will be overwritten.
