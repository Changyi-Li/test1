### List
This list displays all activities based on selected activity types under the Selection tab. You can, for example, use the list to monitor activities with a certain status.
You can update responsible person, performed by, reported date, and status. You can also enter a comment and link files to each activity, as well as write a log text, for example, if you do an update on an activity.
On the function menu you find the following buttons for handling of the list.
With the Print button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_print.png) (Ctrl + P), you can print a list of all activities.
With the Preview button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_preview.png) (Ctrl + Shift + P) you can preview the list before printout and configure different settings for the printout.
With the Export button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_export.png) you can export the list to different file formats and to Clipboard.
With the Send by e-mail button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_email.png) you can export the list to different file formats and attach it to an e-mail.
With the Find button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_search.png) (Ctrl + B) you open a search field where you can perform exact match searches in the list.
With the Find & replace button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_change_record.png) (Ctrl + H) you open a dialog window where you can search and replace texts in updateable columns.
With the Filter button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_filter.png) (Ctrl + Shift + F), you open a dialog where you can create filters and filter the list by different terms.
With the Copy records to Clipboard button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_copy.png), you can choose to copy records to different records in the Clipboard.
With the Go to procedure button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) you can load the selected record in related procedures.
