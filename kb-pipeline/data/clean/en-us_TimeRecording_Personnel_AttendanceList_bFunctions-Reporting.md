### Functions/Reporting
In this box you can handle different recording information. This is possible to do if you are allowed to adjust attendance for the person in question.

#### Report absence
By clicking the button you open a small window where you can report absence for an employee. You can for example start an absence record for a person who calls in and reports sick. The suggested time will in these cases be the same as the start of the schedule of today. If the person in question was already reported as absent, you can here change absence code and at the same time enter as of which date and time should apply.
When reporting absence, today’s date is suggested as end date. This creates a planned absence that in turn reduces the capacity if the employee is linked to a manual work center.

#### Show schedule
By clicking this button you get to see the schedule to which the person is linked.

#### Planned absence
By clicking this button you access a calendar where you can view, enter, and change planned absence. You can select one or several days in the calendar and then add/enter the absence in the table below it. The planned absence is then shown in the calendar along with the absence code and the number of hours per day.

#### Last recordings
By clicking this button you can view a list of the recording items of the recent days. You can enter how many days to show.

#### Schedule exceptions
By clicking this button you can view and also create schedule exceptions. You can mark days with different schedules to create schedule exceptions for multiple days.

#### Time balances
By clicking this button you will see the current balance for the time balances which the person in question can use. By clicking on ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you can view log records for each balance.
