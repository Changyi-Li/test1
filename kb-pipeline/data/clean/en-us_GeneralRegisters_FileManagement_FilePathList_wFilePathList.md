## File path list
In this procedure, in a list, you can change existing paths and file paths (sub-directories) to files already linked in records in the database, without breaking the links.
You can find and replace paths and file paths on all rows in the list. When you save in the procedure, the changes will be executed.
The procedure is useful if the company, for example, is to change the directory structure on a file server or in SharePoint Online, and move linked files, or replace the file server with another file server.
