### Calculation mark-up
- The basic for SO, SC, sales OH, and Profit, are all system settings in G4. There is also a setting in G4 which you activate to be able to create exceptions from SO and SC.
- All these system settings have been removed in G5 and the mark-ups have been moved to this procedure. It is always possible to enter alternatives (exceptions) so that separate setting is not available in G5. Being able to add alternatives for sales OH and profit, and then entering these for the parts is a new feature. Earlier these values were generally added in the system.
- In G5 it is possible to use multiple expense types and also name the types. There are also new ways to enter the expenses. In addition to "each" and "% of price" to distribute the costs on, it is now also possible to distribute costs per order, per package, per kg (net), and per quantity (where you can enter an optional quantity). You can activate the expense types you want to use in the system. In the Part list procedure you can use the list type Material costs to perform a mass update of purchase expenses for parts.
