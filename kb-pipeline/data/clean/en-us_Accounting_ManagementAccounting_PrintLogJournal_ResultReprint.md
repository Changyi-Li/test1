### Result – Reprint
In this box you see one row per Journal number. You also see the Voucher date. Voucher number is shown if the journal has integration with the accounting. The Period column displays the accounting period to which the journal belongs. For the reprints, you will also see when the journal was approved and by whom.
If you select a journal, it will be shown in the box Preview to the right.
When you choose to print ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_print.png) in the procedure, one printout will be created for each journal number.
