### Invoice
In this box you add the record which is the basis of the accrual. For example, a supplier invoice. For existing accruals it is not possible to change record if a release has been made. Which fields that are displayed depend on the type selected in the header row. For the type Manual entry, this box is empty.

#### Consecutive number
In this field you enter the consecutive number of the supplier invoice the accrual concerns. When an accrual is automatically created from the Register supplier invoice procedure, this link will automatically be created. One and the same supplier invoice can be linked to multiple accruals, e.g., when there are several accrual accounts on one and the same invoice. In cases where you manually create a new accrual you must select a consecutive number.

#### Account
Here you select the posting row on the entered supplier invoice which should be accrual accounted. The posting row you select is automatically added in the Posting box.

#### Amount
Here you see the amount on the posting row.

#### Supplier
Here you see the supplier name.
