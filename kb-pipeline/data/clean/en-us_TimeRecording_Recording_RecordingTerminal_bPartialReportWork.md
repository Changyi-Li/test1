### Partial report work
In this mode you can partial report a work item or project activity in progress.
This mode contains the same information and fields as the mode where you [stop work](bStopWork.htm). The button Stop is instead called Partial report.
The difference between partial reporting and stop/finish work, is that when performing partial reporting the work time is not stopped and the work item/project activity will remain as a work item in progress after the reporting.
