### 通用登记
在员工你设置查询描述已登记基础数据在 通用登记 安装之后的模块 Monitor ERP。
首次开始 适用于公司以前不使用过MONITOR 的情况。移民 适用于公司从MONITOR G4 迁移/转换的情况。
有关措施和设置的说明被用于在相应程序的在线帮助功能中。
| 措施 | 什么时候 | 受影响的程序 | 解释 |
|---|---|---|---|
| 登记/控制公司数据 | 首次开始、迁移 | 公司信息 | 登记公司信息并检查全部现有的信息是否正确，例如货币、银行账号、语言、国家 / 地区、地址等。添加公司商标（显示在不同的文档上，例如发票）。 |
| 检查日历 | 首次开始、迁移 | 日历 | 检查系统被用于的日历，并将“节假日在中间的日”（如果适用）标记为休息天数。如果需要，登记更多日历。有两种系统设置可确定用于哪些日历来计算付款日期以及计算发票到期日。如果应用仓库，你还应该在程序中每仓库选择一个日历 公司信息。 |
| 检查系统设置 | 首次开始、迁移 | 系统设置 | 检查全部系统设置并根据需要更改默认设置。 |
| 创建桌面配置模板 | 首次开始、迁移 | 桌面模板 | 如果需要，创建用户可以应用的共同的桌面模板。另一种方法是让用户自己在后台创建自己的桌面配置。 |
| 登记用户权限组 | 首次开始、迁移 | 用户权限组 | 如果需要，如果包含的可应用用户的角色不够，则为用户登记自己的用户权限组。 |
| 登记/更新用户 | 首次开始、迁移 | 用户、审核设置 - EIM | 登记和更新用户并应用角色，或用户权限组和特定用户权限。为用户添加默认打印机，例如用于货运文档的打印机。配置哪些用户应该被已允许登录到 Web客户端。如果应用电子发票管理 (EIM)，你还需要配置供应商发票审核设置。 |
| 登记部门 | 首次开始 | 部门 | 强制的在员工记录中为员工选择部门，在工作中心登记中为工作中心选择部门。 |
| 登记员工 | 首次开始、迁移 | 员工记录 - 通用 | 登记员工并链接到部门和用户。要登记的信息例如是此员工是联系人人、销售员等等。你还可以将图片/图片链接到该员工。 |
| 登记/更改路径 | 首次开始、迁移 | 路径、文件路径列表 | 登记可以链接到记录的外部文件的路径。编辑已已链接文件的现有的路径。 |
| 登记导出和导入路径 | 首次开始、迁移 | 导出 / 导入设置 | 登记付款文件、SIE文件、发票文件等的导出和导入路径。向nShift 交付或 nShift Web-TA登记登录信息。 |
| 登记/检查货币，更新汇率 | 首次开始、迁移 | 货币 | 登记并检查应使用哪些货币和汇率类型。配置汇率自动更新日程表。 |
| 登记货运服务 | 首次开始、迁移 | 货运服务 | 登记货运服务和货运模板（基于您在nShift 交付 、或 nShift Web-TA 的科目设置）。 |
| 添加收取 Email 设置 | 首次开始、迁移 | 收取 Email 设置 | 添加用于接收Email的 Exchange 或 IMAP服务器的设置 Monitor ERP。还添加用于不同类型Email的Email 账户的收件箱。 |
| 创建数据挖掘到商业智能的日程计划 | 首次开始、迁移 | BI 设置 | 创建一或更多数据挖掘到商业智能的日程表项目。对于每个日程计划事项，你可以配置要包括的公司和数据源。挖掘的数据然后用于 商业智能 采购和销售模块中 的程序. |
| 检查文档设置 | 首次开始、迁移 | 文档设置、文档模板 - 工单 | 检查文档的默认设置，例如报价、询价和发票，对于工单文档，你应该检查工序文档、物料文档和生产工单。 |
| 检查编号序列 | 首次开始、迁移 | 编号序列 | 检查起始号码 后续编号 在编号序列中。默认下，一编号应比 最大号码已使用。例如，如果贷项发票应使用与发票相同的编号序列，你取消选中该设置 激活的 为贷项发票号序列。 |
| 登记/检查其它表格包括基础数据 | 首次开始、迁移 | 多个程序 | 登记、检查并补充其它表格中的基础数据信息 通用登记 （例如条款、原因代码、订单类型、语言、货币、国家 / 地区等）。 |
| 登记不同的分类 | 首次开始 | 分类,折扣分类 | 登记用于组件、客户、供应商等的分类。登记所需的折扣分类。 |
| 登记/控制财务数据 | 首次开始、迁移 | 多个程序 | 登记并控制会计年度、凭证号序列、标准科目、VAT设置、银行设置和开票计划的数据。创建由客户组、供应商组、产品组、过账组、销售科目和采购科目组成的过账矩阵。创建预算图表。 |
| 创建附加文本、付款提醒文本 | 首次开始、迁移 | 文档文本 | 为将要使用的文档和文档组创建附加文本。可以在文档上创建用于打印的附加文本，也可以创建用于通过Email已发送文档时使用的附加文本。文档组链接至公司 / 仓库、客户和供应商的不同地址。还可创建付款提醒文本，以便已打印在付款提醒上。 |
| 导入组件余额、库位、批次号。 | 首次开始 | 库存余额导入 | 导入组件余额、库位和组件批次号（如果有）。导入是使用制表符分隔或逗号分隔的文本文件执行的。此导入通常在上线（实际的开始）之前的准备阶段完成。 |
