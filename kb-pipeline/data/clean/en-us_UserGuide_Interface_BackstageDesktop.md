### Backstage
In the desktop backstage there are some general functions and settings for Monitor ERP and you as a user.
![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/Backstage.png)
Button to backstage on the desktop.
| Function | Explanation |
|---|---|
| [Settings](../GeneralFeatures/BackstageSettings.htm) | Here you configure settings for color range/theme, reminders, printouts, etc. |
| [Warehouse](../GeneralFeatures/Warehouse.htm) | Here you see and select among the available warehouses. |
| [Language](../GeneralFeatures/Language.htm) | Here you see and select default language and the current language. |
| [Accounting year](../GeneralFeatures/AccountingYear.htm) | Here you see and select default accounting year and the current accounting year. |
| [Desktop](../GeneralFeatures/Desktop.htm) | Here you select layout and desktop components for your desktop. |
| [About](../GeneralFeatures/About.htm) | Here you will find information about Monitor ERP. |
| [Log out](../GeneralFeatures/LogOut.htm) | Here you log out from Monitor ERP. |
