### Settings – Calculation information
There are settings available for the list types Calculation information – Detailed and Calculation information – Total.

#### Only main rows
This setting determines if only main rows will be loaded to the list. Associated sub-rows in the form of additional texts, alloy costs, and included parts in fictitious part will not be displayed. This setting is activated by default.

#### Include SO for P-parts
With this checkbox you determine if SO mark-ups, if any, should be added to purchased parts when calculating CM The contribution margin (CM) is the difference between the standard price and the sales price..

#### Calculation alternative
Here you select calculation alternative should be used as basis for the manufacturing costs for the parts. These costs will be compared with the invoiced value. The available options are:
- Current standard price calculation
- Standard price calculation at delivery
- Standard price calculation at invoicing
- Post-calculated mean price
- Future standard price

#### Cost factors
Here you select which cost factors will be used as basis for the processing cost in the parts' manufacturing cost according to the pre-calculation. It is possible to combine the three different cost factors that are available for work centers.

#### Debit/Credit
With this setting you determine if all invoices should be included, or alternatively, only debit invoices or credit invoices.
