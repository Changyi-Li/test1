### Cross references
In this box you add one or more cross reference codes in Monitor ERP with codes used in EDI EDI is the acronym of Electronic Data Interchange. EDI is about exchanging electronic business documents with your business partners, e.g. customers and suppliers. The EDI concept can be wide and a bit unclear, and can many times be used about all types of documents which are sent electronically, even if it might be PDF files sent via e-mail or publishing business documents on a website. What we refer to as EDI – and what is traditionally meant by EDI – is structured business documents following given standards, electronically sent or received and which are compiled and interpreted automatically and that is integrated with the customer's/supplier's ERP system. messages. This is made for the marked data row in the table.
The data for which you can add cross references depends on the selected transaction type on the row in the table to the left in the tab. These are for example codes used for currency, delivery method, delivery terms, part unit on rows.
In the left section, you see rows with data whose codes can contain cross references. Some data rows are grouped and you can click the arrow ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_expand_row.png) to the left to expand the data row. In the right section, you add the actual cross references between codes.

#### Name
Here you see the name of the data in the transaction type.
When a cross reference is registered, you see an orange symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/orange_snowflake.png) to the left of the name.

#### From
The code from which you refer, for example "$" for US Dollar.
- If the transaction type's direction is Export ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_export.png) you refer from a code used in Monitor ERP.
- If the transaction type's direction is Import ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_import.png) you refer from a code used in EDI messages.

#### To
The code to which you refer, for example "USD" for US Dollar.
- If the transaction type's direction is Export ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_export.png) you refer to a code used in EDI messages.
- If the transaction type's direction is Import ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_import.png) you refer to a code used in Monitor ERP.
