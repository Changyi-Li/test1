### Register sales forecasts
- In G4 the procedure is designed as two tabs. In G5 you see the forecast codes and the rows in the same view. There you can see and edit the rows for the selected code.
- For a forecast it is possible to enter terms/conditions which will determine which customer orders will be deducted from the forecast. These are Customer, District, and Customer group. If one of these terms is entered on the forecast, it means only the customers order which fulfill the term will be deducted from the forecast. For example, if district is set to US, only customer orders with customers linked to US will be deducted from the forecast.
- You can import a sales forecast in the same procedure as the manual editing. In G4 these procedures are separated and are found in different modules.
- The forecast code is alphanumerical and can contain a maximum of 5 characters. In G4 it could hold a maximum of 3 characters.
- The name on the following row is not shown if it is the same part number as on the above row.
- It is possible to see and select unit on the forecast row.
- Any changes made in sales forecasts are logged.
