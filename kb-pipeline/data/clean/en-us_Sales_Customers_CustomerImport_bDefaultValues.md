### Default values

#### Customer type
Here you select which customer type that by default will be selected for the imported customer. Customer types are handled in the procedure Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – CRM.

#### Customer status
Here you select which customer status that by default will be selected for the imported customer. The default alternative here is Actual customer. Customer statuses are handled in the procedure Basic data – CRM.
