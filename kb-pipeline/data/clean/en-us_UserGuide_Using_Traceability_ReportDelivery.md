### Report delivery
When reporting parts with traceability, it’s important to actually report the batch or serial numbers that have been physically picked. As a result, a quantity to report is usually not suggested and you must enter this manually. However, it is possible to allow automatic withdrawal through settings in the Part register.
One approach is to allow automatic reporting of what is cleared on the pick list. Another method is to use the pick list to move the quantity you want to pick to the pick list, and allow automatic withdrawal only from pick list.
The quantity to report is always entered in the box with locations, on the row with location/batch number.
When a customer order with a traceable part is delivered there are two scenarios: 1. Picking from stock. 2. Delivery from linked order orientated manufacturing or purchase order.
When there is no link between customer order and manufacturing order you are free to choose any location and thereby also to choose any batch you please. This is done by opening the location window and there you enter a quantity for a location/batch.
When delivering a customer order where there is a linked order, only withdrawal from the balance of the linked order is allowed. In this case it’s recommended to allow automatic withdrawal at part level.

#### Traceability at serial number level
The same principle applies for reporting of parts with serial numbers.
It is possible to show the delivered serial number on the Delivery note, delivered document. This happens if the setting Show serial number is activated for the document in the Document settings procedure.
