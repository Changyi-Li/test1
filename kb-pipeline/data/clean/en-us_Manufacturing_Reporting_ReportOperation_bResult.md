### Result

#### Include
This checkbox determines which documents that will be printed when you save.

#### Part number
Here you can see the part number for the operation.

#### Reported quantity
Here you can see the reported quantity/transfer to stock. The reported quantity can be edited, if needed.

#### Quantity/package
Here you can enter quantity per package. This affects how many transport labels will be printed. In this column the reported quantity is shown by default. If you have entered a quantity per package in the Miscellaneous box under the Manufacturing tab in the Part register, this quantity will be shown by default.

#### Number of copies
Here you select the number of copies that should be printed. The default number of copies is determined in the Document settings procedure.
