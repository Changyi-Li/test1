### File management
- File management was called Document viewing in G4.
- When you link external files for example to an operation in the BOM and routing, then it is possible to activate a function which generates a unique copy of the file when manufacturing order is created. This file can also be edited by for example the operator. This can be used e.g. when the operator should enter information in an inspection form in Excel.
- The procedure File path list has been added in G5. This procedure makes it possible to quickly handle changes of many file paths (document paths in G4) at the same time, for example when changing a file server or modifying directory maps where you have saved linked files.
- In G5 it is always possible to open linked files in the computer's associated programs. This is done using the button Open on the function menu.
> Viewing and printing of linked files of the type PDF is included in the standard version of G5. In G4 this is a supplement function. To manage other files in G5 such as images, Word documents, and drawings, then the option called Extended file viewer is needed.
