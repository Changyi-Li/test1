### Generation
Here you configure settings regarding which suggestions that should generate actual orders in the procedure.

#### M-order type
Here you select which manufacturing order type that will be generated from the order suggestions. This setting does not apply to suggestions that have requirements linked to customer orders. They always get the order type Customer order oriented. The choice of order type affects e.g. the priority of the generated orders. You can only select among the order types registered as active in the Order types procedure, except for the basic type Stock driven.

#### Suggest "Apply" for all suggestions
This checkbox determines whether or not the Apply column will be checked by default for all the suggestions in the list.

#### Suggest "Apply" for rescheduling suggestions
This checkbox determines whether or not the Apply column will be selected by default for all the rescheduling suggestions in the list.

#### Save changes directly
When generating manufacturing orders, changes will be saved in the background, without needing to open the Register manufacturing order procedure. This setting must be saved as a default value in order to enable automate running of the procedure.
