### Result
In this box you can see the arrivals that was loaded from the Rows tab. Here you select the arrivals that you want to print.

#### Include
In this column you determine if the document should be printed or not using the checkbox Include.

#### Quantity/package
Here you see the quantity per package that should be printed on the transport label. This value is loaded from the part, but it can be modified. It affects the number of copies to be printed. If the arrival reported quantity is 200 and you enter 100 as quantity/package, it means two transport labels will be printed. The package number will be updated and shows that the package is divided. The unit for quantity/package and transport label is determined by the unit that is selected for arrival on the part in the part register.

#### Number of copies
Here you select the number of copies that should be printed. The default number of copies is determined in the Document settings procedure.
