### Settings

#### Recipient type
You can choose to include all e-mail addresses from the References box and/or the Communication – Delivery address box in the Customer register.

#### Recipient of
With this setting you can decide to only include the e-mail addresses which are registered as recipient of a specific or multiple options. This is registered in the Communication – Delivery address box in the Customer register.

#### Show
Here you decide if you want to show Customers with e-mail address and/or Customers without e-mail address. Customers with e-mail address are selected by default.

#### Pre-select "Include"
With this setting you decide if all e-mail addresses should be checked in the Include column in the list. This setting is activated by default.

#### Logging in CRM
With this setting you determine if a log record should be created in the section Log of activities/E-mails under the CRM tab in the the customer register. This setting is activated by default.

#### Bcc
Here you decide if all e-mail addresses should be entered as Bcc (blind carbon copy) in the e-mail. The purpose of this is to make it impossible for the recipients to see to which other e-mail addresses that the same e-mail has been sent. This setting is activated by default.

#### Include references
With this setting you decide if references entered in the References box in the Customer register should be shown in the list.
