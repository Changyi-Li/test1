### List
This list loads the selected parts in order to calculate their order quantity. The calculation takes place automatically.

#### Save
In this column you decide which parts you want to save.

#### Part type
Here you see the part type.

#### Part value
Here you see the part value. The part value differs depending on if the setting Part value including setup cost has been configured or not.
The following applies when Part value including setup cost has not been configured:
- For purchased parts, the part value is = standard price
- For manufactured parts, the part value is = standard price according to calculation - setup cost.
- For manufactured parts with subcontract, the part value is = standard price according to calculation - setup cost - transport cost
The following applies when Part value including setup cost has been configured:
- For purchased parts, the part value is = standard price + setup price on the default supplier link
- For manufactured parts (with or without subcontract), the part value is standard price according to saved calculation

#### Annual volume
Here you see the part's annual volume.

#### Difference
Here you see the difference between the previous order quantity and the new order quantity.
More info
Under More info ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you find additional columns. Below you find the online help topics for the columns.

#### According to
Here you see according to which method the new order quantity is calculated. The methods are Wilson formula, number of orders per year, and minimum quantity for the part.

#### Calculations
Under the button, you will see staggered price calculations that have been used when calculating order quantity using the Wilson formula.

#### Planning method
Here you will see the part's planning method.

#### Control method
Here you see if the part is stock driven or order oriented.
