### Invoice rows
This box is available when the option EIM Workflow is installed in your system.
Here you see invoice rows from interpreted and imported supplier invoices. On the function menu you find buttons for specific actions for the invoice rows. These are described below.
Explanation of the buttons on the function menu:
- The Link invoice rows button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) opens a window where you can take care of all invoice rows which could not be linked by Workflow, and manually link them to purchase order rows. You can also link a purchase order row to an invoice row by dragging the purchase order row from the Purchase order box using the mouse pointer, and dropping it on the invoice row.
- The Force invoice to authorization button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_streamline.png) forces the marked invoice to be sent to signer to be manually handled. This will occur even though the marked invoice has invoice rows which have not been matched with the corresponding purchase order rows. This means the signer has to take care of the invoice rows that have not been matched.
- Send invoice to Workflow as expense invoice ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_cancel.png) send the invoice along in the Workflow as an expense invoice, that is, there are no invoice rows on the invoice to link to purchase order rows.
- With the Unlock for editing button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/Padlock.png) you unlock the marked invoice row making it possible to modify most data on the row.
- The Show linked rows button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_show_hidden.png) shows invoice rows which are linked to purchase order rows.
When an invoice row is missing a linked purchase order row you will see this symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_reject.png) to the left on the row. You then get to link a purchase order row to the invoice row. If there are no order rows to link to the invoice rows you can send the invoice to Workflow as an expense invoice.
When there is a purchase order row linked to an invoice row, this symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/StatusFinished.png) will be shown to the left on the row if all of the information on invoice row and purchase order row match. A warning ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png) is displayed if the information does not match. You can in that case expand the invoice row by using the ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_drill_down.png) button to the far left in order to see the linked purchase order row. You can also expand/minimize all linked rows using the standard function of the Expand all button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_expand_collapse.png) (Shift + F8).
On a linked purchase order row it is possible to change the Purchase account or the entire posting. This is accessed by clicking the Posting button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png). If data on the order row does not match the corresponding value/information on the invoice row, a warning ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png) is shown on the order row. You can then unlock the invoice row and change the information on the invoice row.
If the wrong order row has been linked you can disconnect/unlink it from the invoice row by using the ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) button to the far left on the order row.
