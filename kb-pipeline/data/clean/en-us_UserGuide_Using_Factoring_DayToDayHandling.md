### Day-to-day handling

#### Customer register
In this procedure you find the setting called Factoring. This setting determines if invoices to the customer should be exported to the factoring company or not. When registering new customers this setting is checked by default. You find this setting by clicking the button Other invoice settings ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) in the box called Invoicing under the Settings tab.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/TrainingMaterial/factoring5.png)](../../../../Resources/Images/TrainingMaterial/factoring5.png)
> If you have activated factoring via Swedbank Payex and use the Invoice service option, it is possible for you to choose which Distribution method should be used for your invoices. E-mail, Letter, and Filing of invoice are available distribution methods to choose from. If you for your customer selected E-mail as printing method for invoices, E-mail will become the default distribution method. If you have a different printing method for your invoices, Letter will be used as default distribution method.
Review/Approve invoice
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/Distribution_method.png)](../../../../Resources/Images/UserGuide/Distribution_method.png)

#### At the bottom of the Selection tab there is a setting called Factoring export which determines if export for factoring should take place in connection with approving the invoice to print it or send via e-mail. This checkbox is then checked by default in cases where the Factoring setting (mentioned above) is activated for the customer.
After the invoices have been approved a question will appear asking if a printout should be made. If you choose to do a printout you will be linked to printing/e-mailing invoices in the Print invoice procedure.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/TrainingMaterial/factoring6.png)](../../../../Resources/Images/TrainingMaterial/factoring6.png)
Print invoice

#### It is via this procedure the export will take place. The file will become created after the printouts are finished and you save by approving the printouts.
After you approved the printouts a file dialog will be shown containing the path and the file name which have been entered in the Settings for export/import procedure. The file is created when you confirm the file dialog.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/TrainingMaterial/factoring7.png)](../../../../Resources/Images/TrainingMaterial/factoring7.png)

#### The following applies when you do not want to create factoring files at each invoicing: For example when you invoice several times per day and you want to export the invoices at the end of the day. Then you should follow this instruction:
When you are doing your continuous invoicing you should make sure that the setting Factoring export is not checked in the Settings box under the Selection tab. This can be configured using default values.
1. When the invoicing has been completed and you want to finish by exporting all invoices to the factoring company, open the procedure Print invoice.
2. Check the settings Reprint and Factoring export in the Settings box under the Selection tab.
3. Select the invoices to export, for example by selecting per invoice date.
4. Select the invoices to export, for example by selecting per invoice date.
