### Header row
In the header of the recording terminal you select which employee number to load. To the right of the header row, you see which day and date it is, as well as the current time. You see the time given in the company's/warehouse's time zone, otherwise you see the time of the Monitor ERP server.

#### Employee number
Here you enter the employee number or the card code. When the employee number has been loaded, you see the photo of the person to the left (if the employee in question has a photo in the Personnel records procedure) and the name is displayed to the right of the field.
The recording terminal is now in a recording mode and the terminal shows a section with recording buttons and sections for more information, time balances, and work in progress.
It also possible to go back to the basic mode by using the button Clear ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_delete.png), if you for example entered the wrong employee number.
If the system setting called Activate site recording is activated, a symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/Site.png) is shown next to the name and a text lets you know which site is selected. If the person is clocked out, the text "No recording site selected" is displayed.

#### Operator
If the system setting Enter signing employee number at machine recording has been activated you will also see the field called Operator in case you have loaded the employee number of a machine in the field above. Here you then enter the employee number of the operator, that is, the person who will man the machine at the moment. The operator must first be clocked in before he/she can register as operator.
