### Microsoft Entra 标识 （Azure Exchange/Sharepoint）

#### 应用程序 (客户端) ID
如果你已已选择 基于服务器, 通过 Microsoft Exchange Online 作为 Email 发送方式。复制 应用程序 (客户端) ID 从 Microsoft Entra 标识 （以前称为 Azure 激活 目录 ）中的客户端程序中值自，然后将其粘贴到这里。

#### 目录 (租户) ID
如果你已已选择 基于服务器, 通过 Microsoft Exchange Online 作为 Email 发送方式。复制 目录 (租户) ID 从 Microsoft Entra 标识 （以前称为 Azure 激活 目录 ）中的客户端程序中值自，然后将其粘贴到这里。

#### 认证流
如果你已已选择 基于服务器, 通过 Microsoft Exchange Online 作为 Email 发送方式。在这里你选择针对 Exchange 使用的认证流。有以下选项可用：
- 客户端密码 –如果你将认证流 客户端密码。必须在 Microsoft Entra 标识中已创建此客户端密码。
- 用户名 / 密码 – 如果你将使用 Exchange 帐户的用户名和密码，选择此认证流。目前，你此认证流时存在某些限制 -例如，如果管理员已将多重身份验证已配置为需求，则不全部使用 Microsoft Entra 标识 的组织选择支持条件访问和多因素验证。

#### 客户端密码
如果你已选择了 客户端密码 在上面的系统设置中。复制你在 Microsoft Entra 标识中已创建的客户端密码的值*，并将其粘贴到这里。
> * 请注意！你待复制 值 将客户端密码客户端密码其他库位，与在 认证和机密 Microsoft Entra 标识页，然后能够将该值至复制到此字段。客户端密码在 Microsoft Entra 标识中也具有一定的有效期。这意味着你必须在有效即将到期时创建一个新建的客户端密码，然后将新建的客户端密码复制到这里。
