## Basic data – Attendance
In this procedure you register data for time reporting of attendance. This is done by using existing data or by creating your own salary typesSalary types are used to create salary bases for worked time and absence. Different salary types are used, for example, for work during regular working hours, flex, overtime, shorter working hours, and sick leave. The salary bases are used to manage salaries in a payroll system. Salary types are linked to absence codes in addition to work schedules and overtime schedules., time banksTime banks are used in order to save recorded time outside scheduled working hours. Different time banks are for example used for comp time, makeup time, flex time (positive/negative), and shorter working hours., absence codesAbsence code is used in order to be able to link causes to recorded absence. Salary types can be linked to absence codes and thereby the system can link the different types of absences to the correct salary type. Examples of some of the most common reasons for absence are illness, parental leave, leave of absence, late arrival, etc. Furthermore, absence codes can be linked to time balances so that the absence recording automatically reduces the balance for flex time, comp or makeup time., salary type classes, overtime types, and additions.
Under the Salary types tab you create and name the salary types and select which class of salary type it is. You also configure settings for export to external payroll program for each salary type (option). For salary types there is also a setting determining (per salary type) in which time unit the recorded time should be exported to the payroll program. You can also configure if the salary types are of the type absence or attendance. For the salary types you wish to merge in exports to the payroll program you enter the same export alias.

It might for example be attendance, overtime, paid or unpaid absence, flex time, and sickness.
You register the different codes for absence under the Absence codes tab. There you can create codes for different types of absence and link the codes to e.g. salary types.
Under the Overtime types tab you register different overtime types. It can, for example, concern paid overtime, compensatory leave, makeup time, paid + flex.
You can also create time banks for example for flex and makeup. This is done under the Time banks tab.
Under the Additions tab you register data for other activities making up salary, for example travel time, allowances for expenses, etc.
If site recording is activated (via the system setting called Activate site recording), a tab is available called Sites. Sites are used when recording attendance and breaks. They are used to describe the physical location to which the employees record in/out. Sites are used in order to show, in the Attendance list and Evacuation list, where all staff who are clocked in and all staff who are clocked out on a break are currently located – that is, within the building or elsewhere.
You can register different common activities to follow up on regarding the personnel under the tab Activities. This can for example be personal development discussions.
Under the tab Activity templates you can create templates for your commonly occurring activities, for example, the activities which should be performed when a new person is hired by the company.
If the option Export of salary basis is installed you also have a tab called Export settings. Here you can then register paths and link file formats to the paths, to be able to export salary basis as files.
