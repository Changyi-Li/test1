### Monitoring selection
In this box you can add one or more monitoring selections in the monitoring task.

#### Warehouse
For monitoring tasks of the type Balance – Part, it is possible to choose in which Warehouses you want to use the monitoring task. This column is only available if you have installed the option Warehouse.

#### Monitoring terms
For each monitoring task you configure a Monitoring term. The available monitoring terms are determined by the type of monitoring task.

#### Value
For monitoring tasks of the type Balance – Part, you can for some monitoring terms enter the balance's Value. That is, the balance level which should be monitored.

#### Message
By using the button Message ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you can see and change the message text that is sent to the recipient when the monitoring term has been fulfilled. You can also format the text as well as add phrases and images.
> Please note! You shall not modify the existing variables in the text! These are the text strings with double square brackets, for example "[[partNumber]]".
