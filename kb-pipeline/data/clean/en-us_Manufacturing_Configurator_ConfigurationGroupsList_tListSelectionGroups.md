### The list type Option lists
In this list you can see information about the selected option lists. It is also possible to select the list by part.
You can see in which configuration groups and sections that an option list is included. For an option list you will see default settings for the option list and each part in the option list, in the respective configuration group where the option list is included. The list is grouped in three levels by configuration group, section, and option list.
