### Customized reports

#### Key for publishing customized reports
Here you add a signing key that will be used when publishing customized reports. An HTTP client uses this key to sign all outgoing calls. By using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_browse.png) you can create a path to the key. The signing key (a file with the extension .rsa) will be sent to you from Monitor ERP System AB.
