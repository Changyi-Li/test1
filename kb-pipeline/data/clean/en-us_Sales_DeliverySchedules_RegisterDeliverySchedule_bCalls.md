### Calls
In this box you can manually add and edit all calls for each part in the delivery schedule.
In the box Generate calls, you can as an alternative configure a set of calls, based on the start date and end date, number of calls, and on which week days the calls should be made. You then generate the calls using the button Add the above entered number of calls ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_batch.png) which you find on the function menu in the this box.
On the function menu you also find buttons you can use to add and delete call rows. There is also a button you can use to go to the related procedure for the marked calls.

#### Quantity
Here you see/enter the quantity of the call.

#### Delivery date
Here you see/enter the delivery date of the call.

#### At customer
In this column you see when delivery should have arrived at the customer's location. It is Delivery date + Transport time Transport time is the number of work days that it takes to send a shipment from sender to a receiver..
You enter the transport time in the Header box and it is shown in a column under the More info button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) on call rows in this procedure as well as in the procedures Handle delivery schedules and Analyze delivery schedules.

#### Type of requirement
Here you select the type of requirement. Fixed order, Forecast, or According to agreement.

#### Cause code
Here you enter the cause of the call. Normal, Lag The term "lag" refers to the total sum of the planned setup time and unit time that has not yet been reported as finished for a planned finish period., or Urgent requirement.

#### Reference number for delivery
Here you see/enter the reference number for the delivery.
The More information button
The following columns are by default only available under the More info button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) at the far right in the table.

#### Initial quantity
Here you can enter an initial quantity in the call.

#### Desired delivery date
The setting Handling of delivery days in EDI EDI is the acronym of Electronic Data Interchange. EDI is about exchanging electronic business documents with your business partners, e.g. customers and suppliers. The EDI concept can be wide and a bit unclear, and can many times be used about all types of documents which are sent electronically, even if it might be PDF files sent via e-mail or publishing business documents on a website. What we refer to as EDI – and what is traditionally meant by EDI – is structured business documents following given standards, electronically sent or received and which are compiled and interpreted automatically and that is integrated with the customer's/supplier's ERP system. behaviors affects the import of delivery schedules. It can take the customer’s delivery days into account and adjust the delivery date when delivery schedules are transfered to customer orders, The initial delivery date from the delivery schedule will then be saved in this column.

#### Transport time
Here you see the transport time of the delivery schedule. You enter the transport time in the Header box, and it is shown on each call-off. The transport time is updated in the customer order header at each transfer.

#### Requirement type code
Here you see/enter if the requirement refers to a certain date, a weekly requirement, or a monthly requirement.

#### Delivery date – Earliest
Here you enter the earliest delivery date for the requirement.

#### Delivery date – Latest
Here you enter the latest delivery date for the requirement.

#### Commitment level
Here you can select the level of commitment: Manufactured or Buy material, if the requirement is concerned by commitment level.

#### Kanban number
Here you see/enter the Kanban number for the call-off.

#### Reference number for manufacturing
Here you see/enter the call-off’s reference number for manufacturing (for example chassis number).

#### Drawing number
Here you enter the drawing number for the call-off.

#### Customer's order row position
This makes it possible to import and enter different values for the customer's order row position on the call-off level. The field is editable if the status on the delivery schedule is New.
