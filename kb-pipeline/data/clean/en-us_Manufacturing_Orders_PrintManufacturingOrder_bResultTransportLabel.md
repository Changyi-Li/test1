### Result (Transport label)
Here you select for which orders you want to print transport labels. A preview of the transport label for the selected order is also displayed.

#### Include
The rows that are checked in this column are the order that will be printed.

#### Order number
Here you can see the number of the order. This column is sorted showing the lowest number first.

#### Part number
Here you can see the number of the part on the order.

#### Planned quantity
In this column you can see the planned quantity of the manufacturing order.

#### Number of copies
Here you select the number of copies that should be printed. The default number of copies is determined in the Document settings procedure.
