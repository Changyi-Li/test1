### Result (Manufacturing order)
Here you select which manufacturing orders you want to print. By default you also see a preview of the first manufacturing order document for the selected order. When you have selected and printed the documents you can approve the printouts or cancel them and go back and print them again.
At the bottom you see the total number of orders that have been loaded. You can also see the number of orders that are marked to be included in the printout. This total is updated if you make modifications in the columns.

#### Include
The orders that are checked in this column are the orders that will be printed.

#### Entire structure (E)
This checkbox determines whether or not the entire structure will be printed, from the selected node and down in the structure. You can check or uncheck this for the separate rows in the list. If the checkbox is not is not checked, the manufacturing order document will only be printed for the selected node's level. This setting affects manufacturing orders which have included part nodes.

#### Structure (S)
The Structure button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) appears if Entire structure is unchecked. By clicking this button you can see the structure and select the part node for which documents will be printed.

#### Part number
In this column you see the main part on the order or the part number you selected under the Structure button.

#### Operation
If you uncheck Entire structure, the Op. field will become activated. Here you can then select a specific operation on the order to print manufacturing order documents for, you can for example print separate operation documents.
