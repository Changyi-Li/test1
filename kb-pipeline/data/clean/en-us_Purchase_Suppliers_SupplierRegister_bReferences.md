### References
In this box you register the supplier's references, with different information for each reference.

#### Default
Here you select whether or not the reference should be selected by default (e.g. on orders that are being registered).

#### Name
Here you see/enter the name of the reference.

#### Phone/Mobile phone/E-mail/Fax number
Here you see/enter contact information for the reference. There are fields available for phone number, mobile phone number, e-mail address, and fax number.

#### Remark
Here you enter a remark you might have regarding the reference, e.g. the job title.

#### Comment
Using this button you open a text editor where you can enter comments regarding the reference.

#### Files
By clicking this button, you can link external files to the reference.

#### Reference category
In this field you can see/enter the category to which the reference belongs.

#### Category selection (CS)
By clicking the Category selection button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png), you can select a category if categories have been registered in the Categories procedure. If no categories are registered, you can type as you please in this field. Categories can be used as a selection term in different lists. Read more about how categories can be created/constructed in the online help function for the [Categories](../../../GeneralRegisters/Categories/Categories/wCategories.htm) procedure.

#### Extra 1-3
If the system setting Show extra information about supplier's reference has been activated, three additional fields will open in the table. These are called Extra 1, Extra 2, and Extra 3. These fields can be used to enter optional information about the references.
