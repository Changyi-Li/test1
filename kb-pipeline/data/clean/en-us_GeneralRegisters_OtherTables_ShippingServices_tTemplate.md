### Template
Under this tab you can add shipment templates that you want to use for shipping services. Shipment templates are primarily used for shipping agents linked to nShift Web-TA. However, they can also be used for shipping agents linked to Pacsoft Online and nShift Delivery.

#### Shipment template
Here you enter an internal name of the shipment template.

#### Code for shipment template
Here you see/enter a code for the "template" in the nShift Web-TA account. You can also enter the ID (the identity) of the "printout favorite" in Pacsoft Online or nShift Delivery.
Specific settings for nShift Web-TA
The settings below apply to nShift Web-TA Monitor ERP Normally export four addresses in shipments: Seller's address/Purchaser's address, Consignor address ID (Web-TA)/Pickup address ID (Web-TA). With these settings you can determine if seller's address and purchaser's address should be exported or not. Some services in Web-TA requires that seller's address and purchaser's address are exported. You can also enter an ID for Consignor address ID and Pick-up address. These are used to link shipments to the correct consignor address and pick-up address in Web-TA and for example determine which OPAL number should be used.

#### Advice to
This setting determines the default value for the default dispatch advice method when this template is used in the Register shipment procedure. A checkbox next to Phone, Mobile phone, or E-mail is checked for the default method. The following options are available:
- None
- Phone
- Mobile phone
- E-mail

#### Seller's address
Here you determine if Seller's address in the shipment should be exported.

#### Purchaser's address
Here you determine if Purchaser's address in the shipment should be exported.

#### Consignor address ID (Web-TA)
Here you enter the sender's consignor address in Web-TA that should be exported by default. This ID applies to the sender’s default consignor address in the shipment. If another consignor address has been selected in the shipment, the number for that consignor address will be exported instead.

#### Pick-up address ID (Web-TA)
Here you enter the sender's pick-up address in Web-TA that should be exported by default. This ID applies to the sender’s default pick-up address in the shipment. If another pick-up address has been selected in the shipment, the number for that pick-up address will be exported instead.

#### Customs payer
This is where you enter the account/agreement number of Customs payer.

#### ID/Warehouse
If you have installed the option Warehouse, you can use the button ID/Warehouse to add the consignor address ID as well as pick-up address ID in Web-TA per warehouse. This will then override the general ID entered in the abovementioned fields.

#### Active
Here you decide which templates should be active for integrations with nShift Web-TA.
