### Attachment types
Under this tab you can add, modify, and delete attachment types. Attachment types are used to make it possible to link other documents to the scanned document, such as delivery notes, purchase orders, travel claims, etc. Attachments are added by using the button Add document/enclosure ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add.png) in the toolbar of the document viewer.
The attachment type 1 Invoice (document) is fixed and cannot be modified or deleted.
A few examples of attachment types are included in the system. You can modify the name text of these, if needed. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.
- E-invoice (XML) – When importing e-invoice from XML file (if you are using a different e-invoice solution than via Crediflow) you can also import attachments to the invoice. To do this you must first choose which attachment type to use for these attachments.
- Global Pay – (applies if you are using the Bank integration option). Here you select which attachment type will be used for Global Pay. As the records are loaded from the bank, a bookkeeping basis showing proof of payment information is automatically attached as a PDF. This PDF is automatically saved as a document to the voucher which is created during the confirmation reporting.
You can also delete the attachment types you do not wish to use. However, you cannot delete any attachment type that is already being used for a scanned invoice. If you try to delete an attachment type that is used, you will see a message telling you that it cannot be deleted and information about where it is used.
