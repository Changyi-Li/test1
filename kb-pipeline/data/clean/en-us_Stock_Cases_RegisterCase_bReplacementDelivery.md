### Replacement delivery
If the customer should receive or if the supplier should send a new delivery, it is managed in this box. The Lookup The Lookup feature is a powerful search tool which allows you to search and load information from large registers. You open the Lookup feature by clicking on the dropdown button or by using F4 on your keyboard. function is filtered by the customer’s/supplier’s order. If you enter an order, the correct invoice will be automatically displayed.

#### Customer nonconformity
If the customer should receive a new delivery, you can either create a new customer order in Register customer order procedure or link an existing customer order. Here you can create a link between the replacement order and the case.

#### Supplier nonconformity
If the supplier should send a new delivery, you can either create a new purchase order or link an existing. A link is automatically created between the case and the order.
