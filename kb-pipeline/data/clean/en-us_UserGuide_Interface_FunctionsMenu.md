### The Function menu
There is a function menu to the left of all lists, selection rows, and different tables in the procedures. This menu contains buttons with different functions. If you place the cursor over a button, the function of the button is shown in a tooltip. In the image below you see an example of how the function menu might look at in a list.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/functionbuttons.png)](../../../Resources/Images/UserGuide/functionbuttons.png)
Many of the buttons on the function menu are also available on the context menu when right-clicking for users who prefer to use that menu instead. Read about it in the topic [The Context menu](ContextMenu.htm).
