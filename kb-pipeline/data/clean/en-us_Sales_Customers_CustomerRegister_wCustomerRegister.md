## Customer register
This procedure is used to register new customers, as well as change and delete existing customers. You can also see an overview for a customer.
On the main row there are two fields where you can enter customer number and customer name
There are tabs under which you can enter and update contact information, settings, CRM, and budget for the customer in question. There is also a tab called Overview where the customer’s quotes, orders, invoice bases, invoices, shipments, and statistics are gathered. The tab is similar to the CRM view procedure.
Deleting a customer
If you try to delete a customer from the customer register, the system will check if the customer is in use. Checks will be made in: quotes, invoices, customer agreements, blanket orders – sales, accounts receivable ledger, and customer links on parts. If the customer is used in any of these registers, you will get information about this in a window when you try to delete the customer. However, if the customer is not in use in the system, it will be deleted.
Extra fields
You can add extra fields for this procedure in the Extra fields procedure. If such fields already have been created, these will be available under the Extra fields tab.
Warehouse
If you have installed the option Warehouse, it is possible to save certain information per warehouse. The information that is saved per warehouse is: Delivery terms, Delivery method, Delivery days, Transport time Transport time is the number of work days that it takes to send a shipment from sender to a receiver., and Place of terms of delivery. If you want to change warehouse, you use the button Warehouse ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_warehouses.png) (Ctrl + Q) on the toolbar of the procedure. If the customer has alternative delivery addresses, this information will also be determined by the delivery address. This means that the information will be saved per alternative delivery address and warehouse. For quotes, customer orders and invoice basis, you can select to which warehouse it belongs. For customer orders it is also possible to select warehouse per customer order row. The combination of the selected delivery address and the selected warehouse determine the mentioned information. Read more about the option [Warehouse](../../../UserGuide/Using/Warehouse/Warehouse.htm).
At the very bottom of the window you can see information about who created and most recently modified the information for the current record and at what time. Using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_log.png) you will access a log containing all modifications.
