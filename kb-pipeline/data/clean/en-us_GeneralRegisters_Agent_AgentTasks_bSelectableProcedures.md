### Selectable procedures
In this section you see all procedures that can be run via agent task. The procedures are shown structure map. You can expand/minimize the entire structure map by using the button Expand all ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_expand_collapse.png) (Shift + F8) on the function menu.
By using the Find button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_search.png) you can open/close the search window to find procedures.
You can add several procedure to the same agent task. You add procedures by using the drag and drop function with the cursor to the section Selected procedures or by using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_goto_next.png) between the sections.
Certain customized reports can be run via agent task.
