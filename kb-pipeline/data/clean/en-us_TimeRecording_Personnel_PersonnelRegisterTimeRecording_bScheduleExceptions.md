### Schedule exceptions
This box is only available if you for the setting Schedule management have selected the option According to schedule cycle.
You can select to show inactive records (schedule exceptions in past time) using the button Show inactive records ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_approve_document.png).

#### Schedule
When required, you can here add schedules which will become exceptions and thereby they override ther person's regular schedule cycles.

#### Date
A schedule exception applies for a specific date which you select here.
Using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you get to see the schedule in chart form.

#### Available schedules at schedule change
By clicking this button you open a table where you can select the schedules that should be available for the person when changing schedule in the recording terminal.
