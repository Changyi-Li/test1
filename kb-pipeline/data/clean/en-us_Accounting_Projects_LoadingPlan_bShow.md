### Show

#### Capacity
This checkbox is activated by default. When it is activated, you will in addition to the loading also see capacity in both the chart and the list. You will also see the difference between them – per period and accumulated. In order to show capacity it is required that theCapacity for project activities setting has been configured for the user.
> Settings for capacity are configured in the Users or User list procedure. There you can choose if capacity should be calculated based on schedule or fixed capacity.

#### Accumulated difference including lag
This checkbox is activated by default. It determines if the accumulated difference should include the hours that are lagging or if the difference should be counted from now on.

#### Percentage loading
This setting is not checked by default. If you activating this setting, the loading hours will not be displayed in the chart. The bars in the chart will instead be displayed as percentages of the loading divided by capacity. That is, the bars display a loading of 100 % when the loading is the same as the capacity.

#### Only capacity from days with loading
This setting is not activated by default. If you choose to activate it, capacity will only be shown for the days where there is loading, otherwise you will see capacity for all days including the ones where there is no loading.

#### Show only main/sub-projects
This setting is not activated by default. If you activate this setting you will only see projects of the main/sub-project type in the list/chart.
