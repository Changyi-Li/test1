### Settings

#### Enter voucher date manually
If integration with the accounting has been configured for the journal, then it is possible to activate this setting and enter a different voucher date in the Voucher date field. This setting should only be used if the records belong to a closed period and have to be recorded in a different period. This setting is not available for the list types for reprints.

#### Integration
Here you see a Yes or a No, letting you know if integration with the accounting has been configured for the journal. Integration is configured for each separate journal in the Voucher number series/Journals procedure.

#### Journal information
In this table you see information about number of posting items and invalid posting, if any, for each log.
