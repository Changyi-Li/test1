## Document templates – Manufacturing order
In this procedure you can for example configure settings for all manufacturing order documents in the system.
When you start up the system for the first time all settings are activated by default. The settings determine which data should be shown. You can also change the layout of the document to some extent.
You can create variants of the standard document templates for manufacturing order documents, if needed. You can also select which variant of each respective document template should be used by default. The standard documents included in the system are Traveler, Operation document, and Material document.
Each document template is divided into sections (document components). You can also create variants of the document components and select which variant should be used by default. The different sections in a manufacturing order document are (from the top): header, text, operations, material, tools (in systems with the Tools & Maintenance option), and footer.
It is also possible to create an empty document variant if you want to design your own manufacturing order document.
> Please note! The part name in the part register can have a maximum of 50 characters. Only the first 20 characters are included in standard documents due to lack of space. If you want to include more characters, you must create a customized document variant. Creating custom document variants requires certain specialist knowledge. If you need help with this, you should primarily contact a consultant at Monitor ERP System AB. Assistance regarding adaptation of document variants is not included in the support and update agreement. Please contact the Adaptation department at Monitor ERP System AB by using this [form](https://monitorerp.com/sv/services/) or by calling +46 650 766 03.
Corresponding settings and variants for other document templates included in the system (for example transport labels, orders, and delivery notes) are managed in the Document settings and Document templates procedures.
DevExpress Report Designer
Monitor ERP is delivered with a third party program used to design and edit variants of documents and document components you have created. The program is called DevExpress Report Designer and is available under the button Edit ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_xtrareport_designer.png) in the Variants box.
