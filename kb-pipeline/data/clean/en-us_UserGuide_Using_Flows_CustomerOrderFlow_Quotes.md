### Quote

#### Register quote
Register a new quote or modify an existing quote. It is possible to generate a customer order from a quote.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/TrainingMaterial/CustomerOrderFlow1.png)](../../../../../Resources/Images/TrainingMaterial/CustomerOrderFlow1.png)
> In the Customer orders box you can see if a quote has turned into a customer order.

#### Print quote
Print quotes using a printer or send it by e-mail. You can also print a separate quote directly from the Register quote procedure.
> Monitor tip! Under the Activities tab you can log activities regarding the quote. Use the Quote list procedure to monitor your quotes. Use the Quote statistics procedure to view statistics over previous quotes. Use Sub-numbers (related quote) to register revisions of quotes.
