### FAQ – General
How do I add text that should always appear on certain documents?
In the Document texts procedure under Additional texts, you are able to add text that should appear on certain documents. First select the document group this should apply to, the document the text should appear on, and then write the additional text that you would like to appear on the document, and then click save. Read more about [Additional texts](../../../../GeneralRegisters/DocumentManagement/DocumentTexts/tAdditionalTexts.htm).
How do I add text that should always appear in certain e-mails?
In the Document texts procedure under Additional texts, you are able to add text that should appear in certain e-mails. Read more about Additional texts in e-mails in the [Additional texts](../../../../GeneralRegisters/DocumentManagement/DocumentTexts/tAdditionalTexts.htm) section.
How do I create an import file?
The import file needs to follow the format template in order to be correctly imported. You can find the import template in the backstage for the import procedure. Read more about [creating format templates](../../GeneralFeatures/FormatTemplates.htm). The following import alternatives are available: [Import sustainability data](../../../Manufacturing/Sustainability/SustainabilityImport/wSustainabilityImport.htm), [Part import](../../../Stock/Parts/PartImport/wPartImport.htm), [Price import](../../../Stock/Parts/PriceImport/wPriceImport.htm), [Customer import](../../../Sales/Customers/CustomerImport/wCustomerImport.htm), [Supplier import](../../../Purchase/Suppliers/SupplierImport/wSupplierImport.htm), [Chart of accounts import](../../../Accounting/ChartOfAccountsDimensions/ImportOfChartOfAccounts/wChartOfAccountsImport.htm), and [Voucher import](../../../Accounting/Vouchers/VoucherImport/wVoucherImport.htm).
How do I set default values?
If you would like a certain default value to be shown when you open the procedure, click the Default values procedure in the toolbar. Read more about creating [default values](../../GeneralFeatures/DefaultValues.htm).
Is it possible to make it so that an activity isn’t automatically added for certain users/roles?
The activity templates are linked to order types and are not able to be limited to a person, roll, etc. You can change the default order type for the user via the Default order/record types button under the General tab in the Users procedure. Select an order type that doesn’t have an activity template.

What is Monitor-to-Monitor?
Monitor-to-Monitor facilitates your communication with customers and suppliers who also use Monitor ERP By attaching an XML file when you send a purchase order to a supplier, the supplier can simply drag the XML file into their Monitor system to register the customer order. You can use Monitor-to-Monitor for many types of communication and minimize the risk of errors by e.g. not having to manually register orders. Read more about [Monitor-to-Monitor](../../GeneralFeatures/M2M.htm).

How do I start using discount categories based on the number of ordered parts?
Activate the system setting named Manage staggered discount rates in the procedure Discount categories under the System overall tab in the System settings procedure. You can then create staggered discount rates in the Discount categories procedure.
What is the purpose of order types?
Order types can be seen as templates containing certain predefined values, such as, price strategy, price list, document, and payment terms, etc. You can, for example, create different order types for new sales, service, etc. Then you can enter these order types as default for specific users based on the role of the user. You create the order types in the [Order types](../../../GeneralRegisters/OtherTables/OrderTypes/wOrderTypes.htm) procedure.
You can create order types for:
- Quote
- Customer order
- Inquiry
- Purchase order
- Manufacturing order
- Blanket order – Purchase
- Blanket Order – Sales
- Customer agreement
