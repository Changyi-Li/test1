### Result
In the table under this tab, you see the result of generated location names based on the definition you have entered.
It is possible to modify location names, block names, and configure if it should be allowed to only have one or several parts on a location name. This is made before you save. You can also enter a comment for each location name. If you have saved the location names and then want to change a setting, this can be done in the list type Locations, in the Location list procedure.

#### Save
Here you check the box for the location names you want to save. If you want to save all names, you check the box in the column heading.
> Please note! Nothing under this tab is saved in the location register until you have checked the box and clicked Save on the toolbar of the procedure. If you have saved the location names and then change your mind and want to delete a location name, this can be done in the list type called Delete locations in the Location list procedure. Please note! If a user has arrival reported parts to a location name which you have delete, the location name will remain in the part register for the affected part.
