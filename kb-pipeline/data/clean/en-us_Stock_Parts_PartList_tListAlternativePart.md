### The Alternative part list
In this list you can update alternative parts. The list contains parts which have been registered in the system as alternative parts, that is, they can replace the regular part when there is a balance shortage.
If you make the list possible to update by using the Updateable button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_edit_list.png) (Ctrl + U), you chan edit the part number and the conversion factor.
