# 安装 Monitor ERP 网络服务器
安装 Monitor ERP Web服务器通常执行由监控支持中心的员工执行。

## 准备工作
1. 复制文件​ MONITOR Web服务器准备.exe 和许可证文件 MONITOR认证- [您的系统名称].rsa 对于您的MONITOR系统，将其保存到应作为 Web服务器的计算机上的某个文件夹。
2. 你安装之前，开始关闭全部其它程序。

## 在程序服务器（MONITOR服务器）上安装
> 如果 Web 客户端仅应在网络中本地使用（例如，由使用通过 Wi-Fi 连接的智能手机/平板电脑记录出勤 / 工作或执行库存报告的员工），请遵循本指南。
1. 使用该文件开始Web服务器安装 MONITOR Web服务器准备.exe。
2. 如果窗口 用户科目控制 显示后，你应该允许安装在计算机上进行变更。点击 是的 在那个窗口中。
3. 在窗口 MONITORWeb服务器安装 显示的，点击 下一个 开始安装。
4. 下一个，你应该点击浏览按钮 ... 并选择相同的许可证文件 MONITOR认证- [您的系统名称].rsa 它是在程序服务器（MONITOR服务器）安装过程中使用的。点击 打开 你许可证文件之后，然后 下一个。
5. 在下一个步骤，你选择Web服务器应该使用哪个MONITOR服务器。默认设置 自动查询MONITOR服务器 被推荐。然后点击 下一个。
6. 在下一个中，你安装路径 服务器。建议安装在默认路径下。点击 下一个。
7. 在下一个中，你输入Web服务器应该使用哪个端口来监听来自 Web 客户端和应用程序的入站流量。端口 443 是默认设置的。这是 https（即通过 SSL 加密流量）的标准端口。
1. 停用 使用 https 设置，因为当 Web 客户端仅在网络中本地使用时，通常不此项。在仓储费用过程中，端口会自动已变更为 80，这是 http（即未加密流量）的标准端口。
2. 输入 用户名， 密码， 和 确认密码，用于运行Web服务器服务的Windows 域管理员科目。你可以使用与运行程序服务器（MONITOR服务器）的服务相同的科目。然后点击 下一个。
8. 在此步骤中，你输入应该用于Web 服务器更新服务的端口，该端口也安装在此安装中。更新服务用于使Web服务器保持与程序服务器相同的版本已更新。端口 8714 是默认设置的。建议你使用默认端口。
1. 也输入 地址 如果默认下 还不输入 , 则 为 网络服务器输入 .程序服务器将向该地址发送更新通知到 Web服务器。该地址作为计算机的 DNS名称(computername.yourdomain.com) 输入。然后点击 下一个。
9. 现在你将看到所做配置的汇总。如果你后悔现在做出的选择，可以后退 后退 按钮。但如果一切OK，你应该点击 下一个 开始安装。
10. 最后，完成你安装 完成。

## 在 DMZ 中的单独计算机上安装
> 如果你希望也可以在网络外使用 Web 客户端（例如，拜访客户并希望通过连接到手机网络的智能手机/平板电脑访问报价、客户订单和发票的销售员），请遵循本指南。
1. 按照上面相同的方式开始安装Web服务器，在 在程序服务器（MONITOR服务器）上安装。你应该按照步骤1-6 进行操作，然后按照查询的描述进行你。
2. 在此步骤中，你输入Web服务器应使用哪个端口来监听来自 Web 客户端和应用程序的入站流量。端口 443 是默认设置的。这是 https（即通过 SSL 加密流量）的标准端口。建议你使用此端口。如果你对 https 使用不同的端口，你还必须记住在防火墙配置中进行此更改。
1. 在这里你应该保持 使用 https 设置已激活。
2. 输入 用户名， 密码， 和 确认密码，用于运行Web服务器服务的Windows 域管理员科目。你可以使用与运行程序服务器（MONITOR服务器）的服务相同的科目。然后点击 下一个。
3. 下一个，你应该将 Web服务器链接到为计算机采购件的SSL认证（以便能够在其 Web 服务器的端口上使用 https）。点击按钮 … 并选择你在计算机上已保存的认证文件（.cer）。通过标记并单击即可完成 打开。然后点击 下一个。
4. 在此步骤中，你输入应该用于Web 服务器更新服务的端口，该端口也安装在此安装中。更新服务用于使Web服务器保持与程序服务器已更新到相同的版本。端口 8714 是默认设置的。建议你使用默认端口。如果你使用不同的端口，你还必须记住在防火墙配置中进行更改！
1. 你可以在这里离开 使用 https 设置未激活，因为 Web服务器和程序服务器在中间的内部的流量不必要。激活你设置，则将使用与前道步骤2-3相同的认证文件。
2. 在此步骤中你还输入 地址 如果默认下 还不输入 , 则 为 网络服务器输入 .程序服务器将向该地址发送更新通知到 Web服务器。该地址作为计算机的 DNS名称(computername.yourdomain.com) 输入。
3. 然后点击 下一个。
5. 现在你将看到所做配置的汇总。如果你后悔现在做出的选择，可以后退 后退 按钮。但如果一切OK，你应该点击 下一个 开始安装。
6. 最后，完成你安装 完成。

## 核实安装
1. 开始一个 Monitor ERP Windows客户端并打开调用的程序 系统设置。转到标签页 系统总体 并向下滚动到标题 自动更新定制包。检查是否有行 网址 和 验证密钥 在表格中输入 Web服务器。
2. 标记表格中的行并单击按钮 验证连接 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_test_call.png) 检查与 Web服务器的通信是否正常。
