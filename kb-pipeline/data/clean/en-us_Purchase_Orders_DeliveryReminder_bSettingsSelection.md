### Settings – Selection
Result

#### Days of grace for delivery
With this setting you determine the number of work days that should apply as days of grace for delivery. This applies to all orders with a delivery date before or the same day as the entered printout date.
Example: 1 day is entered as days of grace. Only order rows where the delivery is at least 1 work day delayed in relation to the row's delivery date at the printout date will be included in the document. You can also enter a negative value, in order to include deliveries that are to be delivered within the next few days. In some cases it is customary to remind upcoming deliveries as well.

#### Days between reminders
With this setting you determine how many work days that must pass from the most recent reminder sent until you are able to send the next one.

#### Use days of grace, if any, on supplier
You can enter the days of grace for the supplier in the Supplier register. If you have entered days of grace for the supplier and checked this setting, it will be used instead of the value entered for the settings Days of grace The term days of grace (or grace period) is used at requirements planning in order to calculate rescheduling of actual orders that cover the requirement but that are too late in time, instead of suggesting a new order. for delivery and Days between reminders. If you have not entered any days of grace in the supplier register or if you do not check this setting, the number of days entered in the above fields above will be used.

#### Include stray suppliers
With this setting you determine whether or not suppliers marked as “stray suppliers” will be shown in the list.

#### Only order confirmed order rows
This setting determines whether or not a check of the row status should be performed before printing. If you activate this setting, only the order rows that are confirmed will be printed, provided that they are included in the selection.

#### Include order rows confirmed as delayed
With this checkbox you determine if you wish to show/include order rows that have been confirmed as delayed.

#### Pre-select "Include"
This setting determines whether or not the “Include” box should be checked by default for all rows in the list/result.
Printout

#### Printout date
The date that is shown on the document as the date of the printout. Today's date is shown by default. By using the available calendar, you can select another date.

#### Number of copies
Here you select the number of copies that should be printed. The default value here is 1. If more than 1 copy is printed it will say "COPY" on all documents following the first printout. This feature can be turned off with the setting Mark as copy for each document in the Document settings procedure.
