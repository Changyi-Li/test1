### Periods
In this box you will see the periods for the selected accounting year.

#### Period
A table with one row per accounting period. Each row has a period number which starts from 1.

#### From date and To date
Each month is set as one period by default for a new year. It is possible to change the date for the periods, but they cannot overlap each other. However, you cannot change the date if the period in question contain accounting.
