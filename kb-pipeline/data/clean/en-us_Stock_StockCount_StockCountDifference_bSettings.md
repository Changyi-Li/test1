### Settings

#### Price alternative for purchased part/manufactured part
Here you select the price which should be used to valuate purchased and manufactured parts.
If you select the option Price list you can select a specific list to use from the setting Price list.
If it is possible for the selected price alternative to be in another currency, the setting Rate type becomes available. This applies to the alternatives Supplier price and Price list. All active rate types are then selectable. The default rate type is set in the system settings. When you select a rate type, the price will be recalculated to the company currency.

#### Part's unit
The unit in which the part will be displayed. The price, the stock counted quantity, and the stock count difference are shown in the selected unit.

#### Parts with stock update
With this setting you determine which parts to show in the list: All, Only parts with stock update, or Only parts without stock update.

#### Minimum value
(Applies to list type Detailed) Here you decide the minimum value of the stock count differences in order for them to be accounted. If this field is left empty, the detailed list will contain all records in the stock count log, regardless the magnitude of the difference. If you for example enter SEK 100 as minimum value, all separate stock count records that have a value change between −99 SEK and +99 SEK will be totaled as small negative amounts and small positive amounts. The small amounts are included in the total amount in the list.
