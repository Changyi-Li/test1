### The Total list
This list type has two presentations which show totals for planned and reported measuring per operation in manufacturing order.
The presentation called Reporting status of rows per operation will add together the number of measuring points that are planned and that have been reported.
The presentation called Reporting status of forms per operation will add together the number of measuring forms that are planned and that have been reported.
The number of remaining measuring items per manufacturing order are also shown in a chart. This list type can, for example, be used to find the operations where there are measuring points which have not been reported.
