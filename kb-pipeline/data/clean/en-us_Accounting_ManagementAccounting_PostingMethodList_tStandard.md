### The Standard list
The data loaded to the Standard list depends on which presentation you have selected. You can edit most of the columns.
Term/Value to post
In this list you can see settings made for the posting method. You can for example edit Name, Part type, Control method M-part, Part's basic type, Include packaging, Event type, Reverse posting on reversed event type, and Allow duplicates. It is also possible to change Quantity, Price alternative, Price list, Price type, Cost factors, and if the posting method is active or not. The alternatives may vary depending on the part type.
In this list you see information from the [Terms](../RegisterPostingMethods/bTerms.htm) and [Value to post](../RegisterPostingMethods/bValueToPost.htm) boxes in the Register posting method procedure.
Posting
In this list you can see how the different posting methods are posted. For example you can change Name, Part type, Debit account, and Credit account. It is also possible to edit dimensions, if any, and if the posting method in question is active or not.
In this list you see information from the box [Posting](../RegisterPostingMethods/bPosting.htm) in the Register posting method procedure.
