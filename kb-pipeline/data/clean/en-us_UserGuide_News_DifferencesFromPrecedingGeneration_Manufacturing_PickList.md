### Pick list
- The pick lists are available as documents which makes it possible to do own changes of the layout.
- The extra name of the part is shown on the pick list (document setting).
- The material's position number is shown (document setting).
- A pick list can by grouped by included material and then you will see the total quantity per material (the presentation Grouped by material).
- The main part's quantity is shown (the presentation Grouped by order).
- Each pick list gets a pick list number. This makes reprints possible and it is easier to select when reporting in the Report pick list procedure.
- You can enter which person who created the pick list.
- There are different variants of the pick list (different groupings and sorting alternatives) which can be selected when it is created or printed.
- In the Pick listA pick list is a list of parts/products which should be picked from stock for a manufacturing order or a customer order. you can choose that the procedure Report pick list should open directly after the pick list has been created.
