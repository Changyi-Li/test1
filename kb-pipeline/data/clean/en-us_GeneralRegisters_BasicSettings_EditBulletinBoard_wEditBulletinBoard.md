## Edit bulletin board
In this procedure you can enter information on a bulletin board. This procedure is very useful for spreading information to the users in Monitor ERP, in the company, in the warehouse, or in all companies in the system.
There are bulletin boards for Monitor ERP's Windows client and mobile client. You find bulletin boards for the Windows client under the Standard tab. You find bulletin boards for the mobile client under the Mobile client tab.
There are three types of bulletin boards. A common bulletin board for all companies, a unique bulletin board per company, and a unique bulletin board per warehouse. (Warehouse is an option.)
Users can see the bulletin board by using a component they can add to the desktop in their client. In the component the users select which of the above mentioned bulletin boards they want to show. Users can also have multiple components with different bulletin boards, for example, one common and one for the specific company or warehouse.
