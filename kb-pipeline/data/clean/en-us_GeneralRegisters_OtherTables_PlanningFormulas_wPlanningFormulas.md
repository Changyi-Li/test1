## Planning formulas
In this procedure you can see planning formulas that are used in different calculations of material requirements, as well as putaway strategies for arrival to stock. A set of different planning formulas and variables for different stock calculations is included in the system.
The calculations which apply these formulas are:
- Calculation of safety in the Calculate stock levels procedure.
- Calculation of order quantity in the Calculate order quantity procedure.
- Calculation for stock refill in the procedures called Stock refill – Purchase and Stock refill – Manufacturing.
- If you are using the Advanced stock management option there are also formulas for putaway strategies.
You cannot delete or change the planning formulas that are included in the system. However, you can create new own planning in two different ways:
- By copying a formula using the button Split row ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_copy_row.png) (Ctrl + Shift + C) on the function menu and then make changes in the new formula. This is the recommended method.
- By creating a new formula using the buttonAdd new row at the end ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_row.png) (F5). This formula is completely empty from the start and you must enter something in the formula editor, for example a variable, to be able to save the formula.
You can also delete formulas that you have created by using the button Delete selected row ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_delete_row.png) (F6).
> Remember this: We recommend that you book one of Monitor ERP System AB's consultants when you should create own planning formulas. Own planning formulas are not included in the support and update agreement with Monitor ERP System AB. Any support cases regarding creating new planning formulas or calculations based on own planning formulas will be charged on a continuous basis by Monitor Support Center. Planning formulas in Monitor G4 will not be converted to Monitor ERP.
