### Included in
In this list you can see in which structure parts the selected part in the [Consists of](bConsistsOf.htm) list, is included. The Included in list type is like a reversed version of the Consists of list with the corresponding columns.
Function buttons
The button called Load the selected part to Consists of ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_replace.png) is available in this list if you have selected the Consists of/Included in list type. By clicking this button you see which parts the marked part consists of. The part is then shown in the Consists of (structure map) box. This is useful if you wish to analyze which parts another part is included in. The other function buttons correspond to the buttons available in the other box.
The More information button
By clicking the More info button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) at the far left of the list, you find additional columns with information from the BOM and routing and the part register.
