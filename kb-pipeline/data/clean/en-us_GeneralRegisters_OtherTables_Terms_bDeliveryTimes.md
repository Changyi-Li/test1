### Delivery times
In this table you register delivery times. Delivery times are used to describe the different delivery times (in number of work days) that should apply to quotes.

#### Default
Here you determine if the delivery time should be used default when registering new quotes.

#### Number
Here you can see the number for the position of the row. This field is numerical. A new row will by default be assigned the next available number. The table/list is sorted by this column. A number is unique and cannot occur on more than one row in the table.

#### Name
Here you enter a name for the delivery time. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Number of days
Here you enter the number of work days for the delivery time when you turn a quote into a customer order. Customer order rows created from the quote rows get the same delivery date as order date + delivery time (that is, the number of work days entered here).
