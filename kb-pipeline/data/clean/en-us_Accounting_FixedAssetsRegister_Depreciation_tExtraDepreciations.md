### Extra depreciation
Under this tab you make adjustments to the scheduled depreciation (extra depreciation). It is possible to temporarily change the integration setting in the top box in the window if you for example need to make an adjustment which only should affect the fixed assets register and not the accounting.
You can choose if you want to save, save as, or print the journal. If you use direct integration it is only possible to save, and the depreciation becomes recorded directly when you save.
Please note! Extra depreciation will affect the fixed asset's residual value. This means that the future depreciation will be changed.
