### Export/Import

#### Country of origin
In this field you can choose a country of origin for parts in this template. The name of the country is shown to the right of the field.

#### Status
Here you determine if a default status should be set on parts in this template.

#### Activity template
Here you determine if default activities from an activity template should be set on parts in this template. Activity templates for parts are created in the Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Part procedure.
> Please note! A selected activity template in a part template will not be synchronized in the procedure Synchronize part template.

#### Fixed weight
With this setting you decide if the net weight for parts in this template should be fixed and not be possible to recalculate in the Calculate weight procedure.
