### The Languages table
In the table you will find the following columns:

#### Language code
Here you will find existing language codes. If you add a row for a new language, then you select language code in this field. The available language codes follow the international standard ISO 639-1. In the Name column you will see the name of the selected language.

#### Document group
The document group for the language. To each existing language code you will find a default document group. However, this can be manually changed. The document group determines that the document headings will be displayed in the language into which they are translated. When adding a new language you must also create a new document group for the language in question. This is made in the Document texts procedure. The new document group will then be selectable in the table. The headings will be translated per document group under the Phases tab in the Document texts procedure.

#### Active
Here you can activate/inactivate languages. If you inactivate a language you can no longer translate name texts and such into the language in question. The translation is made under the Translations button in different places in the system.
