### Delivery
These procedures are normally used when/where deliveries are made, i.e. during picking, packing, and shipping (dispatching). They are used to monitor what has to be delivered, make delivery reports, and print the necessary shipping documents.

#### Pick list
Print a pick list to use as basis e.g. for what should be delivered today. You can use the Delivery planning procedure.

#### Pack for delivery
If you are using the Delivery planning procedure, and you have created a pick list, then you are able to pack the order rows in a package structure in the Pack for delivery procedure. This package structure reflects the physical package structure. Based on the packing and the package structure you can then print packing list and transport labels reflecting the structure. When the packing is completed, you mark the entire structure as ready for delivery.

#### Report delivery
Deliver the entire order (the order receives status 9) or make a partial delivery (the order receives status 5). You can print delivery note and transport label, if any. The balance is updated for the delivery reported parts. You have the opportunity to add rows, for example for packaging and freight charge.

#### Register shipment
Book freight and print the required shipping documents.
