### Shipments
In this box you see the shipments which have been sent/shipped to the selected suppliers.

#### Include
Check the box in this column for the shipments that you want to undo.

#### Shipped quantity
In this column you see the shipped quantity.

#### Purchase order number
Here you see the purchase order number of the subcontract which has been shipped.

#### Shipment date
Here you see the date and time of when the shipments was made.

#### Information
In this column you will see a warning symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png) if the shipment you want to undo results in something you need to be informed of.
If for some reason it is not possible to undo the shipment, an error symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/error.png) will be shown. For example, an arrival reporting might have been made for the shipment.
A tooltip is shown when you hover over the different symbols, each displaying information about the warning/error.

#### Supplier number
In this column you see the supplier number of the subcontractor.

#### Supplier name
Here you see the name of the subcontractor.

#### Manufacturing order number
Here you see the manufacturing order number of the subcontract.

#### Delivery address (DA)
Here you find the delivery address of the subcontractor.

#### More info
Under the More info ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) button you find additional information about the subcontract.
