### Priority planning
- You can see if the manufacturing order is Confirmed as delayed.
- A difference column is shown where Finish date and New finish are compared.
- More customer order data is shown (accessed via button).
- You can perform material clearance directly in the priority plan without opening any other procedure.
- Filter by time horizon in the priority plan.
- It is possible to change the simulation factor and see the effects of the change in the priority plan.
- The lead time chart for the entire work center is found as a separate tab in the procedure.
- You can save filters for material, which can make it easier/quicker to filter in the same way at a later time.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/News/PriorityPlanning.png)](../../../../../Resources/Images/News/PriorityPlanning.png)
- In the BOM and routing it is possible to add Alternative work centers for the operations. In the priority planning you can then see in which work center this work also can be run and that way you know to which work center is it appropriate to replan an operation, if there is a shortage of capacity.
- The function for Alternative work centers has also been further developed. Now when you change to an alternative work center, the times etc. will then be replanned according to what was entered in the BOM and routing.
- Now it is possible to select the field on which the Priority plan horizon should be based. Earlier, the priority plan horizon was always filtered by the field New finish, but now you can use the system setting Time horizon filters by to choose how to filter. You can filter by: New finish date, Planned finish date, or Planned start date.
