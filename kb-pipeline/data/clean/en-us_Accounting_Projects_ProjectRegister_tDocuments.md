### Documents
Under this tab you can print project reports summarizing different information about a project. In addition to general information about the project, the project report also shows phases/activities, costs/income, and time check.

#### Document
The project report is available as two different documents: Internal project report and External project report. Different document settings can be made for each report, and you can this way decide which fields and sections that will be printed.

#### Variant
The variants determine which columns are displayed under the sections Cost/Income and Time check on the documents.

#### Printout date
Here you select the printout date to be printed on the document.

#### View level for activities
With this setting you decide if phases and activities should be shown.

#### Show cost/income
Here you decide if the Cost/Income section should be shown on the document. You can choose to show per Group/type, Type or Do not show.

#### Show time check
Here you decide if the Time check section should be shown on the document. You can choose to show per Group/type, Type or Do not show.

#### Select project
By using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_project.png) you can select which projects' values should be shown in the sections Cost/Income and Time check. Please note! Only total values are shown, not sub-totals per sub-project.
> In the Users procedure you can configure if you want sub-projects to be loaded by default when a main project is loaded.
