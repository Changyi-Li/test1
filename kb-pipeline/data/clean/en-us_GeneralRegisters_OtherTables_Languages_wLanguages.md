## Languages
In this procedure you can register languages in addition to the languages included in the system when you start up the program for the first time. You can also delete a language that you have registered, if you do not use it anymore. However, the languages included in the system cannot be deleted.
Language is for example used when printing different documents such as order confirmations in the recipient's language. When you register a customer (or supplier), the customer's language is set based on the country entered in the customer's mailing address. However, this can be manually changed in a separate language field in the customer register. The corresponding also applies to the supplier register.
All headings and lead texts on documents are translated into the different languages included in Monitor ERP. They are saved in a phrase register in the Document texts procedure.
Data such as names of records that are printed on different documents, for example part names on order rows and names of different terms in the order header, can also be translated into the language configured for addresses on customer, supplier, as well as user. The translation of these names should be made in the affected procedures, for the languages that should be used on the customer's and supplier's addresses and on user. If these names are not translated, the names will be shown in the company language on the documents. Read about [translation of data and phrases](../../../UserGuide/GeneralFeatures/TranslatingData.htm).
Language is set per user in the Users procedure. This determines that all headings and text in the interface in Monitor ERP are shown in the language configured for the user or in a temporary language selected for the user. It also determines that different names on data will be displayed in the user's language provided that the data is translated into this language. To temporarily change language in Monitor ERP, a user can select Language in the backstage of the desktop.
Example:
A user working in a warehouse speaks Finnish and runs Monitor ERP in Finnish. Lead texts and part names in a pick list are then shown in Finnish for this user. The user who registers orders speaks English and runs Monitor ERP in English. This user sees the corresponding information in English on the customer order. The customer has a mailing address in France and a delivery address in Germany. In the corresponding way, the order confirmation and delivery note will be shown in French respective German. This is possible since the affected data is translated into Finnish, English, French, and German.
