### Header row

#### Part number
Here you enter the number of the subcontract part. Only parts of the Subcontract type can be loaded here. In the LookupThe Lookup feature is a powerful search tool which allows you to search and load information from large registers. You open the Lookup feature by clicking on the dropdown button or by using F4 on your keyboard. feature in the field, you will only see this type of parts. The number of the part is automatically taken from a number series for subcontract parts. The number series is called Subcontract part and is managed in the Number series procedure.

#### Name
The name of the subcontract parts will be generated automatically. The prefix is the main part in the BOM and routing, and the suffix is the operation number in the BOM and routing (where the subcontract part was created). A name can for example be "1500 - 10".
If the subcontract is added on the manufacturing order, the order number will also be added. A warning will also be shown letting you know that there is no operation row and that the part is not included in any BOM and routing. This is done to make the user aware that it is an operation not included in the regular BOM and routing.

#### Type
The subcontract part type is shown. Only parts of this type can be loaded in the procedure.
