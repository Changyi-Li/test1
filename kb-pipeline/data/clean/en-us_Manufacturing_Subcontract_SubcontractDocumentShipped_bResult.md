### Result
In the result you can select which purchase orders will be printed/sent via e-mail. By default, all are selected. In the right section you can preview the document you have selected.
By using the Go to procedure button ![](https://help.monitorerp.cn/CN-MONITOR_G5/G5_Sales_SV/Content/Resources/Images/button_link.png) you can go to procedures such as BOM and routing, Register manufacturing order, Work centerA work center is a part of the factory. It can be a single machine or a group of machines, a single workstation or a group of workstations. register, and Register purchase order. The links to Part, BOM and routing, Manufacturing order and others are only available if you have selected to review the document Transport label. The links to Supplier and Purchase order are available for all documents.
By using the Create shipment button ![](https://help.monitorerp.cn/CN-MONITOR_G5/G5_Sales_SV/Content/Resources/Images/button_add_shipping.png) you can create a shipment for the subcontracts where Include box is marked. A shipment draft with all of the information pre-filled is then created in the Register shipment procedure.
> When you have printed and confirmed purchase orders, you can switch to the delivery note document to print/send via e-mail and approve the printout.

#### Include
With this checkbox you determine which subcontracts that will be included in the documents to print.

#### Printing method
Here you choose printing method for the subcontract in question. The available alternatives are Printer or E-mail, that is, whether the document will be printed to a printer or attached as a PDF file to an e-mail message. You confirm the printout by using the button Print/Send ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_mail_and_print.png) in the toolbar of the procedure. If E-mail is selected, it is also possible to create an XML file that can be imported into the supplier’s Monitor system. You will find settings regarding this in Supplier register.

#### Quantity/package
(Transport label) Here you can enter which quantity should apply per package. This affects how many transport labels will be printed.

#### Number of copies
Here you select the number of copies that should be printed. The default number of copies is determined in the Document settings procedure.
