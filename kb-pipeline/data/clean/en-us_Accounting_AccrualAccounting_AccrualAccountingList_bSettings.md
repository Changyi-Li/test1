### Settings

#### Date
This setting is available for all list types. When calculating released and remaining value on accruals, the date entered here will be taken into consideration. In the list you will see the accruals up to the date you selected here. The default date is the last day of the current period.

#### Include fully released
This setting is only available for the list type Standard. With this setting you determine if the list should include all accruals up to and including the selected date. Fully released accruals will be included if you check this box, otherwise you will only see the accruals where there is something left to release.

#### Include released
This setting is only available for the list type Period allocation. With this setting you determine if the list should include accruals which have been released during the accounting year in question.

#### Only accrual accounts
This setting is not available for the list type Reconciliation by accrual. With this setting you determine if the list should be based on accrual accounts, that is, only on accounts with the setting Accrual account entered in the chart of accounts. This is equivalent to pasting a selection in the account selection only containing accounts referring to accrual accounting.

#### Only canceled accruals
This setting is only available for the list type Standard. With this setting you decide if the list should only display accruals which have been canceled.
