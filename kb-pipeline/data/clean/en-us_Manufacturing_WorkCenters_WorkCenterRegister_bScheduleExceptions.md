### Schedule exceptions
In this box you enter exceptions for schedules applied during hourly planning or capacity via schedule. Using the Schedule button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png), you get to see the schedule in chart form.

#### Date
In this field you enter a date for which there should be a schedule exception.

#### Exception from number of machines/Exception from number of persons
Here you can enter an exception from the number of machines (or and exception from number of persons if the work center is of the type Manual work). Example: If the work center normally consists of two machines, but one of them is broken, then you can enter one machine instead.

#### Regular schedule
Here you can see the number of the regular schedule. It is not possible to modify.

#### Name
Here you see the name of the regular schedule. It is not possible to modify.

#### Schedule for exceptions
Here you select the number of the schedule from which the exception is loaded.

#### Name
Here you can see the name of the schedule which is used as the exception.

#### Schedule exceptions
By clicking this button you access the exception schedule in chart form.
