### 邮寄地址
地址设置
点击 地址设置 按钮 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_change_settings.png) 你可以更改语言和文档组。一需要使用与 国家 / 地区 交货地址地址中的字段或者是否应该使用不同的文档组，即不由语言确定的组。你还可以看到所使用的地址格式。这也是由已选择的国家 / 地区决定的。你还可以预览当前地址格式的邮寄地址。

#### 语言
选择国家时，语言会自动填写。该字段可以编辑，您可以选择任何语言。这可能是有用的，例如适用于使用多种语言的国家/地区，或者客户/供应商希望将所有文档以某种特定的语言使用，而与发送国家/地区无关。通过使用“查找”功能，可以在“语言”程序中登记为活动语言的语言中进行选择。这可能是有用的，例如适用于使用多种语言的国家/地区，或者客户/供应商希望将所有文档以某种特定的语言使用，而不考虑发送到的国家/地区。您可以在语言程序中登记为活动的语言中进行选择。

#### 文件组
在这里，您将看到输入地址的默认文档组。文档组确定哪些文本（短语）将作为标题显示在文档上。文档组由在上述字段中选择的语言确定，但可以选择不同的文档组。您可在文档文本程序登记的文档组中进行选择。

#### 地址格式
这是一个显示所选国家地址格式的信息字段。地址格式是在国家/地区程序中按每个国家/地区配置的。
此按钮到右边有一些按钮，你可以使用它们来预览地址并在 Google 地图上显示该地址。

#### 名称
地址中使用的公司名称。此强制字段。

#### 地址
邮政信箱地址或街道地址。每个行最多可包含 50 个字符。

#### 邮编
邮寄地址的邮编。已登记在​ 邮编登记 程序，你可以选择一个邮编。

#### 城市
邮寄地址所在的城市。这是自动从 邮编登记 如果 已经 输入 了 该国家 / 地区的邮编则 可以程序.
这 城市 字段可用于以下地址格式：
- 邮编 + 城市
- 城市， 邮编 （两行）
- 城市 + 州 / 地区 + 邮编。

#### 州 / 地区
邮寄地址所在的州或地区。这是自动从 邮编登记 如果 已经 输入 了 该国家 / 地区的邮编则 可以程序.
字段 州 / 地区 以地址格式可用 城市 + 国家 / 地区 + 邮编。例如在美国使用此地址格式

#### 城市 / 省
邮寄地址所在的城市或省份。这是自动从 邮编登记 如果 已经 输入 了 该国家 / 地区的邮编则 可以程序.
字段 州/省 以地址格式可用 城市 / 省+邮编。例如在中国就使用这种地址格式。

#### 国家 / 地区
国家 / 地区是强制的输入的，它决定了邮寄地址将使用的语言和地址格式。语言和地址格式每国家 / 地区已配置 国家 / 地区 程序。如果已选择的国家 / 地区不特定的地址格式，则将应用通用地址格式。国家 / 地区显示在文档邮寄地址的最后行。
