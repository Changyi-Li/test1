### Channels
In this box you find all active EDI EDI is the acronym of Electronic Data Interchange. EDI is about exchanging electronic business documents with your business partners, e.g. customers and suppliers. The EDI concept can be wide and a bit unclear, and can many times be used about all types of documents which are sent electronically, even if it might be PDF files sent via e-mail or publishing business documents on a website. What we refer to as EDI – and what is traditionally meant by EDI – is structured business documents following given standards, electronically sent or received and which are compiled and interpreted automatically and that is integrated with the customer's/supplier's ERP system. channels. An active EDI channel is linked to an active EDI configuration via an active channel configuration.
Here you can see the Status of last run of the channel, and if it has been started.
Under the Runs![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) button you see all runs that have been made of the current channel, when the runs were made, the result of the runs, as well as if the runs were automatically triggered by a schedule or manually triggered by a user. For each run you can use the button Log ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) to see what has happened in the run such as steps, events, details, time, and level.
The button Start channel ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_run.png) in the function menu will start the run of the selected channel.
The button Delete run(s) ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_delete.png) (F6) on the function menu deletes all runs, all belonging transactions, and logs for the selected channel. A question appears before the deletion is executed.
