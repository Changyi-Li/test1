### The Requirements – Detailed list
In the Requirements – Detailed list, you can get an overview of transferred calls and see differences in requirements between delivery schedule and order backlog.
To simplify, you can say that there are two categories of changes:
- The changes that were made, that is, which order rows were deleted, which were created, which were changed regarding quantity and by how many they were changed.
- The changes which were not made, that is, what e.g. was within the frozen period and therefore was not included in the transfer.
The list is loaded and displayed based on the selection and settings you have chosen. As in all lists in Monitor ERP, you can drag and drop in order to change the column to group by.
The Grouped by delivery schedule/customer/part presentation displays the columns Customer’s delivery schedule date and Status.
The calculated column Age displays the age of the delivery schedule, calculated using the amount of days that have passed since the Created when date in Monitor ERP.
The Age threshold column is the threshold for age that has been entered in the Number of days setting, if Warn if schedule (or section) is not replaced within set time is set to Yes. If the threshold value passes, the same warning as in the Analyze delivery schedules procedure is shown.
