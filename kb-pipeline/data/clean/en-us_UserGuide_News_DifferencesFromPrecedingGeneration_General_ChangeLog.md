### Changelog and Print log

#### Changelog
The Changelog is a general function which for every record displays a log of when it was changed and by which user. It is logged on field level what the value was before and after the change/modification. In G4 there was logging of changes made in certain registers, while in G5 it is a general feature for all registers. This is not something which needs to be activated, it is always active.

#### Print log
The Print log is a general function available in all places in the system where it is possible to print documents. All such printouts are saved to a print log. In this log you can view the document as it was at the time of the printout. Regardless of what has been changed on for example an order, after the printout was made. This can e.g. be used to make reprints and to be able to look at previously printed documents.
