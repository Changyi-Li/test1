### The Standard list
This list shows information about the stock value for the selected parts per location. The list is sorted by part number. The value of all parts are shown as total per location. The list has a total of small positive and negative amounts. What is shown here depends on the value you entered in the settings as minimum value. A total value of the selected parts is also shown.
Each location displays price, balance, unit, and value. If the Warehouse option is installed, you see to which warehouse the location belongs. If you have activated the setting Show calculation information you can see information about cost of material, SO, subcontract, SC, processing, and cost factors.
This list shows detailed information about the stock value for the selected parts. The list can either be grouped by part code or product group. All parts included in the respective part code or product group are shown under its grouping. Each grouping has a total of small positive and negative amounts. What is shown here depends on the value you entered in the settings as minimum value. You will also see a total value.
Each part row displays price, balance, unit, and value. If the Warehouse option is installed, you will see in which warehouse the part is. If you have activated the setting Show calculation information you can also see information about cost of material, SO, subcontract, and SC.
