### Pick lists (Release preliminary pick lists)
In the list you see the selection of preliminary pick lists which had not been released to regular pick lists.
The pick list rows are grouped in sections in the same way as in the Delivery status box in the Picking plan list.
In the Order rows bow to the right you find the same information on the order rows as in the Picking plan list. Read more about this information in [Order rows](bOrderRows.htm).

#### Release
Using the Release checkbox in the section called Ready for delivery you mark which preliminary pick lists should be released to become regular pick lists. When you save in the procedure when there is a marked checkbox, a balance check is made and the quantity to deliver on the pick list is cleared. A delivery note is also created if it on the order has been configured that delivery note should be created when delivery planning.

#### Other information on the rows
On the rows for preliminary pick lists you see the pick list number, customer number, customer name, pick time, printed when and by, date and time when the pick list was created and by whom, and percentage packed of the pick list.
Under the More info button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you see if the package structure is ready for delivery (this is marked for the pick list in the procedure Pack for delivery), number of handling units, earliest and latest delivery date, gross weight, payload net weight, loading meters, volume, and internal and external comments.
