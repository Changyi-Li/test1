### 后台
桌面后台有一些通用功能和设置 Monitor ERP 以及作为用户的你。
| 功能 | 解释 |
|---|---|
| [设置](../GeneralFeatures/BackstageSettings.htm) | 你在此配置颜色范围/主题、提醒、打印等的设置。 |
| [仓库](../GeneralFeatures/Warehouse.htm) | 你在这里查看并选择可用仓库。 |
| [语言](../GeneralFeatures/Language.htm) | 在这里你可以看到并选择默认语言和当前语言。 |
| [会计年度](../GeneralFeatures/AccountingYear.htm) | 在这里你可以看到并选择默认语言和当前语言。 |
| [桌面](../GeneralFeatures/Desktop.htm) | 你可以在这里选择桌面的布局和桌面部件。 |
| [关于](../GeneralFeatures/About.htm) | 你将在这里查询信息 Monitor ERP。 |
| [退出](../GeneralFeatures/LogOut.htm) | 你在此退出 Monitor ERP。 |
