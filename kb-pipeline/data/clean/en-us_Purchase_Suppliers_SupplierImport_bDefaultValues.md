### Default values

#### Supplier type
Here you select which supplier type that by default will be selected for the imported supplier. Supplier types are handled in the procedure Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – SRM.

#### Supplier status
Here you select which supplier status that by default will be selected for the imported supplier. The default alternative here is Actual supplier. Supplier statuses are handled in the procedure Basic data – SRM.

#### Supplier role
Here you select the role/roles that should be given to the imported suppliers. The available options are: material supplier (default), subcontract, shipping agent, and miscellaneous.
