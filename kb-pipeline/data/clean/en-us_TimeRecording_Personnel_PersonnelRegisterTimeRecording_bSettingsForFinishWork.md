### Settings for Stop work
In this box you find settings for the person in question regarding stop work and partial reporting of directly work (operation) in the recording terminal.

#### Suggest remaining
If you check this setting, the remaining quantity will be suggested.

#### Show goods location
If you activate this setting, the field Goods location will be shown. There you can enter a goods location where the reported goods should be placed when the work is not the final operation.

#### Show location
If you activate this setting, the LP button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) will be shown. There you can select a location where the reported goods should be placed when the work is the final operation. If the part which you report has traceability, then it is mandatory to enter batch number/serial number on location even when this setting is not activated.

#### Show material rows
If you activate this setting, the settings below become available. This is done to make it possible for the employee in question to manually report material.

#### Allow material reporting
If you check this setting, the button Automatic withdrawal of material ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_show_no_structure_part.png), is shown when the employee stops a work item and when partially reports a work item. This setting makes it possible for the employee to activate/deactivate the button, deciding if manual reporting or automatic reporting of material should be made. The setting will also permit the employee to only perform material reporting using the button Material reporting for work in progress.

#### Allow material addition
With this setting you activate the button Add new row at the end ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_row.png) (F5) when the employee stops a work item or when he/she makes a partial reporting. The button will then make it possible for the person in question to add extra material rows to a work item when reporting.
