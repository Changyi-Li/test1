### 访问地址
地址设置
点击 地址设置 按钮 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_change_settings.png) 你可以更改语言和文档组，如果需要与一 国家 / 地区 访问地址中的字段或者是否应使用不同的文档组，即不由语言确定的组。你还可以看到所使用的地址格式。这也是由已选择的国家 / 地区决定的。你还可以按照当前地址格式预览访问地址。

#### 语言
你可以在这里决定访问地址应用于哪种语言。如果地址用于的语言与国家 / 地区所输入的语言不同，可以在此处已变更语言。当你选择国家 / 地区时，语言会自动填写。该字段可以编辑，并且你可以选择任何语言。例如，对于具有多个的国家 / 地区或客户 / 供应商希望全部文档都使用某种语言（无论文件已发送到哪个国家 / 地区）的情况，此功能很有用。你可以在已登记为激活的语言中选择 语言 程序。

#### 文档组
在这里你可以看到/选择访问地址的默认文档组。文档组由上面字段中已选择的语言决定，但可以选择不同的文档组。你可以在已登记的文档组中选择 文档文本 程序。

#### 地址格式
这是显示已选择国家 / 地区地址格式的信息字段。地址格式针对每个国家 / 地区/地区已配置 国家 / 地区 程序。
此按钮到右边有你用于预览访问地址并在 Google 地图上显示该地址的按钮。

#### 名称
访问地址中使用的公司名称。此强制字段。

#### 地址
邮政信箱地址或街道地址。每个行最多可包含 50 个字符。

#### 邮编
访问地址的邮编。已登记在​ 邮编登记 程序，你可以选择一个邮编。

#### 城市
访问地址的城市。这是自动从 邮编登记 如果 已经 输入 了 该国家 / 地区的邮编则 可以程序.
这 城市 字段可用于以下地址格式：
- 邮编 + 城市
- 城市， 邮编 （两行）
- 城市 + 州 / 地区 + 邮编。

#### 州 / 地区
访问地址所在的州或地区。这是自动从 邮编登记 如果 已经 输入 了 该国家 / 地区的邮编则 可以程序.
字段 州 / 地区 以地址格式可用 城市 + 国家 / 地区 + 邮编。例如在美国使用此地址格式

#### 城市 / 省
访问地址所在的城市或省份。这是自动从 邮编登记 如果 已经 输入 了 该国家 / 地区的邮编则 可以程序.
字段 州/省 以地址格式可用 城市 / 省+邮编。例如在中国就使用这种地址格式。

#### 国家 / 地区
国家 / 地区是强制的，它决定了访问地址将使用的语言和地址格式。语言和地址格式每国家 / 地区已配置 国家 / 地区 程序。如果已选择的国家 / 地区不特定的地址格式，则将应用通用地址格式。国家 / 地区显示在文档上的访问地址的最后行。
