## Report withdrawal of tools
This procedure is part of the Tools & Maintenance option. Here you can manually report withdrawal or return of reusable tools.
The procedure is used for tools not linked to operations on a manufacturing order. Reporting of manual withdrawal and return is instead linked to a person.
Tools which have been withdrawn in this procedure can also be displayed and returned in the Withdrawal list procedure.
For tools linked to operations in the material list on a manufacturing order, the withdrawal and returning is not performed in this procedure. Instead, this will take place when the operation on order is started and reported as finished or by using the procedures Report pick list for withdrawals and Withdrawal list for returns.

#### Tools and Stock accounting
Posting of withdrawal of tools are managed in the stock accounting. These transactions are posted via the transaction type called Direct stock reporting.
Read more about [tools & Maintenance](../../../UserGuide/Using/ToolsMaintenance/ToolsMaintenance.htm) under Using Monitor in the online help function.
