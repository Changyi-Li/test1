### Settings
General

#### Method of calculation
With this setting you determine how the calculation should be performed. Manual input is selected by default. If you select Invoicing log option, you enter on how many months of sales the calculation should be based (the invoicing log is based on invoicing date). Next to this field you see a factor, it makes sure the result always is equivalent to one year (12 months) of sales. If you enter 4 months, the factor is 3. If you enter 24 months, the factor is 0.5. The first month that is loaded is the first complete month back in time. Then the months are loaded in reversed chronological order.
Example:
Today's date is January 31, 2022. If you enter four months, the sales is loaded from September to December for year 2021.

#### Total from all warehouses
This setting is only available if the Invoicing log option is selected in the setting above. With this checkbox you decide if the logs from all warehouses should be included in the total. The saving of data is not affected by this setting, since saving is always made to the warehouse in which you are using the procedure.

#### Year to compare to
With this setting you determine which year should be displayed as Old value in the list. The default option here is the current year.

#### Year to save to
Here you decide which year to save to. The default option here is the current year.

#### Price alternative
With this setting you determine which price via price list that should be saved for the part. In the field below you can select rate type if another currency applies to the price list you selected. Rate types must first be registered and activated in the Currencies procedure.

#### Save to field
Here you decide which field to save to. If the system setting Show annual budget, annual volume, and order quantity with current pace has been activated, you can choose to save the quantity to Annual budget or to Annual budget, current pace. If you choose to save to the last-mentioned, the distribution chart will not be saved. Also, no monthly distribution will be updated. Only quantity, price list, and price will be saved.

#### Budget chart
Here you determine which budget chart that should apply. For the Selected budget chart you can choose among the alternatives which have already been registered in the Budget charts procedure. The selected budget chart determines the distribution in the periods over the year. If you choose the option Selected budget chart, the budget chart of the part will be updated. If you select the option According to the part's budget chart then the Even distribution will be used for all parts for which no budget chart is previously registered.

#### Pre-select "Save"
With this checkbox you decide if the column Save should marked by default in the list. This setting is not checked by default.
Load price from
These settings determine which prices should be shown for purchased parts, manufactured parts, and services. If you select the price list option for any of the settings, the field below it will become available. There it is possible to select which price list to apply. If you have selected a supplier price or a price in another currency, the field where you can select rate type will also become available.
