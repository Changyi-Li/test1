### Settings for export/import
- This procedure is used to configure settings applying to different types of exports to file/web services or similar, and the corresponding for imports. Each type can have unique settings for file name, login information, or what else might be in question for the different cases.
- Exports and imports are based on a plugin model where you in this procedure can select which plugin to use. Each plugin determine which file format it handles and if it should manage files on the hard drive or if it should connect to for example a web session to load or send data. One import type is for example the import of orders in the Register customer order procedure. There you find a standard plugin which handles the Monitor-to-Monitor format for customer orders.
