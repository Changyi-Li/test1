### The Reorder point list for pick locations
In this list you find parts that have a pick location and/or a pick location for work center. Only parts where the current/disposable balance on each pick location falls below the reorder point on the pick location are shown in this list. This is determined by a setting.
In the list, you check the box Apply for the pick locations you want to refill.
In the Suggested quantity field, you see the quantity entered as refill quantity on the pick location. If no quantity has been entered as Refill quantity for the location, the suggested quantity will be the difference between the reorder point and quantity. The same applies if the Refill quantity is less than the requirement. The suggested quantity can be changed, if needed.
You can also enter a Comment regarding the refill.
The reorder point list is created by using the button Generate ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_run.png) on the toolbar.
When the reorder point list for refill is created:
- you cannot order a new refill for the pick location until this refill has been reported.
- an asterisk (*) is shown in front of the pick location's current balance. The asterisk and balance are shown in orange. This can be seen in different procedures where locations are displayed, for example Report material, Part register, and Stock count.
