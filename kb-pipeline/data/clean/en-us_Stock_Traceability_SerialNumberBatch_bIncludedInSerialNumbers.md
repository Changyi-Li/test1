### Included in serial number/batch
If the serial number/batch number you have loaded using the record selector in the procedure, is included in one or multiple other serial numbers/batch numbers, you can here see these "included in serial number/batch numbers".
You cannot modify the data in the fields in this box.
By using the ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_replace.png) button on the function menu you can load the marked serial number/batch number to the record selector of the procedure.
