### Related work center’s priority plan
In this box, you can see the priority plan of the selected related work center. The list is by default sorted by the earliest date for planned start at the top.
The rows are yellow for the operations shown in the pool work center, where you have entered the related work center as a new work center. That way, you can see the priority plan that you are about to create along with the already planned operations.
You can also read more about the information on the rows and the functions in the box in the [Priority plan](../PriorityPlanning/bPriorityPlan.htm) in the online help function for the Priority planning procedure.

#### Include
Here you can select the rows that you want to include by checking the checkboxes. You might wish to load the rows to another procedure via the go to-link or change work center for the operations.

#### Priority of operation
Here you can enter the priority of the operation. This is an alphanumerical field.
