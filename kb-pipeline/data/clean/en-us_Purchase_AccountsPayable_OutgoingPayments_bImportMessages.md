### Import messages
In this box you see import messages from the confirmation file. These messages consist of different warnings that describe what could not be loaded/read from the file from the bank. The tab Warnings from file is only available if any warnings appeared during the import.
The confirmation files might contain records that do not match any record in the ledger. One example is that the invoice is already fully paid in the system. Another example is that the file contains payments that do not refer to invoices in Monitor ERP. If this or something similar occurs, then these records are displayed under the warning tab.
Information about the file is displayed in the box below. This box constructed as the Confirmations box.
