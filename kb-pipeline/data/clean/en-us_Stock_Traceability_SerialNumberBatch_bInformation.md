### Information
In this box you see on which locations the serial number/batch is present. You also see the current balances for those locations. If you have more than one serial number placed on a location, these are shown as total on one row.

#### Best-before date
If you in the Part register procedure have set the traceability to Batch A batch is the set of components/products manufactured at the same time and made from the same original material. or Serial number A serial number is a number that is used for traceability for parts on entity level. for a part, then it is possible to activate the setting called Apply best-before date in the Traceability Traceability in Monitor ERP is all about being able to trace a specific serial number or a batch in each step it is being processed, as of when a part or a material arrives with you from a supplier. Traceability is also about stating what is withdrawn from and what is added to stock, so it is then possible to trace from customer order, via manufacturing order to purchase order. But it is also about being able to trace the other way around; from purchase order via manufacturing order to customer order. box in the part register. If this setting is activated, you must enter a best-before date when you arrival report the part to stock. The date is saved on the serial number/batch and is shown in this procedure. It is also possible to edit the best-before date here.
If best-before date is also applied to material of which the serial number consists, the serial number will get the same best-before date as the material with the earliest best-before date.
If the best-before date has passed, it is shown in red.

#### Batch number
This field is only available for serial number. If the part with the serial number is also linked to a batch number, this is shown here as <batch number> - <part number>. You can select among the batch numbers linked to the part number. You can link batch numbers to part and serial number, for example, when arrival reporting.
If there are multiple serial numbers in the same batch, the button Serial numbers in the same batch becomes activated ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) and using it you can see location, current stock balance, and warehouse, for the other serial numbers in the same batch number.

#### Charge number
Here you can enter a charge number, it is information from the supplier. This can for example be the supplier's batch number.

#### Certificate
You can link a certificates in PDF format to batch/serial number in this procedure or in connection with arrival reporting. All certificates that are linked in the structure under the selected batch/serial number can be printed in connection with delivery reporting. A certificate and a serial number/batch number document together form a compound document based on the Product description including certificate document template. In order for the linked certificate to be included in the document printout when you deliver a serial number/batch number, the setting Automatic printout must be checked when you link the certificate.

#### Configuration
Here you see information about the configuration if the manufacturing order or purchase order which created the serial number, has a configuration.
