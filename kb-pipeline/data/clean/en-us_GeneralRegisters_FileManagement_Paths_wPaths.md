## Paths
In this procedure you can register local paths on the Monitor server, UNC paths to shared directories on the network, and SharePoint Online URL paths. These paths are used in order that users can preview and link new and existing files to different records in Monitor ERP.
The paths can be used with the file link function found under the Files button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_file_link.png) in the procedures. The function can be found in different places in single-record procedures. When using the button, a window appears where you can link files to different records. It is also possible to preview the files in a file viewer.
Users can link files from the paths (and their sub-directories) that you add and set as active in this procedure. We recommend that you only register paths to shared directories on a computer in the network to which other users always have access.
Users can use the drag and drop function to link a new file, for example, via Explorer, in Windows, or via an e-mail program (attachment in e-mail). You than drop the files on the button Files ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_file_link.png) or in the table Linked files in the file link window under the button. Then you must select to which registered path the file should be copied.
> Keep this in mind regarding UNC paths: If you register a UNC path, the Windows account running the server service on the application server (the Monitor server) must have "Full control" to shared directories where files/documents are saved that will be used in Monitor ERP. A user’s Windows account must have read permissions in the UNC path to be able to view and browse files in the Paths procedure. Files that are already linked can be printed and previewed, even if the user’s Windows account does not have permissions in the UNC path. Keep this in mind regarding SharePoint Online URL paths: Only SharePoint Online is supported, not SharePoint On-Premises. In order to register SharePoint Online URL paths, settings for SharePoint must firstly be configured in Azure Portal and in Monitor ERP. See [this guide](https://help.monitor.se/EN/Monitor_G5/PDF/Setup_Sharepoint_Azure_Monitor.pdf) (in English). Keep this in mind regarding different types of files: As standard, you can link all types of files. However, you can only preview PDF files. If users need to preview and print file types such as Word, Excel, CAD files, etc., the Extended file viewer option is required. [Read more here](../../../UserGuide/Options/ExtendedFileViewer.htm) about how the Extended file viewer works, and which file types are supported.
