### 供应供应商设置

#### 供应商登记/供应商列表
电子发票地址 (EIA)
你还可以输入 电子发票地址 (EIA) 为您的供应商。此地址用于在导入供应商发票时查询正确的供应商。当你导入收到的发票时，还可以使用供应商的企业 ID 号或VAT 登记号来识别供应商。
审核人代码
输入一个 审核人代码 (审核人) ,订单供应商自动送至审核.
跨州口号
在里面 跨州口号 字段，该字段与供应商登记一起已导出到 CrossState API，你可以输入数据，以便在解释过程中改善供应商的匹配。例如，如果你已登记了两个相同的供应商，仅的差异是一使用货币欧元，一使用货币瑞典克朗，那么你可以在每个供应商的标语字段中输入欧元和瑞典克朗（订单区分它们）。最多你输入50 个字符。仅当你拥有 CrossState科目时，此字段才可可用。
向供应商发送电子发票邀请，邀请他们开始向你发送电子发票
已链接电子发票 – 在这里你可以看到您的供应商是否已连接到电子发票，这意味着供应商可以向你发送电子发票。如果供应商不连接，你可以向供应商发送邀请。你通过点击以下按钮发送邀请： 发送电子发票邀请![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_more_info.png)。然后会打开一个窗口，你可以在其中看到从 Crediflow 的电子发票登记中加载的有关供应商的信息。为了能够发送邀请，系统需要在电子发票登记中查询您的供应商。因此，为你的供应商输入正确的信息（如企业 ID 号、VAT 登记号和国家 / 地区代码）非常重要。如果可以使用企业 ID 号和国家 / 地区代码的组合进行搜索，则供应商最有可能在登记中被找到。因此，为你的供应商输入正确的企业 ID 号和国家 / 地区代码非常重要。如果一切正常，发送点击 发送邀请 按钮。要检查已已发送邀请的状态，请点击 检查邀请状态 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_more_info.png) 再次。
如果你在电子发票登记中不供应商的Email 地址，添加可以在 通信 下面的框 联系信息 标签页。在里面 接收者的 列，选择 电子发票邀请函。然后会将邀请已发送到该地址。
> 如果供应商是新建的或者细节在 供应商登记 程序，请记住，在发送邀请之前必须第一个登记已上传到 Crediflow。登记日自动已上传一次，但也可以人工的上传 导出 / 导入设置 程序。[你可以在这里阅读更多](SettingsEInvoiceImport.htm)。
供应商角色
如果你有EIM 工作流选项，则适用此规定。为了使系统能够分离订单发票和费用发票，你需要为供应商配置设置。您的供应商的供应商角色控制是否将供应商的发票已导入为订单发票、费用发票或两者的混合。打开 供应商登记 程序或 供应商列表 程序（选择 标准 列表类型和 其它的 格式）。
如何为不同的供应商角色已导入发票：
-   
物料供应商 和 分包商 – 具有这些角色的供应商的发票将被已导入为订单发票。
-   
货代 和 其它的 – 具有这些角色的供应商的发票将被已导入为费用发票。
-   
混合（例如， 物料供应商 和 其它的) – PDF发票将已发送至 CrossState 进行验证。电子发票已导入时，有订单号的为订单发票，无订单号的为费用发票。
> 这应用至通过 CrossState 以及 M2M 和其它类型的 XML发票已导入的发票。
