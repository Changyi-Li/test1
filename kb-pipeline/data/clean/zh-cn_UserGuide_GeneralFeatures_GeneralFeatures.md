### 通用特征
在 Monitor ERP 有许多通用功能可供你在整个系统用于。本章描述了一些重要的通用特征。
程序中的数据校验
在全部单记录程序中以及全部可以已更新的列表和表中，系统都会对某些字段进行校验。然后系统检查数据是否不存在或输入的数据是否错误的。校验可能结果错误消息和警告。
例如，如果客户订单中不存在交货方式，校验将显示错误符号 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/error.png) 字段下一个.如果客户订单行上的交货日期不工作日或不客户建议的交货天数一，然后校验将显示警告符号 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/warning.png) 字段下一个.
如果你光标放在符号上，则会在工具提示中显示其原因。当字段出现错误和错误与警告时，程序窗口的底部也会显示一个校验窗口。
![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/UserGuide/ValidationWindow.png)
校验窗口在顶部显示全部发生的错误，在结束显示所有发生的警告。本文还揭示了其原因。如果不足够的空间来显示完整的原因文本，你可以将光标放在错误或警告上，文本将显示在工具提示中。如果你校验窗口中的错误或警告，光标将放在受影响的字段中。你可以使用按钮最小化校验窗口 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_goto_down.png) 如果你现在不看到该信息，或者校验窗口冻结了程序窗口中的信息。
你不一次更正错误，可以继续输入其它信息。然而，在错误被纠正之前，你不能保存在程序中保存。这是可视的的 保存 工具栏上的按钮为红色并显示感叹号 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_save_error.png)。如果存在警告，则可以保存，因为警告仅通知你输入的值可能不最佳保存值。

带有日历的日期字段内置日期解析器
在具有日历部件的日期字段中，包含一个用于投入日期数的解析器。该解释器根据低于表格将代码转换为日期数。当你离开该字段时，代码将被解释并显示在该字段中。对于选择行中的默认值，这些代码可用于例如获取一周中的天的日期，或获取相对于今天的日期的日期。当使用代码确定日期时，一旦你焦点移动该字段，日期将以斜体显​​示。如果你再次移动焦点移至该字段，则会显示代码以便进行变更。
> 日历部件中的语言（月和星期几的名称）由用户系统中已选择的地区决定。
| 代码 | 解释 |
|---|---|
| 1–7 | 当前周日 |
| 01–31 | 当前月份的日 |
| 吨 | 今天的日期 |
| 匹配行 | 当前月份第一天 |
| n | 当前月份最后日 |
| 是 | 当前年度的第一天 |
| 是 | 当前年度的最后日 |
全部证书代码都可以与数字组合。例如，如果你类型 匹配行-3 结果日期将是当前月份3 个月之前的该月第一天。如果你类型 y+2 结果日期将是当前年度年之后的第一天。如果你不类型+/- 符号，也就是说你仅类型 y2，它将被解释为 y+2。

生成唯一的文件
对于工序、物料以及组件生产评论，你有机会激活 生成唯一的文件 当你链接文件时。然后系统创建并链接已链接原始文件的副本。然后针对组件的每个工单都执行此操作。生成的唯一已链接文件然后获得订单号和文件名称中的流水号。例如，此功能可应用需要伴随工单并由操作员下班的测量记录。你可以使用系统设置输入唯一已链接文件的路径 生成唯一文件的路径。如果你不将份数保存在与BOM 与工艺路线中的原始文件已链接相同的路径下，这将很有用。
如果你激活生成唯一文件，你也可以激活设置 允许打开外部程序。然后，操作员可以在 Windows 中文件类型的标准程序中载入和编辑工单的已链接文件，例如测量记录。

语言管理
语言 Monitor ERP 存在于多个层面。你可以在程序中显示/用于不同的语言。这些可以被已选择并且也可以已配置为用户的默认。然后，显示用户在 Monitor更改在中间不同的语言。在安装中还可以已选择公司语言。这是用于显示数据库被用于的基础数据的语言。最后，你还语言在 语言 程序，并已选择国家 / 地区 国家 / 地区 程序。国家 / 地区可以 为公司中 的 不同地址,客户和供应商而已选择, 并且 确定每个地址默认使用由 的语言.可以已变更特定地址的语言，然后将覆盖该地址的默认语言。
不同语言的数据也可以翻译。这应用至不同类型记录的名称、描述、解释等。翻译用于诸如采购订单、订单确认和发票等外部的文档。在可翻译的数据下一个，你会看到 翻译![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_translate.png) 按钮。你可以在那里添加/输入您自己的翻译。
一个基本原则是，向用户显示的全部数据（例如不同程序中的字段）都应该能够以用户的语言看到。如果数据不翻译，则将以公司语言显示。这意味着用户 英语 随着显示的语言不同，会看到不同的英语条款、组件名称、组件代码、价格列表等。只要这些内容已被翻译，这便适用。
文档中的短语（标题）可以翻译成不同的语言 文档文本 程序。最好将文档中的短语/文本翻译成您的客户和供应商的语言。如果文档短语的翻译不存在，例如，客户订单上的邮寄地址语言，然后文档上的文档短语将主要以英语显示，其次是公司语言。
阅读更多内容 [翻译数据和短语](TranslatingData.htm)。
语言管理 Monitor ERP 例如可以实现以下场景：
一位瑞典语用户登记了一个客户订单，其邮寄地址在英国，交货地址在德语。在客户订单行中，用户可以看到该零件的瑞典语名称。订单确认单上显示英语名称，交货单上显示德语名称。一位在货运部门工作的芬兰语同事打印了一份拣货单，上面显示了零件的芬兰语名称。
在大登记中查找
在大登记（例如组件登记和不同订单登记）中，有一个强大的搜索功能可用于查询和载入登记中的记录。该功能被称为 查找。使用此查找功能，你可以浏览记录、进行模式搜索以及视图最近从登记已载入记录。你还可以在此处创建查找格式。你添加在其中输入你搜索的登记列，和/或你筛选，选择可以搜索的可能性的不同类型的记录。阅读更多内容[在大登记中查找](SearchInRegisters.htm)。
查找程序
在该字段 查找程序 （Alt + D）标题有一个“边输入边查找”功能，你可以使用堆来查询和打开程序。这是在模块菜单中寻找程序的替代方法。
对你类型的文本进行模式搜索。例如，如果你开始输入“ust”，你将点击数名称中包含“ust”的程序，例如 客户登记 和 价格调整， ETC。阅读更多内容[查找程序](ProcedureSearch.htm)。
更新列表
在许多列表中 Monitor ERP 可以通过直接在列表中修改值来更新数据并将保存到相关记录的数据库中。你还可以使用 查询 & 替换 列表中的功能可以更改某一列中的全部值。当你对数据库中的记录进行大量更新时，这非常有用。阅读更多内容[在列表中查询和替换](SearchReplaceInLists.htm)。
剪贴板
这 剪贴板 功能位于标题堆，它是一个表格，可以包含不同的临时数据记录，你可以复制由这些数据记录，以便在其它列表的选择中重新用作剪贴板。这样做的目的是为了能够对某些选择的数据记录进行进一步的数据加工。阅读更多内容[剪贴板](ClipBoard.htm)。
修改日志和打印日志
在全部可以更新不同记录的程序中，当记录被已修改时总是创建时间一个日志登记。字段层级的修改已保存在修改日志中，其中包含更改之后的值先于、已变更记录以及更改用户的信息。
在你打印文档的程序中，打印创建时间总是创建一个日志登记。打印将按打印中时间的状态已保存在打印日志中，同时保存有关打印时间和打印用户的信息。因此，无论打印之后发生了什么已变更，你时间仍然可以看到初始的打印的样子。打印日志还订单重印。
