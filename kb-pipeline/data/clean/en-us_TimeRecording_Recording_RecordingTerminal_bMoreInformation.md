### More information
When you have entered your employee number/card code in the header and pressed Enter or Tab, the terminal opens the recording mode. By using the buttons in the More information box you can see your last recording items, show and change schedule, view planned absence, and see schedule exceptions in calendars. You can also enter comments regarding the recording items. If the Tools & Maintenance option is installed, there is an extra button in this box that you can use to view information about tools relevant to you at the moment.

#### Last recordings
Here you see a log containing your most recent recording items. You can select to show attendance or work and you can also choose to show log records for a selected number of days. This is by default set to seven days. When machine recording it is only possible to show a log of work recording items.

#### Show schedule
By clicking this button you can see your schedule.

#### Change schedule
If such action is allowed you can here change schedule. This is possible to do before you clock in for the first time of the day. It is also possible to create schedule exceptions for weeks to come, for example to make it possible to change schedule next week.

#### Planned absence
To be able to open Planned absence the setting Planned absence via terminal must be activated for your parameter group in the Parameter groups procedure. You can enter/apply for future planned absence. It is not possible to enter planned absence after it has occurred.
Planned absence can be entered and reviewed in a table or via a calendar in a separate tab. In the calendar, absence applied for is shown in italics, and approved absence in bold font. If the absence concerns part of a day, an asterisk * is shown after the selected absence code.
You cannot edit denied absence, but it is possible to delete.
Approved absence cannot be deleted in the recording terminal.
The button shows an icon ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_information.png) when your signer has made changes to your planned absence.

#### Schedule Exceptions
The schedule exceptions are displayed in a calendar view. When one or several days have been selected in the calendar you will see one row per schedule. You can then select which schedule exception should apply for the marked days.

#### Comment
Here it is possible to enter before you record attendance (clocking in/out). The comment is also saved and can be seen afterwards for the rest of the day by clicking this button, but you can also see it under the Adjust attendance tab in the Authorize/Adjust recording procedure.

#### Tool information
This button is available if the Tools & Maintenance option is installed. In the window you open by using this button you can see information about tools that are relevant for you at the moment. The tools displayed to you in the window are:
- Tools withdrawn to operations in progress on which the employee is recording.
- Tools marked with "Work centerA work center is a part of the factory. It can be a single machine or a group of machines, a single workstation or a group of workstations." as location/site for the operations in progress.
- Tools marked with you (the specific employee) as location/site.
In the window you see, for example, the status of the tools and serial number/batch, and if a tool is blocked or has a warning.
On the function menu in the window you can go to the procedures Part register and Serial numberA serial number is a number that is used for traceability for parts on entity level./BatchA batch is the set of components/products manufactured at the same time and made from the same original material.. This is useful if you, for example, want to change the status of a tool.

#### Chat messages
By clicking this button you open the chat function called Monitor chat. There you can send chat messages to other employees in the company. To be able to send chats, the Permission to send chat messages setting must be activated in the Personnel records – Time recording procedure. If you have one or several unread messages, the inbox will open automatically when you have entered your employee number. A notification on the button will also display the number of unread chat messages.
Please note! If an employee number is linked to a user you can choose not to receive notifications in the Recording terminal. Read more about this in the [General](../../../GeneralRegisters/UserPersonnel/Users/bGeneral.htm) section in the online help function for the Users procedure.

#### Additions
To be able to open Additions the setting Handle additions in recording terminal must be activated for your parameter group in the Parameter groups procedure. Here you are able to handle additions such as expenses, mileage allowance, and refund of expenses. Additions must first be registered in the Basic dataWith "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Attendance procedure.
