### The Summary tab
This tab displays a document containing a summary of the values from the total sums under the lists in the other tabs.
The summary shows two calculations for the selected main part: the first column shows the calculation result based on a single one of the main part on the order and in the next column you see the calculation result based on the main part's order quantity. Under the Summary tab, the post-calculation is shown on one hand based on the planned values and on the other hand based on the reported values in the company currency.
- If the selected list type is Total by order, you can in the left part of the window select which order and main part you which to see the summary for. If there is one or several warnings for an order, a button appears on the row. By clicking this button, you go to the Warning list tab.
- If you have selected the list type called Part (mean price calculation), you can in the left section of the window mark for which main part to show the summary. Using a button on each respective row, you can link to the first order of the part i question under the Order summary tab.
The summary displays the following information:
- The Material section with: direct material + stocked + SC mark-up.
- The Subcontract section with: unit price + setup price + unit, stock driven + setup, stock driven + SC mark-up + transport.
- Processing consisting of: unit cost + setup cost + unit price, stock driven + setup, stock driven. The unit cost and setup cost are also shown divided in cost factors.
- Manufacturing cost consisting of: material + subcontracting + processing.
- Sales OH shows the sales overhead mark-up in money. The sales overhead mark-up in percent is displayed in gray.
- Cost price consisting of: manufacturing cost + sales OH mark-up.
- Profit that shows the profit mark-up in money. The profit mark-up in percent is displayed in gray.
- Quote price consisting of: cost price + profit mark-up as a percentage.
For cost price and quote price, you will also see how large a share that is setup cost, and the cost price/quote price excluding the setup price.
At the bottom of the summary, you will see information about:
- Material, Subcontract, and Processing as a percentage of the manufacturing cost.
- The throughput time in number of work days between the start and finish time, for the selected lot size and the finish period. In (including material procurement) the lead time is included in the throughput time for the purchased parts that have the lot sizing rule lot-for-lot and linked requirement.
- Worked hours.
- Result that shows a weighted mean or average value for the cost factors for planned and reported values. The result consists of:
(sales value − ∑ material cost − ∑ subcontracting cost − manufacturing cost of stock driven parts) ∕ worked hours.
- Value added consisting of: (processing total + subcontract total) × sales overhead as a percentage + SO mark-up.
- Profit/result consisting of: result in money ∕ worked hours.
- Comparative price consisting of: setup price + total incl. setup price + contribution margin + contribution margin as a percentage.
