### Settings

#### Only orders confirmed as delayed
With this checkbox you determine if you only wish to show/include orders confirmed as delayed.

#### Date format
Here you decide which date format that will be used.

#### Show time
This setting determines whether or not start and finish time will be shown in the list.
This setting is only available if you have activated the system setting called Enable hourly planning for work center.

#### Pre-select "Include"
This setting determines whether or not the “Include” box should be checked by default for all rows in the list/result.
The selected rows can be loaded to other procedures by using Go to procedure ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png). This setting is only available for the list type Total.
