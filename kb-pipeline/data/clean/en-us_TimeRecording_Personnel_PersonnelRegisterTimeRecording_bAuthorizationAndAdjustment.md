### Authorization and adjustment
Under the Signer tab you find a table where you can add the users who should have the right to authorize the person's attendance recording items and/or adjust work/attendance recording.

#### User
Here you see/select the user who should have the right to authorize and/or adjust. When the Warehouse option is installed you can choose among users from all warehouses.

#### Adjust work
In this column you decide if the user selected for the row should be authorized to adjust the person's work recording.

#### Adjust attendance
In this column you decide if the user selected on the row should be authorized to adjust the person's attendance recording.

#### Authorization
Here you select how the user should be allowed to authorize the person's attendance recording items.
- Cannot authorize – This option means the user is not allowed to authorize if the user has a general permission to authorize attendance via a user-unique user right, user rights group, or role.
- Main signer – This option means that the user is intended to be the main signer.
- Secondary signer – This option means that the user is intended to authorize recording items in cases where no main signer is available (for example when the main signer is on vacation).
