### Desktop configuration
You can create you own desktop configuration containing different interactive desktop components on the desktop in Monitor ERP. You might also have been assigned a default configuration according to a template. There are two options you can use to decide which configuration to use, and also an option to use an empty desktop.
The minimum screen resolution for desktop configurations is 800 x 600 pixels.
Empty
The Empty options means a empty desktop will be shown without any configuration.The desktop then shows a background image depending on which color range/theme you have selected under Settings in backstage.
According to template
The According to template option refers to a configuration with which you can select among templates which are common for the personnel. Normally it is an ERP manager, administrator, or similarly authorized member of the staff who has created one or more templates in the Desktop templates procedure and then made these templates available to you. With these templates you get access to finished desktop configurations. It is not possible for you to make alterations to a desktop configuration you have selected from According to template. If you wish to make changes to the configuration you need to create/build an Own as described below.
In the above mentioned procedure it is possible to create several different configurations and make them available to individual users, groups, or roles.
Own
The Own option is a configuration you can create yourself. If you select Own configuration you can then select among the available [desktop components](DesktopComponents.htm) by dragging and dropping them on the grid which represents the desktop surface. Each component you drag onto the grid becomes a panel which you can move around on the grid. You decide the size of the panel, both width and height. The smallest panel covers only one square of the grid and the biggest covers the entire desktop. The components all have a default setting for width and height. Change the size by dragging a corner of the panel.
Each panel has a button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_settings.png) where you can make settings for the component. Using the x button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_close.png) you delete the component from the configuration. When you have finished your desktop configuration or when you have made changes to it you need to save it by using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_save.png) which you find above the grid.
