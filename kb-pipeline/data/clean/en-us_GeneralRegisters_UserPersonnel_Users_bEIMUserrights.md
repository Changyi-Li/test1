### EIM user rights
If you have installed the option called Electronic invoice management you can click the button EIM and there determine the user's user rights to view PDF invoices in for example lists, tables, accounting reports, and journals.
In the field User right to view you configure the user's user right to view. The available alternatives are view all invoices, view invoices handled (authorized) by the user, and view invoices according to user rights group. If you select the alternative "According to user rights group", the field User rights group view will be activated in which you must select a user rights group. User rights groups for viewing of invoices must first be registered in the procedure Authorization settings – EIM. Regardless of the selected user rights group, the user can always view invoices that he/she has handled in the flow.
