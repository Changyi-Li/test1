## File manager
The File manager is a procedure in Monitor ERP which makes it possible to handle files and folders is a way similar to the Windows Explorer.
This procedure is available to customers who use Monitor Cloud. Only users with the user right called File manager marked in the Users procedure have access to the function. Additionally, the user only has access to the paths where such permission has been assigned in the Paths procedure.
In the File manager procedure you can:
- Show files and folders
- Upload and download files
- Copy, move, and delete files and folders
The File manager can be used for both SharePoint Online and local server areas, which provides a uniform and efficient file handling, regardless if you run Monitor locally or in the cloud.
