## Part template
In this procedure you add and handle your part templates. A template can be used to create parts that should have the same default values in some fields found in the Part register procedure. The default template is Part which concerns regular parts which you buy, manufacture, and sell.
Part templates can be created for different basic types of parts and for tools. There are three different basic types for tools. These are Consumable, Reusable, and Tool list. A tool lists is a tool which consists of a structure with several incorporated/included tools.
Using the procedure Synchronize part template you can update all parts which are linked to a part template with values from the part template in question making it the same as in the part template.
