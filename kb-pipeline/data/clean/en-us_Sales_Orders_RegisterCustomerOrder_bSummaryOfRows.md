### Summary of rows
At the bottom of the Rows tab you will see a total of the order’s remaining value excluding VAT, the total excl. VAT and the order’s total incl. VAT. All totals are shown in the order currency and in the company currency.
To the right of the Total excl. VAT field, there are two editable fields. In the left, you can enter a total, i.e. a separate Order value. You can use this to e.g. round an order's total in the order’s currency. Based on the order value, an order discount is calculated which is applied to on all order rows as an Order discount (code 2). Instead of entering your own order value, you can enter an Order discount in % in the top editable field. This order discount is entered on all order rows on the order as Order discount (code 2). An equivalent order value is calculated and entered in the editable field on the left.
Depending on whether you’ve entered an order value or an order discount, the functionality differs. If you have entered an order discount and additional order rows have been added to the order, this order discount is automatically applied to the order rows. If you have entered an order value and add new order rows or remove rows, or if you make changes that affect the order’s total on the existing order rows, you must approve the order value or enter a new order value.
Using the Clear button, you empty the Order value and Order discount fields. The order discount is also removed from all order rows.
> The order discount is calculated based on the order’s total amount excluding setup costs. This is because the discount doesn’t affect the setup price on the order row.
> If total row (row type 3) appears on the order, the order discount fields are grayed out. Total row and order discount cannot be used on the same order.
You can also see a total of the standard price for all rows. This is calculated as standard price multiplied by quantity per row, and then the rows will be added together. A total of the order's total net weight and volume are shown. You can also see the rows’ total CM The contribution margin (CM) is the difference between the standard price and the sales price. and CR The contribution ratio (CR) is the portion of the invoice amount (sales price) that the contribution margin represents. CR is entered as a percentage..
The More totals button
- Total of setup price – Displays the total amount of all setup prices registered on the order rows. You cannot enter an order value lower than the total of the order’s setup prices. In such cases, the setup prices should be lowered.
- Total for selected rows excl. setup price – Displays the total amount of all the selected rows, with the setup price deducted. This is the total that the discount is calculated with.
- Total – The total is calculated as follows: Total setup prices + Total, excl. setup prices. Each total is shown excl. VAT in both the order currency and in the company currency. In these totals, no order discount has been applied.
- Last entered order value – Shows the current order value. If this total is bold, this is the order value that has been entered for the order. Otherwise, it is calculated based on the entered order discount.
- Last entered Discount – Shows the current order discount. If this value is bold, this is the discount that has been entered for the order. Otherwise, it is calculated based on the entered order value.
The More totals window is a floating window which means that you can click on the drawing pin in the upper right hand corner so the window remains open while the procedure is open.
The Approve order value button
If you have entered your own order value and make a change (add or remove an order row, change price, change setup price, change discount, or change quantity) that affects the total value, a warning will be displayed advising you that the order value has changed. Is the entered order value, despite having been changed, still correct? By clicking the Approve order value button, you approve the previously entered order value. Otherwise, you enter a new order value.
The transport time is also shown at the bottom of the tab. It refers to the transport time to the selected delivery address, primarily on the order and secondarily on the delivery address entered on the customer. This time can also be changed on the order. The customer's delivery days are also displayed. Read more about transport time and delivery days in the topic [Delivery/Shipping](../../../../G5_Sales_SV/Content/Topics/Sales/Customers/CustomerRegister/bDeliveryShipping.htm) in the online help function for the Customer register procedure.
The button Shipping information ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) shows package information about quantity, goods type, package type, weight, volume, loading meters, length, width, height, and the packaging part used. The total quantity, weight, volume, and loading meters are also displayed. This information can be updated.
