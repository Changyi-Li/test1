### Export/Import
- The procedure has been renamed and was previously called Import / Export SIE. This has been done to reflect that the procedure is a more general export and import procedure, not only handling SIE files.
- Support for export of both SIE 4I and SIE 4E.
- More settings for import of SIE files, for example:
- Possible to select which voucher number series and dimensions to import.
- Warnings/blocks if SIE file contains double vouchers, vouchers in locked periods, etc.
- When importing SIE file which contains an error on a row, you will see which row in the file that is preventing the file from being imported.
- When importing SIE file which contains a format error, a message is now displayed with information about which row in the SIE file that contains the error.
