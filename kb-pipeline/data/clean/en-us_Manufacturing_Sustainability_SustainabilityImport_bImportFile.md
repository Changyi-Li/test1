### Import file

#### File
By using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/G5_Stock_SV/Content/Resources/Images/button_browse.png) you can enter a path to the file. You will then see the file path in the field.

#### Format template
Here you can select a format among the formats created in the backstage of the procedure. If you have made any temporary settings for the format, which have not been saved as a separate template, this will be shown as Current settings (not saved template).
