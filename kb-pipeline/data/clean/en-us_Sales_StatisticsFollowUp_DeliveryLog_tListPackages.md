### The Packages list
The list is loaded and displayed based on the selection and settings you have chosen. As in all lists in Monitor ERP, you can drag and drop in order to change the column to group by.
In this list type you can select package numbers and the list shows packages (package numbers) and the package’s payload related to the delivery. This list type only shows deliveries where a pick list has been used and where there is a package structure. By default, the list is grouped by pick list and delivery note number.
