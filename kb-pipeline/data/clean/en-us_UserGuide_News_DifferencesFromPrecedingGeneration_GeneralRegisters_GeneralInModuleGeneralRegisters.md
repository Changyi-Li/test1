### General in the General registers module
- The module has change name from Global settings to General registers.
- Such registers which are not general have been moved to other modules, for example Part codes and Units which have been moved to the procedure Basic dataWith "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Part in the Stock module.
- It is possible to define an Own paper size or use a Standard for the printer when printing via server printer.
