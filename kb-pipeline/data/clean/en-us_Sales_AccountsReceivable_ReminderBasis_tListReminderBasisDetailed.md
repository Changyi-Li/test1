### The Detailed list
This list type displays detailed bases for sending payment reminders to customers. The overdue invoices that have exceeded their grace period can be loaded here. By default, all invoices are marked for payment reminder. You can also – per invoice – update the number of payment reminders that have been printed, and choose to send invoice an agency for collection.

#### Number of payment reminders
Here you see how many payment reminders have been sent to the customer for the invoice in question. If it says 0 (zero), it means that no payment reminder has been sent to the customer. For each reminder you send, the value in this column will increase. You can manually change the number in this column, e.g. if you have reached the maximum number of payment reminders and still wish to send a reminder. In that case, you have to count back one step. Or if the opposite scenario arises, and you have only sent one reminder but still wish to send the invoice for collection, then you can change the number here. You then need to increase the number so it reaches the limit for Number of payment reminders to apply (a system setting) in order to add the invoice to the collection list.

#### Last reminder date
In this column you can see the date when the most recent reminder for the invoice in question was printed. The column is empty if no reminder has been sent.

#### Payment reminder
With this checkbox you decide if payment reminder will be applied for the invoice in question.

#### Accrued interest
This column shows the accrued interest for the remaining amount (in the company currency) that has accumulated after the due date. That is, the penalty interest that corresponds to the delay. It is the amount of money in interest that the customer would have to pay, as of today, in addition to the remaining amount. The accrued interest will be zero if the invoice is marked with Credit.

#### Comment
Here you can see comments for the accounts receivable record.

#### Collection
This checkbox determines if the invoice will be sent to an agency for collection. For such invoices, reminders are no longer sent. When you select Collection, today's date will be used as collection date, but this can be changed in the Collection list.
