### Activity
If you report an income it is only the field Time to report which is available.

#### Activity
Here you can select an activity among the activities linked to the project in question. The sorting of the options is according to the order of the activity list for the project. An activity or a cost type must be selected here. The activity you enter can suggest a cost type if you have entered an activity with such linked in the Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Project procedure.

#### Quantity
Here you enter the quantity you would like to report. It is not mandatory to report quantity for an activity. It is also possible to enter quantity even though you have not selected an activity. The time you enter can suggest an amount based on the hourly cost in the box Cost/Income. The hourly cost is entered for the cost type in the Basic data – Project procedure.

#### Status
In you have entered an activity you will here see the status of it. It is possible to change. You can for example set it to Finished if you know that it is the last reporting you perform on the activity in question.

#### Performed by
If you change the status of an activity to Finished, the logged-in user will become the person entered in this field. However, it is possible to select another user from the user register.

#### Planned time
In this field you see the planned total time for the activity in question.

#### Reported time
In this field you see the reported total time so far, for the activity in question (excluding the time which is being reported in this session).

#### Last reporting date
Here you see the most recent reporting date for the activity in question, that is, the latest date already registered for the performed activity reporting items. By clicking the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you can view all registrations previously made for the activity.

#### Activity comment
Here you can see a comment for the activity, if any, and also linked files.
