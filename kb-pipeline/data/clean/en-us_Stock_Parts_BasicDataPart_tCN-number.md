### CN code
Under this tab you enter CN codes, using eight digits, for parts that will be purchased or sold within the EU. These codes are used on Intrastat Intrastat is the system which gathers statistics relating to trade in products within the European Union. Gathering of Intrastat statistics is handled in the same way by all EU member states. reports for export and import to and from EU countries. CN codes are only used within the EU.

#### CN code
If you change an existing CN code, the change will affect all parts for which the code is registered. If you delete the code, it will be deleted from all affected parts.

#### Show
In this column you enter how the CN code should be shown in the report:
- Weight (default) – With this option only net weight will appear in the report.
- Other quantity – This option will only show quantity (other than weight) in the report. Unit for quantity must be selected in the Unit field.
- Weight and other quantity – With this option both weight and quantity (number of pieces) will appear in the report.
- Exclude the code from accounting – A part with this option will not be included in the Intrastat report.

#### Unit
Here you choose unit for CN codes that have to be reported with another quantity in the Intrastat report. If no unit is entered, this CN code is blocked in the Intrastat report.

#### Demander/Authority
Here you decide if the CN code should be included in different sustainability reports or other reports relating to environmental standards. The Demander/Authority available in the dropdown menu must first have been registered in the Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Sustainability procedure.
