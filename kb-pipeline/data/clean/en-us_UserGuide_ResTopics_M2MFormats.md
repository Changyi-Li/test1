### Formats for Monitor-to-Monitor
Here you’ll find descriptions of the M2M formats available in Monitor ERP. For each format there is:
- A PDF file that describes the format’s data structure and content.
- One or more example files.
- An XML schema.
> Please note that all information is in English.
