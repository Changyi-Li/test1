### Link employee to reference and seller
In G5 you configure if the employee should be possible to use as reference and/or seller. This means that you must link employee to reference, and employee to seller in G4 ahead of the transition to G5. Otherwise multiple employees with the same name will be created in G5. This can be done in good time before the conversion.

#### Link employee to reference in G4
Go to Global Settings | Company Info | References.
By entering the reference's employee number in the Emp. no. field in this procedure, you let the system know to which employee number the reference should be linked.
![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/LinkEmployee.png)

#### Link employee to seller in G4
Go to Sales | Services / Sellers | Update Seller.
By entering the seller's employee number in the Emp. No. field in this procedure, you let the system know to which employee number the seller should be linked.
![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/LinkEmployee1.png)
