## Report traceable material
In this procedure you can report withdrawal of traceable material. The difference between this procedure and the Report material procedure is that here the reporting focuses on batch/serial number. Multiple batches/serial numbers can be reported on a material's report number.
You load a report number to report material from the report. You can either manually enter the report number or you can scan it using a bar code scanner. In this procedure it is only possible to load report numbers in which there is traceable material.
In the Material box you can add and delete material rows for reporting.
