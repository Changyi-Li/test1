### Selection

#### Voucher date
In these fields you can select which transactions should be imported based on the voucher date. The first field is the start date and the second field is the end date. If these fields are left empty it means all transactions from the entire accounting year you are in, will be exported. This does not apply to SIE 1.

#### Voucher series
In these fields you can select if vouchers for a specific voucher series should be exported. In the first field you select from which series and in the second field select to which series. The interval you enter here will be exported. This does not apply to SIE 1-3.

#### Voucher number
In these fields you can select which voucher numbers that should be exported. In the first field you select from which number and in the second field you select to which number. The interval you enter here will be exported. This does not apply to SIE 1-3.
