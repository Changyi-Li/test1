### Grouping/Posting
If you add one or multiple alternative delivery addresses for the customer, then you can for example select customer group and VAT group – per delivery address. On a new customer orders order, these settings will then be determined by the selected delivery address on the order.

#### Customer category
Here you can enter a customer category. By clicking the Category selection button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png), you can select a category if categories have been registered in the Categories procedure. If no categories are registered, you can type as you please in this field. Categories can be used as a selection term in different lists. Read more about how categories can be created/constructed in the online help function for the [Categories](../../../GeneralRegisters/Categories/Categories/wCategories.htm) procedure.

#### Customer group
Here you select the suitable customer group for the customer in question. You register Customer groups in the Posting matrix procedure. The customer group determines which sales accounts that will be suggested for quotes, customer orders, and invoices to the customer in question. The sales accounts are determined by order type and the combination of customer groups and product groups on parts.

#### VAT group
Here you select a VAT group for the customer. VAT groups must first be registered in the VAT settings procedure. The VAT group determines the default VAT code used on quote rows and customer order rows.

#### Priority
Here you can select a priority for the customer, from 1 to 9. The default priority for a new customer is 9. When the priority is set on an new order, the priority entered here (on the customer) will be combined with the priority of the order type. The highest priority (lowest number) of either the order type's priority or the customer's priority, is then the priority that will be set for the order.
