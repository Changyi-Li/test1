### Miscellaneous

#### Order/invoice rows
In connection with order registration, you can see in the rows how the part will be recorded in the IntrastatIntrastat is the system which gathers statistics relating to trade in products within the European Union. Gathering of Intrastat statistics is handled in the same way by all EU member states. report. The CN code, Weight, and Transaction type columns are shown under Mer info. The CN code is loaded from the Part register procedure. It is possible to override the part’s setting by changing this data uniquely for this row. Row type 2 must be chosen manually in order to be recorded in the Intrastat report.

#### Three-party trading
If the company is an intermediary in three-party trading, an exemption from Intrastat reporting is required, since the goods do not cross the country’s border. This is automatically handled by the system by excluding order rows that contain a VAT code referring to three-party trading. You can read more about this in the [VAT settings](../../../GeneralRegisters/FinanceAccounting/VATSettings/wVATSettings.htm) procedure.
