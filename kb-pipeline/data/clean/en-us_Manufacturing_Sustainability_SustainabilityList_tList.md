### Sustainability list – Standard
In the sustainability list you can select different parts and see or update emissions and material types for many parts at the same time. This can be very useful, for example, when you start using the sustainability functionality in Monitor ERP.

#### New emission value
This is a calculated field. That is, the value shown here is created by the part’s net weight being multiplied by the emission factor from its material type in the Basic dataWith "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Sustainability procedure.

#### Synchronize
With this check box you can determine which parts should be updated/synchronized with the new emission values.

#### Annual volume
This is loaded from the Part register.

#### Calculated emissions
In this column you see the CO2e emission x the Annual volume. This column can also be used to identify the parts that have the highest annual emissions. That is, the parts that can give the greatest effect to work on in the company’s sustainability work.
> Please note! The annual volume is shown per warehouse.
