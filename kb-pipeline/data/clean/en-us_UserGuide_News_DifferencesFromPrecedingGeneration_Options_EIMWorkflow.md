### EIM Workflow
EIM Workflow is an option available for G5, in the same way as it is a supplement in G4 (there called Extended EIM).
- EFH Workflow is fully integrated in the procedures Register supplier invoice and Authorize supplier invoice.
- No extra work is needed regarding configuration of user rights. These are included in the user rights structure in the user register.
- The entire function concerning exception handling has been reworked.
- A register containing settings for general exceptions in EIM Workflow is always activated. On supplier there is also a register with settings for exceptions per supplier. Here you can create own variations of exceptions or deactivate general exceptions. In G4 there is only one exception register. This must be linked per supplier to take effect on the supplier.
- It is possible to use an exception account for a supplier group when an account has been entered for an exception.
- If you link a part to an exception, the posting will then take place according to the posting matrix for that part (product group and supplier group).
- It is possible to configure a unique amount limit per currency for each exception. You configure general amount limits in the procedure EIM Workflow settings. These can be overridden per supplier in the Supplier register procedure.
- An empty (blank) field for price differences and amount limits in the settings means the EIM Workflow will not take this field into consideration. However, if you enter zero (0,00), it means no difference or amount limit will be accepted. In G4, zero in this filed meant that the field would not be taken into consideration.
- Invoices will automatically be final recorded if everything is matched with the purchase order during the import. But you can enter an exception per supplier, that automatic final recording should not be performed. In G4 you have to manually activate if invoices should automatically be final coded.
- When linking an invoice to a purchase order, the linked delivery row's amount and posting will be the basis of the posting. In G4 it is the posting from the delivery row and the amount from the invoice row which is used as basis for the posting.
- In the procedure Invoice overview – EIM there are lists for with logs and monitoring of imported invoices and the running of the service in EIM Workflow.
- When importing comprehensive invoices which are linked to more than one purchase order, an authorization list is automatically created based on the references of the order in question. This requires that the references' users have also been registered as signers in the authorization settings for EIM. Also, they have to have been entered as references and must be linked to a user in the personnel records.
- It is possible to modify imported invoice rows if something went wrong during the interpretation. In G4 you have to re-interpret the invoice which means an additional cost.
- In G5 you will get notifications directly in the user interface when there is an invoice for you to handle (you can choose for which statuses you want to receive notifications).
- When exporting the supplier register, the field for CrossState Slogan is added for the supplier, which can be used to get a better match on suppliers when interpreting supplier invoices. For example, if you have two identical suppliers registered, where the only difference is that one has the currency EUR, and one has the currency SEK, you can enter EUR and SEK in the field for Slogan for each supplier (in order to separate them). You can enter a maximum of 50 characters.
