### The Order oriented M-parts tab
Here you will find detailed information about order oriented manufactured parts that are included in the selected main part.
By clicking a button on each row, you can link to the part in question under the Level list tab and see where it is located in the structure.

#### Show values per unit
At the bottom of the window there is the setting called Show values per unit. It determines if values will be shown per unit or for the part’s calculated quantity.
