### Information boxes
In this procedure there are six boxes. Using the button Floating ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_float_window.png) (Ctrl + U), you can unpin a box and thereby make it a separate window. It is possible to change size of the window and move it around on your computer monitors.
Activities
You can here update the person responsible for the activity, enter a comment, change the planned date, and the status of the activity. The default setting is to only display activities which are not finished. By using the Include finished activities button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_goto_critical_op.png) you can choose to also show all activities which have already been completed.
Customers
Here you see the seller’s customers, that is, the customers for which the seller is selected under the CRM tab in the Customer register. The customers are sorted by customer number. The last contact date refers to the actual date for the most recently performed CRM activity. The quote backlog is the number of quotes with status 1 and 2. The order backlog is the number of orders with a remaining quantity.
Quotes
All quotes with status 1, 2, and 7 for the entered seller, are shown. This box can be used, for example, to see which quotes, for the selected seller, that have valid through dates that are about to expire. Under the More info button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you find more information about the quotes.
The quote value is displayed in the company currency. The quotes are sorted by the valid through date.
Customer order
All customer orders with status 1–5 with the entered seller, are shown. The order value (for remaining quantity) is shown in the company currency. The orders are sorted by order number.
Invoices
You will see invoices that have been invoiced during the last 3 months. The invoices are sorted by invoice number. The amount (the invoice amount) and the contribution margin are shown in the company currency.
Statistics
Here you see different types of statistics regarding the seller, both in lists and in chart form. You can select a historical limit (except for budget and result). This is set as a number of months. You can select to show:
- The seller's budget and result of the seller's sales for the current year.
- Number of finished activities per week, presented in a list or a chart.
- Quote statistics for the selected seller's quotes.
- Order backlog for the selected seller's orders. The amount is shown over time in the chart.
- Sales statistics for the selected seller's invoices. The amount is shown over time in the chart.
