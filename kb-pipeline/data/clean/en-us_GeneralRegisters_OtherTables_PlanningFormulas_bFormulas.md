### Formulas
Here you can see existing planning formulas and create new formulas. You can copy or add rows for new formulas in each type in the table. The formulas are used in the following different calculation prodcedures: Calculate stock levels, Calculate order quantity, Stock refill – Purchase, and Stock refill – Manufacturing. If you are using the Advanced stock management option there are also formulas for putaway strategies. Such putaway strategies are created in the Location selection procedrue.

#### Type
Under Type you select if they are planning formulas for calculating Order quantity, Safety stock, or different formulas for Stock refill – Purchase and Stock refill – Manufacturing, or Reorder point. At least one standard formula is included for each type.

#### Default
You can set a formula for the selected type as Default in the calculation procedure.

#### Code
Here you enter a code for the formula using a maximum of 20 characters.

#### Name
Here you enter the name of the formula. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Active
The setting called Active determines if the formula is active and if it thereby can be selected in the calculation procedure. Several formulas can be set as active.

#### Changelog
By using the Changelog button, you see any changes made in the formula. You also see by whom and when the changes were made.
Formula editor
In the lower portion you find a formula editor where you create or edit a formula. This is done by first copying a row of a standard formula or by adding a row for a new formula. Before you can save a new formula, you must enter something in the formula editor, for example a variable. In the right section called Variables you find all available variables in the system. There you also find a table with manual variables, if any. It is the variable's Code that is used in a formula.
The formulas included in the system can guide you on how to create own formulas.
IntelliSense in the formula editor
In the formula editor there is something called "IntelliSense". This helps you write formulas quickly and it also prevents you from writing incorrect variable codes. It gives you suggestions of variables and functions as you are typing in the formula editor.
[Read more about IntelliSense](../../../UserGuide/Using/Configurator/Formulas.htm#IntelliSense) and all functions, in the online help function regarding formlas for the Product configurator option.
Please note! In the planning formulas’ formula editor, the variables are written using capital letters. In the product configurator's formula editor, the variables are written within square brackets [] and are case sensitive.
