### Other part identities

#### Use other part identity
If the corresponding setting has been activated under the Sales company tab, you should also activate it here under the Production company tab. You then enter the same code for other part identity in the field below.

#### Code for other part identity
If you have activated the setting above, here you enter the code for other part identity you want to use on parts in the production company. This code must be available in the table with other part identities in the Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Part procedure in the production company.
In the part register in the production company, you can add the code for other part identity on parts. In the Identity field, you enter the sales company's part number.
You can also add the code for other part identity on parts in the part register in the sales company. As identity for the code you enter to production company's part number for the same part.
