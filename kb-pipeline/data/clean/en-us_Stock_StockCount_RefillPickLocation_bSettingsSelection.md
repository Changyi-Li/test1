### Settings – Selection
Show

#### Include
- Only parts below reorder point – (activated by default) this setting only includes parts whose current balance on pick location falls below the entered reorder point for the pick location. This setting only applies to the reorder point list.
- Buffer locations with "Exclude balance" – this setting also includes locations for which the setting Exclude balance has been activated.

#### Pick locations
This setting determines which locations should be shown in the reorder point list. The available alternatives are Pick location and/or Pick location for work center.

#### Include reservations
This setting determines if reservations should be included in the reorder point list or not. If you want to include reservations, the following alternatives are available Yes, only orders or Yes, both orders and suggestions.

#### Daily pace
If the system setting Show annual budget, annual volume, and order quantity with current pace has been activated, you can choose one of the following alternatives Daily pace Daily pace is the consumption per day of a specific part. or Daily pace, current pace. If the system setting has not been activated, only Daily pace is available.
The system setting affects the display of the reorder point list regarding how many work days the current balance in the pick location will suffice, considering consumption at daily pace or daily pace, current pace. If reorder point is entered for the pick location, this will also be considered. The basis of this is the calculated and saved annual volume for the part in the Calculate annual volume procedure.

#### To date
If you have chosen to include reservations, you can select up to which date you want to include them.

#### Suggest "Apply" for all suggestions
With this setting you determine whether or not the checkbox Apply should be marked by default for all parts in the reorder point list.

-
