### Default setting

#### Allow multiple part numbers
Here you configure if multiple part numbers or only one part number should be allowed per location name. This is configured as a default setting for each location name. This setting can be changed per location name, if needed, under the Result tab before the location name is saved.
If you activate this setting, multiple part numbers are allowed per location name.

#### Default location template
Here you can select a location template which will be used by default. The location templates are loaded from the Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Advanced stock management procedure. The location templates make it easier to decide the size of the locations, as well as decide on a maximum weight for the locations.
