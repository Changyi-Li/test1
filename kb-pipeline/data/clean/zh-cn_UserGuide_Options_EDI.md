# 电子数据交换
我们的 EDI 解决方案意味着你可以在中间以结构化消息的形式传输业务文档： Monitor ERP 以及您的客户/供应商的 ERP系统。全部的通信都会更多地自动进行。

#### EDI通信
在中间的EDI通信 Monitor ERP 并且您的客户 / 供应商将通过 EDI 桥在互联网上进行联系。

#### EDI消息
Monitor ERP 使用内部的格式的 EDI消息，这意味着这些消息必须转换为所需的标准，例如EDIFACT。消息转换通过外部的EDI软件或 VAN服务执行。消息将在此转换为客户/供应商要求的标准/从客户 / 供应商要求的标准转换。
Monitor ERP 支持以下业务事务：

#### 销售流程
- 导入客户订单
- 导入交货日程表
- 导出订单确认
- 导出客户发票
- 简化发货通知的
- 导出复杂的发货通知
- 导出客户订单响应
- 客户订单交货报告

#### 采购流程
- 导出采购订单
- 导出交货日程表
- 导入订单确认
- 导入简化发货通知
