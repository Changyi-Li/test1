### Print transaction list
- In the procedure Outgoing payments you can choose if this procedure should be used or not. That is, it is possible to create a payment file directly without using this procedure.
- The transaction list is now a document which can be redesigned using the new document concept in G5.
- The transaction list for LB displays separate sections for Giro payments, Account deposit, and Cash payments.
- It is now possible to reprint transaction lists.
