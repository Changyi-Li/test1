### Origin
Purchase and Manufacturing
In this box you see, for example, information about from which purchase order or manufacturing order the serial number is from. If not, you can select a purchase order or a manufacturing order to which to link the serial number/batch number.
If you enter a manufacturing order for a batch which is linked to a serial number, or the opposite, the manufacturing order for the linked entity is also filled in.
If a purchase order is selected you see information about the supplier and references as well as the country of origin. In this field you see the country which was entered on the suppliers delivery address at the time when the arrival was reported.
Project
The project, if any, is loaded and saved in the Project field for the serial number/batch number which was created at arrival from the purchase order row or a direct stock reporting. If a serial number is created from a customer order row or a manufacturing order, where a project is entered, the project number will also be shown in the field.
