## Location selection
In this procedure you create location selections and putaway strategies that can be applied to parts.

#### Location selection
Location selection means that when a part is arrival reported, only the location names that are included in the part's location selection will be available.
A location selection is created by a selection criteria. This is a selection of location names that works in the same way as a selection made for a list. That is, you can add several rows with different intervals of location names, select if an intervals of location names should be excluded, use wildcard characters.
You can apply location selection for individual parts with the use of the Location selection field in the Location settings section under the Stock tab in the Part register procedure. You can also update the location selection for multiple parts at the same time by using the Location selection – Part list type in the Location list procedure.

#### Putaway strategy
A putaway strategy means a set of rules/priority order for how the system should suggest a location when arrival reporting a part to stock or when moving a stock balance. Putaway strategies are used in the Stock location system option.
Read more about [Advanced stock management](../../../UserGuide/Using/StockLocationSystem/StockLocationSystem.htm) under Using Monitor in the online help function.
