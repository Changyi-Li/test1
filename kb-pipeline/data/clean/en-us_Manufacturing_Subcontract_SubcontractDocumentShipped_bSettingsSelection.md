### Settings – Selection
View

#### Suggested quantity
The quantity that is selected by default to be reported as shipped and is printed on the documents. The following options are available:
- None – No quantity is suggested.
- Left to ship – The quantity that is left to ship will be suggested. This quantity is calculated as: remaining quantity minus already shipped quantity of the operation.
- Remaining quantity – The remaining quantity is suggested.
- Available to ship – The quantity that is available to send will be suggested. This quantity is calculated as: reported quantity on previous operation minus quantity at supplier minus quantity at receiving inspection minus quantity reported on the operation.

#### Already printed operations
With this setting you decide if operations which have already been printed (and approved) should be shown in the list.

#### Only operations to ship
Using this checkbox you can determine if the operations will be included in the list, taking the reported quantity in the previous operation into consideration. You can activate this setting in order to print/report the goods that are physically available and ready for shipment to subcontractors. Quantity to ship is calculated as: reported quantity in previous operation minus shipped quantity, subcontract.

#### Only operations with remaining to ship
With this setting you determine that only operations with remaining quantity to ship will be included in the list.
If you have made excess reporting of previous operations and have made partial shipments which exceeds the planned quantity, it means that these rows will not be shown in the list when this setting is activated. You then have to uncheck this setting in order for the rows to be included in the list.

#### Only material ready
This setting determines that only operations that are cleared, taking the material into consideration, or do not have any material linked to them, will be included in the list.

#### Pre-select "Include"
This setting determines whether or not the “Include” box should be checked by default for all rows in the list/result.
Operations selected in the list will be reported as shipped and will be included in the documents.

#### Default replan entire order
Here you decide if the replanning of entire order should be the default handling when the planned date of a subcontract is changed.
Printout

#### Document
Here you determine which documents that you want to be able to print under the Documents tab. The available options are: purchase order, delivery note, and transport label. You can also uncheck all the documents if you only wish to report shipped quantity.

#### Printout date
The printout date in this field will by default be today's date, but it can be changed. If you change it, the printout date on the document will also be changed. However, the date and time registered in the printout log will be the actual time for the printout, regardless of the entered printout date.

#### Our reference
In this field you select the employee number of the person whose name will be displayed under Our reference on the documents.

#### Report shipped
Check this box if you want the Quantity for the operations in the result list to be reported as shipped when you save. Rows with 0 as remaining quantity to be shipped cannot be printed if this setting is activated. If you have not activate this setting it is possible to include rows with 0 as remaining quantity, to be printed for all documents.

#### Shipped by
Here you select the employee who reports the shipment. This field is active if the setting Report shipped above is selected.
