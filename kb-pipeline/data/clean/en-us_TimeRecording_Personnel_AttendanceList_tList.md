### List
Under this tab there is a list showing the recording status for all personnel in the personnel records.
For each person/individual, you can see date and time for the most recent recording, recording comments, absence codes, and the person's schedule.
If site recording is activated (via the system setting called Activate site recording), you can also see on which site the clocked in persons are, and also the site of the persons clocked out on break. This is necessary information which is also displayed in the evacuation list (see below).

#### Filter
In the Filter section you can filter the personnel based on their recording status. The number of persons affected by each filter is shown within parenthesis after the recording status.

#### The Evacuation list button
At the top right corner of the list tab you find the button Evacuation list. This button will open the Evacuation list procedure. This list contains everyone who at the moment are clocked in, or clocked out on break. The list is grouped by department. The evacuation list should be printed and used to tick off all personnel present in the case of an evacuation.
