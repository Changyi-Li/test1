## EC销售列表
在此程序中，你载入欧盟统计报告的基础。
可以在系统外人工的报告此情况。对于某些国家 / 地区，系统支持通过文件以电子方式提交报告。此报告可以每月或每季度进行。使用哪个时间期间取决于已打印报告时选择的日期。
基本
EC销售列表涉及与欧盟国家 / 地区的全部贸易，应每VAT 登记号（买方的）进行核算。每VAT 登记号你可以看到以下信息：
- 货物交货货值
- 三方交易值
- 服务价值
货物交货报告的前提条件：
- 购买者 (发票接收者的) 已在另一个欧盟国家 / 地区已登记VAT。
- 货物被已交货到另一个欧盟国家 / 地区（买方所在国家 / 地区或另一个欧盟国家 / 地区）。
报告三方交易的前提条件：
- 购买者 (发票接收者的) 已在另一个欧盟国家 / 地区已登记VAT。
- 货物不是从自己的公司未交货，而是由另一个欧盟国家 / 地区的销售员直接已交货给买家。也就是说，必须有三个欧盟国家 / 地区参与。
报告服务的先决条件：
- 购买者 (发票接收者的) 已在另一个欧盟国家 / 地区已登记VAT。
- 该服务必须在买方的国家 / 地区/地区执行/实施。
EC销售列表的运作方式 Monitor ERP
EC销售列表数据从 会计模块 和 销售模块 编写本报告。系统读取全部涉及向客户销售的凭证，其中客户的VAT 登记号属于欧盟国家 / 地区。
要获得正确的报告，需要满足以下先决条件：
- 客户发票的集成必须每发票详细，即选项 直接每发票 或者 通过日记账每发票 必须在程序中已选择集成设置 凭证号序列 / 日记账。人工的已记录凭证不影响报告（除了修改客户发票的凭证）。
- 有关欧盟销售的VAT 代码应与EC销售列表的报告链接至。此链接已创建于 VAT 代码 标签页卡中的 VAT设置 程序。
- 必须在客户登记中为客户已登记包括国家 / 地区代码的VAT 登记号。该报告将包括VAT 登记号具有属于欧盟的国家 / 地区代码且作为欧盟销售已编码的客户。
将数据负荷到报告中
报告的数据负荷基本上遵循与常规的VAT 报告相同的逻辑，其中涉及欧盟贸易的VAT 报告中的值显示与EC销售列表的值相同。该报告通过科目或VAT 代码（由低于系统设置确定）加载作为欧盟销售的凭证行的数据从。
与常规的VAT 报告中的系统设置相同 VAT 报告底单载入自 影响值如何加载到报告中。如果选项 会计科目表 VAT 代码 已为系统设置已配置，然后报告将显示全部客户发票凭证上的所有事务，这些凭证包含与标记为EC销售列表的VAT 代码链接的科目。如果选项 总账事务 VAT 代码 已为系统设置已配置，然后报告将显示全部包含与EC销售列表有关的VAT 代码的客户发票凭证上的所有事务。
客户号, 发票
在系统中可以使用该功能 客户号, 发票。这意味着销售流程中涉及两个不同的客户编号。一，你有已登记订单的客户号，其它，你有发票上使用的客户号，将接收此发票的客户号。EC销售列表会在订单客户上加载VAT 登记号。这意味着订单客户的VAT 登记号显示在客户发票文档上，并已记录在EC销售列表中。如果你希望发票上的客户管理EC销售列表，则客户登记中有一个设置可用于 订单客户。此设置称为 使用客户编号, 发票中的 VAT 登记号。你可以在下面查询此设置 其它的 在里面 客户登记 程序。

#### 导出EC销售列表
可以将EC销售列表导出到文件。为此，你应该载入列表，然后单击按钮 导出 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_export.png) 在程序的工具栏中。导出文件的默认路径在程序中已配置 导出 / 导入设置。
列表类型

#### 合计的
此列表类型按 VAT 登记号合计。VAT登记号是从客户登记中加载的。可以展开行并查看详细信息。

#### 详细的
此列表类型显示按客户分组的详细列表。该列表显示每发票的详细信息。
格式
演示文稿确定了如何显示/呈现所选列表。例如，应将其作为分组显示还是作为总计显示。该程序中包含一些标准格式。
在大多数可以加载列表的程序中，可以创建自己的格式。这是在相关程序后台的格式下完成的。例如，如果您创建自己的格式，您可选择它是否应该具有钻取功能和钻取过滤器。
您可选择列表应包含哪些列，并且可以为每一列配置分组、排序、聚合，以及该列是否应以图表形式显示以及是否应打印。此外，您还可以进行打印输出设置、图表设置和有关额外聚合的设置。
在[格式](../../../UserGuide/GeneralFeatures/Presentations.htm)中阅读有关此内容的更多信息。
选择列
在列表程序中，始终有一个名为选择的标签页，您可以在其中选择数据库中不同间隔的数据记录。然后使用程序工具栏中的载入按钮![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_display_list.png)加载数据记录。
在程序后台的选择行下，您可调整位于选择标签页每种列表类型应具有的选择行。在列表类型字段中，您可选择要自定义选择行的列表类型。
一张表显示可以选择的选择行，一张表显示已选定的选择行。您可通过使用鼠标指针拖放来添加、删除或移动选择行。
使用保存按钮![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_save.png)保存选定的选择行。
在[选择](../../../UserGuide/GeneralFeatures/Selection.htm)主题中阅读有关此内容的更多信息。
