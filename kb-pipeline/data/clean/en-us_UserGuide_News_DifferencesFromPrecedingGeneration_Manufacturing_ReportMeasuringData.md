### Report measuring data
- In many ways, the Report measuring data procedure works as in G4.
- If you are allowed to adjust measuring date or not, is determined by permissions (what you are authorized to do).
- The Report measuring data procedure is also available to users with the Recording terminal license type.
- The user right Report measuring data allows you to save measuring data but not to edit existing data. To be allowed to edit existing data you also need the user right Modify measuring data.
- Already reported measuring items are displayed by clicking a button on the toolbar instead of in a list type.
- You can print measuring data on travelers and operation documents. This is determined by a setting in the Document templates – Manufacturing order procedure. On travelers you see all measuring points in a Measuring plan as a separate page. On operation documents you see the operation's measuring points below the material list.
- If an employee is blocked, a validation is shown and the reporting of measuring data cannot be saved.
- If the part is traceable you link BatchA batch is the set of components/products manufactured at the same time and made from the same original material. or Serial numberA serial number is a number that is used for traceability for parts on entity level. to the measuring data you report. You can create new batches in the procedure and these will then be linked to the manufacturing order.
