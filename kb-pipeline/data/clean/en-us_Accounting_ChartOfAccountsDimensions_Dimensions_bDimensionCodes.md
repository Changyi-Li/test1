### Dimension codes
In this box you handle the dimension codes. It is not possible to make changes in this table if the selected dimension is linked to a register, since the dimension code is loaded from the register in question.

#### Number
A number for the dimension code.

#### Name
NameHere you can write a descriptive text as a name. You enter name texts in the company language and they are displayed in the user’s language.
By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Dimension group
This column gets its name after the description entered for the dimension groups in the box Dimension groups. Here you can select a dimension group to link to the dimension code. (If you want to apply dimension groups.)

#### Warehouse
This applies if the Warehouse option is installed. Here you create the link between warehouse and, for example, cost center if you wish to activate automatic posting for cost center, cost unit, etc. based on the order row's warehouse. This applies to all order procedures, quote procedures, and invoice registration procedures in the system.

#### Active
With this checkbox you determine if the dimension code in question should be active. This setting is only available for dimensions not linked to registers.
