### Licenses
Here you find an explanation of all license types and the scope of the user licenses in Monitor ERP.
> A license by Scope + License type, t.ex. Group, Complete or Company, External authorization.

#### Scope of licenses
A user license can have one of the following scopes:
- Group – A group license gives the user access to all companies in the system at the same time. The same name should be registered for the user in all companies.
- Company – A company license only gives the user access to one of the companies in the system.

#### License type
A user license can be one of the following license types:
- Complete – Means that the user has access to all functions. The company can then adjust the user's user rights via roles, user rights groups, or user-specific user rights. This will decide the users access to modify and delete records in different procedures.
- Recording – Means that the user only has access to the following procedures: Recording terminal, Part register, Manufacturing order information, Report measuring data, Report maintenance, and Print transport label – Manufacturing. The user can link files in the reporting procedures. In Monitor Mobile, the user has access to the procedures Recording terminal and Part list. The user only has read-only rights in the latter procedure. This license type is preferably used as a shared time-recording station in production.
> Please note! The recording license does NOT give access to the Print transport label – Part procedure in the Stock module.
- External authorization – Means that the user only has access to the Authorize invoice in Monitor Mobile, the Approve purchase order, Authorize supplier invoice, and Invoice overview – EIM procedures in Monitor ERP.
- Machine terminal – This license is included in the option Machine integration. It is used by users who reports starts/stops etc. in specific machine terminals. This license type does not grant any user rights to procedures; not in the Windows client and not in Monitor Mobile.
- API – Means that the user has access to the system via the existing API. A read-only API license is included. A user with an API license cannot log in to Monitor ERP via the Windows client or mobile client. You find more information about API for Monitor ERP at [https://api.monitor.se](https://api.monitor.se/).
- Personal recording – Gives the user access to the same procedures as the Recording license type, with the difference that this license type allows only ONE person to record time. Therefore, the user must be linked to an employee in the personnel register.
- Daily management – Means that the user only has access to the Daily management procedure as well as to the Message center in Monitor ERP. The license type is used on terminals in order to view the daily management. It is possible to register an unlimited amount of users for this license type.
- Portal – Means that the user is tied to the Monitor portal. A user with a portal license cannot log in to Monitor ERP via the Windows client or Monitor Mobile. You cannot assign the Portal licenses via the client. These are only available via the portal.
- Stock reporting – means that the user only has access to Part register, Report pick list, Pick list A pick list is a list of parts/products which should be picked from stock for a manufacturing order or a customer order. – Manufacturing, Report arrival, Receiving inspection, Report delivery (pick list), Stock count, Stock count against basis, Move stock balance, Direct withdrawal, and Direct arrival in Monitor Mobile.
