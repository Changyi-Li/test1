## Parameter groups
In this procedure you register parameter groups with different settings for attendance recording. Each person in the personnel records should then be linked to such a group. The personnel linked to the same group then get the same settings for example regarding overtime, flex time, and shorter working hours.
For a group you can configure if overtime is allowed and when the overtime starts applying before/after the working time. The overtime is linked to a time bankTime banks are used in order to save recorded time outside scheduled working hours. Different time banks are for example used for comp time, makeup time, flex time (positive/negative), and shorter working hours. on which you configure a minimum limit and a maximum limit and absence codeAbsence code is used in order to be able to link causes to recorded absence. Salary types can be linked to absence codes and thereby the system can link the different types of absences to the correct salary type. Examples of some of the most common reasons for absence are illness, parental leave, leave of absence, late arrival, etc. Furthermore, absence codes can be linked to time balances so that the absence recording automatically reduces the balance for flex time, comp or makeup time..
For shorter working hours you can configure how it should be calculated and which salary typesSalary types are used to create salary bases for worked time and absence. Different salary types are used, for example, for work during regular working hours, flex, overtime, shorter working hours, and sick leave. The salary bases are used to manage salaries in a payroll system. Salary types are linked to absence codes in addition to work schedules and overtime schedules. should be generated on salary basis.
You can configure if flex time should be allowed and if it is included in the daily working hoursDaily working hours is the agreed working hours per 24 hours according to a schedule. and you can also enter a time bank for flex time and salary types for positive flex/negative flex.
Here you also configure how you wish absence check and absence rules to be managed.
Via the parameter group personnel can also be given the ability to edit additions and/or be allowed to adjust attendance recording items in the recording terminal.
