### The list type Ledger – Detailed/Total
This list displays a detailed/total list of invoices with invoice amount, remaining amount, and ordered amount per a certain ledger date. These amounts are also shown in foreign currency. A setting determines if fully paid records also should be included in the list.
The detailed list can be grouped by supplier, supplier name, or due date. You can enter a comment and save it.
The total list can be totaled by supplier, accounts payable account, or currency. If the list is totaled by supplier, you can see the number of invoices. Each row in the list can be expanded to show detailed information. You can also see if the invoice is blocked for payment.
For on account payments you can edit the supplier’s invoice number.
