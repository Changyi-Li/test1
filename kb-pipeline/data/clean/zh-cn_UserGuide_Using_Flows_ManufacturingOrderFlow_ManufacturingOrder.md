### 工单
- 登记工单 – 在这里你登记新订单，也可以修改现有的订单。你也可以直接从这里按订单打印。订单在已登记后会获得状态1 ，已打印之后会获得状态2。可以在报告前打印运输标签，并在运输过程中随货物一起已发送。
[![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/TrainingMaterial/ManufacturingOrder.png)](../../../../../Resources/Images/TrainingMaterial/ManufacturingOrder.png)
- 打印工单– 注册工单之后，你可以按照上面程序直接打印。但你也可以选择在此程序中时间打印多个订单。订单然后变为状态2。
> MONITOR提示！ 使用 工单信息 （ 下班 ）快速查询工单的状态。 使用 订单列表 - 生产 查看整个工单积压。 使用 外协文档 / 已运输 在同一文档上打印多个发给同一分包商的订单。 在调用的程序中 文档模板 - 工单 你可以影响订单文档的外观。
