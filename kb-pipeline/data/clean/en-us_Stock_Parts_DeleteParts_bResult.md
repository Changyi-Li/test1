### Result
In this list you see the parts selected to be deleted.

#### Include
Mark this checkbox for the parts you wish to include in the deletion check.
By clicking the Run deletion check on all selected parts button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_run.png) on the function menu, you run a check on the marked parts to see if they are possible to delete or deactivate.
> Please note! Parts that you delete are deleted from the part register. Parts that you deactivate will remain in the part register but will not appear in the LookupThe Lookup feature is a powerful search tool which allows you to search and load information from large registers. You open the Lookup feature by clicking on the dropdown button or by using F4 on your keyboard. feature and you will not be able to register orders for them. In Monitor ERP it is normally not possible to delete old and expired parts if they still have dependencies, for example that they still exist on manufacturing orders. That is why you can deactivate such parts, where the order status is Historical. The actual execution of deletion/deactivation takes place when you save in the procedure.
- Parts which cannot be deleted or deactivated are displayed with an error symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/error.png) after the check has run. A tooltip for the symbol explains why the part cannot be deleted or deactivated. In the Log for part box you see a log displaying where the part is used.
- Parts which are possible to deactivate are displayed with a warning symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png) after the check has run. A tooltip for the symbol explains that the part can be deactivated and why it cannot be deleted. In the Log for part box you see a log displaying where the part is used.
- Parts which have already been deactivated will be given a red padlock as symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/RedPadlock.png) after the check has run. A tooltip for the symbol explains that the part is already inactive and why the part cannot be deleted. Inactive parts are only shown if the Show inactive parts setting has been activated under the Selection tab.
- Parts which are possible to delete will be given a symbol showing a green green filled circle ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/green_dot.png) after the check has run. A tooltip for the symbol lets you know that the part be deleted or deactivated.
By clicking the Delete/Deactivate selected parts button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_delete.png) you will delete the parts that in the list are marked with the Include checkbox and which have this symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/green_dot.png) after the check has run. Parts that are marked but also have the warning symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png) will instead be deactivated. For parts which cannot be deleted, the Include checkbox will be deactivated after the check. If you again activate the checkbox, the ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_delete.png) button will be deactivated instead.
You execute the deletion/deactivation of the parts in the database by using the Save button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_save.png) (Ctrl + S) on the toolbar of the procedure.
Using the Go to procedure button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) you can via the link open the Part register for the part in question.
