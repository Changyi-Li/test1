## Calculation mark-up
In this procedure you register exceptions from the general mark-ups for:
- [SO](bCalculationMarkup.htm) (storage overhead)
- [SC](bCalculationMarkup.htm) (subcontracting cost)
- [Sales OH](bSalesOH.htm) (sales overhead mark-up)
- [Profit](bProfit.htm)
- [Expenses](bExpenses.htm) (for purchase parts)
You can register several exceptions from the general mark-ups and translate these into different languages. When a new part is created, it always gets the standard mark-up. If you have registered several mark-ups, you can change mark-up for a part. You enter SC mark-up in the Part register, the Manufacturing tab for parts of the type Manufactured. This then affects the calculations etc.
When you start up the system for the first time, only general mark-ups are included in the system.
Delete calculation mark-up
You can delete mark-ups that you have registered. The system checks if the mark-up is used for work centers, parts, operations, manufacturing orders, etc. If you try to delete a mark-up that is being used, you see a message about where it is used, but you can still delete it. This will then be replaced with the general mark-up.
