### Settings

#### Only not recorded depreciation
With this setting you decide if only depreciation not yet recorded should be shown in the list, that is, the same depreciation shown in the Print fixed assets journal procedure.

#### Only not recorded sales/retirements
With this setting you decide if only sales/retirements not yet recorded should be shown in the list, that is, the same sales/retirements as shown in the Print fixed assets journal procedure.

#### Voucher text
The default text depend on the list type you have selected. These texts are handled in the Voucher texts procedure.
