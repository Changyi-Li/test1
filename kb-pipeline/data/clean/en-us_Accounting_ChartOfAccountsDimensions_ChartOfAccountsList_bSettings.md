### Settings

#### Show blocked accounts
With this setting you determine whether or not blocked accounts should be shown in the list.

#### Show only used accounts
With this setting you determine if you want to show only used accounts in the list. "Used accounts" in this setting refers to accounts on which there is an opening balance, or accounts on which transactions have been made at some point.

#### Signer/Approver
Applies to the list type EIM signer/Head signer. Here you can select by signer/approver. This may be useful if a specific signer/approver should be replaced in multiple accounts.

#### Head signer
Applies to the list type EIM signer/Head signer. Here you can select by head signer. This may be useful if a specific head signer should be replaced in multiple accounts.
