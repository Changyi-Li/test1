## Option lists
This procedure is a part of the option called Product configurator. Here you create and update option lists. Option lists are used in configuration groups.
What is an option list?
An option list defines different parts that can be selected in the configuration. The parts will in the normal case be used as included/incorporated parts in a manufacturing order and be added to the basic BOM and routing. For options that do not have the function that they should be included in the structure on the manufacturing order, then fictitious parts are often used.
On the header row in the procedure you can make general settings for the option group. In the table below you add part rows and configure different default values for each part.
Buttons on the toolbar
In this procedure you can also use an option list as template for a new option list. This is done by using the button Save as... on the toolbar of the procedure. There you also find a button used to delete option lists that are no longer used. If you try to delete an option list, a check is made to see that it is not used in any of the configuration groups.
You can rename an option list if you need to. This is done by using the button Rename ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_rename.png) (Ctrl + F2) in the toolbar of the procedure. You then get to enter a new option list code. If you rename an option list, the new name will applied where the option list is used; in configuration groups, quotes, and orders.
Option lists can also be created directly in the procedure Configuration groups, for example in connection with when you create a configuration group or when you create its structure. However, it is not possible to add parts in a new option list created in that procedure. This must be done in the Option lists procedure instead.
