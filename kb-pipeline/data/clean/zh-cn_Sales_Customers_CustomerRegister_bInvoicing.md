### 开票

#### 客户号, 发票
默认下，“客户号, 发票”具有与页眉行相同的客户号。如果客户订单发票上默认应有另一个客户号，则可以在此处进行已变更。例如，当客户有一个总部时，在正常案件下应该收到发票。此字段中的客户号将默认用于相应字段 客户号, 发票 为客户下达新建订单。
> 请注意！为发票的客户是已更新应收账款，并为订单的客户是已更新销售统计。

#### 保险费
在输入你通用保险费。以百分比形式输入（100% 至 -100%）。该成本将作为向客户开具的所有发票的发票值的加成收取。
其它发票设置

#### 汇总发票
在这里你可以选择是否可以打印/向客户发送包含多个发票底单的汇总发票。有以下选项可用：
- 否 –否汇总发票。
- 每客户 –每客户一汇总发票。
- 每订单 –每客户订单一汇总发票。
- 按交货单 –按交货单一汇总发票。
阅读发送汇总发票的条件
订单能够创建汇总发票，必须满足编号标准。全部发票底单必须具有相同的：
- 发票状态
- 客户号, 发票
- 发票类型
- 货币
- 汇率（如果订单有远期汇率）
- 开票费用设置
- 付款条款
- 付款条件文本（当有手动输入的付款条件时）
- 信用期限（当手动输入付款期限时）
- 打印方式
- 发票地址
- Email接收者（如果发票通过Email已发送）。
订单能够创建汇总发票，还必须满足以下标准：
- 客户不能是临时客户（流浪客户）
- 发票不能是贷项发票
- 发票底单无法与开票计划链接至，但同一订单号内的交货发票可以用于汇总发票。
-   
如果协议的发票底单与应计协议链接至，然后不使用汇总发票。

#### 发票挂起
如果你检查此选项，当交货给相关客户时，发票底单将自动变为“挂起”（状态3）。如果不第一个发票底单状态更改为状态1 （未开票），则无法已批准或已打印挂起发票。
使用系统设置 新客户发票底单状态默认状态为“挂起”，你可以决定复选框 发票挂起 对于新客户，此默认已激活由。

#### 开票费用
如果要在给客户的发票中已添加开票费用，检查此框。开票费用金额由系统设置决定 发票费用金额。

#### 催款提醒
对于新客户，此设置默认质检由，即会已打印付款提醒。你可以为相关客户修改这一点。你登记在 文档文本 程序。

#### 催款费
如果应向客户收取催款费，检查此框。通过系统设置 付款提醒费用的金额 你输入要应用提醒的金额。仅向客户开具的利息发票收取催款费。

#### 取整
确定是否应对金额应用取整。小数值1–49 将向下舍入，小数值50–99 将向上舍入。
使用系统设置 新客户默认取整，你可以决定复选框 取整 对于新客户，此默认已激活由。

#### 托收保付
通过此设置，你可以确定是否应通过银行还是通过托收保付公司向客户已开票。也就是说，当你将发票（应收账款）出售给银行或公司时，他们然后处理您的投诉。在里面 银行设置 你登记托收保付公司的银行账号的程序。你还可以配置是否应在文档页脚中显示银行账号，从而替换公司自己的的银行账号。
还必须安装托收保付插件，然后当你登记新客户时此设置将默认激活由。

#### 形式发票使用发票号
通过此设置，你可以决定是否应从发票底单表格加载形式发票的发票号。这意味着形式发票将被已分配与常规的发票相同的发票号。当你批准形式发票时，发票号将被需求 ( - )，并且仅当你自拣货单的形式发票和发票底单创建形式发票时才有可能。如果你批准了基于客户订单创建自的形式发票，则该形式发票将被已分配一个形式发票号序列的编号。
- 否 – 当你批准形式发票时，否需求 ( - )任何发票号。该编号将从形式发票的编号序列中加载。
- 是, 自拣货单 – 在这里你可以确定形式发票是否应该获得与常规的发票相同的编号。当你批准形式发票时，将需求 ( - )发票号序列中的一个发票号 复审 / 批准形式发票 程序，自拣货单的形式发票列表类型Pro forma。
- 是, 自发票底单 – 确定形式发票是否应获得与常规的发票相同的编号。当你批准形式发票时，将需求 ( - )发票号序列中的一个发票号 复审 / 批准形式发票 程序，自发票底单形式发票列表类型形式发票。

#### 联系人代码/联系人编号
当需要应用电子发票时，你可以在这里输入客户的联系人代码或编号，例如项目号、协议编号或其它个人代码。已发送电子发票时，此代码被用于在导出文件中。在导出文件中，联系人代码 / 编号将显示在“BuyerReference”标签下，而客户联系人（名称）将显示在“联系人”章节下。如果否输入代码，客户联系人（名称）将被放置在“BuyerReference”标签下以及“联系人”章节下。
如果否输入已选择联系人的参考代码/编号，则在此字段中输入的联系人代码/联系人编号将成为客户所有发票的所有的默认联系人代码/参考编号 联系信息 标签页。

#### 已链接电子发票
在这里你可以看到客户是否已连接到 Crediflow。通过使用 打开 Crediflow 对话框 按钮 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_more_info.png) Crediflow 进行在线搜索，了解客户是否喜欢或允许供应商发送电子发票。如果客户更喜欢电子发票，你应该复选框 连接 并点击 连接 按钮。如果客户允许电子发票，你应该向客户发送带有邀请的消息，然后客户可以批准您的公司发送电子发票。要发送邀请，你应该使用 发送邀请 按钮。状态将更已变更 已发送邀请。一次客户已批准了电子发票，该字段的状态将更已变更 是的。
当你查找通过 Crediflow连接的电子发票接收者时，建议你仅使用企业 ID 号。这是为了提高您获得匹配的机会。如果你未输入单独的开票地址，则会从邮寄地址表格加载国家 / 地区代码，在这种案件下，国家 / 地区代码主要从开票地址中加载。
如果你有客户的VAT 登记号或GLN 号，也可以在搜索时使用它。请注意！你必须确保编号准确，因为它必须与不同电子登记册中输入的号码匹配。如果你未输入单独的开票地址，则会从邮寄地址表格加载国家 / 地区代码，在这种案件下，国家 / 地区代码主要从开票地址中加载。

#### 电子发票地址 (EIA)
在这里你客户的电子发票地址，输入基于你在下下一个字段中选择的电子发票地址标识 。电子发票地址可以例如客户的企业 ID 号、 GLN 号或VAT编号。电子发票地址 (EIA) 当客户连接到 Crediflow 时会自动加载。

#### 电子发票地址 ID (EAID)
你在此处为客户的电子发票地址标识选择一个选项。有以下选项可用：企业 ID 号、 GLN 号或VAT编号。如果你选择 瑞典语VAT编号 以及客户的 VAT 登记号 已输入 其它的 框中，该编号将自动输入到 电子发票地址 (EIA) 上面的字段。请注意！这 电子发票地址 ID (EAID) 当客户连接到 Crediflow 时会自动加载。
