### Locking of records
The type of edit lock-ups found in G4 is not used in G5. In G5 you are allowed to make changes in a record while another user has the record open. If a user for example is editing a part and you load the same part, you will be notified that the first user is editing the same part. However, this is not a block. It means you can both continue editing the same part at the same time. As long as you do not make changes to the exact same field, it is not a problem. If the first user edits the part code and you change the standard price, both changes will be saved. But if you both make changes in the same field, the value entered by the user who saved last will apply.
Another scenario which in G4 caused an edit lock-up, but which is not a problem in G5, now makes it possible for you to have the Register customer order procedure open with an order loaded at the same time as you delivery report the order in question.
