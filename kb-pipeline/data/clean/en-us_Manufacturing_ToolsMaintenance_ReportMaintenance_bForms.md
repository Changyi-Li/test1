### Forms
Here you see the form which is linked to the selected maintenance template. Here you enter the reported values, select status, and enter comments, if any.
Under the Documents tab you see the document for the form with values already filled in once you save the reporting.

#### Reported value
Here you enter the measurement to report. In the fields to the right you see the minimum tolerance, setpoint, and maximum tolerance. If the measured value falls outside the tolerances, the status will become Not OK. Reported value can also be a checkbox, a text box, or a date field. If it is a checkbox and you mark it, the status will be changed to OK. If it is a text box or a date field, you have to update the status manually.

#### Status
Status will automatically be updated based on the Reported value, if it is numerical or a checkbox, but you can also change the status manually. The options that exist for status are: OK, Not OK, and OK with action. For the status OK with action it is possible to create maintenance orders.

#### Tool serial number
Here you select which tool should be used on the row for the control measuring. You can select reusable tools that have a serial number. A tool such as e.g. a calibration weight when calibrating a scale.

#### Comment
Here you can enter an optional comment to the reported value.

#### Instructions
Here you can read instruction for the row in question. These were entered on the format template.

#### More info
By clicking the More info ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) button you see what type of row it is, and the type of field for the reported value.
