### Settings
General

#### Only show orders with a difference
With this setting you decide if only customer orders where there is a difference, should be shown in the list.

#### Only show fields with a difference
With this setting you decide if only fields on customer orders and customer order rows where there are differences, should be shown in the list.

#### Pre-select "Save"
With this checkbox you decide if the column Save should marked by default in the list. This setting is not checked by default.
Synchronize prices
Under Synchronize prices you can update settings which affect the customer order's and the customer order row's prices.

#### Currency
With this checkbox you decide if the currency on the order should be updated in the synchronization. Currency can only be changed on a customer order if no delivery reporting has been made and there is no invoice basis. If you check the Currency setting, the settings called Price each and Setup price, will automatically be activated. If you only want to change the exchange rate without converting prices, then you should uncheck the Price each and Setup price.
With the checkboxes below you determine if price and discount concerning order rows, should be updated during synchronization.

#### Price each
With this checkbox you decide if the price each on the order row should be updated in the synchronization.

#### Discounts
With this checkbox you decide if the discount on the order row should be updated in the synchronization. You can select to synchronize:
- Discount (code 1)
- General project discount (code 4)
- Order type discount (code 5)
- Discount on discount (code 6)

#### Setup price
With this checkbox you decide if the setup price on the order row should be updated in the synchronization.
Synchronize posting
Under Synchronize posting you update the settings which affect the customer order's and the customer order row's posting.

#### Customer group
With this checkbox you decide if the customer group on the order should be updated in the synchronization. If you check the Customer group setting, then the setting called Posting will automatically be activated.

#### VAT group
With this checkbox you decide if the VAT group on the order should be updated in the synchronization. If you check the VAT group setting, then the setting called VAT code will automatically be activated.
With the checkboxes below you determine if posting and VAT code concerning order rows, should be updated during synchronization.

#### Postings
With this checkbox you decide if posting on the order row should be updated in the synchronization.

#### VAT code
With this checkbox you decide if the VAT code on the order row should be updated in the synchronization.
Delivery rules
Under Delivery rules you update the settings which affect the customer order's delivery rules. See further explanation of the settings in the help chapter for [Delivery/Shipping](../../Customers/CustomerRegister/bDeliveryShipping.htm) for the Customer register procedure.

#### Apply delivery planning
With this setting you decide if the delivery planning on the order should be updated in the synchronization.

#### Apply preliminary pick list
With this setting you decide if the preliminary pick list of the order should be updated in the synchronization.

#### Delivery horizon
With this setting you decide if the delivery horizon on the order should be updated in the synchronization.

#### Partial delivery
With this setting you decide if partial delivery on the order should be updated in the synchronization.

#### Create delivery note number when delivery planning
With this setting you decide if the information in "create delivery note number when delivery planning" on the order should be updated in the synchronization.
Other options for synchronization
Here you find different settings placed in the order header and which you can choose to synchronize.

#### Customer name
Here you decide if customer name should be updated in the synchronization.

#### Payment terms
Here you decide if payment terms should be updated in the synchronization.

#### Delivery terms
Here you decide if delivery terms should be updated in the synchronization.

#### Delivery method
Here you decide if deliver method should be updated in the synchronization.

#### Apply delivery planning
With this setting you decide if settings concerning delivery planning on customer orders, should be updated in the synchronized.

#### Priority
Here you decide if priority on customer orders should be updated in the synchronization.

#### Seller
Here you decide if seller should be updated in the synchronization.

#### Print order via
With this checkbox you decide if the setting for the customer order's printout via (printer or e-mail) should be updated in the synchronization.

#### Comprehensive invoice
Here you decide if the setting regarding comprehensive invoice should be updated in the synchronization.

#### Invoicing charge
Here you decide if the setting for invoicing charge should be updated in the synchronization.

#### Print invoice via
With this checkbox you decide if the setting for print invoice via (printer or e-mail) should be updated in the synchronization.

#### Invoice is pending

#### Factoring
Here you decide if the setting for factoring should be updated in the synchronization.

#### Customer number, invoice

#### Invoice address
Here you decide if invoice address should be updated in the synchronization.

#### Mailing address
Here you decide if mailing address should be updated in the synchronization.

#### Delivery address

#### Communication
