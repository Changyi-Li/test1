### Reading
In this box there are three fields where you can see and update the results of the readings. This is mainly used for serial numbers sold to customer.
If you have installed the Tools & Maintenance option, this also applies to tools with serial numbers (which are considered entities), where these should be calibrated or maintenance should be performed on certain intervals or after a certain operation time or number of cycles.

#### Distance
Here you see the reported distance in kilometers.

#### Run time
Here you see the reported run time in hours. This value is updated for withdrawn tools with serial numbers when reporting on manufacturing orders.

#### Number of cycles
Here you see the reported number of cycles. This value is updated for withdrawn tools with serial numbers when reporting on manufacturing orders.

#### Report
By clicking the button Report reading ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_edit_data.png) you can manually update values for Distance, Operation time, and Number of cycles. You also see what the difference is compared to already updated values. You execute the change with the Report button in the dialog shown.
By clicking the Reporting log ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_log.png) you will see a log of values updated using the button described above. The values in the log are grouped by Distance, Time, and Cycles. In this log you can also see date and time of the reporting items, reporting type, reported value, and value after reporting.
If the Tools & Maintenance option is installed, you will in the log also see a grouping by Manufacturing reporting. This shows order number, reported quantity, quantity per cycle, and cycle time. There you see updates which has taken place of these values when reporting manufacturing orders where the serial number is included as a tool in the material list. It is the reporting type in the log that shows from where the updates have been loaded, if they have come from a manufacturing order or from a manual update in the procedure via the above button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_edit_data.png).
