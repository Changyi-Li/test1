### Header row

#### Number
In this field you can load existing reports based on the number of the report. If you want to create a new empty report you enter an unused number in the field. If you create a new report it is not possible to assign it a number between 1 and 99 since these report number are reserved by the system.

#### Name
Here you see/enter the name of the report. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Active
With this checkbox you determine if the report in question should be active. If a report is active it means it is shown and can be selected in the Print accounting report procedure.
