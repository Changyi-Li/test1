### Header row

#### Pick list number
Here you enter the number of the pick list. You can use the Lookup The Lookup feature is a powerful search tool which allows you to search and load information from large registers. You open the Lookup feature by clicking on the dropdown button or by using F4 on your keyboard. function (F4) to find the correct list.

#### Type
Here you see if the pick list concerns material or tools.

#### Suggested quantity
Here you select which quantity should be suggested to report on the material. You can select among the alternatives Suggest remaining, Zero (0), and Quantity in pick list.

#### Only material with remaining quantity
With this setting you decide if only material rows which have a remaining quantity should be shown.

#### The material's unit
Here you decide if the parts' standard unit (the default unit) or the unit for material withdrawal for manufacturing order, should be used for the material when reporting the pick list. You configure the unit for material withdrawal for manufacturing order by clicking the Usage button in the Units box in the Part register procedure. If you for the work center have configured to report material reported using the standard unit, this will apply, regardless of what you choose in this setting.

#### Person
Here you select the person from the personnel records that is reporting the pick list.

#### Date
Here you enter the date when the list is reported. Today's date is shown by default.
