### Settings

#### Show blocked parts
With this setting you can decide if you want to show the parts that are blocked for modifications in BOM and routing.

#### Show blocked work centers
With this setting you determine if you want to show the work centers that are blocked for Registration or Reporting.

#### Show staggered prices
This setting determines if staggered prices from subcontracts should be shown or not in the list. This setting is only available for the list type Subcontracts.

#### Calculate values for
If the system setting Use cycle time and ineffective time in BOM and routing is set to Yes, then you can calculate values for Unit time, Cycle time Cycle time is the productive time in the operation in which the unproductive time is not included. Cycle time plus Ineffective time adds up to the unit time for an operation., or Ineffective time Ineffective time is time which is necessary in the operation, but not directly productive.. The selected alternative which is calculated cannot be updated manually in the list when it is in the updateable mode. This setting is only available for the list type Internal operations.

#### Replace "Ineffective time" with value from work center
If the system setting Use cycle time and ineffective time in BOM and routing is set to Yes, then you can with this setting choose to replace the ineffective time with the work center's default ineffective time. This setting is only available for the list type Internal operations. This setting is deactivated if the above setting is set to Ineffective time.

#### Use default setup time when work center is changed
With this setting you decide if Setup time should be loaded from the work center's default setup time if you change work center in the list. This setting is only available for the list type Internal operations.

#### Use default setup cost when work center is changed
With this setting you decide if Setup cost should be loaded from the work center's default setup cost if you change work center in the list. This setting is only available for the list type Subcontracts.
