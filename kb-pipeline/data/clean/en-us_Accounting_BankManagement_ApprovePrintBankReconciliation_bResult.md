### Result
In the result list you can see the bank reconciliation reports that have already been approved from the selections made under the Selection tab.
By marking a report in the result list you open the selected report and can view it in the Preview section to the right.

#### Reconciliation report number
This is the number the bank reconciliation report has based on the number series.

#### From date
The date from which the report applies.

#### To date
The date to which the report applies.

#### Cancel
With the the Cancel checkbox (C) in the list you decide if the report should be canceled. Mark the checkbox and save the procedure if you want to cancel the bank reconciliation report. When the report has been canceled you can load the bank reconciliation report again for the same period.
