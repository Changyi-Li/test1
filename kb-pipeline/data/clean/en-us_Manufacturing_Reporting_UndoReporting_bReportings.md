### Reporting
In this box there is a list of reporting items made for manufacturing orders. The list is grouped by order number.

#### Undo
Check the box in this column for the reporting items that you want to undo. For the same manufacturing order, it is only possible to undo one reporting item at a time.

#### Order number
Here you can see the order number of the manufacturing order that has been reported.

#### Reported date
Here you see the date and time of when the reporting was made.

#### Part node
Here you can see the part number of the part node in the order structure.

#### Information
Here you can see information in the shape of symbols: for warning ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png), for block ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/error.png). A tooltip is shown when you hover over the different symbols, each displaying an explanation.
The warning symbol is shown if the undoing action results in something you need to be informed about. For example, clearance of the reported material will become deleted.
The block symbol is shown if it for some reason is not possible to undo the reporting in question. For example, if the part has already been consumed in a higher node in the structure order.

#### Traceability information (T)
The symbols for traceability at serial number level ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/serialnumber_image.png) or for traceability at batch level ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/batch_image.png), will be shown here when the part node in the order has traceability and traceable material is included in the reporting. In the boxes with reported operations and material, you can in the column T see information about which serial numbers or batch numbers which are affected when you undo reporting and will be deleted.

#### More info
Under the button More info ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you find information about the order type and you see which user who performed the reporting. You also see the recording date and who recorded it (if the Time recording module is used). You can also see to which node on the order the reporting belongs
