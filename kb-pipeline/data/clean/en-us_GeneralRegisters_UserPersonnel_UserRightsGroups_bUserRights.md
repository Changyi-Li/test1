### User rights
In this box you configure user rights for the selected group to perform different activities for different types of records.
Depending on the type of record, there are different activities for which you can determine the user rights for the record. For example show, create, modify, undo, print, add, replace, delete. For these activities you can check the box Allow or Deny for the group. That way, you can determine the group's user rights to the activities for different types of records.
You can allow or deny for the entire record (one level up). Then it applies to all activities for that specific record.
You can allow or deny for an entire module (the highest level). Then it applies to all activities for all different records in that specific module.
Even if you allow or deny all activities per record or module, you can override this per activity. The checkbox for that level will then be filled instead of displaying a check mark.
> Please note! Deny is ranked higher than Allow. If for example the user has a role that allows a certain activity but at the same time belongs to a user rights group that deny the same activity, the user will not be allowed to perform the activity.
