### Automatic update of adaptations

#### Notify the adaptations/services below that restart or update has taken place
If you have installed Monitor ERP web server, the installation program has added URL and authentication key for the web server in this table. The information is automatically loaded when the web server is installed. The purpose is that the web server automatically should reconnect to the Monitor ERP application server (Monitor ERP server) after a restart. It should also be automatically updated when the application server has been updated.
On the function menu, you find the button Verify connection ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_test_call.png). This button is used on each respective in order to check that the connection to the web server works.
By using the Update ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_upload.png) button you can manually start an update of the web server or the adaptation/service after an update of the application server.
Using the button Add new row at the end ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_row.png) (F5) it is possible to add rows for URL and authentication keys for different adaptations/services.
By using the Delete selected row button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_delete_row.png) (F6) it is possible to delete the selected row for URL and authentication key.
> To manually add or delete rows for URL and authentication key is done by support staff from Monitor ERP System AB, if needed.

#### URL
Here you enter the URL (website) to the web server or adaptation/service.

#### Authentication key
Here you enter the authentication key to the web server or adaptation/service.
