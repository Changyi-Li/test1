### Selected procedures
In this section you find the procedures which you have added from the section Selectable procedures. For each procedure you add, you can save/send (sub)results.
You can remove a procedure that no longer should be included in the agent task. This is made by using the drag and drop function with the cursor to the section Selectable procedures or by using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_goto_previous.png) between the sections.
You can change the order of the procedures in the agent task. This is made by using the buttons ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_goto_up.png) and ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_goto_down.png) on the function menu in the section. The procedure at the top will be run first, followed by the procedure on the second row, and so on. In the first procedure you can for example copy the records in the result to a clipboard. You can then load the records from that clipboard in the next procedure that is run.
