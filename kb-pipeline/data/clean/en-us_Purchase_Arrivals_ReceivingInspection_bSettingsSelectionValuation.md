### Settings – Selection (Valuation)

#### Price alternative
Here you select the price alternative that should be used when valuing the arrival reported quantity. In the next field select which Price list to use, if you as Price alternative chose price list.

#### Rate type
The Rate type field will become activated for supplier prices and price lists that are registered in another currency. It gives you the possibility select another rate type (for prices in another currency) to base the valuation on. Instead of valuate according to the exchange rate that is linked to the price alternative, you can select between Current exchange rate or AFS rate. The default rate type is determined by the system setting Default rate type.
