### Logotype
In this box you can add an image file which will be used as the company's logotype on all documents.
By using the Import button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_import.png) you can load an image file from the computer using the file formats .jpg, .png, or .tiff. In connection with the import, you can crop the image proportionally according to the fixed width/height relation (1:4) set for logotypes on documents. The image can have any size in pixels. However, the image must have the correct image ratio, that is, 1:4.
By using the Preview button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_preview.png) you can see how the logotype will look on the document.
By using the Delete button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_delete.png) you can delete the image.
