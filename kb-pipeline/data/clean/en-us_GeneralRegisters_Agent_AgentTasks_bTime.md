### Time
Here you configure all settings regarding when and how often you want to run the agent task.

#### Repeat every
Here you enter the number of times it should be repeated. Then you select one of the alternatives; Day, Week, Month, Year, or Last day of every month.

#### Only workdays
Here you determine if the agent task only should be run during workdays. This checkbox is available if you have selected Day in the setting above.
If you use the Warehouse option: If the run includes more than one warehouse, the day will be considered a workday when at least one of the warehouses are working as usual. Which days are considered workdays can be adjusted by creating own calendars for each warehouse.

#### Calendar
Here you can select which calendar should apply (in the same way as in the Company information procedure.) You must select a calendar if you have checked the box Only workdays above. The default calendar is the same calendar as the one used in the company or in the current warehouse (if you have installed the option Warehouse).

#### Start time
Here you can enter a start time for the agent task.

#### Repeat until further notice
Here you determine if the agent task should be repeated without any stop time.

#### End after
Here you determine if the agent task should be ended after a specific number of runs. You also select how many runs should be made before the agent task become inactive.
