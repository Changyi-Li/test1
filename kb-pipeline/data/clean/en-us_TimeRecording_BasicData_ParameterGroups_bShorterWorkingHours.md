### Shorter working hours

#### Shorter working hours
With this setting you decide if shorter working hours should be calculated for the group. The other settings in this box are only available if Shorter working hours is checked. Shorter working hours is automatically calculated by the system when the recorded days become authorized.

#### Time bank for shorter working hours
Here you select the time bank to where the shorter working time generated should be added.

#### Basis of calculation
With this setting you decide how to calculate the shorter working hours. The available options are Per day, Per hour, and According to schedule. If you select the Per day option you can also select calculation factor and minimum time per day. If you select the Per hour option you can select calculation factor. If you select the option According to schedule, it means that it is the schedule of the employee which will determine how the shorter working hours should be calculated.

#### Calculate for holiday
With this checkbox you decide if holidays which fall on a work day should be included in the calculation of shorter working hours. This setting is activated by default.

#### Calculation factor
Here you enter how large a share of each hour should be regarded as shorter working hours. You enter the calculation factor in hours using four decimals, for example 0,0300.

#### Minimum time per day
Here you enter the minimum number of hours per day which needs to be recorded in order for shorter working hours to be generated. This field is only available when the calculation basis has been set to the option Per day. Minimum time per day is entered in hours using two decimals, for example 2,00.

#### Salary types
Here you select the salary types which should be generated on the salary basis when shorter working hours is calculated.
