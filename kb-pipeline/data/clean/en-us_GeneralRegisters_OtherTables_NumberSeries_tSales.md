### Sales
Number series for Sales.

#### Number series
The name of the number series.

#### Next number
Here you can see the next number that will be used in the number series.

#### Greatest number used
Here you can see the greatest number that has been used in the number series. It is useful to see if there is a need to adjust the number series in order for it not to clash with previously used numbers.

#### Order type
Via the Order type button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you can configure separate number series for each order type. This is only available for certain types of number series.

#### Active
Here you determine if the number series is active. This is only available for the number series Credit invoice, Cash receipt, Interest invoice, Advance invoice, and Internal invoice. If you deactivate one of these number series, it will then use the same number series as Invoice. The field Next number is then deactivated and displays the same the next number as the invoice number series.
> If you have activated number series for all invoice types, please remember that the number series for invoice should have a gap of at least 10000 numbers between the lowest next number in the number series for the other invoice types. The number series for the other invoice types should have a gap of at least 1000 numbers between them. If you enter a smaller gap, a warning ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png) appears in the Next number field. These gaps are necessary in order to avoid a collision between the different number series.
