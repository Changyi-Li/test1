### Scheduled update of exchange rates
The Scheduling tab is available if the company currency supports automatic loading of exchange rates.

#### Active
Here you determine if the scheduling should be active or not.

#### Notify
By using this button you can decide to whom notifications should be sent regarding the update. You can also choose when notifications should be sent. You can configure which roles, groups, and users should be notified.

#### Update now
By using the button Update now you can update the exchange rates immediately.

#### History
When clicking this button you find a log of previous exchange rate updates. In the log you can see date and time for the update as wells the status. A green check mark is shown if the update was performed, while a red cross is shown if the update failed. In the Notifications you will also get a notification and a message if the update failed.
> Please note! Your Monitor ERP server must have internet access via TCP port 443 and 80, in order for the automatic loading of exchange rates to work.
