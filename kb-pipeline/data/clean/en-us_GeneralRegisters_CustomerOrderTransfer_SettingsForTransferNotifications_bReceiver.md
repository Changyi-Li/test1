### Receiver
Here you configure to whom notifications about different events should be sent. You can add several rows per event.

#### Type
Here you select type of receiver. The available options are Our reference (on customer order), Seller (on customer), User, Group, and Role.

#### User
Here you select a user if you have selected the option User in the Type column.

#### Group
Here you select a user rights group if you have selected the option Group in the Type column.

#### Role
Here you select role if you have selected the option Role in the Type column.
> There is a specific role called Responsible for transfer which is useful as receiver of notifications.
