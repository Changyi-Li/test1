### Cost/Income

#### Cost type
Here you can select a cost type among the activities linked to the project in question. The cost types must have the option Direct reporting selected in the field Result is loaded from.
An activity or a cost type must be selected here. The cost type will be suggested if you have entered an activity which there is a link to in the Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Project procedure.

#### Cost per hour
In this field you see the hourly cost if such has been entered in the Basic data – Project procedure.

#### Amount
Here you can enter an amount if a cost type has been entered. An amount is suggested if you have entered a time to report and there is an hourly cost entered for the cost type in the Basic data – Project procedure. However, an exception for the hourly cost might have been configured in that procedure for the project type.
