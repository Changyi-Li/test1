### List restrictions
Under this tab you can find the system settings that limit the number of rows in a list. Limiting the number of rows improves performance when loading data.

#### Enable row limit
With this setting you determine whether the limit for rows should be enabled or not.

#### List row limit
If the above setting is set to Yes, you can enter a limit for rows in lists.

#### Procedures exempted from row limit
Here you can select which procedures should be exempted from the general limit determined by the above settings. Row limits can be entered per procedure.
