### Header row

#### Part template
Here you enter a number or code for the part template.

#### Name
Here you enter a name for the part template. This field cannot be left empty. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Basic type
Here you decide if the template should concern regular parts or different types of tools. Part is selected by default for new templates. The basic types available for tools are Consumable (for example, cutting steel, weld pins), Reusable (for example, hand drilling machine, angle grinder), and Tool list. A tool list means a tool consisting of a structure with multiple incorporated tools (for example, a tool kit).

#### Active
Here you determine if the template should be active, that is, if you should be able to choose the template for parts.

#### Part type
Here you choose the part type which should be set on parts which have this template. See a description of part types in the help topic [Header row](../PartRegister/hPartRegister.htm) in the Part register procedure.

#### Use in calculation
Here you determine if the parts in this template should be included in pre-calculations, post-calculations, and WIP calculations. For part templates for the basic type Part, this box is checked by default. For part templates for any of the tools basic types, the setting will automatically be set to No. This means that a tool can be included in BOM and routing without affecting calculations and WIP. You cannot manually modify the setting in the template.

#### Default
Here you determine if the part template should be used by default when you register new parts. Only one of the templates can be default. If you do not choose a default template, a template must be selected when a new part is registered.
