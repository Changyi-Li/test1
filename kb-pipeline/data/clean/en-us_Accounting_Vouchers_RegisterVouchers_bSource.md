### Source

#### Journal number
Here you see which journal the voucher has been created from. The journal number here can refer to different types of journals such as invoice journals, payment journals, stock reporting journals, depreciation journals, etc. By using the button to the right, you can see the journal document.

#### Invoice number/Consecutive number
Here you see which customer invoice/supplier invoice the voucher has been created from. This is only shown on voucher for customer invoices and supplier invoices if detailed integration is applied. It is also shown on a manual voucher if it refers to rectification of a voucher for an invoice (to make it possible to trace when searching for postings for a certain invoice). If you have Electronic invoice management (EIM) in the system you can use the button to the right to see a preview of the customer invoice/supplier invoice.
