## 基础数据和设置
这里描述了在公司开始使用之前应该已登记的基础数据以及应该控制和可能已修改的默认设置 Monitor ERP 在日常业务中。基础数据是用户、组件、工作中心、 BOM 与工艺路线、客户、供应商等。附加，你还需要在其它基础数据使用由的不同表中登记基础数据，例如不同的条款、组件代码、价格等。
组件、客户和供应商可以已导入到 Monitor ERP 来自其它ERP 系统和电子表格应用程序。对于你已已导入的为组件，还可以导入余额、库位和批次号。这些导入是使用包含从其它ERP系统或电子表格程序已导出的信息的文本文件执行的。
当时间上线时，你应该已经已登记了最重要的基础数据，仓储费用工作人员可以开始工作 Monitor ERP 登记订单等随着时间的推移，你将添加不同类型的其他基础数据。
如果公司从生成前道MONITOR转换，则大多数数据和设置将包含。但是，某些基础数据必须再次已登记，并且你配置新建设置。
> 周三建议在咨询以下导师/顾问后登记基础数据： Monitor ERP System AB。在训练时 Monitor ERP 你还将了解基础数据及其设置。然后你可以讨论如何应用 Monitor ERP 订单获得系统的最佳利用。
