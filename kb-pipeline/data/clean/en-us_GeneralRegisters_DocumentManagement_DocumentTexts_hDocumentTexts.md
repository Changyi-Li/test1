### Header row

#### Document group
A numerical code for the document group, a maximum of 20 digits. A new record is highlighted by a green dot ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/green_dot.png) shown in the field. This dot will disappear when the record is saved for the first time.

#### Name
Here you see the document group's name, for example, the name of the language/language variant. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Document font
Font on phrases and texts in the document. The default standard font is Arial which is used for most languages. If you have created a new document group for the Chinese language, you should here select SimSun for Simplified Chinese. If the document group in question concerns the Thai language, you should here select the Kanit font.
> Please note! The default font used for additional texts and payment reminder texts is always Tahoma.
