### Overview
Under the Overview tab you can see an overview regarding the customer containing all quotes, orders, invoice bases, invoices, shipments, and different statistics.
You can select a Time limit. This is entered in number of months. Three months is the default value. The time limit determines for how far back in time data should be included in the statistics. This applies for all boxes.
With the setting called Include alloy cost you can decide if the alloy cost should be included in the amount or not.
