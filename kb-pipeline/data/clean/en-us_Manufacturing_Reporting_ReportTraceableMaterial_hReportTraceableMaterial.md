### Header row

#### Report number
Here you enter the material's report number to load the record. In this procedure it is only possible to load traceable material.

#### Other information on the main row
On the header row you also find information about the basic type of the material (Basic type B is shown with a symbol and is loaded from the part template the material is linked to in the part register), part number, name, and to which manufacturing order the material belongs. The remaining quantity of the material, its total stock balance, total available balance, and which type of traceability is activated for the part, can also be seen here. Furthermore, you can see comments and files linked to the material and the order.

#### Stock count request
Stock count request is mainly used if you find that the stock balance does seem to add up and you wish to signal this in Monitor ERP. When you activate this checkbox, today's date and the time will be set in the Request date field.
The parts for which there is a stock count request can be shown in the Create stock count basis list in the Stock count in list procedure. This is done by activating the Include requested stock counts setting. You can also select by Stock count request date. The list also displays the comment. When the stock count has been performed and saved for the part, the field and the comment will be cleared.

#### Request comment
If you have checked the Request comment checkbox, you can here add a comment regarding the cause of this request.

#### Include empty batches
Determines if empty batches that are reported for the report number should be displayed. This makes negative reporting (material returns) possible even if the batch has a zero balance.
