### Direct project reporting
- It is possible to register income directly.
- More information fields, such as Planned time, Reported time, Last reporting date, and Cost per hour.
- It is possible to see earlier reporting items.
- There are fields where you can enter Performed by in connection with finishing the activity.
- In the reference field you can write anything.
- When deleting, the system sets the record as status Deleted instead of completely deleting it from the database.
