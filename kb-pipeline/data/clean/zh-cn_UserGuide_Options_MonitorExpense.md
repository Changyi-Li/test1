# Monitor 费用
简化费用管理并保存时间
利用“Monitor 费用”，你可以在公司和员工在中间建立直接链接，从而轻松管理费用。
使用Monitor 费用应用程序，你可以轻松管理费用、津贴和里程报销。全部信息都安全存储，可通过浏览器两者直接在应用程序访问。作为管理员，你可以调整会计科目表设置，创建到公司工资和簿记系统的直接链接，以及修改应用程序的外貌。
你还可以将您的公司卡直接链接到应用程序，并在应用程序中自动获取全部事务。只需拍一张收据的照片，链接到事务，你全部回复完成了。

#### 使用Monitor 费用，你可以：
-   
直接从连接的商店和连锁店接收数字收据，并通过Email提交收据。
-   
自动过账全部费用，包括公司娱乐费用。
-   
直接链接到公司卡以自动传输事务。
-   
管理国内和国外的日常津贴。
-   
与电子驾驶记录链接至的里程补偿。
-   
有效管理费用报告和审核流程。
-   
将费用数据直接发送到MONITORERP 和其它会计系统。
-   
自动更新定期进行，无需管理员采取活动
