### Settings – Splitting options
These settings are available if you have selected the list type Split pick list.

#### Split by
With this setting you decide if the pick list should be split by Order, Manufactured part, Operation, or Work center A work center is a part of the factory. It can be a single machine or a group of machines, a single workstation or a group of workstations.. You can also choose the option None if you don't want to split the pick lists.

#### Pre-select
With this setting you decide if the pick lists loaded in the list should be pre-selected to be created. This is available for pick lists with status Cleared, Partially cleared, and Not cleared.
