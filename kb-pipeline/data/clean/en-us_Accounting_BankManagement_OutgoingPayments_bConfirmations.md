### Confirmations
In this box you can see data from the loaded file. When loading, a match will be made of the invoices with status Ordered in the accounts payable and the entries/records in the file. It is not possible to deselect invoices from confirmation. This is only possible when performing manual confirmation. The data that exists in the file is sent from the bank, and is nothing that you should change.
Red text in the columns means that the names also will be updated in the List tab.
It is possible to enter a bank charge and a comment.
