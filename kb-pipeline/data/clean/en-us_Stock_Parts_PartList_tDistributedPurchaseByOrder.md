### The list Distributed purchase by order
In this list you can when needed, for each part where distributed purchase is applied, update which suppliers in the distributions should receive the next purchase. This is useful if you at some point want a different supplier to be purchased from next.
In the Next column you can mark which supplier should be purchased from next time. When that purchase has been made, the supplier on the next row will get Next marked. This mark is automatically moved to the next row for each purchase and will then start over with the supplier on row 1.
