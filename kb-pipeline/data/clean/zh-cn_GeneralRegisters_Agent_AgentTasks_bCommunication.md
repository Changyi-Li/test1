### 通信
如果可以导出标记的程序 已选择程序 框中，你可以在这里选择你以何种格式导出代理任务的结果。你还可以选择是否将结果已保存在服务器上并通过Email已发送。

#### 导出
在这里你选择代理任务结果（列表）的导出格式。目前，支持 Excel 和 PDF。

#### 原始数据
如果选中此复选框，则会已导出原始数据。
此设置仅在代理任务 打印财务报告 程序你选择导出到 Excel。

#### 保存
选择你保存代理任务结果的路径。你激活选择在​​ 路径 程序。

#### 发送
在这里你可以选择结果已发送 Email 或者 Email (Monitor ERP 用户)，或者是否应该已打印在 服务器打印机。

#### 接收者
在这里，你可以配置将结果已发送到哪些接收器，具体取决于你在列中已选择的选项 发送..
-    
如果你选择 Email，你在此输入Email 地址。你可以输入多个地址，并用分号分隔。
> 系统设置调用 结果 Email 的发件人 必须输入根据 Monitor 代理程序 标签页卡中的 系统设置 程序，否则将显示警告 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/warning.png)。系统设置调用 用户名 (Exchange) 和 密码 (Exchange) 标签页 Email方式 系统设置已已配置为 基于服务器, 通过 Microsoft Exchange 或者 基于服务器, 通过 Microsoft Exchange Online。
- 如果 Email (Monitor ERP 用户) 被已选择，你应该在这里输入一个用户。用户应该在 用户 程序。
- 如果你选择 服务器打印机，你在这里选择一台服务器打印机。你可以在选择服务器打印机 服务器打印机 程序。

#### 导出 / 发送空列表
你可以在此确定是否应已导出并已发送空列表。

#### 包括
在这里，你决定是否应在导出中包含“选择标签页和筛选（如果已使用）以及页。这样就可以在打印上看到已做出的选择以及用于创建列表的筛选。在打印的页眉，你查询关于打印的来源公司以及打印时间例如信息。

#### 覆盖文件名
你可以在此处输入代理任务应已导出并已保存/已发送的文件的自定义文件名称。你不输入文件扩展名（.pdf 或 .xlsx）。这是自动已添加的。如果你字段空，文件名称变成程序加上今天的日期。
> 请注意！文件名称不能包含对文件名称无效的字符。输入你的字符，将会出现错误消息。
可以在文件名称中输入变量。可用变量低于表格所述。
| 变量的 | 解释 | 例子 |
|---|---|---|
| ％年 | 年(YY) | 21 |
| %Y | 年(YYYY) | 2021 |
| %匹配行 | 月编号 | 04 |
| %周, %周 | 周数（从周一开始） | 14 |
| %U | 周数（从周日开始） | 15 |
| ％A | 一周中的天，名称（短） | 周五* |
| ％A | 一周中的天，名称 | 周五* |
| ％b | 月名称（短） | 四月* |
| ％B | 月名称 | 四月* |
| %j | 年中的日 | 106 |
| ％日 | 月的天数 | 16 |
| ％X | 当前日期 | 2021-04-16 * |
| ％X | 当前时间(HHMM) | 1051* |
| ％ 当前日程表图表 | 当前日期和时间(HHMMSS) | 2021-04-16 105108 * |
| %小时, %小时 | 小时（24小时） | 16 |
| ％我 | 小时（12小时） | 04 |
| ％p | AM/PM（与 %I 一起使用） | 下午 |
| %匹配行, %i | 分钟 | 25 |
| %S，%s | 第二 | 59 |
| %% | 百分比 | % |
> 请注意！日期格式以及一周中的天和月名称的拼写由 Windows 中的区域设定和语言设置决定。显示的时间没有小时、分钟、秒在中间的分隔符。
