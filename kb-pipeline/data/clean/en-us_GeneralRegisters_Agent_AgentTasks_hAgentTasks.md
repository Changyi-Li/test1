### Header row

#### Number
In this field you enter a new agent task number or you load an existing one using the Lookup The Lookup feature is a powerful search tool which allows you to search and load information from large registers. You open the Lookup feature by clicking on the dropdown button or by using F4 on your keyboard. feature (F4). The agent task number should be alphanumerical and can contain a maximum of 20 characters. You create a new agent task by entering a number that does not already exist. If the field is left empty, a new agent task is created with the next available number from the number series for agent tasks. You can also create a new agent task by clicking the button Create new ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_new.png) (Ctrl + N) on the toolbar of the procedure.
A new record is highlighted by a green dot ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/green_dot.png) shown in the field. This dot will disappear when the record is saved for the first time.

#### Name
Here you enter the name of the agent task by using a maximum of 35 characters. This field cannot be left empty. You can edit this field at any time. If you change the name of an existing agent task, a control question appears when you save.
The name can be translated into the active languages registered in the system.

#### Status
Here you select the agent task's status. The available status alternatives are Active and Inactive. Inactive agent tasks will not be run regardless of what has been configured under the Scheduling tab. You can for example have an agent task that you want to keep, but you only want to run it during certain periods. Then you can switch between the status alternatives Active and Inactive.

#### Language
Here you select the language of the agent task. Results (lists) that are exported from the agent task will be in this language.
