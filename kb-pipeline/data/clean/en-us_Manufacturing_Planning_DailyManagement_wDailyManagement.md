## Daily management
In the Daily management procedure, you can create and display different views in which you can see essential product information used on a daily basis by departments and work centers. This is intended to be made on larger screens (or touch screens) out in the actual production unit.
This procedure is intended to replace or be a complement to the "analog" version of daily management which normally is a large whiteboard in the different departments.
Configuring views
By clicking the Configure button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_settings_blue.png) on the toolbar of the procedure, you first create the views which the company needs. The different views consist of different components deciding what should be shown in the view. Some of the components can also be configured using different settings. How you create views and configure components is the same as when you create a desktop configuration in Monitor ERP.
The views you create are common/joint and can be used by other users of the procedure in the company. The views become possible to select on the header row in the procedure.
On the header row you can also choose for which date the information should be shown in the view. This means the components will display the information for this date.
Fullscreen mode
When a view should be shown on a monitor you should preferably use the fullscreen mode, in order to make use of the entire screen. The fullscreen mode is activated by the Fullscreen button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_expand_box.png) on the function menu. You can close the fullscreen mode with the Esc key. You can also double-click the heading or rapidly tap twice if you have a touch screen. On the function menu you also find the Reload button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_refresh.png). You can use this if you want to update the data directly in the components. Otherwise the data will be updated according to the interval you entered when configuring the view.
Maximizing/minimizing components
Each component in a view can be maximized by clicking or tapping the component heading. This way only this component will be shown in the view. To reset, just click (or tap) on the component heading.
Components for Daily management
A number of components are included for the Daily management. With these components you can for example see status of different work centers, see the priority plan for the selected work center, change priority for operations, replan orders, lend personnel between work centers, and change capacity in work centers, see rejections in manufacturing orders, and see efficiency factor in work centers. Daily management currently supports day planning.
There are also components which can show absence of personnel, texts, images and hyperlinks, and show websites.
Read a description of the [components](DailyManagementComponents.htm).
> By using a touch screen you can interact with the components directly on screen to perform the above mentioned actions.
Separate user license and role for Daily management
You need one user per computer which will show Daily management. You register these users as usual in the Users procedure, for the separate user license Daily management which will only gives the user access to this procedure in Monitor ERP. There is no limitation to how many users you can register on this user license.
To the users which have been registered you assign the role Daily management. With that role the user will get complete user rights for this procedure as well as to the message function (chat) in Monitor ERP.
When Daily management should be shown on a computer you should first login to Monitor ERP using one of the users you have registered. You do this for each computer which should show Daily management.
