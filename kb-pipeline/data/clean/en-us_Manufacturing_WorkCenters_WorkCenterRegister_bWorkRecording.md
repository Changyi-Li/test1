### Work recording

#### Time calculation
Here you find three alternatives regarding how to report time for operations in the work center:
- Recorded time – With this alternative the operations will get the time which the operators report in the recording terminal.
- Planned time – With this alternative each reporting in Time recording will set the planned time for the reported quantity on the operation.
- Batch recordingBatch recording of the operations in the recording terminal means that several different operations can be started and finished at the same time, and that the reported time will be distributed evenly among them. The time calculation will distribute the time according to the planned time and quantity taken from the pre-calculation, as well as the reported quantity. Batch recording can for example be made in cutting operations, when several operations have the same raw material and also have short lead times. This is then used to avoid unnecessary work with the reporting. – This alternative allows batch recording of the operations in the recording terminal. BatchA batch is the set of components/products manufactured at the same time and made from the same original material. recording means that several different operations can be started and finished at the same time, and that the reported time will be distributed evenly among them. The time calculation will distribute the time according to the planned time for the reported quantity on each operation. If 1 operation in the batch is reported with 0 quantity, it will not get any reported time. For the event that all operations are reported with quantity 0 (for example when the employee clocks out for lunch) the distribution among the operations will be based on planned time for each operation. Batch recording can for example be useful in cutting operations, when several operations have the same raw material and also have short operation times. This is then used to avoid unnecessary work with the reporting.

#### Show in priority plan
With this setting you determine if the operations in the work center should be available for the operator to select from a priority plan in the recording terminal.

#### Multiple operators
With this setting you determine if more than one operator can report on the same operation at the same time in the recording terminal.

#### Recording in work center
Here you can to add which persons that are allowed to report on the work center. This will partly correspond to the information entered under the Work tab in the Personnel records – Time recording procedure, where you enter which work center an employee has access to.
In that procedure you can also (for work centers of the Manual work type) enter if the person is a capacity for the work center and you can enter an availability (in percent) for the person in the work center. That information can be seen here by clicking the More info button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) on the row of the person.
By using the Add from work center button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_copy_to.png), you can add all persons from another work center.
