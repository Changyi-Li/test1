### FAQ – Users and rights
Which user right is needed to manage properties?
This is determined by the user right Administer properties which can be found in the User-specific user rights box under the Roles/User rights tab in the Users procedure. The roles of ERP manager and System administrator have these rights.
How do I create an API user?
In order to do that, you need have the API license type in the system. Those in the company with the role of ERP manager are able to administer the company’s users.
1. Go to the Users procedure.
2. Enter the desired user name for the API user. Press [Tab].
3. Enter a description of the user in the Description field.
4. Click the Security tab and enter a password.
5. Save.
6. Then click the Modify license settings ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_change_record.png) on the right-hand side of the License field.
7. Select an available API license and click OK.
> This user’s user name and password can now be used to log in via API. Please note! The API license type cannot be used to work in the Monitor client.
How do rights and roles work in Monitor?
There are a number of pre-defined roles to choose from. A role is a template of user rights that the user normally needs in different procedures, based on different job titles. You can add several roles for a user, if needed.

How do I choose which type of news to show in Monitor News?
You can decide which news to show in two different ways:
- Under the General tab in the Users procedure. There you can configure the settings called Roles/Areas and Countries.
- Via the User settings ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserIcon.png) in the top right corner on the title bar.
Where can I add an e-mail signature?
Under the E-mail signature button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) in the Users procedure, you can add an e-mail signature. You can format the text and add images, links, etc. as a signature. You are able to copy an existing signature from Outlook and paste it in.
If you are using a method for sending e-mails that requires Outlook to be opened externally, the e-mail signature you have entered here will not be carried over. The signature only works with methods that use the inbuilt e-mail client in Monitor ERP.
