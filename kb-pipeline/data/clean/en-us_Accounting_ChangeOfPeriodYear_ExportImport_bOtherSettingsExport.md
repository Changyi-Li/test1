### Export

#### Budget number
The budget data in the budget number you select here will be exported. It is only possible to export one budget number to the export file.

#### Chart of accounts/Dimensions
With this setting you determine if chart of accounts and posting dimensions should be exported. This applies to the SIE type 4I.

#### Blank voucher series + voucher number
With this setting you decide if voucher series and voucher numbers should be emptied (made blank) in the file at the export. This allows the receiver to import to any series.

#### Balances
With this setting you decide if balances should also be exported. This applies to the SIE type 4E.

#### Include previous year
With this setting you decide if balances for opening balance (OB), closing balance (CB), and profit/loss account, for the previous year, should be included in the export. These will be included in the export by default.

#### Comment
In this field you can enter a comment text for the export if you want to.
