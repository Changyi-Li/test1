### The list type Part contents calculation
This list type is used to calculate the part contents for manufactured parts.
In this list you can choose which parts that should be included in the calculation. If needed, you can here change the order quantity. By clicking the Start calculation (Ctrl + R) button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_run.png) you start the calculation. The result of the calculation is shown under the Result tab.
