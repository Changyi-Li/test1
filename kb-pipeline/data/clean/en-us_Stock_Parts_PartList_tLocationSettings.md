### The Location settings list
In this list you can update location settings for different parts. Each location for a part is shown on a separate row in the list.
You can enter Priority of locations, and configure if locations should be Arrival location, Pick location, or Pick location for work center, or both. You can enter a Reorder point and Refill quantity if the location is a pick list or pick list for work center. You can also choose to Exclude balance on locations.
Read more about these settings in the topic [Locations](../PartRegister/bStock.htm) in the online help function for the procedure Part register.
