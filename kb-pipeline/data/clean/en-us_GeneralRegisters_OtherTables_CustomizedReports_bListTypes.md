### List types
In this box you add/delete rows with list types to the customized report (the list procedure). When you create a new report there is always a row for list type which you cannot remove.
By clicking the Edit report button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_edit.png) you build the actual list type that is marked. Read more about this in the [Edit report](wEditReport.htm) section.
With the Copy button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_copy_row.png) you copy a list type to a new list type. All changes you have to the list type you copy will be included in the new list type. This can be useful if you, for example, want to create multiple list types with the same selections and settings in the customized report.
By using Copy report's DisplayID to clipboard ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_copy_to_clipboard.png) you will copy the report's DisplayID to the Clipboard in Windows.

#### Name
Here you see/enter the name of the list type. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Type
Here you find the alternatives List and Free-format layout.
- List – A regular list with columns and rows.
- Free-format layout – A document for which you can change the layout.
> If you select Free-format layout for a report, you must also have knowledge about the report design tool DevExpress Report Designer which you use when you edit the report.

#### Sub-reports
If Type of list is set to Free-form layout, you can here add sub-reports to link to.
