### Reporting requirements
The information in this box is used when communicating with the customer regarding the part contents. For example, the information in the box can be used to attach documentation about part contents.

#### Code
Here you select the code of the reporting requirement. The reporting requirements must be registered in the Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Sustainability procedure.

#### Demander/Authority
Here you see the name of the demander/authority that is loaded from the Basic data – Sustainability procedure.

#### Reporting requirements
Here you decide if the chemical/part contents requires reporting. The following options are available:
- N/A (Not applicable)
- Yes
- No
