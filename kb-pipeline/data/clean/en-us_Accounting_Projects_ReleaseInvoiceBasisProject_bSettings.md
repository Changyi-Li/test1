### Settings

#### Include reportings not marked for invoicing
This setting determines whether the list should include reportings that have not been marked for invoicing.

#### Summarize costs
This setting determines how reportings should be summarized on invoice bases.
You can choose from the following options:
-   
No – costs are not summarized
-   
By cost type/employee
-   
By cost type/employee/activity
-   
By cost type/employee/date
-   
By cost type/employee/activity/date

#### Pre-select “Release”
This setting determines whether all rows in a list should be pre-selected for release. The setting is activated by default.

#### Group rows by
This settings determines how rows in the list should be grouped. You are able to select multiple options for how the list should be grouped. The rows will be grouped in the same way on the invoice basis.

#### Grouping text variables
With this setting you decide which grouping text should be shown in the list. Variables are loaded automatically when an option is chosen in the Group rows by setting. You can also leave the field empty, add text, or write your own text.
> The grouping text is visible on the invoice document.

#### Sort rows by
Here you can decide how rows should be sorted. The following options are available:
-   
Reporting date / Consecutive number – Sorts by reporting date followed by consecutive number.
-   
Consecutive number – Sorts by consecutive number.
-   
Cost type number / Reporting date / Consecutive number – Sorts by cost type number, then reporting date, and finally consecutive number.
-   
Cost type number / Consecutive number – Sorts by cost type number and then consecutive number.
