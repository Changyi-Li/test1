### Recording terminal
- If operations have been replanned to reporting batches in the Priority planning procedure, then these will be shown with a unique background color in the Include column in the recording terminal. When you select a work item, the other operations in the same reporting batch will automatically become selected.
- In the list of work in progress there is a new button called Material reporting you can use to report material. By using that button, the operator can perform the material reporting for direct work in progress, if the operator has sufficient user rights in oder to report material. In the material reporting window you can enter reported quantity, which is used to suggest the corresponding quantity for all materials linked to that operation. The operator can also enter a quantity on a part row or on location rows to report only that specific material. There is a function which suggests the remaining quantity for all materials. Then the operator first gets the opportunity to select for which operations this should be done. This is especially useful when material is partly withdrawn via pick list and the rest should be reported via recording. In the material reporting window there is also a function you can use to only show material with remaining quantity and a function to show all locations. It is also possible to change the remaining quantity for part rows.
- It is possible to report measuring data via a link when reforming partial reporting of work, finish work, and for active work.
