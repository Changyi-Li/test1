### Header and Footer (section settings)
In the Header table you add one or several rows which form the header in the section of the report.
In the Footer table you add one or several rows which form the footer in the section of the report.

#### ID
In this column you see an ID for this row in the section.

#### Type
Here you select which type of row it is. The following types are available:
- Total – This type shows a total. In the Total type and Total expression fields you can select and possibly also edit the total/summary.
- Text – This type only shows the heading text you enter in the Text field.
- Chart – This type will present the data rows in the section in a chart. If you select this type a window will appear where you can configure the chart. You can then at any time open this window using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_chart.png) to the far right on the row.
- Line – This type shows a delimitation line (separating line).

#### Column exception (C)
By clicking the button Column exception ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you can on rows of the Total type, add exceptions for the column contents. This makes it possible to total different contents in one and the same column in a section. After clicking the button you can also configure which column should have exceptions by selecting the column to show instead.

#### Text
In this column you see/enter the heading to be displayed on the row. Texts are not shown on rows of the type Line.

#### Translations
By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Total type
If the row is of the type Total then you can choose and configure how to total the row. The following options are available:
- Total entire section – This option means that all data rows in the section will be totaled.
- Custom total within section – With this option a window will open where you can select which data rows in the section to total.
- Custom total – With this option a window will open where you can select which data rows in all sections to total.
- Total to this section – This option means that all data rows in all sections above will be totaled.

#### Total expression
If the row is of the type Total then it is here possible to edit, if needed, the total expression you get from the selected Total type.
