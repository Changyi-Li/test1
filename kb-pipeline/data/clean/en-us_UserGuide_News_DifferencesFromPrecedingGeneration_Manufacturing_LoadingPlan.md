### Loading plan
- Loading / Work Center and Loading Selection have been merged into one, the procedure called Loading plan.
- Other sectioning (in G4 it was called series).
- Values regarding loading/capacity are shown under the bars in the chart.
- Loading is shown as bars and capacity as a line in the same chart.
- It is possible to replan the operation's start and finish dates/times by typing in other digits under the List tab.
- It is possible to see multiple time horizons in the same chart (day, week, month) since the loading is shown as a percentage in relation to the capacity.
