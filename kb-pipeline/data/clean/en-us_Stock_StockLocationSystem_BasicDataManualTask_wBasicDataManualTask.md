## Basic data – Manual task
In this procedure you create templates for manual tasks for the stock personnel. You create manual tasks in the Recording terminal or Priority plan – Stock in the mobile client. These tasks are then available for the storage/stock personnel to start in the Priority plan – Stock in the mobile client. A "manual task" means a work item that does not involve a stock transaction, for example, cleaning the storage, or emptying metal scrap, etc.
Manual tasks can have different priorities which means they have to be completed within a certain number of hours.
