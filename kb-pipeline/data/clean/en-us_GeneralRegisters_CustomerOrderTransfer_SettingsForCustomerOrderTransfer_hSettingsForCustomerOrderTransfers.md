### Header row

#### Setup number
Here you enter a unique number for a new setup of settings. You can also select a number if you want to load an existing setup. If you create a new setup of settings, default values will be loaded. However, these can be changed if needed. This field cannot be left empty. You can also create a new setup by clicking the button Create new ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_new.png) (Ctrl + N) on the toolbar of the procedure. The setup number is alphanumerical and can contain a maximum of 20 characters.
You create and change these settings in the sales company.

#### Name
Here you can write a descriptive text as a name. You enter name texts in the company language and they are displayed in the user’s language.
The text can consist of a maximum of 35 characters. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.
