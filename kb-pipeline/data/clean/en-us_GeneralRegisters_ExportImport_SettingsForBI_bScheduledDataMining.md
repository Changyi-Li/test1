### Scheduled data mining
In this box you add rows to schedule data mining for the business intelligence at different occasions and with for example different companies or data sources.

#### Active
Here you determine if the data mining should be active.

#### Name
Here you enter the name of the data mining.

#### Schedule
Shows the scheduling selected in the settings.

#### Last run
Shows the date and time when the last data mining was run.

#### Number of years
Here you see the number of years configured in the settings.

#### Number of companies
Here you see the number of companies included in the data mining.

#### Number of data sources
Here you see the number of data sources included in the data mining.

#### Created and Created by
Here you see by whom the data mining was created and when.

#### Modified and Modified by
Here you see by whom the data mining was modified and when.
