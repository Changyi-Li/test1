### Preview
In this box you can preview the selected document variant to see how it looks in the different document groups (per language) in the system. You can zoom the document variant by using Ctrl + the scroll wheel or the scroll percent in the lower part of the box.

#### Document group
Here you select language on all headings and phrases in the document variant.

#### Data source language
Here you decide in which language the data source should be displayed.

#### Data sources
Data sources are records from different registers that you can choose to display information from on the selected document variant. The data source window can also be used as a floating window. This is made by clicking the button in the top right corner.

#### Refresh
The Refresh button is used to manually refresh/update the preview of the selected document template.
