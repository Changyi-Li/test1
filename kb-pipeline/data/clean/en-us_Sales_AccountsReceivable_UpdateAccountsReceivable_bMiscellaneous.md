### Miscellaneous
In this box you see miscellaneous information about the accounts receivable records.

#### Customer group
The customer group is loaded from the customer for new accounts receivable records, but this can be changed. The customer group affects the standard accounts, if any, used when posting the invoice. The field will be locked for a new accounts receivable record if you mark the checkbox Posting in the Posting box. If you need to change the customer group before you save, you must uncheck the checkbox.

#### Comment
Here you can enter a comment for the accounts receivable record.

#### Bookkeeping list
The bookkeeping list shows gathered information about the transactions for the accounts receivable record, not only postings but also its payments and rectification vouchers, if any. The transactions must be entered in journals, that is, they must have a journal number to be shown. At the bottom of the list you see totals of the debit and credit columns. The information under the button is about the same as in the Payments list in the Accounts receivable list.

#### Cancellation comment
When deleting an accounts receivable record, you can enter a cancellation comment. This comment can then be seen here.

#### Country
The purpose of this field is to subsequently adjust the country on an invoice for the Intrastat Intrastat is the system which gathers statistics relating to trade in products within the European Union. Gathering of Intrastat statistics is handled in the same way by all EU member states. reporting. It is not possible to enter a country when you register new records in this procedure or for invoices which do not have underlying orders. If it is a comprehensive invoice it might be linked to multiple delivery addresses and multiple countries, then you will instead see a button where you can change the addresses that need to be modified.

#### Original invoice number
Shows the original invoice number for invoices that have been imported with Monitor Import, meaning that ledgers have been imported from a different ERP system and contains a number series that is not handled in Monitor ERP (e.g. alpha-numerical).

#### Factoring
Here you see if the invoice has been exported to the factoring company via the factoring integration, or not. If the checkbox is activated, it means that the invoice has been exported.
