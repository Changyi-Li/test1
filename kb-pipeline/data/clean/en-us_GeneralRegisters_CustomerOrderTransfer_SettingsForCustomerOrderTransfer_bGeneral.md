### General

#### Block changes from sales company at following status or higher
With this setting you decide at which order status the customer order rows in the production company will no longer be possible to change if changes are transferred from the sales company. The most common case is that the customer order rows will be blocked for editing after the order confirmation has been printed, that is, when the order has been given status 2 in the production company.

#### Allow disconnecting of customer order row
This setting determines if it should be possible to disconnect customer order rows. You can then empty the field Transfer profile on a customer order row in the production company. However, in the sales company you can always empty this field on the customer order row. When disconnecting, the link between the companies will be broken. Any changes made on the disconnected customer order row in the production company will not be transferred to the sales company. It is not possible to disconnect a remote configured row in the sales company because it would then not be possible to see the remote configuration for the part.
> Consequences when disconnecting customer order rows When a transfer profile is removed on an order row, either in the production company or in the sales company, the transfer profile will not be removed on the same order row in the other company. If a customer order row has been disconnected in the production company and then changes are made on the same order in the sales company, a new customer order row will be created on the order in the production company. This is made since the transfer profile remains on the order row in the sales company. If a customer order row has been disconnected in the sales company and then changes are made on the same order in the production company, an error message appears during transfer to the sales company. This occurs since the transfer profile remains on the order row in the production company but the order cannot be found in the sales company.
