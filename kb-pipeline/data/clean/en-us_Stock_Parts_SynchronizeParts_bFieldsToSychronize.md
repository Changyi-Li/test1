### Fields to synchronize
Here you select which general data to include for the part in the synchronization for the selected schedule. This is data fields on the header row and under the General tab in the Part register. You can select data for new and existing parts. By default, all alternatives are marked to be included in the synchronization. You can have multiple schedules with different settings regarding which data to include.
The field called Other part identities is only synchronized if there is an other part identity for the part in the receiving company.
The Configuration group and Remote configuration, supplier no. fields are only used with both options Product configurator and Customer order transfer. The synchronization of these fields are made from the production company to the sales company. In the Remote configuration, supplier no. field you enter the production company's supplier number in the sales company. The sales company also has the production company's supplier number selected in a transfer profile.
During a synchronization a supplier link is created on the part in the sales company with the entered supplier number, if that supplier link did not already exist. The supplier link will also get the Remote configured setting activated.
But no configuration group will be synchronized for the part. The part only has the configuration group in the production company. The purpose of this is to prepare so that new and existing parts in the sales company can be remote configured on customer order rows created in the sales company.
The data on supplier links which will be synchronized is: the supplier's part number, price, unit, purchase comment, dock, storage, brand, and alloy cost.
The data on customer links which will be synchronized is: the customer's part number, price, unit, pick instruction with linked files, if any, GS1 code, and quantity for lead time.
