## CRM view
This procedure works as a hub, an information center, for a seller, sales manager, or multiple sellers. If you have not selected any seller/sellers, then information will be displayed for all sellers.
In this procedure you can see activities, customers, statistics, quotes, customer orders, and invoices that are relevant and linked to the selected seller/sellers. You can e.g. easily see which quotes, for selected seller/sellers, that have valid through dates that are about to expire.
By using the function button Go to procedure ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png), you can for these records go to the related procedures. For example, you can from a quote go to the Customer register, Register quote, and Quote list procedures. Via a customer order activity you can go to the Register customer order procedure. From a project activity you can go, for example, to the Project register.
Using the button Floating ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_float_window.png) (Ctrl + U), you can unpin a box and thereby make it a separate window. It is possible to change size of the window and move it around on your computer monitors.
