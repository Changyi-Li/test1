### The Reporting tab
This tab becomes available when you have started the stock count under the List tab. Here you enter the result of the stock count.
You can enter the stock counted quantity, select revision and enter a comment for the reporting.
With the Add new row at the end button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_row.png) (or F5), you add a new row where you enter the balance of a part that is missing from the stock count basis.
With the Delete selected row button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_delete_row.png) (F6), you can delete the marked row you have added.
With the Find & replace button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_change_record.png) (Ctrl + H) you enter a value to search for and a value to replace with.
With the Add location button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_subrow.png) or Shift + F5, you add a row with a new location to the article that is marked.
If the part has traceability, the button called Add serial number/batch ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_batch.png) is activated. You can use this to add rows and enter the stock reported quantity as well as the batch number/serial number respectively for the existing or for a new location. To add a new location you first use the button above.
If you perform a stock count for a location again in the same list, a dialog is shown. In the dialog you can select whether the new balance should be added to the previous one, or whether the new stock count will replace the previous one.
You can use the button Export stock count basis ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_export.png) to export the rows that have not yet been reported to a .csv file.
> If a dialog is shown asking if you want to convert the ID column in excel, you should choose NOT to convert. If the column is converted, the risk is that it will not be possible to read correctly when importing to stock count in list. It is not possible to add parts or locations other than those on the stock count basis.
The button Import stock count basis ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_import.png) makes it possible to import a stock count basis that has been exported previously (.csv file). This makes it possible to perform the stock count in an exported list and then import it again and report the stock count to Monitor ERP.

#### If you apply stock count approval
When you save your reporting, the rows that need to be approved are excluded, according to the settings in the General approval settings procedure. These lines are marked for later approval and the rows become locked for further changes. The signer/approver can then approve/reject these rows in the Stock count difference procedure, in the Approve stock count list type. The signer/approver can receive a message in Tasks that there are stock counts to approve. You activate this notification in the General approval settings procedure.
