### Posting
In this box you will see the posting of the outgoing payments under the List box.
If needed, you can modify the posting before the confirmation is made. The information on the posting rows is the same as on the posting rows e.g. in the Register supplier invoice procedure.

#### Total accounting order
If you check this box, a total posting will be shown for the outgoing payments in the list. If the box ix checked, it is not possible to modify the posting.
