### 序列号的库位 / 位置
每个序列号可以已分配一个 库位 / 位置 在里面 序列号 / 批次 程序。可用的备选有部门、工作中心和员工。交给分包商的设备必须有以下类型的工作中心 外协。
![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/TrainingMaterial/LocationSite.png)
然后在多个地方使用库位 / 位置以预留的方式显示设备或在特定情况下显示有趣的设备。

#### 序列号库位列表
在里面 序列号库位列表 程序，你可以基于设备的库位 / 位置查看设备。有关设备状态的信息都汇总在列表中。这样，你就可以轻松查看每库位 / 位置有“问题”的设备。
[![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/TrainingMaterial/SerialNumberLocationList.png)](../../../../Resources/Images/TrainingMaterial/SerialNumberLocationList.png)
[![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/TrainingMaterial/SerialNumberLocationListExpanded.png)](../../../../Resources/Images/TrainingMaterial/SerialNumberLocationListExpanded.png)

#### 已计划的维护
库位 / 位置也很有用 已计划的维护 程序。排序、筛选和分组都很简单 库位 / 位置。你可以在此处使用功能来 [组列表](../../GeneralFeatures/GroupLists.htm)。例如，你可以创建一个分组，在其中你每部门或每工作中心的维护。这对于坐标工作很有用。
[![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/TrainingMaterial/PlannedMaintenanceGrouping.png)](../../../../Resources/Images/TrainingMaterial/PlannedMaintenanceGrouping.png)

#### 记录终端
在里面 记录终端 程序，你查询一个名为 工具信息。通过使用此按钮，你可以看到记录操作员放置的工具或操作员打卡的工作中心的工具。你还可以看到取出在制的工具。这样做的目的是轻松查看当前设备的状态。操作员可以从窗口中的工具链接到组件登记和序列号登记。你还可以报告维护并创建案件以订单维护。
[![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/TrainingMaterial/ToolsLocationRecordingTerminal.png)](../../../../Resources/Images/TrainingMaterial/ToolsLocationRecordingTerminal.png)
