## Phrases
In this procedure you can register an optional number of phrases for different purposes. The phrases can be inserted in:
- Comment windows.
- Row type 4 on orders.
- Text fields containing multiple rows, for example, Additional name in the Part register to avoid typing the entire text manually.
In the comment windows and next to the text fields you will find the button called Insert phrase ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_phrase.png). This button is used to insert one of the registered phrases. Phrases are saved per company.
If you use EIM, you also have the Messages in EIM tab where you can predefine messages which can be used when authorizing supplier invoices.
