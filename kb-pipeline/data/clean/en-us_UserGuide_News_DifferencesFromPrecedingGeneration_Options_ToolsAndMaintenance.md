### Tools & Maintenance
- Since tools are handled in the Part register in G5, the standard procedures are used to perform physical inventory/stock count of tools.
- In the procedures Stock count in list and Stock count difference you can use the selection alternatives Part template and Basic type to load lists of tools.
- In certain procedures you will see icons indicating the row refers to a tool.
- In G5 you can define multiple maintenance templates and via maintenance plans these can be linked to a tool. In G4 you can only enter an instruction and a set of measuring points linked to a tool.
- In the Form templates procedure there is a tab where you can preview and print a document which shows the form. In the Report maintenance procedure there is also a tab where you can preview and print a document as a record of the data you reported. Both documents are available in the Document templates procedure where you also can create your own versions of the documents.
- The procedure Report maintenance corresponds to the procedure Calibration Reporting in G4 and is used to report different types of maintenance, including calibrations. In G4 there is only one type of reporting.
- Maintenance types is a new term in G5. You find the Maintenance types table in the procedure Basic dataWith "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Maintenance and is used to create a structure of codes. These codes are then used for follow-ups on maintenance types.
- Color codes according to Swedish standard used for calibration of measuring tools are included in the system but these can be modified, if desired. In the procedure called Basic data – Maintenance, you can update and change color codes, if desired or required.
- You can link an optional number of maintenance templates to a tool. This means you can for example have one template for annual maintenance and another template used for an emergency repair.
- Tools that are linked to operations in the Preparation in G4, will be converted to material rows in G5. The tools are converted after the regular material rows. If there are multiple tools for an operation, it is the row number in G4 which decides how it is sorted in G5. The tool quantity is converted to setup quantity on the material row. If there is a description, this will be converted to an instruction of the material row. Number of details in the procedure Update Tool in G4 is converted to the material row's field Quantity per cycle.
- It is possible to make exceptions per work center for the settings Exclude from automatic reporting of tools and Exception from Suggest withdrawal of tools at start of operation. These can also be seen an updated in the Work centerA work center is a part of the factory. It can be a single machine or a group of machines, a single workstation or a group of workstations. list procedure.
- The Serial numberA serial number is a number that is used for traceability for parts on entity level. location list displays an overview of serial numbers and their status. The overview consists of a structure map grouped by the location/site of the serial number. The top level shows if the serial number/tool is with us, at a supplier, or at a customer's location. You can then choose which levels to show in the structure map. Levels possible to choose are: Location, Work center, Employee, and Department. For each serial number you can see its status.

In the Recording terminal there is a button where you can see information about the tool. The tools displayed to the employee are:
- Tools withdrawn to operations in progress on which the employee is recording.
- Tools marked with "Work center" as location/site for the operations in progress.
- Tools marked with "Employee" as location/site.
- Register maintenance order is a procedure where you register and update maintenance orders for your tools and machines. Maintenance orders are used to plan and report time and material for different types of maintenance. A maintenance order is always linked to a serial number on which the maintenance is carried out, and a maintenance template which describes the operation.
When a maintenance order is registered you can choose to use operations and material from any part, as well as utilize variant codes and configured parts. This enables you to register maintenance orders seamlessly. When the maintenance order has been saved, operations and material can be supplemented and modified, and instructions can be added.
Maintenance orders are a type of manufacturing order, and are based on the basic type Maintenance. If needed, you can create multiple order types for that basic type. This is done under the Manufacturing order tab in the Order types procedure. Since maintenance orders are a type of manufacturing order, you report time and material in the regular reporting procedures for manufacturing orders.
In the Report maintenance procedure there is a form where you report maintenance.
For purchase of maintenance – for example, calibration of measuring tools – the maintenance order must include a subcontract for the calibration.
