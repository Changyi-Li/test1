### Communication
In this box you configure to which recipients the message should be sent as well as when. The message is sent when the monitoring term has been fulfilled.

#### Notification type
With this setting you determine if the message should be sent via Notification or E-mail. If you choose notification, the message is available in the Notifications window, in the Message center on the title bar in Monitor ERP. If you choose e-mail, the message is sent via e-mail.

#### E-mail
Here you enter the recipient's e-mail address if you have selected e-mail as notification type.
> You must enter one e-mail address as e-mail sender in the system setting E-mail sender for result e-mail. You must also configure the system settings Server address (Exchange/SMTP) and Port (Exchange/SMTP).

#### User
Here you select to which user you want to send the Notification.

#### Language
Here you determine the language of the e-mail message. The default language is the company language.
