### Case management

#### Create case/internal nonconformity at rejection of operation
This system setting determines if a case/internal nonconformity should be created at rejection of operation. The following options are available:
- No – No case is created.
- Yes, always – A case of the type selected in the Default case type settings is always created at rejection of an operation.
-    
Yes, with question – A dialog opens when rejecting an operation where you can change case type but can also close the dialog and reject the material without creating a case.
> Please note! When the Yes, with question option is active no case will be created for rejections in the Recording terminal. The dialog is only shown in the Report manufacturing order and Report operation procedures.

#### Default case type
This system setting is activated if the system setting above has been set to one of the Yes alternatives. This system setting determines which case type should be set as default.

#### Create case/internal nonconformity at rejection on material
This system setting determines if a case/internal nonconformity should be created at rejection of material.

#### Default case type
This system setting is activated if the system setting above has been set to one of the Yes alternatives. This system setting determines which case type should be set as default.
