### Return order
By clicking the Go to procedure button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) on the function menu, you can go to the Register return order procedure to register a return order (a purchase order with a negative quantity) based on the case in question.
Information that is automatically loaded from the case to the selection in that procedure is: supplier (supplier nonconformity), parts, purchase order for initial delivery (supplier nonconformity), alternatively purchase order for initial purchase (customer nonconformity, 8D). The case number is entered automatically for the purchase order rows which have been selected for the return order.
When the return order is saved in the Register return order procedure, it will here be shown on a row if you update the case by using the Reload button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_refresh.png) (Ctrl + Shift + R) on the toolbar of the procedure. On this row you then see the information from the return order.
When there is a row here with a return order, you can also use the Go to procedure button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) to go to the Register purchase order procedure with the return order already loaded.
