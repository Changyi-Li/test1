### Resulting user rights
Here you can see the resulting user rights for the user for each type of record.
The resulting user rights are generated by the settings in the boxes Roles, User rights groups and User-specific user rights. If you change a setting for a user right, you will see an orange star ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/orange_snowflake.png) here for the user right in the column to the far right in the box. This is shown until you save.
