### Header row

#### Invoice number
Here you enter the invoice number in the accounts receivable. If you want to load an existing accounts receivable record, you should here select an invoice number. You can also search by customer order number if the invoice is created via a customer order. If you want to add a new accounts receivable record you can either enter the invoice number or leave the field empty. If you leave the field empty, the next available invoice number will be loaded from the number series.
Below the field you will see, for example, if the invoice example is fully paid, partially paid, unpaid, or canceled.

#### Customer
Here you see/enter the customer of the invoice. You can select customer when you add a new accounts receivable record. If you have entered an invoice amount and then marked the Posting checkbox, then it will no longer be possible to change customer. If you uncheck Posting, all rows in the box will disappear. Not until then it is again possible to change customer. Also, you cannot change the customer of an existing accounts receivable record. The name of the customer is displayed to the right of the field. For accounts receivable records without orders, the customer name is alsways shown.

#### Order number
If the invoice is created via a customer order, that is, if it is created in the normal way via the invoicing procedures, you will here see the order number.
