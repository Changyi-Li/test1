### User rights according to warehouse
Roles, user rights groups, and user-specific user rights, which you register for a user are saved per warehouse level. You change warehouse by using the warehouse selector ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_warehouses.png) on the toolbar of the procedure. For example, a user could be a Purchaser in one warehouse and a Planner in another Warehouse.
In cases where the user should have the same user rights in all warehouses, you should here choose to synchronize the user rights between the warehouses for the user. You synchronize the the user rights by using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_change_record.png) next to the Synchronize user rights checkbox. You then get to select on which warehouse the user rights should be based.
After you have synchronized, the checkbox will be marked and the ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_change_record.png) button is not shown. If you later on modify a user right of the user in one of the warehouses, that user right will automatically be synchronized to the other warehouses when you save.
If you wish to end the synchronization of user rights for the user, you deactivate the Synchronize user rights checkbox.
