### Response times
In this table you register response times. Response times are used to describe the different response times in number of days that apply to inquiries.

#### Default
Here you determine if the response time should be used default when registering new suppliers.

#### Number
Here you can see the number for the position of the row. This field is numerical. A new row will by default be assigned the next available number. The table/list is sorted by this column. A number is unique and cannot occur on more than one row in the table.

#### Name
Here you enter a name for the response time. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Number of days
Here you enter the number of days for the response time.
