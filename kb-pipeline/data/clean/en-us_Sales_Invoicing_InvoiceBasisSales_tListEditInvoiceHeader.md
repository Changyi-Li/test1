### The Edit invoice header list type
This list displays the information found in the invoice header. The list can be made possible to edit via the ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_edit_list.png) button on the toolbar. This enables you to edit information for invoice bases with status For invoicing, Preliminary, and Pending. It is, among other things, possible to mass-update the statuses of the invoice bases using the ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_replace.png) Change status button in the function menu.
