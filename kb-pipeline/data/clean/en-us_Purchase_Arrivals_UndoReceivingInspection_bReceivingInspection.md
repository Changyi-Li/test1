### Receiving inspection
In this box you can see a list of receiving inspection reportings that have been made for purchase orders.

#### Undo
Check this box if you wish to undo receiving inspection for the order.

#### Information
The error symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/error.png) will be shown if the receiving inspection cannot be undone for different reasons. When you hover over the symbol, a tooltip will display the cause in text form.

#### Reported by (user)
In this column you can see the user name that performed the receiving inspection.

#### Reported by (person)
In this column you can see if an employee from the personnel record is linked to the user who reported the receiving inspection.
