### Settings

#### Also show inactive forecasts
With this setting you determine if inactive forecasts should also be loaded. This setting is not activated by default. If you do not check this setting, only active forecasts will be loaded.

#### Used staggered price
With this checkbox you determine if staggered prices should be shown in the list.

#### Price alternative for forecasts with customer
Here you can select which price alternative which should be used in the calculated amount (quantity × price) in the list. The default option here is Customer price, but it is also possible to select Price list or Standard price.
If you select the option Price list, you can then select which price list to use in the next field.
If the price is in another rate type than the company currency, this can be selected in the Rate type field. The default rate type here is determined by the system setting Default rate type (for Sales, not for Stock).
If you select the Customer price option, the customer linked price for the forecast rows which have a linked customer, will primarily be used. Secondarily, the price will be loaded from the customer's price list (in case there is no customer linked price for the part).

#### Price alternative for forecasts without customer
This setting mirrors the setting above, but for forecasts without customer. The Customer price option is not available for this setting.
