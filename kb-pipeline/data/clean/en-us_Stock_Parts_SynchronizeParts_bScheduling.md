### Scheduling
Here you create one or several schedules for synchronization of parts between companies. Each schedule can have specific settings regarding transfer profile, selection of parts, and part fields that should be synchronized.

#### Active
With this checkbox you determine if the synchronization in question should be active.

#### Name
Here you can write a descriptive text as a name. You enter name texts in the company language and they are displayed in the user’s language.
By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Schedule type
Here you select schedule type Time or Time interval.

#### Changed
Here you determine if only parts that have been changed and new parts added since the last synchronization should be synchronized.
> Make sure that all selected parts have been synchronized at least once before you activate this setting.

#### Days
If you have selected schedule type Time, you select on which days the synchronization should be made.

#### When
If you have selected schedule type Time, you select the time when the synchronization should be made.

#### Interval
If you have selected schedule type Time interval, you enter a time interval for the synchronization in minutes.

#### Transfer profile
Here you select a transfer profile. Transfer profiles are registered in the Transfer profiles procedure.

#### Run
The synchronization can also be run manually by using the button Run ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_run.png).

#### Runs
By clicking the Runs button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png)you access a log where you can see the most recent synchronizations. Here you find information about status, progress, type of run (automatic/manual), user name who started the run (displays "TRANSFER" if it is an automatic run), start time, end time, duration, selected parts, affected parts, sent parts, parts with problems, new parts, and a log.
