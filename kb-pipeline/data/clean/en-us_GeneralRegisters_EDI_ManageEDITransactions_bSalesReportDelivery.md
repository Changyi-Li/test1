### Sales – Report delivery
In this list you see EDI EDI is the acronym of Electronic Data Interchange. EDI is about exchanging electronic business documents with your business partners, e.g. customers and suppliers. The EDI concept can be wide and a bit unclear, and can many times be used about all types of documents which are sent electronically, even if it might be PDF files sent via e-mail or publishing business documents on a website. What we refer to as EDI – and what is traditionally meant by EDI – is structured business documents following given standards, electronically sent or received and which are compiled and interpreted automatically and that is integrated with the customer's/supplier's ERP system. business transactions of the Customer order delivery reporting type. These are loaded from imports of reported deliveries via EDI file. The information in the list and the buttons on the function menu also exist under the List tab. If a transaction is completed, this is shown in the Status column as Finished ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/StatusFinished.png). Here you can also see row status for the customer order rows in each transaction. Row status shows errors ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/error.png) and warnings ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png) if it occurs on some order row. If all order rows are ok, nothing is shown.
In the Report delivery information, Rows, and Matching order rows boxes, you see data for the business transaction marked in the list. In these boxes you adjust the business transaction if errors occur. If there are any errors an error symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/error.png) appears. When you hover over the symbol, a tooltip displays the error in text form.
You can also unpin the Rows and Matching order rows boxes and use them as floating windows. This way the box will be larger and you get a better overview.
When you have adjusted a business transaction, the transaction status is set to Corrected ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/StatusRegistered.png). You can then run the transaction again by using the Start transaction button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_run.png).
