### The list type Administer supplier links
This list shows the parts' supplier links. The list can be grouped by part number or supplier.
By clicking the Updateable button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_edit_list.png) (Ctrl + U), you can load the list and update/modify information in the supplier links on multiple parts. This corresponds to what you can modify per part in the Supplier links box in the Part register procedure.
The first column Default is checked when the supplier is default for the part.
You use the list to delete existing supplier links. If you delete the default supplier link from a part, the next supplier link will automatically become default.
Mark the checkbox in the Delete column for the supplier links you want to delete for the respective parts.. You execute the deletion by using the Save button on the function menu. A control question is first shown where you confirm the deletion of the link/links.
If distributed purchase is applied for the part, you cannot delete any supplier links. An error message ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/error.png) is displayed if you mark the Delete checkbox for a supplier link.
> If you load the list without making it updateable, you can see which parts are missing supplier links. Then the supplier name will be "Supplier link is missing". Use the presentation called Group by supplier to show the parts without supplier links in the first group in the list.
