### Miscellaneous

#### Fixed assets category
Here you can enter a fixed assets category. By clicking the Category selection button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png), you can select a category if categories have been registered in the Categories procedure. If no categories are registered, you can type as you please in this field. Categories can be used as a selection term in different lists. Read more about how categories can be created/constructed in the online help function for the [Categories](../../../GeneralRegisters/Categories/Categories/wCategories.htm) procedure.

#### Work center
Here you can enter the object's link to a work center.

#### Department
Here you can enter the object's link to a department. Department is suggested based on the work center entered in the above field.

#### Serial number
In this field you can enter a serial number for the fixed assets object.

#### Location
Here you can enter information about where the fixed asset is located. You can type a text here or you can choose among locations registered in the procedure Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Fixed assets register.

#### Used by
Here you select the person who is using the fixed asset. You select from records in the personnel records.

#### Responsible
Here you select the person who is responsible for the fixed asset. You select from records in the personnel records.

#### Event log
This log displays event which have taken place regarding the fixed asset, for example depreciation. All changes to the object which relate to depreciation, or which will affect future depreciation, are saved in the event log – that is, modified acquisition values, depreciation periods, depreciation method, etc.
The log is used to get information and traceability, but is also used as a basis for calculating acquisition value, accumulated depreciation, and residual values at a certain date in the past (via the fixed assets list).
The events that are logged are:
- Scheduled depreciation
- Calculated depreciation
- Extra depreciation
- Changed acquisition value
- Undone scheduled depreciation
- Undone calculated depreciation
- Activated investment.

#### Budget object
With this checkbox you determine if the fixed asset in question is an object which is used for simulation of future years' depreciating. If the budget object box is checked, then is it possible to enter a future acquisition date.
