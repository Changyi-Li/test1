### The List tab
The list is loaded and displayed based on the selection and settings you have chosen. As in all lists in Monitor ERP, you can drag and drop in order to change the column to group by.
The list contains main rows that have been arrival reported, that is, no sub-rows or text rows will be included. It is in normal cases not possible to update anything in this list.
> You can update the Delivery date in the list if you have a user-specific user right to do so. Please note! Permission to change delivery date should be limited to very few persons! This permission is not given to anyone by default.
The information in this list can also be viewed in chart form in a bar chart. This can be done via the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_chart.png).
