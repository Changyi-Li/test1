### 报价

#### 登记报价
登记一个新询价或修改现有的查询报价。可以根据报价生成客户订单。
[![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/TrainingMaterial/CustomerOrderFlow1.png)](../../../../../Resources/Images/TrainingMaterial/CustomerOrderFlow1.png)
> 在里面 客户订单 你可以在框中查看报价是否已转化为客户订单。

#### 打印报价
使用打印机打印询价或通过Email发送。你还打印直接报价 登记报价 程序。
> MONITOR提示！ 在下面 活动 标签页你可以日志与报价有关的活动。 使用 报价列表 程序来MONITOR您的报价。 使用 报价统计 视图前道报价统计的程序. 使用 子号码 (相关报价)登记报价的版本.
