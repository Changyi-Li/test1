### Desktop
The desktop in Monitor ERP is the main window. The user interface is clear and flexible. It contains different menus, tool bars, and functions.
From start, the desktop shows different background images, determined by the color range/theme you have selected. You can also create desktop configurations and fill the desktop with interactive desktop components showing different types of information.You find desktop configurations and color range/theme under the headings Desktop and Settings in backstage. Read more about [Desktop configuration](../GeneralFeatures/DesktopConfiguration.htm).
You can minimize the desktop window or partially reduce the size of it. If the desktop is minimized or reduced in size you can still see, open, and close procedure windows as usual since these are not locked to the desktop. When you restart Monitor ERP, the desktop will be shown in the same size and position, as well as on the same screen, as when you were last using Monitor.
At the top of the desktop you find the title bar. To the left on the title bar you find the buttons Window (1), Message center (2), Clipboard (3), and the Find procedure field (4). In the middle of the title bar there is a section (5) where you see in which company, database number, warehouse, accounting year, and period, you are working. Your user name is shown at the end of the text section. To the right of the text section on the title bar you find the User settings button (6) and a help button (7) which opens the start page for the online help function. Next to it you see a field for Monitor search (8) which is used to search for records in the entire system.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/TitleBar.png)](../../../Resources/Images/UserGuide/TitleBar.png)
At the top left on the desktop you find the Backstage (1) function. In the backstage there are different functions and settings. Next to backstage you find the Module menu (2) with a button for each module. There you find all procedures to which you have access.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/Backstage_ModuleMenu.png)](../../../Resources/Images/UserGuide/Backstage_ModuleMenu.png)
To the far right on your Monitor desktop you find a button for the news component called Monitor News ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/MonitorNews.png). Read more about [Monitor News](MonitorNews.htm).
Read more about the functions in [Title bar](TitleBar.htm), [Backstage](BackstageDesktop.htm) and [The Module menu](ModuleMenu.htm).
