### Scheduling
Under this tab you can activate that the system automatically should run a project calculation in the background at certain given times. Calculation is made for costs, income, and time. This takes place for all projects except for the ones with status 9 (Historical). In addition to the scheduled times/occasions, a project calculation is also made automatically in the background when you load a project in the Project register procedure. Project calculation can also be performed via the procedure Project follow-up.

#### Active
With this checkbox you determine if the scheduled project calculation should be active.

#### Logging
Here you decide if the logging of calculations should be activated or not. Under the History button you see the logged items.

#### History
By clicking this button a log is shown containing the calculations made. The information shown here is what time it was when the calculation started, how long it took, and how many projects were calculated.

#### Run calculation
By clicking this button you can manually run the calculation. When a project calculation has been started, a message will appear at the bottom right corner informing you of this.
