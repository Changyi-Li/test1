3. 当客户连接到 Crediflow 时， 分配模式 字段自动设置为 电子发票。如果你希望操作员负责全部发票的分配，包括Email和纸质发票，然后你可以通过选中复选框人工的将客户连接到操作员 通过运营商分配。然后，你输入操作员应使用哪种分配模式将发票分配客户：Email或纸质发票（已打印）。请注意！纸质发票/PDF 可能还涉及每发票的附加成本。如果你希望将附件（已链接文件）与发票一起发送，你需要激活设置 [将嵌入的 PDF 附在 XML 中](../../../GeneralRegisters/ExportImport/SettingsForExportImport/tExport.htm#E-faktura) 在您的电子发票导出设置中。此类已链接文件/附件将按照你为发票已选择的相同方式进行已分配。
4. 这 电子发票地址 (EIA) 当客户连接到 Crediflow 时会自动加载到字段。请注意！即使分配模式设置为Email/纸质发票，也强制的输入EIA。由于 XML校验采用 Peppol格式，因此需要输入此项。Peppol发票已发送 Monitor ERP 给操作员，即使操作员反过来通过Email/纸质打印分配发票，仍然必须完成校验，订单你被已允许创建Peppol发票。
5. 在里面 电子发票地址 ID (EAID) 字段你查询以下选项：企业 ID 号、 GLN 号或VAT 登记号。如果客户有GLN 号，这将是用作 EIA 和 EAID 的第一个。如果不，则将使用企业 ID 号作为标准。如果客户连接到 Crediflow，则会自动加载。
输入客户的企业 ID 号和VAT编号是一个好主意。如果客户的电子发票地址 (EIA)和操作员代码不存在，Crediflow 将使用客户名称和VAT 登记号来开具发票。
