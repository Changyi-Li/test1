### Breaks
In this box you add the breaks which should exist in the schedule.

#### Start and End
In these columns you enter the start time and the stop time of the break. The total break time for all breaks you add here is shown under the table.

#### Paid
With this checkbox you determine if the break should be paid. This means no time will be recorded for the work in progress during the break, but the entire break will be counted as attendance.
If the schedule has flex zones for schedule start and schedule end it is not possible to add a paid break within the negative flex zones of the schedule.

#### Flex start and Flex end
Here you decide if flex time should be allowed in connection to the break. If so, you should here enter start time and end time for the flex zone. You can leave these field empty if flex time does not apply. Then you must also leave the field Min. break empty.

#### Minimum break
Here you enter the minimum break time allowed when using flex time. Enter the flex time in minutes. The minimum break (Min. break) is the shortest break allowed for the personnel.
The break time entered here will be registered in the recording if an employee records a break shorter than the minimum break time.
If the minimum break is shorter than the regular break then the person can get positive flex for the time difference between regular break time and the recorded break time.
Example: The regular break is between 12:00 PM and 13:00. The minimum break is 30 minutes. The employee clocked out for break at 12:00 PM and clocked in again at 12:35. This means the employee will receive 25 minutes positive flex time.
If the break is paid, the minimum break time allowed becomes equal to the regular break time and this field becomes unavailable.
