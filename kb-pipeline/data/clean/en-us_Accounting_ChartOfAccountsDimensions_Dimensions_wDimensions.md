## Dimensions
In this procedure you can define different dimensions you can post on. The dimensions you register and name are found in many procedures of the system. For example, you will find them in all posting windows, in vouchers, lists, and reports.
Monitor ERP handles up to fifteen posting dimensions.
When you register new dimensions they will automatically be included in for example posting windows, selection rows (containing dimensions) and more. However, new dimensions will not automatically be included in lists or reports in the system. For these to be shown, you need to add the new dimensions in the configuration for the list in question.
For example, if you add a new fourth posting dimension and want it to be shown in the general ledger, then you need to configure the general ledger to make the new column appear. For journal printouts, new dimensions are automatically added in these documents.
> Tip! In order to fit the dimensions to the documents you can change the Orientation setting for the document from Portrait to Landscape. This is done under the Accounting tab in the procedure called Document settings. This will then apply to all journal documents and to the Accounting order document. A more advanced solution is to adjust the templates of the documents to allow space for the dimensions to fit. Such adjustment should in that case be made in the Document templates procedure, but this requires you to be knowledgeable in DevExpress Report Designer.
You can also create Dimension groups for dimensions. The purpose of this is to be able to group multiple dimension codes in a dimension to a superior term to use for reporting purposes. You can create dimension groups for different business areas, or different project types such as, for example, customer projects, fixed assets projects, or development projects.
In this procedure you can also register basic tables with the dimension codes which should be available to register on in each dimension. This is done in the box called Dimension codes. If the dimension is linked to a register you will instead see the codes available to record on in the dimension, for example the project table.

#### Would you like a more in-depth follow-up of the accounting?
You can get a more in-depth follow-up of the accounting by using automatic posting on dimensions linked to the following registers:
- Part
- Part code
- Product group
- Customer
- Supplier
- Work center A work center is a part of the factory. It can be a single machine or a group of machines, a single workstation or a group of workstations.
- Department
- Employee
- Customer group (on customer)
- Customer district
- Customer type
- Supplier group (on supplier)
- Supplier district
- Supplier type
The purpose is to be able to analyze, follow up on, and measure profitability on a more in-depth level, based on the posting of the above mentioned terms. To post on one of the registers above, you register it as a separate dimension. You then activate which accounts should be posted on that dimension in the Chart of accounts procedure. It is also possible to budget by these dimensions in the accounting.
