### Initial posting
In this box you enter terms for automatic allocation to be generated. This is a fixed table with rows displaying the posting dimensions used in the system.

#### Dimension
In this column you see/enter the dimension which the row concerns. The dimensions listed here are the ones registered in the Dimensions Dimensions are used by large companies in their accounting in order to divide up activities and make it easier to track internal results. An account is a dimension, although large companies usually use the dimensions cost center (CC), cost unit (CU) and project. In addition to these you can create other dimensions in Monitor ERP based on your own operational follow-up. procedure.

#### Filter
In this column you select if a filter should be used for the dimension. The following options are available:
- No filter – This option means that automatic allocation will be generated regardless how the dimension has been posted. For example, the automatic allocation will take place regardless if you enter a cost center in the initial posting or not.
- Is between – With this option an automatic allocation becomes generated when you post on a specific dimension code or an interval of dimension codes. For example, automatic allocation will take place if you post on cost center 10, but no automatic allocation will take place if you post on another cost center or without a cost center.
- Is not empty – This option means that automatic allocation will be generated when you post on a dimension code. For example, automatic allocation will take place if you post on any cost center, but no automatic allocation will take place when you post without using a cost center.
- Is empty – With this option an automatic allocation will be generated when you post without a dimension code. For example, here automatic allocation will only take place if the cost center is empty.

#### From and To
These columns are available for the Account row and for dimensions which have the filter set to Is between. You can enter as of which account/dimension code (From) and up to and including (To) which account/dimension code the automatic posting should apply. These fields can not be left empty.

#### Project status
This column is available for the project dimension for the types Period balance and Accumulated balance. Here you can enter which project status should be automatically allocated. You can choose more than one project status.

#### Project type from and project type to
The columns are available for the dimension project for the types Period balance and Accumulated balance. You can enter as of which project type (From) and up to and including (To) which project type the automatic allocation should apply.
