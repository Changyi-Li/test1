### Invoices
In this box you see the supplier invoices that are posted (final recorded) on the project in question. All supplier invoices which have been final recorded (except for canceled invoices) are displayed, that is, unpaid, partially paid, and fully paid invoices. The information is loaded from the accounts payable.
From the row in the table you can go to the Register purchase order procedure via a link or by double-clicking the record.
Using the Show document button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_form_viewing.png), you open the document in a separate window. There you can also reprint the document or attach it to an e-mail message.
By using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_goto_critical_op.png) you can choose to only show invoices with remaining amounts.
