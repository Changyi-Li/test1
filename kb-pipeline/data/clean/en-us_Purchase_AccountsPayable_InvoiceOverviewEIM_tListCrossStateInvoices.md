### CrossState invoices list
This list displays information about e-invoices and interpreted invoices if you have activated CrossState (digital invoice flow). The list contains raw data loaded from CrossState, such as invoice header, invoice rows, and application settings. This information is useful if you want to review invoice details or if you have questions regarding how the invoice has been processed in CrossState when in contact with the Monitor Support Center.
The Standard presentation displays the main information from the invoice. The Standard rows presentation displays details about the invoice rows which is particularly useful if you work with EIM Workflow and thereby interpreted invoices at row level, but you will also see rows which are imported from e-invoices. In the Application settings presentation, you see the application settings which were applied when the invoice was loaded via API.
