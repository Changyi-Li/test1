### Agreements

#### Handle suspended output VAT when invoicing in advance
Here you determine how suspended VAT should be handled during payments of advance invoices.

#### Default VAT code used for suspended VAT
Here you enter the VAT code to use if you use suspended VAT when invoicing advances.

#### Copy "Customer's agreement no." to "Customer's order no." on the agreement basis
This setting determines whether the Customer’s agreement number should be copied to the Customer’s order number field on the customer order when agreement bases (customer orders) are released. The following options are available:
- No (default) – The customer’s agreement number is not copied.
- Yes – The customer’s agreement number is copied to the Customer’s order number” field on the customer order.
