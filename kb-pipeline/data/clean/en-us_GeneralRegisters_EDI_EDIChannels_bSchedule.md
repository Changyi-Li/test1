### Schedule
In this box you configure the selected schedule with time records.

#### Active days
Here you select on which days you want to run the schedule.

#### Active times
Here you add one or several rows with active time records for the schedule. This applies to each active day. You can select start time and end time for the schedule as well as interval and time unit. If you only want to run the schedule once, you only enter a start time. The schedule is then only run once at this specific time during the active days.
A check is made to make sure that the entered end time is not earlier than the entered start time. A check is also made to ensure that time intervals in different time records do not overlap.
