### Information
In this box you enter basic information about the person.

#### Image
Here you can add an image file, for example a photo of the person in question. The image size can be a maximum of 100 x 100 pixels. If the image file is bigger, a message is shown letting you know the image needs to be cropped. The most common file types are supported, for example png, jpg, gif, and bmp. This image will then be displayed on the person's contact card where it occurs in the system.
Personal information

#### User
Here you can link the person to a user by selecting the user name in the field. If another person in the personnel records already is linked to the selected user, then you cannot link the person to the user in question. You also receive a message about this.

#### Personal identity number
Here you can enter the person's personal identity number. With the regulations on processing of personal data, e.g. GDPR, in mind, consider whether it's necessary to enter the personal identity number here. You are likely to already have entered the personal identity number for the employee in the payroll system.
> Please note that a personal identity number must be entered in order to active Bank integration.

#### Department
Here you select the department to which the person belongs.

#### Title
Here you enter the title of the person.

#### Category
Here you enter a personnel category to which the person should belong. By clicking the Category selection button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png), you can select a category if categories have been registered in the Categories procedure. If no categories are registered, you can type as you please in this field. Categories can be used as a selection term in different lists. Read more about how categories can be created/constructed in the online help function for the [Categories](../../../GeneralRegisters/Categories/Categories/wCategories.htm) procedure.

#### Signature
By using the Signature button, you can select an image of the person's signature. The most common file types are supported, for example png, jpg, gif, and bmp. You can use signatures on documents where the person in question is Our reference. This way you do not have to manually sign printed documents. For it to be possible to insert signature images, you must also add Signature via a tag in additional texts for different documents in the Document texts procedure.
> Please note! Don't make the signature image file too large, that is, the signature should not be to large (in pixles). We recommend a height of 40–50 pixels. This way the signature will not be too big large.
> There are two types of signatures, the image type which you add here and which then works as a signature on different documents. And the text signature with date and time which you can insert in comment boxes and on text rows (row type 4).

#### Blocked
Check this box if you want to block the person from recording (attendance and work), as well as from reporting measuring data. The name of the user who blocked the person as well as the date when it was performed will be highlighted red.

#### Project exceptions
Under this button you can create exceptions that exempt users from the default settings for cost types in the Basic dataWith "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Project procedure. Under Part for invoicing, you can determine whether a part should be selected by default on invoice bases. Under Hourly cost, you can enter whether another hourly cost should be used when the user creates reports linked to the cost type.

#### Available as
-   
Reference – Check this box if the person is a reference person in the company. The person will then be selectable in Our reference fields in different procedures.
-   
Seller – Check this box if the person is a seller in the company. The person will then be selectable in Seller fields in different procedures.
-   
Purchasing agent – Check this box if the person is a purchasing agent in the company. The person will then be selectable in the field Purchasing agent for the supplier in the supplier register.
-   
Planner/Production engineer – Check this box if the person is a planner for a work center or administrator for a part. In fields where you can select a planner or production engineer, you can use the LookupThe Lookup feature is a powerful search tool which allows you to search and load information from large registers. You open the Lookup feature by clicking on the dropdown button or by using F4 on your keyboard. feature to find employees for whom this box has been checked.
-   
Responsible for customer – Check this box if the person is responsible for customer. In fields where you can select a person responsible for customer (customer register), you can use the Lookup feature to find employees for whom this box has been checked.
-   
Authorized signer – Check this box if the person should be possible to select as authorized signer on supplier invoices in the Register supplier invoice procedure. This setting is not available if you use Electronic invoice management (EIM). Then all signers are registered in the Authorization settings – EIM procedure. There you also configure different authorization settings such as authorization lists, authorization limit exceptions, and user rights to view invoices.
-   
Project manager – Check this box if the person is project manager. The person can then be selected as project manager the Project register and Basic data – Project procedures.

#### Permission to start new chat
Here you decide if the employee is allowed to start new chat conversations in the Monitor chat to other employees at the company. Employees who have this setting deactivated can only reply to chat messages in existing conversations.
