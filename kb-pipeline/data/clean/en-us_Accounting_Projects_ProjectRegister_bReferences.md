### References

#### Our reference
If a customer order number has been selected on the project you will in this field see Our reference loaded from the customer order, if a reference has been selected there. If the project is created from a customer order, Our reference will be loaded from that customer order. If there is no link to a customer order you can in this field select Our reference among the persons in the company who are registered as references in the personnel records.
If the logged in user (in the system) is linked to an employee (which is a reference) in the personnel records, then that person will be suggested provided that the reference is not loaded from the customer order. If there is no such link, the person most recently entered as reference in the procedure by the user in question will be suggested.
The button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) displays information and contact information for the person after you have selected a name in the Our reference field. From here you can also start a chat session with the person in question.

#### Customer's reference
In this field you see/select the customer's reference who is linked to the project. If no customer or customer order has been selected for the project, then it is not possible to here choose a person as the customer's reference.
If a customer has been selected for the project, then the customer's reference from the customer register will be suggested. If a customer order number has been selected for the project, then the customer's reference from that customer order will be suggested. If the project is created from a customer order, the customer's reference will be loaded from that customer order.
The button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) displays information and contact information for the person after you have selected a name in the Customer reference field.

#### Description
In the text box Description you can enter a description of the project in order to quickly see what the project concerns.
The text entered here is then possible to search by in the Monitor search.
