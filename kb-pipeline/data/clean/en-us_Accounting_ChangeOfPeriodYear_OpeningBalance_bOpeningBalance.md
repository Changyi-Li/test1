### The table with opening balances

#### Warning
In this column you can see warnings that exist for the row. For example if the posting already exists in the list.

#### Account
In this column you see/enter the number of the account. It is also possible to enter accounts which in the chart of accounts are configured as blocked for manual posting.

#### Name
Here you see the name of the account. The account names are displayed in the user's language.

#### Dimensions
The dimensions are shown in separate columns. It is not mandatory to enter for example Cost center even though it is configured this way in the chart of accounts. If the application of the dimensions have been set to Yes or Mandatory, this means that the fields are available, otherwise they are grayed out.

#### Opening balance
In this column you see/enter the opening balance. The system recognizes which currency has been configured for the account from the chart of accounts. If you enter a value in the credit or the debit columns, this field will be updated.

#### Debit
The column is filled in automatically if you enter a positive amount in the Opening balance column.

#### Credit
The column is filled in automatically if you enter a negative amount in the Opening balance column.

#### Created/Modified by
In this column you see who created or modified the OB.

#### Date
Here you see the date when the opening balance was created/modified.

#### More info
By clicking the More information button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you also see exchange rate and quantity. Quantity can be handled if the account has been configured like that in the chart of accounts. The default rate type for the currency is defined in the system settings.

#### Total
At the bottom of the box you see totals of the debit and the credit columns. The difference between these are shown at the very bottom of the window. It is possible to save even though a difference exists.
