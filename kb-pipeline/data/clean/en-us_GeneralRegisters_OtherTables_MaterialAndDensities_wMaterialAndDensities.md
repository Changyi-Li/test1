## Material and densities
This procedure is used to add and delete material densities. These are used during weight calculation of different materials included in parts for which BOM and routing is created.
In the BOM and routing procedure there is a weight calculation function for material rows. When calculating weight you can select among the materials available in this procedure, or you can enter an optional density for a specific material profile.
The weight calculation function is also available in the Part register procedure. You find it under the Manufacturing tab under the Miscellaneous heading. The weight calculation there works as a template which has values already entered. It can be used for weight calculating material rows in BOM and routing and in manufacturing orders.
Read more about weight calculation in the online help function for the mentioned procedures.
