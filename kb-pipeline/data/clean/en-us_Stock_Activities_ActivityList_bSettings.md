### Settings

#### Activity type
Here you determine which activity type should be displayed. You can select several activity types.

#### New responsible user
If you want to change responsible user for the activity, here you select new responsible user. When you want to find activities for a specific responsible user, you should use the selection row Responsible user.

#### Performed by
Here you select who performed the activity. The default option here is your user.

#### New reported date
Here you can select another date for the reporting than today's date. Today's date is selected by default.

#### Show log window when finishing activity
Here you determine if the log window should be opened when an activity is finished.

#### E-mail
Here you can enter a default e-mail address to send the activity list to, if you choose to send it by e-mail.

#### Pre-select "Include"
This setting determines whether or not the “Include” box should be checked by default for all rows in the list/result.

#### Preceding activity finished
When this setting is activated, you will only see activities that are ready to be started. This helps make sure that the work is performed in the correct order and makes it clear for you what is next to be done in the process.
