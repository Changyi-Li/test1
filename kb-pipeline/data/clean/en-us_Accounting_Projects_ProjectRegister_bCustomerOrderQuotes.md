### Customer order/Quote
The information in this box is already entered if the project has been created via a quote or customer order. Otherwise you can enter the information manually.

#### Customer
Here you enter/select a customer to link to the project in question. This field is automatically entered if an order number is entered in the next field.

#### Order number
Here you enter your order number used on the customer order which is or which will be linked to the project. If a customer has been selected in the preceding field you will only see customer orders registered for the customer in question. By using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you can see information from the order header.

#### Add to existing order when invoicing
This setting is available if an order number is linked to the project. The setting determines whether rows should be automatically added to the order number when an invoice basis is released in the Release invoice basis – Project procedure.

#### Customer's order number
The customer's order number is loaded from the customer order selected in the preceding field, and it can be edited here.

#### Seller
Here you select your seller registered for the customer or for the customer order in the preceding field, and it can be edited here.

#### Order type for invoicing
Here you can decide which order type you want to use when invoicing from the project. The default order type is the order type entered in Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Project:.

#### Project discount
A discount that is automatically applied to order rows when projects are linked to a quote, order, or invoice.
