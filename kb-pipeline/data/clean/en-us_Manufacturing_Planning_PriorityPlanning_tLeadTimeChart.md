### The Lead time chart tab
This lead time chart displays the work center's operations graphically in a "Gantt chart". The operations are loaded from existing manufacturing orders in the priority plan. The work center and each operation have a separate row. To the far left you will on each row find information regarding manufacturing order, part and operation.
The operations are displayed as red blocks along the horizontal time axis. The block representing the work center is purple.
If you hover the cursor over the block for the work center, a tooltip will show the planned start date for the first operation, planned finish date for the last operation, planned and reported Total time, and remaining total time.
If you hover the cursor over a block for a specific operation, a tooltip will show the planned start date, planned finish date, planned and reported total time, and report number.
Using the navigation buttons ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_goto_left_leadtime_chart.png) ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_goto_right_leadtime_chart.png) on the rows, you can in a quick and easy way go to the block for an operation which is outside the visual section of the time axis.
Please note that any filtering and settings made on the main row also affect the lead time chart and not only the priority plan.
You can visually replan and move the blocks along the time axis by dragging and dropping the block and then saving. It is also possible to extend or shorten the time of an operation by clicking and getting a hold of one end of the block (the start or the finish time) and drag it with the pointer.
By activating the Replan the entire order button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_replan_order.png) on the function menu, the entire manufacturing order will be replanned when you replan one of the operations.
By using the Go to procedure button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) on the function menu, you can go to related procedures for the marked operation.

#### Scale
Here you can select the scale of the lead time chart. You can configure it as displaying per days or per week. The lead time chart saves the most recently used scale for the next time you open the procedure.
