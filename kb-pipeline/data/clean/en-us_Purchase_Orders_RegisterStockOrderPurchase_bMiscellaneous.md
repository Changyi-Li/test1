### Miscellaneous

#### Status
The status of the stock order can be selected manually, but certain statuses are set automatically by the system at different events. However, you cannot manually select status 9, (final delivery made). An order that is delivered in full (final delivery made) can only be edited by first changing the status to 1, 2, or 5.
- 1) Registered – This is the default status for new stock orders that you register.
- 2) Printed – This status is given when the stock order is printed and the printout has been approved. The order will also get a printout date, and a printout log will be created per document.
- 5) Partial delivery made – This status is given when an order row has been fully or partially delivered (arrival reported).
- 9) Final delivery made – This status is given when all order rows have been arrival reported, (0 in remaining quantity).

#### Confirmed
This box can be checked if the stock order has been confirmed by the other warehouse (supplier).

#### Currency
The currency on the stock order is always shown in the company currency.

#### Order date
The order date is set to today's date by default. You can modify the order date for the stock order in question. The date entered here is then set by default as order date on the order rows.

#### Warehouse
Here you see the order's warehouse which is the receiving warehouse. The suggested warehouse is the warehouse you are working in. It is possible to choose another warehouse except for the sending warehouse that is selected on the main row. When you have selected a part on the order row, you can change receiving warehouse by using the button Change warehouse ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_change_record.png). However, you can only change warehouse as long as you have not saved. When you save, the linked stock order for sales will also be created. The order's warehouse must also be linked to a customer. This is configured for the warehouse in the Company information procedure.
