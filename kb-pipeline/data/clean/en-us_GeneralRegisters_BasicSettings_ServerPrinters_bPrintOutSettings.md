### Printout settings

#### Printers
For Locally installed printers, you select the printer driver that should be used for the server printer. You can select among the printer drivers that are install on the computer.
> Please note! The selected printer driver must be installed on the application server in Monitor ERP.
For PrintNode printer you select a printer.

#### Printer's e-mail address
For E-mail based printer, you enter the address to where the printout should be sent.

#### Orientation
Here you determine if the orientation should be Portrait or Landscape.

#### Duplex
Here you determine if it should be possible to print on both sides of the paper. The available alternatives are Flip on long edge and Flip on short edge.

#### Paper size
Here you determine the paper size of the printout. You can select A4, A3, A5, or Own.

#### Width
If you select paper format Own, you must set a width in millimeters.

#### Height
If you select paper format Own, you must set a height in millimeters.

#### Color/Black and white
Here you determine if the printouts should be made in black-and-white or color. If you select Color, the printer driver must support color printouts.

#### File path
This field is activated if you have selected Microsoft Print to PDF as printer for this server printer. Here you can in that case select a file path to where the server printer's printouts are always saved. You can select one of the active file paths that are registered in the Paths procedure. If no path is selected here, the user will instead choose where the server printer's printout should be saved every time it is used.

#### Location
Here you can enter, for example, where the printer is placed/located.

#### Comment
Here you can enter optional information which can be of help.
