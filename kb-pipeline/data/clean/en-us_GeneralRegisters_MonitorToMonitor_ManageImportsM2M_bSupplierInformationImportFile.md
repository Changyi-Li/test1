### Supplier information – Import file

#### Order number
The purchase order number from the import file.

#### Supplier's order number
The supplier’s order number from the import file. A warning will be shown if the supplier’s order number from the import file does not match the supplier’s order number on the purchase order in Monitor ERP.

#### Supplier number
The supplier number from the import file.

#### Name
The supplier’s name from the import file.

#### Our customer number
Our customer number from the import file.

#### Our customer name
Our customer name from the import file.
