### 应收账款列表

#### 列表类型付款
回想起来，你就可以看到你给了客户多少现金折扣。这显示在名为“付款”的列表类型中。在下面 选择 标签页，你可以使用选择板条款 销账 选择现金折扣的销账代码。
在列表中，你可以在列中 销账金额 看看给出了多少折扣。
[![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/TrainingMaterial/AccountsReceivablesList.png)](../../../../Resources/Images/TrainingMaterial/AccountsReceivablesList.png)

#### 列表类型分类账 - 详细
在此列表中你可以看到未付款发票，并且标准配置不显示有关现金折扣的任何信息。但是，你可以在后台使用以下列列补充列表：
- 现金折扣 % (限制1)
- 现金折扣日期(限制1)
- 现金折扣 % (限制2)
- 现金折扣日期(限制2)
- 现金折扣 % (限制3)
- 现金折扣日期(限制3)
