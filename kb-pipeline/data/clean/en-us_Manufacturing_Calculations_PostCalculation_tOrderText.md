### The Order text tab
Under this tab you find comments and additional texts linked to the marked manufacturing order in the post-calculation. The tab can be used to see if anything worth noticing has occurred during the manufacturing, that is, events that might affect the order but which cannot be measured in other ways.
The tab is divided in a list of manufacturing orders and three boxes: Customer order, Order comment, and Operation comments. You can unpin the boxes (box by box) by using the Floating button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_float_window.png) (Ctrl + U) and make them floating windows if you, for example, want to increase the box size.
Customer order
In the Internal comment section you find the internal comments for customer orders which are linked to the manufacturing order. If there is a linked addition text row to a customer order row, you can read it in the Linked text row section.
Please note! If there are several linked text rows to the customer order row the manufacturing order is displayed on two rows when it is loaded in the post-calculation. Each of those additional text rows linked to the customer order row, are shown on own rows.
Order comment
The manufacturing order’s comment is shown here. In this section there is a text editor which you can use to edit and format texts and insert images.
Operation comments
Here you see comments for operations in the manufacturing order.
