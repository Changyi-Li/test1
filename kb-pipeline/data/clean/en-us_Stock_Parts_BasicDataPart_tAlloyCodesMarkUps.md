### Alloy codes/Mark-ups
Under this tab you can enter alloy codes and mark-ups. You can create an own list of alloy codes and keep it updated.
Alloy codes for stainless steel are tradition within certain trades. It is used as an addition to the regular price. The price is updated each month based on the world-market price of alloying metals. Mark-ups can be e.g. environmental mark-ups.

#### Alloy code
Here you enter the alloy code of the additional fee, using a maximum of 10 characters.

#### Name
Here you see/enter the name of the alloy code. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Price
In this column you enter the price for the alloy code. This price should always be entered in the company currency. A maximum of 6 decimals are allowed.

#### Unit
Here you see/enter the unit in which the alloy code should be measured. You handle the units under the Units tab.

#### Service part
The service part which should be used for the alloy code on the order.

#### Modified
Here you can see which user who most recently modified the alloy code. The date and time when the modification was made are shown in the column to the right.
Under the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) to the far right, you find a log over all modifications made of the alloy code. Here you see who made the modifications as well as when. You can expand each log record and see what has been changed, the value before and after the modification.
