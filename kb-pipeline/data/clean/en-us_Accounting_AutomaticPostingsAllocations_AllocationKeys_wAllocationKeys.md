## Allocation keys
In this procedure you create allocation keys. The allocation keys can then be applied for automatic allocation in the Automatic allocations procedure.
An allocation key functions as a template in order to allocate costs in percentage terms, for example, among cost centers or cost units, when you apply it to automatic allocation. If you later on make changes in an allocation key which is used in automatic allocation and save in the procedure, you will receive a question if you wish to update the automatic allocation where the allocation key is used. If you click Yes to that question, a window will open where you can choose which automatic allocation items to update.
In an allocation key you add one or multiple allocations in percent for the dimension codes. The total percentage distribution must be 100.
