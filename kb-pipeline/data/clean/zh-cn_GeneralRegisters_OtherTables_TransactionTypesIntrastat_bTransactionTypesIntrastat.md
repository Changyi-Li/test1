### The Transaction types – Intrastat table

#### Default
Here you determine which transaction type should be set as default on customer order rows and purchase order rows.The first transaction type (1) is marked as default.
The transaction type selected for the order type in the Order types procedure, overrides which transaction type will be set as default on order rows with this order type.The transaction type can also be selected manually on order row.This will then be saved and apply to the order row in question.

#### Transaction type
Here you see/enter transaction type.This is an numerical field.

#### Name
Here you see/enter the name of the transaction type.You can use a maximum of 100 characters.
