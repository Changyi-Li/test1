### 记录
当你在页眉输入员工号/卡片代码并按下输入或标签页键时，终端将打开记录模式。在里面 记录 然后显示的章节，你可以记录您的出勤、缺勤和工作。
当你上班/签下班，记录终端将自动撤消所有到基本模式。
根据你输入的员工号是否已允许两者记录出勤和工作（员工）或仅工作（设备），记录模式下会显示不同的按钮。如果仅可已记录仅工作，则全部出勤功能将被未激活。请阅读低于以阅读更多相关内容。
你可以使用数值键盘上的加号（+）和减号（-）键来时钟上班和下班。常规的加号和减号键也工作（许多笔记本电脑没有数值键盘）。
出勤和缺勤记录
表格中描述了可用于出勤和缺勤记录的不同按钮。或不显示取决于您的日程表、时段和参数组。是否以及你记录加班和缺勤也由您的参数组决定。
| 钥匙 | 描述 |
|---|---|
| 上班 - 加班 | 打卡上班 - 加班——日程表开始之前加班、正数弹性时间区之前、日程表结束之后、正数弹性时间区之后、正数弹性时间区内加班。这取决于您的参数组。然后你必须在对话框中选择要用于的加班类型。您的参数组决定是否已允许记录加班（加班限制），以及在日程表之前多少分钟记录加班时间（加班限制）。 |
| 在 (+) | 打卡——在日程表开始之前，在弹性时间区内（结果正数弹性时间或负数弹性时间）。当在日程表开始之前打卡时，如果您的参数组允许加班，你可以选择或不已记录加班。如果你选择记录加班，然后你选择使用哪种加班类型。 |
| 休息后上班(+) | 打卡上班 – 在休息弹性时间期间打卡休息之后。根据你在休息弹性时间期间时钟的时机，将结果正数弹性时间或负数弹性时间。它也受到日程表中的最短休息时间的影响。如果你在休息弹性时间期间之后时钟上班，你为休息弹性时间期间之后所经过的时间选择一个缺勤代码。 |
| 上班 - 缺勤 | 上班打卡–负数弹性时间区缺勤，如果您的参数组允许在负数弹性时间区记录缺勤。然后，你必须在对话框中选择要使用的缺勤代码。此记录不结果在负数弹性时间区内经过的时间内出现负数弹性时间。 |
| 缺勤后上班(+) | 打卡上班 –之后已多于小时。如果您的参数组中已激活了缺勤检查，则此功能可用。然后，你必须在对话框中选择你缺勤的工作日的缺勤代码。你还可以选择一缺勤代码，输入列出的全部缺勤工作日。你选择“自时间银行领用”的时间不能更多您的余额所能支持的天数。 |
| 上班 - 迟到(+) | 打卡——日程表开始之后，值低于区之后。如果您的参数组中已激活了缺勤检查，则此功能可用。如果弹性时间余额少于已允许的最低限制，则在日程表开始之后你时钟时会显示一条消息，让你知道不允许弹性时间。 |
| 下班 - 休息（-） | 下班 - 休息 –在弹性时间区内休息。如果您的日程表中存在弹性时间休息期间，则此功能可用。对于弹性时间余额过低的员工，也已允许记录午餐时间。当员工结束休息时进行检查。休息过长将结果必须选择缺勤代码。 |
| 下班 - 缺勤 | 下班 - 缺勤（无论时段）。然后你必须选择一个缺勤代码。如果你的参数组允许在负数弹性时间区内记录缺勤，并且你在负数弹性时间区内下班缺勤，然后你可以选择缺勤是否应从现在应用（不结果今天的任何负数弹性时间）或从下一个工作日适用（将结果今天的负数弹性时间）。 |
| 下班（-） | 下班打卡——日程表结束之后，在弹性时间区内（结果正数弹性时间或负数弹性时间）。在日程表结束之前或在负数弹性时间区之前打卡下班与下班缺勤的结果相同。 |
| 下班 - 加班 | 下班 - 加班 –日程表结束之后、正数弹性时间区之后、正数弹性时间区内的加班。这取决于您的参数组。然后你必须选择要使用的加班类型。您的参数组决定是否已允许记录加班（之后分钟） 。 |
计划缺勤非整天
如果有计划缺勤并且你在该时间下班，则会出现一条消息通知你计划缺勤已经已开始。系统设置 计划缺勤的时间限制 (分钟) 确定已允许在计划缺勤之外进 / 出多少分钟而不被视为已计划一以外的缺勤。
站点记录
如果系统设置调用 激活站点记录 勾选后，每个时钟你休息下班你时间你选择一个站点。站点是指你时钟的手动计划库位。你登记在 基本数据表 - 出勤 程序。在出勤列表和疏散列表中，站点订单显示全部上班的员工和全部休息时登出的员工当前所在的位置 - 即在建筑物内还是其他地方。
如果您的员工号有默认站点– 或者记录终端有默认站点– 该站点将显示在以下按钮上： 在， 上班 - 加班， 下班 - 休息， 和 休息后上班。加班打卡时，对话框中有两个步骤：选择加班类型，然后选择站点。
如果否为员工或记录终端已选择默认站点，则已建议的打卡站点将是你最近上班的站点。如果你不想在已建议的站点时钟，请点击 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/Site.png) 记录按钮到右边的按钮。然后会打开一个对话框，你可以在其中为相关的记录选择不同的站点，当你在该对话框中确认后，你便可上班。
使用 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_show_in_google_maps.png) 中间的按钮，你在上班、休息登出、登出时间变更站点。例如，你五月想要在午休休息进城办事时变更站点。如果你想在你登出但仍留在大楼内时选择一个站点，这也很有用。例如，如果你日之后去公司健身房。当你使用此按钮时，尽管你登出，你仍会留在疏散列表上。请注意，如果你选择了一个站点并且登出，你将一直留在这个站点直到你下一个时钟。
在记录终端顶部，你的名称下一个模式记录以下符号 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/Site.png) 并有文本描述已选择的站点。如果你已登出，则会显示“未选择记录站点”文本，除非你已使用蓝色按钮已选择了站点 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_show_in_google_maps.png)。
设备记录
如果输入了设备的员工号，则记录终端在记录模式下的设计会略有不同。如果应用“签署员工号”然后还应输入操作员的员工号。通常此人就是此刻操作设备的员工。阅读更多内容 [设备记录](MachineRecording.htm)。
| 钥匙 | 描述 |
|---|---|
| 开始(+) | 打卡设备。然后就可以采用与记录员工工作相同的方式已记录工作。 |
| 停止 (-) | 下班设备。当使用设备记录时，这意味着当操作员休息或停止工作时，必须已停止设备或记录间接工作，订单正确已记录工作。否则，将日24小时已登记时间。 |
工作记录
如果你已经打卡，你可以在记录模式下选择记录工作。
| 钥匙 | 描述 |
|---|---|
| 添加到批次 | 如果你有批次已记录在制，则此按钮可用。使用此按钮你转到开始直接工作模式，仓储费用你向批次中添加其他工作事项。 |
| 开始工作 | 通过此按钮，你转到开始工作模式，在模式中你可以选择开始直接或间接工作。 |
| 停止工作 | 如果你有处理中的直接或间接工作项目，则会显示此按钮。使用此按钮，你可以变更为你停止（完成）在制的模式。如果你下班（例如，当你日离开时）并且有工作事项处理中，然后它将自动已停止。当你下一个然后时钟时，工作事项将自动开始。 |
如果你有一个工作事项处理中或工作待机，那么盒子中的记录模式会有不同的功能 在制。阅读更多内容 。
