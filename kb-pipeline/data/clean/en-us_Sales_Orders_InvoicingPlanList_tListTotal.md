### The Total list
This list shows totaled information about the customer orders you selected that have an invoicing plan. Each row can be expanded using the drilldown function, and then you can see the detailed information. It is not possible to update any information in this list.
The list is loaded and displayed based on the selection and settings you have chosen. As in all lists in Monitor ERP, you can drag and drop in order to change the column to group by.
