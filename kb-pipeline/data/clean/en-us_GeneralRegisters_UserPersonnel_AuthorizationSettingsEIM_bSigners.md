### Signers
In this box you register the users who should be signers in the company.

#### Signer code
Here you enter a code for the signer using a maximum of 8 characters.

#### User
Here you select the user who should be signer. The user's name and role will be displayed in the columns to the right.

#### Active
A signer is active by default, but you can choose to deactivate the signer. Inactive signers cannot be added to signer groups and authorization lists. It is also not possible to select them for authorization. If you deactivate a signer who is included in a signer group or an authorization list, a message is displayed and you get to confirm that the signer should be removed from the signer group or authorization list.
Please note! It is only allowed to have one active authorization code per user. This means that other authorization codes linked to the same user must be set as inactive.
