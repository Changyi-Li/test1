### Loaded records

#### Annual budget
For import of an annual budget, the following fields are mandatory for the import:
- Account
- Annual budget
The following fields are optional:
- Cost center
- Cost unit
- Project
- Budget chart

#### Period budget
For import of a period budget, the following columns are mandatory:
- Account
- Periods (period 1-x)
The following fields are optional:
- Cost center
- Cost unit
- Project
- Budget chart
In this box you see the records that have been loaded from the file after you have imported it. You can also manually add rows. Which columns you can see in the list depends on how you have configured the format template that is used. In the Show box you can filter which records to show: new, existing, and incorrect.
You can mark the checkbox Include for the rows containing records that you want to save. This way you can save in the procedure and thereby remove the rows which you are finished with, from the list. Rows with validation errors that have not been chosen to include, will remain in the list.
> Please note! The Budget chart field is required in the format template (and therefore it must also exist as a column in the import file) in cases where a budget chart has not been selected for the affected accounts in the chart of accounts.
