### Bank statement rows
Here you see the rows on the bank statement. Rows which are not automatically matched can be matched manually. This is done by dragging the row to the right row in the General ledger entries box. If a record to match with is missing (for example, fees, interests, etc.), you can record that record by clicking the Post button. The system can automatically suggest an offset account for the bank account if a link to the account has been entered for the transaction code in the Bank settings procedure, under the Bank transaction rules tab. If you have activated the setting called "Post automatically" for the transaction code in the Bank settings procedure, the Posting will be marked on the row in the bank statement when auto-matching is made.
If reference information is missing and the transaction has a bank transaction code, you will instead see the name of the bank transaction code in the Reference column.
The Function menu
Use the Run auto-matching button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/StatusFinished.png) if you want to run the automatic matching again. This match is run automatically when you load the file, but if you have made changes to the records and want to run the match again, you should use this button.
The button called Delete selected matching ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_reject.png) is used if you wish to delete a match for the selected/marked record.
Via the Only show unmatched rows button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_goto_critical_op.png) you can filter the rows to only show records which were not possible to match with the general ledger.
The Match manually button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_batch.png) is active if you have marked a record which is not matched. With the use of this function you can be helped by the system to match unmatched records. For example, when one or multiple records in the bank statement needs to be matched with one or multiple records in the general ledger. When you click the button a new window opens where multiple records can be matched with each other.
If a bank transaction rule is missing, you can use the Add/update bank transaction rule button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_create_rule.png) to create a new rule for auto-matching. When you create a new rule, the text from the reference field in the file is loaded to facilitate the registration of a new rule.

You open the Lookup feature by clicking on the dropdown button or by using F4 on your keyboard. feature for existing rules and you can also edit/update existing transaction rules.
