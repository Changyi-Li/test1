### Document texts
- The procedure Document texts in G5 is a merger of the three procedures Language, Form Additional Text, and Payment Reminder Text in G4. These procedures are represented by separate tabs in the new procedure.
- The phrases in the different language tables found in G4 are now found as Document groups in the procedure. It is also possible to create new document groups for language variants. In the Languages procedure in G5 there is a link to a default document groups for each registered language. This way it is easier in G5 to register languages such as British English and American English, which you then link to own document groups.
- What is new regarding additional texts for different documents is that it is possible to insert images in the additional texts.
- Reminder text has been renamed and is now called Payment reminder texts.
- You can see/filter by texts which have been changed in comparison to the original text.
