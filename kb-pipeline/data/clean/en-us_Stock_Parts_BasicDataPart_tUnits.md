### Units
Under this tab, you handle the units. Each unit is entered here as an abbreviation, and you can also enter an explanation. In some fields in the system you will only see the explanation of the unit, e.g. under the Alloy codes/Mark-ups tab in the column Unit. The units that exist when you start up the system for the first time are pcs (pieces), kg (kilos), and m (meters).

#### Default
In this column you decide which unit should be default for a new part you register. If the part you register is linked to a part template, this default unit will be overridden by the unit of the part template.

#### Unit
In this column you can enter the abbreviation of the unit, using a maximum of three characters. You can also modify existing units, delete, or add new units.

#### Explanation
In this column you can enter an explanation regarding the unit. In certain unit fields in the system you will only see this explanation since the abbreviations are very short and can be difficult to interpret.

#### ISO code
The unit’s ISO code is configured for the units included from start in a new system. If you add own units you can here choose among a number of predefined ISO codes that are included.
You can also modify, add, and delete ISO codes under the ISO codes for units tab.
An ISO code must be registered for all units when e-invoice is used in the Electronic invoice management (EIM) option.
