### 目标设置
在这里你查询有关通过以下方式导出的设置的描述 目录， Ftp， 或者 安全FTP 来自已选择的目标。
目录设置
目标类型设置 目录。

#### 路径
在此处你已导出输入文件的目录路径。

#### 文件名称
在这里你输入已导出的文件的文件名称和文件扩展名。文件名称可以包含低于表格根据的变量 文件名称中的变量。
FTP设置
目标类型设置 Ftp。

#### FTP服务器
FTP服务器的地址，例如。“Ftp. 公司. com ”你不在地址开头使用“ Ftp ://”。

#### 端口
在输入你Ftp的端口。标准端口为 21（未加密Ftp的控制渠道）。这是默认已选择。如果你选择 隐式（FTPS） 作为低于的加密方式，端口应该已变更为 990（隐式 FTPS 的控制渠道）。

#### 连接模式
在这里你可以选择是否要进行Ftp连接和文件传输 激活的 或者 被动的。默认已选择被动的。在使用 NAT 的防火墙后面，仅被动的有效。

#### 加密方式
选择Ftp连接是否应采用 SSL 加密 隐式（FTPS） 或者 显式（FTPS）。默认替代方案是 无 (FTP)，即未加密的Ftp隐式加密通常通过端口990 启动。通过标准端口21 启动显式加密。

#### 用户名
在输入你Ftp的用户名。

#### 密码
在输入你Ftp的密码。

#### 路径
在此处你已导出输入文件的目录路径。可以左边。

#### 文件名称
在这里你输入已导出的文件的文件名称和文件扩展名。文件名称可以包含低于表格根据的变量 文件名称中的变量。

#### 端口

#### 连接模式
在这里你可以选择是否要进行Ftp连接和文件传输 激活的 或者 被动的。默认已选择被动的。在使用 NAT 的防火墙后面，仅被动的有效。

#### 加密方式
选择Ftp连接是否应采用 SSL 加密 隐式（FTPS） 或者 显式（FTPS）。默认替代方案是 无 (FTP)，即未加密的Ftp隐式加密通常通过端口990 启动。通过标准端口21 启动显式加密。

#### 用户名
在输入你科目的用户名。

#### 密码

#### 密钥文件
在这里你/输入包含验证密钥的文件的文件名称（包括路径） 。

#### 密钥文件密码
在这里你可以看到/输入密钥文件密码。

#### 主机密钥的哈希指纹
如果你字段空，则在测试来源或目标时，它将自动使用主机密钥的哈希指纹进行已更新。如果你了错误的哈希 指纹 或主机更改了其公钥, 则 在你来源/目标时 ,你测试校验警告, 或者运行时你出现连接错误.调整/纠正这个问题，你应该第一个确保你不主题中间人攻击（MITM），然后空该字段并单击测试以测试来源/目标连接。这将更新主机密钥的哈希指纹。

处理

#### 在目标路径文件
在这里你选择是否应该已删除现有的导出文件或者在将 EDI导入目标之后是否应该将数据已添加到同一文件中。

#### 使用临时文件扩展名
应用至 Ftp 和 安全FTP。你可以在这里确定在文件传输处理中是否应在文件名称中使用临时文件扩展名。当文件传输已完成后，常规的文件扩展名将根据 文件名称 上面。如果接收者使用某个程序定期检查并通过你在FTP服务器上已导出文件的路径加载文件，则会使用临时文件扩展名。避免该程序在文件传输处理中中负荷半成品文件。

暗箱

#### 激活的
在这里你可以确定是否应该使用所谓的“暗箱”。这是一个外部程序，它可以将通过渠道从MONITOR ERP已导出的EDI消息转换为其它格式。

#### 文件名称
黑匣子程序文件(.exe) 的完整路径名称。
如果程序安装在MONITOR ERP服务器上，你输入本地路径。例如“当前日程表图表:\ 程序 文件\Blackbox_folder\Blackbox_file.exe”。
如果该程序安装在另一服务器上，你输入UNC路径。例如“\\Other_server\Blackbox_folder\Blackbox_file.exe”。
文件名称中的变量
在里面 文件名称 在目录设置和FTP设置下 的字段中，你可以根据低于表格输入变量.
| 变量的 | 解释 |
|---|---|
| {日期} | 今天的日期 |
| {约会时间} | 今天的日期和时间 |
| *， {我} | 流水号 |
| {年} | 数字年 |
| {年} | 四位数字的年 |
| {毫米} | 月(01-12) |
| {世界} | 周数（从周一开始） |
| {交货日期} | 日(01-31) |
| {HH} | 小时（24小时） |
| {时} | 小时（12小时） |
| {毫米} | 分钟(01-59) |
| { ss } | 秒 (01-59) |
| {K} | 时区 |
| {公司编号}，{ftgnr} | 公司号 |
> 当你将鼠标悬停在字段中的文件名称上时，会显示一个工具提示，显示如何使用输入的变量来格式化文件名称。
