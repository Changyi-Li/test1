### The Logged in users table

#### User name
Here you see the user name of the logged in user.

#### Description
A description of the user account, e.g. first name and last name or some other adequate description.

#### Created
Here you see when the user logged in and the record was created.

#### Status
Here you see the user's status – active or at rest. A record with status Active is shown when a user logs in to the system. If the user logs in a second time from another unit and chooses to lock the first session (instead of ending it), then the status of the first record will be changed to At rest and a (active) record for the new session will be added. If the user logs out or ends a previous session, the row is deleted from the list.

#### Last active
The last time the user was active in the system.

#### Connected from
The name of the unit from which the user has been connected.
