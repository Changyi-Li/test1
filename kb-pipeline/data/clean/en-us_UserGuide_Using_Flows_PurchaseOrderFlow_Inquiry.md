### Inquiry

#### Register inquiry
Register a new inquiry or modify an existing. It is possible to generate a purchase order from an inquiry.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/TrainingMaterial/Inquiry1.png)](../../../../../Resources/Images/TrainingMaterial/Inquiry1.png)
> In the Purchase order box you can see if an inquiry has turned into a purchase order.

#### Print inquiry
Print inquiry using a printer or send it by e-mail. You can also print inquiries (when you only want to print a single inquiry or so) directly from the Register inquiry procedure.
> Monitor tip! Under the Activities tab you can log activities regarding the inquiry and purchase order. Use the Inquiry list procedure to monitor your inquiries. Create related inquiries to send the same inquiry to different suppliers.
