### Include

#### Only primary inquiry
With this checkbox you determine whether or not only primary inquiries should be displayed in the list. If you uncheck this setting, related inquiries will also be included. This setting is available for the lists Detailed and Total.

#### Only main rows
With this setting you decide whether or not only main rows should be displayed in the list. If you uncheck this setting, sub-rows will also be displayed.

#### Alloy cost
With this setting you decide whether or not rows with alloy costs should be displayed in the list.

#### Rows set as excluded
With this checkbox you decide whether or not to include inquiry rows with the setting Exclude from statistics activated, in the list.

#### Rows turned into purchase orders
With this setting you determine if inquiry rows already turned into purchase orders should be included in the list. If these are included, no value will be shown for them. These rows are shown in italic font in the list.
