## Stock administration
Only the Admin user has sufficient user rights for this procedure.
> Only a few employees should be authorized to use this procedure since changes made here are extensive.

#### Net requirement calculation
By clicking the Cancel NRC button you can cancel an ongoing net requirement calculation or unlock a locked session.
This can be useful if, for example, something has occurred that has caused a server issue during the net requirement calculation. Such an issue could in turn cause a lock-up in the net requirement calculation which makes it seem like a net requirement calculation is running when it is not. In these cases, it is not possible to begin a new calculation unless the lock-up is removed.

#### Traceability
Here, you are able to regenerate the traceability structure if it is incorrect.
By clicking the Regenerate traceability structure button, the structure will be regenerated according to all orders that have transactions with traceable parts.
If the top level in the traceability structure is missing, it is possible to add it here.
By clicking the button Add top level to tracability structure, the highest level in the traceability structure will be added on serial numbers and batches where it is missing. If there are serial numbers and batches on parts that are not traceable, tick the Include parts without traceability checkbox to add the top level in the traceability structure.

#### Locations
This procedure can also be used to reinstate locations that still have a balance and that have been deleted by mistake.
1. Select the part for which the warehouse/warehouses should be restored.
2. In the Restore column you mark the locations to restore.
3. Save.
