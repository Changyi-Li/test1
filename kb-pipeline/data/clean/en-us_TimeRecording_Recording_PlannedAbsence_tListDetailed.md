### The Detailed list
In this list you see the dates for which there is planned absence registered for the selected employees. The list shows employee number, date, and the absence code in each date column. The list shows a question mark on days for which planned absence is applied for, a green check for days with approved planned absence, and a red X on days with denied planned absence. If absence is planned for part of day, an asterisk * is shown as well.
A tooltip is shown when you hover over the absence code, displaying the name of the code.
