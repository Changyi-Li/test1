### Sales account
In the Sales account matrix, you register posting settings for sales. To each product group and customer group coordinate in the matrix there is an account string containing sales account and posting dimensions, to which you select accounts.

#### Posting group
Here you select which posting group you want to work with. The posting groups must first be registered under the Posting groups tab. You can copy an entire matrix from a posting group to another by using the function Save as on the toolbar of the procedure.

#### Product group
Here you see all registered product groups on separate rows in the table. There are several account types for each product group according to the below, for which you configure posting against each customer group.
- Sales – on this row you configure the account string for sales account.
- Material – on this row you configure the account string for cost of goods sold (COGS). The row is only displayed if the system setting Record material cost of goods sold at invoicing has been activated.
- Stock – On this row you configure the account string for stock. This row is also displayed if the system setting above has been activated.
- Setup cost – On this row you configure the account string for setup cost. This row is only displayed if the system setting Posting of setup price is set as posting of the part has been inactivated.

#### Customer group
Here you see all registered customer groups on separate columns in the table. You see Account for each customer group and the dimensions in the account string registered in the Dimensions Dimensions are used by large companies in their accounting in order to divide up activities and make it easier to track internal results. An account is a dimension, although large companies usually use the dimensions cost center (CC), cost unit (CU) and project. In addition to these you can create other dimensions in Monitor ERP based on your own operational follow-up. procedure. When you start up the system for the first time, the following dimensions are available: CC (cost center), CU (cost unit), and Project. If an account does not manage postings of a certain dimension, the field is grayed out. If a dimension is mandatory, you will see information about this in the field. However, under this tab you can leave the field empty.
