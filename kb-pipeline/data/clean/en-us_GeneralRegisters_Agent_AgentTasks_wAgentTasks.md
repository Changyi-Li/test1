## Agent tasks
This procedure is part of the option Agent. Here you can configure to run a procedure via agent task at given times.
This means that you can automatically create lists, perform calculations in the lists, and save the result. For some procedures you can send documents via e-mail, print them, and save them on the server. By using the button Run now ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_run.png) you can start the agent task immediately.
Examples of areas of automation:
- To check if there are any quotes that have expired (exceeded its validity period) or to find out about delayed deliveries.
- Periodic information such as creating a stock value or a WIP value.
- Running calculations that require great capacity on times when there is not such a high strain on the database server, for example during the night.
- Automate e.g. printing of invoices or printing of payment reminders.
