### Log
In this box you select which logs should be posted as well as date from and date to.
By using the button Run posting ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_run.png) you can run the posting manually for the log on the row.
The from date is used when starting to use the stock accounting and management accounting. There you enter from which time the posting should be done.
Before all logs have recorded transactions, this date will be suggested as the "from" date for scheduled and manual posting. This is shown in the upper box after you have restarted the procedure.
When you have approved and transferred the first journal to the accounting the Post from field will be deactivated. The program automatically recognizes from when the posting has to take place in order to get all transactions – which are not yet recorded – posted.
