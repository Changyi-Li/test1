### Variants
In this box you find available variants for the selected document. By using the function buttons you can add/delete own variants of the document, edit own variants, as well as select which variant should be used by default.
> Creating custom document variants requires certain specialist knowledge. If you need help with this, you should primarily contact a consultant/instructor at Monitor ERP System AB. Assistance regarding adaptation of document variants is not included in the support and update agreement. Please contact the Adaptation department at Monitor ERP System AB via adaptation@monitor.se or call +46 650 766 03.
> Read more in the section [Functions in document templates](../../../UserGuide/GeneralFeatures/DocumentFunctions.htm).
Add row at the end ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_row.png) creates a new (empty) variant of the document.
Delete selected row ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_delete_row.png) deletes the selected variant of the document.
Copy variant ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_copy_row.png) creates a copy of the selected variant of the document.
Edit ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_xtrareport_designer.png) opens the selected variant in the program DevExpress Report Designer.
By using Copy template ID to clipboard ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_copy_to_clipboard.png) you will copy the template ID to the Clipboard in Windows.

#### Default
Check this box for the variant you want to print by default. However, the user can select from all variants during printout.
In the customer register and supplier register you can select customer specific and supplier specific documents and variants that should apply to the customer/supplier in question. This will then override the default variant selected here.

#### Name
Here you enter a descriptive text for the document variant.

#### Translations
By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Adaptation number
Here you see the adaptation number for the document variant in cases where the variant has been created by Monitor ERP System AB. The adaptation number is also displayed in the section where you preview the document in the affected procedures. The purpose is to be able to separate the variants created by Monitor and the variants you have created on your own.
If/when you add own variants they will not be assigned an adaptation number.

#### O (Override)
For document templates which also have document settings, you have the option to – on variant level – override the settings. This will by default follow the document settings, but you can override this per variant and per setting.

#### Active
This determines whether the document variant is active and can be used when printing documents. An inactive document variant cannot be selected in procedures where you can print documents.
