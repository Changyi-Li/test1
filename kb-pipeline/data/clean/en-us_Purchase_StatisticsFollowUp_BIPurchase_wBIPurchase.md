## BI – Purchase
> This procedure is no longer being developed or maintained and will be removed in future updates. We recommend that you instead use our new, web-based Monitor BI. Read more about [Monitor BI](../../../UserGuide/GettingStarted/MonitorBI.htm).
In this procedure you can access important key figures and statistics for purchase and perform analyses.
This procedure gathers data from the two data sources called Purchase statistics and Purchase order backlog. The data source for purchase statistics corresponds to the Invoice basis – Purchase procedure, the Total list type, where only final record supplier invoices are included. The data source for the purchase order backlog includes all current purchase orders, also the subcontract purchase orders. One view is included for the purchase statistics and one for the purchase order backlog.
In a view there are boxes with different types of information. If you mark a record on a row in a box, the other boxes in the view will also be filtered by that record. You can extend the filter by marking additional records in other boxes.
In each box there is a toolbar containing functions used to filter ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_filter.png) several records in the same box, link ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) marked record to related procedure, filter ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_search_form.png) records via selection, export ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_export.png) the contents of the box to a file (.csv, .pdf, .txt, .xls, or .xlsx), and expand/minimize ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_expand_box.png) the box in the view.
If you have filtered records in the boxes, you can see your current filters by clicking the button Current filter ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_filter.png) on the toolbar of the procedure. When you have clicked that button, it is also possible for you to delete specific filters or all filters, including the selected time period.
With the Reset button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_cancel.png) on the toolbar, you can reset the view to its original mode.
Before you can see any information in the different boxes, you must configure the data mining for the business intelligence. This is done in the procedure Settings for BI. By using the button Most recent data mining ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_clock.png) in on the toolbar in the procedure, you can see when the latest data mining was made.
> Under Settings in the backstage of the procedure, you can create own (custom) views, if you have sufficient user rights. This can be very useful if you need to access and present other information than the information shown in a standard view. Read more about how to [create your own views](../../../UserGuide/GeneralFeatures/BISettings.htm) in BI.
If you load data from multiple companies/warehouses (configured in the Settings for BI), you can choose for which companies and warehouses you want to display statistics by clicking the Company and warehouses button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_warehouses.png). When you open the procedure the main company is the default company. If you wish to view information for more companies you need to mark them here.
