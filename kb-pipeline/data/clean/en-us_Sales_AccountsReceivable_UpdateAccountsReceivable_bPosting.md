### Posting
In the Posting box, you can post new accounts receivable records after having entered an invoice amount and marked the Posting checkbox. You can post before you save a new accounts receivable record. After that, the posting will be locked.
The posting table is the same as in other posting procedures, e.g., the Incoming payments procedure.
If the system setting called Basis for the VAT report's is loaded from has been configured to VAT code in general ledger transactions, you can adjust the VAT code on the posting rows entered in the Posting box.
