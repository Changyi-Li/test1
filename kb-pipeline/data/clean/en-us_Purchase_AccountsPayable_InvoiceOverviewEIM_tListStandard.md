### The Standard list
By default, this list type shows information about invoices that have been sent for authorization. Depending on how you have selected the list, it can also show other invoices such as rejected invoices, invoices waiting to be final recorded, or filed invoices. It is not possible to update any information in this list. Below you find a description of some of the columns.

#### Signer group
In this column Yes is displayed if the invoice is authorized by a signer group. No is displayed if the signer is only one person.

#### Consecutive number
For a credit invoice the consecutive number is displayed in red.

#### Due date
The due date is shown in red if it is less than five days until the invoice becomes overdue.

#### Parallel authorization (P)
Here you can see if the invoice can be authorized in parallel.
Status
Here you see the status of the invoice. For example, Sent for authorization, Find part, Find delivery, or Find order.

#### Action
If this column is empty, it means that the invoice has been sent for authorization and that it is now at the signer in question. Otherwise you will in this column see which action that has been performed, for example Authorized.

#### Handling time
In this column you see the time (in days) that the invoice has been handled. Handling time is shown for all records, including the ones that have not been handled yet (0 days). If the invoice was received by the signer 2017-01-01 and action was taken/it was handled 2017-01-02, you will see 1 day in the column handling time. If it is a future record, this field will be empty.
