### Settings – Selection (Report receiving inspection)

#### Person
In this field you enter the employee who performs the inspection. This is selected from the personnel records. By default, the person to whom the current user is linked is displayed, but this can be changed if, for example, there are several persons performing receiving inspections without changing the logged in user in Monitor ERP. By using the button More information ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) to the right, you can see more information about the selected person.

#### Suggest arrived quantity
With this checkbox you determine if the quantity left to approve will be filled in as approved quantity. If not, no approved quantity will be suggested.
