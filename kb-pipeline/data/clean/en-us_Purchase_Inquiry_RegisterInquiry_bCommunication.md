### Communication
Here you can add communication information. You can modify, delete, and add rows containing communication information for the record in question. E-mail address as recipient is loaded from the supplier. Please see an explanation of the different information in the help chapter for [Communication](../../Suppliers/SupplierRegister/bCommunication.htm) in the Supplier register procedure.

#### Printout via
With this setting you determine if the printout by default should be made using a Printer or via E-mail. This setting is also loaded from the supplier.
