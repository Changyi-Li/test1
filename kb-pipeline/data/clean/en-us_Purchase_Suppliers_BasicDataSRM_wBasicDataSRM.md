## Basic data – SRM
In this procedure you register all the basic data regarding SRM (Supplier Relationship Management). Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. is activities, supplier statuses, districts, supplier types, inspection templates for receiving inspection, as well as number of employees.
This information is then used e.g. under the SRM tab in the Supplier register procedure, and under the Activities tab in the Register inquiry, Register purchase order, and Register blanket order - Purchase procedures.
You can register inspection templates for variable receiving inspection here. You can then link these to suppliers in the Supplier register procedure.
New basic data rows in the tables are given a numerical code that must be unique, containing a maximum of 6 digits. By default, the code is the same as the row number. You cannot modify the code after you have saved the row in the procedure. The texts in names, districts, customer types, and resellers can be modified at any time. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.
You can delete a basic data row as long as it is not used in a record, e.g. a customer. If you try to delete a row that is used, you will see a message telling you that it cannot be deleted and information about where it is used.
