## Configuration groups
This procedure is a part of the option called Product configurator. Here you create and update configuration groups. You link a configurator group to a part in the part register. The part then becomes possible to configure (a product).
What is a configuration group?
The configuration group is a complement to the basic BOM and routing which exists for the part that the configuration group is linked to. The configuration group contains a structure which describes alternative and rules regarding how different variants of a product can be configured. This means, that by using a configuration group in combination with a basic BOM and routing, it is possible to manage a number of different designs or variants of a product. A basic preparation describes the common execution of all variants, while the configuration group describes all selection options and how these can be combined creating different variant of the product. In connection with e.g. order registration, calculations, and quoting, choices are made based on the alternatives and rules that have been created in the configuration group.
Using a configuration group as a template
A configuration group can also be used as a template for a new configuration group. This is done by using the button Save as... ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_save_as.png) (Ctrl + Shift + S) on the toolbar of the procedure. In the dialog box that appears, you enter the new configuration group code and its name. You also choose of quantity formulas, time formulas, price formulas, and configured instructions should be included in the new configuration group. By default it is set to create a copy of the formulas in the new configuration group, but it is also possible to choose to use the same formula (the same formula number) or you can choose not to copy certain formulas.
Deleting an Configuration group
You can delete configuration groups that are no longer in use by clicking the Delete button![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_delete.png) (Ctrl + F6). If you try to delete a configuration group, a check is made to see if it is used on any part, template or configuration.
Sections, option lists, and variables
A configuration group structure is created by sections, option lists, and variables. This becomes a guide which is used in the configuration when an order is created.
In connection with order registration, the configuration will be separated per section. They are also used as heading when configuration information is displayed on the order document. A section has a heading section and a footer. A section is the highest level in the hierarchy, there must always be a section. Under a section you can add option lists and variables the sequence you want.
Option lists contain parts. You can move option lists and variables in under other option lists in the structure. They will then be called subordinate option lists and variables. However, a variable cannot contain sub-levels.
Variables allow you to e.g. create configuration groups for custom-made products, such as doors, windows, and mirrors.
It is also possible to create frameworks and rules between different parts in the structure. Each row in the structure (except for sections) can, by using rules, affect other rows and in their turn be affected by other rows.
