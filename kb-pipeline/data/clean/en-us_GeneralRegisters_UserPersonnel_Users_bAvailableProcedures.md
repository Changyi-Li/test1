### Available procedures
Here you can override user rights per procedure regarding which procedures should be visible or invisible for the user. By default, According to user right has been set for all procedures. This means that the procedure's availability is determined by the role, user rights group, and user-specific user rights that have been configured for the users.
The procedure is selected in the Available column if Allow has been set for the user on some of the user rights to the type of record the procedure handles. You cannot check or uncheck the box. This is instead inherited from settings configured in some of the other boxes.
In the column Overrides, you can configure that the procedure shall be forced to be visible or invisible for the user. The default selection is based on the user rights.
You can e.g. have a user with a role that allows him/her to view and create parts, but he/she shall not have access to the BOM and routing procedure. In that case, you can select Mandatory not visible for that procedure.
Another example is a user with a role that does not give him/her access to a specific procedure. Then the Available box will not be checked and the user will not see the procedure in the menu. If you still want the user to see the procedure, you select the alternative Mandatory visible for the procedure in question. The user will then see the procedure in the menu, but it will be grayed out and cannot be opened.
