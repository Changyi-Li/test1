### Dispatch advice
In the Dispatch advices box under the List tab you find the reported dispatch advice. You can modify the information mentioned below as long as the dispatch advice's Status is not Final delivery made. For each dispatch advice you also see supplier number and supplier name.
By using the button Delete selected row ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_delete_row.png) (F6) on the function menu, you can delete a dispatch advice and then save the list. This is useful if for example the entire dispatch advice has become unnecessary.

#### Delivery note number
The delivery note number that was entered when the dispatch advice was reported.

#### Dispatch date
The dispatch date that was entered when the dispatch advice was reported.

#### Status
The status of the dispatch advice can be Registered, Partial delivery made, or Final delivery made.

#### Shipment number
The shipment number that was entered when the dispatch advice was reported.

#### Link to goods tracking
The link to goods tracking that was entered when the dispatch advice was reported.
