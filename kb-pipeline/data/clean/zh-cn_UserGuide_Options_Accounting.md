# Monitor 会计
Monitor 会计——对于否生产活动的企业（例如属性管理或控股公司）来说，这是完美的替代方案。
Monitor 会计包括管理会计、支付供应商发票和向客户发票你的全部程序。也许你们组里有一家公司否生产活动？
