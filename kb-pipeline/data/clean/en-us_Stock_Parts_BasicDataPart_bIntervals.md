### Intervals
The Intervals box is activated if you have selected the Manual interval setting in the Forecast deduction box. Here you can add rows with the intervals which should be used in the marked interval setting.
Tables with examples can be found [here](tForecastDeduction.htm).

#### Period length
Here you enter the length of the period. You enter it in number of weeks. The default option is 1 week.

#### Number of periods
Here you enter how many periods of the entered period length which should be included. The default option here is 4 periods.
