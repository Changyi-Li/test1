### Header row

#### Order number
Select purchase order number for which to report measuring data. The order is then loaded and you choose row position in the next field.

#### Position
Select which order row position for which measuring data should be reported. The first order row position is loaded by default. You will see information about the part on the order row in the following field.

#### Quantity
Here you enter the quantity to report.

#### Reported by
Here you enter an employee number which is saved on the reporting item. If the user has a linked employee number, that employee number will be pre-filled. If the employee number is blocked for reporting, an error message appears and you cannot save the reporting item.
