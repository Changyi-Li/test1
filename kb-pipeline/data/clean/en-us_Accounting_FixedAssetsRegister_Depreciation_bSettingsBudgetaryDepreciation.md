### Settings – Budgetary depreciation

#### Date
Here you can select which dates the budgetary depreciations should be calculated for. By default the date is from the first to the last day of the next accounting year. A warning will be shown if the next accounting year is missing. In this case, you are able to load the list, but you cannot save the list to the accounting budget (via the Generate budget button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_accounting_budget.png)). Future accounting years are registered in the Register accounting year procedure.

#### Include budget objects
This setting determines whether fixed assets objects marked as budget objects should be included in the list. The setting is activated by default. Budget objects are any object selected as a budget object in the Register fixed assets object procedure. These objects can e.g. be future investments that you want to have as a basis for budgetary planning.

#### Account types
With this setting you determine which account types are to be displayed in the Posting box in the list. You can select more than one option. The default account type is Depreciation account. The accounts that are shown are those that are entered for the fixed assets groups in Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Fixed assets register.

#### Dimensions
With this setting you determine how rows should be grouped in the Posting box in the list. You can choose between CC (cost center), CU (cost unit), and Proj. (project). You can select more than one option. If you do not choose a dimension (default), the rows will be totaled on account level. The level you select also determines to what level you budget if you use the Generate budget function ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_accounting_budget.png) in the function menu in the Posting box.
