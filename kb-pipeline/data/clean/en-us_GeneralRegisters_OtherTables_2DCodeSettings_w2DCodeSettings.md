## 2D code settings
You use this procedure to add templates for how 2D codes should be interpreted. You can scan a 2D code to arrival report an entire purchase order. This is complementary to using a scanner and scanning a bar code per field. This enables you to use a 2D scanner/phone camera to scan a 2D code on the delivery note document and transport label – sales, and this fills out the order number, part, position and quantity all at once.
The following documents have support for 2D codes:
- Delivery note
- Delivery note, delivered
- Delivery note, delivered – Stock order
- Comprehensive delivery note
- Transport label – Sales
You can use the default template or create your own templates by using a prefix for different fields to match the supplier’s delivery documents. In Supplier register you can then select which template should be used with a specific supplier.
