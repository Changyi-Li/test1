### 后台程序
每个程序都有一个后台，根据程序类型的不同，后台的功能也不同。
| 功能 | 解释 |
|---|---|
| [侧面板](SideBar.htm) | 在这里你可以选择在侧面板中显示哪些部件。 |
| [链接](../GeneralFeatures/Links.htm) | 在这里你将超超链接复制到此程序并记录。 |
| [指导](../GeneralFeatures/Instructions.htm) | 你可以在这里针对相关程序创建自己的指导。 |
| [选择行](../GeneralFeatures/SelectionRows.htm) | 在这里你可以显示在 选择 标签页。 |
| [格式](../GeneralFeatures/Presentations.htm) | 你可以在此处为不同列表类型创建自己的格式。 |
| [设置](../GeneralFeatures/BISettings.htm) | 你可以在此处配置商业智能程序中的设置。 |
| [格式模板](../GeneralFeatures/FormatTemplates.htm) | 你可以在此处创建自己的(自定义)格式模板，以便在导入程序中从文本文件导入数据从。 |
