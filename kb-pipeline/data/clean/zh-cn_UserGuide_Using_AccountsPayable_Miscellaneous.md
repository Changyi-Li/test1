### 应付账款的其它程序

#### 打印供应商开票日记账
在此程序中，你打印收款日记账并批准它。日记账也可以不已打印而被已批准并已传输到会计。你还可以在此程序中重印供应商开票日记账。
当将直接集成应用于会计时，此步骤不必需的。请注意！如果期间已关闭.，你五月必须执行日记账打印。

#### 付款
此程序包含向供应商付款的不同功能。
使用付款文件付款：
1. 选择列表类型 付款建议 和付款方式，然后你要包括在文件中的发票。
2. 载入列表并取消选中不包含在付款中的发票（如果有）。
3.    
点击 保存 并选择是否应直接已创建付款文件，或者是否应打开事务列表订单在已创建付款文件之前你它。阅读更多了解事务列表的处理，请参阅 打印事务列表 低于。
另一种方法是点击按钮 移动选择的发票 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_run.png)代替保存 将发票移动 支付由文件(订单)。在该标签页下，你还可以人工的添加发票（时间一）以通过文件付款。例如，这样做是为了通过人工的已添加发票来补充你移动到此处的发票。你然后 保存 在该标签页下创建付款文件。
人工的报告付款：
1. 转到标签页 手动支付。
2. 选择付款方式并添加已已付款的发票 付款 盒子。
3. 按程序保存。
使用 列表 标签页以列表形式报告多个付款。这是发票 包括 在你报告付款的列表中标记的复选框。
取消付款：
1. 选择列表类型 取消付款 并选择你想要取消付款的发票。你可以选择要包括的付款选择状态。
2. 载入列表并标记要取消的付款。
3. 保存列表。当你保存时，会出现一个问题询问你是否要取消已选择的付款。
当付款被已取消时，你将再次在 付款建议 列表。

#### 打印付款日记账
在此程序中，你可以打印付款日记账并批准。你还可以批准并将日记账传输到会计，而无需打印中它。你还可以在此程序中重印付款日记账。
当将直接集成应用于会计时，此步骤不必需的。

#### 打印事务列表
在此程序中，你可以分别载入，复核并批准以及打印付款事务列表。这些事务列表应以文件形式电子已发送至银行。当你批准事务列表时，就会已创建付款文件。然而，正常的工作方式是当你保存付款时将事务列表直接保存到文件中 付款 程序。当你在标签页下保存付款时 支付由文件(订单) 在里面 付款 程序，但是你可以选择打开程序 打印事务列表。
通常你不使用 打印事务列表 创建付款文件的程序。但是你仍然可以使用此程序重印事务列表或更改事务列表的变更状态订单重新发送付款文件。
重印事务列表：
1. 选择列表类型 重印 - 事务列表。
2. 当需要时，选择事务列表以重印并载入列表。
3. 在里面 结果 在框中你可以看到你已选择的全部事务列表。标记打印的列表。
4. 在里面 预览 框中你可以视图已选择的事务列表。单击按钮打印列表或单击按钮将其作为 PDF 附件通过Email发送。
更改状态以重新发送：
1. 选择列表类型 更改状态以重新发送。
2. 需要时，选择你想要变更状态的事务列表并载入该列表。
3. 然后，你应该在列表中检查 变更状态 你想要变更状态的事务列表的复选框。
4. 按程序保存。
现在可以再次加载事务列表，并通过列表类型已保存到新建的付款文件中 事务列表。另一种方法是在 付款 程序。

#### 应付账款列表
你可以在此处执行以下操作：
- 查看未付款发票列表并协调。
- 查找不同的东西，例如某个供应商的发票的付款状态。
- 显示按年龄已分配的应收账款（账龄分析）。
- 查看发票和付款的过账。

#### 发票底单 - 采购
此程序显示与供应商发票未链接的已到货已登记采购订单的列表。例如，这可用于库存估值期间的对账目的。
> MONITOR提示！ 使用 现金流预测 查看每期间预期收入和付款的程序。
