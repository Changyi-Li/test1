## User
In this procedure, you configure the user accounts that should be used in the company database.
User accounts are used when logging in to Monitor ERP. The accounts are unique within a company database, that is, in the company registered in the database. An employee number from the personnel record can be linked to the user account, but this is not mandatory. You can create user accounts independently, for example, for recording terminals. It is also possible to, at a later time, link a user account to an employee number in the Personnel record procedure.

#### General user settings and document/printer settings
You configure different settings for user accounts, e.g., user language, e-mail settings, and different default order types. Furthermore, you can link default printers and assign user rights in the company to the account. This is primarily done via different roles. To the roles you can also add user rights groups and user specific user rights that are not based on a standard template of a role. If you have installed the option Warehouse, the roles and user rights will be saved per warehouse level on the users. The user license primarily determines which functions a user account can access in the company or companies in the system.

#### Security settings
You also configure security settings for a user account. This is on one hand to enter a password for the account. Passwords can be controlled by a password policy that is configured for all user accounts. This is done in the Security settings procedure. You can also link a Windows account to the user account, a so-called integrated login. This means that when you start Monitor ERP, the system checks which Windows user is logged in on the computer. This user will then automatically be logged in to Monitor ERP. You can also activate multi-factor authentication for a user account. This can also be configured for all user accounts in the Security settings procedure.

#### Mobile client settings
Certain system settings for the Mobile client can be overridden on user level.

#### Tips for registering several user accounts
If you are registering several user accounts with the same set of user rights, it is convenient to use the function Save as (Ctrl + Shift + S) on the toolbar of the procedure. First you register a user account that will function as a template for the user accounts you register later on by using the Save as function.

#### Number of user accounts
The number of user licenses that is included in the company license you have bought determine the number of user accounts that you can use at the same time. You can also deactivate user accounts. Then you cannot log in using these accounts. On the other hand, they do not reserve any user licenses. That way, you can create new user accounts that you can use instead of the inactive accounts.

#### Changing the names of user accounts
By using Rename (Ctrl + F2) on the toolbar of the procedure you can rename an account. This is useful if for example one person has ended his/her employment and another person should take over the account.
