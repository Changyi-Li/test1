### Result
In this table the journals which will be generated are shown. A new journal number is generated for each depreciation date and voucher text. Periods are shown in red if they are not open. If there are one or several journals belonging to periods that are not open, then it is not possible to approve the journal printouts, even though there are separate journals belonging to open periods. This does not apply if you use integration. Then you can print and approve journals as you please.
When reprinting you will also see the date of the approval and which user who approved the journal.
