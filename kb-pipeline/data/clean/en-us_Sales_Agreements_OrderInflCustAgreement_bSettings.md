### Settings

#### Show foreign currency
When this setting is not activated, Price, Price/invoicing interval, and Amount/invoicing interval, are shown in the currency specified in the customer agreement.
If the setting is activated, the columns called Price (company currency), Price/invoicing interval (company currency), and Amount/invoicing interval (company currency) are also displayed.

#### Convert price each according to rate type
With this setting you determine if "price each" in foreign currency should be converted to the present exchange rate in the Currencies procedure. If the checkbox is not checked, the exchange rate saved on the record will be used instead. Which rate type to use is selected in the field below.

#### Rate type
The rate type you select here is used to convert "prices each" and price lists in foreign currency to the now applying exchange rate for the selected rate type. The default rate type is From customer/order type. You register rate types in the Currencies procedure.

#### Show agreement value per
Here you decide if the agreement value should be shown by:
- Month (selected by default)
- Quarter
- 6 months
- Year
This setting makes it possible to perform comparisons, even if the agreements you have selected may have different invoicing intervals.
Example: If an agreement has the invoicing interval “Year” and an agreement row with an amount of 1,000 SEK/Year, the value will be shown as 1,000 SEK / 12 = 83.33 SEK/Month if you have selected Month in this setting.
