### Return

#### Goods location
Goods location is available for the case type Customer nonconformity. You can enter a goods location in order to indicate where the returned parts have been placed. This is to avoid defect parts being registered in the stock balance.

#### Previously reported quantity
If you have activated the system setting Affect balance for case you can perform stock reporting by linking ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) to the Direct stock reporting procedure for the case in question. Stock reporting can be made for all case types.
The part's default quantity in the case that is used to report report arrivals or withdrawals on location in that procedure, is calculated as the entered Number of rejections in the case minus Previously reported quantity in the case. In this field you see the previously reported quantity.
By using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) next to the field you find a log where you can see information about previous stock reporting items. You find the following information in the log: reported when (date and time), user name, location name, balance change, and batch number or serial number (if the part has traceability).
You cannot delete a case if stock reporting has been made.
