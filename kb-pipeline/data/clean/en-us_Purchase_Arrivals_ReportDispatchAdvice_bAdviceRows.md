### Dispatch advice rows
In the Dispatch advice rows box under the List tab you find information about order rows included in the selected dispatch advice. The remaining quantity on the order row is shown. You can modify the information as long as the dispatch advice row's Status is not Final delivery made.
By using the button Add linked row ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_row.png) on the function menu, you can add a dispatch advice row with the same supplier and then save the list. This is useful if you for example need to complement the dispatch advice with additional rows.
By using the button Delete selected row ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_delete_row.png) (F6) on the function menu, you can delete a dispatch advice row and then save the list. This is useful if for example a dispatch advice row has become unnecessary. You can delete a dispatch advice row as long as it has not been arrival reported.
Using the button Go to procedure ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) you can go to related procedures with the selected order already loaded.

#### Order number
If you have added a dispatch advice row, you must select a purchase order. You can only select orders with the same supplier.
If there are sub-rows on the order, these can be displayed by expanding the row using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_expand_row.png) to the far left. No information can be changed on sub-rows. Sub-rows are updated when something is changed on the main row.

#### Position
If you have added a dispatch advice row, you must select an order row position for the selected purchase order.

#### Status
The status of the dispatch advice can be Registered, Partial delivery made, or Final delivery made.

#### Dispatched quantity
Here you enter the dispatched quantity.

#### Unit
Here you enter the unit of the dispatched quantity.

#### All
If you configure this setting, the remaining quantity on the order row will be set to dispatched quantity.
