### The Connections table
In this table you can add connections for a receiving company or a production company. By using the buttons on the function menu you can add, delete, and copy connections.
When you add a row for a connection you must first select a remote company in the settings in the section to the right. Start by clicking the button Load company from remote server ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_refresh.png) to see the companies on the remote server and to be able to select one of those companies in the Remote company field.
In the first column in the table, you see this symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/StatusFinishedBox.png) if the connection is valid, and this symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png) if the connection is invalid. A new connection is not always valid, but becomes validated when you save. The connection is then changed into "valid" if the communication between the companies works.

#### Name
Here you can write a descriptive text as a name. You enter name texts in the company language and they are displayed in the user’s language.
The text can consist of a maximum of 35 characters. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Type
In this column you see the type of the connection. For a connection which you have manually created in a sending company or sales company, it will in this column say Production company. When the connection is transferred to a production company via a transfer profile (when using customer order transfer), it will say Sales company.
