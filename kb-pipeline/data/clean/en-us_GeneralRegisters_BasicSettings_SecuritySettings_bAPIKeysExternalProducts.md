### API keys for external products
Once a partner solution, for example Machine Integration, has been delivered to your company the External products tab becomes available.
- Add new row ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_row.png) – creates a row with a new access key and expiration date for the access key. The default validity period is is 6 months.
- Generate ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_refresh.png) – will generate a new access key. After doing so, you have to enter the new access key in the settings for the external product in question.
You use the access key to connect to your external product.

#### Name
This is where you name the API key. Use a clear name so that it is easy to understand to which product the key belongs.

#### Access key
The generated access key that you copy into the external product’s settings.

#### Access key expiration date
Here you see the date after which the access key is no longer valid. It is possible to unlock the field and change the expiration date. When the expiration date is closing in, you will receive a message and you can choose to extend the date or to generate a new key.
