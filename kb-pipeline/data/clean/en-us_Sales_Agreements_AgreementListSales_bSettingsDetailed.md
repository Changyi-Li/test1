### Settings – Detailed
You use the settings described below to see the value for a certain period for the registered agreements. For example, you have agreements lasting for a 5 year period but you want to see the value of this agreement for the future year only.
> Valuation is calculated based on the agreement’s valid-from date (in the Register customer agreement procedure) up to the end date specified in the End date field, unless another setting is activated.
Valuation

#### Show valuation
Here you decide if the valuation should be shown in the list.

#### Valuate from start date
With this setting you determine if the valuation should be calculated as of the start date entered in the Start date field below. If the checkbox is not activated, the valuation will be calculated based on the “Valid from” date specified for the customer agreement in the Register customer agreement procedure.

#### Start date
This is activated when Valuate from start date is marked. This date is used for valuation of the agreements in the list and means that the amount will be calculated starting on this date. Today's date is selected by default. This field cannot be left empty.

#### End date
The default date here is today's date plus one year.
> Please note! If the agreement has a valid to date entered in the Register customer agreement procedure, the valuation will be done no later than up to this date. For example, if an agreement has a “Valid through” date of May 1st, 2024 and you select the end date April 1st, 2024, this means that the valuation will be calculated up to April 1st, 2024. But is you have a “Valid though” date of March 1st, 2024 and you select the end date April 1st, 2024, it means that the valuation will be calculated no later than up to March 1st.

#### Only apply on agreements with no "Valid to" date
When this setting is activated, the End date will only apply regarding agreements which do not have a "Valid to" date.
View

#### Show only main rows
This checkbox determines whether or not only main rows should be displayed. If this setting is activated, the associated sub-rows such as additional texts, alloy costs, and incorporated/included parts in fictitious parts, will not be displayed.

#### Show delivered rows
With this checkbox you decide if delivered rows should be shown in the list.

#### Show foreign currency
With this checkbox you determine if a total per currency code should be displayed at the bottom of the list. The total applies to all rows in the list which have a currency different than the company currency.
