### Header row

#### Parameter group
Here you enter/select the code of the parameter group. It can consist of a maximum of 8 characters.

#### Name
Here you see/enter the name of the parameter group. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Linked employees
Using the button Linked employees ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you can see who in the personnel are linked to the selected parameter group. Blocked employees are not shown.
Personnel must be linked to a parameter group in the Personnel records – Time recording procedure if you configure Time reporting to Attendance/Work or Only work.
