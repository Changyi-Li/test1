### Settings

#### Date
The first date in the current month will be suggested in the From field and the last date in the current month will be suggested in the To field. The date fields cannot be left empty.

#### Adjustment date
If you make additions or adjust the amount in the report, you here determine on which date these additions/adjustments should be saved. The date suggested here is the same date as the date entered in the To field. The field cannot be left empty.

#### Include
Here you determine what you want to include in the report.
- Invoice (default)
- Order which is not linked
- Stock order
- Subcontract
- Adjustments

#### Debit/Credit
The alternative All is selected by default. If you want to exclude all credit invoices from the report you select the alternative Only debit. It is also possible to load an Intrastat Intrastat is the system which gathers statistics relating to trade in products within the European Union. Gathering of Intrastat statistics is handled in the same way by all EU member states. report based on only credit invoices. The latter alternative is for example used if you need to review all credit invoices to EU to see if some records should be excluded from the Intrastat report.

#### Importing country
Here you select for which country the reporting should be made. The available countries are the countries in which the company has warehouses. In the warehouse selector, the warehouses that belong to the selected importing country will be automatically marked.

#### Warnings
Here you can select which checks should be made and which warnings should appear when loading the report. These will appear under the Warnings tab. Here you find the following alternatives:
- CN code is missing
- Weight is missing
- Delivery outside the EU
- Account does not concern trade in goods EU
- VAT code does not concern trade in goods EU
- The part is missing reporting unit

#### Use current weight on part
Here you can choose if you want the current weight on the part to be used. The setting is useful if you for example have changed a net weight for a part in the Part register after the order was created and you want the report to be based on the current/updated weight weight information.
