## Number series
In this procedure you configure start numbers for different registers in the system. These number series should be reviewed before you start to use the system in order to have a numbering for different type of records registered in the system.
A number series can contain a maximum of 19 digits.
The procedure is divided into tabs, one per module (for the modules with records that can be numbered). Under each tab, you find a list of the number series that exist in that specific module. Package number series are however found under the General registers tab.
