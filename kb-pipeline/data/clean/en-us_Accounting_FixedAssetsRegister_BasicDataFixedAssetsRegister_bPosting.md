### Posting
In this box you configure posting settings for depreciation.
All account settings are active if the depreciation method is set to Scheduled depreciation for the marked depreciation type.
For the depreciation type Scheduled you then have to select fixed asset account, accumulated depreciation, depreciation account, profit account, and loss account. You can select an account for investment in progress, but this is optional.
For the depreciation type Calculated you have to select accumulated depreciation and depreciation account.
If the depreciation method is set to No depreciation for the depreciation type Scheduled, then you can choose fixed assets account and account for investment in progress.
