### Available tables
In this box you select the table/tables for which you want to create new optimizing statistics. Check the box called Include for the tables you want to include. It is also possible to include all tables.
When you have selected a table, it appears in the box Selected tables.
You start the process by using the button Create optimization statistics ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_run.png) in the toolbar of the procedure.
The creation of new optimization statistics is generally instantaneous, but for large tables it can take a few moments.
