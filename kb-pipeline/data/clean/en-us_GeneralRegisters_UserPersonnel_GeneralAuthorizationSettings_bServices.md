### Scheduling – Service
In this box you will find a service that you can run manually or you can schedule it to run automatically according to a schedule created in the Settings box. Read more under Services below.

#### Active
Here you activate the service. It will then be run according to the schedule created in the Settings box and in the Settings for Reminder via e-mail box.

#### Run
By using the button Run ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_run.png), the service will be run one time.

#### Last modified by / Last modified on
You can see the date and time when the service has been modified as well as by whom it was modified.
Services

#### Reminder via e-mail
The service Reminder via e-mail sends reminders via e-mail to signers with this setting configured in the Reminders box under the Signers tab. Then activated reminders about purchase orders to authorize/approve will be sent via e-mail. For this service you must also configure settings in the box Settings for Reminder via e-mail.
The e-mail message sent to signers can contain a link with which the relevant purchase order is opened in Register purchase order procedure.
