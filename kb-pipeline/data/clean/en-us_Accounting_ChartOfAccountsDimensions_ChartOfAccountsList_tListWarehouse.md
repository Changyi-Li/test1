### The Warehouse list
This applies if the Warehouse option is installed. In this list you can configure settings for dimension code and warehouse on each account in the chart of accounts.

#### Dimension code
This information can be updated.

#### Warehouse
Here you decide if posting for cost center, cost unit, etc. based on the order row's warehouse, should be automatic. This applies to all order procedures, quote procedures, and invoice registration procedures in the system. This automation will takes place provided that cost center had not already been entered for the part's product group in the Posting matrix procedure.
