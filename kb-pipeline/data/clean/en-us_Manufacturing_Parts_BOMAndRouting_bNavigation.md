### Navigation
You can maximize this box with the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_maximize_section.png) and you can minimize it with ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_minimize_section.png). In this box you find the structure map with the main part at the top level and the included/incorporated parts. The main part is the part that has been loaded in the procedure.
In the box you can navigate between the parts in the structure map. Manufactured parts are called nodes A node is an included/incorporated manufactured part on a certain level in a part structure. A level in the structure part can contain multiple nodes. The node on the highest level is called the main part (order). in the structure map. By marking a node you will see information about the part in the other boxes of the procedure. You can navigate using the cursor or with the arrow keys ↓ and ↑ on your keyboard.
By using the Find button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_search.png) (Ctrl + B) on the function menu you can show or hide a search field where you can search for parts in the structure.
With the Expand all button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_expand_collapse.png) (Ctrl + F8) you can expand or collapse the part structure in the BOM and routing
By using the Go to procedure button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) you can go to different affected procedures for the selected node.
With the Show all parts button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_part_structure.png) you decide if all incorporated/included purchased parts should be shown as well. By default, the purchased parts are not shown. If a BOM and routing exists for a purchased part, you will the part number and name of that part in italics.
With the Show all tools button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_tools.png) you can decide if all tools should also be displayed. By default, the tools are not shown. This button is available if the Tools & Maintenance option is installed.
The buttons Show all parts ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_part_structure.png) and Show all tools ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_tools.png) have a memory function. If you activate one or both of the buttons, the same buttons will become activated in other procedures where they are available.

#### Type
In this column you see the part type indicated by a symbol; Purchased ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/PartTypePurchase.png), Manufactured: Order oriented ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/PartTypeManufacturing.png), Manufactured: Stock driven ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/PartTypeStock.png), or Fictitious ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/PartTypeFictitious.png).
