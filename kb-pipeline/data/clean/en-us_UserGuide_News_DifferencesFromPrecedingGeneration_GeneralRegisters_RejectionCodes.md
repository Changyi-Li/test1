### Rejection codes/Cause codes
Video: Rejection codes/Cause codes (Swedish)
- It is possible to deactivate rejection codes/error codes which you no longer want to use. The statistics available for these codes will remain and can be shown in the lists, but the deactivated rejection codes/error codes will not be possible to select for new reporting items.
- Number of characters for rejection code/error code has been increased to 6 (3 characters in G4).
- You can decide that a comment is mandatory to enter for a certain rejection code/error. The person who reports the rejection/error must then enter a comment before he/she is allowed to save the reporting.
- You can configure it so that a rejection code does not withdraw material when you report a rejection on an operation.
