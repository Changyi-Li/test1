### 创建库存盘点底单
视频：创建库存盘点底单
| 瑞典语 | 英语 |
|---|---|
|   |   |
在里面 库存盘点列表 程序，你可以创建并打印可已报告的库存盘点底单。还可以管理显示已已打印但不完整已报告的清单（列表类型管理库存盘点）。
[![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/TrainingMaterial/StockCount1.png)](../../../../Resources/Images/TrainingMaterial/StockCount1.png)
我们的想法是，第一个使用列表类型你库存盘点底单 创建库存盘点底单。你可以在“选择标签页下选择要包括在相应基础中的组件。每个基础都会收到一个编号，你也可以为它们输入名称。请参见低于图片中的例如。
[![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/TrainingMaterial/StockCount2.png)](../../../../Resources/Images/TrainingMaterial/StockCount2.png)
要查看已已创建但不已报告的碱基，你可以使用 管理库存盘点 列表类型。在该列表中，你还可以删除基地或重印它们。
这 管理库存盘点 列表类型用于选择和报告库存盘点底单。在这里，你可以先选择基础，然后单击开始库存盘点 开始库存盘点 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_run.png)。你也可以在这里暂停 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/StatusOpPaused.png) 并删除 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_trash.png) 使用显示的按钮来查看库存盘点清单。如果不存在此信息，你还可以选择执行库存盘点的员工。
[![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/TrainingMaterial/StockCount5.png)](../../../../Resources/Images/TrainingMaterial/StockCount5.png)
当已开始报告库存盘点时，组件显示在 报告 标签页。它们将按照与库存盘点底单相同的订单进行排序。
> 提示！ 使用库存盘点状态 库存盘点及已保存余额 以便能够在稍后日期（库存盘点之后）登记您的结果。 在里面 文档模板 在程序，你可以编辑文档的布局。
