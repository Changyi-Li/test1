### Settings

#### Show
With this setting you decide which columns will be shown in the report.
- Dimensions Dimensions are used by large companies in their accounting in order to divide up activities and make it easier to track internal results. An account is a dimension, although large companies usually use the dimensions cost center (CC), cost unit (CU) and project. In addition to these you can create other dimensions in Monitor ERP based on your own operational follow-up. – Check this option to show columns for e.g. cost center and cost unit. This option is selected by default.
- Currency information – With this option checked columns for currency, currency balance, and exchange rate in the grouping and rows.
- Quantity – Check this option to show columns for quantity and quantity balance in the grouping and rows. This is the only available option for the Project list type.
- VAT code – Check this option to display a column for VAT code.
