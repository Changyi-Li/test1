### Machine recording
To apply machine recording the machines in the workshop must first have been registered in the Personnel records – Time recording procedure. In that procedure you must select the option Only work for the setting Time reporting. Then no recording items will be created for attendance, overtime, flex time, or absence for a machine, but only work recording (start/stop of the machine).
Work recording will then be made for the machines' employee numbers, not the operators' numbers. Since the operations are then linked directly to the machines the problem described below is solved. (This problem occurs if each separate operator should be the employee numbers which started the work items.):
- Shift work – When changing from one shift to the next, the new shift has to check which operations were finished during the previous shift and which operations that were started instead.
- Line manufacturing – This is when more than one operator are continually working with the same operation. When you stop/finish a work item difficulties might occur since only one operator is allowed to enter the reported part quantity.
- Automatic machines – This is when an operator does not always have to stand by the machine while it is running a work item. Then it might be a drawback that the operator has started the work item using his/her employee number.
> Please consider: To be able to see which operator that has performed the reporting, the setting Enter signing employee number at machine recording must be activated. This makes it mandatory for the operator to enter his/her employee number when reporting work (which is recording for a machine) in the recording terminal. This field is available from when you start the operation in case you wish to enter the employee number as early as then. The operator's employee number is then saved in all types of reporting items for work in the recording terminal. In the work recordings, the manufacturing order log, and the recording log the machines' employee numbers are saved as the reporting number and the operator's employee number is saved as the signing number. In the recording log the operator's employee number is saved only if it is mandatory to enter it in the recording terminal. In the stock transaction log the operator's employee number is always saved. A schedule must be used if you want to deduct fixed breaks from the recorded time of the machine Time recorded outside the schedule or during breaks does not generate time for the manufacturing order. If a schedule is not used for the machine, all recorded time will be registered on the manufacturing order. When using machine recording, it means that the machine must be stopped or clocked-in on indirect work in the recording terminal when there is downtime (when the machine is not running) in order for work to be properly recorded. Otherwise, time will be registered 24 hours a day.
