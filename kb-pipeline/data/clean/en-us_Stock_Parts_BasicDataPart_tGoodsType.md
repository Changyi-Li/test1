### Goods type
Goods type Goods type describes what kind of part it is, for example machine parts, electronics, etc. Goods type is printed on shipping documents. is entered for parts in order to clarify what kind of goods it is. The purpose is to be able to declare/present the goods type in connection to transport.

#### Code
Here you enter the code of the goods type. The code is automatically created for new rows and cannot be changed.

#### Name
Here you enter the name of the goods type, using a maximum of 35 characters.

#### Active
With this checkbox you determine if the goods type should be active.
