### Settings – Selection (Pick list by order)

#### Show all locations
With this setting you can decide if all locations should be displayed if a part on an order row has more than one location.

#### Show only main rows
This checkbox determines whether or not only main rows should be displayed. Related sub-rows in form of additional texts, alloy costs, etc. are not shown. The setting does not apply to sub-rows of fictitious parts. These are always displayed regardless of whether this setting is activated or not.

#### Update the customer order status to "Picking in progress"
With this setting you determine if the selected orders and the affected order rows should be updated to status 4 (Picking in progress) when you print the pick lists and approve the printout.

#### Pre-select "Include"
This setting determines whether or not the “Include” box should be checked by default for all rows in the list/result.

#### Printed by
In this field you can choose which person should be shown on the pick list as the person performing the printout. If the field is left empty, the logged-in user will be shown.
