### Currency

#### Currency
Here you determine if only records in the selected currency will be loaded to the cash flow forecast. If you have entered a balance brought forward for the forecast, that value is entered in the selected currency.

#### Show in foreign currency
With this checkbox you determine whether or not all values in the forecast should be shown in foreign currency. If you have selected a currency in the field above, this setting will become available. The purpose might be ability to see e.g. how the future transaction flow in USD will look like. In order to see that, you need to select the specific currency and set the values to be shown in that currency.

#### Convert price each according to rate type
With this setting you determine if "price each" in foreign currency should be converted to the present exchange rate in the Currencies procedure. If the checkbox is not checked, the exchange rate saved on the record will be used instead. Which rate type to use is selected in the field below.

#### Rate type for incoming payments
The setting is available if Convert according to rate type is activated. You can select the rate type that should be used when converting sales records in another currency. The default rate type is From customer/order type. You register rate types in the Currencies procedure.
This setting is deactivated if the setting above, Show in foreign currency, is checked.

#### Rate type for outgoing payments
The setting is available if Convert according to rate type is activated. You can select the rate type that should be used when converting purchase records in another currency. The default rate type is From supplier/order type. You register rate types in the Currencies procedure.
This setting is deactivated if the setting above, Show in foreign currency, is checked.
