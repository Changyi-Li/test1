### Communication
For a new invoice, this table will by default show the e-mail addresses registered on the customer as recipients of: Order confirmation, Advice, Advice to shipping agent, Delivery note, Invoice, and Pro forma Pro forma is a type of customs document which is used during export of goods. It is used to show information regarding the value of what is to be exported (customs cleared). Pro forma documents are also used in other contexts, for example much earlier than the time of delivery when contacting banks to arrange bank guarantees.. You will also see the phone numbers registered for the customer as recipient of Advice to shipping agent. You can modify, delete, and add rows containing more communication information for the order in question. See the explanation of the different columns in the help chapter for [Communication](../../Customers/CustomerRegister/bCommunication.htm) in the Customer register procedure.

#### Print invoice via
With this setting you determine if the printout of the invoice should be made using a printer or via e-mail. The default value is loaded from the customer.

#### E-invoice
This checkbox shows if the customer should be invoiced via e-invoice. This default value is loaded from the customer register.
