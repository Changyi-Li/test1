### Header row

#### Withdrawn to
Here you enter/select the employee number that should withdraw the tool. The name of the employee selected here is shown in the Name field.

#### Cause code
You can enter a cause code for the withdrawal. The cause codes you can select from are the ones with Tool and Active marked under the Direct stock reporting tab in the Cause codes procedure.

#### Expected return date
Here you select the date when the tool is expected to be returned.

#### Reporting date
Here you select the date of withdrawal of the tool.
