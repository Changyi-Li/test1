### Basic data – Attendance/Work
- The Codes procedure has been replaced by Basic dataWith "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Attendance and Basic data – Work.
- Now you can create as many overtime codes and time banks as you please.
- It is possible to use alias on salary types, which in that case will be used as salary type numbers during export to payroll program.
