### The Standard list
This list type shows information that only exists in one set for work centers. This list type does not show information about work centers of the type Pool and Subcontract.
There are four presentations of this list:
- Loading – In the list you see/enter number of machines or number of persons, machines/persons per order, availability factor, basic time, and queue time, if queue time is whole day or not, simulation factor, and staffing factor for unit and setup.
- Miscellaneous – In the list you see/enter all other settings. For example type, operation name, department, planner, time horizon, options regarding how material should be reported, if partially reported operations should be shown in “Ready to run (P)”, and how tools should be reported. (Tools & Maintenance is an option.)
- Block/Notify – In the list you see/enter blocks or messages for BOM and routing, registrations and reporting items for the work centers. It is also possible to enter message texts. You can also see when entered a message of created a block, and when this was done.
- Work recording – In the list you see/enter type, department, and settings for work recording (time calculation, show in priority plan, multiple operators).
