## Settings for transfer notifications
This procedure is available if the option Customer order transfer is installed in your system.
In this procedure you configure receivers of transfer notifications for different events that occur during customer order transfer. The receivers who can get notifications are: Our reference on order, Seller on customer, User, User rights group, and Role.
The notifications are shown for the receivers in the Notification window in the Message center in Monitor ERP.
The events that create notifications are:
- When transfer failed.
- Transferred new customer order.
- Modified customer order.
- Disconnected customer order row.
- Delivery reported customer order.
A default message text for each event is included in the notification. The text is formatted using different tags. It is possible to edit and translate this text to the different active languages registered in the system.
