### Comment/Files
In this box can enter internal and external comments, and link internal and external files to the inquiry. You can also see comments and linked files on the supplier.

#### Supplier comment
Here you can see comments regarding the supplier, if any, entered in the Supplier register. By using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_file_link.png) to the right, you can see and link files to the supplier. Comments and files are not printed. If there are no comments or files, the buttons are gray.

#### Internal comment
This text is not printed on any documents but it can be seen e.g. in different procedures and lists. By using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_file_link.png) to the right, you can see and link files for internal use. The files cannot be printed.

#### External comment
This text can be printed on different documents by configuring a setting for the documents in the Document settings procedure. The text can also be shown in different procedures and lists. By using the button to the right ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_file_link.png) you can see and link files for external use (e.g. a PDF to be attached to an order document). Files are printed automatically with the documents if the file has Automatic printout selected.
> Please note that file paths must be registered in the Paths procedure in order to enable files to be linked.
