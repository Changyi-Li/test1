### List
This list displays information about where a serial numbers is located.

#### Type
Here you see a symbol indicating where the serial numbers are located. By using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_expand_row.png) you can expand the rows to see the levels.

#### Identifier
Here you see where the serial number is located. It can be With us, At supplier, At customer, etc. When the row is expanded, you will here see additional information regarding the location/site in detail. It can be warehouse, location, work center number, customer number, order number, etc. A symbol for the serial number is shown on the row with the serial number of the bottom level.

#### Description
Here you see where the serial number is located, in text.

#### Status
Here you see the status of the serial number.

#### Blocked
Here you see if the serial number is blocked.

#### Warning
In this column you see if there is a warning entered for the serial number.

#### S/B S (Serial number/Batch status)
Here you see the status of the serial number.
More info
Under the More info button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png), you can generally find additional columns. Below you find the online help topics for the columns.

#### Block/Notify
Here you see if there is a block or a notification configured for the serial number.
