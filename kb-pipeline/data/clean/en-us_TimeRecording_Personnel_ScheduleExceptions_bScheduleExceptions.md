### Schedule exceptions
In this box you can enter schedule exceptions for the employees where you have checked the Include checkbox in the table above.
You must also mark one or several days in the calendar before you can enter schedule exceptions for those days.

#### Original schedule
In this table you will by default see the regular schedule selected for the person in question. By clicking the button More info ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you access the schedule displayed as a chart.

#### Exception schedule
In this column you select the schedule exception that should apply for the employee in question. By clicking the button More info ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you access the schedule displayed as a chart.

#### Number of dates
In this column you see a button, and on it you see a number representing the number of days for which the schedule exception will apply. By clicking the button you see a table in which the dates are specified.

#### Number of persons
In this column you see a button, and on it you see a number representing the number of persons you have selected in the table above to be included in this schedule exception. By clicking the button you see a table in which the persons are specified.
