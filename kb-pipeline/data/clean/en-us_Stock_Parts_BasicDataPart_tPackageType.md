### Package types
Under this tab you can register new package types or delete those which should not be used. You can also select which package types should be active.
There are several different package types included in the program.
A package type describes what kind of package is concerned. When a package type should be used in the system, an entered exception code for the package type on the shipping agent in question, will primarily be used, Exception codes are registered under the Exception button on the row. If the shipping agent does not have an exception code entered under that button, the code entered in the Code column on the row will be used instead.

#### Name
In this column you enter the name of the package type.

#### Code
Here you enter a general code for the package type using a maximum of 16 characters.

#### Exception
By using the button Exception ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png), you can add shipping agents and their codes for the package type. This is useful if different shipping agents use different codes for this package type. The shipping agent's code for package type can consist of a maximum of 16 characters.

#### Active
With this checkbox you determine if the package type should be active. By checking the box you make the package type available to select in fields for package type in different parts of the system.
