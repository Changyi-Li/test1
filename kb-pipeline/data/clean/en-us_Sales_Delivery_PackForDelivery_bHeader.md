### Header

#### Pick list status
In this field you see the status of the pick list. For a preliminary pick list it will here say "Preliminary". For a regular pick list it will here say "Ready for delivery".

#### Delivery status
In this field you see the delivery status of the pick list. For a new pick list it will here say "Registered". If the pick list is partially delivered or fully delivered, it will day "Ready for invoicing".

#### Responsible
Here you see the person selected as responsible when the pick list was created in the Delivery planning procedure. Here you can also select a person who should be responsible to pack all the parts in the pick list. You can also select a person responsible per part to pack on the pick list. This is done in the To pack box.

#### Shipment
In this field you see a shipment number if a shipment has been created for the pick list in the Register shipment procedure.
> On the toolbar of the procedure you can use the Go to procedure button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) and load the pick list in question in the Register shipment procedure and create a shipment.

#### Internal/External comment
Here you can see internal and external comments entered for the packing of the pick list. By clicking this button you access a text editor where you can write and format text, insert images and signature, and hyperlinks, etc. When a comment/text exists, the symbol on the button will change from an empty speech bubble ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_no_comment.png) to a filled speech bubble ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_comment.png).

#### Pick instruction (customer)
If there is a pick instruction entered on the customer in the customer register, you can read it here by clicking the button Pick instruction ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_comment.png). If these circumstances are not filled, then this button is not available. Documents linked to the pick instruction, if any, are shown if you click the Files button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_file_link.png).

#### Comment (customer)
If there is a comment entered on the customer in the customer register, you can read it here by clicking the Comment button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_comment.png). If these circumstances are not filled, then this button is not available. Documents linked to the comment, if any, are shown if you click the Files button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_file_link.png).
