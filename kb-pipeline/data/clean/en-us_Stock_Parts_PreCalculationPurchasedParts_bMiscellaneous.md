### Miscellaneous
Here you find additional settings for the pre-calculation.

#### Quantity if order qty is missing
Here you enter the lot size – according to which the pre-calculations should be made – for those parts that are missing an order quantity. If order quantity is missing for a part, the quantity you enter here will be used instead. This is displayed in the Quantity field under the List tab.

#### Use order quantity, current pace
This setting is available if you have activated the system setting Show annual budget, annual volume, and order quantity with current pace. Then it is possible to use the parts' Order quantity, current pace as the lot sizing rule on which the pre-calculations should be calculated. If order quantity, current pace is missing for a part, the part's order quantity is used instead. If order quantity also is missing for the part, the quantity you enter here will be used instead. This is displayed in the Quantity field under the List tab.
