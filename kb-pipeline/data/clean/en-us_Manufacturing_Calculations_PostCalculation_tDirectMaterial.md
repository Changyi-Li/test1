### The Direct material tab
This tab shows information about planned and reported quantities, times and costs for direct material, that is, purchased parts that are incorporated in the selected order and main part. If rejections should affect the post-calculation is determined by the setting Include cost for rejection.
Under the button Manufacturing order log ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_log.png) on the row, you can find a manufacturing order log for the part. Using the button Go to the level list ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) on each row, you can link to the material under the Level list tab and see where it is located in the structure.

#### Show values per unit
At the bottom of the window there is the setting called Show values per unit. It determines if values will be shown per unit or for the part’s calculated quantity.
