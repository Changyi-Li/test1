### Currency
Under the Currency tab you find a table where you register different currencies that you need. You can also update exchange rates and delete currencies that you no longer need. To the right you see by whom the exchange rate was modified and when. By using the button Historical rates ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) to the far right, you find a table with historical exchange rates. This table can be updated and complemented.

#### Currency
The code is a 3-character currency code according to the ISO 4217 standard.

#### Name
Here you enter and optional name for the currency code. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Rate types
When you register rate types and their description under the Exchange rates tab, columns are created under the Currency tab for each respective rate type. The description is set as column heading. Please note! You must restart the procedure to be able to see the new columns. In these columns you can enter exchange rate for each respective rate type and currency. The rate for a new currency is always 1,00 in relation to the company currency.

#### Per
This factor determines if the exchange rate should be entered per unit (1) or per hundred (100). This factor is set to 1 for new currencies.

#### Historical rates
By using the button Historical rates ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you find a table with previous exchange rates for the currency per rate type. Here it is possible to change these historical exchange rates, per rate type and per modification date. At the top of the table you see the most recent exchange rate which cannot be modified here. This can instead be modified in the main table for currency. It is possible to add historical exchange rates, for example if someone has forgotten to update the rates at a specific date. You can only add one (1) historical exchange rate per date. If an exchange rate has been modified several times during the same date in the main table, it is the exchange rate in the most recent modification that applies to the date. The button to the far right called Changelog ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) can be used to see rate updates that were made at a specific date. This applies per historical exchange rate.
