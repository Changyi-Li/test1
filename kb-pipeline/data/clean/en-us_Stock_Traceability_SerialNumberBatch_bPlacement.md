### Location/site
Location/site is available for serial numbers when the Tools & Maintenance option is installed.

#### Employee
Here you can enter the employee number for the person who has this tool. This will make it easier when performing stock count of tools. In the Recording terminal, a message is shown to this person when the tool needs to be calibrated etc.

#### Work center
Here you can enter in which work center the tool is located.

#### Department
Here you can enter in which department the tool is located.

#### Show using Google Maps
If there is a delivery address linked to the serial number and its location/site, you will here see a button for map ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_show_in_google_maps.png). If you click the button you will see the address in Google Maps. The delivery address can be loaded from different sources in the system according to the following.
If the serial number does not have a balance in stock (delivered) and there is a customer order/owner of the serial number, the address is loaded from the owner (the customer) in the Owner box.
If the serial number has a balance in stock (not delivered), it is the selected Location/site that determines from where the address is loaded. This is described below: If Employee is selected as location/site, the address will be loaded from that person's warehouse. If Work centerA work center is a part of the factory. It can be a single machine or a group of machines, a single workstation or a group of workstations. is selected as location/site and it is a subcontracting work center, the address is loaded from the subcontracting work center's supplier. If it is an internal work center, the address is loaded from the work center's warehouse. If Department is selected, the address is loaded from the warehouse where the balance is.
