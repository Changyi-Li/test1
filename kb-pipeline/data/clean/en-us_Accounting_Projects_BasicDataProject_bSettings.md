### Settings

#### Type of scheduling
With this setting you decide if the project calculation should be performed according to schedule or time interval.

#### Time interval
If you select the option time interval in the setting above, you can here configure how long the interval should be. This is entered in minutes.
> Please note! If you enter a too short interval, this might put a severe strain on the server.

#### Schedule
If you select the option schedule you can here select which days and which time of day to run the project calculation.
