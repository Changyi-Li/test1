### Header row
On the header row you select which manufacturing order you wish to load. Information about the order is shown in the header row. There you can for example see the order type, status, main part, planned quantity, partial quantity on the order, reported quantity, remaining quantity, if the order is linked to customer order, and to which project it belongs, if any.

#### Order number
Here you select an existing manufacturing order number to show information about orders, the order structure, operations, and material. To the right of the Order number field you find the More order information button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png). If you click this button you find additional information such as start date, finish date, priority, customer, and variant code.

#### Partial quantity
If the order has partial quantities the Partial quantity button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) is activated. By clicking the button you find information about quantity of each partial quantity registered for the order.

#### Customer order
If there is a linked customer order for the manufacturing order, then you see the button Customer order data ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png). By clicking it you see additional information such as customer, customer's order number, our reference, customer's reference, and the delivery address.
