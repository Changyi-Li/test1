### 数据不从 G4 转换为 G5
不全部数据都从 G4 转换为 G5。低于你查询从 G4 数据库到 G5 的转换中不包含的数据列表。这必须在 G5 中再次已登记。这可能是你需要重新注册的数据，或者你需要更新/补充的数据。请阅读本章节，了解转换被用于的内容的信息。与您的MONITOR顾问一起确保准备正确。
通用/ 平均价格计算
| 程序/功能 | 去做 |
|---|---|
| 用户 | 用户被用于在向 G5 的转换中，但然后必须为用户已分配许可证和用户权限。 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/UserGuide/NotConvDataUser.png) 记得分配EIM 用户权限和仓库用户权限。这是每用户已分配的。 |
| 用户权限组 | 你必须重新注册用户权限组。如果你不想创建用户权限组，G5 中有预定义的角色可供使用。 |
| 默认值 | 列表中的默认值必须重新已登记。 |
| 已保存的筛选 | 列表中已保存的筛选必须重新已登记。 |
| 自己的设计查找功能 | 已由用户已创建/设计的查找必须在 G5 中重新已创建。 |
| 自动运行（代理任务） | 必须重新已登记AutoRuns/ 代理任务。 |
| 商标 | 必须在 G5 中已添加商标。这是在 公司信息 程序。保持记住，徽标的比例必须是 1:4。 |
| 文档上的背景图像 | 该功能不在 G5 中实现，仓储费用数据不被转换。 |
| 签名 | 在 G4 中链接至联系人的签名必须再次已链接到 员工记录 程序。这些可以用来显示不同文档上的签名。 |
| 桌面/桌面部件 | 如果你使用桌面，则你每角色、用户权限组和/或每用户新建的桌面。 |
| 备份 | 技术/安装的支持员工通常在安装系统时创建备份任务。确保准备正确，并 Monitor ERP 系统有限公司 顾问。 |
| 测试公司 | 技术/安装方面的支持员工通常在安装系统后创建测试公司。确保准备正确，并 Monitor ERP 系统有限公司 顾问。 |
| 附加字段 | 附加字段需要重新注册。可以使用程序将字段中的数据从 G4已导入到 G5 MONITOR导入。 |
| 文档短语/文档文本 | 如果你在 G4 中对文档短语进行了变更，然后你必须在 G5 中再次进行这些变更，因为这些更改不包含在转换中。提示！已变更的文档短语在 G4 中以斜体显示。 |
| 计划公式 | 如果计划公式发生了变更，然后你在 G5 中再次进行这些变更，因为这些更改不包含在转换中。 |
| 时区 | 时区检查 公司信息 程序。如果你使用仓库选项，你每仓库检查。 |
| 生产日历 | 案件在 G4 中已创建了唯一的工作中心日历，然后你在 G5 中再次创建它们 生产日历 程序。 |
| ODBC链接和 SQL问好 | 案件你通过一或多个ODBC链接或 SQL问好载入数据，则必须重新进行这些操作。由于数据库的设计方式不同，全部报告（通常以 Excel 和访问）也必须重新制作。这也应用至将数据负荷到你自己设置的其它程序中。如果你希望获得帮助，则需要收取成本。 |
| 编辑已链接文档 | 在 G4 中，可以使用信息菜单（通过右键单击访问）并从那里打开已链接文档并编辑。所做的修改将被已添加到已链接的文档中，但不已保存在 PDF文档中。这意味着这些变更将不被用于在 Monitor ERP |
| 活动模板 | 不针对案件和项目进行转换，因为 G5 中有一个品牌的术语，称为“阶段”。因此，活动模板包含活动和阶段。 |
| 修改日志 | 转换至 G5 时不包含修改日志（为组件、订单等）。除了从 G4 转换而来的准备日志之外。 |
| ABC 代码–类型 | ABC 代码已转换，但类型将被设置为“未分类”。阅读更多内容 [ABC 代码](../../Stock/Parts/BasicDataPart/tABCCodes.htm)。 |
| 供应商评估外协 | G4 的外协采购不能在 G5供应商评估中进行分析。 |
| 程序指导 | 程序指导（您自己的关于使用某些程序的指导 Monitor ERP 不转换为 G5。如果需要使用该指导，你必须在每个程序中人工的复制它。 |
时间记录
| 程序/功能 | 去做 |
|---|---|
| 日程表日历 | 在 G5 中，称为“日程表日历”的程序被替换为 日程表周期 程序。必须已创建这些日程表周期并将其与员工联系起来。 |
| 导出工资底单 | 创建导出工资底单设置。如果你使用 KONTEK，则需要工资类型别名。将 KONTEK 中的格式更改为 PaXML。 |
| 工作记录日志 | 工作记录日志不转换为 Monitor ERP 然而，工单日志被用于在转换中。 |
| 出勤记录 | 出勤记录项目将转换为当前年度和回到一年前。也就是说，如果转换发生在 2022-02-15，你将看到从 2021-01-01 开始的记录条目。 |
| 调整出勤记录 | 如果在运行时进行转换，你需要调整G5 中日的记录条目，因为员工在转换期间已经登出。 |
| 短工时 | 有关短工时如何已计算的数据不转换。原因是它已保存在 G4 中的 ini 文件中，并且是每用户的设置。 G5 中默认每小时已计算短工时 。 参数组和日程表中的小时已转换。这些都已保存到 G5 中的相应位置。 |
货运配置
必须从头已配置货运 Monitor ERP 请记住预约一位具有特定知识或支持服务的顾问。此配置仅在实际的转换已完成之后才能进行。
> 请记住，这也涉及已已登记的货运- 这些货件不包含在 G5 转换中。
电子数据交换
必须从头开始已配置EDI Monitor ERP 请记住预约一位具有这方面专业知识的顾问。此配置仅在实际的转换已完成之后才能进行。

| 事务列表 | 事务列表不转换。请注意！事务列表中的编号序列也不转换，因为在 G5 中仅一编号序列。请记住人工的设置。 |
