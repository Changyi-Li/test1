### Settings – Register budget
Budget

#### Budget number
With this setting you determine which budget to load. The first budget number is shown by default.

#### Budget chart
With this setting you decide which budget chart the system should take into consideration when generating and manually enter budget rows in the list. This does not affect existing budget rows.

#### Primarily budget chart from account
If you have entered a fixed budget chart in the chart of accounts, this will primarily be loaded. Otherwise the default budget chart from the selection will be loaded. This does not affect existing budget rows.
View

#### Quantity
If you want to budget quantity you should check this setting. This means that columns regarding quantity will be shown in the list.
Generate budget rows

#### Generate empty budget rows
You should activate this setting if you wish to create a new budget and don't want to enter rows manually. The settings below becomes available when you check the checkbox. A list for the accounts you have selected under the Selection tab is loaded containing empty budget rows. You can enter budgeted values on any rows you wish. The account strings where a budget already exists are also shown among the rows and these are possible to modify. The accounts which are missing a budget are shown with 0 (zero) as budget.

#### Only accounts which are used
If you activate this setting, rows will only be generated for accounts which have been used.

#### Budget for dimensions
You can select on which levels to register budget. You can choose between CC (cost center), CU (cost unit), and Proj. (project). If you do not choose a dimension, "zero rows" will only be created on account level. If you choose cost center, "zero rows" will be created for account and cost center. If you select budget on the cost center level and have selected by a cost center in the list, then empty budget rows will become created in the list for the selected accounts and for the cost center.
