### Putaway strategy
A putaway strategy is a set of rules/priority order for how the system should suggest a location when arrival reporting a part to stock. Putaway strategies are used in the Stock location system option.

#### Sorting
You register a putaway strategy per Storage typeby moving the desired sorting term from the Sorting terms box to the Selected sort order box. Use the arrow keys to change the sorting order.
Settings

#### Putaway filter formula
During putaway, the planning formula defined in the Planning formulas procedure is used. It filters and presents the locations that can be used. See more about the formulas and variables in the Planning formulas procedure directly in the Monitor ERP software.

#### Use pick location below refill quantity
With this setting you decide if the pick location should also be refilled at arrival reporting if the quantity in the pick location is less than the refill quantity.

#### Use pick location for work center below refill quantity
With this setting you decide if the pick location for work center should also be refilled at arrival reporting if the quantity in the pick location is less than the entered refill quantity.

#### Include arrival location
With this checkbox you decide if the arrival location should be included in the putaway strategy.

#### Temporary storage area
Temporary storage area is used when the system fails to find a suitable location when arrival reporting to stock. If you are using the Warehouse option you should enter one Temporary storage area per warehouse.
