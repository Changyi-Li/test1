### General in the Time recording module

#### Migration
When migrating data from G4, only recording items from the current year and the two most recent preceding years, will be included to G5.

#### New name
The old module Workshop Info has been renamed and is now called Time recording. This has been done since it is almost as common to record time when working in an office as in the workshop.

#### Schedule management
The old management where one schedule describes one week has been redesigned. A schedule in G5 only contains schedules for one day and these days are instead linked together to a schedule cycle of the length you choose. In the Calendar procedure you enter your days off (if they differ from normal Swedish, Norwegian, Russian holidays). This replaces the schedule calendar which was used in G4 and in normal cases this also mean that no maintenance needs to be performed at the turn of the year.

#### Managing flex time
Now it is possible to use flex zones for all breaks in a schedule. In cases where you don't use flex for a break it is instead allowed to let the schedule start's flex zone overlap a break. As an example you can now add a negative flex zone to 11:00 a.m. even though there is a morning break scheduled at 9:00 a.m.

#### Lunch recording when limit for negative flex has been passed
If a person has a balance in the time bank for flex which has passed the minimum limit, then it is still possible to record flexible lunch. If the lunch is longer than the normal lunch time, then the person has to select an absence code since more negative flex will not be allowed.

#### Salary types/salary codes
The term salary codes has been removed and instead you can choose an optional number of salary types to be generated when recording.

#### Recording without schedule
When recording without schedule you can now get a salary type for attendance, which makes it easier during transfer to payroll programs.

#### Record on project activity
The handling of recording on project has been changed. You now record on the project activities that are registered. In the recording terminal there is a new tab at start work. There you can start project activities. This can either be done by having the activity delegated to the person or by searching via project number.
