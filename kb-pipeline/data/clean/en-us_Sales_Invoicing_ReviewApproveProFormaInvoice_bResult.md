### Result
In this box you see the invoice bases you selected under the Selection tab. Here you mark the invoice bases which you want to review, approve, and print/send by e-mail.

#### Include
In this column you determine if the document should be included.

#### Customer
Here you see the customer number of the customer on the invoice basis.

#### Order number
Here you see your order number/partial delivery number on the invoice basis. Prefix, if any, is displayed before the order number. If it is a comprehensive invoice, you will see several order numbers after each other. The customer number is only stated for the topmost order.

#### Invoice type
Here you see which type of invoice basis is concerned.

#### Printing method
Here you choose printing method for the pro forma invoice in question. The available alternatives are Printer or E-mail, that is, whether the document will be printed to a printer or attached as a PDF file to an e-mail message. The printout will be executed when the invoice basis has been approved. You select a default printing method in the Printouts box in the Customer register procedure. Please note! It is very common to select printer as printing method since pro forma invoices in many cases should be sent along with the goods. However, it is possible to send these by e-mail as well. For example, some use pro forma printouts as bases for advance invoicing. In the [Communication](../../Customers/CustomerRegister/bCommunication.htm) box in the Customer register procedure, you can for the customer enter that it should be recipient of pro forma for the communication type E-mail.

#### Document variant
Here it is possible to select a different document variant than the default, on which the pro forma invoice should be based. The default variant of pro forma invoice document is configured in the Document templates procedure.

#### Conflicts
If there is a conflict on the pro forma invoice, you will here see the button Conflicts ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_information.png). By clicking it you can see what is causing the conflict. It might for example be that another user has the invoice open in any of the procedures Register invoice directly or Review/Approve invoice. When a conflict exists, you cannot include the pro forma invoice for approval.

#### Delivery note number
In this column you see the delivery note number of the delivery.

#### Reused pro forma number
Applies to the list type called Pro forma Pro forma is a type of customs document which is used during export of goods. It is used to show information regarding the value of what is to be exported (customs cleared). Pro forma documents are also used in other contexts, for example much earlier than the time of delivery when contacting banks to arrange bank guarantees. from customer order. A pro forma number can be displayed in this column if the pro forma was printed previously and was then cancelled (via the Register customer order procedure).
When a new proforma forma invoice from customer order is printed, the system will remember this number and reuse it for the next pro forma invoice and this number is shown in this column
If you do not want to reuse the old number, you should mark the pro forma in question and click the button called Remove reused pro forma number and generate a new pro forma number ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_undo_release.png) on the toolbar.
