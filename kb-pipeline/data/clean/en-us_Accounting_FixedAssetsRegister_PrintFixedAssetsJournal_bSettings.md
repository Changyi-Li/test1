### Settings

#### Enter voucher date manually
With this setting you determine if you manually can enter a specific voucher date, e.g., if you wish to load the journal for old records belonging to a locked period.

#### Voucher date
In this field you enter the voucher date manually. This way you can direct the journal to a specific date if it for example contains old records belonging to a locked period.

#### Integration
Here you can see the type of integration configured for the list type in question:
- No – No integration has been configured.
- Direct – Object number is saved on all accounts in the voucher
- Direct – Object number is saved on balance accounts in the voucher
- Via journal – Object number is saved on all accounts in the voucher
- Via journal – Object number is saved on all balance accounts in the voucher
> A warning will appear if the fixed assets journal is not linked to a voucher number series. This is handled in the Voucher number series/Journals procedure.
