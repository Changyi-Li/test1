### Time
In this box you enter a time when the monitoring task should be active and run.

#### Until further notice
This box is checked by default. Then the monitoring task is active until further notice. You can also choose to deactivate it when one of the monitoring terms have been fulfilled. If you deactivate this setting you can instead choose Start time and End time.

#### Start time
Here you enter a date and time when the monitoring task should be started.

#### End time
Here you enter a date and time when the monitoring task should be ended.

#### Deactivate monitoring when any of the terms are fulfilled
If you activate this setting, the monitoring task will be deactivated when one of the monitoring terms have been fulfilled.
