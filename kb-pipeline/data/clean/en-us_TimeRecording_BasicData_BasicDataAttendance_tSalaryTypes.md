### Salary types
Salary types are used to create salary bases for worked time and absence, for example, for regular working hours, flex time, makeup time, overtime, sick leave, etc.

#### Salary type
In this column you see/enter the code of the salary type. It can consist of a maximum of 8 characters.

#### Name
The name of the salary type. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Salary type class
Here you select the class of the salary type. The salary type classes you can select among are the ones registered under the tab Salary typeSalary types are used to create salary bases for worked time and absence. Different salary types are used, for example, for work during regular working hours, flex, overtime, shorter working hours, and sick leave. The salary bases are used to manage salaries in a payroll system. Salary types are linked to absence codes in addition to work schedules and overtime schedules. classes.

#### Export
Here you select in which time unit the recorded time should be exported to an external payroll program (option). You can select among the following alternatives:
- None – This option means the salary type will not be exported.
- Hours – The salary type will be exported in the unit "hours". All the hours for the salary period will be totaled to one row.
- Hours + date – This option is mainly used for absence salary types. The salary type is exported in the unit "hours" and with the start date and end date of each absence.
- Days – This option is mainly used for absence salary types. The salary type will be exported in the unit "days". All the days of the salary period will be totaled to one row.
- Days + date – This option is mainly used for absence salary types. The salary type is exported in the unit "days" and with the start date and end date of each absence.

#### Attendance/Absence
In this column you select how the salary type should be exported to the payroll program; if it should be exported as attendance or as absence.

#### Alias at export
Here you can enter an alias for the salary types used during export of salary basis to the payroll program. If the same alias is used for multiple salary types they will be merged when they are exported to the payroll program. If you have not entered an alias the salary type's code in the first column will be exported.
