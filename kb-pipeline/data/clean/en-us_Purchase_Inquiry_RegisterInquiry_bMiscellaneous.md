### Miscellaneous
Here you find miscellaneous information about the inquiry. The information entered here is the same as in the [Miscellaneous](../../Orders/RegisterPurchaseOrder/bMiscellaneous.htm) box on a purchase order, apart from the information described below.
Order date will be set in the Purchase order box, when a purchase order is created from an inquiry.

#### Status
The status of the inquiry can be selected manually, but certain statuses are set automatically by the system at different events.
- 1) Registered – This is the default status for new inquiries that you register.
- 2) Printed – This status is given when the inquiry is printed and the printout has been approved. The inquiry will also get a printout date, and a printout log will be created per document.
- 3) Responded – This status can be set manually when a response to the inquiry (e.g. a quote) has arrived from the supplier.
- 6) Finished – This status can be set manually if no response or other response has arrived from the supplier regarding the inquiry.
- 7) Partial order – This status is used when a purchase order is created of some of the rows in the inquiry, and you choose to keep the inquiry active.
- 8) Order via related inquiry – This status is used when a purchase order is created from a related inquiry and you choose to finish/close the related inquiries.
- 9) Order – This status is given when a purchase order is created for all rows in the inquiry.
