### Stock management and stock valuation
Tools can be handled in the same way as parts in the stock procedures. This means that you can perform stock count, move, and perform direct stock reporting also for tools.

#### Stock valuation
Stock valuation of tools are made in the same way as for normal parts in the Stock value procedure. By selecting by Basic type and other suitable terms, for example Part template, you will only load stock values for tools or for a specific group of tools.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/TrainingMaterial/ToolsStockValue1.png)](../../../../Resources/Images/TrainingMaterial/ToolsStockValue1.png)

#### WIP
Tools that have been withdrawn to manufacturing orders are not valuated in the WIP. This is determined by that the setting Use in calculation is not checked in part templates with a basic type for tools.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/TrainingMaterial/ToolsNotInWIP.png)](../../../../Resources/Images/TrainingMaterial/ToolsNotInWIP.png)
In order to value tools that have been withdrawn to manufacturing orders, you instead use the list type Withdrawn reusable tools in the stock value list. The list type concerns withdrawn tools of the basic type Reusable. These tools are valued in this list and not in the WIP value procedure.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/TrainingMaterial/ToolsStockValue2.png)](../../../../Resources/Images/TrainingMaterial/ToolsStockValue2.png)
