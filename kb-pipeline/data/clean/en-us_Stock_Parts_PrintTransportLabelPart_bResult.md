### Result
In this box you can see the parts that you have selected and loaded. One row is shown per part, location, and batch/serial number.

#### Include
The rows that are checked in this column will be printed.

#### Balance
The balance that is shown per row applies to the part number on the location.

#### Number of copies
Here you select the number of copies of the transport label that should be printed. The default value here is 1. If you want a different default quantity, this is configured in the Document settings procedure.
