### Packaging parts
In this box you will by default see the packaging parts which are linked to the parts on the pick list. The information on the packaging parts is loaded from the part register.
A packaging type is indicated with a symbol in the Type column. A tooltip is shown when you hover over the symbol, displaying an explanation. The available packaging types are: EUR pallet, Outer packaging, Inner packaging, Cover packaging, and Unspecified.
In the APN column (Assign package number), a "Yes" is shown if the packaging part should be assigned a package number.
Under the button More info ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png), the measures and volume of the packaging part are displayed. Here you can also see the packaging part's pick instruction, if such has been entered.
By using the button Show unlinked packaging parts ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_show_hidden.png) on the function menu, you can show all packaging parts in the part register.
Using the button Find ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_search.png) (Ctrl + B) you can search in all columns.
Using the button Go to procedure ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) you can use the link to go to related procedures for the marked row, for example, to change information on the row.
By using the Distribute remaining quantity button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_package.png), you can choose to distribute the parts in the To pack box, with quantity of choice per package, in the selected packaging part. That is, x pieces of each part is placed in the selected packaging part. In the window which opens you can at the top enter Qty/pkg and press Tab or Enter. This way the rows with parts will be entered with the quantity per package you have specified. You can also enter Qty/pkg on the rows for each part. This is done if there should be different quantity per package for the different parts.
You can decrease the Remaining quantity to pack but you cannot enter a quantity greater than what is actually left to pack.
> With the drag and drop function you can use your mouse pointer to add of packaging parts from here to the Package structure box.
