### Deviating capacity
This box is available if the work center you selected in the box above, have the time precision Day planningDay planning is used when you are NOT applying hourly planning. It means that all operations are planned to a date and not to a specific time on a date..
In this box you enter capacity deviations for marked days in the calendar. That is, for the work centers with a check in the Include column in the work center table. If there are several different capacity deviations among the selected work centers, this will be shown on separate rows.
If no deviating capacity has been registered, you will see one row for the days that have the same capacity. E.g. 8 hours from the standard calendar in the Calendars procedure. Each variant of the capacity gets a separate row if you have selected more than one date. If you select three days where two of them has a capacity of 8 hours and one of 6 hours, you will see two rows where the one with 8 hours capacity will show two as number of dates. You can also see the work centers which are concerned.
You can register capacity deviations for dates that have already passed, but in that case, the dates are shown in gray color. This is saved for the work center on day level and not as an interval.

#### Current capacity
Here you can see the current capacity for the work centers for the selected days in the calendar.

#### New capacity
Here you can enter the deviating capacity which will apply. If you for example enter 6,00 here, the new capacity will be 6,00 hours.

#### Number of dates
Here you see the number of dates that have been selected per calendar in the calendar view.

#### Work center
On this button you will see a number within parenthesis which indicates how many work centers that have been selected to be included in the deviation of capacity. If you click the button, you can see the work centers in question.
