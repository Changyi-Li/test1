### Installation
In this box you can manually enter the installation information.

#### Order number
In this field you enter the order number to which the installation is linked.

#### Installed by
Here you can choose to link the installation to a user who is registered in the system.

#### Installation date
Here you enter the date when the installation will take place or has taken place.

#### Code
Here you can enter a code applying to the installation.

#### Comment
Here you can enter a comment regarding the installation. By clicking the Files button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_file_link.png), it is possible to link different files related to a comment or an instruction for the record in question. When the setting Automatic printout is available for activation, you can choose to get the linked file automatically printed. Read more in the topic [General features](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LinkFiles) about how to link files, automatic printout, and where linked files can be automatically printed. If there are linked files, you will see this symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_file_linked.png) on the button.
