### User, role, and person

#### Personnel records
Information about personnel in the company is now merged into a joint personnel record instead of having to repeat certain information in many registers, such as references, employees, users, and sellers. In the personnel records you can configure which persons should be for example sellers, and in that case enter specific information used for sellers. A person can also be linked to a user in the user register.

#### User register
The user register is a separate register and it determines who can log in to the system. A user can be linked to a person in the personnel register if the login applies for a specific person.
A new feature is that each user is given a role. Roles are predefined and are used partly to determine which user right apply for the user in the system, but it also determine which information will be shown to the user in some cases and how search results will be prioritized.
