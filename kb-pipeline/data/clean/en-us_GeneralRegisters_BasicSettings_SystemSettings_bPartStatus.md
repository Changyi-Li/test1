### Part status

#### Default part status for new part
This system setting determines which part status will be used by default for new parts: Quote, Prototype, New part, or Normal.

#### Change part status 2 to 3 when creating new M-order and P-order
This system setting determines if part status 2 (Prototype) should be changed to status 3 (New part) when creating a new manufacturing order or purchase order for the part.

#### Change part status 3 to 4 when creating new M-order and P-order
This system setting determines if part status 3 (New part) should be changed to status 4 (Normal) when creating a new manufacturing order or purchase order for the part.

#### Change part status 5 to 4 when creating new M-order and P-order
This system setting determines if part status 5 (New revision) should be changed to status 4 (Normal) when creating a new manufacturing order or purchase order for the part.

#### Change part status 4 to 5 at new active revision on part
This system setting determines if part status 4 (Normal) should be changed to 5 (New revision) when a new active revision is set for the part in the part register or BOM and routing.
