### Packaging terms
In this table you register packaging terms. Packaging terms are used to describe the packaging terms that will apply to suppliers, inquiries, and purchase orders.

#### Default
Here you determine if the packaging term should be used default when registering new suppliers.

#### Number
Here you can see the number for the position of the row. This field is numerical. A new row will by default be assigned the next available number. The table/list is sorted by this column. A number is unique and cannot occur on more than one row in the table.

#### Name
Here you enter a description of the packaging term. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.
