### General in the Manufacturing module

#### Day planning vs Hourly planning
It is possible to select which Time precision to apply on the dates regarding manufacturing orders: days or hours. A system setting is available making it possible to select time precision per work center for the capacity. You can choose between Day planningDay planning is used when you are NOT applying hourly planning. It means that all operations are planned to a date and not to a specific time on a date., Capacity via schedule, and Hourly planningHourly planning refers to when planning per work center is done per hour. Hourly planning is activated with a system setting. Period is then entered as date and time. You can view loading on hour basis.. The two final options are similar since you in both cases enter when in the day there is capacity either via a schedule cycle or an exception in the production calendar. The difference is that only hourly planning shows the time on the work center's operations. The dates showing time are all start and finish times for manufacturing order, new finish, and loading. Queue times are also shown in hours instead of days when hourly planning is applied. Subcontract on the other hand always uses day planning since you do not know the subcontractor's capacity for the day.

#### Subcontract
In a subcontract in the BOM and routing, a subcontract part is automatically created in the part register. On this part all information concerning supplier, price, weight, transport cost, etc. is saved even though the information is possible to edit in the BOM and routing.
When the manufacturing order is created, a subcontract purchase order is directly created for the subcontract operations.
The subcontract purchase orders are complete with order header and rows, where the subcontract part is on the row. On these documents information about the main part and the manufacturing order is also shown. The subcontract purchase order is of the order type Subcontract which (if you reschedule it) also can reschedule the manufacturing order. It is possible to print purchase order and delivery note directly in the Register purchase order procedure (printout per order).
The procedure where comprehensive purchase gathers several subcontracts and gives these a collective number (not a purchase order number since this has already been set when registering the manufacturing order).
The subcontract purchase is monitored in the same procedure as the material purchases: Order list – Purchase. In this procedure there are two list types which only handle subcontract purchases and they contain more information about manufacturing order and makes it possible to monitor what has been shipped.
Arrival reporting, receiving inspection, calculating/measuring delivery reliability, etc. are handled is the same way as for any other purchase and in the same procedures. However, transport labels will be printed when arrival reporting and at receiving inspection.

#### Replan times and material quantities on order
In the procedures Priority planning and Pool planning, there is a function you can use to replan operation times and planned material usage. This is done for selected operations by using the button Replan on the function menu in the priority plan. By default these operations will become merged into one reporting batch. All work items in the reporting batch gets a unique color in the priority plan and the Recording terminal, and is then automatically selected in the recording terminal when one of the operations included in the batch is selected by an operator.

#### Change work center
If the function Change work center is used in the procedures Priority planning or Pool planning, then there are the new features:
- The search for a work center takes place via a LookupThe Lookup feature is a powerful search tool which allows you to search and load information from large registers. You open the Lookup feature by clicking on the dropdown button or by using F4 on your keyboard. feature.
- If there are alternative work centers in the BOM and routing, these are the only ones shown in the Lookup feature. However, there is a setting which makes it possible for you to see all work centers, except subcontract work centers.
- There is a setting you can activate to suggest the work center to which operations were most recently moved.
