### Users/Signers
In the Users box, you add users who should be able to register and save purchase orders as well as users who should be signers of purchase orders.
By using the button Create signers based on users ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_show_responsible.png) you can add all users from the user register. Some users might already be added via the button Add new row at the end ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_row.png) (F5). In the dialog box that appears you can configure if all users should be Signer of Purchase order, enter an Amount limit on purchase order, and select a Head signer. To be able to select a head signer you must first have set at least one user in the box Users as Signer of Purchase order.
When all users have been added by using this button, duplicates of the signer code might be created. This is because the function loads the first four characters in the user name and sets it as signer code. If so, you must adjust this afterwards by changing the signer code on the duplicates since the signer code must be unique.
The button Delete selected row ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_delete_row.png) (F6) can be used to delete users who should not be included.

#### Signer code
The user’s signer code is an optional unique code for the user/signer. The field is alphanumerical and can contain a maximum of 8 characters.

#### Users
Here you select the user who should be added. By using the Lookup The Lookup feature is a powerful search tool which allows you to search and load information from large registers. You open the Lookup feature by clicking on the dropdown button or by using F4 on your keyboard. feature (F4) you can search the user register. In the columns to the right you see the user's name and role.

#### Signer of
If the user should be signer of Purchase order, this is selected here. If the field is empty, the user can only register and save purchase orders.

#### Active
A user you have added is active by default. Active determines whether a user is a signer. By unchecking this box, you can set a user as inactive if needed. Please note! An inactive user can register and save purchase orders.
