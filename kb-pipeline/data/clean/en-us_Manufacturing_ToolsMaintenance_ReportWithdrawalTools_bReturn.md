### Return
In this box you find a list of the tools that have been withdrawn in the procedure and which can be returned to the stock.
If the option Warehouse is installed, you can use the warehouse selector ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_warehouses.png) on the toolbar of the procedure, to select to which warehouse the return should be made. You can only return tools to the same warehouse from which the withdrawal was made.
On the function menu there is a button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/gridEmployeeImage16x16.png) you can use to show only tools withdrawn to the person selected in the field Withdrawn to.
For each tool you see information about the withdrawal. This is information loaded from the [header row](hReportWithdrawalTools.htm) and from the [Withdraw](bWithdraw.htm) box.

#### Return
Mark this checkbox for the tool you wish to return.

#### Quantity for return
Quantity for return will by default be the same as Available quantity for return when you check the Return checkbox. For tools without serial numbers it is possible to enter a different quantity. However, it cannot be greater than then available quantity for return.
