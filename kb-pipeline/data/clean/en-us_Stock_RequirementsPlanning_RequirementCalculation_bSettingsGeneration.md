### Generation – Settings

#### Manufacturing order type
With this setting you determine which order type should be given to the manufacturing order when you turn the suggestion into an order. Linked requirements always get the type Customer order oriented.

#### Dividing
With this setting you determine how the dividing for the suggestions should be made. If you choose the option Supplier, then one purchase order per supplier will be created. If you choose the option Part, then one purchase order per part will be created.

#### Purchase order type
With this setting you determine which order type should be given to the purchase order when you turn the suggestion into an order. Only types of the basic type Buy material can be selected.

#### Purchase order type – Stock order
This setting is available if the Warehouse option is installed in your system. Here you decide which order type for stock order that the generated actual orders will have. The choice made here affects e.g. the purchase statistics and priority of the generated orders. You can select among the order types with the basic type Stock order that are active in the Order types procedure.

#### Our reference
The reference you select here will be used as Our reference on generated purchase orders.

#### Goods label
Here you enter what should be entered as goods label on the generated purchase orders.

#### Only create suggestions against definite shortage
With this setting you decide if suggestions should only be created when there is a definite shortage. If the box is not checked you will also get suggestions regarding the safety stock. If you activate this setting, suggestions will be created for parts with definite shortage. Definite shortage means that the disposable balance is negative in the planning window within the selected date interval, regardless of safety stock or reorder point. This will also take the part's settings regarding minimum quantity, rounding quantity, and order quantity, into consideration.

#### Suggest "Apply" for all suggestions
Here you decide if all the suggestions should be applied (converted into actual orders) when you click Apply suggestion.

#### Suggest "Apply" for rescheduling suggestions
Here you decide if the suggestions you replanned should be applied when you click Apply suggestion.
