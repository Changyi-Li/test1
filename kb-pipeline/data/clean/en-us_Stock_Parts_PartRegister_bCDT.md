### CDT
The CDT CDT is short for check delivery times and it is a function on order rows which calculates when the order row in question can be delivered, taking lead times and throughput times into consideration. CDT also checks if existing orders and suggestions can cover material shortages, if any, and affects when the order row can be delivered. ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) is shown if you are apply check of delivery times (CDT), which is activated by a system setting. By clicking the button you access the following functions.

#### Earliest delivery date (CDT)
The fields Earliest delivery date (CDT) and TPT (CDT) are empty by default, but you can see what the delivery date will be and the throughput time for the part by running a CDT calculation. This is done by using the button Run CDT ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_delivery_time_check_again.png) on the toolbar of the procedure.
The earliest delivery date is applicable if you were to register a customer order for the part today. The combination of system settings for CDT, the loading situation in work centers, and the part’s order quantity, determines the earliest delivery date.

#### Throughput time (CDT)
The field TPT (CDT) shows the part’s throughput time in number of work days. This is a result of the earliest delivery date calculated by the CDT.

#### Show CDT's planning window
By clicking the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/StatusRegistered.png) you can show CDT's planning window. Please note! You must perform a check of the delivery time from this procedure in order for the CTD planning window to be shown.
