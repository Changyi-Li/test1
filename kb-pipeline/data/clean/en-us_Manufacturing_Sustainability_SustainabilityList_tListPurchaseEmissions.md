### The purchase emissions list
This list is used to gather Co2e2e values found on supplier invoices in Monitor ERP. This list can be a good option during startup when you have already registered supplier invoices and need to add further CO2e values. You can also use the list to correct the CO2e values on purchased parts. Alternately, you can get these values into Monitor ERP when registering supplier invoices.
When you have loaded the list with updateable activated, you will receive suggestions for New emission, material type based on the settings on parts and accounts. If the column Emission value difference has a difference, you can check Save to update the emission value. If you want to select manually, you need to select Emission type in the New emission, emission type. A value will then be calculated for the row, and you can check Save to update the emission value.
