### Report
In this box you select which report to load.
The reports available are the ones included in the system and the ones you have created and configured as active. You can use Ctrl + click your mouse to select multiple reports for printout at the same time.
It is possible to go to a marked report to the procedure Create accounting report by using the button Links![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) on the toolbar.
> By clicking the button called User rights to view/print in the Create accounting report procedure, it is possible to configure to whom a report should be available. This can be decided by group level, role level, or user level.
> Please note! The Clipboard function is not available under the Selection tab in this procedure.
