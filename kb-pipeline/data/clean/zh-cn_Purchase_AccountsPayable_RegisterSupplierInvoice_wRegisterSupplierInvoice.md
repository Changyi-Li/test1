## 登记供应商发票
在此程序中，你可以登记新供应商发票、修改现有的发票以及贷项或取消发票。你可以登记借项发票、贷项发票和利息发票。你还可以在这里最终记录发票。多个用户可以时间按照此程序工作发票。
登记
在标准中 Monitor ERP 系统,登记是人工的完成 的 .如果客户和供应商两者使用 Monitor ERP、订单和发票可以以XML文件的形式通过Email已发送和已收到。然后你可以在此处导入供应商发票并自动已登记。阅读更多内容 [Monitor - to - Monitor](../../../UserGuide/GeneralFeatures/M2M.htm)。
暂估输入
你可以在登记连接应用暂估输入发票。这是通过系统设置已激活的 供应商发票暂估输入。暂估输入意味着发票默认已编码账在暂估应付标准科目和暂估科目上，以及进项 VAT科目上，挂起最终编码。
可以输入预估采购过账（预过账）。你可以创建暂估输入和最终记录的过账。这些可以通过日记账已打印或者直接已记录到会计中。你还可以用其他货币创建过账。仅已登记或暂估记录的发票不能已付款。
一旦你登记或预估记录发票，你就可以将采购订单预估链接到物料发票。
过账
在过账框中你供应商发票的输入过账。当你登记新建发票时，你可以开始预先发布供应商发票，但这是可选的。在这种模式下，即使还有一些待过帐金额，你也可以保存发票。如果为供应商已选择了采购科目，则在你发票金额之后，该科目的过账将自动加载，但可以修改过账。
如果你在最终记录之前创建过账过发票，并且你 电子发票管理 （见低于），当发票被送至审核时，这些过账将被用于在发票中。
可以通过点击在发票上过账使用应计原则 应用计提科目 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_period.png) 在功能菜单中 过账 盒子。如果当前账户在应计账户中被标记为计提科目，也可以自动完成此操作 会计科目表 程序。
如果选项 固定资产登记 安装后，你还可以在最终记录发票时登记固定资产。点击按钮即可完成 登记 / 补充固定资产对象 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_fixed_assets_object.png) 在功能菜单上。如果当前账户在计提科目中被标记为 会计科目表 程序。
你最终记录发票 最终记录 在过账箱里。最终记录也可以在 订单链接 标签页 最终记录 按钮。
采购订单链接
对于物料发票，你可以通过第一个选择页眉行上的采购订单号或选择采购订单下的采购订单链接采购订单 订单链接 标签页。在该标签页下方的上方框中，你可以看到已选择供应商已到货已登记的采购订单。在底部的框中​​，你可以看到你已选择包括的采购订单的订单行。然后你你链接到供应商发票的订单行。对于每个订单行，可以更新价格，折扣，VAT 代码和过账。
如果你链接一份外协采购订单，且其所属的工单已经最终已报告且状态为 9（历史），然后出现一条警告，通知你外协成本将不在工单上已报告。在这种案件下，你有两个选项。1）继续进行发票登记，忽略外协成本不在工单上已报告的事实。2)取消发票登记并将工单上的状态更改后退6（已交货）。然后继续进行发票登记，并链接外协采购订单。这样，外协成本就会在工单上已报告。然后你再最终报告工单。
当你已完成采购订单的链接后，你可以最终记录订单发票。这就是为什么你也会查询 最终记录 按钮位于此标签页的底部。然后你将被已传输 供应商发票 标签页，然后在 过账 在框中你可以看到发票的过账，包括你通过订单行链接已创建的过账。
可以自动过账价格差异和汇率差异过科目到单独的价差科目并记入汇兑利润/汇兑亏损。这是在链接订单行之后最终记录连接供应商发票时完成的。订单获得汇率已编码，供应商发票和已链接订单行必须使用相同的货币。系统设置 在登记发票时记录价差 确定是否应已编码价差和汇率差异。
最终记录
你可以在登记期间最终记录发票，也可以通过负荷已已登记/暂估记录的发票并通过单击 最终记录 过账框中的按钮，然后保存。如果你在登记保存你之前应用暂估输入并最终记录新建发票，否已创建暂估输入。
在你订单发票保存为已最终记录之前，你仍然可以将采购订单链接到它。但是如果你已将发票已保存为已最终记录，你就否再链接采购订单。如果你最终记录一张具有暂估输入的发票，则预估分录的过账将被最终记录的过账（即常规的科目的过账）所替换。
如果你最终记录了发票，最终记录可以撤销 撤销最终记录 按钮。只要你没有将发票未保存为已最终记录，就可以撤消此操作。然后可以已付款已已最终记录的发票。
如果你使用 电子发票管理 （ EIM ）选项，你可以通过就绪 为最终记录 导航面板中的收件箱。
供应商发票的贷记或取消
当对供应商发票进行贷项时，你可以选择或不将整个借项发票记入贷项。如果你选择不贷项整个发票，你必须人工的输入要记入贷项的发票金额和过账过账。如果有已链接的采购订单，你还可以在订单行上层级选择你想要在借项发票上贷项的内容。
如果你使用 电子发票管理 （EIM）选项以及 EIM 工作流 选项，已导入的贷项发票将自动放置在 登记贷项发票 导航面板中的收件箱。从这里你载入这些发票并以常规的方式贷项。
阅读如何贷项或取消供应商发票 [登记供应商发票](../../../UserGuide/Using/AccountsPayable/RegisterSupplierInvoice.htm) 下的章节 使用MONITORG5 -> 应付账款 在线帮助功能中的菜单。
电子发票管理 (EIM)
使用选项 [电子发票管理](../../../UserGuide/Using/EIM/ElectronicInvoiceManagement.htm) （EIM）你可以将纸质发票扫描为 PDF格式，当你登记这些发票时，会显示发票的图片，然后你可以在登记期间链接该图像（见低于）。EIM 还提供为审核列表的支持。这些与已登记的发票相连，从而可以在审核轮次中发送它们。使用 EIM 时还支持审核人组和会签。
EIM被用于解释和导入供应商发票和电子发票的功能。还包含向客户导出电子发票的功能。请阅读低于以阅读更多相关内容。

你可以激活解释/捕获供应商发票的功能。解释/数据捕获是通过名为 CrossState 的外部的软件完成的，该软件与 Monitor ERP 通过 API。借助解释功能，供应商发票将自动使用OCR 编号进行解释，并已传输至 用于登记 / 验证 收件箱箱中的 导航 盒子。从这里你可以导入发票并登记它们。
要激活解释功能，你必须在 EIM被用于的插件中创建一个科目 CrossState 电子发票。你查询此导入类型的插件 供应商发票， 在下面 导入 标签页卡中的 导出 / 导入设置 程序。
在 CrossState 中你核实解释的发票行。可以重新解释被错误解释的发票行。通过这种方式，你“教育”解释功能，使其在未来的解释中更多准确。
如果您的供应商可以发送电子发票，你也可以激活导入电子发票的功能。你可以在同一插件中激活此功能： CrossState 电子发票。电子发票否解释/标题。相反，它们将自动已导入到 挂起的 收件箱箱中的 导航 盒子。如果你已经输入了供应商的审核人，发票将自动送至审核，而不放置在一收件箱中。
导入是通过 CrossState API 进行的 Monitor ERP。

EIM 工作流
你可以添加选项 EIM 工作流 到您的 EIM。这将使供应商发票的流程自动化：登记、采购订单与物料发票的链接、审核和最终记录。你可以通过EIM 工作流实现完全自动化的流程。通常情况然后，你不在此程序中处理任何发票。
对于物料发票，要求发票行能够和相应的采购订单行已匹配。对于费用发票，流程更多直接一些，因为否层级行匹配，也不否链接采购订单。如果你行层级应用审核（通过系统设置已激活，称为 在过账行上使用扩展审核)匹配将层级行。
如果安装了EIM 工作流 ，你还会查询按钮 保存并发送至工作流 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_save_and_send_to_workflow.png) 在程序的 工具栏 上 。如果发票在收件箱中并且你已固定其原因，然后你可以使用此按钮。然后，如果发票在任何流程中，它将被已发送到审核和最终记录等 创建审核列表 或者 查找订单 / 组件 收件箱（见低于）。
使用EIM 工作流，其他收件箱将已添加 导航 盒子。（不显示XML收件箱，因为使用EIM 工作流时将自动从这些收件箱导入发票。）每个收件箱代表发票流程中的一个步骤。在名为 [导航](bNavigation.htm)。在里面 审核供应商发票 程序，还已添加导航框和一些带有EIM 工作流的收件箱。
如果工作流无法将发票行与采购订单行已匹配，则你核实在 发票行 和 采购订单 订单链接标签页下的盒子。在这种案件下，外部的软件CrossState 将不用于验证。当你安装了EIM 工作流选项后，将已添加“订单链接”标签页下的“发票行”框和“供应商发票”标签页下的“发票行”框。

#### 取整和EIM 工作流
在导入供应商发票时，系统将负责取整。如果发票包含有关取整的信息，则不在审核流中处理/已编码。解释/已导入的取整显示低于 过账 盒子。取整会自动已编码标准取整标准科目。这与发票的最终记录连接。

#### 价格要素的处理
已导入的发票行中价格要素的导入按以下方式处理。价格要素可以例如显示每100 个的单价。关于发票已创建时间 Monitor ERP，单价通过价格要素自动转换为正确的单价，从而可以与采购订单进行匹配。此功能要求你从发票行中解释价格要素。
例如：发票上单价为 10欧元，解释价格要素为 100。结果的单价为 0.1欧元，即采购订单中输入的价格。如果你然后每个0.1欧元的价格采购件了1000件，这将被解释为 1000件，价格为 10欧元/100。解释的单价转换为正确的单价（单价） Monitor ERP。发票上的单价和 Monitor ERP 由于导入时使用的价格要素不同，价格可能会有所匹配。
