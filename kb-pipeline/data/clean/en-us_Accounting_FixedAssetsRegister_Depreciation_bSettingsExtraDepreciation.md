### Settings

#### Voucher text
Here you enter the text that will be shown on the voucher. "Extra depreciation" is entered by default, but it can be changed. Voucher texts are handled in the Voucher texts procedure.

#### Integration
With this setting you determine if and how the depreciation item should be booked. Here you can choose between No and the integration option which is active in the procedure Voucher number series/journals.
With the option No it is possible to temporarily turn off the integration with the accounting.
The other options which might be available in this setting are:
- Direct – Object number is saved on all accounts in the voucher
- Direct – Object number is saved on balance accounts in the voucher
- Via journal – Object number is saved on all accounts in the voucher
- Via journal – Object number is saved on all balance accounts in the voucher
Please note! Extra depreciation will affect future depreciation amounts.
> Please note! Extra depreciation will affect future depreciation amounts.

#### Automatic posting active
With this checkbox you determine if automatic posting/allocation should be active.
