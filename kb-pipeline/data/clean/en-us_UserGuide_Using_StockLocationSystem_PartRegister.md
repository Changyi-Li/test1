### Part register

#### Package sizes
On the part there are a number of different places where you can specify the part’s package measurements.
A way to simplify giving packaging properties is to use packaging parts. The measurements can then be entered for the packaging part and these are loaded to the packaging properties.
If there are different suppliers who supply the same part in different manners, e.g., supplier A uses a pallet with two collars and supplier B uses a half pallet with 3 collars, you can assign the packaging per supplier in the supplier link.

#### If the part is of the type manufactured you can use internal measurements on the packaging with properties which are entered in the Manufacturing tab.
