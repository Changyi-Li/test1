### Header row

#### Schedule number
This is the number or code for the schedule, a maximum of 10 characters is allowed. You can either select an existing schedule number or you can enter a new schedule number. If you enter a new schedule you will be asked a question if the new schedule should be a work schedule or an overtime schedule. After that you can enter settings for the new schedule.

#### Name
Here you can write a descriptive text as a name. You enter name texts in the company language and they are displayed in the user’s language.
By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Night schedule
Applies to Work schedule. Using this checkbox you can determine if the work schedule should be a night schedule. For a night schedule the working time stretches passed midnight.

#### Overtime schedule
Applies to Work schedule. Here you select the overtime schedule to link to the work schedule. By using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you can see the overtime schedule in chart form.

#### SWH
Applies to Work schedule. Here you enter how much shorter working hours (SWH) each hour entitles in the work schedule. You can enter the value using up to 4 decimals.

#### Available overtime types
Applies to Overtime schedule. Here you select which overtime types the overtime schedule should contain. When you mark an overtime type it will be added to the table in the Salary types box. You register overtime types and salary types in the Basic dataWith "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Attendance procedure.

#### Schedule number for export
This field is only available if the option Export of salary basis is installed. The field is used to give work schedules and overtime schedules a different number when exporting to an external payroll program, other than the number of the schedule in Monitor ERP.
