### Show – Settings

#### Unit
This setting determines in which unit the part should be displayed. If you choose Default, the part is shown in the unit that is set as default in the part register. If you choose Purchase, the part will be shown in the unit that is set as default for the purchase order under the button Usage in the part register.

#### Consumption statistics
With this checkbox you determine if consumption statistics should be shown in the list. Three columns can be displayed for 3, 6, and 12 months' consumption.
