### Settings (result)
Here you configure settings for the result of the agent task.

#### Language
Here you select in which language the result including lists, if any, should be printed.

#### Notify
By clicking this button you can decide to whom notifications should be sent regarding the agent task. You can choose from different roles, groups, and users. You can also enter if notifications should be sent when the agent task is completed and when an error has occurred when running the task.

#### History
When clicking this button you find a log of previous runs of the agent task in question. In the log you can see date and time for the calculation as wells as the status of the calculation. A green check mark is shown if the run was performed, while a red cross is shown if the run failed.

#### E-mails
The setting for e-mail is applied to procedures run by agent tasks which produce a result, which can then be sent by e-mail. Here you enter the text which should be shown in the subject row and the text for the e-mail message for e-mails with results from these agent tasks. These e-mails will be sent to the receivers you entered in the Communication box under the Procedures tab.

#### Comment
By using this button you can enter a comment about the agent task. By clicking this button you access a text editor where you can write and format text, insert images and signature, and hyperlinks, etc. When a comment/text exists, the symbol on the button will change from an empty speech bubble ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_no_comment.png) to a filled speech bubble ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_comment.png).
