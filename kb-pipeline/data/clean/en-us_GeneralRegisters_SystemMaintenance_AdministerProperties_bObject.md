### Object
In this box you see a structure map including all objects in the selected property set.
The branches in the structure map that have objects that use properties are displayed in orange color. The objects that use properties are displayed in bold font and with an asterisk (*).
When you mark an object, the Properties box displays what is possible to use on the object.

#### Filter
In the Filter field you can enter the name if the objects in order to filter only these objects in the structure map.
