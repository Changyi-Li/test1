### Posting
The posting box is available both for regular depreciation and for extra depreciation. In the box you see how the depreciation will be recorded, for the selected row in the list. If there are more than one depreciation item in the posting table, then you can activate the Total accounting order checkbox to see how the entire voucher will become. In the column Fixed assets object you see the asset/object numbers set on each posting row and transferred to the created voucher. When you activate the setting mentioned above it means you will see the double amount of rows in relation to the number of assets/objects which are depreciated.
In the Voucher number series/Journals procedure there is a setting which you can use to determine if all postings should be posted on assets/objects or only on balance accounts.
