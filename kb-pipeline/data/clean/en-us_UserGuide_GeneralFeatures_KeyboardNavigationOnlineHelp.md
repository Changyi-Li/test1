### Keyboard navigation in the online help function
You can use keyboard navigation in the online help function. A frame is displayed around the object in focus when you use the Tab key to navigate ahead. Use Shift + Tab to move backwards.
![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/KeyboardNav1.png)
A button which is in focus can be activated by pressing Enter or the space bar. For example, to perform a printout.
![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/KeyboardNav2.png)

#### Sub-menus
You can access sub-menus via the keyboard. If you press Tab on a menu which has a sub-menu, a small button is shown to the right for the sub-menu.
![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/KeyboardNav3.png)
If you press Enter or the space bar, the sub-menu will be displayed when the button is in focus.
![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/KeyboardNav4.png)
You can continue by pressing Tab to navigate in the sub-menu.
![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/KeyboardNav5.png)

#### The find function
In the online help function there is a find/search function. When you have entered a text in the search field you can start the search using Enter. You can also use Tab to place the focus on the search button. Then you can start the search either by Enter or the space bar. Read more about [searching in the online help function](../../Search.htm).
![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/KeyboardNav6.png)
