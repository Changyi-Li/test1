### Manufacturing order suggestion
- Manufacturing order suggestion, Rescheduling suggestion - In, and Rescheduling suggestion - Out have been merged into the procedure called Manufacturing order suggestion which has been moved to the Manufacturing module.
- A calendar function is linked to the field Finish date in the list.
- Shortage date is shown in the list since no suggestions will be created in passed time. A warning is shown if you move the finish date or the shortage date.
- Administrator, revision, safety stock, etc. are now shown as columns in the list.
- Worked time is shown per order suggestion and total for the suggestions marked to generate orders. This information is shown in order for you to see how many hours you are about to register orders for.
