### The Total by date list
This list shows a total by the grouping of dates you selected in the presentation. Each row shows balance and value for the date to which the row refers.
At the bottom of the list you can see a chart of the value based on the dates. By using the button Chart ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_chart.png) on the function menu, you can configure what should be displayed in the chart.
