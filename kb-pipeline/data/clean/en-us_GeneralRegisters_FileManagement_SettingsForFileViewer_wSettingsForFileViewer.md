## Settings for file viewer
This procedure is available if you have installed the option Extended file viewer. Under the tabs Pen settings and Viewer settings, you find tables where you can configure settings linked to the extended file viewer.
> By using the Extended file viewer option, you have support for an additional number of file types that you can link to different records, preview, and print. [Read more about the supported file types and the Extended file viewer option](../../../UserGuide/Options/ExtendedFileViewer.htm).
