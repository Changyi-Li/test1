## Basic data – Work
In this procedure you register basic data for work recording. Here you register codes for indirect work and groups. These two areas are divided into separate tabs in the procedure. The Groups tab is available if you have installed the option Machine integration.
The indirect codes are used when recording non-productive time and when it is not possible to record on a report number. For example when performing machine maintenance or work on a tool, meetings, or wait due to machine error or tool error.
Indirect codes can be linked to groups and that way they are possible to group according to own criteria making it easier to find the correct indirect code during machine recording.
