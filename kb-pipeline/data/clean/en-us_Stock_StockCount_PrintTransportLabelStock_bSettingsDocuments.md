### Settings – Documents

#### Transport label
Here you select the type of transport label you want to print. The types (the formats), you are able to choose from are A4, A5, Label (76 x 51 mm), or Transport label – Grouped. The Transport label – Grouped option means that transport labels for multiple parts can be printed on the same paper if a smaller transport label size is used and the paper size is A4. The Transport label setting will also be used as fallback if no transport label is selected for the part in the part register. The default option is Transport label – A4.

#### Document variant
If you want to print another document variant than the default variant, you can select it here. The document variants are handled in the Document templates procedure.
