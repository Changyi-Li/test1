### Authorization settings for dimensions
Here you configure settings regarding authorization at row level for expense invoices. This is activated with the system setting called Use extended authorization on posting rows. Please note! The head signer also applies to order invoices.

#### Project
For the project dimension you can configure a general setting that the Project manager or Our reference from the project in the Project register should be used as Signer/Approver and Head signer.

#### Dimension
Here you decide for which dimension the settings in the table below will apply.

#### Code
Dimension code.

#### Signer/Approver
Here you enter the signer/approver that will apply per dimension code for expense invoice. The signer must first be registered under the Signers tab.

#### Head signer
Here you enter the head signer that will be used per dimension code for expense invoices and order invoices. If the signer/approver has exceeded his/her authorization limit, the posting row will instead be sent to the head signer entered here. The head signer must first be registered under the Signers tab.
