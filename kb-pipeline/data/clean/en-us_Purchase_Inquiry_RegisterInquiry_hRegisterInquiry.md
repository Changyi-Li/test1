### Header row

#### Inquiry number
In this field you can enter a new inquiry number or load an existing one using the Lookup The Lookup feature is a powerful search tool which allows you to search and load information from large registers. You open the Lookup feature by clicking on the dropdown button or by using F4 on your keyboard. feature. The field is alphanumerical and can contain a maximum of 15 characters.
If you do not enter or select an inquiry number, the system will pick a new number from the number series when you save the inquiry. If you enter an inquiry number manually, the system will check if the entered number already exists, and in that case it will load the existing inquiry.

#### Order type
Here you select which inquiry type to use. It is determined by the system setting called Default order type. If you chose the According to user option in the system setting, the order type for inquiry suggested here will be the order type you have as default in your user account. If you have not configured a default order type there, then the order type you used on the most recent order will be suggested. When needed, it is possible to select another order type. By using the Change order type button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_change_record.png) you can also change the order type for an existing order.
If you selected None in the system setting called Default order type, you cannot save the order until you have selected an order type.
The Inquiry order type is included in the system. Other order types for inquiry can be registered in the Order types procedure. The type then determine the posting group, rate type, priority, and VAT, By using the Change order type button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_change_record.png) you can also change the inquiry type of an existing inquiry.

#### Status
Here you see the status of the inquiry illustrated with a symbol. A tooltip displays the status in text.

#### Supplier
Here you select a supplier from the supplier register. When you open the procedure, the cursor is automatically positioned in this field. It is mandatory to have a supplier on an inquiry. This field is empty the first time you open the procedure. The next time you open the procedure, you will see the supplier number that you used the last time. When you have selected a supplier, the supplier name will be displayed to the right. By using the button Change supplier ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_change_record.png), you can also change supplier for an existing inquiry.
If the supplier is blocked for registration, a message will appear where you can see the cause by using the button Show block cause ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/RedPadlock.png). In that case is not possible to create an inquiry for the supplier. If you for the supplier have selected Notify (Block/Notify), you will see the message/notification by using the button Show messages ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_comment.png). In that case it is still possible to create an inquiry for the supplier.

#### Supplier’s quote number
In this field you can enter the supplier’s quote number.
