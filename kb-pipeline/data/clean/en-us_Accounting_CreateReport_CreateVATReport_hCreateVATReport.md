### Header row

#### Report number
Here you select or enter the number of the VAT report to be shown or created. This field is alphanumerical. If you create a new report it is not possible to assign it a number between 1 and 99 since these report number are reserved by the system.

#### Name
Here you see/enter the name of the report. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts. It is mandatory to enter a name for a new VAT report.

#### Default report
With this checkbox you decide if the VAT report in question should be selected by default in the Print VAT report procedure. Also, if you check this box, the VAT rows from the report will be the ones that can be entered when you select VAT type and VAT code in the Chart of accounts procedure.

#### Default rounding
With this checkbox you decide if rounding should be used in the VAT report. Certain countries allow rounding and others don't. Check with the authority concerned what applies for the country the VAT report is intended for.
