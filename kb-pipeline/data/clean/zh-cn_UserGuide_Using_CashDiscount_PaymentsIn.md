### 收款

#### 手工登记收款
当登记付款时，系统会检查发票上是否有现金折扣。如果输入的付款日期与现金折扣日期日期或更早，然后折扣金额将在字段中已建议 已付金额，但可以已调整。请注意！你在系统设置中输入的现金折扣宽限天数也将被考虑在内。当给予现金折扣时，剩余金额将设置0，系统将自动建议销账代码 现金折扣。如果你使用现金折扣，你添加列 现金折扣日期 和 现金折扣 % 来自更多信息（见图片）。
[![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/TrainingMaterial/ManualPaymentIn.png)](../../../../Resources/Images/TrainingMaterial/ManualPaymentIn.png)
如果发票上有多个现金折扣限额，你将看到有关已满足的现金折扣限制的信息。如果不满足现金折扣条款，则系统中的这些字段为空白。
如果客户已付款太迟无法享受现金折扣，则会已建议发票的剩余金额。如果客户付款时仍已扣减了现金折扣，然后你人工的输入已付款的减少金额。已建议的销账金额然后是 部分付款。如果你将其作为折扣处理，你可以人工的选择现金折扣作为销账代码。
当付款有现金折扣时，折扣会自动已编码现金折扣标准科目。此过账通常会影响VAT 报告并降低营业额。订单调整该营业额的VAT，现金折扣的过账将按低于例如进行划分：

#### 例如：
发票金额：12,500
VAT 金额：2,500（25%）
已付金额：12,250，享受 2%现金折扣
现金折扣：250
| 科目 | 借项 | 贷项 | 解释 |
|---|---|---|---|
| 3XXX | 200 |   | 现金折扣（净值）。250 x 0.8 |
| 26XX | 50 |   | 销项 VAT。250 x 0.2 |

#### 通过文件确认
通过文件确认时，现金折扣条款（包括宽限天数）将自动被考虑在内。如果付款日期在这些条款之内，并且客户已经使用了折扣，则剩余金额将设置0，并且根据与手工付款相同的逻辑应用现金折扣的销账代码。这将结果过账如下例如 收款。
如果付款日期晚于现金折扣日期并且客户已经使用了折扣，你将在状态字段看到“错误的金额”的信息。在这种案件下，你必须人工的匹配付款，然后系统将建议销账代码“部分付款”。如果你仍然希望给予客户折扣，你可以人工的选择现金折扣作为销账代码。
