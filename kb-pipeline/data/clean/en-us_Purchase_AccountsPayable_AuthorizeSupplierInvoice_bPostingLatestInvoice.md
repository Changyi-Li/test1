### Posting
In this box you see the posting of the invoice selected in the box Supplier’s most recent invoices. If the invoice is final recorded the postings are displayed, but if the invoice has been sent for authorization to several persons the pre-posting is displayed instead. The postings are only displayed and it is not possible to make any changes. It is possible to copy certain posting rows from previous invoices to the invoice you are authorizing. You cannot copy rows for supplier debt postings, VAT, or other postings generated by the system. You can only copy postings that are manually registered by the user. It is not possible to copy postings from order invoices.
If you check the Include column, the copy button will become active ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_run.png). When you click it, you will be moved to the first tab and the posting rows will be added at the bottom of the posting box. You have to manually enter the amounts of the rows if the value left to post is not the same as the value of the copied rows.
Apply accrual accounting
If the setting Accrual account has been activated for the account in the Chart of accounts procedure, then the accrual accounting function will automatically be activated when you leave the amount field. However, you can also activate the accrual accounting function manually by using the Apply accrual accounting function button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_period.png).
If the account row in an existing voucher contains an accrual account then you can link to the procedure Register accruals to see the accrual of the posting row.
If you need to accrual account several postings on one and the same invoice, then you need to create separate postings per posting row.
