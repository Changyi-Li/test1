### Additions

#### Handle additions in recording terminal
With this checkbox you decide if it should be allowed to handle additions in the recording terminal for the TimeCard option. Additions could be allowance for expenses, mileage allowance, and refund of expenses, for example.

#### Number of days back in time that can be edited
Here you select the number of days back in time, for which it should be allowed to edit additions. The default option here is 5 days.

#### Available additions
You can use the Available additions button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) to add the additions that this parameter group should be able to access. The additions must first be registered in the Basic dataWith "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Attendance procedure. You can decide whether the additions should be available for Employee and authorizer or Authorizer only.
