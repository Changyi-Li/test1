### Stock count difference
Video: Differences and valuation
| Swedish | English |
|---|---|
|   |   |
The Stock count difference procedure is used to calculate the value of the differences that have occurred after taking stock. Stock count differences are valued in terms of money and as a quantity. A difference can be positive or negative. Stock count differences occur when you report and save stock counts per part.
The procedure is also used to approve stock counts, if this is used.
> Tip! Parts that have a large stock count difference you can stock count again. To be able to create new stock count bases for these parts you can copy the parts to the Part Clipboard by using the button Copy to Clipboard ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/button_copy.png). After this you can paste these using the Clipboard checkbox which is then available in the part selection in the procedure Stock count in list.
