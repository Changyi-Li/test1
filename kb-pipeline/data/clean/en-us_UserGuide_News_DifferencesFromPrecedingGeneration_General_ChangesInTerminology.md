### Changes in terminology
In the Swedish language in G5, some changes have been made in the terminology compared with G4. This has been done to update the language used in the program and to make it easier to comprehend. Some terms have for example become outdated. One example is Display List which has been renamed Load. "Display List" originated from when the user either chose to printe the list och to show the list on the screen. Loading instead refers to simply loading data from the data source (the selected list type).
Below you find a list of some of the changes and the new words in the Swedish terminology.
A number of changes have also been made in the English terminology in G5. Click this link to read about those changes: [Changes in English terminology](ChangesInEnglishTerminology.htm)
