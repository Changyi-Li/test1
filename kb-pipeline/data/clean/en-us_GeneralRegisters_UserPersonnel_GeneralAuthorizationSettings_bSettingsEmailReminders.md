### Settings for Reminder via e-mail
In this box you configure e-mail settings for reminders to approve purchase orders that are sent via e-mail to signers. The setting Send reminder via e-mail must also be activated for the signers. You find this setting in the Reminders box under the Signers tab.

#### E-mail sending method
This method can be Server based, via Microsoft Exchange or Server based, via SMTP.
Which method you should select depends on which e-mail system you use for outgoing e-mail. Please see how the e-mail settings have been configured in the section E-mail, under the System overall tab in the System settings procedure.

#### Sender
Here you select which user should be set as sender when sending reminders via e-mail. E-mail settings must have been configured for the user in the E-mail section in the Users procedure.

#### Subject row e-mail
Here you enter the text that will be shown on the subject row in these reminder e-mail messages.
