# Monitor Portal
Monitor Portal is an option which gives you an edge over your competitors by providing a number or powerful functions that suit different types of users, including resellers, service partners, and customers. Our self-service concept makes administration more seamless, as resellers can register orders and quotations and service providers can start up warranty cases themselves. This way, these processes do not need to be handled via e-mail and then handled via manual registration in Monitor ERP.

#### Self-service solution
- Share relevant information with all business partners.
- Make relevant information available 24/7.
- Enable your business partners to send information back to Monitor ERP.

#### System recommendations
To be able to use the Monitor Portal, you must have a web server where you install the Monitor Portal. Please see the [system recommendations](https://www.monitorerp.com/sv/support/systemrekommendationer/).
For security reasons, we recommend that the web server and Monitor’s application server (database server) are separate, physical servers. Monitor’s server should be located on the internal network (LAN) and the web server on a subnetwork (DMZ) outside of the internal network.
In addition to the above, it is also necessary for the web server to be able to communicate with Monitor’s server.

#### License model
Depending on what is needed, there are three different types of licenses in Monitor Portal.
A business party license is either a sales portal license or a supplier portal license. There is also a full license, which gives the business party more permissions and rights.
