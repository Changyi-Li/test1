### References
In this box you enter references, goods label, and a description of the inquiry.

#### Our reference
Here you can select among the persons in the company who are registered as references in the personnel records. If you start typing in the field, the system will suggest the reference that matches what you have typed. The Our reference field will by default show the name linked to the logged-in user. If no such link exists, the user’s most recently selected Our reference, will be suggested. The More info button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) becomes visible after you have selected/entered a reference. Using it you can access information about the reference in question. In More info you can also open the chat function called Monitor chat ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/buttonChat.png) and send chat messages to the selected reference. To be able to use the Monitor chat, the logged in user has to be linked to an employee.

#### Supplier’s reference
The person suggested in the Supplier’s reference field is the person set as the default reference in the supplier register. But it is possible to select among all references registered for the supplier. If you start typing a name in the field, the system will suggest the reference that matches what you have typed. If you click the Find button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_field_search.png) in the field you will also see reference category and reference remark. The More info button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) becomes visible after you have selected/entered a reference. Using it you can access information about the reference in question.

#### Goods label
Does not apply to Blanket order – Purchase. You can enter goods label on two rows. The goods label is used when the supplier wants the order to be marked/labeled with a certain text or a reference number. The goods label is displayed on order documents and on transport labels. The total length of the goods label cannot be more than 78 characters.

#### Description
Here you can enter a description of the inquiry. This way, you can easily see what the inquiry concerns. You can for example enter an object number here. Descriptions entered here can be found using the Monitor search.
