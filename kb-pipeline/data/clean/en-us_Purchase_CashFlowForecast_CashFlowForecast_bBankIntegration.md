### Bank integration
> These settings are only available if you have activated the option Bank integration.

#### Bank account
Determines for which bank account the balance brought forward should be loaded. The balance that will be loaded is the available balance at the bank (including credit limit, if any). The balance for the selected bank account is displayed in the Balance brought forward field. By default, the balance is loaded for the bank account that is entered in the Company information procedure. It is possible to select more than one bank account. You can only select accounts that your user has access to (consent).
If you instead want to enter the balance manually, you need to uncheck the checkboxes for all bank accounts.
> It is also possible to load balances from currency accounts. This can be useful if the forecast is run with the setting Show in foreign currency activated.

#### Rate type
If the forecast is run using the company currency and the balance brought forward is loaded from currency accounts (meaning that you have selected currency accounts under Bank account), the balance brought forward will be recalculated to the company currency according to the rate type selected here.
