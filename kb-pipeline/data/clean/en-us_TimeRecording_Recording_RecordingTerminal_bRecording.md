### Recording
When you in the basic mode have entered your employee number/card code in the header and pressed Enter or Tab, the terminal opens the recording mode. In the Recording section which is then shown, you can record your attendance, absence, and work.
When you have clocked in/out, the recording terminal will automatically revert to the basic mode.
Depending if the employee number you have entered is allowed to record both attendance and work (person) or only work (machine), different buttons are displayed in the recording mode. If it is only work which can be recorded, all attendance function will be deactivated. Read more about this below.
You can use the keys for plus (+) and minus (-) on a numerical keyboard to clock in and clock out. The regular plus and minus keys also work (many laptops don't have a numerical keyboard).
Attendance and absence recording
In the table the different buttons which can be shown for attendance and absence recording are described. If they are shown or not depends on your schedule, time of day, and your parameter group. If and when you get to record overtime and absence is also determined by your parameter group.
| Key | Description |
|---|---|
| In – Overtime | Clocking in – overtime before schedule start, before positive flex zone, after schedule end, after positive flex zone, in positive flex zone. This is determined by your parameter group. You must then select which overtime type to use in a dialog. Your parameter group determines if and how many minutes before the schedule it is allowed to record overtime (overtime limit). |
| In (+) | Clocking in – before schedule start, within the flex zone (which either result in positive flex or negative flex). When clocking in before schedule start, and if your parameter group allows overtime, you can select if the overtime should be recorded or not. If you choose to record overtime you must then select which overtime type to use. |
| In after break (+) | Clocking in – after being clocked out on break within the flex period for breaks. Depending on when within the flex period for break you clock in, it will either result in positive flex or negative flex. It is also affected by the minimum break time in the schedule. If you clock in after the flex period for breaks, you must select an absence code for the time elapsed after the flex period for the break. |
| In – Absence | Clocking in – absence in negative flex zone, if your parameter group allows absence recording in negative flex zone. You must then in a dialog select which absence code to use. This recording does not result in negative flex for the time which elapsed within the negative flex zone. |
| In after absence (+) | Clocking in – after absence which has lasted for more than 24 hours. This function is available if absence check has been activated in your parameter group. You must then in a dialog box select absence code for the work days you have been absent. You can also select one absence code to enter for all work days listed as absence. You cannot select "Withdrawal from time bank" for more days than your balance covers. |
| In – Late arrival (+) | Clocking in – after schedule start, after negative zone. This function is available if absence check has been activated in your parameter group. If the flex balance is less than the allowed minimum limit, a message will be shown when you clock in after schedule start which lets you know that flex is not allowed. |
| Out – Break (-) | Clocking out – break within the flex zone for breaks. This function is available if flex periods for breaks exist in your schedule. Lunch recording is also allowed for employees with a flex balance which is too low. A check is made when the employee ends his/her break. A too long break will result in having to select an absence code. |
| Out – Absence | Clocking out – absence (regardless of time of day). You must then select an absence code. If you parameter group allows absence recording within the negative flex zone, and you clock out absence in a negative flex zone, then you can select if the absence should apply as of now (will not result in any negative flex today) or as of the next work day (will result in negative flex for today). |
| Out (-) | Clocking out – after schedule end, within the flex zone (which either result in positive flex or negative flex). Clocking out before schedule end or before the negative flex zone gives the same result as when clocking out absence. |
| Out – Overtime | Clocking out – overtime after schedule end, after positive flex zone, in positive flex zone. This is determined by your parameter group. You must then select which overtime type to use. Your parameter group determines if and how many minutes after the schedule it is allowed to record overtime (overtime limit). |
Planned absence for Part of day
If there is planned absence and you clock out for that time, a message will appear informing you that planned absence has been started. The system setting Time limit for planned absence part of day (min) determines how many minutes outside the planned absence that clocking in/out is allowed without it being regarded as another absence than the planned one.
Site recording
If the system setting called Activate site recording is checked, you must select a site each time you clock in or when you clock out on a break. The site refers to the physical location where you clock in. You register sites in the Basic dataWith "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Attendance procedure. Sites are used in order to, in the attendance list and evacuation list, show where all staff who are clocked in and all staff who are clocked out on a break are currently located – that is, within the building or elsewhere.
If your employee number has a default site – or if the recording terminal has a default site – that site will be shown on the following buttons: In, In – Overtime, Out – Break, and In after break. When clocking in with overtime there are two steps in a dialog: choosing the overtime type and then choosing the site.
If there is no default site selected for the person – or for the recording terminal – the suggested clock-in site will be the site where you were most recently clocked in. If you don’t want to clock in at the suggested site, click the ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/Site.png) button to the right of the recording button. A dialog is then opened where you can select a different site for the recording in question and you become clocked in when you confirm in that dialog.
Using the ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_show_in_google_maps.png) button in the middle, you can change site at any time when clocked in, clocked out on a break, or clocked out. For example, you may want to change site when running an errand in town during your lunch break. This is also useful if you want to choose a site when you are clocked out but remain in the building. For example, if you visit the company gym after your working day. When you use this button you’ll remain on the evacuation list, even though you are clocked out. Please note that you if you choose a site and are clocked out, you’ll remain at this site until you next clock in.
Next to your name at the top of the recording terminal you will in the recording mode see the following symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/Site.png) and a text describes which site that is selected. If you are clocked out, the text "No recording site selected" is displayed unless you have selected a site using the blue button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_show_in_google_maps.png).
Machine recording
The recording terminal has a little different design in the recording mode if the employee number for a machine has been entered. If "signing employee number" is applied then the employee number of the operator should also be entered. Normally this is the person who will man the machine at this very moment. Read more about [Machine recording](MachineRecording.htm).
| Key | Description |
|---|---|
| Start (+) | Clocking in the machine. Work can then be recorded in the same way as for a person. |
| Stopp (-) | Clocking out the machine. When using machine recording, it means that when the operator takes a break or stops working, the machine must be stopped or clocked-in on indirect work in order for work to be properly recorded. Otherwise, time will be registered 24 hours a day. |
Work recording
If you are already clocked-in you can in the recording mode select to record work.
| Key | Description |
|---|---|
| Add to batch | This button is available if you have a batch recorded work in progress. Using this button you go to the start direct work mode so you can add an additional work item to the batch. |
| Start work | With this button you go to the start work mode where you can choose to start direct or indirect work. |
| Stop work | This button is shown if you have direct or indirect work items in progress. With this button you change to the mode where you can stop (finish) work in progress. If you clock out (for example when you leave for the day) and have a work item in progress, then it will be stopped automatically. When you then clock in again the next day the work item will start automatically. |
If you have a work item in progress or work on standby, different functions exist in that recording mode in the box Work in progress. Read more about [Work in progress](bWorkInProgress.htm).
