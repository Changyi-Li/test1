### The List tab
In the withdrawal list you see the reusable tools that have been withdrawn via manufacturing order or manually withdrawn from stock.
In the list you see, for example, information about the tool loaded from the serial number register and the part register.
In the list you also see information about the type of withdrawal (via order or manual). If the tool has been withdrawn via order, you will see the order number, operation number, and work center, to which the tool has been withdrawn. If the tool has been manually withdrawn, you will instead see the employee number who withdrew the tool.
In the list you can also see the tool quantity, expected return, and when the withdrawal was made-. If the tool has been withdrawn via order, you can also see the status of the operation to which the withdrawal was made, as well as status of the manufacturing order.
If you have installed the option Warehouse, you will also see in which warehouse the tool is. Using the warehouse selector ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_warehouses.png) on the toolbar of the procedure you can choose which warehouses you wish to include in the list.
With the Return checkbox you can in the list manually report returning of tools which have been manually withdrawn or withdrawn via order. Return can also be reported in the procedure Report withdrawal of tools. With the button Loc. ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you enter the quantity to return on the tool's loaction.
If a tool has been withdrawn via order, you can under the More info button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) see which operation is the returning operation when reporting as finished. But this requires that this has been entered for the tool on the material row in the BOM and routing for the manufactured part. The return will be made automatically if the system setting Return reusable tools when operation is reported as finished has been set to Yes. If that system setting is set to No, you will instead have to return the tool manually in the Withdrawal list procedure after having reported as finished.
