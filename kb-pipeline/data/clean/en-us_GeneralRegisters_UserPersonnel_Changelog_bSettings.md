### Settings

#### All registers (including uncategorized)
Check this box if you want to include all data registers in the list, including uncategorized registers. The setting also includes registers that are not available in the field below.

#### Show more info for created and deleted
With this setting you decide if more information should be displayed for creating and deleting, under the following column headings: Field, Value before, and Value after, for certain types of records.

#### Registers
This setting determines which data registers should be included in the list. By default, all registers are selected to be included in the list.

#### Maximum number of rows
The value entered here is the number of rows that will be included in the list. The default number here is 1000 rows. However, the maximum number of rows that can be included in the list is 10000.
