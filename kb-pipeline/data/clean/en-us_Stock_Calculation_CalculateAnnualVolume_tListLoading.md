### The Loading list
This list type loads saved annual volume and performs an analysis of how much manufacturing capacity which is required in order to manufacture the volume in the different affected work centers. In the list you can modify the parts' included/incorporated quantity and order quantity. Here you select the parts that you want to include in the calculation.
> Please keep in mind that structure parts will be exploded, making the include/incorporated parts also have an annual volume. If you add the included/incorporated parts in the selection, this means the volume for the incorporated parts will be double.
In a second step you start calculation using the Start calculation button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_run.png) (Ctrl + R) on the toolbar of the procedure.
After the calculation, the Loading list opens. Here it is possible to change setup time, unit time, total time, and man-hours for each work center. You can choose which work centers you want to include and save the values to each work center. These saved values can then be displayed in, for example, the Annual volume list in the Work center A work center is a part of the factory. It can be a single machine or a group of machines, a single workstation or a group of workstations. list procedure.

#### Quantity
In this column you see the included/incorporated quantity which you can change.

#### Order quantity
The order quantity is displayed in red and italic font if the part has no order quantity. The value shown here is either the part's order quantity or the quantity entered in the Fallback quantity field. In the latter case, the value is displayed in red and italic font.

#### Include
In this column you determine which rows should be included in the calculation run.
