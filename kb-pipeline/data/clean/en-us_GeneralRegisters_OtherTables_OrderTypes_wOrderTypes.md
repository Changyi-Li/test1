## Order types
In this procedure you can register and modify different order types. These order types determine different things on quotes, inquiries, blanket orders, orders and customer agreement. For example (on customer orders), the order type determines price strategy, posting group, purchase order's address, delivery planning, invoice type, sales statistics, priority, and transaction type for Intrastat Intrastat is the system which gathers statistics relating to trade in products within the European Union. Gathering of Intrastat statistics is handled in the same way by all EU member states..
You can delete an order type that you have created as long as it is not used in any record in the system. You can also deactivate an order type. Then it will no longer be selectable in different parts of the system.
A user can, for example, have different default order types for different purposes. For example a user who only works with purchase can have a default order type for buy material. Then the user does not have to select order type every time he/she creates a purchase order. If no specific order type has been set as default for the user, the order type selected on the latest order that the user registered will be suggested.
