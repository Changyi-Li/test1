### 预付发票/尾款发票的贷记给
要贷项预付发票或尾款发票，你应该执行以下操作：
1. 在​ 登记客户订单 程序。
2. 转到 开票计划 标签页。
3. 标记你想要贷项的分批发票（预付和/或尾款的分批发票）。
4. 选择 创建贷项发票，低于图片：
[![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/TrainingMaterial/InvoicingPlanCredit.png)](../../../../Resources/Images/TrainingMaterial/InvoicingPlanCredit.png)
> Please note!It is only possible to create a credit invoice if the advance/in arrears has been invoiced.
