### 库位选项和筛选中公式

#### 计划公式
该公式由针对库位和组件输入的不同测量值和重量组成。该公式将库位的大小与组件的尺寸进行比较。在这里，你可以自定义规则，仓储费用对库位的最大尺寸有一个容忍层级。例如，是否可以从托盘关已拣货某种类型的组件而无需将托盘下班托盘架上拉出。然后你应该在最大高度上留出足够的空间。计划公式将对“组件是否适合放在架上？”这个问题给出“真的/假的”的答案。你可以在以下位置查询这些计划公式 计划公式 通用登记模块中的程序。
以下变量可用于入库库位筛选中的计划公式：
| 代码 | 名称 | 程序已更新 |
|---|---|---|
| 本地化采购协议 | 位置的最大载入 | 库位 |
| 最大最大荷载 | 位置的最大高度 | 库位 |
| 最大线宽 | 位置的最大长度 | 库位 |
| 最大宽度 | 位置的最大宽度 | 库位 |
| 低密度脂蛋白 | 位置的最小高度 | 库位 |
| 低密度脂蛋白 | 位置的最小长度 | 库位 |
| 低密度聚乙烯 | 位置的最小宽度 | 库位 |
| 包封 | 包装高度 | 组件登记 |
| 包装 | 包装长度 | 组件登记 |
| 派克 | 包装宽度 | 组件登记 |
| 派克 | 包装重量 | 组件登记 |

#### 选择准则
如果仓储费用，库位选项可以与库位和入库策略的选择准则相结合。例如，某个组件应总是存储在“B”章节中。在这种案件下，你可以创建一个筛选来总是查找该特定段中的库位。

#### 入库策略
在入库策略中，已建议库位的订单是决定的。第一个显示最合适的选项，即放置物料的库位
建议你每为基本类型设置的坐标系统排序，例如，如果你要从地板向上载入/填充，输入“层级”的增加排序。
另一个值得注意的排序术语是 路线排序。路线排序将为已计划的“路线”的全部库位配置一种排序方式，这使得进行拣选的员工更容易，即使库位名称与物流最佳顺序不同，全部库位都处于正确的拣选订单。
如果该组件有补充库位，你可以决定当当前余额低于输入的再补充数量时，应向补充库位补货。
如果组件具有要使用的到货库位，则可以科目到这一点，仓储费用到货主要到达该到货库位。如果组件在到货库位，需要帮助 移动库存余额 程序,系统将 建议 另一个库位.
> 请注意！你可以创建多个入库策略以获得期望的灵活性和功能
