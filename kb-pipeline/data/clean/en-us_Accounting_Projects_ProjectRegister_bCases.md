### Cases
In this box you find an overview of which cases are linked to the project. Cases of the basic types Customer nonconformity and Supplier nonconformity are the ones which can have a project link. The project number might be linked on cases in the box Initial delivery in the Register case procedure.
By double-clicking on the row, the Register case procedure will open with the record in question loaded in the procedure.
By using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_goto_critical_op.png) you can choose to only show current cases.
