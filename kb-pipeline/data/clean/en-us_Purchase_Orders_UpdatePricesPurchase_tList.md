### The List tab
This list shows detailed information about the purchase orders you have selected. If you have activated the updateable mode for the list, it is possible to update the Price each.
Column in the list:
- Price each – Here you see the current price for the purchase order row.
- New price – Here you see the current price for the part. This is loaded from the Part register procedure. This can be edited manually.
- Difference – Here you see the difference between New price and Price each.
- Difference (%) – Here you see the difference between New price and Price each in percent.
- Order date – Here you see the order date for the order record.
- Valid through – Here you see the valid through date for the new price.
- Difference (days) – Here you see the difference between the Order date and the Valid through.
