### 组件
为组件的编号序列。
序列盒
你在此处添加你为组件的编号序列。使用按钮 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_goto_up.png) 和 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_goto_down.png) 你可以更改编号序列的订单。具有相同条件的编号序列的顶部行。如果条件满足则使用它。底部行作为通用编号序列，当任何编号序列中无满足任何条件时使用该数字系列。

#### 行
在这里你可以看到编号序列行上的固定编号。如果在表格中向上或向下你编号序列，移动编号序列将获得其所在行的编号。

#### 名称
你可以在此处写一段描述性文本作为名称。你使用公司语言输入名称文本，并以用户的语言显示。
使用按钮 翻译 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_translate.png)s 你可以将文本翻译为系统中已登记的不同激活语言。阅读更多内容 [语言管理](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) 用于可翻译文本。

#### 后续编号
在这里你可以看到此编号序列中将用于组件编号的后续编号。

#### 格式
在此字段中，你输入一或多个标签来描述编号序列的结构和目录。可用于用于组件编号的标签低于。你必须总是在字段中包括< 代码>标签。
| 标签 | 描述 |
|---|---|
| <代码> | 编号序列中的后续编号。 |
| <年> | 年，包含四位数字，例如“2016”。 |
| <年> | 年，包含两位数字，例如“16”。 |
| <図> | 月，其中“01”表示一月。 |
| <交货日期> | 月中的日，例如“22”。 |
| <HH> | 小时。 |
| <毫米> | 分钟。 |
| <ss> | 第二。 |
| <周> | 周数，包含两位数字，例如01-53。 |
编号序列可以由不同的标签组成，这些标签之间用可选字符分隔，见低于的例如。
组合编号序列的例子：
<代码>-<yyyy> 结果是“10001-2020”，“10002-2020”等数字。
<代码>:<yy>-<MM>-< 交货日期> 结果是诸如“10001：20-02-19”，“10002：20-02-19”之类的数字。

#### 激活的
通过此复选框，你可以决定编号序列是否已激活且可以使用。
条件框
你在此处添加条件/条件，决定何时使用相关的编号序列。
如果你具有不同分组条款的添加多个条件，然后当全部这些条件都满足时将使用编号序列。如果你具有相同分组条款的添加多个条件，然后当其中一条件得到满足时将使用编号序列。

#### 分组条款
分组条款决定了编号序列的用途。你可以从以下选项中选择： 组件模板， 组件代码， 产品组， 和 组件类型。
下列哪个编号序列 序列 应使用哪个框取决于分组条款及其间隔。理论上，一个组件可以被多个编号序列包含。如果多个编号序列与分组条款匹配，则按编号序列的订单排列（具有相同分组条款的行顶部的编号序列行）。

#### 从和到
在这些字段中，你可以输入已选择分组条款的间隔。这决定了在分组条款中何时应用编号序列。

#### 排除
在这里你可以决定是否应排除条件中已选择的间隔。这意味着，编号序列不应该在指定间隔的分组条款内使用。
