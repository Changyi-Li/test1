### Features in list procedures
Monitor ERP has many list procedures with finished list types.In the backstage of the procedure you can configure which selection rows should be available. These customizations will be saved for your user account. The selection rows enable selection of data records from different registers.
Based on the selections and settings, data is loaded to the list and is shown in the selected presentation.You can create custom presentations in the backstage of the procedure. You can also export these to a file to make it possible for other user to import it and use presentations which you have created.
It is also possible to configure different settings regarding the printing of lists. This is done by clicking the Preview button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_preview.png) (Ctrl + Shift + P) on the function menu for each list. Read more in the topic [Printing of lists](PrintoutsOfLists.htm).
The list procedures differs. In some lists there is only one list type and you can only select and load data to the list. Some list procedures have no presentations to choose from while others have a few presentations available but you cannot create presentations of your own.
The data records you load can for example be displayed as a chart, be printed as a list, you can analyze, calculate, and update the values. What you can do in the lists vary from case to case. See an image example of a list procedure in the [Procedure window](../Interface/ProcedureWindow.htm) topic.
In all lists you can sort information in the columns in several steps, move columns around or temporarily remove columns, and filter by data/information. In many procedures you can also search for data as well as use the find and replace function per column.
