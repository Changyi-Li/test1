## Measuring templates
In the table in this procedure you register templates for measuring data.
A measuring template has a linked measuring form, and it contains default values and settings.
What is to be measured (measuring points) is described in the measuring form that is linked to the template. Measuring forms must first be registered in the Measuring forms procedure.
You then link measuring templates to operation rows in the BOM and routing. It is also possible to link a measuring template to the operation rows in manufacturing order, if it should be displayed for certain orders.
When reporting quantity on operations in manufacturing orders, you can link the operation to the Report measuring data procedure from one of the following procedures: Report operation, Report manufacturing order, or Recording terminal.
The settings in a measuring template can be modified when you add the template for an operation in the BOM and routing or the manufacturing order.
