### API keys for official partners
Once a partner solution, for example Upsales or Infobric, has been delivered to your company, the Partner solution tab becomes available.
- Add new row ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_row.png) – creates a row with a new access key and expiration date for the access key. The default validity period is is 6 months.
- Generate ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_refresh.png) – generates a new access key or a new expiration date for the access key. You need to then copy the new key into the solution’s integration settings.
You use the access key to connect to your partner solution.
> You need to make sure that TCP port 8001 is open in your firewall to enable your system to communicate with the partner solution. If you are a Monitor Cloud user, our Support Center will assist you with this.

#### Name
This is where you name the API key. Use a clear name so that it is easy to understand which solution the key belongs to.

#### Access key
The generated access key that is copied into the solution’s integration settings.

#### Access key expiration date
Here you see the date after which the access key is no longer valid. It is possible to unlock the field and change the expiration date. When the expiration date is closing in, you will receive a message and you can choose to extend the date or to generate a new key.
> You need to assign the partner a user (no license is needed) and provide the partner with information about user name and password.
