### Handling lists

#### The selection
The selection rows are grouped to keep selection terms with the same origin together. For example, the selection rows in Order list – Sales are grouped by the terms Order, Customer, and Part.
The selection rows are possible to configure for the user. This configuration is done in the backstage of the procedure. You can add, delete, and mark selections as favorites.

#### The list
The list has dynamic columns meaning you can change the column widths and you can also move the columns sideways.
The list can be regrouped and grouped in several levels by dragging the column heading to the grouping section at the top of the list.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/News/List.png)](../../../../../Resources/Images/News/List.png)
In the preview you can configure settings for printout. You can for example shift between portrait and landscape printouts. You can decide if the selection should be included on the printout, if the text should be rescaled to fit the paper width, and if the chart should be printed together with the list.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/News/List2.png)](../../../../../Resources/Images/News/List2.png)
The chart is shown below the list. If you click on a bar, the corresponding row in the list will be marked.
In total lists it is also possible to see data in-depth (so-called drilldown) by clicking on the plus sign button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_drill_down.png) and expand the list. You can for example in a total customer order list see which orders that exist and for which customers. You can then expand the list in several levels down to the order rows.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/News/List3.png)](../../../../../Resources/Images/News/List3.png)

#### Create own presentations of lists
The contents of the lists can be configured by the users themselves by adding and deleting columns, creating own groupings, and saving these as own presentations of lists. For each list there is an extensive set of extra columns to select from which you can add in your own presentations. You can use one of the presentations included in the system as a start and copy it. Then you can design your own list. You perform this configuration in the backstage of the procedure.

#### Access to lists
You can per user, group, or roll, determine which list presentations should be available. This applies both for the presentations included in the system from the start and the presentations you have designed on your own.
