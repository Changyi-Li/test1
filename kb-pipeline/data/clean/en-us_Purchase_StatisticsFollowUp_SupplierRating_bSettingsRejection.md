### Settings – Rejection
The following settings are available for the list types for rejection.

#### Include stray supplier
Suppliers marked as “stray suppliers” in the supplier register are included in the calculations by default, but they can be deselected by unchecking this setting. You may not always be interested in measuring the delivery liability of stray suppliers.

#### Only show inspection reporting
If you activate this setting, only arrivals that have been reported in the Receiving inspection procedure will be shown.

#### Only show rejections
If the previous setting has been activated, this setting will become available. Using this checkbox you can select to only show arrivals which have rejections reported.
