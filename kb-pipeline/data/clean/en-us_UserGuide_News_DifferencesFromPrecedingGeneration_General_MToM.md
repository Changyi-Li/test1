### Monitor-to-Monitor
In G5 (from customer point of view) you can export purchase orders and delivery schedules. These can be sent as XML files in e-mails to the supplier. The customer can import order confirmations and invoices that have arrived as XML files in e-mails from the supplier. The customer can then confirm their purchase orders and register supplier invoices.
In G5 (from supplier point of view) you can import the XML files which arrived in e-mails from the customer, to customer orders and sales forecasts. The supplier can export and send order confirmations and invoices for their customer orders as XML files in e-mails to the customer.
The e-mail messages are tagged with a specific text in the subject row.
These imports are primarily done in the following way: The system checks specified inboxes with different e-mail addresses. If the system finds an e-mail message which is of the "Monitor-to-Monitor" type, that e-mail message will be shown in the desktop component Inbox Monitor-to-Monitor. There you select that the file should be imported and then for example a customer order is created. The affected procedure starts and an information window shows what will be imported. In the information window you will also see the a PDF file of the order and other PDF files for the order, if any, included as attachments in the e-mail, for example drawings.
You can make adjustments and configure settings before the import is executed. If there are differences between your own data for example regarding the customer and what is in the file, then you will see these differences as warnings on the order. These warnings are also shown after you save. The e- mail message is logged under the Activities tab.
You can also drag and drop the e-mail directly in the inbox in the desktop component.

#### Import a customer order file with an alloy cost which comes from G4
If the file is created in Monitor G4, where alloy cost rows on an order are differentiated by a specific row type (3), the alloy cost rows will not be imported to G5 at all. A warning message is shown in the import dialog for each type 3 row included in the import file. These rows are also set as read-only, and thereby not possible to select for import.
