### Case documents
There are different documents that can be printed for registered cases. These documents contain information for each respective purpose.
- For customer nonconformities you can print confirmations to send to customer saying you have received the claim. When printing answers to customer nonconformity you can also print documents linked to External comment.
- For supplier nonconformities you can print claim reports that can be sent to the supplier. Documents linked to External comment can be printed when printing claim reports.
- There is a nonconformity report for each case type concerning the internal handling. This is only used in-house for internal work, and accompany the goods in question.
Please note! If you e-mail the documents and select to print linked documents, these will be attached. This can be useful if you for example want to attach a photo in order to describe a nonconformity item. The linked documents can also be printed if you make a paper printout.

#### Confirmation of customer nonconformity
Once a customer nonconformity has been registered, you can print a confirmation of receiving the claim and send to the customer. This is done under the Documents tab. This confirmation contains information regarding the case number, the responsible administrator, as well as the planned activities. Only activities marked with Print will be printed on the confirmation.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/TrainingMaterial/BasicData_Case8.png)](../../../../Resources/Images/TrainingMaterial/BasicData_Case8.png)

#### Response to customer nonconformity
When a customer nonconformity has been finished/finalized it might be appropriate to print a response and send to the customer. This response contains information about the customer's and your own case number, your own administrator, and a comment in text form, if any.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/TrainingMaterial/BasicData_Case9.png)](../../../../Resources/Images/TrainingMaterial/BasicData_Case9.png)

#### Claim report
Once a supplier nonconformity has been registered, you can print a claim report to send to the supplier. This report contains data and a comment describing the case/nonconformity.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/TrainingMaterial/BasicData_Case11.png)](../../../../Resources/Images/TrainingMaterial/BasicData_Case11.png)

#### Nonconformity report (internal)
The internal document called Nonconformity report (internal) is used as a document to follow during in-house work related to a nonconformity/case. It can also be used as a route card or accompanying document. You can print an internal nonconformity report for all case types. This report contains complete information regarding a case.
