### 警告选项标签页
在此标签页下你可以看到以下警告：
| 警告 | 此警告何时出现？ | 行动 |
|---|---|---|
| CN 代码缺失 | 如果交货地址的国家 / 地区代码或仓库的国家 / 地区代码在欧盟境内，但CN 代码缺失，则会出现此警告（不应用至服务）。 针对全部订单类型（包括库存订单和外协）进行检查。 | 如果要将这些组件纳入境内的报告被用于，你在组件登记中输入这些组件的CN 代码。 |
| 重量缺失 | 如果交货地址中的国家 / 地区代码或仓库的国家 / 地区代码是欧盟内的国家 / 地区，且存在CN 代码，但未否重量（尽管CN 代码已配置为报告重量） ，则会出现此警告。 还针对行类型2 和服务进行了此项检查。在这种案件下，记录将显示在境内的报告中，但重量五月不错误的。 | 在组件登记或外协组件程序中输入组件的重量。 |
| 交货在欧盟以外（简单的VAT处理） | 如果你在VAT 报告中将交货报告为货物贸易（欧盟），但交货不已发送往欧盟，则会出现此警告。 此检查仅应用至发票（不库存订单或外协）。 | 如果要将该记录被用于境内的报告中，则必须在交货地址上已变更国家 / 地区。使用链接转到更新应收账款分类账或登记供应商发票程序，并更改发票上的国家 / 地区。如果不将记录已报告为欧盟贸易，则必须再次已编码发票，仓储费用它就不作为欧盟贸易被用于在VAT 报告中。 |
| 交货地点在欧盟以外（高级选项VAT处理） | 如果你在VAT 报告中将交货报告为货物贸易（欧盟），但交货不已发送往欧盟，则会出现此警告。在这种案件下，该记录作为货物贸易（欧盟）被用于在VAT 报告中，但在境内的报告中不存在。 此检查仅应用至发票（不库存订单或外协）。 | 如果要将该记录被用于境内的报告中，则必须在交货地址上已变更国家 / 地区。使用链接直接转到直接登记发票程序并更改交货地址的国家 / 地区。如果不将记录已报告为欧盟贸易，则必须再次已编码发票，仓储费用它就不作为欧盟贸易被用于在VAT 报告中。 |
| 科目不涉及货物贸易（欧盟）（检查简单的VAT加工） | 如果交货国家 / 地区位于欧盟境内，但你已记录该货物的科目不提及欧盟商品贸易，则会出现此警告。这种案件下 , 该记录会 显示 在境内的报告中 , 但是不在VAT 报告中 记 为 货物 贸易 (欧盟) . 此检查仅应用至发票（不库存订单或外协）。 | 如果该记录不境内的中已报告，则必须修改发票上的国家 / 地区。使用链接转到更新应收账款分类账或登记供应商发票程序，并更改发票上的国家 / 地区。如果该记录应被已报告为欧盟贸易，则必须再次已编码发票，仓储费用将其作为欧盟贸易被用于VAT 报告中。 |
| VAT 代码与货物贸易不（欧盟）（检查高级选项VAT加工） | 如果交货国家 / 地区位于欧盟境内，但已开发票上的VAT 代码不涉及欧盟商品贸易（根据上面相同逻辑），则会显示此警告。这种案件下，该记录将显示在境内的报告中，但是不在VAT 报告中已记录为货物贸易（欧盟）。 此检查仅应用至发票（不库存订单或外协）。仅当VAT 报告从总账事务中加载VAT 代码时，才会进行此项检查。 | 如果该记录不境内的中已报告，则必须修改发票上的国家 / 地区。使用链接转到更新应收账款分类账或登记供应商发票程序，并更改发票上的国家 / 地区。如果该记录应被已报告为欧盟贸易，则必须再次已编码发票，仓储费用将其作为欧盟贸易被用于VAT 报告中。 |
| 组件不存在报告单位 | 如果CN 代码设置为报告另一个数量，但所讨论的单位不在组件登记中为该组件已登记，则会出现警告。 对全部订单类型都进行检查。在这种案件下，该货物将不被被用于境内的报告中。 | 如果要已报告记录，你必须在组件登记中为组件登记一个有效的单位。（只要将其已登记为具有正确换算因数的替代单位就足够了。） |
| 不存在VAT 登记号 | 如果客户不存在VAT 登记号，则会出现此警告。 | 在客户登记中输入客户的VAT 登记号。 |
在某些案件下，同一记录可能会显示多个警告（例如，如果重量和CN 代码两者不存在）。
