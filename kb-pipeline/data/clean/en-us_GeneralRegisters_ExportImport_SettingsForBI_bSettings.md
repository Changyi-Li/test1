### Settings
In this box you configure settings for the data mining to BI selected in the Scheduled data mining box.

#### Active
Here you determine if the scheduled data mining should be active. If you uncheck the box it will not be run.

#### Name
Here you enter the name of the row.

#### Number of years
Here you determine how many years back in time the data mining should be made. If you for example enter 3 and the current year is 2018, data for the years 2018, 2017, and 2016 will be extracted.

#### First day of week
With this setting you decide if Sunday or Monday should be the first day of the week.

#### Schedule
Here you enter when the data mining should be made.
- Dailyl – It is run every day at an entered Time (default).
- Only manual – It can only be run manually from this procedure.
- Own schedule – You select on which Week days the data mining should be done. You also select a Time for the run.

#### Company
Here you mark which companies should be included in the data mining. All companies in the system can be selected.
Please note! The data mining is made even though a company that is included has denied your company access to its data in the BI. This is configured under the Access settings tab. In that case you can make exceptions for specific users of yours, making it possible for the user in question to get explicit access to the other company's data. This is also configured under the same tab.

#### Data sources
Here you select which data sources should be included in the data mining.

#### Last run
Here you see status of the last data mining. You also see start time and time used. The status can either be OK or Error. If something went wrong, you see an error message in the Information box. You see when the run started as well as how long it took.
