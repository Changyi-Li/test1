### The Standard list
This list type is a standard list which shows most information about the chart of accounts. Each account has its own row. In some cases the information in the list can be updated.
The following presentations are available for the standard list: General, Grouped by heading, and Block/Notify.
General

#### Account type
Here you see the account type for the account on the row.

#### Heading
Here you see the heading of the account.

#### Dimensions
Here you decide if the account on the row should post against dimensions.

#### Cost/Income type
Here you select the dimension's type of cost/income (for project accounting). The types of costs and income are those which in the Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Project procedure has been configured to load result from the bookkeeping. This field is available if you have selected to apply the dimension on the account and the dimension in its turn is linked to project in the Dimensions Dimensions are used by large companies in their accounting in order to divide up activities and make it easier to track internal results. An account is a dimension, although large companies usually use the dimensions cost center (CC), cost unit (CU) and project. In addition to these you can create other dimensions in Monitor ERP based on your own operational follow-up. procedure.

#### Cost/Income
If the selected type of cost/income can be both a cost or an income (configured in the Basic data – Project procedure) you can in this column choose if the dimension is a cost or income in the project accounting. If this is not the case, the field will show if the selected type of cost/income refers to a cost or an income.

#### Specification
The specification is a text you can enter on the posting row when posting on the account. It is also used in the accounts payable and accounts receivable to save invoice numbers to accounts payable and accounts receivable accounts.

#### Quantity
If you activate this setting it is possible to enter a recorded quantity on the account.

#### Debit/Credit
With this setting you determine if the account is a debit account or a credit account.

#### Block
With this checkbox you determine if the account should be blocked.

#### Budget chart
Here you can enter a default budget chart for the account in question. This budget chart will then be automatically selected when registering budget and import.

#### Accrual account
With this setting you determine if an accrual should automatically be created when posting on the account in the Register supplier invoice and Register vouchers procedure.

#### Order number
Check this box to be able to reconcile the balance accounts used on invoicing plans.

#### Currency account
With this checkbox you determine whether the account is a currency account or not. Currency accounts are accounts in the bookkeeping where transactions should be recorded in both company currency and other currency. These accounts are normally bank accounts in external currency or accounts receivable accounts/accounts payable accounts in external currency. For a currency account it is possible to see the balance of the account in both currencies. The currency code is shown in the adjoining field.

#### Comment
This checkbox shows if a comment has been entered in the chart of accounts. You can enter/modify the comment in the list.
Grouped by heading

#### Heading
Here you see the heading of the account.

#### Account type
Here you see the account type for the account on the row.

#### Dimensions
Here you see if the account on the row should post against dimensions.
Block/Notify

#### Activity
Here you see the activity which is applied for the account. Read about [Block/Notify](../ChartOfAccounts/bBlockNotify.htm) in the online help topic for the Chart of accounts procedure.

#### Block message
Here you see/enter the message which will appear when the account is blocked.

#### Blocked/Notified by
In this column you see who created the block/notification.

#### Date
Here you see the date when the block/notification was created.
