### Material rows
This box is shown in the list if you have selected the list type Split pick list. Here you see the included/incorporated material rows in the orders you have marked to create pick lists for in the box Clearance status. The rows are grouped by the pick lists that will be created according to the splitting option you chose for the list under settings.

#### Include
This checkbox is marked by default, but you can uncheck individual material rows you don't want to include in a pick list.
You create the pick lists by saving in the procedure. Then they become available under the Document tab.
