### Settings
Here you find settings for the list types in the Priority plan list procedure. For the detailed list type all of the settings below are available.

#### Loading types
With this setting you decide if only Actual orders and/or Suggestions should be shown in the list. The default option is Actual orders.

#### Date format
Here you can configure which date format to use: either Date or the period format YYWWD.

#### Show time
This setting is only available if you have activated the system setting called Enable hourly planning for work center. With this setting you will in that case decide if a time stamp should be shown next to the dates in all date columns in the list.

#### Calculate with man-hours
With this setting you determine if the remaining time should be the time for the staffing converted via the operation's staffing factor, instead of the machine time. Please note that there is a staffing factor for both unit time and setup time.

#### Consider simulation factor
With this setting you can decide if the simulation factor should be taken into consideration. The value of the simulation factor in percent, is loaded from the work center. By activating the simulation factor setting, the remaining time on each operation is divided by the simulation factor. If the operation for example has a remaining time of 10 hours and the work center has a simulation factor of 80%, the new remaining time will be 10 ∕ 0,8 = 12,5 hours. However, no update is made, since this is only a simulation.

#### Show goods location
If you activate this setting, the goods location entered for operations will be shown in a separate column in the list.

#### Mark operations ready to run
The operations that are ready to run will be displayed in green text in the list.

#### New page per work center
If you check this checkbox, a page break will be inserted after each work center when printing. This can be useful if you print the list containing several work centers and you want to distribute it to different planners.
