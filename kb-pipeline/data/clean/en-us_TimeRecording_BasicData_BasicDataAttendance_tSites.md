### Sites
If site recording is activated (via the system setting called Activate site recording), this tab is available. Sites are used when recording attendance and breaks. They are used to describe the physical location to which the employees record in/out. For example, you can register one site per recording terminal, department, building, etc.
Sites are used in order to show, in the Attendance list and Evacuation list, where all staff who are clocked in and all staff who are clocked out on a break are currently located – that is, within the building or elsewhere. Site recording can also be used when working remotely, when employees are working from home or from another site/place.
For persons in the Personnel records and for recording terminals in the Terminal settings, you can decide a default site for clocking in and a default site for when clocking out to go on a break. A default site makes it easy if the personnel is normally located in the same site/place every day. If no default site has been registered, the most recently used site will be suggested for use for the next recording as well.

#### Row
The row number displays in which order the sites are shown where you can select site.

#### Name
Here you see/enter the name of the site. This name is shown in dialogs where you can select a site. The name of the selected site is shown in the attendance list and in the evacuation list. When a person is clocked in or when a person is clocked out on break, the name of the site is also shown next to the person's name at the top of the recording terminal.
By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Code
Here you enter/select the code of the site. It can consist of a maximum of 10 characters. The code of a person's default site or his/her most recently selected site (or the recording terminal's default site), is shown on the recording buttons in the recording terminal.

#### Warehouse
This column is only shown if you have installed the Warehouse option. Here you can choose in which warehouses it should be possible to select the sites. All warehouses are marked by default.
