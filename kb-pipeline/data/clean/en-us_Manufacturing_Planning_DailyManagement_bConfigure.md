### Configure view
> You create and configure a view in the Daily management in the same way as you create a desktop configuration in Monitor ERP.

#### Views
By using the buttons on the function menu you add ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_row.png) new views and you can also copy ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_copy_row.png) views. Views that should no longer be used can be deleted ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_delete_row.png). By using the arrow buttons ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_goto_up.png) and ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_goto_down.png) you can change the internal order of views you have created. This determines in which order the views should be displayed in the dropdown menu on the header row in the procedure.
Click the Settings button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) to access settings regarding update intervals for the view. You can enter from 20 to 999 seconds (30 seconds is set by default). Here you also add the work centers that should be shown and handled in the view.

#### Layout
This box contains a grid where you can add the components you want in the view and configure the size of each component. You can change the size of a component by dragging the sides or the corners. You can arrange the components as you want them in the view by moving them around with your mouse pointer, The components available to choose from can be seen in the list to the right.

#### Components
In this list you see the components available in Daily management. You can drag and drop with your mouse pointer to take a component from the list and place it where you want it in the view in the Layout box.
To delete a component from the view, you click the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_close.png) that has an X.
By clicking the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_settings.png) on each component, you can change their titles and for some components it is possible to make other settings. The available settings depend on the selected component. Read information about each [component](DailyManagementComponents.htm).
Additional components will become available in the Daily management in later versions of Monitor ERP.

#### OK/Cancel
When you have finished the configuration of the view you use the OK button to save. If you want to undo what you have done, click/tap the Cancel button instead.
