### Header row
On the header row you select the pool work center to which the work centers and operations you wish to replan, belong. You can also select what the finish date should be set to when you have selected work center in the pool. The operations that are shown all have a remaining quantity. It is also possible to show operations in manufacturing order suggestions.
The header row in the Pool planning procedure, contains much of the same information and filter functions as the [header row](../PriorityPlanning/hPriorityPlanning.htm) in the Priority planning procedure.

#### Work center
Here you can enter the number of the pool work center. The name in the field to the right is loaded automatically. Only work centers of the type Pool can be selected/entered here.

#### Set finish date to
In this field you can decide if the finish date should be set to the same date as before or if it should be set according to the New finish when you have selected work center in the pool.
