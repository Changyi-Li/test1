### Channel configurations
In this box you add the channel(s) that should be included in the channel configuration. You also choose if channel should be active.
By using the buttons in the function menu you can add and delete channels row by row.
In the Behaviors box, you link one or more behaviors to each channel. When a channel has at least one linked behavior, the channel can be set as active.
A check is made to see if a channel occurs in more than one channel configuration or if it occurs in another EDI EDI is the acronym of Electronic Data Interchange. EDI is about exchanging electronic business documents with your business partners, e.g. customers and suppliers. The EDI concept can be wide and a bit unclear, and can many times be used about all types of documents which are sent electronically, even if it might be PDF files sent via e-mail or publishing business documents on a website. What we refer to as EDI – and what is traditionally meant by EDI – is structured business documents following given standards, electronically sent or received and which are compiled and interpreted automatically and that is integrated with the customer's/supplier's ERP system. configuration. If so, a warning ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png)appears.

#### Active
Here you determine if the channel should be active in the configuration. An active channel can only be linked to an active configuration. This means that this channel cannot be included in another active configuration.

#### Use notifications (U)
Here you determine if it should be possible to configure settings for notifications on this channel in the configuration. This checkbox activates the button Notifications.

#### Notifications (N)
This button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) is displayed if the previous box U has been checked. Here you configure which roles, groups, and users should receive a notification when an EDI transaction has occurred. You configure for which transaction type and transaction status the system should create notifications. The affected users will be notified in the Notifications window, in the Message center on the title bar in Monitor ERP.
In the EDI configurations procedure, you can also use notifications on behaviors. This is useful if you want to add extra notifications that only applies to EDI transactions is a specific behavior.
