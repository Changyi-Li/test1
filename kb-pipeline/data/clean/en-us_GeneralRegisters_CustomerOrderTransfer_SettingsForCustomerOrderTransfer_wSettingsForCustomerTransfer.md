## Settings for customer order transfer
This procedure is available if the option Customer order transfer is installed in your system.
In this procedure you register settings for customer order transfer to a setup number that you later link to transfer profiles in the Transfer profiles procedure. The settings determine for example how customer orders should be create in production companies.
You create and change these settings in the sales company. These are then transferred to production companies via transfer profiles in the Transfer profiles procedure. Each setup will be given a unique number in the production company.
If you want to create additional setups of settings, you can use the button Save as ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_save_as.png) (Ctrl + S).
> Please note! If you change a setting, the transfer profile that uses the setup number in question will be deactivated. You must then go to the Transfer profiles procedure in the sales company and activate it again.
