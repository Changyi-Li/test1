### Columns
In this box you add the columns which should exist in the report. You can either start from the selectable columns or by adding/inserting new columns directly in the table. One row in the table represents one column in the report.

#### Selectable columns
All selectable columns are available in four different types according to Type below. You use the function button Add selected column ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_goto_next.png) to add a selectable column to the report.

#### ID
In this column you see the ID for the column in question in the report. This is used in expressions in computing columns.

#### Type
In this field you select the type of the column. There are four different types to select from as seen below:
- Account/Dimension
- Numerical
- Calculated
- Compare section
Read more about which settings can be configured for each column type in the [help topic](bSettingsColumns.htm) for the Settings box.

#### Contents
Here you see an explanation of the contents of the column. It is governed by the settings you configure in the Settings box.

#### Text
Here you see/enter the heading text for the column. You can format this text in the Preview box.

#### Translations
By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.
