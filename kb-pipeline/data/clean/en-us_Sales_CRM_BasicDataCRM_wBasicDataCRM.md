## Basic data – CRM
In this procedure you register all the basic data regarding CRM. That is, activities, customer status, districts, customer types, retailers, and number of employees.
This information is then used e.g. for the CRM in the Customer register procedure and also for the activities in the Register quote, Register customer order, and Register customer agreement procedures.
New basic data rows in the tables are given a numerical code that must be unique, containing a maximum of 6 digits. By default, the code is the same as the row number. You cannot modify the code after you have saved the row in the procedure. The texts for names, districts, customer types, and resellers can be modified at any time. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts. Du kan ta bort en grunddatarad så länge den inte används på någon post, t.ex. en kund. If you try to delete a row that is used, you will see a message telling you that it cannot be deleted and information about where it is used.
