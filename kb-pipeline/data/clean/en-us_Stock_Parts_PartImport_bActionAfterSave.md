### Action after save
Here you choose how the synchronization to part templates should be handled after the part import. The following options are available:
- Open the Synchronize part template procedure for new parts – After the import, the Synchronize part template procedure will open where you execute the synchronization and update new parts according to the part template.
- Open the Synchronize part template procedure for new AND updated parts – After the import, the Synchronize part template procedure will open where you get to execute the synchronization for new and updated parts in the import file with a part template.
- Auto synchronize part template from import file for new parts – After the import, an automatic synchronization will be made with the part template which will update the new parts in the import file. This requires both that part template is included as a column in the import file, and that you prior to the import have configured a format template (in the backstage of the procedure) which also contains the Part template column and that you then select that format template. This decides that the synchronization takes place in relation to a part template for the part in question. If the part template in the import file is a different template than the one set as Default part template in the Part templates procedure, a dialog is shown when saving where you can see which values have been updated from the template in the import file. If the column for part template is not included in the format template or if part template is missing as a column in the import file, the values from the Fallback values box will be used instead.
- No action – After the import, no action will take place.
