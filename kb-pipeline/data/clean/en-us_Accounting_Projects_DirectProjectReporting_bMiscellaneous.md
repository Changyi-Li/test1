### Miscellaneous

#### Date
Here you see/enter the date for the reporting. Today's date is shown by default. This field cannot be left empty.

#### Reference
Here you can select a reference from the references registered in the system or you can type another name. If you select a reference you will see information regarding that reference by clicking the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png).

#### Employee
Here you can select an employee as the person who performed the reporting. An employee is suggested if there is such who is linked to the user which you entered as reference. Information about that employee is shown under the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png).

#### Work center
From the work center register you can enter the work center which the reporting concerns.

#### Department
Here you can enter a department which the reporting concerns. These are handled in the Departments procedure. The department is suggested based on the department of the reference (user).

#### Internal comment
Here you can enter a comment and also link files to the reporting. This is saved together with the consecutive number. The text can also be shown in different procedures and lists. By using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_file_link.png) to the right, you can see and link files for internal use.

#### External comment
This text can be printed on different documents using the Show external comment setting for the documents in the Document settings procedure. The text can also be shown in different procedures and lists. Using the ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_file_link.png) to the right, you can see and link files for external use. Files are printed automatically with the documents if the file has Automatic printout selected.
> Please note that file paths must be registered in the Paths procedure in order to enable files to be linked.

#### Invoicing status
Here you can see the invoicing status of the report. The default setting the same as the linked cost type in Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Project:. If the cost type that is linked to the activity is set to be invoiced, you’re able to choose whether the specific report should be invoiced or not.
-   
Ready to release for invoicing – The report should be invoiced, invoice basis is created for release in the Release invoice basis – Project procedure.
-   
Not to be invoiced – The specific report should not be invoiced, invoice basis not created.
-   
Invoiced – The report has been invoiced.
-   
No invoicing for this cost type – The cost type linked to the activity is not set to be invoiced in the Basic data – Project: procedure.

#### Order number
When the invoice basis has been released the corresponding order number is shown here.

#### Invoice number
Once the invoice has been approved, the invoice number is shown here.
