### Parameter groups
- In the parameter group there are now some settings which could earlier only be configured via system settings. For example the ability to record in the negative flex zone and ability to enter planned absence via the recording terminal.
- The settings made via a parameter group is no longer possible to change for a specific employee. It was not necessary to in G5 include the handling where the program (in G4) copied changed parameter group settings to the employee register, since this in many cases resulted in unintentional changes for many of the employees.
- A new setting where you can enter which absence codes are not allowed for employees linked to a certain parameter group.
- If rounding of overtime is used, then you can choose to add the rounded time to any time bank you want. You get to choose if all rounded time should go to the time bank or just the rounded time within the flex zone.
- If an employee has fallen below the minimum limit for a time bank, then it is not possible to use the absence code which is configured to affect the time bank in question.
- It is possible to rename parameter groups.
