### Comment/Files
In this box you can enter internal and external comments, and link internal and external files to the customer order. You can also see comments and linked files for the customer.

#### Customer comment
Under this button you can see comments regarding the customer, if any. By using the ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_file_link.png) button to the right, you can see and link files for the customer. Comments and files are not printed. If there are no comments or files, the buttons are gray.

#### Internal comment
This text can be printed on certain documents such as for example manufacturing order documents, by configuring a setting for the documents in the Document templates – Manufacturing procedure. The text can also be shown in different procedures and lists. By using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_file_link.png) to the right, you can see and link files for internal use. The files cannot be printed.

#### External comment
This text can be printed on different documents by configuring a setting for the documents in the Document settings procedure. The text can also be shown in different procedures and lists. By using the button to the right ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_file_link.png) you can see and link files for external use (e.g. a PDF to be attached to an order document). Files are printed automatically with the documents if the file has Automatic printout selected.
> Please note that file paths must be registered in the Paths procedure in order to enable files to be linked.
