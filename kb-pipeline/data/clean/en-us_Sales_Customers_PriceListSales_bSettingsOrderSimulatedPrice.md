### Settings – Order simulated price
Settings for the list types Order simulated price and Order simulated price – External.

#### Language
This setting determines the language used for part name and unit in the list. Provided that there are translations specified. Note that headings etc. are always written in the language of the user.
If you have selected the list type Order simulated price – External, then the language on part name and unit will automatically be the language of the selected customer.

#### Show
This setting determines if price lists and customer links where the price each is equal to zero (0,00) or is missing also should be printed.

#### Order type
The order type is set to the logged in user's default order type. If the user does not have an order type, then the first one will be used. You can change order type to affect the result in the list.

#### Customer
In this field you must select for which customer you want to load prices.

#### Currency
Here you see the customer's currency. The exchange rate is displayed to the right. If the selected customer's currency differs from the currency in the price list, the price will be recalculated based on the customer’s currency . The exchange rate is loaded based on the setting called Rate type strategy in the Order types procedure: either According to customer or According to order type.

#### Customer's Reference
External. The selected customer's default reference is shown but you can change to another of the customer's references.

#### E-mail
External. The selected customer reference's e-mail address is used by default, if such has been entered.

#### Our reference
External. The logged in user's reference is set by default, but you can change to another reference.

#### Order of priority for quantity
In this table you can move the alternatives up or down to select in which order of priority the quantity alternatives should be used when calculating price.
- Order quantity – The quantity is based on the order quantity entered under the Planning tab in the Part register procedure.
- Quantity for lead time (customer) – the quantity is based on the quantity for lead time entered for the customer link under the Sales tab in the Part register procedure.
- Quantity for lead time (part) – the quantity is based on the quantity for lead time entered in the Miscellaneous box under the Sales tab in the Part register procedure.
- Any quantity - The quantity is based on the quantity entered in the field.
