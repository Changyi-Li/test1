### Header row

#### Budget chart
Here you enter the code for the budget chart using a maximum of 3 characters.

#### Name
Here you enter the name of the budget chart. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Number of months
Here you enter how many months should be included in the budget chart. 12 months are selected by default.
