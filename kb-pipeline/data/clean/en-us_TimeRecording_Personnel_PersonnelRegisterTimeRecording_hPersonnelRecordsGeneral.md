### Header row

#### Employee number
Here you enter the employee number for the person using a maximum of 10 characters. This is not linked to a number series, you manually give the employee numbers to the staff. In this field you can load a person or add a new by entering a new number. A new record is highlighted by a green dot ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/green_dot.png) shown in the field. This dot will disappear when the record is saved for the first time.

#### First name, last name, and initials
If the employee number belongs to a person already registered in the personnel records, these fields will become automatically filled in. If you enter a new employee number, you must enter first name and last name. The first letter in the first name and last name will be suggested as initials, but they can be changed.

#### Warehouse
Applies if you use the Warehouse option. Here you select the warehouse to which the person belongs. Persons in the personnel records are linked directly to a warehouse (in the same way as work centers). Warehouse entered for a person is used a selection term in different procedures.
