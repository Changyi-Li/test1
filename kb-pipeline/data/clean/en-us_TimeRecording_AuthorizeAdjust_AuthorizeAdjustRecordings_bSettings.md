### Settings

#### Show employees
- All I can adjust – With this option the list will include the persons for which you are authorized to adjust attendance and/or work. It will also include the persons which do not have a signer at all in the personnel records.
- For which I am main signer – This alternative will include all employees for whom you are the main signer.

#### Show blocked
With this setting you decide if you also want to show blocked personnel, if there are blocked persons in the setting above called Show employees.

#### Authorization interval
Here you select a date interval within which you will be working with authorizing attendance. You must select an interval to be able to authorize persons. When you have selected a date interval, the calendar will start on the week when the date interval starts, otherwise the calendar starts with today's date visible in the calendar. However, you can still navigate in the calendar outside the date interval entered.
