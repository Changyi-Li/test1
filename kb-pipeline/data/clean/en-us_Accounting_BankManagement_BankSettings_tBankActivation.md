### Bank activation
Under this tab you activate which bank/bank format should be used for payment files.

#### Country
By default you will here see the country for which the system is intended (determined by the country package). However, you can select a different country.

#### Banks
Activate the bank you wish to use by marking the checkbox for the bank in question. This decides which active file formats will be displayed in the box to the right.

#### Active file formats
Here you see which payment file formats have been activated for the bank in question. This list is a total list of all the activated banks' file formats. That is, you see all formats available for the banks on which you checked the Active checkbox.
Once you have activated a bank you see the payment formats and confirmation formats for that bank. These formats are available to select for Electronic outgoing payment and Electronic incoming payment found under the Payment method tab.
In the Settings for export/import procedure you will then also be able to access setting for the bank's format. You find them under the Export tab for the export type called Payment file, and under the Import tab for the import types called Confirmation outgoing payments and Confirmation incoming payments.
