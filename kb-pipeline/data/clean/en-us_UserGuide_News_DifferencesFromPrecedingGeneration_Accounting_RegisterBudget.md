### Register budget
- Better user interface (a table) where you register budget.
- You do not have to enter in advance in the chart of accounts, which accounts you want to create budget on.
- The budget chart can be loaded from a setting in the Chart of accounts.
- It is possible to register budget on project level.
- It is possible to handle multiple budgets in parallel.
- It is possible to create a budget by copying from both result and budget at the same time.
- When copying budget you will see the result of the copying in a list before you save the budget.
