### Settings – New emission calculation

#### Calculation
- Recalculate stock driven M-parts – these parts will be recalculated and the result will be shown in the Material section. They are not included in the total boxes.
- Include calculation details – determines if the content in the calculation will be shown in detail. The result will be presented in its own tab, Details, as a tree structure showing emissions for operations and materials. Totals are also shown, per work center for operations, and per supplier for materials.
- Comment – Here you can enter a comment which will be saved together with the calculation.
- Overhead year – Here you can choose which year's overhead costs to base the calculation on. The default option here is the current year.
- Overhead type – Here you can choose the overhead type for the calculation. The overhead type is loaded from the Company emission register procedure.
- Use OH from parts – If this setting is checked, a sustainability calculation can be done for multiple parts simultaneously, each with a different overhead. The overhead entered for parts in the Part register is used.
- Purchased material calculation – The following options are available: Use saved emission value + transport, Run new calculation, and Use most recent calculation.

#### Terms
If you apply terms in BOM and routing, the calculation will be based on the values you enter here.
These values can also be changed per part under the List tab before you run the calculation.
- Quantity if order qty is missing – If order quantity is missing for the part, the value entered here will be used both during distribution of setup times and for terms which are based on quantity.
- Customer – If there are terms in the BOM and routing which are based on customer, the value entered here will be used to calculate for a certain customer.
- Finish date – If there are terms based on date, the value entered here will be used to calculate a specific date. Today's date is shown by default.
- Variant code – If the calculation applies to a specific variant of the part, you should enter a variant code here.
- Order number – If there are terms based on order number, you can enter an order number here for the calculation.
- Warehouse – If there are terms based on warehouse and the calculation applies to a specific warehouse, this warehouse can be selected here.
