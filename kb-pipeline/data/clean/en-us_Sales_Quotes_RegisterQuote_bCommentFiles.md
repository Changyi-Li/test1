### Comment/Files
In this box you can under each respective button see comments and files linked to the customer. You can also enter internal and external quote texts, and link internal and external files to the quote.

#### Customer comment
Under this button you can see comments regarding the customer, if any. By using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_file_link.png) to the right, you can see external files for the customer. The comments and files are not printed with other quote documents. If there are no comments or linked files, the buttons are gray.

#### Internal quote text
Here you can enter internal comments for the quote. These comments are not printed on any documents, but they can be seen e.g. in the Quote list procedure. By clicking this button you access a text editor where you can write and format text, insert images and signature, and hyperlinks, etc. When a comment/text exists, the symbol on the button will change from an empty speech bubble ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_no_comment.png) to a filled speech bubble ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_comment.png). By using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_file_link.png) to the right, you can add files to the quote for internal use. The files cannot be printed.

#### External quote text
Here you can enter external comments for the quote. These comments can be printed on quote documents by configuring settings in the Document settings procedure. They can also be shown in the Quote list procedure. By clicking this button you access a text editor where you can write and format text, insert images and signature, and hyperlinks, etc. When a comment/text exists, the symbol on the button will change from an empty speech bubble ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_no_comment.png) to a filled speech bubble ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_comment.png). By using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_file_link.png) to the right, you can add files to the quote for external use (e.g. to be attached to the quote documents). You can configure the files to be automatically printed together with quote documents.
