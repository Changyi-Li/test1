### Other addresses
In this box you can enter the customer's other addresses.

#### Invoice address
The same address as the mailing address is displayed under the Invoice address button. By checking the box Use separate address you can enter a specific invoice address for the customer. If you have changed the invoice address so it differs from the default address, this is indicated by the symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_broken_link.png) on the button.

#### Visiting address
The same address as the delivery address is by default displayed under the Visiting address button. By checking the box Use separate address you can enter a specific visiting address for the customer. If you have changed the visiting address so it differs from the default address, this is indicated by the symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_broken_link.png) on the button. If you after changing the visiting address, also make modifications to the delivery address, it will not affect the visiting address.

#### Website
Here you enter the address (URL) to the customer’s website. When an address has been entered, a button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_url.png) will be shown to the right. Using this button you open the website in your standard web browser.
