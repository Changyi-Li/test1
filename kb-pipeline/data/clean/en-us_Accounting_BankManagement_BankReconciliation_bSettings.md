### Settings

#### Load file
By clicking the Load file button you load the bank statement file. The default path for the import file is configured in the Settings for export/import procedure.

#### Account
Account number in Monitor ERP to which reconciliation should take place. An account is automatically suggested based on the bank account in the file.

#### Voucher number series
The voucher number series to be used when entries in the bank statement should be recorded.

#### Voucher text
The default voucher text is Bank statement but you can choose a different text for the journal/voucher that is created. These texts are handled in the Voucher texts procedure.

#### Voucher text
Voucher text for the voucher that is created when entries in the bank statement should be recorded.

#### Date interval
Here you see the date interval for the bank statement. The date interval is loaded automatically from the file.
