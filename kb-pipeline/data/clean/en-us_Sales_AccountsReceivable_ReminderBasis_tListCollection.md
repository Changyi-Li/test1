### The Collection list
This list type displays only invoices for which the maximum number of payment reminders have been printed. The limit for the maximum number of payment reminders is determined by the system setting Number of payment reminders to apply. In the list, you can choose invoices to send to an agency for collection.

#### Collection
With this checkbox you determine if the invoice should be sent to an agency for collection. For such an invoice, no further reminders will be sent.

#### Collection date
If you check the Collection setting, this column will be activated and today's date will be set as collection date by default, but it can be changed. If you uncheck Collection for an invoice, the collection date will be deleted from the list.

#### Number of payment reminders
In this column you can see how many payment reminders have been sent to the customer for the invoice in question. In this list the number shown is the maximum number of payment reminders for the invoices, but you can decrease the entered quantity if you for example would want to send additional reminders regarding the invoices.
