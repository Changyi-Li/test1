### The Undo scheduled depreciation list
This list shows only the most recently made depreciation for each fixed asset. The list will not include depreciation already marked as undone. You mark the Undo checkbox for the rows you wish to undo and then you click Save. A total is shown at the bottom for the value of the rows you have marked.
The Voucher date column displays the voucher date of the depreciation. In the same way as when canceling outgoing payments, a warning appears if the voucher date is not within the open periods, and the record refers to a record which is not entered in the journal. If you have marked the Undo checkbox on the row, then you can change the voucher date.
In the menu you can choose Save or Save and print depending on how the integration setting has been configured. If the records you undo are not booked, then you do not have to print a journal. If you use direct integration a box will open showing that it is recorded and which voucher number was assigned.
