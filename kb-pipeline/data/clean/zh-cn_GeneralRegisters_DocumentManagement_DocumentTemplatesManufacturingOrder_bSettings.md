### 设置
在此框中你可以查看和修改已选择文档的所有设置。
你可以低于表中查询所有设置的描述。它们按照部分进行排序。
页眉
| 设置 | 描述 |
|---|---|
| 默认副本数 | 你要打印文档的默认副本数。 |
| 数量的小数 | 行中数量列的值将在文档中以小数显示。如果不，取整为最近的编号。 |
| 显示配置 | 在文档中显示产品配置。 |
| 显示维护计划 | 显示属于已计划的维护的表格。这应用至具有工具和维护选项的系统。 |
| 显示控制计划 | 显示属于已计划的维护的校准点/测量数据的表格。这应用至具有工具和维护选项的系统。 |
文本
| 设置 | 描述 |
|---|---|
| 显示订单的生产评论 | 生产订单的生产评论将显示在文档的文本章节。你可以选择显示 无， 仅评论， 仅已链接文件， 或者 评论与文件两者。 |
| 显示组件生产评论 | 该组件生产评论将显示在文档的文本章节。你可以选择显示 无， 仅评论， 仅已链接文件， 或者 评论与文件两者。 |
| 显示组件版本 | 该部分的默认版本将显示在文档的文本章节中。 |
| 显示组件版本评论 | 该组件版本评论将显示在文档的文本章节中。你可以选择显示 无， 仅评论， 仅已链接文件， 或者 评论与文件两者。 |
| 显示图号和图纸版本 | 第一行上的图号和激活图纸版本将显示在文档的文本章节。可用的备选意味着： 无 将会显示。仅评论 （图号和图纸版本）将会显示。仅已链接文件 图纸版本将 与文档一起已打印.评论与文件两者 (图号和图纸版本) 将会显示并已打印文件。 |
| 显示组件的附加名称 | 该部件的附加名称（如果有）将显示在文档的文本章节中。 |
| 显示客户组件号 | 组件上的客户链接中的客户组件号将显示在文档的文本章节中。 |
| 显示内部评论从客户订单的内部评论 | 客户订单的内部评论将显示在文档的文本章节。 |
| 显示订单组件状态 | 生产订单的组件状态将显示在文档的文本章节，但仅是其偏离状态4（正常）。 |
| 显示组件状态5 的版本评论 | 仅当组件状态5（新版本）时，才会显示该部件对默认版本的组件版本评论。此设置适用设置 显示组件版本评论 不设置为 无。 |
| 显示组件库位 | 该组件库位将显示在文档的文本章节中。 |
| 显示序列号 | 序列号将显示在文档上。 |
| 显示客户订单行的货物标签 | 在这里你可以确定客户订单行的货物标签是否应显示在文档上。 |
| 显示客户。订单行评论 | 通过此设置，你可以决定是否在工单上显示与客户订单行中找到的组件相关的第一个已链接行类型4。 |
| 显示变量代码 | 通过此设置，你可以决定是否在文档中显示变量代码。最多可包含 20 个字符。如果需要更多字符，你可以更改文档布局。 |
工序
| 设置 | 描述 |
|---|---|
| 显示工序 | 对于旅行者，你可以确定 无 或者 全部 应显示工序。加工工序文档，你可以确定 激活的 工序或 激活包括前道和下一工序 应该显示在文档的工序章节。 |
| 显示指导 | 对于旅行者和工序文档，你可以选择显示 无， 仅评论， 仅已链接文件， 或者 评论与文件两者。 |
| 显示时间 | 工序的准备时间、单位时间和时间合计将显示在文档中的工序行上。那个设置 显示时间 影响有关在准备时间、单位时间和时间合计的单位设置以及显示外协成本的设置。 |
| 单位时间单位 | 单位时间可以显示为 分钟， 小时， 数量 / 分， 或者 数量 / 小时。 |
| 准备时间单位 | 准备时间可以显示在 分钟 或者 小时。 |
| 周期的单位 | 周期时间可以显示为 分钟 或者 小时。 |
| 合计时间单位 | 合计时间可以显示为 分钟 或者 小时。 |
| 显示外协成本 | 外协成本将显示在文档的工序行中。 |
| 显示货位上前道工序的货物位置 | 加工工序文档，你可以确定自前道工序的货位将显示在文档上前道工序的行中。 |
| 显示数量 | 操作的数量将显示在文档中每个工序下。如果在BOM 与工艺路线的工序中输入了附加 %或准备数量，则工序中的数量可以不同于（大于）订单中的数量。 |
| 显示报告号 | 操作的报告号将显示在文档的工序行上。 |
| 显示条码(报告号) | 操作的报告号也将作为文档中每个工序低于的基本代码显示。 |
| 显示开始时间 | 操作的开始日期和时间将显示在文档中每个工序的低于。 |
| 显示完成时间 | 操作的完成日期和完成时间将显示在文档中每个工序的低于。 |
| 显示控制计划 | 在旅行者上，你可以在单独页面上看到测量计划中的全部测量点。在工序文档上，你可以在物料列表低于看到操作的测量点。 |
物料
| 设置 | 描述 |
|---|---|
| 显示物料 | 此设置决定了有关物料“加工工序”的信息是否应显示在文档的物料章节中。可用的备选包括 无 或者 到活动工序。后一种选择可激活低于的设置。 |
| 显示指导 | 物料指导(BOM 与工艺路线中的物料说明将显示在文档中每个相应的物料行下。 |
| 显示标准单位 | 此设置决定是否应使用以下单位显示物料： 生产工单的物料领用 在组件登记中，如果物料有多个单位， |
| 显示报告号 | 材料的报告号将显示在文档的物料行上。 |
| 显示条码(报告号) | 物料的报告号也将作为文档中每个物料低于的基本代码显示。 |
| 显示库位和余额 | 你可以选择在文档的物料行上显示没有、全部或已建议的库位及其库存余额。已建议的库位要遵守领用物料规则。也就是说，第一个已建议线边库，然后按库位优先级，最后通过账龄分析。 |
| 仅显示物料剩余数量的物料 | 仅具剩余数量的物料才会显示在文档的物料章节中。 |
| 显示重量计算 | 在这里，你可以决定是否应在工单文档上显示重量计算数据。 |
工具
| 设置 | 描述 |
|---|---|
| 显示工具 | 此设置确定是否应在文档的工具章节中显示有关该工具的“加工工序”的信息。可用的备选包括 无 或者 到活动工序。后一种选择可激活低于的设置。 |
| 显示指导 | BOM 与工艺路线中的工具指导将显示在文档中每个相应的工具行下。 |
| 显示库位和余额 | 你可以选择在文档的每个工具行上显示没有、全部或已建议的库位及其余额。已建议的库位要遵守领用物料规则。第一个，将已建议已为订单已预留物料的库位。然后根据线边库、库存库位优先级以及最终的账龄分析来确定建议。 |
| 显示标准单位 | 此设置决定工具是否应与使用单位一起显示 生产工单的物料领用 在组件登记中，如果工具有多个单位， |
| 显示报告号 | 该工具的报告号将显示在文档的工具行上。 |
| 显示条码(报告号) | 工具的报告号也将作为基本代码显示在文档中每个工具的低于。 |
| 仅具剩余数量的物料 | 只有具有剩余数量的仅物料（工具）才会显示在文档的工具章节。 |
页脚
| 设置 | 描述 |
|---|---|
| 显示页脚 | 页脚将显示在文档上。 |
| 显示 | 通过此设置，你可以决定是否显示产品工程师信息或来自下一级的信息。 |
通用的
| 设置 | 描述 |
|---|---|
| 数量 | 你可以在这里选择显示订单的 已计划 或者 剩余的 文档上的数量。 |
