### Header row
Here you select the report number for which you wish to report material and also whether remaining quantity should be suggested to report.

#### Report number
In this field you enter the report number of the material that should be reported.

#### Suggest remaining quantity
If this setting is checked when you load a report number, the remaining quantity of the material will be suggested in the Quantity to report field. The Suggest remaining quantity when reporting system setting determines whether the setting should be checked by default.

#### Other information on the main row
On the header row you also find information about the basic type of the material (Basic type B is shown with a symbol and is loaded from the part template the material is linked to in the part register), part number, and name. You see to which manufacturing order the material belongs, in which main part the material is included, and which operation the material is for. Furthermore, you can see comments and files linked to the material, the order, the main part, and the operation.
