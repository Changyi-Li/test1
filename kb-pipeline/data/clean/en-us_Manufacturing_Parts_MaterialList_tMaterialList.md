### The list type Material list
In this list you can modify information on material rows. The information shown in this list is the same as the data on material rows in the BOM and routing procedure. For more information about each column, please [see the help function](../BOMAndRouting/bOperations.htm) for that procedure.
> Please note! If you change For operation and the operation number is not associated with any material, you will not receive a warning as you do in the BOM and routing procedure.
