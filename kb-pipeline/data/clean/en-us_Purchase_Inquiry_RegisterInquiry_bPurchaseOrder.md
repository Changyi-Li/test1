### Purchase order
In this box you can create a purchase order based on the current inquiry.
The inquiry rows for which you have activated the Purchase order checkbox when you click the Create purchase order button, will be released to order rows on the new purchase order that is then created.
If there are inquiry rows left, for which the Purchase order checkbox is not checked, you will see a warning in the box saying that there is no marked row to release to order.

#### Create purchase order
When you click the button Create purchase order, a dialog box opens where you can enter a new order number or leave it empty in order to load the next available order number from the number series. You can also select order type and priority. The posting is copied to the purchase order by default.
If the checkbox Purchase order is marked for all the inquiry rows, both this inquiry and its related inquiries will be finished by default when the purchase order is created. But if the checkbox is not marked for some of the inquiry rows, the inquiry will not be finished by default.
You can also choose to copy internal and external comments to the purchase order.
When you click OK in the window, the new order will be created and is then displayed in the Register purchase order procedure by default.
You can see the created purchase orders in the table in the box, and from there you can go to these order via the link ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) and preview the printouts ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_preview.png).
