### Settings (section settings)
Here you find additional settings for the section row in the report.

#### Page break
Here you can configure if you want to insert a page break before or after the section row. The option None is selected by default, that is, that no page break will be inserted.

#### Sign change
With this checkbox you determine if positive values should become negative and vice versa.

#### Show rows
With this setting you decide if the data rows added in the filter should be shown in the report.

#### Show zero-rows
With this setting you decide if the data rows with a zero balance should also be displayed in the report.

#### Active
Here you determine if the section row is active or not. If you deactivate a section row it means that both the header, footer, and the data rows will be hidden in the report.

#### Hide (available for total)
Here you decide if the section should be hidden on the report, but having the values included in the total.

#### Show section without values
With this setting you determine if the entire section should be shown even though it does not contain any values.
