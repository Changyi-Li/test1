## Countries
This procedure consists of a [table](bCountries.htm) where you configure general settings for the countries where you have business relations. This table with data in several columns already exists when you install the program for the first time. The countries can be edited but you cannot add more rows, that is, more countries. You cannot delete countries from the table either.
The settings configured per country are then used e.g. when you register customers and suppliers in the system.
Any changes made here will not be logged in a changelog.
