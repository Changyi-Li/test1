## Security settings
> Only system administrators should have access to this procedure.

#### Password policy
In this procedure you configure settings regarding password policy for users in the company.

#### Multi-factor authentication
Here you can also configure additional settings regarding multi-factor authentication (MFA), if this should be applied for users in the company.
MFA is a security measure which works as an extra layer of protection for the user accounts. The function is designed to prevent unauthorized access to user accounts, also in cases where someone has gained access to the user’s password.
MFA requires the user to identify with an additional authentication factor – here it is a one-time code generated by an authentication app, in addition to the user password. This extra protection makes it harder for unauthorized individuals/attackers to gain access to the user’s user account. This helps protect confidential or sensitive information and prevent unauthorized access. Read more about this in the help topic about the [login window](../../../UserGuide/Interface/LogIn.htm#MFA).
You also find information and instructions regarding MFA and password policy in [this guide](https://help.monitor.se/EN/MONITOR_G5/PDF/MFA_PasswordPolicy.pdf) in PDF format.

#### Partner solutions
If you, as a customer, have purchased a partner solution, the Partner solutions tab will be available, where you can generate access keys for official partner solutions

#### External products
If you, as a customer, have purchased an external product, the External products tab will be available, where you can generate access keys for external products.
