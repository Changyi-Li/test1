## Register stock order – Purchase
This procedure is part of the option Warehouse. Here you can create stock orders for purchase (purchase order). In connection with this, a corresponding stock order for sales (customer order) is also created which is linked to this stock order. Stock orders for purchase can be also be created in the Register stock order – Sales procedure in the corresponding way.
You can also change or delete existing stock orders for purchase. Before a stock order is deleted, a validation is made according to the following:
1. To see that no linked (regular) purchase order or manufacturing order exists.
2. To see that no pick list has been printed.
3. To see that no stock order row has been delivered.
If none of the cases mentioned above has occurred, you can delete the stock order. Then the linked purchase order for sales will also be deleted.
If the validation fails, you must first delete the linked stock order in the Register stock Register order – Sales procedure and then undo any delivery reporting that has been made.
If you add/delete or change a stock order row, then the corresponding will also be made on the linked stock order for sales. However, there are two different scenarios described below if there is a linked (regular) purchase order or manufacturing order to a stock order row for purchase.
- If there is no linked order to the row, you can change it as long as it has not been delivered or printed in a pick list.
- If, on the other hand, there is a linked order then you cannot change row type or part number. You can change delivery date, quantity, and revision but a warning appears informing you that the linked order might lose the synchronization. Then you must check if the linked order can be replanned. In other cases, the abovementioned also applies – that you can change the row as long as it has not been delivered or printed in a pick list.
