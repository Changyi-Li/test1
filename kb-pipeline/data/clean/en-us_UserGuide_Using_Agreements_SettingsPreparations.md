### Settings and preparations
To be able to manage customer agreements in Monitor ERP, you must make the required preparations and configure the following settings.

#### Order types
You may need to created more order types for agreements. This is done under the Customer agreement tab in the Order types procedure. One order type for agreements is included in the system.

#### Basic data – CRM
If required, you can create Activity templates for customer agreements. Such templates can then be used when you register an agreement, or you can configure default activity templates for your agreement order types. This is done in the Order types procedure.

#### Standard accounts
Enter a Preliminary accrual account using suspended VAT on customer agreement if you are using the accrual method (for agreements). Enter a Accrual account for agreements if you wish to use a default account for accruals of agreements.
