### Authorization list
In this box you can see the signers that are included in the authorization list for the invoice.

#### Current
In this column you can see where in the process of authorization the invoice is at the moment.

#### Action (status)
In this column you can see information for the signers that have already handled the invoice. The following actions can be shown:
- Authorized/Approved
- Approved with authorization limit
- Forwarded
- Authorized and forwarded
- Rejected.

#### Signer information
Under the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you can see information about the signer and send messages to the signer in question.

#### Parallel authorization
Here you can see if the invoice can be authorized in parallel. This is only to show if it is possible or not. If the box is checked it means that the invoice does not have to be authorized/approved in a certain order by the signers.
