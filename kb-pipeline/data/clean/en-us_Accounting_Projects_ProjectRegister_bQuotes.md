### Quotes
In this box you see the quotes that exist for the project in question. All quotes for the project are shown (except for quotes with status 6 and 8).
From the row in the table you can go to the Register quote procedure via a link or by double-clicking the record.
Using the Show document button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_form_viewing.png), you open the document in a separate window. There you can also reprint the document or attach it to an e-mail message.
