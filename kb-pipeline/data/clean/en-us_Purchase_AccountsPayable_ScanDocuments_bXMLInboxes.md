### XML inboxes
> You must register an XML inbox and a related file folder if you use a different e-invoice supplier than Crediflow. In that case you can import Peppol e-invoices.
In this box you add rows for paths to XML inboxes for EIM. You enter a path to the folder that should be XML inbox. For an XML inbox you also select a Filing folder and a Filing folder for errors. It cannot be the same folder. Please note! The folders for the XML inbox and filing folder must be created on the Monitor server.
When you have added a row for XML inbox, you click the browse button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_browse.png) next to the Path column and next to the Filing folder and select where the folders are located on the server. There are two options in the window that appears:
- Local path on Monitor server – This option applies to the server computer. Under Name you see the server's folder structure from which you select a folder.
- UNC path – This option applies to other computers in the network. Then you must enter the computer name on the Monitor server in the Server name field and press Enter. Under Name you see the server's folder structure from which you select a folder.
> It is important that you use the same path as the target path configured for E-invoice PEPPOL in the procedure called Settings for export/import. Enter a filing folder too. Please note! The filing folder must have a separate path. You cannot use a sub-folder in the path to the XML inbox.
In the Name field you enter a suitable name for the XML inbox. This name will then be displayed for the XML inbox in the navigation panel in the Register supplier invoice procedure. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.
In order for the inbox to be visible in the procedure above, you must also check the Active box.
