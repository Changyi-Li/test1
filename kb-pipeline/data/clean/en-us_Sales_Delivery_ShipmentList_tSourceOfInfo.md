### The Source of information list
This list displays sources of information, for example customer orders included in the shipment. For each shipment number you see number of packages, weight, shipping agent, freight payer, status, customer number, and customer name. The list is grouped by reference number, and it shows one row per source of information. The type of information source can be customer order/delivery, supplier, pick list, or customer.
The function menu contains the regular functions available for lists.
