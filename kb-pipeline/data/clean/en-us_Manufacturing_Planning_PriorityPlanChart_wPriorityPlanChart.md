## Priority plan chart
In this procedure you can see a graphic description of the planning of priority plans. In which order the operations should run, is shown in a "Gantt chart".
> Only work centers with the time precision Hourly planningHourly planning refers to when planning per work center is done per hour. Hourly planning is activated with a system setting. Period is then entered as date and time. You can view loading on hour basis. are handled in this procedure.
Work centers are shown on one axis and operations are illustrated as blocks along the time axis (the X-axis). The information is shown according to the master plan (planned start and finish times). You can replan operations by dragging the blocks to specific times. For example, you can plan operations during the day and enter gaps between the runs.
You can replan based on finish date or on start date.
The chart is based on master plan data. This means that a work center can have more than one operation planned to run at the same time. In that case, this is shown with several rows for the work center. The planning is only intended for one flow per work center. However, it is possible to replan from one work center to another work center.
It is also possible to show manufacturing order suggestion in the priority plan chart.
