### The list type Calculate alloy cost
If the list type Calculate alloy cost has been chosen, the list will show the selected parts for which you want to calculate and add alloy cost. In this list you can deselect parts that should not be included in the calculation. After the calculation you can deselect parts for which you do not wish to save alloy cost.

#### Quantity
The part quantity that the alloy cost is calculated for is always 1 and cannot be changed.

#### Unit
This column shows which unit that is used for quantity. Here it is always the part's default unit that is displayed.
Before calculation

#### Include
By default, all records are included in the calculation. You can deselect individual records by unchecking the respective box, or deselect all underlying records by unchecking the box in the column heading.
After calculation
In the column next to Save you see an icon ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/alloydata.png) if there is alloy cost data for an incorporated part. An icon is displayed for that part.

#### Save
By default the Save box is checked meaning that the price will be saved for the part. You cannot check the Save checkbox if one or several warnings exist for the part and you have deactivated the setting Save calculation in spite of warning.
