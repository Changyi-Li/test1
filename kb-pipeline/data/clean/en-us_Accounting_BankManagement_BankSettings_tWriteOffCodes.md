### Write-off codes
Under this tab you register write-off codes that can be used to set the remaining amount of the invoice to zero. The invoice will then be regarded as fully paid. Write-off codes can also be used during for example discount in arrears, cash discounts, and rounding. The write-off codes are used in the Incoming payments and Outgoing payments procedures.

#### Code
Here you enter the write-off code using a maximum of 6 characters.

#### Name
Here you can write a descriptive text as a name. You enter name texts in the company language and they are displayed in the user’s language.

#### Translations
By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Cash discount
This is marked for the write-off code that should be used for cash discount.

#### Account incoming payments
Here you select account for incoming payments.

#### Account outgoing payments
Here you select account for outgoing payments.

#### Dimensions
Here you will find dimension columns that can be linked to the write-off code. The dimensions apply to both incoming and outgoing payments.

#### E (Exception account)
Here you can you enter any exception accounts for customer groups or supplier groups.
