### Header row

#### Data source
In this field you select a data source for the business intelligence, that is, from where data should be loaded to be used as basis in this procedure.

#### View
In this field you select the view you want to see in the business intelligence. A view is what is displayed (in the boxes) below the header row. The view is tied to the data source.
> You can create your own views for a data source if you have permission to do this. This is done under Settings in the backstage of the procedure.

#### Period comparison
Here you select the type of period comparison that you want to perform: Date or Year. If you select Year, you can also configure for which years the period comparison should be made.

#### Period of time
Here you select which period of time to show in the view.

#### Year
If you select Year in the period comparison, you here choose for which years the comparison should be made.
