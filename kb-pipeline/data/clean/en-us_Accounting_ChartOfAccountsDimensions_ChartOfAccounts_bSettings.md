### Settings

#### Specification
If you activate this setting it is possible to enter a specification, that is, a text, on the posting row when posting on the account. The specification is also used in the accounts payable and accounts receivable to save invoice numbers to accounts payable and accounts receivable accounts. The specification setting must be activated for you to be able to for example enter a cheque number during incoming and outgoing payments. You can use a maximum of 100 characters in the field. This setting is not activated by default for a new account.

#### Quantity
If you activate this setting it is possible to enter a recorded quantity on the account. This setting is not activated by default for a new account.

#### Accrual account
With this setting you determine if an accrual should be created when posting on the account in the procedures Register supplier invoice and Register vouchers. This setting is not activated by default for a new account.

#### Order number
In order to reconcile the balance accounts used on invoicing plans you should activate the setting Order number for the affected accounts. Order number is saved at incoming payment and invoicing. It is also possible to use order number posting when manually registering vouchers.
In order for all management accounting transactions to be posted, the setting Order number must be activated for example on accounts for WIP to be able to reconcile stock values.

#### Block for manual postings
With this setting you decide that users are prevented from making postings and editing postings on the account. This means that it is only the system which can generate bookkeeping transactions on the account. You activate this setting for example for accounts receivable and account payable accounts, VAT accounts, stock accounts, etc., in order to prevent differences between AP/AR/stock values and the general ledger. However, the account can be selected by the user in certain system procedures, such as e.g. Posting matrix, Standard accounts, and is also available to choose as exception account on customer and supplier etc. This setting is not activated by default for a new account.
