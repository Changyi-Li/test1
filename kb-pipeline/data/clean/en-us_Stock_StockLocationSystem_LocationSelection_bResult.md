### Result
In this box you can see the result of the selection criteria you have added to the location selection. That is, which location names will be allowed to be used with the entered criteria for a specific part. Meaning, an answer to the question "In which locations is there room for the part?"
Select a Part and load it.
In order to load the result to the box you click the Load result button. The result shows if/how the rule works for the selected part.
