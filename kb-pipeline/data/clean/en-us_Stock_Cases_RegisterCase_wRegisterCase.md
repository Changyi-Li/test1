## Register case
In this procedure you register cases. Cases are mainly nonconformities, but there can also be other types of cases. A case can e.g. be a modification of a product or a suggestion of improvement. You can register a case for things you want to follow up on regarding activities and costs.
The case type you select when registering the case can be changed. The case type mainly determines which fields will be visible in the procedure window and the activities that will be suggested. These activities and costs can be changed in the procedure called Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Case.
By configuring some system settings for purchase and manufacturing, you can initiate a registration of a case at rejection in the Receiving inspection procedure and at rejection when reporting manufacturing orders. In that event, the case will be created once you save the rejection. You can then choose to go ahead to that case. A lot of the information in the form is automatically completed.
You can add extra fields for this procedure in the Extra fields procedure. If such fields already have been created, these will be available under the Extra fields tab.
Support for 8D
The case type called 8D Standard makes it possible to apply the 8D method in Monitor ERP. If you have selected the 8D case type, the Header tab will get a different design and contain boxes with all steps included in 8D.
Attach XML file when case is sent via e-mail
If you have customers or suppliers who also use Monitor ERP, you can attach XML files if you send cases as PDF files by e-mail. The setting for this is configured under the Attach XML file button in the Customer register and the Supplier register procedures. To customers you can send confirmations and replies regarding cases. To suppliers you can send claim reports. The customer/supplier then imports the XML files to their cases from the Inbox Monitor-to-Monitor desktop component or by using drag and drop of e-mail or XML file.
