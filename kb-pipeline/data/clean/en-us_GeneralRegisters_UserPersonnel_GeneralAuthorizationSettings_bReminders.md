### Reminders
In this box you configure if the user should receive reminders of different tasks to perform regarding approval of purchase orders. The reminders are sent as notifications.

#### Notification for purchase order
Here you determine if notifications for different tasks should be sent to the user selected in the box Users. The available task options for a user are For approval, To adjust, and To print.
The notification appears in the bottom right corner of the program window when there are tasks to perform. You can see and perform the task under the Purchase order tab in the Tasks window, under the Message center button on the title bar in Monitor ERP.

#### Show purchase order approval dialog
Here you determine if a message should be displayed when a user saves a purchase order whose value exceeds the user's purchase limit.
