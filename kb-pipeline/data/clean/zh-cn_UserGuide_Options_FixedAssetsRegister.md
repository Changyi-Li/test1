# 固定资产登记
会计模块中的此选项为管理公司的固定资产提供了系统支持。

#### 固定资产对象
固定资产对象是指设备设备、建筑物等。这些应该在固定资产登记中已登记为资产。可以基于为对象已配置的设置对登记中的固定资产对象进行折旧。你还可以登记不折旧的物品。你还可以根据应付账款和凭证登记来创建和更新固定资产对象。
[![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/Options/FixedAssetsRegister2.png)](../../../Resources/Images/Options/FixedAssetsRegister2.png)
可以从固定资产登记中已打印不同的清单。这些清单用于多个用途，例如将固定资产的剩余值与资产资产负债表协调或查看有关折旧和销售的信息。它们还可用于显示和更新有关固定资产的信息。

#### 折旧
支持已排程、已计算、 对固定资产登记中的固定资产对象折旧。折旧基于有关固定资产的信息以及固定资产组的设置。
当计划折旧完成时，残余值和累计折旧将被已更新。时间已创建记录/入账折旧的基础。对于计划折旧，有直线法法、余额递减和余额递减+直线法
在已计算折旧时，将基于固定资产组的设置计算折旧。与计划折旧相反，已计算折旧不法律规定。它是基于内部的目的而发生的。这些通常涉及基于资产替换成本而不是购置价的价格计算和盈利能力计算的基础。
[![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/Options/FixedAssetsRegister3.png)](../../../Resources/Images/Options/FixedAssetsRegister3.png)

#### 固定资产日记账
你可以打印有关折旧和过账的日记帐。可以对日记帐进行审查然后已批准。然后它们被已传输到会计。在许多案件下，公司还会打印日记账/会计订单并将其放入凭证夹中。如果你通过日记帐打印输出应用集成应用于会计，则仅你使用固定资产日记账。

#### 销售 / 处置
在固定资产销售 / 处置连接，系统会从资产负债表中删除该固定的值自，时间该固定资产将被赋予“已售出/报废”状态。任何利润或亏损也将被已编码。如果销售是在最近一次折旧之后进行的，则还可以记录截至销售日期的折旧。
如果销售涉及主要对象，你可以选择是否已链接的子对象包含在销售/处置被用于。不包含在处置/销售中的子对象将与主要对象断开连接。例如，子对象可以是大型设备（主要对象）的组件的相关部件。
可以出售/报废组件固定资产。该固定资产在登记中然后保持激活，但购置价和累计折旧/残值会减少。
可以撤销折旧、销售和处置。例如，你可以撤销你执行的折旧，这意味着将时间撤销许多固定资产的折旧。另一个目的可能是撤销特定固定资产的折旧，例如，如果某项固定资产已在时间期间内进行了折旧，但由于新建情况而需要撤销或错误执行。

#### 固定资产导入
可以从文本文件导入固定资产。这主要用于载入全新的记录，但也可以用于更新先有记录。
