### 导出设置
如果你安装了该选项，则此标签页可用 导出工资底单。导出设置决定已导出工资基础的格式。导出的文件格式适合于公司的工资程序。此次导出是在 导出工资底单 你选择一个必须第一个在此处已登记的导出设置的程序。
在里面 薪酬方案 框中你添加导出工资底单的路径 Monitor ERP 加入你的薪酬方案。
在里面 设置 框中你可以向路径添加一或多个文件格式，具体取决于要已导出到工资单程序的文件数量。对于每个文件格式，你输入文件名称、选择部件（如果可用），并标记是否应使用工资类型的别名。

#### 文件格式
在此列中你选择工资单程序的文件格式。目前支持： 帕金森病， 维斯马， 软网 （仅应用至瑞典）， 阿格达， HogiaLön Plus， HogiaLön， V10， 藍色花園， Visma Løn（丹麦） 胡尔特和利勒维克， 联合微电子， 最佳组合， 和 美科。
例如， PAXml用于Kontek 和 Crona Lön。转到 [www.paxml.se](http://www.paxml.se/) 以获取完成列表。
> 在交货包含的文件格式 导出工资底单 可用于在这里选择。
V10 的特别设置
1. 如果公司要将导出工资底单到 V10，已添加在 员工 标签页卡中的 附加字段 程序。
2. 列 ID 对于附加字段也必须被已激活。这是通过系统设置完成的 显示外部程序标识 (附加字段)。
3. 员工标签页下的文本字段应具有ID“V10”。
4. 对于每个员工，你都应该在员工记录的附加字段中输入该人在工资单程序中的代码。
Visma Løn（丹麦）的特别设置
1. 如果公司应该将导出工资底单到 Visma Løn（丹麦），两个文本字段分别称为 客户信息 和 雇主编号 必须已创建附加 公司信息 标签页卡中的 附加字段 程序。以及字段 要导出的员工号 在下面 员工 附加字段中的标签页。
2. 列 ID 对于附加字段也必须被已激活。这是通过系统设置完成的 显示外部程序标识 (附加字段)。
3. 文本字段调用 客户信息 应具有ID“KUNDEFORHOLD”和文本字段 雇主编号 应该具有ID“ARBEJDSGIVER”。
4. “员工”标签页下的文本字段应具有ID“导出”。
5. 对于每个员工，你都应该在员工记录的附加字段中输入该人在工资单程序中的代码。
Bluegarden 的特别设置
1. 如果公司应该将导出工资底单到 藍色花園，字段在 员工 标签页，你还必须在 公司信息 标签页卡中的 附加字段 程序。
2. 列 ID 对于附加字段也必须被已激活。这是通过系统设置完成的 显示外部程序标识 (附加字段)。
3. “员工”标签页下的一文本字段应具有ID：“BLG_SALGR”，代表 Bluegarden工资组。第二个文本字段应具有ID“BLG_EMPNO”，代表 Bluegarden员工号。公司信息标签页下的文本字段应具有ID“BLG_COMPID”，代表 Bluegarden公司 ID。
4. 对于每个员工来说 员工记录 你应该在两个附加的文本字段中输入此人在 Bluegarden 中的工资组和此人在 Bluegarden 中的员工号。后一个字段可以左边。在这种案件下，该人的员工号为 Monitor ERP 将被使用。
5. 在里面 公司信息 对于公司，你应该在附加的文本字段中输入公司在 Bluegarden 使用的标识 。
Huldt & Lillevik 的特定设置
“4 标准 fast lengde”格式适用于 Huldt & Lillevik，文件名称应为“ITxxxTRS.HLT (xxx =客户编号)”。
Mepco 的特别设置
文件名称应为“siirto.txt”。

#### 文件名称
你在此处看到/输入已选择文件格式的导出文件的名称。必须根据低于表格为文件赋予正确的文件名称。
| 文件扩展名 | 文件格式 |
|---|---|
| .xml | PAXml、HogiaLön Plus（出勤 / 缺勤） |
| .tlu | 维斯马 |
| .wli | HogiaLön、HogiaLön Plus（日程表） |
| 。TXT | Agda、V10、Bluegarden、 最佳组合、Mepco |
| .hlw | 胡尔特和利勒维克 |
| .csv | UNI Micro、Visma Payroll |
| .dat | 软网 |

#### 部件
对于格式 帕金森病 可以标记要包括在导出文件中的部件： 工作时间日程表， 时间事务， 和 薪资事务。
对于格式 阿格达 可以选择一部件 出勤， 缺勤， 或者 日程表 包括在导出文件中。你需要为出勤创建一，为缺勤行一，行日程表行一。这将在 Agda 的导出设置中生成三个具有不同名称的不同文件。
对于格式 HogiaLön Plus 可以选择一部件 出勤 / 缺勤， 或者 日程表 包括在导出文件中。你需要为出勤 / 缺勤创建一，为日程表一。这将在 HogiaLön Plus 的导出设置中生成两个具有不同名称和文件扩展名的不同文件。
为了 维斯马， HogiaLön， V10， 藍色花園， 和 胡尔特和利勒维克，否可供选择的部件。

#### 使用薪资类型简称
检查工资类型复选框 导出时别名 填写 如果工资类型不存在别名，则在导出文件中将使用工资类型的代码。
