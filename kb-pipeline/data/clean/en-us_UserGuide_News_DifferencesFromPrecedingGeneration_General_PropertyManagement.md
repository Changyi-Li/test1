### Property management
The function Property management in G5 provides administrators (users with the role of ERP manager or System administrator) with the opportunity to configure properties on different objects in procedures and save this in property sets. The objects on which you can configure properties are checkboxes, fields, buttons, boxes, and tabs.
The administrator accesses the function by using the button Property management ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_settings_blue.png) on the toolbar in each procedure. When using the button, a property window opens where you add one or several Property sets and there you select to which users, groups, or roles each property set shall be applied.
In the property window there is a Test button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_test.png) you use to test a property set.
With the Select object in the procedure window button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_select_control.png) (Ctrl + F7) in the property window, you can activate a mode where you can mark which object you want you can to manage properties for in a procedure window.
The administrator also has access to the Administer properties procedure. Here it is possible for the administrator to select property sets by user, roles, user rights groups , and procedure. The administrator will quickly get a general view of which property sets are available and for which users they apply. It is also possible to add more users, roles, and user rights groups, to a property set. You can also delete property sets which should not be used anymore. However, you cannot edit a property set. To be able to edit, the administrator must open the affected procedure and from there edit the property set by clicking the Property management button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_settings_blue.png).
