### The Order summary tab
This tab is shown if you have selected the Part (mean price calculation) list.
The tab displays a summary per order for the orders that are included in each main part. Apart from that, you will see the same document and the same information as under the Summary tab.
In the left part under each respective main part, you can select the order of which you wish to see the summary. If there is one or several warnings for an order, a button appears on the row. By clicking this button, you go to the Warning list tab.
