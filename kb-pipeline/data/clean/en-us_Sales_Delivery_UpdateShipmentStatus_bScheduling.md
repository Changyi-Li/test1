### Scheduling
In this box you configure scheduling for continuous loading of printed shipments from nShift.
By using the button Reload ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_refresh.png) (Ctrl + Shift + R) you can update the table so you see the date and time of the most recent run.

#### Active
With this checkbox you determine if the scheduling in question should be active.

#### Name
In this column you see a description of the scheduling.

#### Interval
Here you see/enter the interval between the runs. It is shown in minutes. The default value here is 60 minutes.
> Please note! The value must be at least 5 minutes in order to not put unnecessary strain on the nShift web server.

#### Status
In this column you will see a green check mark ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/StatusFinished.png) if the run/task has been completed.

#### Latest task
Here you see the date and time of the most recent task.

#### Run
By using the Run button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_run.png), you can manually start a new run/task.

#### History
Here you see the history and the result of the runs, that is, which deliveries have been imported from nShift Delivery and if they match any deliveries in Monitor ERP.
