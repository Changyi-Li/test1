### The Packaging templates table
In this table you add the packaging templates which you want to use on parts. By using the buttons on the function menu you can add, insert, delete, and copy packaging templates. Each template is given a row number.
For the packaging template marked in the table, you add/create a combination of packaging parts in the Packaging template rows box.

#### Number
Here you see the position number for the row. This field is numerical. A new row will automatically be assigned the next available number. The table/list is sorted by this column. This number is unique and cannot occur on more than one row in the table.

#### Name
Here you enter a descriptive name for the template. This text is shown when the template is selected for a part in the part register.

#### Translations
By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Template code
When the packaging template is used to create a template for packaging structures in Pack for delivery, the code from the template is copied to the column Template code in Pack for delivery. The template code will be copied to the handling unit level.
