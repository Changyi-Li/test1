### Direct stock reporting

#### Use cause/posting in the procedure Direct stock reporting
This system setting determines if cause or both cause and posting must be selected for withdrawals and arrivals in the Direct stock reporting procedure. You can also choose to not use cause and posting for withdrawals and arrivals.

#### Project will be copied from the row above
Here you determine if a new delivery row or arrival row in the Direct stock reporting procedure should have the same project number as the row above, provided that the row above has a project. If the part on the new row already has a project linked in the part register, this will override this system setting.
