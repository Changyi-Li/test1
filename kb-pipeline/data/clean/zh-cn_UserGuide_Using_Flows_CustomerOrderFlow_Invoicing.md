### 开票
交货报告之后，就有就绪已开票的发票底单。

#### 直接登记发票
载入和修改现有的发票底单，或新建的发票基础。贷项发票也在这里已创建。

#### 发票底单
在这里你可以看到已已交货但未开票的商品。

#### 复审 / 批准发票
每个发票底单都必须经过已批准，之前你打印发票。当基础被已批准时，就会已创建发票号和应收账款。销售统计也将会已更新。你可以在发票底单获得已批准之前对其进行修改。已批准的发票不可撤销或已修改。在这种案件下，你需要将其记贷项。

#### 打印发票
你在这里打印发票。你可以通过以下链接直接访问 复审 / 批准发票。

#### 打印客户开票日记账
打印这些文档来更新您的会计。
> MONITOR提示！ 使用 发票日志 视图每客户、组件、期间等的销售统计。 使用程序 复审 / 批准形式发票 开票发票之前打印发票（国际的货运中必须随货物附上的发票）。 使用 更新应收账款分类账 不第一个开票而直接在应收账款中登记未付款记录。
