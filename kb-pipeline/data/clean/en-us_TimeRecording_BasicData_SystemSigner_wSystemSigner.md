## System signer
In this procedure you add users who should be system signers. A system signer is a user who has the rights to adjust attendance, adjust work, and/or authorize attendance for all employees.
However, you do not have to use system signers. As an alternative, you can manually add users as dedicated signer per person in the personnel records, with the corresponding rights.
Under the Signer tab in the Personnel records you see the system signers you register here and their corresponding rights.
> Please note! If the same user is both system signer and dedicated signer for a specific person, the settings for the dedicated signer will override the setting of the system signer.
