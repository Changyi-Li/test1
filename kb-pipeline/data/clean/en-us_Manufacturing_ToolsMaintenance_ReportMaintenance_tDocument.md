### Documents
Under this tab you see the document for the maintenance you are reporting. This document will become filled in with values once you save the reporting. If the maintenance status is Not OK, it will be shown in red text on the document.
This document can be printed ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_print.png) or sent via e-mail ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_email.png) as a PDF in an attachment. This is done by using the buttons on the toolbar of the procedure.
At the bottom of the tab you can zoom using the lever or by using Ctrl + the scroll wheel.
> In the Document templates procedure you can create your own variants of this document. There you find the document under Manufacturing and it is called Service reporting.
