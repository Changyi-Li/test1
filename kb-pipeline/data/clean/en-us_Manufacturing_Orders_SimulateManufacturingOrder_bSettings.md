### Settings
The terms you can enter below will be taken into consideration as if they are entered for parts, operation rows, and material rows in the BOM and routing. You can override values per part under the List tab before you start the simulation.

#### Quantity if order qty is missing
Here you enter the lot size according to which the simulation should be made. This will apply to those parts that are missing an order quantity. The default value is 1.
Under the List tab you see the quantity either as order quantity or the quantity entered in this field. If order quantity is missing for a part, the quantity will be displayed in red color in the list.

#### Customer
Here you select a customer if you wish to base the simulation on a certain customer number.

#### Finish date
This field is used to enter a finish date for the orders that are to be simulated. Terms entered in BOM and routing, if any, will also be validated regarding the date. Today's date is suggested by default.

#### Variant code
Here you can enter a variant code if you want the simulation to be based on a certain variant code.

#### Order number
You enter a customer order number here if the simulation should be based on a specific customer order.

#### Warehouse
If the simulation should be performed for a certain warehouse, you select the warehouse to use here. The current warehouse is selected by default. This setting is available if the Warehouse option is installed in your system.
