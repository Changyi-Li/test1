# 产品配置
通过使用产品配置选项 Monitor ERP，你可以管理和组合一个产品的多个变量和型号。基于某个基本模型，你可以组成不同的变量并创建产品的不同模型，然后计算价格并创建工单。

#### 用途
配置可根据工序字段和工作方式用于不同的需求：
销售 – 在报价和订单时可以轻松定义不同的产品变量，并且你可以直接看到可以创建哪些配置以及它们的成本。产品配置可以与网络解决方案相结合，为销售人员或客户提供一个用户友好的界面。这样，你就能提供更好的可访问性。
生产 – 通过正确的工序和物料目录制造右边的产品变量。这样可以轻松管理直接从客户订单生成的每个单独订单的变量。对任何配置都进行按标准计算、结构清单、检查交货时间以及相应的结构管理。基于最少量的组件，可产生多种不同的产品变量。
售后 –产品配置可以对每个产品变量进行详细的跟踪和可追溯性。通过集成的产品登记，每个售出的（特定）产品的信息都通过唯一的序列号进行管理。这有助于管理和提供备件、质保承诺以及每个变量产品的维护。

#### Web 解决方案
如前所述，你可以轻松地将产品配置与 Web 解决方案结合起来。然后，选择就可以根据自己的具体要求和需求例如网址的设计和布局。
全部配置数据都直接从MONITOR数据库加载。如果数据库发生变更，网址上的信息也会更改。
- 网络解决方案为客户和零售商提供了根据自己的需求自行配置和订单产品的机会。利用不同的登录信息可以调整产品范围、布局、语言等，以满足客户/零售商的需求。
- 这样，销售人员可以使用网络解决方案，在与客户讨论的同时直接设计产品，并一次了解可以创建什么，时间给出成本。

#### 基础数据
基础数据组成基本BOM 与工艺路线以及配置组，其中指定了不同产品变量的选项列表和规则。

#### 支持功能
附加，还有已配置产品的计算和订单程序以及用于显示和管理配置统计的功能。

#### 原则
产品配置可以看作是备选BOM与工艺路线的替代方案。在备选BOM与工艺路线中，你使用完成的“最大BOM 与工艺路线”作为基础，其中列出了全部可能的物料和工序变量，并借助规则你其中哪些将包含在BOM 与工艺路线中，或不包含在某个变量代码、版本、订单、客户、数量或期间的物料清单和工艺路线中。
当使用产品配置时，你将使用基本BOM 与工艺路线或“迷你BOM 与工艺路线”，其中仅你总是应包括在产品中的项目，并且这些项目不可选的，例如组件。

#### 配置
在配置中，不同的部件被组合成为已完成。该配置与订单登记、按标准计算、报价等连接。
