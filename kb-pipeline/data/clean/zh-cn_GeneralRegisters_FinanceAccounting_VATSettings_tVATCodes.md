### VAT 代码
你在此标签页下添加或修改VAT 代码。VAT 代码表格五月因系统运行的国家 / 地区不同而不同。例如，VAT 代码在系统中用于以下位置：
- 在发票/订单行上确定行的VAT 税率、VAT过账和VAT信息文本（后一种选择仅在销售期间可用）。
- 在会计科目表中的科目上，确定应如何在VAT 报告中已呈现当前账户的销售 / 采购情况。科目中的VAT 代码还决定了在会计中输入的手工过账行会计中应默认使用由哪个VAT 代码。后者仅在低于系统设置已被已激活时才适用。
-    
这输入于凭证上的过账行、供应商发票上的过账行、客户发票上的过账行等等。
> 请注意！过账行上的VAT 代码仅在你已选择了以下选项时才有意义 总账事务 VAT 代码 系统设置 VAT 报告底单载入自。然后，系统的VAT 报告将通过已保存的VAT 代码从每个会计事务中载入VAT 报告的基础。否则，仅会计科目表中的VAT 代码才会影响VAT 报告，即与当前VAT 代码链接至的科目的余额。

#### VAT
在输入你VAT 代码的VAT 税率。默认值0.00%。如果VAT 代码指的是 逆转付款责任，VAT 税率应总是为 0.00%。

#### 逆转付款责任
此设置仅应用至采购。如果应用逆转付款责任，检查此框。如果在采购时需要使用VAT 代码（例如从欧盟国家 / 地区采购），则估计的进项 VAT和销项 VAT将自动过已编码。

#### 逆转付款责任%
如果VAT 代码中已激活了逆转付款责任，则可以输入此项。在此字段中，你输入用于过账估计投入和销项 VAT的VAT百分比。此次VAT过账账与供应商发票登记连接。

#### 销项 VAT
在这里你可以选择应用至包含VAT的发票上已编码的销项 VAT的科目。如果你已选中 逆转付款责任，输入在逆转付款责任时你用于销项 VAT的科目。

#### 进项 VAT
在这里你可以选择应用至包含VAT的发票上过已编码的进项 VAT的科目。如果你已选中 逆转付款责任，则在逆转付款责任时你用于进项 VAT的科目。

#### 免赔额 %
对于组件VAT可扣除的VAT 代码，你可以在此处输入应扣除的百分比。这样做的目的是，当发票包含VAT不全额扣除的记录案件，实现组件供应商发票登记的自动化。对于VAT 代码，你输入可扣除的份额（％）以及用于无折扣VAT的科目。当你登记供应商发票时，仅可扣除的VAT 金额才会已编码进项 VAT科目。VAT的剩余部分将人工的已编码，或自动记科目无折扣进项 VAT科目。

#### 导入 VAT - 无免赔额
在这里你用于无折扣VAT的科目。

#### VAT信息 - 发票
你在此处输入VAT 代码的VAT信息，VAT 税率设置为 0%。在客户发票上，你将看到VAT信息，作为信息文本，解释为什么该发票豁免VAT。

#### VAT 报告链接 - VAT行(采购)
会计中的VAT 报告识别VAT 代码，订单决定在报告中显示的位置。如果在采购过程中使用了当前VAT 代码，而购置的VAT 底单应在VAT 报告中已报告，则你输入应在报告中的哪一VAT行中已报告。VAT行定义在 创建 VAT 报告 程序。

#### 采购链接
采购链接是VAT 报告链接 - VAT行(采购)列的扩展的设置。在这里你可以输入如何在国家VAT 报告中已报告采购/销售情况。系统支持处理多个并行VAT 报告（每国家 / 地区一VAT 报告）。在按钮下，你可以输入应在VAT 报告中的哪一行显示采购。这是针对每个国家的VAT 报告进行的。通常情况下，你仅输入VAT 报告中默认设置的VAT行即可。 创建 VAT 报告 程序

#### VAT 行 - 输入 VAT
会计中的VAT 报告识别VAT 代码，订单决定在报告中显示的位置。如果在采购时使用了当前VAT 代码，而进项 VAT应在VAT 报告中已报告，则你输入应在报告中的哪一VAT行。VAT行定义在 创建 VAT 报告 程序。

#### 链接 - 输入 VAT
链接 - 输入 VAT是增值税列- VAT 行 - 输入 VAT的扩展的设置。在这里你可以输入如何在每个国家的VAT 报告中已报告进项 VAT。系统支持处理多个并行VAT 报告（每国家 / 地区一VAT 报告）。在按钮下，你可以输入VAT 报告中的哪一行应显示VAT。这是针对每个国家的VAT 报告进行的。通常情况下，你仅输入VAT 报告中默认设置的VAT行即可。 创建 VAT 报告 程序

#### VAT 报告链接 - VAT行(销售)
会计中的VAT 报告识别VAT 代码，订单决定在报告中显示的位置。如果在销售中使用当前VAT 代码，且应在VAT 报告中已报告销售的VAT 底单，则你可以在此列中输入应在报告中的哪一VAT行中显示值。VAT行定义在 创建 VAT 报告 程序。
在采购和销售两者可以使用同一VAT 代码。这意味着该代码可以与VAT申报中的销售和购置两者链接至。例如，涉及欧盟贸易的VAT 代码两者被已报告为对欧盟国家 / 地区的销售，又被报告为从欧盟国家 / 地区的采购，具体取决于已记录该代码的科目是否具有VAT类型 采购科目 或者 销售科目。

#### 销售链接
销售链接是VAT 报告链接 - VAT行(销售)列的扩展的设置。在这里你可以输入如何在每个的VAT 报告中已报告销售 / 采购。系统支持处理多个并行VAT 报告（每国家 / 地区一VAT 报告）。在按钮下，你可以输入应在VAT 报告中的哪一行显示采购。这是针对每个国家的VAT 报告进行的。通常情况下，你仅输入VAT 报告中默认设置的VAT行即可。 创建 VAT 报告 程序

#### VAT 行 - 输出 VAT
会计中的VAT 报告识别VAT 代码，订单决定在报告中显示的位置。如果在销售中使用当前VAT 代码，而销项 VAT应在VAT 报告中已报告，则你输入应在报告中的哪一VAT行。VAT行定义在 创建 VAT 报告 程序。

#### 链接 - 输出 VAT
链接 - 输出 VAT是增值税列- VAT 行 - 输出 VAT的扩展的设置。你可以在这里输入如何在每个国家的VAT 报告中已报告销项 VAT。系统支持处理多个并行VAT 报告（每国家 / 地区一VAT 报告）。在按钮下，你可以输入VAT 报告中的哪一行应显示VAT。这是针对每个国家的VAT 报告进行的。通常情况下，你仅输入VAT 报告中默认设置的VAT行即可。 创建 VAT 报告 程序

#### EC销售列表（仅应用至欧盟国家 / 地区）
在这里你创建一个链接到 EC销售列表。EC销售列表（欧盟销售）的报告会识别科目或事务的VAT 代码（取决于上面提到的系统设置），以确定销售是否涉及欧盟贸易。此内容已输入至此列。你还可以输入应如何已报告值，如 贸易就是商品， 服务， 或者 三方交易。

#### ISO代码
这是自动已配置的，但是可以根据需要进行已变更。ISO 代码用于电子发票。

#### 日志
在已已修改的VAT 代码下一个，你会看到此按钮 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_more_info.png)。单击此按钮后，你可以看到谁已变更了VAT 代码、更改的日期和时间以及进行了哪些变更。

你在这里确定VAT 代码或不已激活。
