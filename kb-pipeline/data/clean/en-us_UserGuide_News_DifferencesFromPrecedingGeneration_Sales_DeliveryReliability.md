### Delivery reliability
- There is a separate column for remaining quantity in the list. This makes it possible to filter by e.g. 0. Not an asterisk * as in G4.
- It is possible to include stray customers (casual customers) in the list.
- If you via the net requirement calculation have calculated New finish for manufacturing order and customer order, then it is possible to use new list types in the Delivery reliability procedure to see the theoretical future delivery reliability. There are also two new desktop components which can display the future delivery reliability.
