### Cash flows
In this table you add a row for each cash flow, that is, the calculated distribution of incoming and outgoing payments over different periods.

#### Code
In this column you enter an alphanumerical code for the payment. It can contain a maximum of 10 characters. You cannot enter the same code on several rows, the code is unique for each row. However, it is possible to change the code for an existing payment.

#### Type
Here you select if the payment is an incoming or an outgoing payment. Outgoing payment is selected by default.

#### Amount
In this column you enter the payment amount in the company currency.

#### Start date
Here you select a start date for the payment. In the cash flow forecast, the number of days in a month is taken into consideration. For example, if the start date is set to 2016-01-31 and the periodicity is set to Month, the February payment will be made on the last day of that month, that is, 2016-02-29.

#### Periodicity
The periodicity selected here indicates how often the payment should recur in the cash flow forecast. You can choose between day, week, or month. Month is selected by default.

#### Quantity
Here you enter the quantity, that is, how many times the payment will recur in the cash forecast. The default number is 1 (non-recurrent payment). If the payment is recurrent, you enter a higher value. If you enter for example 3, the payment will recur three times starting from the start date.

#### Comment
Here you can enter a comment for the payment.

#### Active
With this checkbox you determine if the payment is active, and therefore should be included in the cash flow forecast.
