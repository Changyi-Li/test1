### Template
This is where you create templates for the 2D codes you need. The Default template cannot be edited.

#### Default
Here you select which template should be default.

#### Template name
Here you enter the name of the template. The name can contain a maximum of 50 characters.

#### Separator
Here you enter a separator. The separator can contain a maximum of 5 characters. Separators can be e.g. a semicolon (;) or a colon (:)

#### Separator type
This decides how the string is built, whether it is sequential or whether it uses a prefix.

#### Prefix delimiter
Here you enter a prefix delimiter. The prefix delimiter can contain a maximum of 5 characters. A prefix delimiter could be e.g. an equals sign (=).

#### Start
Here you enter a start value. Start values can be up to 10 characters long and must contain a number. E.g. >MD2;.

#### Thousands separator
Here you select a thousands separator. The following options are available: Space, Comma, Apostrophe, Period or No thousands separator.
