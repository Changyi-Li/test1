### 组件价格解释
为组件有多个不同的价格。在系统中，价格也被称为“价格类型”或“备选价格”。你可以在系统的不同位置选择当时可用或关注的价格在中间。
例如，在计算组件时，可以选择不同的价格类型，例如 标准成本， 最近采购价， 平均采购价，仅举几例。
有可已更新的价格类型，也有报告时生成的统计的价格类型。内部的价格类型以及统计价格类型总是以本位币显示。
在里面 价格调整 程序，你可以更新那些可以更新的价格类型。
可以更新不同的价格类型
| 价格类型 | 描述 |
|---|---|
| 标准成本 | 标准成本是系统中最为重要的组件价格。标准成本描述的是组件的值，它在多个场合使用，例如作为采购件物料的计算基础价格、库存估值、边际贡献等。对于采购件，标准成本可以是采购价格+ 采购成本（如果有）的建议价格。对于自己的生产件，意味着在系统中进行按标准计算，并将其已保存为标准成本。每个组件你有仅一标准成本。 |
| 未来标准成本 | 未来标准成本也是一个重要的价格。它可用于计算即将到来的年的未来价格。每个组件你有仅未来标准成本。 |
| 按实际计算平均价格 | 当生产组件主要由库存驱动组件组成案件，按实际计算平均价格是一个重要的价格。价格是已更新于 [按实际计算](../../../../../G5_UserGuide/Content/Topics/Manufacturing/Calculations/PostCalculation/wPostCalculation.htm) 使用列表类型组件(平均价格计算)的程序，它是基于已选择的工单编号的平均价。例如，按实际计算平均价格可以用作发票日志中边际贡献/ 边际贡献率的比较价格。 |
| 供应商价格 | 供应商价格是每供应商链接的采购件的当前价格。价格默认以供应商已选择的货币输入，但也可以在零件的供应商链接上已变更货币。当向相关供应商订单组件，然后默认以供应商链接的货币显示该价格。供应商价格可以交错，即你可以为某个组件的某个采购数量输入一价格，为另一个采购数量输入另一个价格，等等。 |
| 未来供应商价格 | 未来供应商价格是每供应商环节采购件的下一个价格。但是，在从相关供应商订购组件时不已选择未来供应商价格，但它可以在采购件的按标准计算和后计算以及不同的清单中使用。还可以错开未来供应商价格。 |
| 客户价格 | 客户价格是每供应商链接的为组件当前销售价格。价格默认以客户已选择的货币输入，但也可以在零件的客户链接上已变更货币。当登记客户对该组件下的订单时，然后默认以客户链接的货币显示该价格。因此，该价格将覆盖其它销售价格（价格列表），但仍可以在订单行上选择这些价格。客户价格可以交错，即，你可以为某个组件的一定销售数量输入一价格，为另一个销售数量输入另一个价格，等等。 |
| 未来客户价 | 未来客户价是每客户链接的为组件的下一个销售价格。未来客户价如何应用由系统设置决定 管理未来销售价格。在登记客户对该组件的订单时，可以选择未来客户价，也可以在不同的列表中已选择。还可以错开未来客户价。 |
| 准备价格（采购时） | 当供应商已为采购件组件提供了准备价格时，使用此准备价格。备选价格可以与供应商价格挂钩。你可以在订单登记连接查看并更新订单行上的准备价格。 |
| 准备价格（销售时） | 此准备价格通常用于确定自己的生产件的价格，其中销售数量影响销售价格。备选价格可以与客户价格和价格列表链接至。你可以在订单登记连接查看并更新订单行上的准备价格。 |
| 平均价 | 平均价是另一种平均采购价，已计算在 计算平均价 程序。计算平均价时，你可以选择你数量价格还是使用时间限制。你还可以计算加权平均价平均价（考虑到采购数量）。 |
| 价格列表 | 价格列表主要用于销售价格，但也可以用于其它目的。当可能需要使用可选价格时，大多数案件下，价格列表都作为一种价格类型包含在系统中。你可以为某一组件登记无限编号的价格列表。你要应用的价格列表已创建在 价格列表 程序。在此程序中，你可以看到已创建的价格列表，其中包含每个相应列表的编号、名称、货币和汇率类型。与全部其它价格类型不同，价格列表不预先定义的。每个价格列表可以包含阶梯价格，也就是说，你可以为某一组件的一定销售（数量）输入一价格，为另一销售输入另一个价格，等等。价格列表是在客户登记中已选择的，当组件否已登记与客户已链接价格案件，价格表决定在报价、客户订单和发票上已建议哪个价格。 |
不同的统计价格类型
| 价格类型 | 描述 |
|---|---|
| 平均采购价 | 平均采购价是基于最近十次到货组件采购的价格，已计算方法为：（数量x最近十次到货的价格）/合计采购数量。 |
| 最近采购价 | 最近采购价是在最新到货报告的订单行中找到的采购价格。当你将到货与供应商发票链接并更改发票上的价格时，价格也会已更新。 |
| 平均销售价 | 平均销售价是基于最近的编号最近发票的某一组件的销售价格的平均价值。用于已计算价格的发票数量预先定义为最近发票的平均价值。当发票被已打印并批准时，平均销售价就会已更新。 |
| 最近销售价 | 最近销售价是最新一张发票上的销售价格。当发票获得已批准时，最近销售价就会已更新。 |
| FIFO 价格 | FIFIO价格仅用于库存估值目的。此价格根据第一个( 第一个 ) 原则已计算（见低于）。系统在到货报告中生成的库存日志是此项计算的基础。 先进先出原则： FIFO 是通过系统中现有的旧的库存日志记录来已计算的。所有记录都有一个价格，该价格在到货报告期间已保存。然而，对于采购订单，当供应商发票与到货已登记项目相链接时，价格将会已更新。这意味着即使在已创建最近的库存价值列表之后否发生库存， FIFO值也可能更改。库存盘点和直接至仓库都以标准成本作为值。其它事务（例如通过工单对物料进行值低于报告）不影响先进先出的计算。当要已计算先进先出 (FIFO) 时，第一个要检查零件的余额。然后程序将查询尽可能多的 (值高于)事务以 评估 这些组件. FIFO计算例如： 你合计有 100件组件的余额。与该组件相关的最近行动是，你第一个以每个20欧元的价格采购件了80件，然后以每个10欧元的价格采购件了20件。然后FIFO 将为 80 × 20欧元+ 20 × 10欧元= 1 800欧元。也就是说，单价为18欧元。 |
