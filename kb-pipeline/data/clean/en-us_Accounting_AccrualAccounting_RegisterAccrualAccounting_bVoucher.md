### Voucher
In this box you add the record which is the basis of the accrual. For example, a voucher or a reversal voucher. For existing accruals it is not possible to change record if a release has been made. Which fields that are displayed depend on the type selected in the header row. For the type Manual entry, this box is empty.

#### Voucher number series
Here you select from which voucher number series you want to load voucher number. Under this field you see the voucher date of the voucher.

#### Voucher number
Here you see the voucher number the accrual refers to.

#### Account
Here you select the posting row on the entered voucher which should be accrual accounted. The posting row you select is automatically added in the Posting box.

#### Amount
Here you see the amount on the posting row.
