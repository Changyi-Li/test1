### The Attendance/Absence list
In this list you see information about made adjustments of attendance and absence recording items. The adjusted information is shown in boldfont.

#### Type
Here you see which type of adjustment has been made. New records have the type Created. Records which have been updated have the type Updated. Records which have been removed have the type Deleted.

#### Employee number
In this column you see the number of the employee for which the row applies. The list is sorted by this number.

#### Log date
Here you see the date and time when the adjustment was saved.

#### By
Shows the user who made the adjustment.

#### Clocked in and Clocked out
In these columns you see the date and time of the clocking in and clocking out. The row marked with Old shows the old recording item before it was adjusted. If no such previous recording exists, then the row will be empty. The row marked with New shows the new and adjusted recording item. The row is empty if the adjustment is of the type Deleted.

#### Schedule
Here you see which schedule the recording has taken place in.

#### Time, Overtime, and Flex
In these columns you can see the recorded amount of time (in hours) and how much of this was overtime and/or flex.

#### Absence code
Here you see the selected absence code and its name.
