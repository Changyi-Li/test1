## Work center register
In this procedure you create work centers, update existing work centers, and delete work centers. A work center is a part of the factory's machinery, for example a separate machine or a group of similar machines. It can also be manual work or a subcontractor.
If it is a group of several similar machines, then it is possible to configure that the manufacturing takes place parallelly in the machines, via number of machines per order.
A work center with several of the same type of machine can also be a pool work center. Then each machine is a work center which is included in the pool work center. Then the BOM and routing and the planning will be made against the pool work center and not for a specific machine. Read more about this in the online help function for the procedure Pool planning.
You must first create work centers in order to register BOM and routing. In BOM and routing, each operation is linked to a work center. There are two reasons why each operation is linked to a work center: to calculate the cost in a pre-calculation, and to show a loading plan. The criteria for making a part of the factory an individual work center is therefore that the costs differ but are homogeneous within the work center; or that you want to create a loading plan for that particular part of the manufacturing process.
The Work centerA work center is a part of the factory. It can be a single machine or a group of machines, a single workstation or a group of workstations. register procedure consists of tabs where you enter information for planning, costs, and power for the work center in question. There is also a tab called Schedule which is active for work centers with the time precision Hourly planningHourly planning refers to when planning per work center is done per hour. Hourly planning is activated with a system setting. Period is then entered as date and time. You can view loading on hour basis. and Capacity via schedule.
You can add extra fields for this procedure in the Extra fields procedure. If such fields already have been created, these will be available under the Extra fields tab.
Extra fields for work centers can be used for selections in lists and columns in own presentations.
