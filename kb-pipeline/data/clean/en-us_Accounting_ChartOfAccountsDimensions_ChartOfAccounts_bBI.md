### BI

#### Alias for BI
Alias for BI can be entered on accounts if the Use alias when exporting to Business intelligence system setting is activated. The default alias is the same as the Account field (the account’s number), but this can be changed. This setting determines which account alias should be shown in Monitor BI. The purpose of the alias is to aggregate data, if the same alias is used on multiple records, the data from the reports will be merged into one record.

#### Heading for BI
Each account can be linked to a heading for BI, this is however optional. Headings are a way to structure accounts and determine how data is grouped and summarized in Monitor BI. Headings and their numbers are registered and updated under the Headings for BI tab in the Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Chart of accounts procedure.

#### Group internal
This setting determines how data is summarized in Monitor BI. The check box can be marked by accounts that are group internal and should be excluded in cases where you have views that summarize multiple consolidated companies.
