### Changes
In this box you see all details and you can choose which changes/actions you wish to execute. You execute them by saving on the toolbar. The box is divided in the nodes, operations, and material which exist on the manufacturing order.
The checkbox Include is activated by default so the changes will be included in the synchronization. If there is a warning ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png) on a row you have to manually check the checkbox if you want to include the change in question. In certain cases, a change cannot be included. Then you see an error symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/error.png) on the row. When there is a warning symbol or an error symbol on a row, you will see the reason for this in text in a tooltip over the symbol.
By clicking the button Changes ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) to the far right on a row, you get to see what the row will change, the value before and the value after the change, if any.
