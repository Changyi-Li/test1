## Print outgoing payment journal
In this procedure you can load journals of outgoing payments and their postings. You can review the journals and then approve them without printing. You can also print a journal together with an accounting order and in connection with this you can approve the journal, e.g. in order to put it in a binder with vouchers.
> You only need to use the procedure if integration to the accounting via printout of journals can be made. If you apply direct integration of payments, you do not need to load the journals and approve them, alternatively print and approve the journals.
If you do not have the Accounting module in Monitor ERP, you use the procedure to create accounting records to be recorded in your separate accounting system.
New entries will be shown in this procedure when paying supplier invoices or canceling payments in the Outgoing payments procedure. One journal per voucher date is then created. When you approve the journals, the entries will no longer be seen in this procedure. However, you can reprint the journals by selecting a reprint.
> This procedure is available in the Purchase module and the Accounting module, with the same contents.
List types

#### Outgoing payment journal
This list type is used to load outgoing payment journals in order to approve them. After the approval, the journals will be transferred to the accounting. You can also use this list to print the journals.

#### Reprint – Outgoing payment journal
This list type is used to load already approved outgoing payment journals. With this list you can reprint them.
