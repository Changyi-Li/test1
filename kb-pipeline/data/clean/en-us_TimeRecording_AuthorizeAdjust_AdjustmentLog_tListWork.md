### The Work list
In this list you see adjustments made regarding work recording items. The adjusted information is shown in boldfont.

#### Type
Here you see which type of adjustment has been made. New records have the type Created. Records which have been updated have the type Updated. Records which have been removed have the type Deleted.

#### Employee number
In this column you see the number of the employee for which the row applies. The list is sorted by this number.

#### Log date
Here you see the date and time when the adjustment was saved.

#### By
Shows the user who made the adjustment.

#### Clocked in and Clocked out
In these columns you see the date and time of the work recording. The row marked with Old shows the old recording item before it was adjusted. If no such previous recording exists, then the row will be empty. The row marked with New shows the new and adjusted recording item. The row is empty if the adjustment is of the type Deleted.

#### Schedule
Here you see which schedule the recording has taken place in.

#### Time
In this column you see the recording item's duration (in hours).

#### Report number
Here you see the operation's report number which was recorded (direct work).

#### Indirect code
In this column you see the code for indirect work which has been recorded.

#### Quantity
Here you see the quantity reported in the recording. For indirect work you always see the value 1,00.

#### Rejections
Here you see the reported rejected quantity, if any.
