## Basic data – Project
In this procedure you register different basic data for the project accounting.
Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. means:
-   
Project types
-   
Phases
-   
Activities
-   
Activity templates
-   
Costs/Income
-   
Project groups
-   
Profit mark-ups, if any
-   
Scheduling
Data from this procedure is then used in different projects you register.
When you install the system, some basic data is included as examples. This is project types, phases, and costs/income. These examples can be edited or deleted.
