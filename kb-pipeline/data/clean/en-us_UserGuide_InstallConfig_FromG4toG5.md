## Upgrading from G4
Here we have gathered information for those who are upgrading Monitor from G4 to G5. To be able to upgrade as smoothly as possible, it is important that you go over the items below:
- Watch the [G5 intro for G4 customers (SV)](https://vimeo.com/340140872/3acdc459f4).
- Update your G4 installation ([instruction](https://help.monitor.se/SV/MONITOR/9_0/Default.htm#Konfigurering/att_uppdatera_programmet.htm?TocPath=Startbok%2520i%2520MONITOR%257CKonfigurering%2520och%2520underh%25C3%25A5ll%257CSystemunderh%25C3%25A5ll%257C_____5)) to the most recent version (9.0.17). Download the latest version from [Monitor Support information](https://supportinfo.monitor.se/Account/LogOn?ReturnUrl=%2f).
- Read the instruction called [Link employee to reference and seller in G4](LinkEmployeeWithReferenceSeller.htm) and link sellers and references.
- Make sure your G5 server conforms with our recommendations, please see the current [system recommendations](https://www.monitorerp.com/sv/support/systemrekommendationer/).
- To maximize the user experience, book a 1-2 hour appointment with one of our technical consultants. Contact [support@monitorerp.com](mailto:support@monitor.se?subject=Book a consultant for setup of G5 server).
- Are you interested in the Monitor Cloud solution instead of having your own server? Read more about [Monitor Cloud](https://www.monitorerp.com/EN/monitor-cloud/).
- Send a current backup of your G4 database to Monitor ERP System AB. You will receive a link to use when uploading. This is supplied by support@monitorerp.com. Please see [instruction](https://help.monitor.se/sv/MONITOR/9_0/Default.htm#Systemvard/Skrivare_-_Anvandare/Administration_av_databas/instruktion_ladda_upp_filer.htm?TocPath=Systemv%25C3%25A5rd%257CSkrivare%2520%252F%2520Anv%25C3%25A4ndare%257CAdministration%2520av%2520databas%257C_____2).
- Read about [Differences between G4 and G5](../News/DifferencesFromPrecedingGeneration/DifferencesPrecedingGeneration.htm), available both as text and videos.
- CAREFULLY READ the information about what data will NOT be converted ([Data not converted from G4 to G5](DataNotConverted.htm)). Please check with one of our consultants how you should go about to complement the data.
- A support technician will install the latest version of G5 on your G5 server.
- Read the instruction called [Register users after test conversion](SettingUpUsersAfterTestConversion.htm) and link the users.
- Read through and download the document [Go-live assistance from Monitor](https://help.monitor.se/EN/MONITOR_G5/Training/Assistance_Go_LiveG5EN.docx).
