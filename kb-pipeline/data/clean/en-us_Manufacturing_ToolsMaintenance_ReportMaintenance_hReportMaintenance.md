### Header row

#### Service number
The service number of the reported maintenance. You can either enter a service number or leave the field blank. If you leave it blank, it will be assigned the next available number from the number series for service numbers once you save the reporting for the first time. By using the LookupThe Lookup feature is a powerful search tool which allows you to search and load information from large registers. You open the Lookup feature by clicking on the dropdown button or by using F4 on your keyboard. feature in the field you can choose among the existing service numbers. You can search for a service number via, for example, serial number, maintenance type, and maintenance order.

#### Maintenance order
If there is a maintenance order registered for a tool, you can here select the maintenance order to report maintenance of the tool.
When you have selected the maintenance order the order's serial number and maintenance will automatically be entered. The fields Maintenance order, Serial numberA serial number is a number that is used for traceability for parts on entity level., and Maintenance, will be deactivated once an order is selected. If the selected maintenance order already exists on a created reporting item, the service number will also be filled in automatically.
By using the Change maintenance order button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_change_record.png) you can change the maintenance order if, for example, the wrong order was selected. You can only select among the maintenance orders registered for the same serial number and maintenance, and which does not already exist on reporting items already created.

#### Serial number
Here you enter the serial number for which maintenance will be reported.

#### Maintenance
Here you select the maintenance template to use when you report the maintenance item. You can choose from the maintenance templates available in the maintenance plan that applies for the part linked to the serial number.
