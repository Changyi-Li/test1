## Variables
This procedure is a part of the option called Product configurator. Here you add and update variables if they need to be used in configuration groups.
What are variables?
Variables allow you to create custom-made products, such as e.g. doors, windows, and mirrors.
Where are variables used?
Variables are used in different formulas such as rule formulas in configuration groups, time formulas and quantity formulas in BOM and routing, and price formulas for parts.
Where can I create variables?
Variables are added and updated in this procedure. Variables can also be created directly in the procedure Configuration groups, for example in connection with when you create a configuration group or when you create its structure. Those variables are also saved in this variable register.
Remove or deactivate variables
You can remove variables that are no longer being used by unchecking the Active checkbox, and then removing the variable. However, it is only possible to deactivate a variable which is not used anywhere in, for example, a configuration, BOM and routing, in any type of order.
Read more about how the [product configurator](../../../UserGuide/Using/Configurator/Configurator.htm) works under Using Monitor in the online help function.
