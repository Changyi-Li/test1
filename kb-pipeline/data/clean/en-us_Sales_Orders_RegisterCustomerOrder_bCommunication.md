### Communication
For a new customer order you will here, by default, see the e-mail addresses registered for the customer as recipient of the order confirmation and advice. Phone numbers registered for the customer as recipient of Advice to shipping agent, will also be shown. You can modify, delete, and add rows containing communication information for the order in question. It is the communication information registered on the default delivery address which is shown. If you change the delivery address of the order, then the communication information registered on that delivery address will be shown instead. See the explanation of the different columns in the help chapter for [Communication](../../Customers/CustomerRegister/bCommunication.htm) in the Customer register procedure.
The following rules apply regarding default recipient of e-mail:
1. The e-mail address which is recipient of Order confirmation, will primarily be used.
2. The selected reference’s e-mail address, will secondarily be used.
3. And in third hand, the first e-mail address which is missing a "recipient of" in the Communication box in the Customer register, will be used.

#### Printout via
With this setting you determine if the printout of the order confirmation and the delivery note by default will be made via printer or e-mail. The default value is loaded from the customer.

#### Print invoice via
With this setting you determine if the printout of the invoice should be made using a printer or via e-mail. The default value is loaded from the customer.
