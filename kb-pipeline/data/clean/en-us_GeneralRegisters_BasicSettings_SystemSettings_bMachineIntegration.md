### Machine integration
The system settings under this heading only apply to systems that use the option Machine integration.

#### Default code for indirect work during interruption
Here you select a code for indirect work that will be set for "undefined work" during reporting/acknowledgment of interruptions in the machine.

#### Indirect code for setup time
Here you select a code for indirect code that will be set for setup time during reporting/acknowledgment.

#### Indirect code for short stops
Here you select a code for indirect code that will be set for "short stops" during reporting/acknowledgment.

#### Indirect code when running without order
Here you select an indirect work that will apply when running without order for machines which are included in a Line. The machine's running time without order will be given this code.

#### Time limit for short stops (minutes)
Here you can enter a time limit in minutes for short stops. The value can be entered in decimal form. Stops which are finished within this time limit do not have to be manually reported by the operator.

#### Limit for yellow area on gauge used to show performance (entered in %)
If an OEE gauge is used, you enter the start value in percent for the yellow area on the gauge used to show performance.

#### Limit for green area on gauge used to show performance (entered in %)
If an OEE gauge is used, you enter the start value in percent for the green area on the gauge used to show performance.

#### Limit for yellow area on gauge used to show availability (entered in %)
If an OEE gauge is used, you enter the start value in percent for the yellow area on the gauge used to show availability.

#### Limit for green area on gauge used to show availability (entered in %)
If an OEE gauge is used, you enter the start value in percent for the green area on the gauge used to show availability.

#### Limit for yellow area on gauge used to show quality (entered in %)
If an OEE gauge is used, you enter the start value in percent for the yellow area on the gauge used to show quality.

#### Limit for green area on gauge used to show quality (entered in %)
If an OEE gauge is used, you enter the start value in percent for the green area on the gauge used to show quality.
