### Settings – Route sorting
Setting for the Route sorting list type in the Location list procedure.
General

#### Pre-select "Save"
With this checkbox you decide if all rows with locations in the list should be marked by default to be saved.
View

#### Sort according to
Here you decide how to sort the list of locations. The available options are: Name, then route sorting number and Route sorting number, then name.

#### Existing route sorting numbers
With this setting you decide if the existing route sorting numbers should be listed Ascending or Descending.

#### Location name
With this setting you decide if the location names should be listed Ascending or Descending.
New numbering

#### Numbering
With this setting you decide if the new route sorting numbers should be listed Ascending or Descending in the locations.

#### Start value
Here you enter a start value for new route sorting numbers. The default start number is 1010 (with an interval of 10). If route sorting numbers have previously been created and saved for the locations, the starting number will be the next available number according to the saved interval.

#### Interval
Here you enter the interval between new route sorting numbers. The default value here is 10.
