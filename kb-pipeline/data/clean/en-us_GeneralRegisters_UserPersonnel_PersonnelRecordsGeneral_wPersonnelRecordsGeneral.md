## Personnel records – General
In this procedure you register all personnel with employee number, name, and department.
For the person in question you can enter more information such as if the person is a reference, seller, purchasing agent, or responsible for customer. You can link the person to a user in Monitor ERP. This way you can see if the person, for example, is logged in, clocked in, etc. You can add an image of the person, enter periods of employment, and home address.
You can select persons in different contexts, e.g., as administrator of parts, our reference on customer order, seller for customer, purchasing agent,
For sellers you can then enter more information in the Seller procedure. There you can select among the persons specified as sellers in the personnel records. You can for example create budgets for a seller.
You can add extra fields for this procedure in the Extra fields procedure. If such fields already have been created, these will be available under the Extra fields tab.
> There is an expanded variant of this procedure called Personnel records – Time recording procedure, in the Time recording module. They have the same basic register but in that procedure you can also enter information about the person's schedule for attendance and settings regarding work recording. If the Machine integration option is used, you also find settings for this.
