## Monitor BI

#### Smarter decisions with clear visualizations
Monitor BI is a function that converts your company’s data into valuable insights. With this function you get the tools you need to simply and effectively analyze data, create compelling visualizations, and make smarter decisions.
In Monitor BI there is a wide selection of preinstalled dashboards and an editing feature which enables you to create new dashboards and customize existing dashboards.

#### Why choose Monitor BI:
- Gathers data in one place
- Create dashboards and KPIs
- Web-based
- Standard in Monitor ERP
