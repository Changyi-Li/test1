### Header row

#### Calendar number
In this field you can enter the calendar number. If you want to create a new calendar, you enter a new number.

#### Name
Here you can write a descriptive text as a name. You enter name texts in the company language and they are displayed in the user’s language.

#### Translations
By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Calendar type
Here you can select No holidays, Only Saturday/Sunday, Only Sunday, or a specific country's holidays. The system is delivered with holidays for some specific countries.

#### Go to date
The date selected here determines the start of the calendar. The week containing this date will be shown as a whole. The field shows today's date by default.
