### Header row

#### Consecutive number
In this field you can select/enter a consecutive number. You can load an existing consecutive number or leave the field empty to create a new consecutive number. When you save, the reporting will be given a consecutive number and the procedure is emptied. In the Previous consecutive number field you will then see the consecutive number you just saved.

#### Project
Here you can load an existing project from the registered projects. If you load a consecutive number, you will in this field see to which project it is linked. The name of the project is shown in the next field.

#### Main project
For sub-projects you will here see which main project it belongs to. If a main project has been loaded in the procedure, the Main project field is not available.

#### Cost/Income
Here you select if the reporting item concerns cost or income. If it is an income item it will not be possible to select an activity. The options shown for the cost types depend on what has been configured in the procedure Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Project under the Costs/Income tab.
