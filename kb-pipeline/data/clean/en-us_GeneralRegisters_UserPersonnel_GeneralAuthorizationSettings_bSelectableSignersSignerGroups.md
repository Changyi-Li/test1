### Selectable signers/signer groups
In this box you see all signers and signer groups that you can add to the authorization list in the Selected signers/signer groups box.
You can also add signers and signer groups by using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_goto_next.png) or by using the "drag and drop” function.
