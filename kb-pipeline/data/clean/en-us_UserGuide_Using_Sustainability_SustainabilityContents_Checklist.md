### Sustainability Contents/Chemicals – Checklist
This is a comprehensive checklist designed to help you start using the sustainability functionality for Contents/Chemicals in Monitor. Part contents can be used for many types of reports and is not solely intended for ECHA/Reach (chemical reporting).
Data in the following registers is used when calculating certain contents:

#### Basic data – Sustainability
In the Demander/Authority box, you enter the name of the demanders/authorities that should receive reports of the part contents (chemicals).
- In the Part contents types box under the Part contents tab, you should enter a Code and a Description of the contents type.
- In the Part contents box, you then enter the part contents (chemicals) that you need to establish a register of. You select Classification, enter the EC no., and CAS no., and if the content (chemical) is registered as a part in the Part register, you enter the Part number. You can select the unit g or kg. Select the Demander/Authority that requires a report of the contents. Read more about [Classification, EC no. and CAS no.](../../../Manufacturing/Sustainability/BasicDataSustainability/bPartContents.htm). You can enter a Comment, Link files, see which parts the part contents are Included in, and More info.
- Basic dataWith "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Part

#### Under the CN code tab, you select the Demander/Authority for the CN codes that should be included in the environmental/sustainability reports such as CBAM etc. CN codes are linked to the relevant part in the Part register.
Part register

#### To be able to manufacture sustainable products, all hazardous chemicals and contents in the product must be registered. By doing this, you get a better picture of how you should manage and care for the product throughout its entire life cycle.
If you have environmental/sustainability reporting requirements for different CN codes, you need to select the CN codes for the part.
- In the Table of contents box under the Sustainability tab, you select the Part contents (chemicals) that the part contains.
- The information in the Reporting requirements box is used in communication with the customer to disclose to them what the part contains. The information in the box can be e.g. used to attach documentation regarding part contents.
- Sustainability statistics

#### This procedure is used to follow up on sustainability data. In different list types, you can see the calculated actual CO2e emissions from manufacturing orders and from purchases.
The statistics are based on finished manufacturing orders and arrival reported purchase orders and correspond to a post-calculation or arrival log, but with a calculation of CO2e emissions.
Sustainability calculation

#### Once you have entered all of the above information, you can start the part contents calculation. The part contents calculation is based on information in the BOM and routing and Basic data – Sustainability procedures.
Select the parts you want and run the calculation.
- You can export the results to Excel for further processing and analysis.
- Part contents report

#### This report is used to report the part contents from the manufacturing. You can, for example, use the result if you are required to report the usage of certain chemicals at the end of the year. In the list you can also see which parts contain which substance/chemical. You can export the list to Excel for further processing and analysis.
You can use the report to pull data required according to [European Chemicals Agency (ECHA)](https://echa.europa.eu/regulations/reach/candidate-list-substances-in-articles/notification-of-substances-in-articles). To ensure that the report is correct, the parts’ weight and weight calculation are required.
To carry out the calculation, the Contents list in the Part register for the manufactured part must be updated with the correct contents.
