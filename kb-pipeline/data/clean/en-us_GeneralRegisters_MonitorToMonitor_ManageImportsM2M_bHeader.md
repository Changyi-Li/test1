### Header

#### Our order number
The matching purchase order number. If no matching purchase order number is found automatically when importing, you are able to manually select the matching order here. An error message is shown if no matching order is found.

#### Dispatch date
This is loaded from the import file. If no date is found in the file, the date will default to today’s date and a warning will be shown.

#### Delivery note number
The delivery note number from the import file. A warning is shown if this delivery note already exists for this supplier and delivery date.

#### Shipment number
The shipment number from the import file.

#### Link to goods tracking
The goods tracking link from the file. Use the Go to website button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_url.png) to the right of this field to track the goods.
