### Languages
- The direct link between language and document phrases is not used in G5. Instead you can to the language link a default document group. The document group can then be changed for different addresses, for example for mailing address and delivery address.
- That language decide the translations of data, for example the name of the part.
- It is possible to hide languages from translations which makes it easier to find the languages which you actually need to translate to. This can for example be done when no user, customer, or supplier, uses the language in question.
- It is possible to add own languages, but then you can only select among the languages existing in the LookupThe Lookup feature is a powerful search tool which allows you to search and load information from large registers. You open the Lookup feature by clicking on the dropdown button or by using F4 on your keyboard. feature (all acknowledged languages in the word).
