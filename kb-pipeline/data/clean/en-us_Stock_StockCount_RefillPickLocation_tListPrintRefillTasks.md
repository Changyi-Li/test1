### The Print refill tasks list
In this list you load and print a refill task with the parts which are included in the Reorder point list for pick locations.
In the list, you check the box in the Apply column for parts that should be included in the document Refill pick location. The document is created by using the button Generate ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_run.png) on the toolbar.
The document is then displayed under the Documents tab, where you can preview the document before printout. You also find [settings](bSettingsDocument.htm) under this tab for the document in question.
On the printed document, you manually enter the quantity that is moved from each buffer location to pick location.
