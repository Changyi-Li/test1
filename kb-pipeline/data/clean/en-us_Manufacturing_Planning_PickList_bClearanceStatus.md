### Clearance status
This box is shown in the list if you have selected the list type Split pick list. Here you see for which manufacturing orders you can create pick lists for the included/incorporated material. The list is grouped by Fully cleared, Partially cleared, and Not cleared.
On the function menu you find three buttons used to select all orders in one of the different grouping options. It is also possible to select individual orders using the checkbox called Select.

#### Select
With this checkbox you can mark individual orders for which to create pick lists. When one or multiple orders are marked, you will in the Material rows box see which materials will be included on the split pick lists.
You create the pick lists by saving in the procedure. Then they become available under the Document tab.
