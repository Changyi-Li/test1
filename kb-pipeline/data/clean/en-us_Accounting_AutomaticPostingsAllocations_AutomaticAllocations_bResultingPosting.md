### Resulting posting
In this box you define which allocations should take place when the terms in the box Initial posting have been fulfilled.

#### Account
Here you see/enter the account on which the allocation will be recorded. If you leave the field empty, the recording will be made on the same account as the initial posting. Otherwise you can enter the account which should apply for the row.

#### Dimensions
Each dimension is shown in a separate column. You enter dimensions if posting should take place on a specific dimension code. If the account on the row manages posting on dimensions, but dimension is left empty, then the dimension code will be inherited from the initial posting. For example, if you post on cost center 10 and this generates an automatic posting. If the generated posting row has an account handling a cost center, cost center 10 will be used on that row.

#### Percent
Here you can enter how many percent of the initial amount should be posted on the row in question. You can enter the percent with a maximum of 2 decimals.

#### VAT code
By clicking the More info button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) a window opens where you can enter a VAT code.
