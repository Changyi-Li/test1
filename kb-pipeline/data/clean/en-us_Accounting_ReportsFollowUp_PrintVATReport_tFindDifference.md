### Find difference
Under this tab you find the vouchers which are causing a difference between the output VAT and the turnover. The turnover amount is calculated based on the booked VAT. The calculated turnover is then compared with the recorded turnover. If a difference occurs, the size of the difference can help you decide whether or not it might be a book-keeping error that has to be corrected before the VAT is submitted. The "Find difference" is grouped by VAT control type. This check/control is similar to the one made under the VAT control tab, only the Find difference search is made for each voucher. The vouchers which are controlled are the ones containing accounts linked to the VAT report.
If the setting Basis for VAT report is loaded from has been set to VAT code in general ledger transactions, it means the system will check the VAT code on transaction level regarding turnover. If the VAT control does not correspond for these vouchers they are shown in this list. Under the Selection tab you can enter an allowance for error (the difference) which will be accepted. This way the vouchers with a difference smaller than the entered amount will not be shown in this list.
