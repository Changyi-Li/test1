### Optimization settings

#### Optimization level
Here you decide the amount of effort made by the SQL Anywhere query optimizer to find an access plan for an SQL statement. Allowed values are between 0 and 15. The default value here is 9.
> Please note! This value needs to be changed only in certain cases, and if so, it should be done in consultation with the Monitor Support Center. For additional information about the setting, please see [SQL Anywhere's documentation](https://infocenter.sybase.com/help/index.jsp?topic=/com.sybase.help.sqlanywhere.12.0.1/dbadmin/dboptions-s-5315547.html).
