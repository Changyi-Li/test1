## Authorize/Adjust recording
This procedure is used to review and adjust attendance and work recording made by the personnel. The procedure is also used to authorize attendance recording and thereby approve the recording items to be included for payroll.
> To be able to authorize and/or adjust recording items you must have the user rights to authorize and/or adjust attendance and/or work. You can have these basic user rights either via user-specific user rights, user rights group, or role. In addition to this the following applies:You can be Main signer, Secondary signer, or have the option Cannot authorize for one or more persons. Independently of this, you can also have or not have user rights to adjust and/or work. This is registered in the Personnel records – Time recording procedure.If you are System signer you will be secondary signer for all personnel and you are also allowed to adjust attendance and work recordings. System signers are registered in the System signer procedure.If you do not have any of the above rights/permissions, you can only authorize and/or adjust recording items for the personnel who do not have any settings for authorization or adjustment of attendance/work.
Under the Selection tab you choose the personnel to show. In the Settings box you can select to only show the employees for whom you are the main signer, select to also show blocked employees, and select authorization Interval.
In the left section under the List tab you see a list containing the personnel you have selected. Here you can mark persons and authorize their attendance recordings.
Under the Calendar tab you can see the recorded times for the person you have marked/selected in the list. Under the Adjust attendance tab you can authorize and adjust attendance recordings per day. Under the Adjust work tab you can adjust work recordings per day.
Selection rows
In a list procedure there is always a tab called Selection where you can select data records in different intervals from the database. The data records are then loaded by using the Load button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_display_list.png) in the toolbar of the procedure.
Under Selection rows in the backstage of the procedure, you can choose which selection rows that each list type should have, under the Selection tab in the procedure. In the List type field you select for which list type you want to customize the selection rows.
One table shows selection rows possible to select and one one table shows the selected selection rows. You can add, delete, or move selection rows by dragging and dropping the selection rows with your mouse pointer.
Using the Save button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_save.png) you save the selected selection rows.
Read more about this in the [Selection](../../../UserGuide/GeneralFeatures/Selection.htm) topic.
