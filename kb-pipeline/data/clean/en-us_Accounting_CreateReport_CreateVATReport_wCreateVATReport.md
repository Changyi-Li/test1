## Create VAT report
In this procedure you can create custom (own) VAT reports and configure how the reports should be designed.
A few standard VAT reports are included in the system. These are adapted for different countries. You can use these as basis if you want to create you own VAT reports. To create your own customized VAT report from an existing report you use the Save as button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_save_as.png) (Ctrl + Shift + S) on the toolbar of the procedure.
You decide which different VAT rows and totals that should be included and also how the layout should be designed in your own VAT report. This is done under the VAT report – Construction tab. Under the VAT control tab you configure a control function between the output VAT and the turnover.
The VAT report is constructed of different VAT rows. The rows indicate which field in the report they refer to.
The report you have created can be printed in the procedure Print VAT report. It provides you with a basis for reporting VAT to your tax authority.
