### Intrastat export
- The country of the delivery determines the reporting instead of the country entered for the customer.
- Handling of different transaction types and how to determine this.
- It is possible to decide which value should be reported per order type in the IntrastatIntrastat is the system which gathers statistics relating to trade in products within the European Union. Gathering of Intrastat statistics is handled in the same way by all EU member states. report.
- There is support for handling of wage processing (subcontract in EU country).
- You can decide in which unit to report the goods number.
- The Intrastat reports can be selected by date instead of by period.
- There is a drilldown function in the Intrastat reports you can use to see which records are behind the reported goods records.
- It is possible to make adjustments/additions in the Intrastat reports. These are saved and can be seen if you again load/print the list.
