### The Warnings tab
This tab is available for the list type Reconciliation/day. If there are any warnings you will here see a list containing information about the cause of the warning as well as a link ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) to the procedure in which you can perform the necessary actions.
| Warning | Action |
|---|---|
| There are customer invoice journals left to record. | Use the link ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) to go to the procedure Print customer invoice journal and print the journal. |
| There are cancellation journals left to record. | Use the link ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) to go to the procedure Print customer invoice journal and print the cancellation journal. |
| There are incoming payment journals left to record. | Use the link ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) to go to the procedure Print incoming payment journal and print the journal. |
| There are set-off journals left to record. | Use the link ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) to go to the procedure Print incoming payment journal and print the journal. |
| There are preliminary vouchers left to record. | Use the link ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) to go to the procedure Voucher list and record the journal. |
