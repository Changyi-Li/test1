### Groups
The Groups tab is available if you have installed the option Machine integration. You can use groups to group indirect codes according to own criteria. The purpose of groups is to make it easier for operator during machine recording to select the correct code in cases where many codes for indirect work are registered. You select a group for an indirect code.

#### Code
Here you enter the code for the group. It can consist of a maximum of 10 characters.

#### Name
Here you see/enter the name of the parameter group. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.
