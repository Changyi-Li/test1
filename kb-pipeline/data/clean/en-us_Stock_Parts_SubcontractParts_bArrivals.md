### Arrivals

#### Receiving inspection
With this setting you determine if a receiving inspection should be made when subcontract purchase orders are arrival reported.

#### From
Here you see the date from when the receiving inspection should start to take place.

#### Instruction
Here you can enter an instruction and link files regarding the receiving inspection. By clicking the Files button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_file_link.png), it is possible to link different files related to a comment or an instruction for the record in question. When the setting Automatic printout is available for activation, you can choose to get the linked file automatically printed. Read more in the topic [General features](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LinkFiles) about how to link files, automatic printout, and where linked files can be automatically printed. If there are linked files, you will see this symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_file_linked.png) on the button.

#### Arrival log
By clicking this button you will see the arrival log. There you can for example see the part's arrival date, order number, quantity, and if an inspection has been performed.
