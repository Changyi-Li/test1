### New client – New user interface
G5 is a completely new client compared to G4. The user interface is designed around a desktop where you find the module menu and [desktop components](../../../GeneralFeatures/DesktopComponents.htm). The desktop is the surface in which the procedure windows will open and then you can move them around. It is also possible to move the procedure windows to other computer screens, if you are using multiple screens.
The user can choose/switch between three different themes: gray, blue, and white.
