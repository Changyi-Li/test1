### Calls
In this box you see information about each call in the delivery schedule. If the calls have been imported, you see a green checkmark ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/StatusFinished.png) in the status column. You see the calls' delivery date and quantity from the import file. The date and time of the most recent run is displayed. By using the button More info ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you also find information about cause code, type of behavior, as well as earliest and latest delivery date.
You can unpin the box and use it as a floating window. This is done by using the button Floating ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_float_window.png) (Ctrl + U). This way the table will be larger and you get a better overview of the calls.
