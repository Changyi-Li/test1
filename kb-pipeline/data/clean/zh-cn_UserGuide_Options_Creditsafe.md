# 与 Creditsafe集成
与 Creditsafe选项的集成将自动更新您的客户 Monitor ERP 提供有关其贷项评级的信息。
与 Creditsafe集成是一个程序，旨在自动从 Creditsafe载入有关贷项评级的信息，并为已选择的客户更新此信息 Monitor ERP。这样，你可以减少维护客户登记所需的一些手工劳动。通过与 Creditsafe 的集成，你可以获得以下信息 Monitor ERP 已更新：
- 信用额度
- 客户名称
- 客户的邮寄地址
- 冻结 / 通知
- 贷项评级（已保存在客户登记的附加字段中）

#### 集成是如何工作的？
你创建了需要已更新贷项信息的客户选择。可以通过使用客户组和/或国家 / 地区来选择客户。你还可以配置排除员工和私人企业、合伙企业或有限的合伙公司。你还应该配置信息的加载频率。
[![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/Options/Creditsafe.png)](../../../Resources/Images/Options/Creditsafe.png)

#### 集成的好处
- A 信用额度 它会基于客户的财务状况总是已更新。
- 客户' 名称 和 邮寄地址 都会自动保持已更新。
- 冻结 / 通知 在订单登记中，由Creditsafe 提供的信息决定。
- 贷项评级 已保存在客户登记的附加字段下。

#### 使用集成你满足的条件
- 这 与 Creditsafe集成 选项 Monitor ERP。
- 这 获取数据 与 Creditsafe 合作的服务。
