### FAQ – Undo deliveries
How do I undo the delivery of a customer order that has been invoiced?
Unfortunately it is not possible to undo a delivery for a customer order that has the “Final delivery made” status which has been invoiced. To correct this, you first need to credit the invoice and ensure that the crediting is reflected in the stock balance. If there is a remaining amount left on an order, this can be canceled using the Report delivery procedure. If necessary, you can now create a new customer order.
> You can use Save as to create a new customer order.
Go to the Register invoices directly procedure, select your customer, check the Credit box, and then select the invoice that should be credited.
![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/FAQ/FAQ_UndoDelivery1.png)
You will then see a dialog where you can select which rows should be included in the credit.
![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/FAQ/FAQ_UndoDelivery2.png)
If you would like to return the goods to the stockroom, you should check the Affect balance box (see the image below). If you do not want the stock to be affected, it is important that you uncheck Affect balance. Even parts included in fictitious parts must be unchecked.
![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/FAQ/FAQ_UndoDelivery3.png)
Once you have done this, click Save, and check that the document looks right. Then you can approve the credit with the Approve invoice button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_approve_document.png).
![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/FAQ/FAQ_UndoDelivery5.png)
You need to then delete the order using the Report delivery procedure. Enter the order number under the Selection tab.
![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/FAQ/FAQ_UndoDelivery4.png)
Enter 0.00 in the Quantity to deliver column, check the Delete remaining box, and then click Save.
![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/FAQ/FAQ_UndoDelivery5.png)
You can now create a new customer order for what is going to be delivered to the customer.
