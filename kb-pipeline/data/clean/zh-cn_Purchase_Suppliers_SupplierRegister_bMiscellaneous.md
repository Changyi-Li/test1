### 其它的
在此框中你输入其它信息并根据以下内容为供应商配置不同的设置。

#### 企业 ID 号
在输入你商的企业 ID 号。如果输入的编号已被其他供应商使用由，则会显示一条消息。

#### 我方客户号
在这里你输入我们在供应商已登记的自己的客户号。这显示在已发送给供应商的文档中。

#### VAT 登记号
你可以在此处输入供应商的VAT 登记号。
如果输入的编号已被其他供应商使用由，则会显示一条消息。
点击 VIES 验证 按钮 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_validate.png) 你可以根据VIES（VAT信息交换系统）检查VAT 登记号是否有效。VIES 是一种电子方式，用于验证在欧盟已登记的经济操作员在边界进行商品或服务事务时的VAT登记号码。这样你就可以知道该编号或不有效。根据国家数据保护规则，一些国家 / 地区还会提供与给定VAT编号链接至的名称和地址，因为它们已记录在国家数据库中。系统还日志所进行的检查/校验以及返回的结果。
如果VAT编号显示为无效的，你应第一个与相关公司检查，以确保该编号正确（字符数正确、长度正确和国家 / 地区前缀正确）。如果之后检查后，该编号仍然是“无效的”，你应该要求该公司联系人其税机关，请求已更新国家VAT信息交换系统(VIES) 中的数据（仅国家税机关可以更新VIES 数据）。
如果您自己的公司信息错误的日期，你应该联系人您的税机关并要求他们更正信息。保持记住，一些成员/北爱尔兰要求此类更新请求必须以书面形式或通过网络表格提出。
一些成员/北爱尔兰要求对欧盟内部（和北爱尔兰）的商品和服务事务进行单独的VAT登记，并且仅在其国家数据库中记录此类VAT号码。因此，VAT编号即使正确，也有可能不通过 VIES 验证，因为该VAT编号的所有者不参与欧盟内部事务（和北爱尔兰）不登记此类销售。
阅读更多 [欧盟](https://ec.europa.eu/taxation_customs/vies/#/faq)

#### EORI 号
在输入你的EORI 号（经济操作员登记和识别号）。你可以使用EORI 号来处理欧盟境内全部与海关相关的业务。您可以根据欧盟佣金可用的数据库来验证您输入的EORI 号。点击 EORI 号无效 按钮 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_more_info.png) 然后 验证 EORI 按钮 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_validate.png)。在你验证了EORI 号后，有关该公司的信息将加载到窗口中，你可以查看EORI 号或不有效。按钮 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_more_info.png) 将更已变更 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/StatusFinished.png) 如果EORI 号有效。无论EORI 号或不有效，你都可以在按钮的工具提示中看到该编号最近的验证时间及验证者。
[![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/SubProjects/EORI_validation_valid.png)](../../../../Resources/Images/SubProjects/EORI_validation_valid.png) [![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/SubProjects/EORI_validation_invalid.png)](../../../../Resources/Images/SubProjects/EORI_validation_invalid.png)

#### 发票供应商号
如果你想要在到货报告之后在发票底单上已打印另一个供应商号，你应该在此字段中输入。发票供应商号用于当采购订单已已发送至一公司但由另一家公司已开票（例如来自中央仓储等）的情况。

#### 订单确认单宽限天数
你可以在此处输入向供应商已发送提醒以告知你不已收到订单确认单之前应经过的天数。此设置应用至所有打印日期已超过输入的工作日编号或更多的所有订单。

#### 交货宽限期
你可以在此处输入之前供应商已发送提醒以告知你不已收到交货的天数。宽限天数总是计入工作日。

#### 审核人
在这里你输入谁是审核人。然后，该员工将自动成为该供应商的供应商发票的审核人。

#### 审核人代码
如果你已经已激活了EIM选项，你将看到此字段，而不是上面提到的字段。你可在此输入员工或已审核审核人员工列表的代码。这将默认使用由相关供应商的供应商发票。

#### 其它发票设置
电子发票地址 (EIA)
你可以输入 电子发票地址 (EIA) 对于发送电子发票的供应商。导入供应商发票时可以使用此地址来查询正确的供应商。你还可以使用供应商的企业 ID 号或VAT 登记号在导入时查询正确的供应商。
已链接电子发票
（应用至科目 CrossState 电子发票 并通过 Crediflow导入电子发票）。在这里你可以看到您的供应商是否已连接到电子发票，这意味着供应商可以向你发送电子发票。如果供应商不连接，你可以向供应商发送邀请。你通过点击以下按钮发送邀请： 发送电子发票邀请![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_more_info.png)。然后会打开一个窗口，你可以在其中看到从 Crediflow登记中加载的有关您的供应商的信息。如果一切正常，发送点击 发送邀请 按钮。要检查已已发送邀请的状态，请点击 检查邀请状态 按钮 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_more_info.png) 再次。
> 为了能够发送邀请，系统需要在电子发票登记中查询您的供应商。因此，为你的供应商输入正确的信息（如企业 ID 号、VAT 登记号和国家 / 地区代码）非常重要。如果可以使用企业 ID 号和国家 / 地区代码的组合进行搜索，则供应商最有可能在登记中被找到。
不创建发票底单
仅当你选中了系统设置的任何备选时，此设置仅可视的 在到货时创建发票底单。如果复选框被已激活，就不将订单与供应商的供应商发票链接。

#### 零散供应商
零散供应商是用于从不同的实际的供应商进行一次性采购的供应商号。这些供应商不在供应商登记中已登记。对于标记为离群供应商的供应商，你需要填写订单上的全部字段。如果有针对该供应商号的提醒，则将每订单进行划分，并且当未选择此设置时，它们将不聚集在一提醒中。这样，你就可以区分不同实际的供应商的提醒打印。

#### 日历
你可以在此处将日历链接到供应商。默认日历一在 公司信息 程序。你登记在 日历 程序。日历决定哪些天数工作关天数和假期。
如果在询价行、采购订单行和采购建议中已选择的交货日期是相关日历中的假期或关日，你将在受影响的程序中看到警告。请注意！CDT 会考虑供应工作的关天数。
如果 默认订单行交货日期 系统设置设为 今天 + 交期 这意味着为采购订单行已计算的交货日期从不不会被设置至一日历的工作或关天数之一。例如，检查交货时间的计算、净需求的计算以及创建自工单创建的采购订单。

#### 日历例外
你可以在此处添加选定的日历的例外或附加日期间隔，这些日期间隔将专门应用于相关的供应商。这些是供应商已关闭营业的日期数，例如假期期间。
打印
在打印按钮下方 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_more_info.png) 你可以为供应商配置不同的设置打印中订单和其它文档。

#### 打印订单 / 询价由
通过此设置，你可以确定是否使用打印机或通过Email打印采购订单和询价。你在此处选择的方式将成为向相关供应商采购订单和询价的默认选项。

#### 打印对账单自
通过此设置，你可以确定是否使用打印机或通过Email打印对账单。此处已选择的方式将成为向相关供应商声明的默认。

#### 打印交货单 / 运输标签由
通过此设置，你可以确定是否应使用打印机或通过Email打印交货单（用于外协）和运输标签。你在此处选择的方式将成为相关供应商的交货单和运输标签的默认选项。
