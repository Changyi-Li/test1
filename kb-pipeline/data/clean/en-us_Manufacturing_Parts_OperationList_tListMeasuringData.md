### The Measuring data list
This list type displays settings regarding measuring data linked to the work center on operations in BOM and routing.
You can edit the part's measuring template and measuring form. If the frequency of the measuring template is set to Sample, you can also update the quantity and interval. If the frequency of the measuring template is set to Other, you can update the frequency text.
It is also possible to select a work center which should use a setting for measuring data. If that field is empty it means that this this setting for measuring data is always applied. If a work center is selected it means that measuring data is only reported by this specific work center.
