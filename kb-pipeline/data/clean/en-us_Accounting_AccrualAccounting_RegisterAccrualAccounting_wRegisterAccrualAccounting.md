## Register accruals
You use this procedure to show existing accruals and manually register accruals. The procedure handles data for accruals and links to vouchers, invoices, as well as invoice which have been released from customer agreements. There is a specific type of accrual called Customer agreement. This type will be assigned automatically when you have checked that the customer agreement should be accrued. Please note! You cannot manually register an accrual of this specific type.
The voucher text used when releasing is the Agreement number plus the customer name.
Accruals are used when you wish to distribute the recording of a total amount over a number of months. In normal cases accruals are created from other procedures in the system, for example from Register supplier invoice or Register vouchers. But accrual accounting can also be created directly in this procedure, and you can still link it to e.g. a supplier invoice or a voucher. The monthly amounts, which should be recorded for accruals, are released in the procedure Release accruals.
The accrual accounting function can also be used to reverse a voucher in a future accounting period, for example a closing record voucher which should be reversed next year. There is no period allocation for such an accrual, instead there is a fixed date when the entire posting of the voucher in question is reversed as total.
> In the Register vouchers procedure you can use Save as for a voucher which should be reversed and then select Reverse via accrual accounting and also enter when it should be reversed. The recording of the reversal takes place when releasing the month in question.
It is also possible to delete accruals that have not been released. They will then be completely deleted from the database. If the release of an accrual has been started, but you try to delete it, the accrual will instead be canceled and not deleted. You must also enter a comment for the cancellation. The system will not perform any automatic adjustments for the releases already made at the time when you cancel an accrual. Such adjustments has to be done manually, if needed. Canceled accruals are filtered out (not shown) in the Release accruals and Change period/accounting year procedures. However, in the Accrual list procedure you can select to show canceled accruals.
