### 组件同步期间的限制
发送公司和接收公司在中间的组件同步具有某些限制，值得注意。这些限制在此处描述。

#### 什么类型的数据可以已同步？
在里面 要同步的字段 在程序的同步框中，你查询可已同步现有的组件和/或在同步在接收公司中已创建的新的组件的数据列表。该组件的其它数据不已同步。

#### 删除组件
如果你在发送公司中删除某个组件，则接收公司中的该组件不被已删除。

#### 重命名组件
如果你在发送公司为该组件赋予了一个新组件号，则接收公司将会已创建一个具有新编号的新组件。这意味着接收公司中旧的组件号和新组件号两者存在。
如果接收公司然后使用旧的组件号创建客户订单，则会出现一条警告，通知你发送公司（组件已重命名的地方）组件缺失。然后你必须人工的变更为订单上的新组件号。

#### 姓名翻译
- 如果两者公司使用相同的公司语言，组件名称将与接收公司的语言已同步。
- 如果公司语言不同，则发送公司公司语言的部件翻译名称将已同步到接收公司。
-    
若不否翻译，则将已同步发送公司公司语言的组件名称。请参阅低于表格。

| 名称（SV） | 普拉特伯克 |   | 名称（EN） | 锡 |
| 名称（EN） | 锡 |   |   |   |

#### 组件状态
如果选择已由 状态，五月会发生以下情况：
1. 全部状态为 3 的组件都将从发送公司已同步到接收公司。
2. 然后，发送公司中 A组件的状态已变更为 4。
3. 对状态为 3 的全部组件进行新建的同步。
4. 接收公司的 A组件仍为状态3。这是因为 A组件在发送公司中已被赋予状态4。此组件然后不被用于在已同步的组件选择中。
