### The Addresses list
In this list you can update different addresses for the suppliers. For both delivery address and mailing address you can enter four address rows and zip code, city, region, and country. The information corresponds to the information registered in the Contact information tab in the Supplier register procedure.
It is possible to update mailing addresses and delivery addresses directly in the list. To be able to edit the visiting addresses, you must first check the setting Use separate address for the address in question in the supplier register.
