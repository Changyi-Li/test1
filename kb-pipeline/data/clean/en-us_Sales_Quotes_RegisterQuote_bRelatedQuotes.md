### Related quotes
In this box you can create a new quote "related" to the quote in question. For example, if you wish to revise the quote or send a copy of it to another customer.
A related quote is linked to the primary quote from which it was created. If this link between the quote and the related quote is not necessary, you can use the regular Save as function on the toolbar of the procedure.

#### Create related quote
When you click the Create related quote button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_new.png) you will see a dialog box where you can enter a new quote number or leave the field empty in order to load the next available quote number from the number series. You can choose order type. The header and rows are copied to the new quote by default.
You can also choose if you wish to load current prices to the new quote. Then prices are loaded from default customer links on the parts on the quote rows. Otherwise the prices will be loaded from the rows on the current quote.
You can also set the related quote as primary by default. It is also possible to afterwards select in the box which quote should be the primary one.
By clicking OK in the dialog box, the new related quote will be opened in a new procedure window.
Related and primary quote is also shown in the table in the box. Here you can use ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) link to open these and you can also preview ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_preview.png) what they will look like at printout.
In the Quote list procedure, the primary quotes are shown by default. Normally, the primary quote is the quote that most likely will be turned into an order. But you can there uncheck the alternative to only include primary quotes.

#### Relate existing quote
When you click the Relate existing quote button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_test_call.png) you will see a dialog where you get to select an existing quote number (regardless of status and customer) to which this quote should become linked. You can also choose which quote to use as the Primary quote.
Check the Open related quote checkbox if you wish to open a new window showing the related quote.
By using the Disconnect related quote button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_broken_link.png) you can disconnect the related quotes. This button is only active if there are any related quotes.
