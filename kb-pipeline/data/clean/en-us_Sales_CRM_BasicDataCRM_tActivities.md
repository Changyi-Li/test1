### Activities
The Activities tab is used to define customer activities that will be selectable when registering activities for customers, quotes, or customer orders.
When you start the system for the first time, there are some examples of activities already registered in the program. You can modify the name of these, if needed. A total list of possible CRM activities will be created containing all the activities that you add here, and those already included in the system.

#### Activity types
Here you decide the activity type/types where this activity should be possible to select. The types under the Activity templates tab can be selected.
