### Settings
These settings are available for the list types Detailed and Total.

#### Include
This setting determines the status which the order must have to be included in the list.

#### Show foreign currency
With this checkbox you determine if a total per currency code should be displayed at the bottom of the list. The total applies to all order rows in the list that have another currency than the company currency.

#### Only show records which can be released
With this setting you decide if only the partial invoices which can be released (create invoice bases) should be shown.

#### Pre-select for release
If you activate this setting it means that the checkbox Release (create invoice basis) will be checked by default in the list.
