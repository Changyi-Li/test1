### Customer order

#### Register customer order
Register a new customer order or modify an existing order. The order receives status 1 (Registered).
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/TrainingMaterial/CustomerOrderFlow2.png)](../../../../../Resources/Images/TrainingMaterial/CustomerOrderFlow2.png)

#### Print customer order
Print order confirmation using a printer or send it by e-mail. The order receives status 2 (Printed) when you print it. Printouts can be done directly from the procedure Register customer order or in the Print customer order procedure.

#### Order list – Sales
Monitor your customer orders per customer, delivery period, etc.
