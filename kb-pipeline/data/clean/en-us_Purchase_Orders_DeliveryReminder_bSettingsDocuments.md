### Settings – Documents

#### Document variant – Linked suppliers
If you want to print another document variant than the default variant for the linked suppliers, you can select it here. The document variants are handled in the Document templates procedure.

#### Document – Stray suppliers
If you want to print another document variant than the default variant for the stray suppliers, you can select it here. The document variants are handled in the Document templates procedure.

#### Default supplier linked document variants
In the Supplier register procedure you can for each supplier configure default supplier linked document variants. This is done in the box [XML/Documents](../../Suppliers/SupplierRegister/bXMLDocuments.htm) (the button Supplier-specific documents). If you uncheck this setting or if the supplier on the row does not have a default document variant, then it is the document variant above that will apply.

#### Linked files
This checkbox determines if files linked to the reminder (set to be printed automatically) also will be included in the printout.
