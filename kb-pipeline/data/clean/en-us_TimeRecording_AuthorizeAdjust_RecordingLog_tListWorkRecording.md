### The Work recording list
In this list you see work recording items made by personnel and machines. Only in this list is it possible to see machine recording items.
The list is grouped by employee number and shows the work recording items' date, in/out times (start/stop), type of work recording (unit time, setup time, indirect work), recorded time, order number, part number, operation/activity, reported quantity, rejected quantity, rejection code, code for indirect work and is name, report number, distribution in percent, and comment for the recording, if any. Under the More info button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you by default find columns for schedule number, part name, the department of the employee, rejection name, comment for the rejection, and kommentar till kassation samt signing employee number (of the operator who performed the recording).
