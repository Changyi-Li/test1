## Register vouchers
You use this procedure to create vouchers and load existing vouchers in the current accounting. The loading of existing vouchers apply both to manual vouchers and vouchers created automatically via integration. Depending on the status of an existing voucher it is also possible to modify it.
See more: [Create a voucher](CreateVoucher.htm).
> You can save a document to your voucher, for example, a receipt. [Read more about it here](SaveDocumentToVoucher.htm).
You are not able to cancel vouchers, however to correct them you are able to create rectification and reversal vouchers from previously registered vouchers. You can also copy vouchers and accrual account a voucher (a reversal voucher in the subsequent period/year). This is done using the function Save as on the toolbar of the procedure where you can select a new type of record.
See more:
[Making changes in a voucher](Make changes in a voucher.htm)
[Create a rectification voucher](CreateRectificationVoucher.htm)
[Reverse voucher via accrual accounting](ReverseViaAccrualAccounting.htm)
[Automatic posting of VAT](AutomaticPostingVAT.htm)
Vouchers created via integration that have the Preliminary checkbox activated, are also possible to load, modify, or record.
