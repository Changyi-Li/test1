### Print delivery documents
- This procedures Print Delivery Note (Delivered), Print Transport Labels, and Comprehensive Delivery Note have been merged into this new procedure.
- The transport label has a new layout and can also be printed in the shape of a label.
- On the transport labels a 2D bar code is always shown, containing information about the customer’s order number, part number, and quantity. In G4 it is only possible to print the transport label with 2D bar code on A4 as a separate document.
- The comprehensive delivery note collects all customer orders to the same customer which are on the same pick list. In order for them to end up on the comprehensive delivery note, it is requires that all the customer orders have the same delivery address and delivery method. In G4 it is also required that the invoice basis has the same currency. This is not the case in G5.
- The document Product description including certificate can also be printed here.
