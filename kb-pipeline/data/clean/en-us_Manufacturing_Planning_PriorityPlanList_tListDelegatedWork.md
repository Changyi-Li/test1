### The list Delegated work
The list is loaded and displayed based on the selection and settings you have chosen. As in all lists in Monitor ERP, you can drag and drop in order to change the column to group by.
In the list type Delegated work you see which operations that are delegated and locked. They are displayed grouped per employee. For the most part, the list contains the same columns as the [priority plan](../PriorityPlanning/bPriorityPlan.htm) in the Priority planning procedure.
You can enter a Priority and a Manual operation status in the list, if you first have made the list possible to update by using the Updateable button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_edit_list.png) (Ctrl + U) on the tool bar of the procedure.
