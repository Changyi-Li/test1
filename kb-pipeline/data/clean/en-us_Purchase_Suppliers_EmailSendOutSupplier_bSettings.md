### Settings

#### Recipient type
You can choose to include all e-mail addresses from the References box and/or the Communication box in the Supplier register.

#### Recipient of
With this setting you can decide to only include the e-mail addresses which are registered as recipient of a specific or multiple options. This will be added to the Communication box in the supplier register.

#### Show
Here you decide if you want to show Suppliers with e-mail address and/or Suppliers without e-mail address. The setting Suppliers with e-mail address is selected by default.

#### Pre-select "Include"
With this setting you decide if all e-mail addresses should be checked in the Include column in the list. This setting is activated by default.

#### Logging in SRM
With this setting you determine if a log record should be created in the section Log of activities/E-mails under the SRM tab in the Supplier register. This setting is activated by default.

#### Bcc
Here you decide if all e-mail addresses should be entered as Bcc (blind carbon copy) in the e-mail. The purpose of this is to make it impossible for the recipients to see to which other e-mail addresses that the same e-mail has been sent. This setting is activated by default.
