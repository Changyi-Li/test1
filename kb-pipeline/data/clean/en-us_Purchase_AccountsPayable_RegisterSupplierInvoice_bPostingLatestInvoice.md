### Posting
In this box you see the posting of the last invoice selected in the box Supplier's most recent invoices. If the invoice is final recorded the postings are displayed, but if the invoice has been sent for authorization to several persons the pre-posting is displayed instead. The postings are only displayed and it is not possible to make any changes. It is possible to copy certain posting rows from previous invoices to the invoice you are registering/authorizing/final recording. You cannot copy rows for supplier debt postings, VAT, or other postings generated by the system. You can only copy postings that are manually registered by the user.
If you check the Include column for rows, the copy button will become active.. When you click it, you will be moved to the first tab and the posting rows will be added at the bottom of the posting box. You have to manually enter the amounts of the rows if the value left to post is not the same as the value of the copied rows.
