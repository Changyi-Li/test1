### The Lead time chart tab
The lead time chart displays the order structure graphically in a "Gantt chart" containing manufacturing orders, parts, and operations as blocks on a time axis. Each order, part, and operation, has its own row. To the far left you will on each row find information regarding manufacturing order, part and operation.
If you hover the cursor over the block for a specific order, a tooltip will show the planned start date, planned finish date, planned and reported quantity, and remaining quantity.
If you hover the cursor over the block for a specific part, a tooltip will show the same information as for an order.
If you hover the cursor over the block for a specific operation, a tooltip will show the work center, planned start date, planned finish date, planned and reported total time, and report number.
In addition to manufacturing orders, parts, and operations, you will also see the delivery date of the customer order row, provided that the order is of type Customer order oriented.
Blocks for manufacturing orders are green, blocks for customer orders are brown, blocks for parts are blue, and blocks for operations are red.
A percentage shown on the blocks and a darker color shows how much that has been final reported.
Using the navigation buttons ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_goto_left_leadtime_chart.png) ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_goto_right_leadtime_chart.png) on the rows, you can in a quick and easy way go to the block for an order, part or operation which is outside the visual section of the time axis.
It is possible to replan the start date and finish date. You can visually replan and move the or operation along the time axis by dragging and dropping the block for an order or an operations, and then you save. It is also possible to extend or shorten the time of an order or an operation by clicking and getting a hold of one end of the block (the start or the finish time) and drag it with the pointer.
> For it to be possible to replan in the lead time chart you must load the list as Updateable, which is only possible for the detailed list.
By activating the Replan the entire order button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_replan_order.png) on the function menu, the entire manufacturing order will be replanned when you replan one of the operations.
By using the Go to procedure button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) on the function menu, you can go to related procedures for the marked operation.

#### Scale
Here you select which time scale to use on the time axis: Day, Week, Month, or Quarter. The lead time chart saves the most recently used scale for the next time you open the procedure.

#### Show
Here you decide if Manufacturing orders, Parts, and/or Operations, should be displayed. All options are checked by default to be shown.
