### Include

#### Only primary quotes
With this setting you determine whether or not to only include primary quotes in the list. If you uncheck this setting, related quotes will also be included. This setting is available for the lists Detailed and Total.

#### Only main rows
This setting determines if only main rows should be included in the list. If you uncheck this setting, sub-rows will also be included, e.g. linked text rows and sub-parts for fictitious parts.

#### Show alloy cost
With this setting you decide whether or not rows with alloy costs should be displayed in the list.

#### Rows set as excluded
With this setting you decide if quote rows with the setting Exclude from statistics activated, should be included or not in the list.

#### Rows turned into customer orders
With this setting you determine if quote rows already turned into customer orders, should be included in the list.
