### Default values
In this box you enter default values for phases/activities and costs for the selected template.

#### Phases/Activities
Under this tab you add default phases and activities in the template. First you add a row for phase and then one or multiple sub-rows for activities in the phase. An activity always belongs to a phase. A phase must always contain at least one activity.
You can select a user responsible for phases and for activities. For an activity you can also add comments, link files, enter planned time, queue time, and select a default status. You can decide if the activity should be printed/shown on documents. You can also create reminders and decide if the activity should be mandatory. You can mark if the activity should be charged.
Settings regarding planned time and charging of activity are loaded from the main tab called Activities.

#### Costs
Under this tab you can add default costs in the template. You add one row for each cost. For each cost you can enter an amount in the company currency and mark if the cost should be charged.
Settings regarding cost and charging of costs are loaded from the main tab called Costs.
