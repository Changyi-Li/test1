### External companies
Under this tab you can add external companies from Business Intelligence in Monitor G4 systems. Information from these companies is loaded from data files instead of being extracted directly from the databases.

#### Name
Here you enter the name of the external company, as it should be displayed.

#### Company key
This is a unique ID that identifies the company. The ID is generated automatically.

#### Format
Here you select format of the data file:
- Monitor G4 (preceding generation) – Data is loaded from a company in BI in a Monitor G4 system. This is the only available option at present.

#### Path
Here you see/enter the path to the folder where data files are saved when data is exported from BI in the Monitor G4 system. By using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_browse.png) you can browse to the folder on the computer or a computer in the network.
> Please note! If the file path leads to a shared folder on a computer on the network, then you should enter the UNC path to the folder, for example, \\computername\shared_folder.

#### File key
Here you enter the same file key as should already have been entered in the setting for the company in the BI in the Monitor G4 system, from where the data is exported. [Read more about the settings in the online help for Business Intelligence in G4](https://help.monitor.se/EN/MONITOR_BI/9_0/#UserGuide/Using/ExportImportCompany.htm).
