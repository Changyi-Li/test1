### Settings

#### Period
Here you select for which date interval you wish to see the price development. The default interval is January 1 to December 31 for the previous year. It is recommended to select an interval which spans an entire year (365 days) to get the best overview.

#### Include categories
Here you select which price categories should be included. The default options are Purchase, Sales, and User-defined (calculated prices such as e.g. Standard price).

#### Price alternative
Here you select the price alternatives for which you wish to see the price development. You can select from the price alternatives in the price categories you have chosen to include.

#### Alternatives
Here you can activate Only default supplier. If a part has multiple supplier links, only the supplier price from the default supplier link will be included. Parts without supplier links are not affected.

#### Chart interval
Here you decide in which interval the chart should be displayed. You can select from Day, Week, Month, Quarter, and Year.
