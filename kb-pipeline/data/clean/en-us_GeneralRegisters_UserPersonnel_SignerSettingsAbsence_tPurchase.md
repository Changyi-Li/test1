### The Purchase tab
Signer/approver info

#### Signer code
Here you see the signer code of the signer/approver.

#### Active
Here you decide if the signer is active or not.
Substitute

#### Substitute signer
Here you select the signer who should replace the regular signer. You can only select among the users who already are signers.

#### Substitute signer group
If you use signer groups you can select the signer groups which should replace the regular signer.
Reminder

#### Notification for purchase order
Here you determine if notifications for different tasks should be sent to the user selected in the box Users. The available options are For approval, To adjust, and To print.
The notification appears in the bottom right corner of the program window when there are tasks to perform. You can see and perform the task under the Purchase order tab in the Tasks window, under the Message center button on the title bar in Monitor ERP.

#### Show purchase order approval dialog
Here you determine if a message should be displayed when a user saves a purchase order whose value exceeds the user's purchase limit.

#### Send reminder via e-mail
Check this box if you also want to send the reminder via e-mail to the signer. The signer's language setting determines the language in the e-mail message.

#### After number of days
Here you enter how many days are allowed to go by until a reminder should be sent via e-mail.

#### Remind
Here you decide for which events a reminder should be sent. The following events can be chosen:
-   
For approval
-   
To adjust
-   
To print
