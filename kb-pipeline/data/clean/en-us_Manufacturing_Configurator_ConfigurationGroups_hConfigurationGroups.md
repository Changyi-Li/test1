### Header row

#### Configuration group
Here you enter the code of the configuration group. It can consist of a maximum of 20 characters. If you enter a code which has previously not been used, then you can create a new configuration group. If you select an existing code, an already registered configuration group will be loaded.

#### Name
Here you enter the name of the configuration group with a maximum of 80 characters. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Comment
Here you can write and see comments for the configuration group. The comment is shown in the guide during order registration and can then be of help.

#### Files
Here you can link files and see files linked to the configuration group.

#### Linked parts
Here you see the parts which use the configuration group.
