### Time banks
In this box you see the available time banks. Available time banks are the time banks linked to an overtime type or absence code in the procedure Basic dataWith "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Attendance.

#### Minimum limit
Here you enter the minimum number of hours allowed for the time bank in question. It is possible to enter a negative value. If the employee's balance in the time bank is less then what is set as the minimum limit, the employee will not be able to record absence using any of the absence codes which apply for the time bank. These absence codes are configured under the Absence codes tab in the procedure Basic data – Attendance.

#### Salary type for increasing balance
Here you enter/see the salary type which should be used for balances increases in the time bank, for transfer to the payroll program.

#### Maximum limit
Here you enter the maximum number of hours allowed for the time bank in question.

#### Salary type for decreasing balance
Here you enter/see the salary type which should be used for balances decreases in the time bank, for transfer to the payroll program.

#### Absence code
When performing change of period, this absence code will be used instead of withdrawing additional time from the time bank if the balance on the time bank is less than what is allowed. Normally, you will here select an absence code which results in a salary deduction. It is not possible to select an absence code which affects the balance in the time bank, for example in the time bank for flex time you cannot choose an absence code for withdrawal of flex time.

#### Flex time
In this column you will see a check mark if the time bank in question is used for flex time. This is configured in the Flex time settings box.

#### SWH
If this checkbox is marked it means shorter working hours (SWH) is used for the time bank in question. This is configured in the Shorter working hours box.
