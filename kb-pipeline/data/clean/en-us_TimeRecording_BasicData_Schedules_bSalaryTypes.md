### Salary types
Here you see/add salary types for the schedule. There must be at least one salary type.

#### Start and End
Here you enter a start time and an end time in the schedule for the salary type. A salary type cannot have a start time or end time outside the schedule's start and end. A salary type can end within the schedule's start and end time, but there must be salary types covering all scheduled time. A salary type with start time and/or end time in gray color is the same as the corresponding time in the schedule. If you change the schedule's time, the salary type's corresponding time will automatically be changed as well.

#### Attendance
Applies to Work schedule. Here you see/select the salary type(s) which will be generated when recording attendance between the entered start time and end time.

#### Absence 1 and Absence 2
Applies to Work schedule. These are additional salary types for absence. One or both of these salary types will be generated when the employee records absence, with an absence code with Absence 1 and/or Absence 2 marked in the Basic dataWith "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Attendance procedure.
In the first column (Absence 1) you select, for example, a salary type for IWH during absence, such as business trips, etc.
In the second column (Absence 2) you select for example a salary type for IWH when sick, that is, the sickness benefit an employee can receive for time when IWH compensation would have been paid.
You name Absence 1 and Absence 2 using the system settings Name – Absence 1 and Name – Absence 2.

#### Overtime types
Applies to Overtime schedule. For each overtime included by the schedule, you select one or multiple salary types from the ones registered in the Basic data – Attendance procedure.

#### Factor
Applies to Overtime schedule. For overtime types with a balance (that is, types linked to a time bank) you can enter a factor which the salary type's time balance should be multiplied by. For overtime types linked to paid compensation you cannot enter a factor. For such an overtime type, you enter a factor in your salary/payroll program.
