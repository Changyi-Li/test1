### Selection list/Multiple selection list
In this table you add register data as different alternatives to the current extra field. These alternatives will be selectable in a drop-down menu for the extra field where it occurs.
You can only use the table if the extra field has type Selection list or Multiple selection list.

#### Code
An alphanumerical code for the alternative, a maximum of 12 characters. The code will be displayed in a drop-down menu for the extra field.

#### Name
Here you enter a name of the alternative. The text will be displayed in a drop-down menu for the extra field. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Active
Here you determine if the alternative should be available in the drop-down menu.
