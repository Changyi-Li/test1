### Toolbar
You will find the toolbar at the top of all procedure windows. Here you will find buttons with general functions for the procedure in question. The buttons available in the toolbar differs depending on which type of procedure it is. If you place the cursor over a button, the function of the button is shown in a tooltip. In the image below you will find an example of a toolbar.
![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/toolrow.png)
In the table below the most common buttons on the toolbar are described. There you also find the shortcut for the button, if any.

| ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_search_form.png) | Filtering | Filter via selection. In a side panel to the right of the procedure, you will see the filtered records and you are able to mark the record you wish to work on. When the filter is applied, you can see the number of records on the title bar of the procedure window and you are able to browse among the records that have been filtered. The navigation buttons are shown in orange. By clicking this button you can also load default values and clear the filter. After you clear it, the active record is left in the procedure. In e.g., Register customer order, you can paste a selection of records from a list procedure. E.g., the customer orders that have order rows with 0 in them in price each can be filtered and copied to the clipboard in Order list – Sales to be pasted into Filter in Register customer order. You when then see all customer orders that need updated straight to the side panel in Register customer order and you can work on them. | – |
| ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_warehouses.png) | Warehouses | Change warehouse and/or select warehouses to show data from in procedures. If you have changed warehouse, the button is shown in orange ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_warehouses_alt.png). | ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_import.png) | Import | Import for example a sales forecast or report definition from file. | – |
| ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) | Go to procedure | Go to the selected procedure. There are different related procedures which you can go to from the current procedure using this feature. The active record in the procedure is automatically loaded in the procedure you choose to go to. The purpose is to rationalize the daily work. | – |
| ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_follow_active.png) | Follow active record | Follow active record in other procedures. This function means the procedure automatically loads the active record or that it becomes highlighted in another procedure. | ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_property_management.png) | Property management | Open the property management for the procedure. Read more about [Property management](../GeneralFeatures/PropertyManagement.htm). | – |

This instruction is shown in a separate window next to the procedure window. If the procedure does not have an instruction the button is not active. If the instruction is new or if it has been modified since you read it last, then the button is displayed in orange ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_instruction_unread.png). Read more about [Instructions](../GeneralFeatures/Instructions.htm). | Ctrl + Shift + I |

You cannot add the procedure in a desktop configuration which is created according to template. Read more about [Favorites](../GeneralFeatures/Favorites.htm). |   |
