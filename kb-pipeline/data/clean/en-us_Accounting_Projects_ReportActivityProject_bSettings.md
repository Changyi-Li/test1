### Settings

#### Default reporting date
This is a date field where you select the reporting date which should be set by default. Today's date is entered by default, but it can be changed. Since you can create many reporting items (consecutive numbers) at once, it is possible to set a default reporting date which should be suggested.

#### Reporting for user
You can select among users with the field Can be set as responsible for activity activated. With this setting you filter activities with the user you select as responsible.
By default, the logged in user is shown in this field. If the user has sufficient user rights to Report activity for any user then the user can edit this field and that way be able to filter other users' activities and report these.

#### Only show activities ready to be reported
With this setting you determine if only the activities for which the preceding activity has been finished, should be shown in the list. If an activity does not have a dependency with the preceding activity, then it is shown in the list if the above activity has been canceled. If an activity has a dependency with the preceding activity, then it is shown in the list if the dependency type allows it. That is, that the preceding activity is either started or finished.

#### Only main/sub-projects
With this setting you decide if you only want to load projects which are main or sub-projects, the other projects will be disregarded.
