### Calculations

#### Default cost factors
Here you select which cost factors should be default.

#### Staffing affected cost factors
This system setting determines which cost factors should be staffing affected. The selected cost factors will only be calculated at for example 50% in calculations if the staffing factor on an operation has been set to 50%.

#### Calculate sales OH mark-up for
This system setting determines if sales OH mark-up should be calculated on material, subcontract, and/or manufacturing. Material and manufacturing are selected by default.

#### Calculate profit mark-up for
This system setting determines if profit mark-up should be calculated on material, subcontract, and/or manufacturing. Manufacturing is selected by default. Please note! The entire sales OH mark-up is included in the basis on which the profit mark-up is calculated.

#### Include calculation mark-up in default values
Here you decide if the calculation mark-ups in the Pre-calculation and Post-calculation procedure should be included or excluded from default values. Yes is selected by default. If you select the No option, the calculation mark-ups will be excluded from the default values. The calculation mark-ups will in that case be loaded to the calculation procedures from their basic data register in the Calculation mark-up procedure.
