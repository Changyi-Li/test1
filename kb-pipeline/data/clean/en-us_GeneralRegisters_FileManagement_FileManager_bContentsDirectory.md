### Contents of the directory
In the box to the right, Contents of the directory, you’ll see the files and sub-directories which can be linked in the selected path. In the Linked column, the checkbox is checked if the file is linked to a record in the system.
By using the buttons on the function menu, you can:
- Preview ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_preview.png) – Opens a preview of the selected file, for example, a PDF or an image, without you having to download it.
- Delete ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_delete.png) – Deletes the selected files or folders.
- Rename ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_edit.png) – Makes it possible to change the name for a selected file or folder.
- Copy ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_copy.png) – Copies the marked object so you can paste it in a different location.
- Cut ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_cut.png) – Moves the marked objects (folders or files) to a different location by pasting them.
- Paste ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_paste.png) – Pastes earlier copied or cut files and folders to the directory in question.
- Upload ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_upload.png) – Makes it possible to upload files from your computer to the selected directory.
- Download ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_download.png) – Downloads the marked files to your computer.
- Create new folder ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_folder.png) – Creates a new sub-directory in the path in question.
