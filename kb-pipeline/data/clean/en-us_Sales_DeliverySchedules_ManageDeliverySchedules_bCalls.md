### Calls
In this box you find a list of all calls in the marked delivery schedule or for the marked part in the delivery schedule.
The list contains all necessary information about each call. It is information loaded partly from the delivery schedule and partly from matching customer order rows in Monitor ERP which makes it possible for you to compare the delivery schedule's requirements with what is actually on the corresponding customer orders. Manually added rows from the customer order, if any, are also shown.
The calls in the list are sorted by part per delivery date. If the delivery date is in past time, it is shown with a pale red background. Delivery dates as of today's date are shown with a light green background. Calls with a delivery date within the part's lead time are shown with a pale yellow background. These colors for the delivery dates are the same as in the planning window in the part register.
In the Quantity field you can change the quantity in the calls as long as the delivery schedule or the part in question, has not been reconciled.
When the delivery schedule or the part in question has been reconciled, the Quantity – Result field becomes available. There you can modify the quantity in the call, if that should be needed as a result of the reconciliation. A changed quantity in any of the fields is indicated with italics and the initial quantity is shown in a tooltip over the field.
When you have performed the reconciliation, then it is also possible to use the checkbox to the far right to select which calls should be transferred to customer order. By default, all calls are selected.
After transfer, you will also see the order number and order row position which were created in Monitor ERP.
For new order rows created at the transfer to customer order, the order date on the order row will be set to today's date. For existing order rows that are updated at the transfer to customer order, the order date on the order row is set to today’s date only if the type of requirement in the call is Fixed order.
On the function menu there is a button called Go to procedure ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png). By using this you can go to the related procedures for the selected call/order row.
> By using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_float_window.png) in the top right corner, it is possible to unpin the box and make it a floating window. You can then increase width and height, and for example move the window to another screen to get a better overview of the calls.
