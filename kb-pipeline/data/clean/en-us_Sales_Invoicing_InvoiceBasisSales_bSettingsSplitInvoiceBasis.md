### Settings for list type Split invoice basis

#### Suggest quantity
Determines the quantity that will be entered by default for the invoice basis rows in the list. By default, the setting is configured to All, but it can be changed to Zero.

#### Show only main rows
Determines if only main rows will be shown in the list. If this setting is activated, the associated sub-rows, such as additional texts and incorporated/included parts in fictitious parts, will not be displayed.
