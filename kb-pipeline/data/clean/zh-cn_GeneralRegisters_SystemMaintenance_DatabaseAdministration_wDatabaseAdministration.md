## 数据库管理
> 请注意！此程序仅应由管理员或ERP 经理使用由，最好咨询MONITOR ERP 系统 AB 的支持Monitor 代理程序。
该程序可以在系统中的所有公司中运行，其目的如下：
- 通过特定补丁更新相关公司的数据库。补丁由MONITOR 支持 中心创建人，例如作为 .mql文件附加到Email消息。
-    
通过正在上传文件链接或Ftp将包含不同日志文件的数据库上传到MONITOR支持中心。目的是使MONITOR支持中心的员工能够测试、排除故障并解决数据库中的问题/错误（如果有）。
> 如果数据库在 SQL Anywhere 上运行，则仅可以从这里正在上传数据库。如果数据库在 Microsoft SQL 服务器上运行，你通过从MONITOR支持中心你的链接人工的上传它。
- 为数据库中的一、多个或全部表创建优化统计。这通常在数据库服务器运行时完成。仅在特殊案件下你才可能需要人工的新建的优化统计。
- 更改数据库存取密码。该密码与SAP SQL Anywhere 数据库用户相关联 只读用户。
- 更改 SQL Anywhere 的优化层级。
