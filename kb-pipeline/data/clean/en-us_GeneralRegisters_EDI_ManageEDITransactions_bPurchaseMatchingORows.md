### Matching order rows
In this box you see the matching order rows for the row selected in the Rows box above.
In cases where "Match and fit" is not applied, there will be a "one-to-one ratio" between the Rows box and the Matching order rows box.
In cases where "Match and fit" is applied, a row in the Rows box can have multiple matches in the Matching order rows box.

#### Order number
Matching purchase order numbers.

#### Position
Matching position numbers.

#### Quantity
The sent quantity for this matching order row.

#### Delivery date
Here you see the delivery date from the matching order row (this will in a way reflect the "age" of the matching order row)
Under the More info button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png), you can generally find additional columns. Below you find the online help topics for the columns.

#### Warehouse
Here you see the warehouse for the matching order/row.

#### Batches
Here you see the advised batch numbers for the matching order.

#### Serial number
Here you see the advised serial numbers for the matching order.
