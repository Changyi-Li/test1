### Arrival

#### Mandatory delivery note number at arrival
This system setting determines if the delivery note number should be mandatory to enter before you can save in the Report arrival procedure.

#### Mandatory shipment number at arrival reporting
This system setting determines if the shipment number should be mandatory to enter before you can save in the Report arrival procedure.

#### Reasonability check for excess reporting in the procedure Report arrival
This system setting determines if a reasonability check for excess reporting of quantity should be made at arrival. The available alternatives are Inactive, Warn, or Block.

#### Allowed excess reporting in % of planned quantity
If the system setting above has been set to Warn or Block then this system setting will also be activated. Here you enter how much excess reporting in percent of planned quantity is allowed on the order row that is being arrival reported. If the allowed excess reporting is exceeded, you can use the system setting above to receive a warning (the order row can still be arrival reported) or block the order row for arrival reporting.

#### Reasonability check for deletion of remain. in the procedure Report arrival
This system setting determines if a reasonability check for deletion of quantity should be made at arrival. The available alternatives are Inactive, Warn, or Block.

#### Max. deletion of remaining allowed in % of planned quantity
If the system setting above has been set to Warn or Block then this system setting will also be activated. Here you enter the maximum deletion in percent of planned quantity on the order row that is being arrival reported. If the allowed deletion is exceeded, you can use the system setting above to receive a warning (the quantity can still be deleted) or block the quantity for deletion.

#### Apply receiving inspection for stock order
This system setting determines if receiving inspection should be applied to stock orders. The same conditions apply as for regular orders. Receiving inspection must be activated on part, supplier, or order. You can also activate receiving inspection at the arrival.

#### Setup time for arrival per order row
This system setting determines the planned setup time for arrival. For each order row one setup time will be added to the planning.

#### Unit time for arrival per package
This system setting determines the planned unit time for arrival. For each order row one unit time will be added to the planning.
Setup time and unit time for picking per order row and package are used to create loading plans for arrivals in the Order list – Purchase procedure in the same way as you do in the manufacturing. In that procedure you can use the Loading plan list to see the number of arrivals per day measured in package quantity and arrival time. Weight, volume, and number of order rows are also displayed in that loading plan.
