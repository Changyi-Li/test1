### Settings – Prices

#### Price
Applies to the Change price list type. Here you select the price of the part that you wish to adjust. The parts' existing and new price are shown in the list. The default value is the standard price.

#### Price list
This field is available if the Price list or Future price list option is selected as price to change or to copy from, and also for the list type called Change staggered price – Price list.

#### Show discount
Applies to the Change price and Copy price list types. With this checkbox you decide if the discount should be shown as a column in the list. This checkbox is available if you have selected customer price, future customer price, supplier price, or future supplier price. Only these prices handle discounts.

#### Use discount
Applies to the Copy price list type. With this checkbox you decide if the customer link's/supplier link's discount should be shown in a column in the list and be deducted from the price before it is copied to the selected price. The setting is available if you have selected to copy the price from customer price, supplier price, future customer price, or future supplier price.

#### Change setup price
With this checkbox you decide if the setup price should be adjusted. If the field is left empty, only "price each" will be changed. This checkbox is available if you have selected customer price, future customer price, supplier price, future supplier price, or price list. Only these prices have setup prices.

#### Only parts with price
Applies to the Change price list type. With this checkbox you determine if only parts with prices should be loaded to the list. If you do not activate the setting, the parts will be loaded regardless if they have a price since before.

#### Only show parts with new price
With this setting you can choose to show only parts with updated prices.

#### Adjust future
Applies to the list types: Change staggered price – Price list/Customer/Supplier. With this setting you select if future staggering also should be adjusted. If not, only the current staggering will be adjusted.

#### Copy from price
Applies to the Copy price list type. Here you select the price from which you want to copy. If you select Price list you can then select which price list you refer to in the next field. If you select Customer price, you must enter a Customer number in the field under. The customer number determines which customer link on the part from which the price will be copied. The supplier price is always copied from the default supplier link.

#### Copy to price
Applies to the Copy price list type. Here you select the price to which you want to copy. If you select Price list you can then select which price list you refer to in the next field. If you select Customer price, the price will be copied to all customer links if you have not selected by customer. For Supplier price, you can choose if the price will only be copied to the default suppliers or to all suppliers.

#### Rate type
Applies to the Copy price list type. If the price that you copy from or to is registered in another currency than the company currency, a currency conversion will be made.

#### Only default supplier
Applies to the Copy price list type. If you have chosen to copy to Supplier price or Future supplier price, then it is possible to activate this setting in order to only copy within the default supplier link of the part. If you do not activate this setting, you will copy within all supplier links on the part.
