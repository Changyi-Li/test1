### Preview
In the Preview box under the Document tab you can preview the document in question before printing it. If the printout consists of several pages, it is possible to scroll in the box. You can zoom the document by using Ctrl + the scroll wheel or the scroll percent in the lower right part of the box.
(Manufacturing order) By clicking the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_documents.png) in the Preview box, you access a window where you can select the document which should be previewed. You can choose between Traveler, Operation document, or Material document. Here you can also, when needed, change the number of copies to print of each document, as well as choose if linked files should be printed (for example drawings).
