### Exposure time
In this box you can see the Code, Exposure time, Remaining time, and Number of cycles for the selected batch. The Exposure time box is displayed if the system setting called Exposure time is activated.

#### Code
This is loaded from the Part register where you’ve selected the code for the part. New codes are registered in Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Part.

#### Exposure time
Here you see, in hours, how long the selected batch can be exposed before any action must be taken.

#### Remaining time
Here you can see, in hours, how much exposure time the selected batch has left.

#### Number of cycles
Here you can see how many cycles the batch has gone through.

#### New cycle
By starting a new cycle, you can reset the Remaining time to the selected Exposure time. The fields are only visible if the Exposure time system setting is activated under the Stock tab in the System settings procedure.
By using the Start/Stop button you can start and stop the current cycle. This button is synchronized with the Move stock balance. This means that it, for example, is not possible to start the exposure time if the batch is in a controlled/secure location.
