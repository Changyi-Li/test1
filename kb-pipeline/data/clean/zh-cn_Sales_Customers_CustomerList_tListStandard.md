### 标准列表
加载到标准列表的数据取决于你已选择的格式。除开头两列外，你可以编辑大多数列。它们显示每个行涉及哪个客户。
条款 / 价格
在此列表中，你可以查看和更改价格客户的设置以及付款条款、交货、交货方式、有效期。可用选项在 条款 程序。你还可以更改价格列表、配置价格列表（如果使用产品配置选项）和折扣分类。这些备选在各自的程序中处理 通用登记。折扣，合金成本，以及开票计划也在列表中处理。
该列表对应于盒子 条款 和 价格 在里面 客户登记。
导出 / 打印
在此列表中，你可以查看和更改有关导出到客户的设置以及如何已打印订单和客户发票的设置。例如，你可以配置订单打印和发票打印的默认执行由：通过Email已发送到打印机。例如，你还可以更改语言、货币和时区。
该列表对应于盒子 导出 和 打印 在里面 客户登记。
XML / 文档
在此列表中，你可以查看和修改针对 XML文件和客户特定文档所做的设置。例如，关于将客户订单、发票或XML 形式案件文件的设置。你还可以更改要使用的文档变量，例如，报价、订单确认单、客户协议、交货单、运输标签和形式发票。
该列表已配置设置在 XML / 文档 框中的 客户登记 程序。
交货 / 货运
在此列表中，你可以查看和更改有关向客户交货和货运的已配置设置。例如，有关交货规则、交货天数、运输时间、交货指导、拣货指导和从开始日期起的累计数量的设置。
该列表对应于 交货 / 货运 框中的 客户登记。
例外
在此列表中，你可以查看和更改针对已选择客户的通用设置所做出的例外。例如，可以对利息费用和罚息作出例外。该列表对应于 例外 框中的 客户登记。
CRM
在此列表中，你可以查看和更改针对已选择客户的CRM设置。例如，你可以查看谁是销售员、谁客户负责人、客户的状态以及员工数量。
该列表对应于 设置 框中的 客户登记。
其它的
在此列表中，你可以查看和更改为客户所做的其它设置。
该列表对应于以下盒子已配置的设置： XML / 文档， 开票， 和 其它的 在里面 客户登记 程序。
