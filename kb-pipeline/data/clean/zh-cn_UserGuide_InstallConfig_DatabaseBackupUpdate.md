### 数据库备份和迁移
> 请注意！如果数据库在 SQL Anywhere 上运行，则此描述适用。如果数据库在 SQL 服务器上运行，则更新无法复制或移动数据库，如下低于。数据库将直接迁移到 SQL 服务器上。这就是为什么第一个你备份很重要 微软 SQL服务器管理套件 根据微软的文档，在你更新之前 Monitor ERP 服务器。
备份和迁移 SQL Anywhere 数据库，与更新 Monitor ERP 服务器按以下方式进行。这全部都将自动发生：
1. 全部数据库都从常规的数据库目录复制到 安装_温度 目录位于当前日程表图表:\ProgramData\ MONITOR ERP 系统 G5\ 下。公司配置文件也被复制到该目录中。
2. 之后，下班临时目录中的数据库迁移到新版本。
3. 临时目录迁移之后，会发生以下情况：
1. 常规的数据库目录中的全部数据库都将移动到 安装_旧 目录，在当前日程表图表:\ProgramData\ MONITOR ERP 系统 G5\下。
2. 临时目录中的迁移数据库然后将被移动到常规的数据库目录。
4. 更新之后，MONITOR服务器开始时，系统数据库和商业智能数据库也会被迁移。
如果数据库迁移由于某种原因失败，整个更新将被已取消。
