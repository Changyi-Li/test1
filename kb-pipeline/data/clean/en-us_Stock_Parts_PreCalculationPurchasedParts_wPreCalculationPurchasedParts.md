## Pre-calculation – Purchased parts
In this procedure you can perform pre-calculations for purchased parts in order to calculate the parts' total cost (including different expenses) and also quote price.
You can configure which information new calculations should be based on. For example:
- Price alternative for purchased part
- Quantity (order quantity)
- Different purchase expenses (alloy costs, certificates, freight, customs, setup cost, tools, and miscellaneous)
- SO mark-up
- Sales OH mark-up
- Profit mark-upThe profit mark-up is a percentage mark-up on the cost price which will generate a suggested quote price.
In the Part list procedure, you can use the list type Expenses to perform a mass update of purchase expenses for parts.
It is possible to save from purchase cost, cost price, quote price, or net cost – to standard price, future standard price, price list, or future price list. You can configure to save to one or multiple prices in the same calculation run by adding more rows in the Saving table.
In the list that can be loaded in the procedure, you can change the quantity on which the calculation should be based for each part. You can also choose which parts should be included in the calculation run. You start the calculation by using the button Start calculation ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_run.png) (Ctrl + R) on the toolbar of the procedure.
After the calculation run, you can for each part choose if calculation and price or only the calculation should be saved. You save by clicking on the button Save ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_save.png) (Ctrl + S) on the toolbar of the procedure.
In the Part register procedure you can also pre-calculate purchased parts, but only for one part at a time.

#### Stock accounting and Management accounting
If you use stock accounting or management accounting, you can by using saved calculations on purchased parts, select how expenses for purchased parts should be posted. This is done in the Register posting method procedure. There you use the field Price alternative for purchased part to choose if the price alternative should be set to Standard price excluding expenses or just Expenses.
> You can automate the running of this procedure with the Agent option. Read more about [The Agent](../../../UserGuide/Options/Agent.htm) can help make your processes more efficient.
