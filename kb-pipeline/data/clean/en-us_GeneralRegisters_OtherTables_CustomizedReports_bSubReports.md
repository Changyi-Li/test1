### Sub-reports
In this box you add/delete sub-reports to the customized report procedure. You can link to sub-reports from a list type of the type Free-format layout.
Click the Edit report button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_edit.png) to start building the actual sub-report. Read more about this in the [Edit report](wEditReport.htm) section.
By using Copy sub-report's DisplayID to clipboard ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_copy_to_clipboard.png) you will copy the sub-report's DisplayID to the Clipboard in Windows.

#### Name
Here you enter the name of the sub-report. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Sub-reports
In this column you can add other sub-reports to link to from the sub-report.
