## Document settings
In this procedure you can configure all document settings in the system besides some specific settings regarding manufacturing orders that are configured in the Document templates – Manufacturing order procedure.
When you start up the system for the first time all document settings are activated by default. The settings determine which data should be shown. You can also change the layout of the document to some extent. The documents are divided into one tab per module Manufacturing, Purchase, Sales, Stock, Time recording, and Accounting.
