### Depreciation
In this box you enter the fixed assets for which you want to make extra depreciation. When you have entered how much you wish to depreciate you will see the posting for the fixed asset at the bottom of the window in the Posting box.

#### Object
In this column you select the fixed assets object which should be depreciated. A fixed asset (object) can only be entered once. Sold/retired fixed assets or fixed assets tagged as Not depreciable can not be entered. Fixed assets which are investments in progress cannot be depreciated until the time when the asset begins to be used.

#### Depreciation date
Here you can enter by which date the extra depreciation should take place. By default the most recent depreciation date of the fixed asset is entered here but this can be changed. For example if you have depreciated the asset in January but you need to make an extra depreciation in the AFS (December).

#### Depreciation
Here you can enter the amount to be depreciated. The amount can be entered as positive and negative. A fixed assets object which has a positive acquisition value can never be depreciated making the new residual amount less than zero. A fixed assets object which has a negative acquisition value can never be depreciated making the new residual amount greater than zero.

#### New residual value
The new residual value is shown here after you have entered the depreciated amount. You can also choose to enter another amount in the field, and then the depreciation will be adjusted instead. The residual value for an object with a positive acquisition value can be the same as or greater than 0. The residual value for an object with a negative acquisition value can be the same as or less than 0.
