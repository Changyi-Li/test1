### Settings

#### Time bank
With this setting you select which time bank to load to the list.

#### Balance alternative
With this setting you decide if it is the current balance or the historical balance which should be updated. The Current option means right now. The Historical option means the time balance which applied on the date you select in the field below.
> Using the option Historical you can for example in arrears add the time balance which should apply as opening balance at the turn of a month.

#### Date
Here you select the date for which you wish to update the time balance. It is only possible to select dates which are historical, that is, dates already passed.

#### Show blocked
With this setting you determine whether or not blocked employees should be shown in the list.

#### Include former employees
With this setting you can determine whether or not employees who have ended their employment should be included in the list.

#### Salary transaction
Using this setting you can make a reconciliation of payroll transactions, comparing them with minimum value and maximum value in hours for a time bank. At the same time you can insert an addition for the balance change in the procedure Authorize/Adjust recording which can then be transferred to the payroll program. What is required is that the parameter group has a salary type entered for the affected time bank in the fields Salary typeSalary types are used to create salary bases for worked time and absence. Different salary types are used, for example, for work during regular working hours, flex, overtime, shorter working hours, and sick leave. The salary bases are used to manage salaries in a payroll system. Salary types are linked to absence codes in addition to work schedules and overtime schedules. for increasing balance and Salary type for decreasing balance. The following options are available in the setting:
- No – No reconciliation is made.
- Manual limits – Reconciliation will be made with the entered minimum value and maximum value (in number of hours) which you enter in the fields below. These fields become available when you select Manual limits.

#### Maximum value
Here you enter a max. value for reconciliation if Manual limits was selected above.

#### Minimum value
Here you enter a min. value for reconciliation if Manual limits was selected above.
