### Parts

#### Include
This setting determines which part rows should be included in the imported delivery schedule. All rows are selected by default.

#### Status – Calls
Here you can view whether there are any validation errors at call level for the part.

#### Part number
The part number in Monitor ERP. This is obligatory and cannot be left blank. If the part is not matched during the import process, you can manually select the part number.

#### Action
If you manually select part numbers, you can select the action you want to perform, i.e., whether you want to Update/Create customer link or Add other part identity.

#### Supplier's part number from file
The supplier’s part number from the import file. This cannot be updated.

#### Part number from file
The part number from the import file. This cannot be updated.

#### Part name from file
The part name from the import file. This cannot be updated.

#### Unit
Here you see the part's unit In Monitor ERP. This cannot be updated.

#### Unit from file
The unit from the import file This cannot be updated. If the unit matches an existing unit for the part in Monitor ERP, this unit will be used, otherwise a warning will be displayed and the standard unit from usage for customer order will be used.

#### Other part identities from file
Other part identities can be used to match the import file. This button shows two columns. The first column shows Code and the other column shows Identity.

#### Port
The port to which the part should be delivered. This cannot be updated.

#### Storage
Which storage the part should be delivered to. This cannot be updated.

#### Delivery notes from file
By clicking the Delivery notes from file button, you can view information on the delivery notes you received in the file. The following information is shown: Delivery note number, Delivery note date, Dispatched quantity, Received quantity, and Receiving date.
