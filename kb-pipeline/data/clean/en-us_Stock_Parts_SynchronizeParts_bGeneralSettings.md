### General settings

#### Synchronization option for part type in remote company
Here you decide how different part types should be synchronized in the remote company. Example: The sales company sells parts that they have purchased from the production company that has produced the parts. When the production company synchronizes its manufactured parts, these parts should be entered as purchased parts in the sales company.

#### Synchronization option for revision in remote company
Here you decide if Only active or if All revisions should be synchronized in the remote company. Only active is selected by default. You can also select whether or not file links should be synchronized. This can be useful to, for example, synchronize drawing revisions.
> In order to be able to synchronize file links, both companies must have the same active path. This can be configured in the Paths. Please note that no files are synchronized. Only file names are synchronized.

#### Handling of currency at synchronization
With this setting you determine how the currency should be handled when the sending and the receiving company have the same supplier but different currency settings for the supplier. The following options are available:
- Always use sending company's currency
- Convert according to supplier's/customer's currency in receiving company
- Convert according to existing link's currency in receiving company, use supplier's/customer's currency for new links
- Convert according to existing link's currency in receiving company, use sending company's currency for new links
