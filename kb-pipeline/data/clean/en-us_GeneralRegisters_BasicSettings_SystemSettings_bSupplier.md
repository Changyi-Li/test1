### Supplier

#### Show extra information about supplier's reference
This system setting determines if it should be possible to enter extra information on supplier's references in the supplier register. If you have activated this system setting, then three columns will be added to the references. The columns are called Extra 1, Extra 2, and Extra 3.

#### Attach XML file by default for new suppliers
This setting determines which XML files are set to default under Attach XML file­ for a new supplier. The XML files are used in Monitor-to-Monitor.

#### Default payment method for new supplier
This setting determines which payment method will be set by default for new suppliers.

#### Reference number activated by default for new supplier
Here you decide if Reference number should be activated by default when registering a new supplier in the Supplier register. For countries which have official handling of reference numbers, a validation is built in to the field to make a validation error appear if you enter an invalid number.
