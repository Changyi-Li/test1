### 其它的
在此框中你输入其它信息并根据以下内容为客户配置不同的设置。

#### 信用额度
你可以在此处输入应用于该客户信用额度的金额。在登记订单和执行交货报告时可以显示警告，提示已超出限制。默认值0（0）。这意味着无限制。信用额度以本位币输入。点击按钮 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_more_info.png)，你将看到有关信用状况的信息。
银行账号（在使用客户订单传输选项的系统中）
通过使用 银行账号 按钮 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_more_info.png) 你可以登记一或多个银行账号。在到左边，你可以看到你登记的科目，你还可以选择默认使用的一。在到右边，你根据以下内容填写相应科目的信息。这主要用于使用客户订单传输选项的系统中，当你希望能够以客户的名称打印交货文档时。

#### 银行账号类型
在这里你选择要已登记的科目类型。你可以在 IBAN、BBAN、UPIC 和其它在中间进行选择。

#### 账号 / IBAN
在输入你银行账号或IBAN，最多50个字符。

#### 银行间金融电信协会
在输入你的 BIC 或 SWIFT代码，最多 20 个字符。

#### 清算编号
在输入你的清算编号（不与 IBAN 一起使用），最多 20 个字符。

#### 清算系统
输入你的清算系统（不与IBAN一起使用），最多使用20个字符。

#### 货币
在这里，你将银行账号与一种货币链接。默认使用由的货币与 导出 框，但这可以已变更。已建议的银行账号主要基于发票的货币。如果有多个银行账号与发票货币相同，然后已建议使用设置为默认的银行账号。

#### 接收者国籍
接收者国籍默认与邮寄地址的国家 / 地区相同，但可以已变更。

#### 国家 / 地区
你在此字段中输入报价有效的国家 / 地区自。默认下，你将在这里看到与邮寄地址相同的国家 / 地区，但这可以已变更。已选择的国家 / 地区会影响将应用的地址格式。如果你选择的国家 / 地区不特定地址格式，则将应用通用地址格式。你将国家 / 地区/地区链接到地址格式 国家 / 地区 程序。更改你国家 / 地区代码，地址格式也会已变更。
地址设置
在到右边 国家 / 地区 字段你查询 地址设置 按钮 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_change_settings.png) 你可以在其中查看和添加与银行所在国家 / 地区链接至的更多信息。单击按钮，将出现一个窗口，名为 地址设置 打开字段 语言 和 文档组 会出现。在窗口中你还可以看到适用于已选择国家 / 地区/地区的地址格式。你可以根据地址格式在窗口底部预览地址。

#### 语言
你在此处选择的语言将是提交给银行的文档所使用的语言。当你选择国家 / 地区时，语言会自动填写。该字段可以编辑，并且你可以选择任何语言。例如，当与普遍使用多于的国家 / 地区打交道时，这可能很有用。通过使用 查找 功能中，你可以选择已登记为激活的语言 语言 程序。

#### 文档组
在此字段中，选择你文档组，该单据组决定了发送给银行的文档中默认使用由的文档组。文档组基于已选择语言，并语言链接至 语言 程序。

#### 地址格式
这是显示已选择国家 / 地区所应用的格式的信息字段。此字段不编辑。

#### 预览
在这里你可以看到按照已选择国家 / 地区的地址格式输入的地址的预览。
通过使用按钮![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_show_in_google_maps.png)，您可以找到并查看输入的地址在 Google 地图中的位置。

#### 名称
在输入你银行。

#### 地址
输入银行的街道地址箱号过账办公室。

#### 邮编
在输入你的邮编。已登记在​ 邮编登记 程序中，你邮编选择 查找 特征。

#### 城市
这里你输入银行所在的城市。如果已在国家邮编中输入相应信息，则此字段将自动填写 邮编登记 程序。
这 城市 字段可用于以下地址格式：
- 邮编 + 城市
- 城市， 邮编 （两行）
- 城市 + 州 / 地区 + 邮编。

#### 州 / 地区
在这里你银行输入的州或地区。字段你在 邮编登记 程序。
字段 州 / 地区 以地址格式可用 城市 + 国家 / 地区 + 邮编。例如在美国使用此地址格式

#### 城市 / 省
在这里你银行所在的城市或省份。字段你在 邮编登记 程序。
字段 州/省 以地址格式可用 城市 / 省+邮编。例如在中国就使用这种地址格式。

#### 私人客户
通过此设置你可以确定客户是否是个人（私人客户）。如果你激活此设置，则你将不输入VAT 登记号或企业 ID 号。相反，你可以输入客户的个人ID编号。已发送给客户的全部文档和价格列表上的价格均含VAT。

#### 个人ID编号
如果客户是私人客户，则此字段可用。然后，你可以输入客户的个人ID编号（类似于社会安全编号）。个人ID编号可以输入10位或12位数字。

#### 企业 ID 号
在输入你的企业 ID 号。如果客户已已激活 托收保付 按钮下方 其它发票设置 oand托收保付是通过 Peppol BIS 3.0 插件，然后必须输入客户的公司标识 。

#### 我方供应商号
在输入你在客户处已登记的供应商号。

#### VAT 登记号
在输入你的VAT 登记号。此编号已打印在提供给客户的不同文档上。如果输入的编号已被其他客户使用由，则会显示一条消息。
点击 VIES 验证 按钮 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_validate.png) 你可以根据VIES（VAT信息交换系统）检查VAT 登记号是否有效。VIES 是一种电子方式，用于验证在欧盟已登记的经济操作员在边界进行商品或服务事务时的VAT登记号码。这样你就可以知道该编号或不有效。根据国家数据保护规则，一些国家 / 地区还会提供与给定VAT编号链接至的名称和地址，因为它们已记录在国家数据库中。系统还日志所进行的检查/校验以及返回的结果。
如果VAT编号显示为无效的，你应第一个与相关公司检查，以确保该编号正确（字符数正确、长度正确和国家 / 地区前缀正确）。如果之后检查后，该编号仍然是“无效的”，你应该要求该公司联系人其税机关，请求已更新国家VAT信息交换系统(VIES) 中的数据（仅国家税机关可以更新VIES 数据）。
如果您自己的公司信息错误的日期，你应该联系人您的税机关并要求他们更正信息。保持记住，一些成员/北爱尔兰要求此类更新请求必须以书面形式或通过网络表格提出。
一些成员/北爱尔兰要求对欧盟内部（和北爱尔兰）的商品和服务事务进行单独的VAT登记，并且仅在其国家数据库中记录此类VAT号码。因此，VAT编号即使正确，也有可能不通过 VIES 验证，因为该VAT编号的所有者不参与欧盟内部事务（和北爱尔兰）不登记此类销售。
阅读更多 [欧盟](https://ec.europa.eu/taxation_customs/vies/#/faq)

#### EORI 号
在输入你的EORI 号（经济操作员登记和识别号）。你可以使用EORI 号来处理欧盟境内全部与海关相关的业务。在里面 文档模板 程序你在文档部件页眉 - 销售中添加EORI 号。
您可以根据欧盟佣金可用的数据库来验证您输入的EORI 号。点击 EORI 号无效 按钮 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_more_info.png) 然后 验证 EORI 按钮 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_validate.png)。在你验证了EORI 号后，有关该公司的信息将加载到窗口中，你可以查看EORI 号或不有效。按钮 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_more_info.png) 将更已变更 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/StatusFinished.png) 如果EORI 号有效。无论EORI 号或不有效，你都可以在按钮的工具提示中看到该编号最近的验证时间及验证者。

#### 远期汇率
那个设置 远期汇率 仅适用于客户拥有本位币其它货币的情况。如果是这种案件，你可以检查此设置，如果客户的新客户订单默认应该有相应的设置 远期汇率 已激活。然后，你就可以输入每个新订单应用的远期汇率。订单中输入的远期汇率也适用于开票。

#### 零散客户
“零散客户”是用于不同客户进行一次性销售（非重复）的客户号。因此，这些客户不在客户登记中已登记。如果设置 零散客户 已经检查，这意味着提醒的打印（如果有）对于该客户号每发票分开，并且不收集到单个提醒中。这样，你就可以为不同的手动计划客户分别打印提醒。

#### 使用客户编号, 发票中的 VAT 登记号
在系统中可以使用该功能 客户号, 发票。这意味着你的销售流程中涉及两个不同的客户编号。一，你有已登记订单的客户号，其它，你有发票上使用的客户号，将接收此发票的客户号。当你输入客户号, 发票时，此设置将被默认标记。然后， EC销售列表和欧盟出口统计表将载入在客户号, 发票下输入的客户的VAT 登记号。这也意味着发票客户的VAT 登记号显示在客户发票文档上，并已记录在EC销售列表和境内的报告中。
打印
在打印按钮下方 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_more_info.png) 你可以为客户配置不同的设置打印中订单和发票。

#### 打印订单 / 报价由
通过此设置，你可以确定是否使用打印机或通过Email打印订单。这里已选择的方式然后成为该客户客户订单的默认方式。

#### 打印发票由
通过此设置，你可以确定是否使用打印机或通过Email打印发票。这里已选择的方式然后成为向相关客户发票的默认方式。

#### 打印形式发票通过
通过此设置，你可以确定是否使用打印机或通过Email打印形式发票。这里已选择的方式然后成为相关客户形式发票的默认方式。

#### 通过以下方式打印付款提醒/对账单
通过此设置，你可以确定是否使用打印机或通过Email打印付款提醒 / 对账单。此处已选择的方式将成为向相关客户发送付款提醒/声明的默认方式。

#### 打印协议报告自
通过此设置，你可以确定是否使用打印机或通过Email打印协议报告。这里已选择的方式然后成为向相关客户协议报告的默认方式。
