### Generate calls
In this box you can configure a set of calls in the delivery schedule, based on Start date, End date, Quantity per call, as well as on which Week days the calls should be made.
You then generate the calls using the button Add the above entered number of calls ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_batch.png) in the Calls box.
