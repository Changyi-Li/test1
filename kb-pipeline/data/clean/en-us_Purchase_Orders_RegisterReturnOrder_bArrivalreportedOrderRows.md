### Arrival reported order rows (Register return order)
Here you see all arrival reported purchase order rows for purchase orders to the supplier selected in the Supplier section to the left.

#### Include
With this checkbox you decide if the order row should be included in the return order.
When you have marked the order rows to include, you create a purchase order for the return order by saving in this procedure. The return order is then displayed under the Results tab which is then available.

#### Unit
The unit is possible to change if the part in question has alternative units.

#### Quantity to return
Here you enter the quantity to return for the order row in question. The quantity cannot be greater than the arrival reported quantity.

#### Case
Here you can select a case to link to the purchase order row. You can choose among cases related to the order row. It is not possible to choose cases with the basic type called Internal nonconformity.
In the Register case procedure it is possible to register return orders from a case.
