### Mobile client
A mobile client is included in G5. The mobile client has a user interface adapted for tablet computers and smartphones and therefore it contains fewer functions than the Windows client for G5. The mobile client is run in a web browser or as an app for Android and IOS.
Before you can use the mobile client you must configure a few settings for the user and Monitor ERP Web server must be installed. Read more in the section [mobile client](../../../GettingStarted/MobileClient.htm) in the online help function.
