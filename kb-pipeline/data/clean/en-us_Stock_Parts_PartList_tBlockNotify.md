### The Block/Notify list
You can use the button called Replace all selected messages ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_change_record.png) in the function menu to mass-update cancel/block/notify on more than one part at a time.

#### Block status
Here you see/enter if the part should be blocked or if a notification should be created during different events.
- None/Cancel (default) – This option means that no block or notification will be used for the part. This alternative will override any previously configured block or notification.
- Notify – This option means that a notification will be used for the part. This option also activates the column For/At and the button Message.
- Block – This option means that a block will be used for the part. This option also activates the column For/At and the button Message.

#### Block type
If Notify or Block has been selected for the part, you must here choose for/at which type of event a block or notification should be used. You can configure that a message is shown or that the part is blocked at the following events:
- Register manufacturing order
- Register purchase order
- Register customer order
- Report manufacturing order
- Report purchase order
- Report customer order
- Withdrawal for manufacturing order
- BOM and routing
- Option in configuration
- Register customer agreement
- Register blanket order – Purchase
- Register blanket order – Sales

#### Block message
If Notify or Block has been selected for the part, you enter the message that will be shown during the events selected in the previous column.

#### Preceding activity
Here you see the preceding activity.

#### Block date
Here you see the date when the block was activated.
