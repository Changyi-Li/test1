### Settings – Translation
Settings for the list type Translation.

#### Language
Here you select the language to which the translation should be made. All the active languages can be selected among here. You must enter a language to be able to create a list. The selected language is shown as its language code in the field and the name is automatically displayed to the right. Only one language can be entered at a time.

#### Translate
Here you select the columns to be included in the list and what should be possible to translate. You can here select name and/or additional name.

#### Copy from language
Here you copy the name and/or additional name from another language. All active languages can be selected among, except for the language you have chosen to translate into. If you do not enter a language to copy from, the names will have empty translation fields in the list. This setting is not possible to edit until you have chosen a language to translate into and you must also have made the list updateable. This is done using the Updateable button in the toolbar.

#### Only parts without translation
With this checkbox you determine if only parts without translation or all the parts should be loaded to the list. Parts where one of the two names does not have a translation will be included.
