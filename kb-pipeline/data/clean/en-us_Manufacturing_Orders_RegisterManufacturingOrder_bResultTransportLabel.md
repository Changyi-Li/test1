### Result – Transport label
You can print a transport label for all the "first operations" in each part node in the structure of the manufacturing orders that exist in the procedure. The purpose is to use these transport labels in order to label/mark the pallets before any quantity reporting has been made.
In this Result box you choose for which parts, on each respective order, that you wish to print transport labels. By default, all rows are selected. In the Preview box to the right, you can preview each transport label before printing.
