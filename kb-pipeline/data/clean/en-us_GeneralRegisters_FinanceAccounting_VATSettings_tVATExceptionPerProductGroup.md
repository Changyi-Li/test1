### Exceptions
Under this tab you can configure that the product group for the part should determine which VAT code should be used on order rows and invoice rows. This is useful if there are mixed VAT codes within a VAT group.
For example, goods that are sold with both full VAT and reduced VAT (for example VAT code 1 and VAT code 2) within the country. You then use separate product groups for these. Then you create exception for the product group that should have a deviating VAT code. The exception is entered per combination of product group and VAT group.
Another example is if you sell both goods and services to EU countries. You then enter a deviating VAT code for a product group referring to services to the VAT group EU.
