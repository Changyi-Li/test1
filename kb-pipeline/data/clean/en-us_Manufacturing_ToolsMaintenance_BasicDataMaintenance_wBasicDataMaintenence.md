## Basic data – Maintenance
This procedure is part of the Tools & Maintenance option. Here you register basic data for maintenance as maintenance templates and maintenance types.
You can create maintenance types if you wish to create structures of the different types of maintenance items. This makes it possible to do follow-ups on these types. For example, you can create one structure for preventive maintenance and a different structure for corrective maintenance.
You can then enter a maintenance type on a maintenance template. The maintenance template is what determines the maintenance which then will be planned and reported. To the maintenance template you also link a form template. This first has to be registered in the Form templates procedure.
Read more about [Tools & Maintenance](../../../UserGuide/Using/ToolsMaintenance/ToolsMaintenance.htm).
