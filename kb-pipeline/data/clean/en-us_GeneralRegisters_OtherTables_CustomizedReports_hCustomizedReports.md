### Header row

#### Report
The report field is alphanumerical and can contain a maximum of 10 characters. Each report corresponds to a procedure. By using the Lookup The Lookup feature is a powerful search tool which allows you to search and load information from large registers. You open the Lookup feature by clicking on the dropdown button or by using F4 on your keyboard. feature (F4), you can load existing reports in order to edit them.

#### Name
Here you see/enter the name of the report. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Position in menu
Here you see where in the module menu the report is placed.
By using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you can select in which sub-module the report should be placed (as a separate procedure). The report will then be added at the end of the selected sub-module.
You can also enter a separated sub-module for the report. Such a sub-module is always added at the bottom of the existing sub-modules in the module where you choose to place it. You enter a menu text for the sub-module. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.
> When you have selected where in the module menu you want to place the report and saved, you must restart your Monitor ERP client or log out and log in again, to be able to see the report in the module menu.

#### Available
By using the ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) button you can determines to which users, user rights groups, or roles the reports should be available. You can also mark Available to all. This means all users can access the report. If you load an updated report, the settings will be kept.

#### Adaptation number
Here you see the adaptation number of the customized report. A customized report created by Monitor's adaptation department is assigned an adaptation number, but this is not the case for a report which you have created on your own.

#### Uploaded
Here you can see and download new customized reports that you have ordered from Monitor ERP System AB. Also modified reports are downloaded here. You can also delete a customized report.
The reports are visible here after they have been uploaded to Monitor's distribution server by the Adaptation department or by trainers/consultants.
When you have downloaded a report, it will be loaded to this procedure. You can then choose where in the module menu it should be placed as well as to which users the report should be available.
