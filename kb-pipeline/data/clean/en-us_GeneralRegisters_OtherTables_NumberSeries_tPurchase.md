### Purchase
Number series for Purchase.

#### Number series
The name of the number series.

#### Next number
Here you can see the next number that will be used in the number series.

#### Greatest number used
Here you can see the greatest number that has been used in the number series. It is useful to see if there is a need to adjust the number series in order for it not to clash with previously used numbers.
> Please remember that the number series for supplier invoices should have a gap of at least 1000 numbers between the lowest next number in the number series for on account payments. Conversely, the number series for on account payments should have a gap of 1000 numbers up to the number series for supplier invoice. If you enter a smaller gap, a warning ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png) appears in the Next number field.
