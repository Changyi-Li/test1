### Header row

#### User name
The user name is the login name in Monitor ERP. In order to create a new user account, you enter a user name that does not already exist. The name can also contain special characters and spaces. The name can have a maximum of 20 characters.
A new record is highlighted by a green dot ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/green_dot.png) shown in the field. This dot will disappear when the record is saved for the first time.

#### Description
A description of the user account, e.g. first name and last name or some other adequate description.

#### License
In this field you see the user's scope of license and license type.

#### Modify license settings
By clicking the Modify license settings button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_change_record.png) you access a window where you select license for a new user. You can also modify the license of an existing user. Please note! The button is inactive until a new user has been saved.
Here you can also check the Inactive box for a user license. An inactive user does not take up any license. If for example a user is on parental leave, you can set his/her user as inactive and instead register a new user for the substitute who will fill in.
You also see the Total quantity of licenses as well as Available quantity of licenses. This is displayed per license combination and as total in the company/group. You can also see license information under About in the desktop backstage.
By using the Selection button to the far left you select license combination of: Scope and License type.
- Scope – The available options are Group and Company.
- License type – The available options are Complete, Recording, Personal recording, External authorization, Machine terminal, API, and Daily management.
