### Link substitute order to case
It is possible to link substitute orders to cases. This means that you can plan, control, and follow-up on substitute orders. A substitute order can be a new order to customer/supplier or a manufacturing order for adjustment or new manufacturing of own manufactured parts.

#### Supplier nonconformity
If it has been determined that the supplier will make a substitute delivery, you must create a new purchase order. You should link the new purchase order number to the supplier nonconformity, so you can plan, monitor, and follow-up the substitute order.
You can see active cases under the Planning window tab in the Part register. If there are any active cases, you can see these by clicking the button Active cases.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/TrainingMaterial/BasicData_Case6.png)](../../../../Resources/Images/TrainingMaterial/BasicData_Case6.png)

#### Customer nonconformity
If it has been determined that you (the company) should make a substitute delivery to the customer, the customer order can be linked to the customer nonconformity, so that you can plan, monitor, and follow-up the substitute order.
Active cases are shown in the planning window in the Part register in the same way as the supplier nonconformity.

#### Internal nonconformity
If it has been determined that you (the company) must perform adjustment operations or do substitute orders, you can link these operations or manufacturing orders to an internal nonconformity, so that you can plan, monitor, and follow-up on it.
Active cases are shown in the same way as for the other nonconformity types in the planning window in the Part register.
