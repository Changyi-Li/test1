The number series GS1 code
If GTIN13 should be used, the following applies. GTIN13 is activated under the tab Other part identities in the Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Part procedure.
The number series GS1 code entered here is put together with a GS1 company prefix, which is entered in the Company information procedure. The company prefix is a combination of six to nine digits. If the company prefix consists of more than six digits, the first six digits should be entered as GS1 company prefix in the abovementioned procedure. The remaining digits in the company prefix should start the number series GS1 code plus a number of zeros for consecutive number. The number series should in total consist of six digits (hundreds of thousands).
In the Part register procedure you can then automatically generate a unique GTIN13 number for each part you are selling. This is made by using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_run.png) next to the GS1 code, in the Miscellaneous box under the Sales tab. A control digit is then added. All in all, the GTIN13 number consists of 13 digits.
