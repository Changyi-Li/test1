### Result
After you have loaded the list you will in the Result box see the selected quotes. You select which rows to include in the printout. When the printouts have been made, you can by activating the checkbox Approve select the quote printouts that you wish to approve with the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/StatusFinished.png). You can cancel by using this button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_cancel.png) and then you can make new printouts. If you approve the printout, that record will be removed from the regular selection. But it is still possible to reprint.

#### Include
In this column you determine if the quote should be included in the printout.

#### Status
In this field you see/enter the status of the quote.

#### Preliminary
Here you can see if the quote is preliminary.

#### Printing method
You can choose if the printout should be made to a printer or via e-mail.

#### Document variant
Here you see the document variant for the quote and it is possible to change variant for a specific quote.

#### Files
A button is shown here if there are any documents linked. In the window opened by the button, you can see all documents which will be included when printing.

#### Approve
In this column you can select which printouts should be approved. It appears after the printout has been made.
