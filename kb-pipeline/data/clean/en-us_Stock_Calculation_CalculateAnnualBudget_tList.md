### List
In the list you can see all quantities in standard units. The values are displayed in the company currency. The Year to compare to which you have chosen under the Selection tab, is in the list compared to the year you wish to update (Year to save to). The prices in the list do not consider staggering (the annual volume is not going to be sold in one single call/order).
At the bottom of the list you see a total of how many parts which have a new quantity.

#### Active
Here you can determine if the cause code is active or not. If the cause code should not be used anymore you can uncheck this checkbox. The cause code in question will then be hidden when reporting. However, you can still enter the specific cause code in fields where selection by cause code is made. This is done in order to create statistics for previous reporting of the cause code.

#### Old price
In this column you see the price saved in the budget from the year you selected under the Selection tab.

#### Old quantity
In this column you see the quantity saved in the budget from the year you selected under the Selection tab.

#### Old value
In this column you see the Old budget × selected price (converted to the company currency) for the selected year.

#### New value
In this column you see the New budget × selected price (converted to the company currency).

#### New quantity
Here you see the new quantity. It is loaded from the invoicing log. The current month is not used: if you select two months, the two previous months will be loaded (these will then be multiplied by 6 to simulate annual invoicing, please see the settings). This quantity is possible to change. If you have selected Manual input this column is empty and you can enter the new quantity.

#### Save
In this column you decide which rows you want to save.
