### Settings

#### Pre-select "Confirm"
With this setting you determine that the checkbox "Confirm” will be selected by default when you load the payment suggestions.

#### Payment date
This field is empty by default. In this case, the system suggests that the payment date during the confirmation is set to the date when the invoices should be paid. If you enter a payment date here, this date will be set on all invoices that are confirmed in the list.

#### Voucher text
Here you select the text that should be used as voucher text on confirmations that you register. The default text is “Outgoing payments”. In the Voucher texts procedure you can create texts to use as pre-defined voucher texts.
