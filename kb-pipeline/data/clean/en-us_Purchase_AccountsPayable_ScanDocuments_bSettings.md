### Settings
Here you configure scanner settings, select inbox, and start scanning.

#### Source
Select the alternative that best suits the type of scanner you have installed on the computer:
- Sheet feeder – Use this alternative if your scanner is a sheet feeder.
- Manual – Use this alternative if you are using a flat bed scanner.

#### Pages/invoice
If you select Sheet feeder as source, you can here enter the number of pages per invoice. Before scanning, you need to sort the invoices so that you scan all the invoices that only have one page separately, then those with two pages, etc. In the field, you enter how many pages there is per invoice in the batch you are scanning.

#### Scanner
Here you select the scanner that will be used. The driver and the scanner must be locally installed on the computer. The scanner must be TWAIN compatible in order to be used.

#### Inbox
In this field you enter the path to a folder on the computer or on a network resource. If you have registered inboxes under the Paths for inboxes tab, you can select an inbox. But you can also choose a folder by using the Browse button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_browse.png) to the right of the field.

#### DPI
Here you select the resolution (picture quality) of the scanning image. DPI is an abbreviation of Dots per inch. The default resolution is 200 DPI.

#### Color
In this field you determine if the scanning will be in black-and-white, gray scale, or color.
> A warning will be shown if you choose gray scale or color, since files like that take up a lot more space in the database. Remember that images with high resolution (DPI) also take up a lot of space.

#### Show scanner set-ups
With this checkbox you decide if the driver settings should be shown before the scanning starts. If you have selected the same settings as on the driver, you do not need to activate this setting.
