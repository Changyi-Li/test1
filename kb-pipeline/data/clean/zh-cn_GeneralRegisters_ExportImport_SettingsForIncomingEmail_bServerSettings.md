### 服务器设置
在此框中你配置服务器名称和轮询间隔。你还可以选择它是 Exchange 还是 IMAPEmail服务器。

#### 服务
服务类型可以设置为 交换， Exchange 在线， 或者 信息访问协议。
如果你将使用 Exchange Online，你在 Microsoft Entra 标识 （以前称为 Azure 激活 目录 ）中登记OAuth 2.0 的客户端程序。请参见 [本指南](../../BasicSettings/SystemSettings/GuideOAuth2.0.htm)。

#### 服务器名称
在输入你Email的 DNS名称或IP 地址。

#### 轮询间隔
在此处你轮询间隔，即MONITOR ERP 应多久检查输入服务器上的新建Email 消息。该间隔以分钟编号输入。

#### 应用程序 (客户端) ID
如果你已已选择 Exchange 在线 作为 服务。复制 应用程序 (客户端) ID 从 Microsoft Entra 标识中的客户端程序中值自，然后将其粘贴到这里。

#### 目录 (租户) ID
如果你已已选择 Exchange 在线 作为 服务。复制 目录 (租户) ID 从 Microsoft Entra 标识 （以前称为 Azure 激活 目录 ）中的客户端程序中值自，然后将其粘贴到这里。

#### 认证流
如果你已已选择 Exchange 在线 作为 服务。在这里你选择针对 Exchange Online 使用的认证流。有以下选项可用：
- 客户端密码 –如果你将认证流 客户端密码。必须在 Microsoft Entra 标识中已创建此客户端密码。
- 用户名 / 密码 – 如果你将使用 Exchange 帐户的用户名和密码，选择此认证流。目前，你此认证流时存在某些限制 -例如，如果管理员已将多重身份验证已配置为需求，则不全部使用 Microsoft Entra 标识 的组织选择支持条件访问和多因素验证。

#### 客户端密码
如果你已选择了 客户端密码 在上面的设置中。复制你在 Microsoft Entra 标识中已创建的客户端密码的值*，并将其粘贴到这里。这样做的效果是用户不输入密码。
> * 请注意！你待复制 值 将客户端密码客户端密码其他库位，与在 认证和机密 Microsoft Entra 标识页，然后能够将该值至复制到此字段。客户端密码在 Microsoft Entra 标识中也具有一定的有效期。这意味着你必须在有效即将到期时创建一个新建的客户端密码，然后将新建的客户端密码复制到这里。
