### Grouping/Posting

#### Customer group
Here you enter the customer group to which the agreement belongs. The customer group selected for the customer is loaded by default, or alternatively, the customer group for the selected delivery address. However, you can change customer group for the agreement in question by using the Change customer group button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_change_record.png). This is possible to do if the agreement has status Negotiation. The customer group together with the agreement type's posting group, determine the posting of the agreement rows. The customer group is handled in the Posting matrix procedure.

#### VAT group
Here you enter the VAT group to which the agreement belongs. The VAT group selected for the customer is loaded by default, or alternatively, the VAT group for the selected delivery address. However, you can change VAT group for the agreement in question by using the Change VAT group button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_change_record.png). This can be done if the agreement has status Negotiation. The VAT group determines the default VAT code on the agreement rows. VAT groups are handled in the VAT settings procedure.

#### Project
You can link the agreement to a project. If all agreement rows should have the same project number, you can enter it here instead of entering it on each row.
