### Links
Under Links in the backstage of the procedure, you can choose to create a "Monitor hyperlink" to the procedure in question by using Copy hyperlink to this procedure (Ctrl + K) ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png).
Another alternative is to create a "Monitor hyperlink" to the procedure in question with the loaded record automatically opened. This is done by using Copy hyperlink to this procedure and record (Ctrl + Shift + K) ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png).
The hyperlinks are in both cases copied to the Clipboard in Windows.
These hyperlinks can then be reused in Monitor chats, e-mails, etc. If you click such a hyperlink the procedure will open and also load the record in question if such a link was inserted in the chat.
