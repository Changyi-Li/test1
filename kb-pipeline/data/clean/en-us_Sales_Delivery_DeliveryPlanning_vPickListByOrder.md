### The list type Pick list by order
In this list you see the selected customer orders where you can choose to create a separate pick list for each marked order.
The following applies in calculation of net weight in the pick list:
- If the Available balance Available balance is the current part balance on the locations minus the cleared quantity. is >= Quantity to deliver, it means that the Net weight = Quantity to deliver x The part's weight
- If the Available balance is < Quantity to deliver, it means that the Net weight = Available balance x The part's weight
- If the Available balance is <= 0, it means the Net weight is = 0
Read more about the different sections of this list in the side menu.
