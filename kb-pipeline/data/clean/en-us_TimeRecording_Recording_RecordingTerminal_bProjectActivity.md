### Project activity
This tab is available if the option Project activity is allowed for you as way of selecting work in the procedure Personnel records – Time recording. Here you mark the activity you want to report time on.
The project activities you see here are the ones you are responsible for (your user) and the activities which have been assigned to your employee number.
Under the button Project ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_search.png) you can select a project and see all activities in that project. Here you can select one of the activities to include. The project activities which are not allowed (for you) are displayed with a warning symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png) and there is a tooltip for the symbol where you see this in text. These are activities which are not added to you via the setting Allowed project activities in the procedure Personnel records – Time recording.
> You can always report on project activities where you are entered as the person responsible and also for the activities which have been assigned to you, regardless of which activities have been added to you as allowed project activities.
The time which is reported for an activity is the time which passed from start to finish of the activity, when you set the activity to Finished when you stop work. It becomes a Direct project reporting which updates the time used on the project.
If you try to select an activity, which has one or several related preceding activities, that are not finished, you will be shown a message about this.

#### The Start button
Using the button Start you start the activity.
If you have the work method Only change the terminal will then change mode to where you can stop the previous work, unless you first chose to stop/finish that work item.

#### The Cancel button
By clicking the button Cancel you cancel the mode where you start work and the recording terminal reverts to the recording mode.
