### EIM Workflow
This tab is available if the option EIM Workflow is installed in your system. Here you can configure supplier-specific settings regarding EIM Workflow. These will then override the general settings configured in the EIM Workflow settings procedure.

#### Do not allow automatic final recording
Automatic final recording is by default allowed for all invoices from all suppliers in EIM Workflow. But you can choose not to allow it for the supplier in question by marking this setting. The invoices from this supplier will then have to be manually authorized and final recorded. When this setting is marked, it is shown in the Reason for authorization column in the Workflow lists in the Invoice overview – EIM procedure.

#### Allowed difference on price each, on row total, and on invoice total
Here you can configure settings regarding allowed differences for the supplier in question. Please see a [description](../../../GeneralRegisters/FinanceAccounting/EIMWorkflowSettings/tSettingsForMatchInWorkflow.htm) regarding these settings in the online help function for the EIM Workflow settings procedure.

#### Exceptions
Here you can add exceptions and configure settings for the exceptions for matching of extra invoice rows on invoices from the supplier in question. These exceptions and settings overrides the general exceptions which are available in the EIM Workflow settings procedure. Please see a [description](../../../GeneralRegisters/FinanceAccounting/EIMWorkflowSettings/tExceptions.htm) regarding the general exceptions in the online help function for that procedure. What is specific for the exceptions created here is described below.
Linked: This determines if the supplier exception is linked to the general exception. This is illustrated by the following symbol on the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png). When the exception is linked, and a setting is changed on the general exception in the above mentioned procedure, that setting will also become updated here. If something else is entered in that setting here, the link/connection will be broken and the button will display a different symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_broken_link.png). If you click the button, the link is recreated and the setting will become updated with the setting of the general exception. However, this does not apply to the settings Invoice's part number and Invoice's part name. These can be changed here on the supplier without the link/connection breaking.
Exception type: Here you select among the exceptions registered in the EIM Workflow settings procedure.
> If you have two different exceptions that have the same exception type, EIM Workflow will use the amount limit on the exception’s part number (if you have set an amount limit for invoice total). See the example below.
Example: Two exceptions that both have the exception type Freight are added to the same supplier. One exception should be matched against part number “FREIGHT” and the other to part number “DELIVERY”. Both exceptions have amount limits for invoice total of 100 EUR. Since the exceptions are to be matched against different part numbers, the amount limits will be interpreted as 100 EUR per exception, meaning a maximum of 100 EUR for the exception that is matched against “FREIGHT” and maximum 100 EUR for the exception that is matched against “DELIVERY”.

If you combine rows with part number “FREIGHT” for a total of 150 EUR and “DELIVERY” for 40 EUR on an invoice, the invoice will be sent for authorization since “FREIGHT” has passed the amount limit of 100 EUR. If the rows on the invoice instead match “FREIGHT” and “DELIVERY” for 80 EUR each, the invoice will not be sent for authorization, since the amount is below the respective amount limits of a 100 EUR.
Invoice's part name: If there is a part name for the exception in the above mentioned procedure, it is shown here. If you do not want to use that part name for the supplier in question or if you want to leave the field empty, it is not possible to just empty the field. You must instead use the wildcard percent %. The percent sign matches all part names which might occur on extra invoice rows. You can, for example, enter %pallet%. This will match all part names containing the word "pallet".
> If you do not configure any settings here but leave it empty, the general settings will be applied. If you add an exception here, the information will be shown in gray in the settings from the selected general exception. The settings can be changed if you want to apply something else for the supplier in question. If you do not want a general exception to apply for a specific supplier, you should add this exception here on the supplier and then uncheck the Active checkbox.
