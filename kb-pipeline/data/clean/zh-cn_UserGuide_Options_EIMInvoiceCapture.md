# 捕获/解释
捕获/解释被用于在电子发票管理 (EIM)选项中 Monitor ERP。此功能提供与 CrossState 的无缝链接，CrossState 是一种基于云的发票管理、扫描和供应商发票解释解决方案。
该解释促进并自动化了供应商发票的导入和登记 Monitor ERP。

#### EIM发票捕获的工作原理
无论您的供应商发票采用何种媒介（电子发票、PDF、EDI、纸质），都可以在 CrossState 中捕获。发票然后被已发送至 Monitor ERP 通过 同一渠道.
该功能的价格根据管理的发票体积基于，并每月已开票。
你可以选择在中间三种解决方案：
1. CrossState 中的内部发票捕获
通过此解决方案，你可以解释供应商发票中的数据并核实发票上捕获的数据是否正确。这是在 CrossState程序中完成的。当你已批准了所捕获的数据后，发票将右边发出，就绪已发送给 Monitor ERP。
如果你有大发票，并且有解释和验证发票数据的经验，则此选项适合您。你将熟悉创建定义和供应商模板等。
该解决方案需要在 CrossState 进行一到天数的培训。
此解决方案对于EIM 工作流选项是强制的。
2.外部的发票获取
使用此解决方案，你无需解释和核实供应商发票，日即可获得完整捕获的发票，就绪直接已发送到 Monitor ERP。
如果你拥有的发票数量小，并且否解释和验证发票数据的经验，则此选项适合您。
采用解决方案 1 时，每发票的价格较高。
3.内部发票捕获 Monitor ERP
通过此解决方案，你可以将 PDF格式的发票发送到特定的Email 地址。这些发票然后到达登记供应商发票程序，并自动加载发票的基础信息。你全部做的就是在保存发票之前核实解释的数据是否正确，并进行必要的变更。还有智能学习功能， Monitor ERP 自动向解释人员提供反馈，订单使未来管理发票时的解释过程更多智能。
此解决方案非常适合 EIM选项，因为该选项中的解释不层级行。对于EIM 工作流选项，当此解决方案用于费用发票时，你可以将此解决方案与解决方案 1 结合起来，而当此解决方案用于订单发票（行层级解释）时，您可以将解决方案 1 与解决方案 1 结合起来。

#### 无缝集成
MONITOR G5 通过 API 与 CrossState 无缝集成，否单独安装。你不与 CrossState 签署协议，因为该服务供应由 Monitor ERP 系统有限公司。
