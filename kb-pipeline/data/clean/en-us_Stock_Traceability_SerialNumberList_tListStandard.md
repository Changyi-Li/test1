### The Standard list
This list displays different information depending which of the following presentations you have selected.
General
With this presentation you see general information about serial number/batch number. Information such as revision, best-before date, charge number, batch number for serial number, and certificate, is also shown. You can also update these fields. Read more about this below.

#### Revision
Here you see the part revision that applied at the time of manufacturing or when purchasing the selected serial number or batch. It is possible to update the information in this field.

#### Best-before date
If the setting Apply best-before date is activated in the Stock box in the Part register procedure, then you can see and change the best-before date. This date is saved on the batch.

#### Batch number for serial number
If the part with the serial number is also linked to a batch number, this is shown here as <batch number> - <part number>. You can select among the batch numbers linked to the part number. You can link batch numbers to part and serial number, for example, when arrival reporting.

#### Charge number
Here you see the charge number that applies to the serial number/batch number. It is an identity that is used for the supplier who manufactured the batch. This identity always come from the supplier. For example, it can be the supplier's own batch number or, for example, a casting (ingot) number.
Reading
This presentation displays information about readings on serial number. The columns Distance, Operation time, and Number of cycles, show value readings. The values for Operation time and Number of cycles can be loaded from reported manufacturing orders if the serial number in question is included as a tool on these orders. This function is available if you have installed the Tools & Maintenance option. Values for all three readings can also be manually updated in the serial number register.
Origin
This presentation displays information about manufacturing order and purchase order that created the serial number/batch number. Information such as supplier, references, actual finish date and delivery date, and country of origin, is also shown.
Customer orders
This presentation displays information about the customer order the serial number/batch is delivered to. Comments and linked files are also displayed. You also see information such as customer, references, planned and actual delivery date, comments, and linked files.
Delivery address
This presentation displays information about the delivery address to which the serial number/batch has been delivered. The delivery address here is automatically loaded if the serial number/batch has a link to a customer order. Otherwise, information from the customer order will be shown if you entered the order number manually in the serial number register. If no order number has been entered, but a Customer has been selected, the delivery address is loaded form there.
Invoicing
With this presentation you will in the list see invoice information about the initial invoice. The invoice number displayed is the invoice on which the serial number/batch number in question has been invoiced. Information about invoice date, sales price and standard price, CM The contribution margin (CM) is the difference between the standard price and the sales price. and CR The contribution ratio (CR) is the portion of the invoice amount (sales price) that the contribution margin represents. CR is entered as a percentage., is also displayed.
Installation
This presentation displays information about installations. Information such as order number, installed by, installation date, code (connected to the installation), installation comment, is shown here, as well as linked files.
Status and Location/site
This presentation displays information about status of the serial number/batch number, as well as information about where it is located. Information such as status, block/notify, employee, department, and work center is shown. It is possible to update status, employee, department, and work center.
