### Print transport label
In this mode you can preview and print transport labels after you have stopped/finished a direct work item. This mode is only shown if it for the work center has been configured that transport label should be printed when stopping work and you have entered a reported quantity, or a rejected quantity when you stopped/finished work. If needed, you can here change the Reported quantity

#### The Print button
Using the Print button you can print the selected transport label.

#### The No printout button
Using the button No printout there will be no printing of transport labels, instead the terminal will revert to its basic mode.

#### Result
In this box you can see the transport labels which can be printed. Include is marked by default so the transport labels will be included in the printout. Here you can also select the format of the transport labels: Transport label – A4, Transport label – A5, or Label. If you want to print a different document variant than the default variant, you can select it on the column Document variant. The document variants are handled in the Document templates procedure. In the Number of copies field you determine the number of transport labels that should be printed. The default number of copies is determined in the Document settings procedure.

#### Preview
In this box you can preview the selected transport label before printing.
