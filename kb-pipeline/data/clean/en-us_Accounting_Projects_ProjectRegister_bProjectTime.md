### Project time
In this box you enter the planned start date and end date for the project. The length of the project is shown in number of work days.

#### Start date
The start date date is by default set to today's date when registering a new project. If there are activities in the project, then the first activity will get the same start date as the project.
If you change the start date and there are activities registered in the project, you will receive a question asking if you also wish to update the start dates and finish dates for the activities. If you answer Yes in that dialog, the start dialog of the first activity will be changed and all following activities will also receive new start dates.

#### End date
Here you enter the planned end date for the project. By default the planned finish date of the final activity will be shown here, if there are activities registered in the project. Otherwise the same date as the start date will be suggested.
If you change the end date and there are activities registered in the project, you will receive a question asking if you also wish to update the start dates and finish dates for the activities. If you answer Yes in that dialog then the finish date of the last activity will be changed and all preceding activities will also get changed dates. The start date of the project will indirectly be affected if you change the end date. If you change the end date a type of backward scheduling will be made based on the end time, that is, the activities will be planned back in time instead of ahead in time.
> Please note! A change of the end date of a project where the activities have been started will not result in a question about moving the start and finish dates for activities. A change of the project's end date will then only affect that specific date.
