### 系统设置
对于现金簿管理，你需要在通用下激活几个系统设置 会计 标签页。

#### 在同一程序 / 日记账中登记收款和付款
通过此设置，你可以决定是否应在同一程序中已登记收款和付款。这个程序称为 登记收款 / 付款 并且可以在采购和销售两者模块找到。你必须重启订单显示这些程序。你必须为付款日记帐登记一个凭证号序列并输入下一日记帐号。这是在 凭证号序列 / 日记账 程序。如果你使用批次号付款，则你在会计标签页下输入批次号的起始号码 编号序列 程序。

#### 使用现金帐簿功能
通过此设置，你可以决定是否在系统中使用现金簿功能。此功能主要针对东欧国家 / 地区，这些国家对于会计收到现金的处理有一定的规则。在现金簿中你登记现金提取和存款。这些可能包括与客户、供应商、员工或银行等之间的事务。此设置现金报告标签页 登记收款 / 付款 程序，你可以打印一个 现金收据 现金簿中已登记的每个事务。请注意！你必须在现金簿中创建付款方式 银行设置 程序。
此功能仅在系统已激活 在同一程序 / 日记账中登记收款和付款 已已激活。
