### Case types
There are four basic types for the respective case types included as standard. These basic types and case types are: Customer nonconformity, Supplier nonconformity, Internal nonconformity, and 8D Standard. You can also register own case types and link them to one of the basic types.
You can enter a Prefix of 1-3 characters and a Priority 1-9 for each case types. Check the Active box for the case types you wish to have active.
