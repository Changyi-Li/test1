# EIM 工作流
EIM 工作流是你可以添加到电子发票管理 (EIM) 的一个选项。EIM 工作流可实现发票流程自动化 Monitor ERP从登记，采购订单链接，审核，到最终的发票最终记录。

#### 有什么好处？
通过EIM 工作流对供应商发票进行电子管理，使流程更多简单、安全和高效。纳入 Monitor ERP， EIM 工作流是一款极其强大的发票管理工具。
只要满足条件， EIM 工作流就会自动匹配发票——你全部下班最终记录。通过完成匹配，可以自动进行最终记录，从而进一步简化流程。
EIM 工作流使你可以选择是否在页眉层级或页眉和行层级匹配发票。如果发现发票和采购订单在中间存在差异，则只需人工的将发票链接至正确的采购订单、到货和组件，即可进行匹配。

#### EIM 工作流如何运作
发票数据被已导入到EIM 工作流中 Monitor ERP 供应商发票被扫描并解释之后。发票信息的扫描和验证通过电子发票管理 (EIM) 中的发票捕获功能在 CrossState 云服务中进行。
然后，发票将自动与采购订单已匹配，两者页眉层级以及行层级（如果适用）。如果EIM 工作流检测到的偏差超出了系统设置中输入的范围，则会发送发票送至审核。
可以从系统设置中为特定供应商设定例外。
事件完成匹配（科目到任何例外和金额限制），发票可以直接已转发为最终记录。
如果发现偏差， EIM 工作流将主要将发票发送给在供应商登记中输入的审核人代码，其次发送给采购订单上注明的联系人。
如果这些链接无存在，你必须通过EIM 工作流中的审核列表人工的发送发票为审核。在此过程中，你还可以通过添加或删除审核人或简单地将发票转发给另一个审核人来更改审核列表，直接从收件箱或从你打开的发票中执行。
审核人将在收件箱中收到案件，只需单击简单即可直接管理发票。
否采购订单的发票（用于费用）将自动提交控制/审核。
一次最终审核人处理了发票，发票就会被已转发为最终记录。审核条款对发票所做的价格和过账调整将在最终记录时自动捕获，只需获得已批准订单关发票进行付款。
