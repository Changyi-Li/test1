### The Measuring templates table
Here you register the measuring templates.
The Measuring forms button on the function menu becomes activated when a measuring form is selected for the measuring template. By using this button you can go to the Measuring forms procedure with the form code in question already loaded.

#### Code
Here you see/enter a code for the measuring template.

#### Name
Here you see the name of the measuring template. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Form code
Here you see the measuring form for the measuring template. This is loaded from the Measuring forms procedure.

#### Frequency
The frequency describes how often measuring should be performed for the details which are manufactured. The following alternatives are available:
-   
First – Measure the first detail.
-   
Last – Measure the last detail.
-   
All – Measure all details.
-   
Sample – Perform random sample measures, measure Quantity of detailed with the entered Interval.
-   
Other – Describe the frequency and interval in text in the field called Frequency text. For example, "Measure first detail after change of material batch".
-   
Per order – Perform a Quantity of measuring per order. For example, if you enter 5 as the number of measuring times, and there are 100 details on an order. This means you will, e.g., measure the 20‎th, the 40th, the 60th, the 80th, and the 100th detail.

#### Quantity
Here you enter the number of details to measure when Frequency is set to First, Last, or Sample.

#### Interval
Here you enter with which interval of manufactured details, measuring should take place when Frequency is set to Sample.

#### Frequency text
Here you can enter a descriptive text for measuring when Frequency has been set to Other.

#### Type
Here you decide if the measuring template should be available to use in the Purchase module, in the Manufacturing module, or both.
