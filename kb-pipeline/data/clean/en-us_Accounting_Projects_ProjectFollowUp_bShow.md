### View

#### Date
Available for the periodic lists. Here you select which date interval should be shown in the list. In the To field, the last day of the current period is suggested by default.

#### Date alternative
Available for the periodic lists. With this setting you determine if the actual date or the log date should be used for results referring to reporting on order. You choose if it should be the date of the reporting (log date) or the date entered for the reporting (actual date).

#### Print result tabs
Available for the list WIP value. Here you decide which tabs should be printed. When you are in the List tab you can preview the printout using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_preview.png). Under the Selection tab you can modify this setting afterwards. If you close the preview and then reopen it, the view will become updated. This means you do not have to reload the list in order to include or excluded tabs from the printout.

#### Rounding
With this setting you determine how the rounding of amounts should be made: Integer, Two decimals, or Thousands The option you select here can make it possible to show reports with many columns in a compact way.

#### Show
Here you determine if contribution margin and contribution ratio should be shown.

#### Only main/sub-projects
With this setting you decide if you only want to load projects which are main or sub-projects, the other projects will be disregarded.
