### The Change signer list
This list is used to move invoices from one signer to another. The list displays invoices with status Sent for authorization. It is also possible to include future signers.

#### Consecutive number
For a credit invoice the consecutive number is displayed in red.

#### Signer code
The signer code determines which signer/signer group has been selected for the invoice. In this column you can change who should authorize the invoice.

#### Handling time
In this column you see the time (in days) that the invoice has been handled. Handling time is shown for all records, including the ones that have not been handled yet (0 days). If the invoice was received by the signer 2017-01-01 and action was taken/it was handled 2017-01-02, you will see 1 day in the column handling time. If it is a future record, this field will be empty.

#### Due date
The due date is shown in red if it is less than five days until the invoice becomes overdue.

#### Parallel authorization (P)
Here you can see if the invoice can be authorized in parallel.

#### Signer group
This box is checked if the signer for the invoice in question is a signer group.
