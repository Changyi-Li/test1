### Database patch
Here you install database patches which you have received from a support agent at Monitor ERP System AB.
The database patch is a file (with the extension .mql) which contains an SQL script created for this specific case.
> Please note! You should first test that the database patch works as intended by installing it in a test company. This should be done before you install it in the actual/live company!
How to install a database patch:
1. Make sure you are in the right company! Try the database patch in a test company the first time.
2. Load the file by using the browse button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_browse.png) next to the File field. In the Created field you will then see information about when the file was created.
3.    
Install the file by using the Install patch button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_run.png) found on the toolbar of the procedure. The SCL script in the file will then be run and the database patch is installed. In the Result field you will see the result of the installation.
> Please Note! The database patch is saved directly in the company database when you install it. It is not possible to back the installation!
