### Monitor 搜索
在里面 调用Monitor 搜索 字段（Ctrl+F），在标题，你可以查找整个系统中的记录。
搜索以你要搜索的短语开头的记录。例如，如果你类型“123”，你获得所有记录的匹配结果，无论它是订单号、组件号、客户号、协议编号、帐号等。
你还可以通过输入登记名称（英语）并在你搜索的内容之前输入冒号作为搜索短语来查找某个登记中的记录。例如，要在客户订单登记中查找“123”，请在搜索字段类型“customerorder:123”。
低于表格显示了你可以使用上面方式查找记录的登记列表。
| 登记 | 搜索短语 |
|---|---|
| 组件 | 组件： |
| 客户 | 客户： |
| 供应商 | 供应商： |
| 客户订单 | 客户订单： |
| 采购订单 | 采购订单： |
| 工单 | 制造顺序： |
| 工作中心 | 工作中心： |
当你执行搜索时，包含全部匹配项的行显示在结果窗口中（见低于）。最多可显示 1,000行匹配项。在结果窗口中，你可以按全部数据、基础数据、订单、供应商发票、案件和/或凭证筛选记录。你还可以按记录的已创建时间筛选：任何时间、今天、最近一周或最近一年。你还可以根据记录的已创建筛选：任何人或你。
还可以通过将一个列标题拖放到其它两个列标题在中间来移动结果窗口列表中的列。你也可以双击列表中的一条记录，然后单击 转到 按钮 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_link.png) 按 相关程序打开该记录.使用按钮 复制至剪贴板 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/UserGuide/button_copy.png) 你将列表中的所有记录复制到监视器的 剪贴板 以供其它列表程序进一步用于。

#### 使用通配符搜索
| 表达 | 解释 | 例子 |
|---|---|---|
| * | 将查询以星号之前的字母开头的全部单词。你可以在除作为首证书之外的全部位置使用星号 (*)。 | ca* 的结果是搜索点击数car、cabin、cabinet，但不railcar 或 side car。 |
| ? | 将替换特定位置的证书。 | f?ll 的结果是 fall、full 和 fill。 |
> 请注意，结果窗口中匹配的行基于三个标准进行排名和排序： 关联 – 如果你查找的短语结果完全匹配，则其排名会比短语仅匹配文本的组件时更高。 数据类型 – 对于某个组件，组件号和名称的排名高于全部其它字段。对于客户来说，排名最高的是客户号和名称。 角色归属 –例如，如果你属于以下角色 销售员，客户和客户订单的排名会更高，如果你属于该角色 买家，供应商和采购订单的排名将会更高。 这种排名和排序的目的是为了强调你更多可能查找的数据。无论这些标准如何，点击数都将相同。它们仅影响排序。 搜索索引每 10分钟是已更新，以包括新建的变更。
