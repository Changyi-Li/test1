### Customer orders
In this box you see which customer order was the initial order when the serial number/batch was sold for the first time. You also see information from customer orders created from agreement.

#### Order number
In this field you see the order number to which the serial number/batch is linked. The order number is shown in this field if the loaded serial number/batch was entered on the customer order row when the order was created or delivery reported. If you manually select an order number here the fields Customer, Our reference, and Customer's reference will be filled automatically with data from the order.

#### Planned delivery date
The planned delivery date is displayed if the serial number/batch is linked to a customer order row. If the order number is manually entered, no date will be given here.

#### Actual delivery date
The actual delivery date shown here is loaded from the delivery log once the serial number/batch is delivery reported.
