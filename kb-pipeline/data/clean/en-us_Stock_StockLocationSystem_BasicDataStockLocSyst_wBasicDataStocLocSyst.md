## Basic data – Advanced stock management
In the Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Advanced stock management procedure the settings for the different storage types in the warehouse must be configured for when you use the Advanced stock management option. Among other things, the coordinate structure is constructed here. You can also create templates for size and weight restrictions for locations.
> It is important to carefully consider the design of the structure before you start configuring these settings.
> Please note! You need to generate locations in the Generate locations procedure before you can use Advanced stock management. Use the location coordinates which you create in this procedure as a template/starting point when you generate locations. The format of the coordinates and the location names will then match. The total number of characters for a coordinate is 35. This is made to match the maximum number of characters in the Location field.
Read more about [Advanced stock management](../../../UserGuide/Using/StockLocationSystem/StockLocationSystem.htm) under Using Monitor in the online help function.
