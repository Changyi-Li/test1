### FAQ – Order inflow
Why do I have negative records in the Order inflow procedure?
This means that the quantity and/or the price of the customer order has been changed. It can also happen when a credit invoice has been created.
Whatever you change or remove on the customer order is registered on the log date.
Whatever you add to (new row) on the order is registered on the order date.
If you use the Adjust order inflow­ button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_copy_to.png) in Register customer order, all the changes you make to the order are registered on the order date. In the Order inflow procedure, you are then able to select the Grouped by order date presentation.
Can I adjust the order inflow of a customer order?
Yes, using the Adjust order inflow button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_copy_to.png) in the function menu in Register customer order. With this button you can adjust order inflow for a separate order row or for the entire customer order. When you adjust the order inflow the records in the current order inflow will be removed and new records created using the customer order’s current information such as price, quantity, discount, and order date.
Can I delete a customer order from the order inflow?
Yes, using the ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_delete.png) Delete button on the toolbar in Register customer order. You can then select Delete order inflow in the dialog window that opens by marking the checkbox. Please note that the checkbox only activates once the Delete checkbox has been ticked.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/TrainingMaterial/Delete_CustomerOrder.png)](../../../../Resources/Images/TrainingMaterial/Delete_CustomerOrder.png)
> You can delete an order as long as it is not included in a pick list (status 4) or partially delivered (status 5).
