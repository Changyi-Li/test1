### Settings – CRM
Here you configure settings concerning CRM for the customer. Data must be configured in the procedures Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – CRM, Probability codes, and Personnel records. Much of the information is also used as selection terms in different lists.

#### Customer status
The default status for a new customer is 1, Actual customer (orders can be registered). For other status levels you will see the symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png) next to the customer name on the main row. A tooltip over this symbol explains that the customer is not an actual customer, and therefore, orders cannot be registered.
If the customer has status 1 you will see the text Date, actual customer below the field. The date when the customer most recently got status level 1 is also shown (if the customer e.g. had status 1, then was set to status 2, and later got status 1 again).

#### Number of employees
Number of employees can be used to generate statistics. The intervals are loaded from the Basic data – CRM procedure.

#### Seller
Here you select the person who is the seller for the customer. You can select among the persons marked as Sellers in the personnel records. By clicking the ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) button to the right you can access contact information for the seller. You can also open the chat function called Monitor chat by clicking the ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/buttonChat.png) button. There you can send chat messages to the seller. To be able to use the Monitor chat, the logged in user has to be linked to an employee.

#### Responsible for customer
Here you select who is the person responsible for the customer. You can select among the persons marked as Responsible for customer in the personnel records. By clicking the ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) button to the right you can access contact information for the person who is "Responsible for customer". You can also open the chat function called Monitor chat by clicking the ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/buttonChat.png) button. There you can send chat messages to that person. To be able to use the Monitor chat, the logged in user has to be linked to an employee.

#### Type
Here you select the customer type to which the customer belongs. The customer types which can be selected must be registered in the procedure Basic data – CRM.

#### District
In this field you select to which district the customer belongs. It can be used as a selection term in different lists.

#### Probability
Here you can enter how probable it is that this customer will become an actual customer, that is, the probability that you will "get" the customer. This field can be edited as long as the customer is not an actual customer (status 1).

#### Reseller
Here you can select a reseller that can be tied to the customer. A reseller/retailer can be given a certain commission in percent. Resellers must first be registered in the Basic data – CRM procedure.
