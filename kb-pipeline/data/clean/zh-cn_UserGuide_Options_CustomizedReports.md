# 定制报表
此选项用于创建定制报告 Monitor ERP。这些报告是根据您的需要设计的。

#### 什么是已定制的报告？
已定制的报告可以最好地描述为具有 SQL 查询形式的自定义设计的定制列表程序，具有其自己的选择条件、设置和布局。
当你安装了选项后 Monitor ERP，你可以访问通用登记模块中的定制报表程序。你在此处创建定制报表。在此程序中，你还可以选择模块菜单中的 Monitor ERP 报告应放置在何处，以及报告应向哪些用户可用。
MONITOR ERP 系统 AB根据您的要求创建定制报表。然后，你可以使用此程序安装并将报告放置在模块菜单中，以及配置对报告的访问权限。
如果你想自己创建定制报表，你必须：
- 了解监视器数据库表和列的名称。
- 知道如何编写 SQL问好。
- 了解如何工具报告 DevExpress报告设计器 （当为报告已创建自由格式布局时）。
