### Header row
This help section describes the header rows in the Report manufacturing order and Report operation procedures. Here you select the report number to report. In the Report manufacturing order procedure you can also choose if you wish to report based on an order. On the header row you can see comments and files linked to the order, the main part, and the operation. You can also configure different settings for the reporting.

#### Order number
(Report manufacturing order) Here you can enter the order number to report on the operations in a manufacturing order. Then you will see the order in the structure map with the main part selected and expanded.

#### Report number
Here you can enter the report number to go directly to a specific operation in an order. The order is loaded and you will see information about the operation. In the Report manufacturing order procedure, you will see the operation marked in the structure map.

#### Time unit for reporting
In this field you select hours, minutes, or seconds as unit. It will determine the time unit for the reporting.

#### Suggest remaining quantity when reporting
This system setting determines if the remaining quantity should be suggested in the Quantity to report field. This will apply to all the included operations of the part when reporting. You can choose if this setting should be activated by default by using the system setting with the same name.

#### Suggest planned time for reported quantity
This setting determines if the planned time should be suggested in the Time to report field. This time is based on the reported quantity for all the included operations of the part when reporting. You can choose if this setting should be activated by default by using the system setting with the same name.

#### Automatic withdrawal of material
This setting determines if the planned quantity should be suggested in the Quantity to report field for included material according to the operation to which it belongs. If you have activated the system setting Automatic withdrawal of material, the setting will be checked by default. In the Report operation procedure, the same setting will be activated by default and grayed out, that is, you cannot uncheck it to deactivate the setting Automatic withdrawal of material.

#### Automatic reporting of tools
This setting is available if the Tools & Maintenance option is installed. With this setting you decide if withdrawal of tools should be made automatically. If the system setting Automatic reporting of tools is set to Yes, this setting will be checked by default.
If the system setting Return reusable tools when return operation is reported as finished is set to Yes, a withdrawn tool will automatically be returned when you report the operation (to which the tool is linked) as finished. If that system setting is set to No, you will instead have to return the tool manually in the Withdrawal list procedure.
