### Fields
In this table you add extra fields that will be available in the basic data register in question.

#### Field name
The field name of a main row will be the heading of the box which the main row results in. The field name of a sub-row is the heading text for the extra field. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Explanation (tooltip)
Here you enter a description text for the extra field. The text is only displayed in this table. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Type
Here you select the type of extra field. The available options are:
- Text field – An alphanumeric field which can hold several thousand characters.
- Integer – A numerical integer field.
- Decimal number – A numerical decimal field that can contain 2–6 decimals.
- Date without time – A date field, only date.
- Date with time – a date field, both date and time.
- Comment – A comment field, a field with a text editor used to enter comments, etc.
- Selection list – A field with a drop-down menu containing the alternatives of register data added in the table to the right. By using the selector in this field, you choose one alternative.
- Multiple selection list – The same as the alternative above but here you can choose several alternatives.
> If an extra field is used (has a value in a record in some register), you cannot change type. A dialog box appears if you try to change type. There you see where the field is used and in which record.

#### Identifier
This column is only available if you have activated the system setting Show identifier for external programs (Extra fields). Here you can enter an identifier for the field using a maximum of 12 characters. The identifier is used to find the specific extra field in external programs during different data exports or in adaptations.

#### Show on order
This column is only shown under the following tabs: Orders – Sales, Order rows – Sales, Orders – Purchase, and Order rows – Purchase.
Here you mark which orders or order rows the extra field should be added to. If you want the fields to be visible on documents, you need to create document variants and add the field in the Document templates­ procedure.
