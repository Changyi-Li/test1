### Monitor ERP printer dialog
In Monitor ERP there is a built-in printer dialog. This printer dialog allows you to control combined printouts which consist of both documents and linked files in different formats and orientations (portrait/landscape) and that are printed on different printers.
For example, if you have a manufacturing order that have a file containing a drawing in landscape A3 format linked to an operation, then you can print that file to an A3 printer while the shop packet is printed in portrait A4 format on a different printer.
Combined printouts are common for manufacturing orders. For a manufacturing order you can print the shop packet (traveler, operation document, and material document) together with linked files on order, part, operation, and material. The linked files should be set to Automatic printout and to be printed on the Auto printer or on printer External 1-3. Read more about [linked files and automatic printout](GeneralFeatures.htm#LinkFiles).
For the printer dialog you can configure how and when shop packet and linked files in manufacturing orders should be printed. The printout order is determined by the system setting called Printing of linked files found in the [Orders](../../GeneralRegisters/BasicSettings/SystemSettings/bOrderManufacturing.htm) section under the Manufacturing tab in the System settings procedure.
You can override the printout order per user with the corresponding setting in the Users procedure.
You can also override the printout order per printout using the corresponding setting in the Register manufacturing order, Print manufacturing order, and Register maintenance order procedures.
The printer dialog also sorts the printouts of the Transport label – Package structure. This makes the transport labels for each package print in the correct order in the package structure and you don't have to manually sort the the documents after printing. Different number of copies of each transport label is also managed by the printer dialog.
At the time of each printout you can, in the printer dialog, also deselect documents and files which should not be printed, if any. The default setting is to print all documents and files.
There is support for the Monitor ERP printer dialog in procedures where there are combined printouts or a need to sort printouts.
The Monitor ERP printer dialog is activated by default.Under Printouts in the desktop backstage it is possible for you to deactivate the printer dialog (module by module), and instead use the Windows printer dialog.
