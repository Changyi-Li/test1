### Variants
This box works in the same way as the [Variants](../DocumentTemplates/bVariants.htm) box in the Document templates procedure. However, there are more functions for the variants on manufacturing order documents.

#### Adaptation number
Here you see the adaptation number for the document variant in cases where the variant has been created by Monitor ERP System AB. The adaptation number is also displayed in the section where you preview the document in the affected procedures. The purpose is to be able to separate the variants created by Monitor and the variants you have created on your own.
If/when you add own variants they will not be assigned an adaptation number.

#### Comment
Under the button Comment ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_no_comment.png) you can enter an internal comment for the document variant.

#### Files
Under the button Files ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_file_link.png) you can link external files to the document variant. If you link several files, you can choose which file should be selected by default. You can choose if a file should be printed automatically together with the document variant. You can also choose printer and orientation. Printer Auto means that the printout will be made to the same printer as the manufacturing order (document variant). The printers External 1–3 mean that the printout will be made to printer External 1, External 2, or External 3 selected for the user in the Users procedure.

#### Active
This checkbox determines if the document variant is active and thereby can be used when printing manufacturing order documents. An inactive document variant cannot be selected in procedures where you can print manufacturing orders.
