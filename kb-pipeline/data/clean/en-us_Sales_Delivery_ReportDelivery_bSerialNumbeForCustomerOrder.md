### Serial number for customer order
In the box Serial number A serial number is a number that is used for traceability for parts on entity level. for customer order you can add serial numbers to the parts which should be delivery reported on the order row. You can import serial numbers from a text file using the ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_import.png) button, called Import serial numbers.
If it has been configured on the part that serial number should be created At registration of order, then you will here see the created serial numbers. Then you can mark the serial numbers you wish to deliver. You have to check the same number of serial numbers to deliver as exists on the order row.
If it has been configured on the part that serial number should be created When reporting delivery and configured that number should be entered Manually, you must here enter a start value for the serial number and how many should be delivered, and the end number will be calculated automatically. If it has been configured that number should be taken From number series, the correct number of serial numbers will automatically be added from the number series.
The system will keep track of the serial numbers you deliver on the order row. If you make a partial delivery of e.g. 7 pieces on an order row where the planned quantity is 10 pieces, the first 7 serial numbers will be registered as delivered. When the next partial delivery is made (3 of 10), the system will suggest to deliver the 3 serial numbers that are left. You cannot deliver a serial number that is already delivered.
Delivered serial numbers will be updated with the actual delivery date in the register (Serial number/Batch A batch is the set of components/products manufactured at the same time and made from the same original material.).
Excess delivery is not allowed on order rows which already have serial numbers. Deleting remaining quantity on order rows that already have serial numbers will delete the residual serial numbers from the register.
If it is a stock order you are about to deliver, then the button is deactivated. Serial numbers are not used on stock orders.
When needed, you can enter a Remark for the serial number.
> Please note! If the part on the order row has traceability on Serial number leve, a serial number will be created for each entity of the part when arrival reporting on location. This can take place when purchasing and when manufacturing. In that case you should instead choose serial number in the Location box.
