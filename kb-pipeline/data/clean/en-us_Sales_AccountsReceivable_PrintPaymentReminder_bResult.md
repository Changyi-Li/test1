### Result
In this box you see all customers loaded using the selection and settings. With the checkbox Include you decide which documents you want to print/send. In the box to the right, you see a preview of the record selected in the list. In the Printing method column you select if printer or e-mail should be used. The system suggests printout method based on the setting Print payment reminder via in the Customer register procedure.
When you have printed or sent the records via e-mail, they are saved. If you are happy with the printouts you can approve the rows with the Approve button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/StatusFinished.png). You can make a new printout of the row if you first click the Cancel button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_cancel.png). You can then print/send using the same printing method or you can select the other one. You can also cancel this step.
At the bottom of the box you will see a total of the list.
