### Manual withdrawal and return
To keep track of tools that are not linked to BOM and routing but are withdrawn to different persons, you find functions used for manual withdrawal and return of tools in the procedure Report withdrawal of tools.

#### During withdrawal, you must select an employee number in the field Withdrawn to and an Expected return date. You add a row in the box Withdraw and select the tool in the field Serial no./Batch no. (if the tool has serial number) or in the field Part number. Then you save.
1. When the tool is returned, you can select an employee number. Then all withdrawn tools for the employee in question will be displayed. The button [![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/gridEmployeeImage.png)](../../../../Resources/Images/gridEmployeeImage.png) on the function menu will then be activated. If you deactivate the button or if you do not select an employee number, you will see all employees' withdrawn tools. You can minimize the Withdraw box in order to give more space to see withdrawn tools in the list. You return tools by entering the quantity and then you save.
2.   
Withdrawn tools can also be displayed and monitored in the Withdrawal list procedure. There you can also report return by selecting Return in the list. You can also see and select to which location Loc. ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) the return should be performed. When you save, the return will be executed for the tools you have selected to return.
1.    
Save.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/TrainingMaterial/ToolsWithdrawal.png)](../../../../Resources/Images/TrainingMaterial/ToolsWithdrawal.png)

#### Returning tool in Report withdrawal of tools
1.   
When the tool is returned, you can select an employee number. Then all withdrawn tools for the employee in question will be displayed. The button [![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/gridEmployeeImage.png)](../../../../Resources/Images/gridEmployeeImage.png) on the function menu will then be activated. If you deactivate the button or if you do not select an employee number, you will see all employees' withdrawn tools. You can minimize the Withdraw box in order to give more space to see withdrawn tools in the list.
1.    
You return tools by entering the quantity to return and then you save.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/TrainingMaterial/ToolsReturn.png)](../../../../Resources/Images/TrainingMaterial/ToolsReturn.png)

#### Returning tool in Withdrawal list
You can also choose to show withdrawn tools and monitor them in the Withdrawal list procedure.
1. Report the return by marking the Return box in the list. You can also see and select to which location Loc. ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) the return should be performed.
1.    
When you save, the return will be executed for the tools you have selected to return.
