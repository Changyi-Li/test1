### Settings (General)
In this box you configure general settings for the report.

#### Show only charts
With this checkbox you determine if only charts should be shown in the report.

#### Orientation
With this setting you decide if the report should be in portrait or in landscape orientation.

#### Size
With this setting you decide the paper size to which the report should be adapted. The default size is A4. This means the report will be adjusted to be printed on the paper size A4 of the selected orientation. You can choose A3 to fit additional columns to the printout of the report.
In the Print accounting report procedure you can also choose whether or not a line break should be made for columns that are too wide to fit on the printout.

#### Report configuration – Header
Here you select which header variant to use for the report document Accounting report, if there are more than one variant of that document registered in the Document templates procedure.
By using the button Edit document configuration ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_xtrareport_designer.png) you open the document in the program DevExpress Report Designer. This is a third-party tool which is included in Monitor ERP for document design.
> Read more in the section [Functions in document templates](../../../UserGuide/GeneralFeatures/DocumentFunctions.htm).

#### User rights to view/print
By clicking the button called User rights to view/print, you can configure if the report should be available to all, or if the availability should be limited by group, role, or user level. The Available to all checkbox is marked default.

#### Margins
Here you configure margins for left, right, top, and bottom of the report. You enter the values in millimeters (mm).
