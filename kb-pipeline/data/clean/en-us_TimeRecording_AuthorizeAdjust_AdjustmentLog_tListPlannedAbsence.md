### The Planned absence list
In this list you see planned absence, adjustments made for such absence, and also if it has been authorized. The adjusted information is shown in boldfont.

#### Type
Here you see which type of adjustment has been made. New records have the type Created. Records which have been updated have the type Updated. Records which have been removed have the type Deleted.

#### Employee number
In this column you see the number of the employee for which the row applies. The list is sorted by this number.

#### Log date
Here you see the date and time when the adjustment was saved.

#### By
In this column you see the user who registered the planned absence or who made an adjustment regarding it.

#### Planned start and Planned end
Here you see the planned start of the absence and the planned end of the absence. The row marked with Old shows the old absence before it was adjusted. If no such previous recording exists, then the row will be empty. The row marked with New shows the new and adjusted absence. The row is empty if the adjustment consists of a deleted planned absence. The rows Old and New also apply to the Authorized column.

#### Absence code
Here you see the absence code and the name of the absence for the planned absence.

#### Authorized
In this colulmn you see a checked checkbox if the planned absence has been authorized.
