### The General list
At the top of the list you see projects which for some reason need to be checked. These are shown together with a warning and an explanation. It can, for example, be a project where the stage of completion falls outside the interval 0-100% or if the project shows a loss if you apply fixed price.
When a project is marked with "Include" it is possible to edit forecast values and the stage of completion (if the corresponding system setting has been activated). These changes will affect the calculation of the stage of completion and the calculated recognized income.
> Please note! When saving, the forecast in the Project register is automatically updated for the project in question. You can see how the project is removed from the list as soon as you save. However, you can always load it again for the same period as long as the journal has not been reset.
If you want to undo edited forecast values, mark the row and reset the forecast values by clicking the Undo button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_cancel.png) in the function menu. After you have saved your changes you cannot reset the forecast values. In that case, you need to change them manually after you again loaded the project in the list.

#### Calculation of the column called Result after calculation
Result after calculation = Result, income - Result, cost + Recognized income
