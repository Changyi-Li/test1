### Zip code register
- You can create zip code registers manually by adding rows and entering information about zip code, city/province, state/region.
- It is also possible to import zip code registers from a text file which you in that case load from a supplier offering this. For Sweden there is a supplier called [Postnummerservice](https://www.postnummerservice.se/).
> Please note! Swedish zip codes are no longer included in the procedure at installation.
