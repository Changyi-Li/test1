### The Generate locations list
In this list you can generate location names of existing stock locations in the part register.
Check the box Save for the locations whose names you want to generate. The names are saved in the location register when you click save in the procedure.
You can also choose to block a location name in the list. Here you can choose if one or multiple parts should be allowed per location name. The location names that are used on more than one part already allow multiple parts. You can also enter a comment for each location name. These settings can also be configured afterwards on generated locations in the Locations procedure.
