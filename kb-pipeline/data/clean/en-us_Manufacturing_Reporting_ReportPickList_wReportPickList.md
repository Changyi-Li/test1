## Report pick list
In this procedure you can report material withdrawal on manufacturing orders for the material for which you at an earlier stage have printed a pick list. The material must be linked to a pick list number in order to be able to report the material.
You go to this procedure from the Pick listA pick list is a list of parts/products which should be picked from stock for a manufacturing order or a customer order. procedure by using the button Go to procedure. In that procedure you select material rows which you use to create a pick list. When you load the selection of material rows you will see the result in the List tab. From this list you select which material rows you want to include on the document which you can print. When saving, the material withdrawal will be reported for the manufacturing order and in the manufacturing order in log. A stock transaction log is created for these transactions.
Material rows with a suggested material withdrawal from pick location, or pick location for work center, are shown in italics.
When saving, the material rows and their quantity are reported for the manufacturing order. Manufacturing order log and a stock transaction log are created.
