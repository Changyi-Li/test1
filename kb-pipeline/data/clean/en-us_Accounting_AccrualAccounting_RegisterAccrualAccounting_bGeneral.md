### General

#### Start date
Here you enter the start date which is the date when the accrual should start. That is, as of which date it should be recorded/released. Today's date is shown by default. The start date is saved in the accrual and it also affects the table in the box Period allocation, which accounting period which should be at the top of the table. You cannot select a start date in a closed earlier period. However, you can select a date in a future closed period. It is also not possible to select an accounting year which is not registered. You can change the start date before the release of the accrual is started.
Start date, number of periods, and end date, are not available for accruals of the Reversal voucher type.

#### Number of periods
In this field you enter the number of months the accrual accounting should span. It is not possible to enter more months ahead than what exists in the current and future registered accounting years. Registration of future accounting years is made in the Register accounting year procedure.

#### End date
In this field you see the end date for the accrual. This is determined by the start date and the number of periods you have entered.

#### Voucher date
The field called Voucher date is only available for accruals of the Reversal voucher type. Here you see the date when the accrual accounting should be recorded (reversed). A reversal voucher only has one period meaning start date and end date is the same date.
