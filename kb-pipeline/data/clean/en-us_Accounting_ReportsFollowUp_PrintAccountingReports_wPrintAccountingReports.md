## Print accounting report
In this procedure you load and print different reports from the Accounting.
When the system is delivered to you, there are complete balance reports (with or without dimensions), balance sheets, income statement, etc. You can also create you own customized reports and then print those here. These reports must first be created in the Create accounting report procedure.
The data which the reports are based on is balances in the accounting and can be printed for all dimensions in the system. You can also click your way from a balance to view the underlying transactions and documents which the balance is based on.
The system also supports graphic display in reports. This requires you to have a report which has been constructed for this type of presentation.
> You can automate the running of this procedure with the Agent option. Read more about [The Agent](../../../UserGuide/Options/Agent.htm) can help make your processes more efficient.
> Please note! The Clipboard function is not available under the Selection tab in this procedure.
