### The list type Total by cause code
This list shows one row per cause code. In the chart you see each cause code as a separate bar. By default, the Share, quantity % is the value which is displayed. With the function button Chart ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_chart.png) you access settings used to handle the chart.
In the column Share, quantity % you can see how large a share each cause code has of the total number of quotes. In the Share, value % column you can see how large a share of the total value that each row represent.
