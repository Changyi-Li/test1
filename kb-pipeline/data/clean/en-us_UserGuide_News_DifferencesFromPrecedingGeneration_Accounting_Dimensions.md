### Dimensions
- This procedure was in G4 called Cost Center / Cost Unit. Here you create codes and names for the different dimensions in the system.
- A major new feature is that you can register which dimensions to handle in the system. It is possible to handle a dynamic number of dimensions, up to eight dimensions in addition to Account. You can link dimensions to different registers in the system, so this is automatic in the posting. For example, to create dimensions relating to Department, Customer, Part and Employee, etc. In G4 it was a fixed number of dimensions (three dimensions).
- It is possible to enter what each respective dimension should be called. In G4 it was not possible to change the names of the dimensions (Center, Cost unit, and Project).
