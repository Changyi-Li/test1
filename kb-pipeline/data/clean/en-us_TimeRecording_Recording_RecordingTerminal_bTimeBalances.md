### Time balances
In this box you can see your different time balances, displayed in number of hours. Via the More info buttons ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you can open a window where you can see log records for the number of days back in time which you have selected. With the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_show_hidden.png) on the function menu you can show/hide your time balances. Time balances are shown in red if they exceed or fall below the allowed time limits.
