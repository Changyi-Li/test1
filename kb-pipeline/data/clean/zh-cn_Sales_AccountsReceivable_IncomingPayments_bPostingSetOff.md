### 过账
在此框中，你可以看到你选中行的默认过账 抵销。
过账方式
在全部场合下，每条过账记录都会已创建每付款记录。在过账记录中，应收账款/应付账款总是已记录在过账的一。在过账的其它端，将使用一个临时科目。此科目的目的是为了暂时余额过账。此临时过过账将自动抵消你抵销的发票记录过账已编码。
例如1
贷项发票9001 与借项发票5001抵销。抵销金额为1000瑞典克朗。
贷项发票9001 的过账将是：
| 科目 | 规格 | 借项 | 贷项 |
|---|---|---|---|
| 1510应收账款 | 9001 | 1000 |   |
| 9000 临时科目抵销 |   |   | 1000 |
借项发票5001 的过账如下：
| 科目 | 规格 | 借项 | 贷项 |
|---|---|---|---|
| 1510应收账款 | 5001 |   | 1000 |
| 9000 临时科目抵销 |   | 1000 |   |
将被已记录的合计过账数为：
| 科目 | 规格 | 借项 | 贷项 |
|---|---|---|---|
| 1510应收账款 | 9001 | 1000 |   |
| 1510应收账款 | 9001 |   | 1000 |
例如2
借项发票5001 与应付账款中的流水号110抵销。抵销金额为1000瑞典克朗。
客户发票5001 的过账如下：
| 科目 | 规格 | 借项 | 贷项 |
|---|---|---|---|
| 1510应收账款 | 5001 |   | 1000 |
| 9000 临时科目抵销 |   | 1000 |   |
流水号 110 的过账如下：
| 科目 | 规格 | 借项 | 贷项 |
|---|---|---|---|
| 2440应付账款 | 110 | 1000 |   |
| 9000 临时科目抵销 |   |   | 1000 |
将被已记录的合计过账数为：
| 科目 | 规格 | 借项 | 贷项 |
|---|---|---|---|
| 1510应收账款 | 5001 |   | 1000 |
| 2440应付账款 | 110 | 1000 |   |
例如3
贷项发票9001 与借项发票5001抵销。抵销金额为1000美元。贷项发票9001 的初始汇率为 8.00。借项发票5001 的初始汇率为 9.00。
贷项发票9001 的过账将是：
| 科目 | 规格 | 借项 | 贷项 |
|---|---|---|---|
| 1510应收账款 | 9001 | 8000 |   |
| 9000 临时科目抵销 |   |   | 8000 |
借项发票5001 的过账如下：
| 科目 | 规格 | 借项 | 贷项 |
|---|---|---|---|
| 1510应收账款 | 5001 |   | 9000 |
| 9000 临时科目抵销 |   | 8000 |   |
| 8180 汇兑损失 |   | 1000 |   |
将被已记录的合计过账数为：
| 科目 | 规格 | 借项 | 贷项 |
|---|---|---|---|
| 1510应收账款 | 9001 | 8000 |   |
| 1510应收账款 | 5001 |   | 9000 |
| 8180 汇兑损失 |   | 1000 |   |

#### 合计会计订单
如果复选框 合计会计订单 经过检查后，你将在窗口中看到全部应付款科目和应收账款记录的合计过账。如果你在应付账款和应收账款在中间进行抵销，然后合计过账将被过账，第一个显示抵销发票，然后显示应进行抵销的发票合计。

#### 发票过账以抵销
如果已激活此设置，你将看到分类账记录的过账，该记录位于 抵销发票 盒子。
