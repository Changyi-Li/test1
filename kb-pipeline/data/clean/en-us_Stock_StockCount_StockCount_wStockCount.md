## Stock count
In this procedure you can report stock count of parts. The following information can be entered in this procedure:
- New balance
- Unit
- Location
- Stock count date
When the stock count is saved for the parts, the time of the stock count and the users who reported the stock count will also be registered. Furthermore, the difference between the stock counted balance and the previous balance will be saved for each part. This information can be seen in the Stock count difference procedure. Saved changes in the balance between the previous balance and the stock counted balance can also be seen in the Stock transaction log procedure.
In this procedure a message is shown when a part is under stock count, that is, if it has received the stock count status Under stock count or Under stock count with saved balance in the Stock count in list procedure. In that case it is not possible to report stock count in this procedure, instead you have to report it in the procedure where the part has received this status.
TraceabilityTraceability in Monitor ERP is all about being able to trace a specific serial number or a batch in each step it is being processed, as of when a part or a material arrives with you from a supplier. Traceability is also about stating what is withdrawn from and what is added to stock, so it is then possible to trace from customer order, via manufacturing order to purchase order. But it is also about being able to trace the other way around; from purchase order via manufacturing order to customer order.
For parts with the traceability function activated, you must enter batch number/serial number, if you want the stock counted balance to change. You can do this by using the function button Add serial number/batch ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_batch.png). A new row will then be added where you enter a new or an existing serial number/batch. Whether it is the field Batch numberA batch number is a number that is used for traceability for a set of or a batch of parts. A purchased material can have a batch number that should be able to be traced back to a certain charge number from a supplier. or Serial numberA serial number is a number that is used for traceability for parts on entity level. that can be edited depends on the traceability level entered for the part that is being stock counted. If you have selected None for the part, none of these fields will be possible to edit and it is also not possible to add a row for traceability.
If traceability is activated for a part, no withdrawal can be made from locations where the part does not have traceability/batch.

#### If you apply stock count approval
When you save your reporting, the rows that need to be approved are excluded, according to the settings in the General approval settings procedure. These lines are marked for later approval and the rows become locked for further changes. The signer/approver can then approve/reject these rows in the Stock count difference procedure, in the Approve stock count list type. The signer/approver can receive a message in Tasks that there are stock counts to approve. You activate stock count approval in the General approval settings procedure.
