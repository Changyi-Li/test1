### User
- Default types can be used for the user in a number of registers, for example, regarding order type on customer order and purchase order, quote, case type, etc.
- In the printer settings for the user you enter the Windows printers which should be used, this means that there is no printer register in G5.
- You can enter a default printer which should be used in all cases where you have not entered otherwise. Then you can create a table containing the exceptions for different document settings which should be made for a specific printer. For example that invoices are printed on a specific printer or that a certain transport label should be printed from a specific paper tray on a certain printer.
- It is possible to select a role for the user. The user can also have more than one role, but in that case one of the roles is the main role and determine for example what information is most relevant for the user.
- User rights groups can be chosen to modify the user rights given by the role of the user.
- You can also add user rights directly to the user if you need to have user-specific user rights settings.
-   
There is a new type of user-specific user right which makes it possible to hide specific fields in the entire system or to make them read-only.
- There is a Save as function where you can save a user as a new user or copy selected settings from the user in question to another user.
- In the e-mail settings for the user it is no longer possible to configure to send e-mail with e-mail program (via MAPI). There is support for Client based e-mail (via MS Outlook) and Server based e-mail (via Microsoft Exchange or via SMTP). It is the same in the corresponding system setting as well.
-   
The Report measuring data procedure is also available to users with the Recording terminal license type.
