### Time banks
This box is available if you for the setting Time recording have selected the option Attendance/Work. You also need to select the option According to schedule cycle for the setting Schedule management for the box to become available.
In this box you can see time banks based on the person's parameter group. You see the current time balance in the respective time bank. Inactive time banks are not displayed.
By clicking the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you access a window in which a information is shown about log records in the time bank. At the top of this window you select for how many days you wish to see the log.
