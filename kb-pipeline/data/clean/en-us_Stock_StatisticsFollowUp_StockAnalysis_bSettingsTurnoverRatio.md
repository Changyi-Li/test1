### Settings (Turnover ratio)
General

#### From date/To date
Here you select the date interval for the time span used when calculating the part's turnover ratio. The default dates here are from the first of January of the present year, to the last of December of the present year. It is recommended to select an entire year (365 days), otherwise a warning will be displayed ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png) next to the fields.

#### Date alternative
With this setting you decide if the calculated turnover ratio should be based on Actual date or Log date in the stock transactions.

#### Pre-select "Include"
If you activate this setting, the Include checkbox will be marked by default on all row in the list.
Price type
The price alternatives for purchased and manufactured parts are the bases of calculating values in the list. Standard price is the default option.
If you select Price list for any of these alternatives, the corresponding Price list field becomes active and there you select which price list to apply.
If you have selected Supplier price, Future supplier price, or a price list in a different currency, the Rate type field will become available. There you select the rate type of the currency.
You find an explanation of the different price alternatives in this [topic](../../Parts/PartPrices.htm).
