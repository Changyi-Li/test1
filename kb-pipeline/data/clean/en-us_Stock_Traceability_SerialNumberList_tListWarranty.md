### The Warranty list
This list type shows information about warranties for the serial number. On the row you can see which part it concerns. It is possible to update information in this list. The information in the list is loaded from the boxes [Reading](../SerialNumberBatch/bReading.htm) and [Warranty](../SerialNumberBatch/bWarranty.htm) in the Serial numberA serial number is a number that is used for traceability for parts on entity level./BatchA batch is the set of components/products manufactured at the same time and made from the same original material. procedure. The information that can be updated in the list is the same as the information found in the Warranty box in that procedure.
