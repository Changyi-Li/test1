### Log of activities/E-mails
Here you create notes to log activities and e-mails for the record in question. Both incoming and outgoing e-mails are logged here.
At the top of the box there is a search field where you can search for text occurring in notes. You can also open a search window via the Find (Ctrl + B) ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_search.png) button. Here you’ll find the Subject field, which is activated for new notes and new e-mail messages (read more under the Subject heading).
By clicking the Add new row at the end button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_row.png) (F5) on the function menu, you add rows with notes regarding activities and contacts. It is mandatory to enter a Subject for each note. You can link files to a note (read more under the Files heading). There is also a text editor where you enter the actual log text. You can format the text and insert images.
By using the Send a new e-mail message button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_email.png) you create a new e-mail message (in your regular e-mail program) related to the record in question. You must enter a Subject and write a log text for a note. You can choose not to insert a log record for the activity and you can choose not to insert a log record for the e-mail. These two log records are created by default for a new e-mail message.
By using the Import from inbox button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_import.png) you can import e-mails from the inbox in question. This function requires you to configure setting in the procedure called Settings for incoming e-mail.
By using the Show e-mail message button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_preview.png) you can open and read e-mail messages on rows that have the e-mail symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_email.png) to the far left in the log.
You can also double-click a row with the e-mail symbol to open and read the e-mail in a separate window. By using the buttons at the top of this window you can reply to, reply to all, or forward, the e-mail. If there is a file attached in the e-mail, you can click the attached file to open and view it. There is also a button next to the file which you can use to download the file to your computer.
By using the Delete selected row button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_delete_row.png) (F6) you delete the marked row containing notes or an e-mail.

#### Subject
The subject is mandatory for new notes. This text will also become default as a subject in a new e-mail message.

#### Files
External files linked to the note. By clicking the Files button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_file_link.png), it is possible to link different files related to a comment or an instruction for the record in question. When the setting Automatic printout is available for activation, you can choose to get the linked file automatically printed. Read more in the topic [General features](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LinkFiles) about how to link files, automatic printout, and where linked files can be automatically printed. If there are linked files, you will see this symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_file_linked.png) on the button.

#### Time
Here you see the date and time of when the note was created.

#### Created by
The user that created the note.

#### Dir. (Direction)
Here you see if it is an incoming (In) or outgoing (Out) e-mail.

#### From
Here you see by whom the e-mail message was sent.

#### To
Here you see to whom (name or e-mail address) the e-mail was sent.

#### Copy (Cc)
Here you see to whom (name or e-mail address) the copy was sent.

#### Bcc
Here you see to whom (name or e-mail address) the secret copy (Blind carbon copy) was sent.
