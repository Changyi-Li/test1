### Settings – Change signer

#### Include future signers
This system setting determines if future signers should be shown on separate rows in the list. If you check this box, the invoice’s current and future signers are shown on separate rows. If you do not check this box, then only the signer who has the invoice right now is shown.
When parallel authorization is used, then all signer who have the invoice right now are shown.

#### Handling time more than
This setting can be used as a filter in order to load invoices that have been waiting for authorization for a long period of time. If you for example enter 7 days in this field, you will in the list only see invoices that have been awaiting authorization for a week or longer. By default 0 (zero) is selected in this field.
