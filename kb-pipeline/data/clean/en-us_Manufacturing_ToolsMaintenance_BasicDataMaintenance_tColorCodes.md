### Color codes
Here you register color codes used to indicate which year maintenance should be performed. This is used when a date decides when maintenance should be performed. The standard used today consists of four different color codes which are changed automatically each year in a rolling schedule.
The standard colors and years are: 2018 Blue, 2019 Yellow, 2020 Green, 2021 Orange, etc.
Here you also generated the schedule for a number of years ahead, from a start year.
You can change color code for each separate row of the already registered color codes. If you change a color code, you update it in the schedule by regenerating the schedule.
Mark tools which should be calibrated with a label in the same color as the color of the year when the next calibration should be performed. On this label you normally also enter a number indicating the month of calibration.
Settings
Here you enter a Start year and Number of years. By default, the start year is the year following the last year included in the generated schedule. By clicking the button Generate color codes ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_run.png), colors become added in the schedule for the entered number of years, starting from the start year. In the Result box you see the added years in the schedule, and the color they have been given according to the interval of colors you have registered.
Interval
In this box you create the interval of color codes you want to use. The row number in this box determines the order of the colors in the rolling schedule. The first year gets the color of the first row, the second year gets the color of the second row, location, and so on.
Result
In this box you see the schedule showing which color code belongs to which year, of the generated years.
