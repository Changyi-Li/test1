### The Administer customer links list
This list is used to administer customer links. The list can be grouped by part number or customer. You use the list to delete existing customer links. If you delete the default customer link from a part, the next customer link will automatically become default.
Mark the checkbox in the Delete column for the customer links you want to delete for the respective parts..
Using the Delete selected rows button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_trash.png) on the function menu you then execute the deletion. A control question is first shown where you confirm the deletion of the link/links.
