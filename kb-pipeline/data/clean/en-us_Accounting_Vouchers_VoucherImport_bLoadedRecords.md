### Loaded records
In this box you see the records that have been loaded from the file after you have imported it. You can also manually add rows. Which columns you can see in the list depends on how you have configured the format template that is used. In the Show box you can filter which records to show: new and/or incorrect.
You can mark the checkbox Include for the rows containing records that you want to save. This way you can save in the procedure and thereby remove the rows which you are finished with, from the list. Rows with validation errors that have not been chosen to include, will remain in the list.
