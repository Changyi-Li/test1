### Posting of logs/Approve log journal
The heading of this box depend on which row is marked in the Scheduling box.

#### Type of scheduling
With this setting you decide what type of scheduling should apply for posting of logs/approve log journal. The available options are Schedule or Time interval.

#### Time of day
For Schedule you can enter times for posting of logs/approve log journal.

#### Time interval
For Time interval you can enter a time interval for posting of logs/approve log journal.

#### Logging
Here you decide if running the posting should be logged.

#### History
By clicking this button you access information about previous runs.

#### Notify
Here you configure which roles, groups, or users, should be notified when the run starts, when the run is completed, and when errors occur.

#### Modified by
Here you see who changed the scheduling.

#### Modified when
Here you see when the scheduling was modified.
