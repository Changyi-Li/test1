### Resulting posting
In this box you define which postings should take place when the terms i the box Initial posting have been fulfilled. On each row you determine which automatic posting should be generated based on the initial posting. Each row will generate two postings: one posting on debit and the other posting on credit. The amount which should be automatic posted is (with exception of the text section below) based on the amount of the initial posting and is entered in percent.
By selecting a row it is possible to insert an automatic posting on a sub-level via the function button Add sub-posting located next to the box. A sub-row is then created where you can enter an additional posting row which should be generated. Such posting row is recorded with an amount based on the regular posting.
To put it simply, it is an automatic posting of the automatic posting.

#### Account
Here you see/enter the account on which the posting will be recorded. The accounts you enter in this column will be recorded on the same side (debit/credit) as the initial posting. If you leave the field empty, the recording will be made on the same account as the initial posting. Otherwise you can enter the account which should apply for the row.

#### Dimensions
Each dimension is shown in a separate column. You can enter dimensions if posting should take place on a specific dimension code. If the account on the row manages posting on dimensions, but dimension is left empty, then the dimension code will be inherited from the initial posting. For example, if you post on cost center 10 and this generates an automatic posting. If the generated posting row has an account handling a cost center, cost center 10 will be used on that row.

#### Offset account
Here you see/enter the account on which the posting will be recorded on the opposite side (credit/debit).

#### Percent
Here you can enter how many percent of the initial amount should be posted on the row in question. You can enter the percent with a maximum of 2 decimals. This refers to the percent of the initial posting which should be posted (on the first level). When making a sub-posting, you here enter the percent of the amount posted in the first level.

#### VAT code
By clicking the More info button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) a window opens where you can enter a VAT code.
