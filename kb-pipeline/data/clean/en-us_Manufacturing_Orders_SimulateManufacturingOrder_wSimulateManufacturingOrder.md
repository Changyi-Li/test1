## Simulate manufacturing order
This procedure is used to simulate manufacturing orders. This is done to make sure that BOM and routing and configurations, if any, are correct. It is possible to simulate multiple manufacturing orders at the same time. This function can be compared to the calculation run in the Pre-calculation procedure.
Under the Selection tab you select which manufacturing orders you want to simulate.
Under the List tab you can see and complement the terms which should apply for the simulation.
You start the simulation by using the Start simulation button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_run.png) on the toolbar of the procedure. You can also redo the simulation if you have made changes in the list.
For a part possible to configure, you first create a configuration by using the button Possible to configure ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/Button_Configuration_Available.png) in the list before you run the simulation. If a configuration is saved for the part you will instead see the button Configured ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/Button_Configuration_Done.png) in the list.
Under the Manufacturing order tab you see a summary of the order's structure, operations, and material (just like in the view in the Manufacturing order info).
There are also two warning tabs under which you can see warnings for the order in question and in total from the simulation. These tabs are the same as in the Pre-calculation.
From the BOM and routing procedure you can go to this procedure with the part number already loaded to be able to simulate a manufacturing order based on the BOM and routing.
Selection rows
In a list procedure there is always a tab called Selection where you can select data records in different intervals from the database. The data records are then loaded by using the Load button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_display_list.png) in the toolbar of the procedure.
Under Selection rows in the backstage of the procedure, you can choose which selection rows that each list type should have, under the Selection tab in the procedure. In the List type field you select for which list type you want to customize the selection rows.
One table shows selection rows possible to select and one one table shows the selected selection rows. You can add, delete, or move selection rows by dragging and dropping the selection rows with your mouse pointer.
Using the Save button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_save.png) you save the selected selection rows.
Read more about this in the [Selection](../../../UserGuide/GeneralFeatures/Selection.htm) topic.
