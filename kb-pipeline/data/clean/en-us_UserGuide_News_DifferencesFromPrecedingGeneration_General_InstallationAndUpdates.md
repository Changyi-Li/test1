### Monitor Installation manager

#### Updates
When installing a Monitor ERP system, the program Monitor Installation manager will also be installed. This is a program where you administer the installation, as well as download and install updates and components. You can also use the program to install more companies. The Installation manager keeps track of options and that adaptations are available in a compatible version before you can update the G5 version.
When updating Monitor G5, it is standard to run backups of all databases. If the update should fail, the databases will automatically be reset and Monitor is reset to the same version as it was prior to the update. This means you can continue using the system even though the update failed.

#### Test companies and backup
You also use the installation manager to create and administer test databases as well as creating and scheduling backup tasks of databases. It has become much easier and more clear to administer these areas in Monitor G5. The program Monitor Backup has been discontinued, and you no longer have to use the Task Scheduler in Windows.
