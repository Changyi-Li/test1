### Planned absence
In this box you select absence codes and if the absence should apply for "part of day". You do this for the employees for which you have checked the Include box in the table and for the days marked in the calendar. One row will be created in the box per absence code for each interval of day squares you mark in the calendar.

#### Absence code
Here you select absence code for the day in question. This field is mandatory.

#### Part of day
If the absence does not apply for an entire day, you check this checkbox. Then the From and To fields becomes activated. There you can enter the time when the absence starts and ends during the selected day.
