### Validity periods
In this table you register validity periods. The validity period is applied on quotes. Furthermore, the system uses this term to calculate the valid through date based on the quote date.

#### Default
Here you decide if the validity period should be selected by default when registering new customers.

#### Number
Here you can see the number for the position of the row. This field is numerical. A new row will by default be assigned the next available number. The table/list is sorted by this column. A number is unique and cannot occur on more than one row in the table.

#### Name
Here you enter a name for the validity period. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Number of days
The number of days of the validity period, from the quote date to the valid through date.
