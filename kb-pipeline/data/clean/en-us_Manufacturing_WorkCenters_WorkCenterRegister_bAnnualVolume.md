### Annual volume
In this box you can enter planned annual volume for the work center. 0,00 is shown by default if nothing has been previously saved.

#### Unit time and Setup time
If you enter unit time and setup time, this will be added together to create Total time.

#### Total time
The total time is the unit time and the setup time. If you enter or change a total time, this will only affect the unit time.

#### Cost
The cost is calculated by loading hourly costs for the cost factors.

#### Cost factors
Here you see the cost factors that are used by default according to the system setting Default cost factors.

#### Man-hours
The man-hours are calculated like this: unit time × the staffing factor of the work center + setup time. If you enter a value for man-hours, then no other value will be changed.
