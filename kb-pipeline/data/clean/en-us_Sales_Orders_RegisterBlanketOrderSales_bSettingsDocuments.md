### Settings – Documents
In the Settings box under the Document tab there are different document settings as seen below which you can modify before printout, if needed.

#### Documents
The document you select is shown in the Preview box.

#### Document variant
Here you choose which variant of the document to show and print, if another variant than the default one should be used for this printout.
Variants of different documents can be created in the Document templates procedure.

#### Linked files
This checkbox determines if linked files should also be printed when printing the document. The linked files which can be printed are the ones activated for Automatic printout in the file link. [Read more about linked files and where they can be printed automatically](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LinkFiles).

#### Printout date
The printout date in this field will by default be today's date, but it can be changed. If you change the printout date here, the printout date on the document will also be changed. However, the date and time registered in the printout log will be the actual time for the printout, regardless of the entered printout date.

#### Number of copies
Here you select the number of copies to print of the selected document. A default number of copies can be configured for the document in the Document settings procedure.

#### Show prices
Here you determines if the parts' price each will be displayed on the document. The alternative you select here will be saved on the loaded record. The checkbox Show prices is only available for certain documents. If you want this setting to be activated by default, this can be configured for the document in the Document settings procedure.

#### Show total amount
This checkbox determines if the total amount should be shown on the document. The alternative you select here will be saved on the loaded record. The checkbox Show total amount is only available for certain documents. If you want this setting to be activated by default, this can be configured for the document in the Document settings procedure.
