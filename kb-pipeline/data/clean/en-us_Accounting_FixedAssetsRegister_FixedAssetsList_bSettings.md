### Settings

#### Valuation time
Detailed and Total. You choose here if you want to load the lists with values based on the current values or by a historical date. If you choose Historical, a date field to the right becomes available where you can enter the date.
> If you choose Historical as the valuation time, you can see the This year’s depreciation column in the Detailed and Summarized lists.
It is taken into account when the object got the status Sold/Retired (the date which was entered in the Sales/Retirement of assets procedure). If the asset for example was sold on 2017-05-31 and you create a fixed assets list at 2017-05-31 and later, then the object should be handled as sold. If you load objects to the list with historical date before 2017-05-31, then the object should not be handled as sold.

#### Depreciation type
Depreciation log With this setting you determine if scheduled or calculated records should be shown in the list.
If you select the Scheduled option the following records will be included in the list:
- Historical depreciation
- Extra depreciation
- Scheduled depreciation
- Undone scheduled depreciation.
If you select the Calculated option the following records will be included in the list:
- Calculated depreciation
- Undone calculated depreciation.

#### Show modified acquisition value
Depreciation log With this setting you decide if amounts for records of the type Modified acquisition value should be shown in a separate column in the list.

#### Only main objects/sub-objects
Here you decide if only objects which are linked to other objects (that is, objects that are main objects or sub-objects) should be loaded to the list. If you check this setting, no separate objects will be loaded to the list.

#### Show budget objects
With this setting you determine if fixed assets which are marked as budget objects, should be loaded to the list
