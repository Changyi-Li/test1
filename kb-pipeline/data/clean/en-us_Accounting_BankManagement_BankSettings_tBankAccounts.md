### Bank accounts
Under this tab you register all bank accounts of the company. Bank accounts of factoring companies, if any, are also registered here.
To each bank account you register different account information, bookkeeping account, and bank address. The information is printed on different documents and is used during incoming and outgoing electronic payments.

#### Code
Here you enter the bank account code using a maximum of 5 characters. You can enter an optional code for the account and the code is only intended for internal use.

#### Name
Here you enter the bank account name. The bank account name will be shown in fields where you select bank account, for example in the Company information procedure.

#### Translations
By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.
