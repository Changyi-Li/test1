### The Scheduled depreciation list
The list can either be shown as standard with depreciation per asset on each row or it can be shown grouped by fixed assets group The records shown in the list are those which have vales left to depreciate. Assets marked as Not depreciable (belonging to a group which is not depreciable), and assets with status Investment in progress or Fully depreciated are not shown in the list.
You mark the rows you want to include to save and execute the depreciation. When you execute the depreciation the following takes place:
- Accumulated depreciation and residual value are updated for the assets in question.
- The date for the most recent depreciation is updated for each asset in question.
- A log item for done depreciation is saved for each asset in question. The log is used both for information and traceability, but is also used as a basis for calculating acquisition value, accumulated depreciation, and residual values at a certain date in the past. In connection with depreciation the asset's log becomes updated.
- A posting of depreciation is saved for each asset in question.
- Posting items for each asset is shown in total in this list. And as in the customer invoice journal it is possible to see the posting of each record with a total accounting order at the very bottom.
- If you save and have configured to use direct integration, then a box is shown in the same way as in accounts payable and accounts receivable.
- If it is not possible to book/record the voucher, a dialog containing information about why will be shown.
