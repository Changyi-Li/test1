### FAQ – Time recording
How do I make it so that multiple employees can be clocked in on the same job at the same time?
If multiple operators should be able to be clocked in on the same job, select Multiple operators under the Recording/Printouts tab in the Work centerA work center is a part of the factory. It can be a single machine or a group of machines, a single workstation or a group of workstations. register procedure.
How do I add more work centers for the employees to choose in the Recording terminal?
You add more work centers for the employee under the Work tab in the Personnel records – Time recording­­ procedure.
The Recording terminal procedure isn’t showing for one of our employees, why?
The procedure is likely showing off screen. To view the procedure, click Alt + O or try using Overlapping on the Window button to the left above the colorful module circles. Procedures remember which screen they were last closed on, however you are able to open them on the home screen again with the use of buttons.

How do I start a group recording?
You can start group recordings with the Start button in the Attendance list procedure. In the dialog window which opens you can enter a name for the group, select an indirect code, and select which employees should be included in the group recording.
