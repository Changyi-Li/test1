### Settings – Documents

#### Add interest
If it is possible to add interest to the invoice basis selected in the Result box, the button Add interest ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) will become available. By clicking that button it is possible to add interest to the invoice basis.

#### Show invoices with validation error
If you activate this setting you will also see invoice bases with validation errors, for example were payment terms are missing etc. For these invoice bases you will then see an error symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/error.png) before the Order number column. By hovering the pointer over the error symbol, you will see the text of the validation error in a tooltip. It is not possible to Save or Approve invoices if you have marked an invoice basis with a validation error in the Result box.
