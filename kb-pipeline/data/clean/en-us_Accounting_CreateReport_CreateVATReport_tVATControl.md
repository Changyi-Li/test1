### VAT control
Under this tab you create the VAT controls/checks. These controls can be selected for a VAT row under the tab VAT report – Construction.

#### Number
Here you see/enter the VAT control number.

#### Name
This text describes the VAT control and is printed under the VAT control heading on the VAT report. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.
