### ISO codes for units
Here you manage ISO codes for units which can be linked to the units under the Units tab in the procedure.
You can add your own ISO codes and delete the ones you do not use. When you install the system, there are a number of predefined ISO codes.

#### Code
Here you see/enter the ISO code.

#### Name
Here you see/enter the name of the ISO code which is a description of the code. This is normally entered in English.

#### Translations
By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.
