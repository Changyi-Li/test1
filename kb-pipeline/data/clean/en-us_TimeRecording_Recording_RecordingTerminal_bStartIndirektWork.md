### Indirect work
This tab is available if the option indirect codes is allowed as method to select work for you in the procedure Personnel records – Time recording.
Here you select the indirect work you want to start. The indirect work items you can see here are determined by the setting Allowed indirect codes in the above procedure.

#### The Start button
Using the button Start you start the indirect work.
If you have the work method Only change, the terminal will then change mode to where you can stop the previous work, unless you first chose to stop/finish that work item.

#### The Cancel button
By clicking the button Cancel you cancel the mode where you start work and the recording terminal reverts to the recording mode.
