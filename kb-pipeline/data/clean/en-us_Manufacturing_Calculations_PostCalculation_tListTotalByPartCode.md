### The Total by part code list type
In this list you see the selected orders in total by the parts' part codes. You can use the list to calculate which range of parts is the most profitable. This can also be calculated for the parts with the same part code. You can expand each part row and see detailed information about the manufacturing orders that exist for parts with each part code.
By using the Chart button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_chart.png) you can choose to show the information in a chart at the bottom of the window.

#### Part code
Here you see the main part’s part code in orders.

#### Name
Here you see the part code's name.

#### Warnings (W)
If warnings exist after the calculation, you can click the button to view the warnings, if any. Warnings that you have not clicked on are displayed with a warning sign ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png) on the button. The warnings that you have clicked are displayed with an exclamation mark ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning_validation.png). Warnings are not saved for calculations.

#### Include
By default, all records are included in the calculation. Here you can deselect individual records by unchecking the respective box, or deselect all underlying records by unchecking the box in the column heading.

#### Number of orders
Here you see the number of orders containing parts with the part code.

#### Number of parts
Here you see the number of parts with the part code in orders.
Columns that are displayed after the calculation

#### Planned cost
Here you see the planned manufacturing cost (in the company currency) for orders containing parts with the part code.

#### Reported cost
Reported manufacturing cost (in the company currency) for orders containing parts with the part code.

#### Difference %
The difference in percent is shown here between the planned cost and the reported cost.

#### Comparative price
In this column you see the selected price to compare with. The name of the column is dependent of which comparative price you have selected. If you have chosen, for example, Post-calculated mean price, then the column heading will be Post-calculated mean price.

#### CM
The order contribution margin for parts when the part code is used (CMThe contribution margin (CM) is the difference between the standard price and the sales price.).

#### CR
The order contribution ratio for parts when the part code is used (CRThe contribution ratio (CR) is the portion of the invoice amount (sales price) that the contribution margin represents. CR is entered as a percentage.).

#### Save price
With this checkbox you determine whether or not the calculated price should be saved for the parts with the part code.
