### Rows
In this box you can compare data from the order rows in Monitor ERP with information on the order rows in the import file. You also see if the part status is OK after the import ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/StatusFinished.png). From here you can link to related procedures for the selected order row.
If needed, you can here choose to skip one or several order rows by checking the checkbox called Skip order row. Order rows which have been skipped in an earlier transaction can be included later on in a complementary transaction. This is done by deactivating the checkbox and rerun the transaction by clicking the Start transaction button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_run.png) which you find in the function menu in the list in the tab.
You can also correct the business transaction if errors occur on order rows, for example, if one or several parts cannot be matched. If there are any errors an error symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/error.png) appears on the part's status and where the error occurred. When you hover over the symbol, a tooltip displays the error in text form. On the row you can then select part and use the Action button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) to choose to add another part identity or a customer link.
If a unit is incorrect on a part from the import file and/or if it is missing in Monitor ERP, this can be shown as an error ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/error.png) or a warning ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png). The unit can also be ignored. This is determined by the setting Check of unit on part row in the EDI EDI is the acronym of Electronic Data Interchange. EDI is about exchanging electronic business documents with your business partners, e.g. customers and suppliers. The EDI concept can be wide and a bit unclear, and can many times be used about all types of documents which are sent electronically, even if it might be PDF files sent via e-mail or publishing business documents on a website. What we refer to as EDI – and what is traditionally meant by EDI – is structured business documents following given standards, electronically sent or received and which are compiled and interpreted automatically and that is integrated with the customer's/supplier's ERP system. behavior to which the customer is linked. If the part's unit is missing from the import file, the part's default unit in Monitor ERP will be used. You cannot adjust the unit here. This must be added to the part in the part register (usage on Customer order).
You can unpin the box and use it as a floating window. This is done by using the button called Floating ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_float_window.png) (Ctrl + U). This way the table will be larger and you get a better overview of the order rows.
