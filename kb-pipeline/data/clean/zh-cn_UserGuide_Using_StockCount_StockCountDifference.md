### 库存盘点差异
视频：差异和估值
| 瑞典语 | 英语 |
|---|---|
|   |   |
这 库存盘点差异 程序用于计算库存之后发生 的 差异值.库存盘点差异条款金钱和数量来衡量。差异可以是值高于，也可以是值低于。当你报告并保存每组件的库存数量时，就会出现库存盘点差异。
如果使用的话，该程序还用于批准库存盘点。
> 提示！ 对于库存盘点差异大的组件，你可以重新库存盘点。为了能够为这些组件新建的库存盘点底单，你可以使用按钮将组件复制到组件剪贴板 复制至剪贴板 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/UserGuide/button_copy.png)。之后，你可以粘贴 剪贴板 复选框，然后在程序中的组件选择中可用 库存盘点列表。
