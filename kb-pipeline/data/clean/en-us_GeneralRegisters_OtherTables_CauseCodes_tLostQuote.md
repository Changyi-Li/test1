### Lost quote
Under this tab you can register several cause codes for lost quotes. When you install the system, three cause codes are included in the system. These cause codes cover the most common reasons why a quote is lost.
When status Finished is set on a quote, you must select one of the cause codes registered here.

#### Cause code
The cause code can be an alphanumerical value containing a maximum of 6 characters.

#### Name
Here you can write a descriptive text as a name. You enter name texts in the company language and they are displayed in the user’s language.
By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Mandatory comment
For certain cause codes you may wish to configure a mandatory comment if the cause must be further described. In that case you should check this box. The user will then have to enter a comment after having selected a cause code in the procedure in question. Otherwise, it is optional to enter a comment.

#### Active
Here you can determine if the cause code is active or not. If the cause code should not be used anymore you can uncheck this checkbox. The cause code in question will then be hidden when reporting. However, you can still enter the specific cause code in fields where selection by cause code is made. This is done in order to create statistics for previous reporting of the cause code.
