## Authorization settings – EIM
This procedure is used to configure authorization settings when the option Electronic invoice management (EIM) is installed.
- Here you register the users who should be signers.
- Enter authorization limits.
- Configure absence settings as well as settings regarding forwarding for the signers.
- Create signer groups and authorization lists (authorization flows), as well as authorization limit exceptions.
- Configure settings for viewing of invoices.
- Schedule automatic forwarding of authorizations.
- Schedule reminders via e-mail when there are invoices to authorize and/or final record.
- Configure settings regarding authorization at row level. This is activated with the system setting called Use extended authorization on posting rows.
If you have not installed EIM, you can use the Personnel records procedure to select which persons should be authorized signers. However, then there is no corresponding system support for for example authorization limits and authorization flows.
