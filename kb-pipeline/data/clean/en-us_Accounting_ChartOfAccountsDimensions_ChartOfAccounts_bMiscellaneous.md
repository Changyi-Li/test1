### Miscellaneous

#### Debit/Credit
With this setting you determine if the account is a debit account or a credit account. When posting, the cursor will by default be placed on the account side selected in this field.

#### Heading
Each account can be linked to a heading, however, this is optional. Using headings is a way to structure accounts for chart of accounts printouts. Headings and their numbers are registered and updated in the Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Chart of accounts procedure.

#### Account category
Here you can enter an account category. By clicking the Category selection button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png), you can select a category if categories have been registered in the Categories procedure. If no categories are registered, you can type as you please in this field. Categories can be used as a selection term in different lists. Read more about how categories can be created/constructed in the online help function for the [Categories](../../../GeneralRegisters/Categories/Categories/wCategories.htm) procedure.

#### Budget chart
Here you can enter a default budget chart for the account in question. This budget chart will then be automatically selected when registering budget and import.

#### Signer/Approver
If you apply authorization at row level (activated with the system setting called Use extended authorization on posting rows), you can here choose a signer/approver for the account.

#### Head signer
If you apply authorization at row level (activated with the system setting called Use extended authorization on posting rows), you can here choose a head signer for the account.
