### Settings – Documents

#### Linked files
When this setting is activated, linked inspection documents (files), if any, will be printed together with the inspection report. Depending on where the receiving inspection is activated (on part, supplier, order, arrival), the external inspection files are loaded from one of these sources. Viewing of PDF files is supported.Using the option Extended file viewer you can view/show more file types, such as different drawing formats and Office formats. By clicking this link you access a complete list of the [supported file formats](https://www.rasterex.com/file-formats?hsCtaTracking=f7142bf7-4cfa-4c3b-8be8-cde24df7f2b4%7Cdae7ecbb-26b0-43cd-b9d0-3579248ec31b).
