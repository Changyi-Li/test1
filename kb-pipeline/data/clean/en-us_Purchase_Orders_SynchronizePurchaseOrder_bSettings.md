### Settings
General

#### Only show orders with a difference
With this setting you decide if only customer orders where there is a difference, should be shown in the list.

#### Only show fields with a difference
With this setting you decide if only fields on customer orders and customer order rows where there are differences, should be shown in the list.

#### Pre-select "Save"
With this checkbox you decide if the column Save should marked by default in the list. This setting is not checked by default.
Communication

#### Communication address
Here you decide if the information in the Communication box under the Header tab, should be synchronized.
References
Here you decide if the Supplier reference field should be updated in the synchronization.
Synchronize posting
Under Synchronize posting you update the settings which affect the purchase order's and the purchase order row's posting.

#### Supplier group
With this setting you decide if the supplier group on the order should be updated in the synchronization. If you check the Supplier group setting, the setting called Postings will automatically be activated.

#### Postings
With this checkbox you decide if posting on the order row should be updated in the synchronization.

#### VAT group
With this checkbox you decide if the VAT group on the order should be updated in the synchronization.
Terms

#### Payment terms
Here you decide if payment terms should be updated in the synchronization.

#### Delivery terms
Here you decide if delivery terms should be updated in the synchronization.

#### Delivery methods
Here you decide if deliver method should be updated in the synchronization.
