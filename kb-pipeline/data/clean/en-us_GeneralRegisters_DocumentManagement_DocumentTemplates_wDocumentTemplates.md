## Document templates
In this procedure you can create variants of the standard document templates included in the system. You can also select which variant of each respective document template should be used by default.
Each document template consists of a number of document components. You can also create variants of the document components and select which variant should be used by default.
It is also possible to create an empty document variant if you want to design your own document template.
All document templates are in A4 format. The document template Transport label is also available in A5 and a variant called Label. The label's standard format is 76 × 51 mm. If you create own variants of document templates you can use any optional format.
You can select variants of document templates that are customer specific or supplier specific. This is made in the customer register and supplier register respectively. This is useful of you for example want to use a customized order confirmation for a specific customer.
> Creating custom document variants requires certain specialist knowledge. If you need help with this, you should primarily contact a consultant at Monitor ERP System AB. DevExpress Report Designer
Monitor ERP is delivered with a third party program used to design and edit variants of document templates and document components you have created. The program is called DevExpress Report Designer and is available under the button Edit ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_xtrareport_designer.png) in the Variants box.
