### BOM and routing

#### Comment changes in BOM and routing
Here you decide if it should be possible to enter comments when a change is made in the BOM and routing. The comments is saved in the log. The following options are available:
- No comments – You cannot enter comments.
- Allow comments – You can enter comments.
- Mandatory comments – It is mandatory to enter a comment and you cannot save unless a comment has been entered.

#### Time unit for setup and unit time for operations
This system setting determines which default time unit should be used for setup time and unit time for operations in BOM and routing. However, the time unit can be changed later on for an operation in a BOM and routing.

#### Default currency for subcontracts
This system setting determines which currency should be selected by default for subcontracts in BOM and routing. However, the currency for the subcontract may be changed later.

#### Use cycle time and ineffective time in BOM and routing
If you activate this system setting, you get better follow-ups of machine usage. You can then separate Cycle time Cycle time is the productive time in the operation in which the unproductive time is not included. Cycle time plus Ineffective time adds up to the unit time for an operation. from Ineffective time Ineffective time is time which is necessary in the operation, but not directly productive. in the BOM and routing. The system setting activates the fields Cycle time and Ineffective time %. It also deactivates the field Unit time on operation rows in the BOM and routing procedure. This makes it possible to create BOM and routing via cycle time and ineffective time instead of using unit time.

#### Warn if material is not unique
With this setting you determine if a warning ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png) should be displayed in cases where a material is not unique in a BOM and routing. Yes is selected by default. You can set this setting to No if you have the same material on several material rows in one or multiple BOM and routings and you don’t want to see the warning on those material rows.
