### Templates/Default
When you have created data under the other tabs, you can under this tab create templates and register default values for different case types. When you later on register cases, the user can select which template to use and will then receive suggested phases, activities, and costs.
The template you have marked in the table is the one you handle in the Default values box.

#### Case type
Select the case type you wish to work with. You can create one or several templates for each case type. For 8D Standard there is a predefined template.

#### Default
Here you decide that the template will be used by default for new cases of the selected case type.

#### Name
Here you can write a descriptive text as a name. You enter name texts in the company language and they are displayed in the user’s language.

#### Translations
By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Expand phases/activities
If this checkbox is checked, phases and activities for cases that use this template will be expanded as standard. If you change between cases with different templates, the phases/activities will remain expanded if they have been expanded in the previous case regardless of this setting.
