### Changes in English terminology
When using the English language in G5 changes have been made in comparison with the terminology in G4. Below you find a list of these changes in the terminology.
| Swedish name | English name in G4 | English name in G5 |
|---|---|---|
| Attestkod | Authorized signer | Signer code |
| Beredare | Prepared by | Production engineer |
| Beredning | Preparation | BOM and routing |
| Blankett | Form | Document |
| Dokument | Document | File |
| Inventering | Physical Inventory | Stock count |
| Generella register | Global Settings | General registers |
| Journal | Ledger | Journal |
| Kassation | Reject | Rejection |
| Kontering | Coding | Posting |
| Lager | Inventory | Stock |
| Plugin | - | Plugin |
| Relaterad offert | Sub-quote | Related quote |
| Sök & hämta | PopUp | LookupThe Lookup feature is a powerful search tool which allows you to search and load information from large registers. You open the Lookup feature by clicking on the dropdown button or by using F4 on your keyboard. |
| Tillval | Supplement | Option |
| Urval | Selection | Clipboard |
| Verkstadsinformation | Workshop Info | Time recording |
| Ärende | Nonconformity | Case |
