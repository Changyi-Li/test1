### Settings
For the Subcontract list type, the only available setting is Show foreign currency and the list type Shipped subcontract does not have any settings at all.
View

#### Show only main rows
Applies to the Detailed, Total, and Stock order list types. If you activate this setting, only main rows will be shown in the list. This setting is activated by default. If you deactivate this setting, the associated sub-rows such as additional texts and incorporated/included parts in fictitious parts, will be displayed.

#### Show alloy cost
Here you decide if the alloy cost should be shown in the list.

#### Show arrival reported rows
With this setting you can decide if order rows that have been arrival reported should be shown in the list

#### Only orders confirmed as delayed
This setting determines if only orders that are confirmed as delayed should be shown.

#### Show foreign currency
With this checkbox you determine if a total per currency code should be displayed at the bottom of the list. The total applies to all order rows in the list that have another currency than the company currency.
Price alternative

#### Price alternative PD/PD %
Here you select a price alternative used to compare with the purchase price on the arrival reported order rows. Differences between purchase price compared to the selected price alternative are shown in the columns PD The price difference (PD) is calculated as purchase price minus standard price for purchased parts. Regarding subcontracts, PD is calculated as actual cost for subcontract (the price on the supplier invoice) minus planned cost for subcontract. and PD % (price difference) in the list.

#### Price list
If you have selected the Price list alternative for the setting Price alternative for PD/PD %, you can here select a price list. If you choose to use a price list in foreign currency, you will also be able to select a rate type in the field below.

#### Convert price each according to rate type
With this setting you determine if "price each" in foreign currency should be converted to the present exchange rate in the Currencies procedure. If the checkbox is not checked, the exchange rate saved on the record will be used instead. Which rate type to use is selected in the field below.

#### Rate type
The rate type you select here is used to convert "prices each" and price lists in foreign currency to the now applying exchange rate for the selected rate type. The default rate type is From supplier/order type. You register rate types in the Currencies procedure.
Unit

#### Unit according to
Here you decide which unit that should be used to display ordered quantity, arrival reported quantity, and remaining quantity. Applies to the Detailed, Total, and Stock order list types. The following units can be chosen:
- Purchase order row – Default
- Standard unit
- According to usage – If you choose the option "According to usage" you must select which unit in the setting below.

#### Unit usage type
Here you select which type of alternative unit should be used for the calculation. The following options are available: Material withdrawal for manufacturing order, Purchase order, Report arrival, Customer order, Report delivery, Stock count and stock reporting, and Statistics.
