### The Locations – Detailed list
In this list you can see if a location name allows one or multiple locations. You can also see if the location name is blocked and in that case from which date. In the list you can see which parts exist on each location name. Here you also see the stock balance. You can also see which locations have been set as be arrival locations, pick locations, and/or pick location for work center. This is configured in the part register.
You cannot change any setting in this list.
