### Number series
- In G5, this procedure is built up with tabs per procedure.
- The voucher number series is in G5 moved to a separate procedure called Voucher number series/Journals. In that procedure you also handle integration of journals to the accounting.
- In G5, both number series for serial numbers and batch numbers has been moved to this procedure. Regarding batch number, it is also possible to use a tag to force the users to manually enter batch number.
- In the Number series procedure, you will see a warning if separate number series for invoice, credit invoice, etc. has been activated, and there is a risk of those series colliding.
- It is possible to use multiple number series for parts. There is a separate tab for parts in the Number series procedure.
- You can have a separate number series for advance invoices (when using invoicing plans).
- To avoid that number series clash or collide, a prefix has been added for batch number and for serial number when converting from G4. The prefixes are B for batch number and S for serial number.
