### Withdraw
In this box, you add one row for each tool that should be withdrawn.
If the option Warehouse is installed, you can use the warehouse selector ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_warehouses.png) on the toolbar of the procedure, to select from which warehouse the withdrawal should be made.

#### Traceability (T)
In this column you see a symbol representing the traceability level of serial number or batch number. If you place the cursor over the symbol, a tooltip will appear displaying an explanation of the symbol.

#### Basic type (B)
In this column you find a symbol for the basic type of the tool. If you place the cursor over the symbol, a tooltip will appear displaying an explanation of the symbol.

#### Serial number/Batch number
For tools to withdraw that are registered with serial number or batch number in the Serial number A serial number is a number that is used for traceability for parts on entity level./Batch A batch is the set of components/products manufactured at the same time and made from the same original material., you can enter this number here to facilitate the reporting.

#### Part number
For tools to withdraw that are not registered in the Serial number/Batch procedure, you can here enter the part number.

#### Location
The location of the tool.

#### Quantity for withdrawal
Here you enter the tool quantity to withdraw.

#### Disposable balance
Here you see the disposable balance of the tool in the location.
