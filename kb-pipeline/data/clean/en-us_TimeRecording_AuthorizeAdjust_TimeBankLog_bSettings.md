### Settings

#### Balance to show
(Standard) With this setting you determine which time bank to load. Here you find all balances which you can select among, except for the ones that are inactive.

#### Show employees
With this setting you determine which employees should be included in the list:
- All – This alternative will include all employees found in the personnel records.
- For which I am main signer – This alternative will include all employees for whom you are the main signer.
- For which I am secondary signer – This alternative will also include the employees for whom you are secondary signer, and it includes the employees which do not have a signer in the personnel records.

#### Show blocked
With this setting you decide if you also want to show blocked personnel, if there are blocked persons in the filter above.

#### Date alternative
(Historical balance) With this setting you determine for which date alternative the historical balance should be displayed. In the field to the right you select the date.
- Log date – If you select this option, the most recent record for the selected date will be loaded. If no record exists for the selected date the immediately preceding record will be loaded instead. If there are no log records prior to the selected date, "0,00" will be shown as balance. The log date will the first time be set to the date when a recording item is saved. If an adjustment is made for the recording item at a later time, the log date will be changed to the date of the adjustment.
- Actual date – If you select this option the most recent record for the selected date will be loaded. And if no record exists for the selected date the immediately preceding record will be loaded instead. After this, all changes become added from newer log records of which the actual date is the same or older than the selected date. All logs up to today's date will be checked this way. Actual date is the date which a recording item refers to.
Example: The balance on January 30 was 10 hours. On February 10 a log record is created which has January 25 as actual date where 2 hours have been deleted on an adjustment. Then the balance for January 30 will show 8 hours.
