### To pack
In this box you see information about all payload parts to pack and the quantity of the parts. The information is loaded from the pick list and from the rows in the Package structure box.
If you activate the setting called Suggest qty/package from the part register, the quantity per package will be loaded for each part in the table.
If there is a quantity per package entered in the customer link, this quantity will be used primarily. Secondly, the quantity per package entered on the part, will be used. When you uncheck the checkbox, the quantity per package will be reset to zero.
Certain information here is updated from the Package structure box. This is: Preliminary quantity, Cleared quantity, Packed quantity, and Percentage packed (the rows set to completely packed).
If the part has an alternative unit, you can change unit in the Unit column. The default unit for Pack for delivery can be selected under Usage in the Part register. It is possible to change the unit unless the pick list status is Package structure ready for delivery. If you change the unit it will also affect the unit in other boxes in the procedure. When you change the unit in Pack for delivery, it will affect the unit on the following documents; Packing list A packing list describes in which packages and using which types of packaging, the parts/products have been packed for delivery. The packaging list often contains information about package number and gross as well as net weight. and Transport label – Package structure.
If the part has partial quantities, the Partial quantity column is shown. By clicking the ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) button you find the partial quantity on the customer order.
A warning symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png) is displayed in the Quantity to pack column if the quantity in the Package structure box is less than the Quantity to pack for a part row.
A warning symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png) is displayed in the Preliminary quantity column if the quantity in the Package structure box exceeds the Quantity to pack.
If the packed quantity differs from the quantity to pack, a warning symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png) is shown in the Packed quantity after the part row has been marked as completely packed in the Package structure box. A tooltip over the warning symbol displays the same in text. Here you also see the warning symbol if the packed quantity differs from the delivered quantity. In that case you will also see the warning symbol on the button in the Location column.
In the Location column you can by clicking the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) see location name, cleared and packed quantity per location. If the pick list has been delivered, you can also see the delivered quantity here.
If a part is not stock updated, no clearance is made of that part. Order rows with row type 2 are not possible to pack. This is indicated by a warning symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png) in the To pack box. A tooltip over the warning symbol displays the same in text.
By clicking the button More info ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you can select who is Responsible to pick the part, if this should not be the same person as is selected as responsible in the Header box. Here you can also choose to show the pick instruction entered for the part and the pick instruction for the customer order.
By using the Add new row at the end (F5) button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_row.png) on the function menu, you can add rows if the pick list has a different status than Ready for invoicing.
Using the button Delete selected row ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_delete_row.png) (F6) on the function menu you can delete the marked part row.
Using the button Find ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_search.png) (Ctrl + B) on the function menu to search in all columns.
By clicking the Distribute remaining quantity using template button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_package.png) on the function menu, you can open a dialog to distribute the remaining quantity according to the selected packaging template. This button is active as long as there is a quantity left to pack. The dialog displays the rows left to pack. In the dialog you enter Qty/pkg which makes the Quantity/package on the rows to be filled out automatically with the quantity you provided. It is possible to enter a different quantity for rows if you want to. Select an Packaging template. The packaging template is filled in automatically for all rows. When needed, you can select a different packaging template on row level type. The Use mixed load setting determines if part can be packed together with other parts/packages. The options are:
- Do not use mixed load – If you choose this option you will never mix payload parts in the same package at any level.
- Mixed load, packaging – If you choose this option, no payload parts will be mixed in the same inner packaging, but inner packagings with different parts will apply mixed load on the same overlying level (for example, pallet). The inner packaging will be packed on the overlying level part by part, for example, if you have 10 boxes of part A and 8 boxes of part B and each pallet can carry 6 boxes the result will be: Pallet 1 with 6 boxes of part A, pallet 2 with 4 boxes of part A and 2 boxes of part B, pallet 3 with 6 boxes of part B.
- Mixed load, payload – If you choose this option, this means that all selected parts will be packed together (mixed) in the same inner packaging with the entered quantity/package. (Default option.)
Mark the rows you wish to pack. In the column called Remaining quantity to pack you can decrease (but not increase) the quantity you want to pack using this template. Click OK to confirm and create the package structure. The result is displayed in the Package structure box.
Using the button Go to procedure ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) you can use the link to go to related procedures for the marked row, for example, to change information on the row.
> With the drag and drop function you can use your mouse pointer to add of parts from here to the Package structure box. This is useful if you, for example, want to add packaging parts there to distribute the number of parts to pack to additional packages.
