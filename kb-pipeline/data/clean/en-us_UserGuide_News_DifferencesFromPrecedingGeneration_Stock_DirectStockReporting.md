### Direct stock reporting
- A common problem in this procedure in G4 was that the user was located in the wrong tab (withdrawal/arrival) when performing the reporting. To make it easier for the users, the work in G5 now takes place in two different boxes. You choose to report in the Withdrawal box or in the Arrival box, instead of selecting tabs.
- Instead of entering a reference in a text field as in G4, you in G5 enter a cause code (which has been registered in a table) which is then possible to search for in the stock transaction log.
- It is possible to get the posting of the direct stock reporting to be dependent of the entered cause code.
