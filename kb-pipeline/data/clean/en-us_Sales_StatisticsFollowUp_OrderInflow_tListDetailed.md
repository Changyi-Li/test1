### The Detailed list
The list is loaded and displayed based on the selection and settings you have chosen. As in all lists in Monitor ERP, you can drag and drop in order to change the column to group by.
The list shows detailed information about the value of each individual order row plus a total of the value for the selected grouping.
If quantity, price, discount, or setup price has been updated on an order row, you will see what has been modified. This is why the same order row can appear several times in the list.
