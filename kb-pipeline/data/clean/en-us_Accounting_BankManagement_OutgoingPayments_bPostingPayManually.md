### Posting
In this box you will see the posting of the outgoing payments in the Outgoing payments box.
If needed, you can here modify the posting before the payment is made. The information on the posting rows is the same as on the posting rows e.g. in the Register supplier invoice procedure.

#### Total accounting order
If you check this setting, a total posting will be shown for the outgoing payments in the Outgoing payments box. If you have entered a batch total and add all invoices in the batch in the box, then you can use the setting Total accounting order to in a clear way check that everything is correctly recorded before you save the outgoing payment. If the box ix checked, it is not possible to modify the posting.
