### Other part identities
Under this tab you can register other part identities, for example ETIM codes.
A few fixed part identities are included in the system for GTIN8, GTIN12, GTIN13, and GTIN14 (Global Trade Item Number), SGTIN (Serial Global Trade Item Number), and Other/No type. These cannot be edited or deleted.

#### Code
In this column you enter the code you wish to give the part identity. Each part identity must have a unique code that can contain a maximum of 10 characters.

#### Name
Here you can write a descriptive text as a name. You enter name texts in the company language and they are displayed in the user’s language.
By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Active
Here you determine if the part identity should be active. A part identity is active by default. Then it can be selected for parts in the part register.
