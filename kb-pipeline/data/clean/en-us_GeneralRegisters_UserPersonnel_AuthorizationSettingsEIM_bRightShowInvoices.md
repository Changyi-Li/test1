### User right to view invoice documents

#### User right to view
Here you configure user rights for individual signers to view scanned supplier invoices in for example lists, tables, accounting reports, and journals.
A signer can have access to view all invoices, invoices handled by the signer during the authorization round, or invoices according to user rights group. A new signer has access to view all invoices by default. If you select the alternative "According to user rights group", the field below will be activated where you must select a user rights group.
You can also assign user rights to view invoice documents to user who are not signers. This is made under the button EIM in the Users procedure under the tab Roles/User rights.

#### User rights group view
User rights group for the signer when viewing invoices. User rights groups must be registered under the tab User right to view invoices. Regardless of the selected user rights group, the signer can always view invoices that he/she has handled in the flow.
