### 快捷键
你可以在这里查询全部快捷键 Monitor ERP。
单击瑞典语国旗 [![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/UserGuide/SwedishFlag.png)](https://help.monitor.se/sv/MONITOR_G5/Training/ShortcutsG5SV.pdf) 或英国国旗 [![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/UserGuide/EnglishFlag_12x10.png)](https://help.monitor.se/en/MONITOR_G5/Training/ShortcutsG5EN.pdf) 以您所需语言的 PDF 格式下载此页。
| 捷径 | 描述 |
|---|---|
| Alt + 当前日程表图表 | 关闭所有程序窗口 |
| Alt + D | 查找程序 |
| Alt + 结束 | 转到寄存器或筛选器的最后一条记录 |
| Alt Gr + 8 | 在公式编辑器中显示全部可用变量（产品配置） |
| Alt + 主页 | 转到寄存器或筛选器的第一条记录 |
| Alt + 匹配行 | 最小化所有程序窗口 |
| Alt + O | 重叠程序窗口 |
| Alt + Pg Up/Pg Dn | 转到上一个/转到下一个（记录在登记或筛选中） |
| Alt + 提醒 | 重置所有程序窗口 |
| Alt + S | 平铺所有程序窗口 (并排) |
| Ctrl + B | 在列表中查找 (所有列) |
| Ctrl + 当前日程表图表 | 复制字段的值 |
| Ctrl + F | Monitor 搜索 |
| Ctrl + F2 | 重命名活动记录 |
| Ctrl + F4 | 关闭活动程序窗口 |
| Ctrl + F6 | 删除活动记录 |
| Ctrl + F7 | 在程序窗口中选择对象 (在属性管理中) |
| Ctrl + F11 | 客户订单信息 |
| Ctrl + 选项卡号 | 转到程序中的选项卡 (选项卡编号) |
| Ctrl + G | 转到程序中的字段 |
| Ctrl + 小时 | 在列表的选定列中查找并替换 |
| Ctrl + K | 复制此程序的超链接 |
| Ctrl + L | 加载数据至列表 |
| Ctrl + 匹配行 | 以 PDF 格式通过 Email 发送 (此功能可在列表中使用) |
| Ctrl + 空格 | 在公式编辑器 (产品配置器) 中显示所有可用的变量和函数 |
| Ctrl + N | 新建的 |
| Ctrl + O | 将光标置于记录选择器中 |
| Ctrl + P | 打印 |
| Ctrl + Pg Up/Pg Dn | 转到上一个/转到下一个（程序窗口中的标签页） |
| Ctrl + 数量 | 变更 / 选择在程序中显示数据的仓库 |
| Ctrl + 提醒 | 在列表中运行计算 |
| Ctrl + S | 保存 |
| Ctrl + 班次 + 当前日程表图表 | 拆分行 |
| Ctrl + 班次 + F | 筛选器列表 |
| Ctrl + 班次 + F5 | 将基础行添加到所选行 |
| Ctrl + 班次 + I | 打开程序说明 |
| Ctrl + 班次 + L | 在跟随其它程序中的活动记录 |
| Ctrl + 班次 + 匹配行 | 以 Excel 格式通过 Email 发送 (此功能可在列表中使用) |
| Ctrl + 班次 + P | 预览文档 / 列表 |
| Ctrl + 班次 + 提醒 | 再次加载活动记录 |
| Ctrl + 班次 + S | 另存为 |
| Ctrl + 标签页 | 在打开的程序间切换 |
| Ctrl + U | 激活 / 停用列表更新功能 |
| 输入 | 转到下一字段 (后台中设置) |
| F1 | 程序中活动部分的帮助 |
| F3 | 在单独窗口显示文档 |
| F4 | 查找 |
| F5 | 在末端增加新行 |
| F6 | 删除已选行 |
| F9 | 打开临时模块菜单（程序窗口最大化时有用） |
| F10 | 显示 / 隐藏侧面板 |
| F11 | 工单信息 |
| F12 | 组件登记 |
| 班次 + F1 | 该程序的帮助主题 |
| 班次 + F5 | 插入新行 |
| 班次 + F8 | 展开 / 最小化所有行 |
| 班次 + F11 | 供应商登记 |
| 班次 + F12 | 客户登记 |
| 班次 + 标签页 | 转到前道字段 |
| 标签页 | 转到下一字段 |
