### Invoicing plan list
- It is possible to choose which status types on partial invoices that you want to show in the invoicing plan list.
- The list contains more information regarding the invoicing plan, for example invoice number and ability tho review the document.
- There is also a reconciliation list in the procedure. By using this list it is possible to reconcile the remaining value per order with the corresponding value in the accounting. You can reconcile against accounts concerning advance payments and payments in arrears.
