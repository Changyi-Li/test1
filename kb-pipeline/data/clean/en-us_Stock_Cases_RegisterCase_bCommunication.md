### Communication
In this box you register communication information for the case. This includes phone numbers, mobile phone numbers, fax numbers, and e-mail addresses. For e-mail address you can determine if the address should be recipient of different documents according to the following. If the customer/supplier does not have a Recipient of entered in the Customer register or Supplier register respectively, the reference entered in the case will be used instead.
Add communication addresses from template ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_template.png) – adds communication addresses from a template that has been created in the Basic dataWith "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Case procedure. These templates can contain both internal and external addresses.
For customer nonconformities:
The e-mail address can be recipient the documents Confirmation and Response.
For supplier nonconformities:
The e-mail address can be recipient the document Claim report.
For internal nonconformities and own nonconformity types:
The e-mail address can be recipient the document Nonconformity report.
