### 电子发票导入及解释设置
按照低于步骤激活电子发票并解释供应供应商发票 Monitor ERP。
> VAT 登记号你在​ 公司信息 配置设置之前的程序。
导入电子发票的设置
> 如果你在登记科目时遇到问题，请联系人MONITOR支持中心。
在你开始使用系统中的电子发票服务之前，必须已配置以下设置：
1. 转到​​ 导出 / 导入设置 程序。
2. 选择 供应商发票 在导入类型下。
3. 检查 CrossState 电子发票。
4. 输入 公司 ID 如果你已经拥有 CrossState科目。如果不，你创建科目 创建科目 低于的按钮。一次已创建科目，公司 ID将自动填写。
5. 选择 生产 使用 CrossState 的生产科目订单导入已解释的供应商发票。生产科目的Email 地址扩展名为@crossstate.se。
6. 上传登记 / 导入发票 确定是否应已上传登记，以及是否可以导入发票。这 激活电子发票 当你已创建科目时，设置会自动激活时间。登记是指供应商登记、订单行以及根据联系人匹配的选择的审核人。登记正在上传两者从 Monitor ERP 及发票导入.你激活设置意味着 Monitor ERP 将在每个固定时间（20:00 CET）开始供应商登记和订单登记导出到 CrossState。这样做是为了让 CrossState 能够匹配你收到的发票上的供应商。这应用至电子发票和解释的供应商发票。
7. 此按钮用于人工上传供应商登记。此按钮适合在你第一个时间激活科目时使用，以确保所有内容均可正常已上传。如果正在上传中出现问题，你将通知有关此问题以及无法已上传的供应商的信息。
8. 上次发票导入 显示最近导入供应商发票的日期和时间。
9. 寄存器的最新更新 显示已发送给 CrossState 的最近登记更新的日期和时间。
10. 选择 通过 Email 激活发票的人工验证和解释，决定是否应使用手工验证和解释发票。
在里面 用于发票解释的 Email 在字段输入在通过Email进行手工验证和解释发票时应使用的Email 地址。Email 地址的域名组件从 CrossState 获取。
建议你根据以下格式输入Email 地址： companyname_abbreviatedcompanyname@crossstate.se。
> 请注意！Email 地址最多可包含 21 个字符（不包括@crossstate.se）。
你地址后，使用标签页离开Email字段。然后将为不同的发票类型和申请ID已创建两个Email地址。这样做是为了能够两者费用发票和物料发票（订单发票）。
请注意！地址将自动已更新为 艺术 和 奥姆克 在地址中的 @之前（参见低于图片中的黄色突出显示）。例如中的图片来自测试科目。在测试科目中 @efaktura。净值 用来代替 @crossstate.se 使用由生产科目（真实科目）使用。

在里面 偏差通知 Email 字段你用于输入有关 CrossState 偏差消息的Email 地址。也就是说，当 CrossState 收到不支持/无法处理的解释附件时。周三建议你在此处输入地址，以确保在将发票正在上传到 CrossState 时出现问题时你错过任何信息。
激活发票收到通知 – 在这里，你可以决定是否你收到一封包含你发送给 CrossState 进行解释/验证的每个发票的确认Email。默认下，此复选框未检查。
你选择错误消息接收者 错误时通知 按钮。如果在导出登记或导入供应商发票时出现问题，则会显示这些消息。错误消息以通知的形式显示给系统中受影响的用户。
使用 创建科目 如果你不拥有 CrossState科目，请按按钮登记一个。在显示的对话框中你第一个必须选择一个合作伙伴类型。选择 MONITOR 与 CrossState创建Monitor 合作伙伴科目。MONITOR 默认已选择。选项 瑞典光电公司 仅应在需要使用 CrossState已创建独立客户账号的特殊案件下才已选择。如果你是 CrossState 的现有的客户，并且想要开始导入发票 Monitor ERP。
确保公司信息正确，并输入联系人及其联系信息。如果你已已登记GLN 号，请联系人MONITOR支持中心以获取帮助，以便在您的科目上激活该号码（全球库位编号）。
选择 激活电子发票 订单激活电子发票以导入实际的供应商发票 Monitor ERP。
检查设置 在 Peppol 目录中登记我方 如果你想在官方 Peppol登记将您的公司登记为电子发票接收者。您可以在创建新科目时直接进行登记，或者如果你已经有科目，也可以稍后再进行注册。挪威的相应设置是 在 ELMA 登记中登记我方。这是订单在ELMA 登记中显示为电子发票的接收者。
检查 我已阅读并接受此服务的条款 / 条件 盒子。
科目​​ 创建科目 按钮。该科目是通过与 CrossState 的 API连接已创建的。如果一切正常，你将自动收到您的公司 ID。现在，科目登记已已完成。
保存。

#### 显示已登记的信息
当你输入了公司 ID或已创建了科目后，此按钮可用。在这里你可以看到已登记的公司信息和有关电子发票的已登记信息。

#### 激活电子发票
即使你在已创建上面科目时不选择自行激活，此按钮仍然已激活。如果在注册时不与电子发票接收者创建科目，则会出现红色消息。
创建电子发票科目已失败的原因是因为您的组织信息与其他操作员相关联。例如，如果您的公司在不同的 ERP系统中使用电子发票，然后使用了不同的操作员，则可能会出现这种情况。
如果 是 这样 的案件,你必须联系人你 的旧的操作员并 要求 他们释放你的 组织信息.你必须主动通知您的旧的操作员，你想要更改操作员。这类似于与某个操作员绑定的手机号，你必须要求他们将该电话号码移动到其他操作员。
信息已释放一次，你可以点击 激活电子发票 再次。
> 提示！如果你不确定你拥有哪个操作员，请联系人MONITOR支持中心寻求帮助。
提前计划更换操作员是明智之举，仓储费用你就可以确保在上线日期你正确的操作员并你使用电子发票。然后，你必须通知您当前操作员，你将终止协议，并告知他们应在日期释放信息以供新建操作员激活。
