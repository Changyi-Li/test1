### Settings

#### Payment method
Here you select which payment method you want to confirm. The format of the confirmation file, or which import plugin that is used, is linked to the payment method. If you have entered a default payment method for electronic outgoing payment in the Bank settings procedure, this payment method will be suggested.

#### Path
Here you can see the path to the confirmation file. This path is created in the Settings for export/import procedure. You can also enter a path to a filing folder.

#### Load file
With this button you open the Explorer where you select which file you want to load. When you have selected a file, data will be loaded and presented in the Confirmations box.
Monitor ERP can load confirmation files in the format CAMT053 regardless of the file's version number.

#### File date
Here you see the date when the file was created.

#### Voucher text
Here you select the text that should be used as voucher text on confirmations that you register. The default text is “Outgoing payments”. In the Voucher texts procedure you can create texts to use as pre-defined voucher texts.
