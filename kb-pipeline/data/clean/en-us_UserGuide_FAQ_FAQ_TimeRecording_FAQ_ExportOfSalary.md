### FAQ – Export of salary basis
Where can I change the path for salary export?
The path for salary export can be changed in the Basic dataWith "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Attendance procedure under the Export settings tab in the Salary program box.
When I’m exporting a salary basis, I get an error message saying “invalid characters in the path”, why?
Check the path for the files. You can find the path in Basic data – Attendance under the Export settings tab in the Salary program box. The is most likely a character in the path that shouldn’t be there.
We have changed our salary program, how do I change all salary types?
You can rename the existing salary types and give them new numbers. In cases where two old salary types must be merged, you can use the Alias at export field to give the salary type the correct number when exporting. Please note that Export of salary basis is an option.
