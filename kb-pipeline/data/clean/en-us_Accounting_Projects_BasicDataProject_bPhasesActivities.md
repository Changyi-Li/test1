### Phases/Activities
In this box you add rows with default values for phases/activities which should be included in the activity template. The columns are the same as the ones under the Activities tab, except for those described below.

#### Preceding activity/phase
Here it is quick and easy to create a link/dependency to the preceding activity. It is possible to select one or multiple activities as preceding activity. A preceding activity with a dependency can also be an activity in a different phase. As soon as you have created a dependency between activities, you will no longer have the option to create dependencies between phases and the other way around. It is not possible to mix dependencies between activities and phases in the same list.

#### Dependencies (D)
The Dependencies button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) becomes activated if you have selected a preceding activity. By clicking the button you see which activities that are preceding and you can also select Dependency type between the activities.

#### Comment
The comment can be seen in multiple procedures where the activity is used. It is possible to edit the comment.

#### Files
Linked filed can be seen in multiple procedures where the activity is used. You can add and delete files.

#### Planned time
You can set a default planned time for the activity.

#### Lead time
You can set a default lead time for the activity.

#### Queue time
You can set a default queue time for the activity.

#### Print on project report
With this checkbox you determine if the activity should be shown on the project report. This checkbox will by default have the same setting as the setting of the activity in question under the Activities tab.

#### Reminder
Here you determine if the activity should generate a reminder. A reminder is sent as an internal message in Monitor ERP to the person registered as responsible for the activity.

#### Mandatory
Here you decide if it should be possible to delete the activity from the project or if it is mandatory to include it.
