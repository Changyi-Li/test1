### The Overhead tab
Overhead
In the Overhead box, you can register multiple overhead types. The overhead types must first be registered in the Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Sustainability procedure. Having multiple emission types means that you can use different overheads when calculating different product groups.

#### Overhead types
Here you select the Overhead types.

#### Allocation key for OH
With the Allocation key for OH you decide how the emissions handled as overhead should be distributed/allocated. The allocation keys you can choose between are Quantity, Total production time, and Weight.

#### Total number of manufactured parts
If you selected the Quantity allocation key, you should here enter the yearly total number of manufactured parts.

#### Total weight of manufactured parts
If you selected the Weight allocation key, you should here enter the yearly total weight of the manufactured parts.

#### Total time for manufactured parts
If you selected the Total production time allocation key, you should here enter the yearly total production time of the manufactured parts.

#### Emission factor OH
Emission factor OH is calculated based on the Allocation key for OH you have selected and will be used in the sustainability calculation.
Scope
In the Scope box, the same columns are available as in the Budget and result field.

#### Distribute as OH
Here you enter the values to be used as overhead in the calculation of emissions. This refers to the emissions that you have not allocated in detail such as production hours, materials, transport, etc.

#### %
In the percentage column, you can see how much the different scopes and categories represent on an annual basis.

#### Comment
Here you can enter a comment for the scope.

#### Active
With this checkbox you decide if the scope is active and is used in the sustainability calculations.
