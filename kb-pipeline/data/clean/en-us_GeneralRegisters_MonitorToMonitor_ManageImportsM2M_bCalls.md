### Calls

#### Delivery date
The delivery date from the import file. If "DeliveryDatesAdjustedForTransportTime" is "true” in the file, the date set as the delivery date in Monitor ERP is used, otherwise the transport days on the customer are deducted from the delivery date (taking non-business days into account).

#### Quantity
The quantity from the import file. This is the called quantity in Monitor ERP.

#### Cause code
The matching cause code from the file. If it is not matched, the cause code is Normal.

#### Type of requirement
The matched type of requirement from the file. If it is not matched, the cause code is Forecast.

#### Reference number for delivery
From the import file, available via More info.

#### Reference number for manufacturing
From the import file, available via More info.
