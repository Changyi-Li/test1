### Settings – Order simulated price

#### Language
This setting determines the language used for part name and unit in the list. Provided that there are translations specified. Note that headings etc. are always written in the language of the user.

#### Show
This setting determines if price lists and supplier links where the price each is equal to zero (0,00) or is missing also should be printed.

#### Order type
The order type is set to the logged in user's default order type. If the user does not have an order type, then the first one will be used. You can change order type to affect the result in the list.

#### Supplier
Here you select from which supplier you want to load prices.

#### Currency
Here you see the supplier's currency. The exchange rate is displayed to the right. If the selected supplier's currency differs from the currency in the price list, the price will be recalculated based on the supplier’s currency.

#### Order of priority for quantity
In this table you can move the alternatives up or down to select in which order of priority the quantity alternatives should be used when calculating price.
- Order quantity – The quantity is based on the order quantity entered under the Planning tab in the Part register procedure.
- Any quantity - The quantity is based on the quantity entered in the field.
