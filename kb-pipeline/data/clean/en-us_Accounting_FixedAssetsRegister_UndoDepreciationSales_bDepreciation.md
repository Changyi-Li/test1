### Depreciation
In this box you can undo depreciation for a separate fixed asset. It is possible to undo multiple depreciation items back in time.

#### Undo
You mark the Undo checkbox for the rows you want to undo.

#### Depreciation date
Here you see/enter date for the sale/retirement. It is possible to enter manually. The log date when you performed the actual retirement cannot be affected, since this is always logged in real time.

#### Voucher date
This field shows the same date as the field above by default. You will receive a warning if the voucher date is not within the open periods, if the record refers to a booked record. It is possible to change the date if you have checked the Undo checkbox on the row.
