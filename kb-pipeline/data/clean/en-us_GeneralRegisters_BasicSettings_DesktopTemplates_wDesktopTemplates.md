## Desktop templates
In this procedure an ERP manager or other qualified personnel can create desktop configurations that will be used as templates. The users can then choose from these templates.
The purpose of these templates is to have the same desktop configuration per group, role or user in the entire company.
A user then selects a desktop configuration by choosing the alternative According to template under Desktop in backstage. This way the users do not have to create own desktop configurations. However, it is still possible to create own desktop configurations.
The procedure is designed in the same way as the function Desktop in backstage. But in this procedure you can also add, delete, and copy desktop configurations.
