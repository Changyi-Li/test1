## Register fixed assets object
In this procedure you can register and modify fixed assets objects. Fixed assets (objects) refer to machinery and equipment, buildings, etc. which should be registered as assets in the fixed assets register. Depreciating the fixed assets in the register is possible based on the settings configured for the objects. You can also register objects which should not be depreciated. You can also create and update fixed assets objects from the accounts payable and the registration of vouchers.
Save as
If you use the Save as button you can name the new fixed asset or you can leave the field empty, then the fixed assets object will be given a number according to the number series. Everything is copied from the existing fixed assets object except for voucher number, voucher number series, consecutive number, initial acquisition value, and event log. Information regarding the depreciation made for the object you copy, will also not be copied.
Data in the procedure
The procedure mainly handles data from the fixed assets objects and from certain tables, for example sales logs and depreciation logs. Data from the general ledger transactions are managed here.
The object's number
When registering a new record you can either manually give the object a number or it can get a number from the number series. If the group has a prefix entered it can be used in the number series.
Investment in progress
In this procedure you can handle investments in progress, that is, a fixed asset being built/constructed. For such objects, no depreciation will be made. You can activate such an investment and convert it into an active object at the same time as the system change the booking of the value between the account for construction in progress and regular fixed assets account.
If a fixed assets register from a previously used system should be registered you can use a function to register a historical fixed asset.
Linking
By using the Go to procedure function ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) on the toolbar you can go from this procedure to other procedures where you can make extra depreciations on objects, sell/retire objects, or undo depreciations and sales.
