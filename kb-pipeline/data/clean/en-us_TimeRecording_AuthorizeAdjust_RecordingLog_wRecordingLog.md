## Recording log
In this procedure you can load lists containing recording items.
Recording items refers to attendance and absence recording items, work recording items, and the generated salary types. You can also see discrepancies between planned and recorded time, and totals per salary type. You can regard the recording items as a log in chronological order.
The information loaded to the lists depends on the selected list type. In the selection and under Settings, you choose the personnel you wish to show.
> There are no presentations to select among for the list types concerning attendance in this procedure. They are "locked" from editing, that is, it is not possible to create own presentations. The reason for this is these list should always have a uniform design/format.
List types
In this field you select the list type to load.

#### Recording items
This list displays records with attendance recording items grouped by person.

#### Salary types and Salary types – Total
These list types display the recording items per salary type and person. The lists are grouped by person. The detailed list shows date and time for each recording item. It also shows salary type, quantity, and action. The total list type shows quantity totaled by salary type and person. At the bottom of the list you see a total per salary type for all persons in the list.

#### Recording and total per salary type
This list shows the same information as the list type Recording items, plus a total of number of hours per salary type and person.

#### Authorization status
This list shows the days containing recording items which both have and have not been authorized. The list is grouped by person. The list shows date, schedule number, and name of the schedule. For each person you see employee number, name, authorized by, and authorized when.

#### Discrepancy between planned/recorded time
This list shows if there are time differences between planned and recorded time, that is, difference between attendance/absence and the scheduled time.

#### Log list – Attendance
This list shows all attendance recording items (In/Out), absence recording and overtime recording items in chronological order, day by day.

#### Log list – Site
This list is available if site recording has been activated. This is done with the system setting called Activate site recording. This list shows all attendance recording (In) and recording of breaks together with the site recorded. The recording items are displayed in chronological order, day by day.

#### Work recording
In this list you see work recording items made by personnel and machines. Only in this list is it possible to see machine recording items.

#### Work in progress
In this list you see work recording items which are in progress.
Selection rows
In a list procedure there is always a tab called Selection where you can select data records in different intervals from the database. The data records are then loaded by using the Load button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_display_list.png) in the toolbar of the procedure.
Under Selection rows in the backstage of the procedure, you can choose which selection rows that each list type should have, under the Selection tab in the procedure. In the List type field you select for which list type you want to customize the selection rows.
One table shows selection rows possible to select and one one table shows the selected selection rows. You can add, delete, or move selection rows by dragging and dropping the selection rows with your mouse pointer.
Using the Save button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_save.png) you save the selected selection rows.
Read more about this in the [Selection](../../../UserGuide/GeneralFeatures/Selection.htm) topic.
