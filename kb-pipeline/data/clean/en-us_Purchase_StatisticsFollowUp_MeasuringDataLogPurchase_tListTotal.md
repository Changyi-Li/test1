### The Total list
This list type have are two presentations which show totals for planned and reported measuring per order row on arrival reported purchase orders.
The presentation called Reporting status of rows per purchase order row will add together the number of measuring points that are planned and that have been reported.
The presentation called Reporting status of forms per purchase order row will add together the number of measuring forms that are planned and that have been reported.
The number of remaining measuring items per purchase order are also shown in a chart. This list type can, for example, be used to find the order rows where none of the measuring points have been reported.
