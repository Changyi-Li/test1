### Time banks
Time banks are used in order to save recorded time outside scheduled working hours. You can have different time banks for example for flex and makeup. When you install the system, the time banks "Time bankTime banks are used in order to save recorded time outside scheduled working hours. Different time banks are for example used for comp time, makeup time, flex time (positive/negative), and shorter working hours." and "Flex time" are included.

#### Active
With this checkbox you determine if the time bank in question should be active. This means that the overtime type becomes available to select in different parts of the system.

#### Name
In this column you see/enter the name of the time bank. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Salary type for rounded overtime
Here you register the salary types which should be used for time bank changes resulting from rounded overtime, for transfer to the payroll program. The time bank where rounded overtime should be placed, is entered on the Parameter groups procedure.
