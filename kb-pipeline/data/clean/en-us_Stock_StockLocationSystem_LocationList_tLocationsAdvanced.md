### The Locations – Advanced list
This list type can be used for administration/handling of the locations. Here you determine the properties for volume and weight You can also see how much of the locations' capacity is used, in total volume/weight, and in percent.
Location templates can be used to easily define the size and weight the location holds.

#### Name
Here you see the location's name. A validation error will occur if the name of the location and the name of the coordinate do not match, for example, if the number of characters differ. You can edit this by clicking the Coordinates button.

#### Allow multiple parts
With this setting you decide if the location allows that one or several different parts can be stored at the same time on the location.

#### Maximum number of packages
Here you can see the maximum amount of packages a location is allowed to contain.

#### Occupancy (m3)
Here you are able to see the occupancy in terms of volume. If the location is overloaded, an exclamation mark is shown in the field.

#### Volume occupancy (%)
Here you see occupancy in terms of volume, but in percent. Please note! When the occupancy is more than 100% you will see an exclamation mark in the Occupancy (m3) field.

#### Occupancy (kg)
Here you are able to see the occupancy in terms of weight (measured in kilograms). If the location is overloaded, an exclamation mark is shown in the field.

#### Weight occupancy (%)
Here you see occupancy in terms of weight, in percent. Please note! When the occupancy is more than 100% you will see an exclamation mark in the Occupancy (kg) field.

#### Comment
By clicking this button you access a text editor where you can write and format text, insert images and signature, and hyperlinks, etc. When a comment/text exists, the symbol on the button will change from an empty speech bubble ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_no_comment.png) to a filled speech bubble ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_comment.png).

#### Block status
Here you can block and unblock locations.

#### Block message
Here you can enter a cause regarding why the location is blocked.

#### Storage type
Here you can select which storage type should be applied for the location. The storage type must first be defined in the Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Advanced stock management procedure.

#### The Coordinates button
By clicking the Coordinates button you can see the coordinate structure.

#### Coordinates
Here you see the coordinates.

#### Location template
Here you can select a location template to be used in order to easily define the size and weight the location holds.

#### Description
Here you see the location template's description.

#### Min. width
The minimum width allowed for the location. This is loaded from the location template but you can also enter it.

#### Max. width
The maximum width allowed for the location. This is loaded from the location template but you can also enter it.

#### Min. length
The minimum length allowed for the location. This is loaded from the location template but you can also enter it.

#### Max. length
The maximum length allowed for the location. This is loaded from the location template but you can also enter it.

#### Min. height
The minimum height allowed for the location. This is loaded from the location template but you can also enter it.

#### Max. height
The maximum height allowed for the location. This is loaded from the location template but you can also enter it.

#### Max. volume
The maximum volume allowed for the location. This is loaded from the location template but you can also enter it.

#### Max. weight
The maximum weight allowed for the location. This is loaded from the location template but you can also enter it.
