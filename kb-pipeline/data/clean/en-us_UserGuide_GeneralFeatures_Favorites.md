### Favorites
By clicking the Favorites button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_favorites.png) on the toolbar in procedures you can add, change, and delete the procedure in question as a favorite.
First you must have added the Favorites desktop component in an Own desktop configuration.
> Please note! It is not possible to add procedures as favorites in desktop configurations which are based on According to template.
When you add a procedure as a favorite you can give it your own name. If there are default values saved in the procedure you can choose if a default value should be loaded when you open the procedure as a favorite. You can also choose in which desktop component of the Favorites type you wish to add the procedure, in case you have more than one.
When you have added the procedure as a favorite, a link to the procedure will be displayed in the desktop component.
