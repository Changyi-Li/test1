### VAT report – Construction
Under this tab you create the VAT reports. These reports can then be printed in the Print VAT report procedure.

#### Row type
In this column you determine if the row should be of the type VAT row, Heading, or Total row.

#### Number
Here you see/enter the number of the VAT row which will be shown on the report.

#### Name
This text will be shown in the VAT report, as a description of the VAT row. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### VAT type
In this column you see/select the contents of the row, for example Output VAT or Sales.

#### VAT
Here you see/enter the VAT percentage which applies to the row.

#### Select VAT rows
If the row is of the type Total row or VAT row you will in this column see a button. By clicking this button you get the chance to enter which VAT rows that should be totaled.

#### Control number
Here you see/enter a control number for the VAT control. You handle the control number under the VAT control tab.
