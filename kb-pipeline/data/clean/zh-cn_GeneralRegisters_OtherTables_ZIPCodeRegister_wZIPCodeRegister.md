## 邮编登记
在此程序中，你可以创建和/或编辑不同国家 / 地区的邮编表，将邮编与使用这些邮政编码的国家 / 地区/地区的城市/省份以及州/地区联系起来。
使用按钮 导入邮编 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/button_import.png) 你可以导入包含已选择国家 / 地区邮编表格的文件。这样，你就不人工的添加每个邮编。导入文件应为制表符分隔的文本文件，并使用 UTF-8 编码。该文件应按邮编订单排序，并且一个邮编在文件中仅出现一次。文件不能包含? / ( ) * 等特殊字符。但是，已允许连字符 - 。该文件最好包含与程序中的表格相同的三列。但是，可以仅使用第一个两列邮编和城市 / 省。
在这里你查询不同的示例 [地址格式](../Countries/bCountries.htm#Adressformat)。
对于瑞典的邮编，你文件订单 [邮政号码服务](https://www.postnummerservice.se/)。
