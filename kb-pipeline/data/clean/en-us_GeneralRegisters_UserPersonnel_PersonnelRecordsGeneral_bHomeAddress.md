### Home address
In this box you can add country for the person's home address.
The address format is determined by the selected country, in the same way as in other address boxes in the system. By using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) you can see which address format is used. You can also preview the address in the current address format.
