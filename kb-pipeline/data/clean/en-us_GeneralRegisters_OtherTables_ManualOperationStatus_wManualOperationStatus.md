## Manual operation status
In this procedure you can add, change, and delete manual status for operations. This is done in a table.
The manual operation status is an extra status you can enter for operations when priority planning in the Priority planning and Priority plan list procedures. Manual operation status is shown for the operations in the priority plan in the Recording terminal.
This status is useful if you, for example, need to describe other events on operations before they have started. When the Tools & Maintenance option is used you also find an extra list type in the Priority plan list. There you can use manual operation status as tool status for the operations, and describe if the tools for the operations are ready so the operations can be started.
When you install the system, there are a number of different status items included as examples. These can also be edited or deleted as required.
