### Posting
In this box you can enter the posting of the fixed asset. In the column for Fixed assets account there is an information field showing the fixed assets account to which the fixed asset belongs. This account is set according the the fixed assets group. If the fixed asset is an investment in progress you will here see the account for investment in progress. The fields referring to dimensions are used when posting depreciation made on the fixed asset. You can see the dimensions via Lookup The Lookup feature is a powerful search tool which allows you to search and load information from large registers. You open the Lookup feature by clicking on the dropdown button or by using F4 on your keyboard. feature. It is not possible to enter historical projects.
If you use the depreciation method Straight-line/deprecation difference, you must also enter the accounts for Depreciation difference and Accumulated depreciation difference.
