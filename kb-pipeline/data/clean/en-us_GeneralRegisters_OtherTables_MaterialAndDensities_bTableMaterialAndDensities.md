### The Material and densities table
This table consists of rows with columns where you enter information about density and unit for different materials.
Use the Add main row at the end button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_row.png) (F5) to add a row for a new material density. You can enter an optional number of rows, as needed.
Using the Delete selected row button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_delete_row.png) (F6) you can also delete rows If you delete a row with a material density, a check is made to see if it is used in a weight calculation. If the material density is in use, a dialog is shown letting you know for which part numbers/material part numbers the density is used.
When you install the system, material densities are included for steel, aluminum, bronze, glass, copper, nickel, brass, plexiglass, and silver.
The Row column shows a row number that can be edited. It is used for sorting purposes of the rows.
In the Material column you enter a text for the name of the material. By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.
You enter optional values for Density, Weight unit, and Volume unit in the columns in question.
The unit for density is always kg/dm³ when weight-calculating in Monitor ERP. If the density you enter is provided in any other unit, you must enter a numerical value as Factor which will convert the density into kg/dm³.
With the Active checkbox you determine if the material density can be selected when performing weight calculations.
