## Terminal settings
> You only need to use this procedure if you wish to be able to control different functions available in the recording terminals.
In this procedure you can configure different functions for recording terminals, linked to specific terminal users*.
You add the terminal users for the recording terminals where you wish to be able to control the functions. Then you configure the functions that each of these recording terminals should/should not use.
* A terminal user is a user intended for a recording terminal, that is, a user license that should be logged-in to Monitor ERP on a recording terminal/computer.
