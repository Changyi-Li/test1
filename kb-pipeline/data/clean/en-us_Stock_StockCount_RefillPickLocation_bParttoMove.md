### Pick location to refill
In this box you see the pick locations that need to be refilled.
Here you check the box Apply for the pick locations you want to refill. The field Quantity will then be pre-filled with the pick location's refill quantity. However, this can be changed. In the box Buffer location to move from, the same quantity will be filled in automatically n the Quantity to move field. For the selected part row in the list you see the part's buffer locations in that box.
If the refill quantity does not match the quantity that has been physically moved by stock personnel, you can change the pre-filled quantity. The document Refill pick location is used as basis for the reporting.
