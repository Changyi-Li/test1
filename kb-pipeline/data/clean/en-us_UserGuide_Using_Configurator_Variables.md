### Variables
In this procedure you create and update variables.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/TrainingMaterial/ConfiguratorVariables.png)](../../../../Resources/Images/TrainingMaterial/ConfiguratorVariables.png)
The variables can be of the following types:
![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/TrainingMaterial/ConfiguratorVariableTypes.png)
The variable's code is used when you write formulas and rules. The variable code is written within square brackets "[ ]" in formulas. The variable's name is shown on documents and when configuring orders. Please note! The variable code is case sensitive. This means the variable codes "Width" and "width" are two separate variables.
Most values you register here for the variables, you can override when they are used in a configuration group.
