### Schedule cycles
- In the Schedule cycles procedure you link multiple days to create a chain. In the normal case this chain is 7, 14, or 21 days long. There is no limitation regarding how many days can be included in a cycle, as long as it is evenly divisible with 7.
- To each cycle you link a holiday calendar and which overtime schedule should apply for non-working weekdays. Then you link these to the employees and it will be used until something else is entered for the employee in question. This is used instead of the calendars which in G4 were created per year.
