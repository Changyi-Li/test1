### Warehouses
If you have installed the option Warehouse, then this box will be displayed. Here you can add warehouses that you want to use in your company.
You add a new warehouse by clicking the button Add new row at the end ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_add_row.png) or by pressing F5. Then a dialog box appears where you must enter Code and Name for the warehouse as well as select Copy from warehouse. You select the information to copy from the selected warehouse. The following information is available: Administrator, Supplier links, Planning info on part, Customer information, Supplier information, and User rights. However, supplier links cannot be deselected. When you click OK in the dialog box, the warehouse will be added to the box. You can then select a Customer and Supplier.
If needed, you can later change the Code, Name, Customer, and Supplier for the warehouse.
> Please note! You cannot delete a new warehouse that you have added. If you for example have made any incorrect selections in the dialog box for the new warehouse you must instead close the procedure without saving and start over again. That is why you need to make sure that the warehouses you add have the right settings and that you only add warehouses that are used in the company. No users should be logged in to Monitor ERP when a new warehouse is added.

#### Code
Here you enter the code for the warehouse. It can consist of a maximum of 10 characters.

#### Name
Here you enter the name of the warehouse. It can consist of a maximum of 35 characters.

#### Customer/Supplier
In these two fields you select the customer number for the internal customer who "purchases" to this warehouse, as well as the supplier number for the internal supplier who "sells" to this warehouse. An internal customer/supplier must first be registered in the customer register and supplier register. A warehouse can be both a customer and supplier, or it can just be a customer or a supplier. It is also possible for a warehouse to be neither a customer nor a supplier.
> This means that you only have to select customer and suppler for those warehouses where it should be possible to acquire parts between the warehouses.
