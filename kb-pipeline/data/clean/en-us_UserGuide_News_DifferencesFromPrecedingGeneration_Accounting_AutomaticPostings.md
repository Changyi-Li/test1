### Automatic postings
- Each automatic posting has an identity, that is, it has a number and a name. This means they are possible to search for using the LookupThe Lookup feature is a powerful search tool which allows you to search and load information from large registers. You open the Lookup feature by clicking on the dropdown button or by using F4 on your keyboard. feature.
- It is possible to copy an automatic posting by using the button Save as.
- It is possible to create automatic posting which should apply for an interval of accounts and dimension codes.
- The system setting called AutoCoding/AutoAllocation at account level? does not exist in G5. For each automatic posting you can instead enter, per dimension, which term should apply for the automatic posting to be made. For example that cost center must be empty, or must be entered, or must be recorded for one or an interval of cost centers.
- It is possible to test/simulate a recording in order to see how the automatic posting will be made.
- You can go to the Chart of accounts procedure by using a link.
