### The Clearances list
In this list you will only see parts for which clearances have been made. A clearance can e.g. be made for manufacturing order, customer order, pick list for manufacturing, or pick list for customer order. The date of the clearance is shown in the list.
A clearance row can have been made against several locations. In that case, each location is displayed on a separate row but applies for the same requirement date, clearance type, and order number/pick list.
If traceable parts are cleared you can see for which serial number/batch this has been made. This is shown in the Serial number A serial number is a number that is used for traceability for parts on entity level. and Batch number A batch number is a number that is used for traceability for a set of or a batch of parts. A purchased material can have a batch number that should be able to be traced back to a certain charge number from a supplier. columns. The disposable balance is loaded form the serial number's/batch's balance if there is a serial number/batch. If not, the location's balance will be shown instead.
Incorrect clearances (which does not have the type of clearance) can be removed.
