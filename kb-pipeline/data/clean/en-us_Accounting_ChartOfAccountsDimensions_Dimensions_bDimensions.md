### Dimensions
The following dimensions are available in the system from the start: Project. You can handle these or delete them, if they have not been used. It is also possible to add own dimensions. These as well can be deleted only if they are not used.
You can use a maximum of 8 dimensions.

#### Dimension number
Here you see the number of the dimension. These numbers are created automatically by the system and cannot be changed.

#### Abbreviation
Here you enter an abbreviation of the name of the dimension. It is used for example in reports since it requires less space. The abbreviation can contain a maximum of 5 characters.

#### Link register
Here you select if the dimension should be linked to a register. The default option here is No. This means the dimension is not linked. You can choose among the following registers:
- Project*
- Product group
- Part code
- Part
- Department
- Work center A work center is a part of the factory. It can be a single machine or a group of machines, a single workstation or a group of workstations.
- Customer (on order)
- Customer (on invoice)
- Supplier
- Employee
- Customer group (on customer)
- Customer district
- Customer type
- Supplier group (on supplier)
- Supplier district
- Supplier type
* You can only link one dimension to a register. If you choose not to link to the dimension called Project to the project register, it means that the dimension can be posted for the codes you enter in the Dimension codes box. If you choose to link to the project register it means that the dimension can be posted on the project numbers registered in that register. In the Dimension codes box you will see the existing projects.
