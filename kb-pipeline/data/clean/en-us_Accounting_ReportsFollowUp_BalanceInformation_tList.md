### The Balance information list
The upper table displays a balance overview for the accounting year with opening balance, debit and credit per period, period balance, accumulated balance per period. You can compare with accumulated balance per period for the previous year. You can also compare with the budget number you selected under the Selection tab, either as budget per period or as accumulated budget per period.
You can view the information in a graphical chart by using the Chart ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_chart.png) button.
You can mark the periods you wish to include in order to see detailed information about these period balances. By default it is the current period which is selected to be included in the list.
The bottom table in the list shows detailed information with vouchers per account for the periods marked in the upper table. For certain vouchers you can via a button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_form_viewing.png) view documents for invoices and journals. You can see postings for entire vouchers by expanding the voucher rows. Additional information about the vouchers can be added via the More information button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) on the row. At the very bottom the total of the debit and credit columns is displayed. By using the function buttons you can access the search function, filter function, copy accounts to the Clipboard, and also links you can use to go to related procedures.
