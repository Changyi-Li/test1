## Cause codes
In this procedure you register different cause codes.
You can register cause codes for:
- Delayed purchase orders
- Customer order changes
- Modified manufacturing order
- Direct stock reporting
- Lost quotes
When for example a user marks a purchase order with confirmed as delayed, the user can select one of the cause codes that you have registered here. For each respective code you can select that it should be mandatory to enter a comment.
You can delete a cause code that you no longer need. A check is then made to see if it is used somewhere in the system. You cannot delete a cause code that is used. However, you can set it as inactive to prevent them from being used in future reportings.
