### User rights
There are specific user rights for the Revenue calculation and Print revenue calculation journal procedures.
Sufficient user rights are included for these procedures in the following roles: ERP manager, Financial manager and Financial assistant.
[![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/UserGuide/PCM3.png)](../../../../Resources/Images/UserGuide/PCM3.png)
You cannot edit forecast values in the Revenue calculation procedure if you do not have sufficient user rights to modify projects. This is because the values will be updated straight away in the project when you save.
> If you change the user rights, it is important that users with the permission to modify the revenue calculation also have permission to modify projects. Otherwise, the modifications you make in the forecast in the revenue calculation will not be saved in the project.
