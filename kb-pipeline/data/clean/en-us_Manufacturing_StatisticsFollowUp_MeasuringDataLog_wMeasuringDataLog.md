## Measuring data log
In this procedure you can load a list containing the reported measuring data for operations in manufacturing orders.
Measuring data is reported in the Report measuring data procedure for subcontracts and internal operations.
List types

#### Detailed
The detailed list shows the reported measuring data on operation rows. The list has a presentation grouped by part number.

#### Trend
This list provides you with a quick overview regarding how numerical measuring values have changed over time. These values are presented both in a list and in chart form.

#### Total
This list type has two presentations which show totals for planned and reported measuring per operation in manufacturing orders which have been created. The presentations adds together the number of measuring points, and also adds together the number of measuring forms, that have been planned and reported. The number of remaining measuring items per manufacturing order are also shown in a chart. This list type can, for example, be used to find the operations where there are measuring points which have not been reported.
Presentations
The presentations determine how the selected list should be displayed/presented. For example if it should be presented as grouped or as total. There are some standard presentations included in the program.
In most procedures where you can load lists, you are also able to create your own presentations.This is done under Presentations in the backstage of the procedure in question. If you create your own presentation you can for example choose if it should have a drilldown function and a drilldown filterering.
You can select which columns the list should consist of, and for each of the columns you can configure grouping, sorting, aggregation, and if the column should be shown in chart form and if it should be printed. Additionally you can also make printout settings, chart settings, and settings regarding extra aggregation.
Read more about this in [Presentations](../../../UserGuide/GeneralFeatures/Presentations.htm).
