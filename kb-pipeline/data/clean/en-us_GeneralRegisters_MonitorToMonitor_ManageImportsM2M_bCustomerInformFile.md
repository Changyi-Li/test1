### Customer information – Import file

#### Usage
Usage loaded from the import file.

#### Customer's delivery schedule no.
The customer's delivery schedule number from the import file.

#### Customer number, receiver
The customer identity from the import file. This value is used to find a matching customer in the customer register.

#### Our supplier number
The customer’s identity for us from the import file. This value is used to find a matching customer in the customer register if no match could be found on Customer number, receiver (see above).

#### Name, receiver
The name of the customer from the import file. By clicking the ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) button you can see the address fields from the import file.

#### Delivery dates adjusted
Here you can see whether the delivery dates have been adjusted for transport time.
- Yes – The delivery dates have been adjusted by the customer when the file was created, so you do not need to adjust them. The delivery dates show when you intend to send the parts.
- No – The delivery dates have not been adjusted by the customer when the file was created, so if there is a transport time entered in the Customer register, the system will adjust the delivery dates. The delivery dates in the file show when the customer expects to receive the parts.
