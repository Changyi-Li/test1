### Exceptions
In this box you can register, copy, and delete exceptions from authorization limits entered for the signers. The exceptions can be used as templates with predefined authorization limits and head signers, as well as terms per authorization limit.
Examples when using exceptions and authorization limits:
You want to set common authorization limits for a certain group of signers for the purchase department. The following then applies to the purchase department:
- Suppliers with category A = amount limit 100 000
- Suppliers with category B = amount limit 15 000
In the first step you create a code and name for the purchase department in the Exceptions box. Then you enter this code on all signers who belong to the purchase department in the Exceptions field under the Signers tab.
In the box Authorization limits you enter which limits should apply. In this case it is two rows, one row for category A and one for category B.
Generally, the following applies:
Suppliers outside these limits follow the general authorization limit entered for the signer. If such a limit does not exist, the invoice will not be sent to a head signer.

#### Number
Here you can see the number for the position of the row. This field is numerical. A new row will by default be assigned the next available number. The table/list is sorted by this column. A number is unique and cannot occur on more than one row in the table.

#### Name
Here you can write a descriptive text as a name. You enter name texts in the company language and they are displayed in the user’s language.

#### Translations
