## Automatic postings
In this procedure you can create a register for automatic postings. These automatic postings make it possible for the system to automatically perform several extra postings. These will be made in connection with transactions being recorded in the system. In this procedure you define the terms needed to make the postings take place automatically and also to determine what the posting should result in.
Automatic posting is for example used when social security contributions should be automatically calculated and posted in connection with posting the salaries. Another example is the automatic posting EU purchases based on the posting of EU VAT.
In connection with posting in the system you can temporarily deactivate the automatic posting for a specific posting row in for example the Register vouchers procedure. Uncheck the Automatic posting active checkbox on the posting row before you enter the amount on the row. The Automatic posting active checkbox is by default placed under button the More info on the row.
You can test the automatic postings by using a button on the toolbar. It is also possible to copy an automatic posting by using the button Save as.
You can test the automatic posting without any voucher becoming registered. By doing this you can see if the terms have been configured to make the posting take place for the correct variant of posting string and that the rows become correct. First you fill out the upper box and then you can click the test button. The result is shown in the bottom box.
