### File settings

#### Format
In this field you enter which type of export to be made. It can be SIE type 4E, SIE type 4I, or other export formats defined in the Settings for export/import procedure.

#### File path
In this field you enter the path to the folder where the export file should be created. You can save the file on a local drive or on a network drive. A UNC path should also be entered if you select a network drive. It is mandatory to enter a file path here.

#### File name
In this field you enter the name of the export file. It is mandatory to enter a file name here.
SIE4I files should have the file name extension .si and SIE4E files should have the extension .se.
