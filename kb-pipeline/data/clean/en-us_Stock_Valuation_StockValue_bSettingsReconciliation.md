### Settings – Stock value change/Reconciliation

#### Reconciliation of general ledger
This setting is activated by default if Stock accounting Stock accounting is a standard feature in Monitor ERP. It is used to continuously post all stock transactions in the system. This way the stock value in the Stock module matches the recorded value in the Accounting module. Changes in stock which are due to changed standard prices, direct stock reporting, arrivals and deliveries, stock count differences, nonconformities (cases), etc. will automatically be posted and give a better understanding of changes in stock and the company's gross profit margin in the income statement. and Management accounting Management accounting is an option in Monitor ERP. It is used as a complement to the standard function called Stock accounting. The function means that all transactions on manufacturing orders (WIP value) are posted and transferred to the general ledger in the Accounting module in Monitor G5. The hours worked are recorded in the income statement, and provide a financial follow-up, for example, made per department and cost factor. Calculation differences are posted and these can be followed up per product, per order, etc. This function also contains extended management of cost of goods sold. are applied. With this setting activated, the Booked change and Difference columns are displayed as well as everything relating to bookkeeping.
By not activating this setting, companies which have not activated the Stock accounting or Management accounting can use this list as a basis for the manual recording of the change in stock.

#### Account
Here you enter the accounts against which the reconciliation should be made. This is used when the Reconciliation of general ledger setting is activated.

#### Reconciliation period
Here you enter a date interval for the reconciliation period. This period is by default configured to be the last month. This is done to improve the performance. However, you can change the date interval.

#### Include SO mark-up
With this checkbox you determine if SO mark-up (storage overhead mark-up) should be Included in the reconciliation.

#### Include parts without entered value
With this setting you determine if parts without entered value should be included in the reconciliation.

#### Only show parts with difference
With this setting you determine if only parts with difference should be include included in the reconciliation. This is used when the Reconciliation of general ledger setting is activated.

#### Include not approved journals
With this setting you determine if journals which are not approved should be included in the reconciliation. This is used when the Reconciliation of general ledger setting is activated.

#### Show configured parts
With this setting you decide if configured parts should be included in the reconciliation.
