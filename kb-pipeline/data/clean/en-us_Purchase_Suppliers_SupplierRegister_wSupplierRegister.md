## Supplier register
This procedure is used to register new suppliers, as well as change and delete existing suppliers. On the main row there are fields where you can enter supplier number, supplier name, supplier role. If you have checked the role Shipping agent, additional fields will become available. Below, you will see tabs for contact information, settings, SRM, and budget. Under these tabs, there are a number of boxes where you can enter information about the supplier.
If you try to delete a supplier from the supplier register, the system will check if the supplier is in use. The check is made for inquiries, purchase orders, invoices, accounts payable, supplier links, and subcontractors for work centers. You cannot delete the supplier if it is used in one of these registers. However, if the supplier is not used in the system, it will be possible for you to delete it.
It is also possible to deactivate a supplier. This can be done unless there are open inquiries, purchase orders, blanket orders, cases, or supplier invoices registered to the supplier. An inactive supplier cannot be selected when registering inquiries, purchase orders, subcontract purchase orders, cases, or supplier invoices. If there is a supplier link in the Part register, it is removed when the supplier is deactivated. Inactive suppliers can also not be searched for in procedures such as Inquiry list, Order List – Purchase, Supplier list and others. History is however saved for deactivated suppliers for statistics/follow-up purposes.
You can add extra fields for this procedure in the Extra fields procedure. If such fields already have been created, these will be available under the Extra fields tab.
If you have installed the option Warehouse, it is possible to save certain information per warehouse. The information that is saved per warehouse is: Delivery terms, Delivery method, Delivery days, Transport time Transport time is the number of work days that it takes to send a shipment from sender to a receiver., and Place of terms of delivery. If you want to change warehouse, you use the button Warehouse ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_warehouses.png) (Ctrl + Q) on the toolbar of the procedure. For inquiry and purchase order you can select to which warehouse it belongs. The selected warehouse determines the mentioned information. Read more about the option [Warehouse](../../../UserGuide/Using/Warehouse/Warehouse.htm).
At the very bottom of the window you can see information about who created and most recently modified the information for the current record and at what time. Using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_log.png) you will access a log containing all modifications.
