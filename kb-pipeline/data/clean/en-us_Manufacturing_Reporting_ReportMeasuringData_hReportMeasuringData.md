### Header row
Here you select the report number to report.

#### Report number
Enter the report number to go directly to a specific measuring point in an order. The order is loaded and you will see information about the measuring point.

#### Quantity
Here you enter the quantity to report. The suggested quantity here is the planned quantity from the manufacturing order.

#### Reported by
Here you enter an employee number which is saved on the reporting item. If the user has a linked employee number, that employee number will be pre-filled. If the employee number is blocked for reporting, an error message appears and you cannot save the reporting item.

#### Order number
In this field you see the order number to which this report number belongs.

#### Operation
Here you see the operation number.

#### Comment
The Comment field is used to write and save a comment regarding a measuring item. You can also link files to a measuring item.
