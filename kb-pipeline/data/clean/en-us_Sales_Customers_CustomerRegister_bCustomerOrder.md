### Customer order
In this box you will by default see all orders which have a remaining amount. That is, order with status 1–5.
Using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) you can go to the Register customer order procedure or the Customer order info procedure for the selected order in the box.
By using the Show document button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_form_viewing.png) you can view the actual document for the selected row in the box.
By using the Show orders with final delivery made button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_goto_critical_op.png) you can choose to also show all orders where final delivery have not been made.
You can also see the total number of records and the total order amount.
