### Settings

#### Pre-select "Include"
This setting determines whether or not the “Include” box should be checked by default for all rows in the list/result.

#### Include already returned arrivals
With this setting you decide if arrivals which have already been returned, should also be shown in the list.

#### Suggested quantity
Here you select what the suggested quantity for return should be. The options are Arrival reported qty and Zero (0). Please note! If you have chosen the option "Arrival reported quantity" and there is already a quantity which has been returned for that order row, then the remaining quantity will be suggested.

#### Delivery date
The date when the return order is expected to be delivered.
