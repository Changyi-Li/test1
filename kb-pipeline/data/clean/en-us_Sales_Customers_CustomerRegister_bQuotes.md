### Quotes
In this box you can see the quotes for the customer. Only quotes with status 1 (Registered), 2 (Printed), or 7 (Partial order) are shown.
Using the button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_link.png) you can go to the Register quote procedure for the selected row in the box.
By using the Show document button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_form_viewing.png) you can view the actual document for the selected row in the box.
By using the Include finished quotes button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_goto_critical_op.png) you can choose to also include quotes which have already been finished/closed.
You can also see the total number of records and the total quote amount.
