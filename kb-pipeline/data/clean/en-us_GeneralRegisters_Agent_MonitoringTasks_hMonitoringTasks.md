### Header row

#### Number
Here you see/enter a number for the monitoring task using a maximum of 20 characters. A new record is highlighted by a green dot ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/green_dot.png) shown in the field. This dot will disappear when the record is saved for the first time. By using the Lookup The Lookup feature is a powerful search tool which allows you to search and load information from large registers. You open the Lookup feature by clicking on the dropdown button or by using F4 on your keyboard. feature, you can find existing monitoring tasks.

#### Name
Here you can write a descriptive text as a name. You enter name texts in the company language and they are displayed in the user’s language.
By using the button Translations ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_translate.png) you can translate the text to the different active languages registered in the system. Read more about [language management](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LanguageManagement) for translatable texts.

#### Type
In this field you select the type of monitoring task. The type determines which monitoring selections with monitoring terms you can make. Today you can choose to make a balance check for part, check status of different activities, check status of operation in manufacturing order, and check if arrival reporting has been made for part and purchase order row.

#### Active
Here you determine if the monitoring task should be active or not. Only active monitoring tasks are used.
