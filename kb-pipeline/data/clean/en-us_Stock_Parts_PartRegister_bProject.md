### Project

#### Purchase on project
Applies to Purchased parts. Here you choose if the part should be purchased on project or not. That is, that the purchase is reserved for a specific project. The setting indicates that the part is purchased on project. By activating the system setting Purchase/manufacturing on project by default for new parts this setting will always be checked by default for new parts. The Pick from stock first option is available if the part has the lot sizing rule set to Lot-for-lot.
If you choose the Pick quantity from locations option, no linked requirement will be created as long as there is available material in stock. Example, if there are 80 pcs available in stock, that is, balance that is not cleared, but the linked requirement is 100 pcs. Then 80 pcs will be picked from stock and a linked purchase order suggestion will be created to cover the remaining 20 pcs.

#### Manufacturing on project
Applies to Manufactured parts which are stock driven. With this setting you determine if the part should be manufactured to be used in a project. By activating the system setting Purchase/manufacturing on project by default for new parts this setting will always be checked by default for new parts.

#### Project
With this field you enter if the part is linked to a specific project. You can select among the registered projects. When you link a part to a specific project this means that the part is added to the project under the Manufacturing/Stock tab in the Project register procedure. If a part linked to a project is withdrawn or arrival reported in the Direct stock reporting procedure, the project number will automatically be entered on the transaction.
