### The Export list
This list shows the selected employees for which you can export a salary basis for the selected date interval.

#### Warnings
In the column next to Name you will see a warning symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/warning.png) if for example a recording item has not been authorized or if there are time differences. A tooltip is shown when you hover over the symbol, displaying the cause of the warning in text form.

#### Export
Check the Export box if salary basis should be exported for the employee of the row.
You carry out the export by using the button Export salary basis ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_export.png) on the toolbar of the procedure. A message appears afterwards showing that the file has been exported and in which path that the file was created.
