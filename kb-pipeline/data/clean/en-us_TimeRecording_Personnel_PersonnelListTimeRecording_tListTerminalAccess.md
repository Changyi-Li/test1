### The Terminal access list
This list type shows information regarding the terminal access of the personnel. You can also see the properties of the respective terminals. The list only displays personnel for whom it has been specified which recording terminals they have access to. The list is grouped by employee number and cannot be updated.
In the list you can in the column Type of terminal see if recording of attendance and/or work is allowed in the terminal. In the Only card column you see Yes if it is mandatory to record using your card in the terminal. Otherwise you will here see No.
Terminal access for the personnel is handled in the procedure Personnel records – Time recording. Properties for the terminals are configured in the Terminal settings procedure.
