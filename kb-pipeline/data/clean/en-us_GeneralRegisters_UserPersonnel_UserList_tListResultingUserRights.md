### The Resulting user rights list
In this list you find all resulting user rights for one or multiple users. You cannot modify any user rights for users in this list.
If the Warehouse option is installed you can choose to see the user rights for users in one or several warehouses.
The list displays the information available to users in the Resulting user rights section under the User rights tab in the Users procedure.
In the list you can, for example, filter the User rights column to find users with specific user rights.
