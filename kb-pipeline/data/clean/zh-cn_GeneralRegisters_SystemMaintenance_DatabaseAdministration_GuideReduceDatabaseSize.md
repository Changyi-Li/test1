### 减小数据库的尺寸
本指南概述了如何在从数据库已导出二进制大对象数据之后你数据库的手动计划文件尺寸，这意味着在以前存储二进制大对象数据的位置已创建空空间。
> 请注意！ 如果你运行 选项或定制包 在您的MONITOR ERP系统中，减少数据库手动计划文件尺寸的过程必须与MONITOR支持中心进行对话。否则，数据五月会丢失。在这种案件下，联系人MONITOR支持中心支持 支持协议不涵盖在减少数据库文件尺寸时与管理选项和定制包相关的成本。
- 如果数据库在 SQL 服务器上运行，则可以使用 SQL 命令来减少尺寸。你可以在 Microsoft 的文档中阅读更多。
- 如果数据库在 SQL Anywhere 上运行，你可以使用控制台程序 MONITOR.DatabasePortation.Console.exe 以减小其尺寸。该程序包含在程序服务器（MONITOR服务器）中，通常存储在以下路径： 当前日程表图表:\ 程序 文件 (x86)\ MONITOR ERP 系统 AB\MONITOR服务器。该程序将数据库中的全部标准表份数到临时文件（卸载），然后从这些文件创建一个新建的数据库（重载）。新建的数据库不包含二进制大对象数据已导出时产生的空区域，结果文件尺寸更小。
减少 SQL Anywhere 数据库的尺寸：
1. 打开窗户 命令线界面 （cmd.exe）以管理员转到上面的目录“ MONITOR 服务器”。
2.         
输入低于两个示例中概述的命令：
减少数据库“001”的尺寸：
MONITOR.DatabasePortation.Console - 当前日程表图表 001 -d 0
减少数据库“001”的尺寸，临时文件路径为“e:\data”：
MONITOR.DatabasePortation.Console - 当前日程表图表 001 -d 0 -fe:\data
要查看程序中支持的全部参数，输入以下命令：
MONITOR.DatabasePortation.Console
3. 该程序运行，完成后，你会在你减小尺寸的新建数据库的子目录中查询新建的数据库。该路径通常为当前日程表图表:\ProgramData\ MONITOR ERP 系统 G5\Databases。
4. 使用新建数据库复制旧的数据库。订单做到这一点，你必须第一个停止程序服务器（MONITOR服务器）的服务，然后停止 SQL Anywhere 数据库服务器的服务。然后你可以复制数据库。然后，按相反​​的订单重新开始服务。
