### 警告选项标签页
在此标签页下你可以看到以下警告：
| 警告 | 此警告何时出现？ | 行动 |
|---|---|---|
| CN 代码缺失 | 如果国家 / 地区代码在欧盟范围内但CN 代码缺失，则会出现此警告（这不应用至服务）。行类型2 和虚拟件的子零件排除本检查范围内。对全部订单类型都进行检查。 | 如果要将这些组件纳入境内的报告被用于，你在组件登记中输入这些组件的CN 代码。 |
| 重量缺失 | 如果国家 / 地区代码在欧盟范围内且存在CN 代码，但否输入重量（尽管CN 代码已配置为报告重量） ，则会出现此警告。此项检查还包括第 2行类型和服务。对全部订单类型都进行检查。 | 在组件登记中输入组件的重量。 |
| 交货至欧盟以外（简单VAT处理） | 在这种案件下，该记录作为货物贸易（欧盟）被用于在VAT 报告中，但在境内的报告中不存在。此检查仅应用至发票（不库存订单） | 如果该记录应被用于在境内的报告中，则必须在供应商发票上已变更国家 / 地区。使用链接转到登记供应商发票程序并更改国家 / 地区。如果不将该记录已报告为欧盟贸易，则必须再次已编码发票，仓储费用它就不作为欧盟贸易被用于在VAT 报告中。 |
| 交货至欧盟以外（高级选项VAT处理） | 在这种案件下，该记录作为货物贸易（欧盟）被用于在VAT 报告中，但在境内的报告中不存在。此检查仅应用至发票（不库存订单） | 如果该记录应被用于在境内的报告中，则必须在供应商发票上已变更国家 / 地区。使用链接转到登记供应商发票程序并更改国家 / 地区。如果不将该记录已报告为欧盟贸易，则必须再次已编码发票，仓储费用它就不作为欧盟贸易被用于在VAT 报告中。 |
| 科目不涉及欧盟货物贸易（简单VAT处理） | 如果交货国家 / 地区在欧盟境内，则会出现此警告，但 科目 你所已记录的不指欧盟商品贸易（根据上面描述的相同逻辑）。 | 如果该记录不在境内的中已报告，则必须修改发票上的国家 / 地区。使用链接转到登记供应商发票程序并更改发票上的国家 / 地区。如果要将该记录已报告为欧盟贸易，则必须再次已编码发票，仓储费用将其作为欧盟贸易被用于VAT 报告中。 |
| VAT 代码与货物贸易不（欧盟）（检查高级选项VAT加工） | 如果交货国家 / 地区在欧盟境内，则会出现此警告，但 VAT 代码 已开发票上不提及欧盟商品贸易 . 此检查仅应用至发票（不库存订单） | 如果该记录不在境内的中已报告，则必须修改发票上的国家 / 地区。使用链接转到登记供应商发票程序并更改发票上的国家 / 地区。如果要将该记录已报告为欧盟贸易，则必须再次已编码发票，仓储费用将其作为欧盟贸易被用于VAT 报告中。 |
| 组件不存在报告单位 | 如果CN 代码设置为报告另一个数量，但所讨论的单位不在组件登记中为该组件已登记，则会出现警告。然后它将不被用于在境内的报告中。该国家 / 地区还必须是欧盟国家 / 地区才能已激活该检查。 对全部订单类型都进行检查。 | 如果要已报告记录，你必须在组件登记中为组件登记一个有效的单位。（只要将其已登记为具有正确换算因数的替代单位就足够了。） |
在某些案件下，同一记录可能会显示多个警告（例如，如果重量和CN 代码两者不存在）。
