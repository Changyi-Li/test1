### Test automatic allocation
You can test automatic allocations without any voucher becoming registered. By doing this you can see if the terms have been configured to make the posting take place for the correct variant of posting string and that the rows become correct.
You select an automatic allocation number on the header row and then you click on the button Test automatic allocation ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_run.png) on the toolbar of the procedure. In the Test posting window which is then shown, you enter a posting as seen below.

#### Posting
In this box you enter account, dimensions, debit and credit for the allocation.

#### The Test button
When you have entered a posting you click on the Test button. The result is then shown in the Result box.

#### Result
In this box you see the result of the automatic allocation.
