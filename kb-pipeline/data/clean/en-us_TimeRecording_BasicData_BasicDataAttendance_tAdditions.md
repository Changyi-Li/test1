### Additions
Additions are used to account for other activities making up salary, for example travel time, allowances for expenses, etc. Additions can be handled when adjusting attendance recording or be added by the employee in the recording terminal (as long as the employee’s parameter group has the Handle additions in recording terminal setting activated).

#### Active
With this checkbox you determine if the addition should be active. This means that the addition becomes available to select in different parts of the system.

#### Salary type
Here you see/select the salary types which should be generated on the salary basis for the addition in question.

#### Link to project
Here you decide if the addition either should be optional or mandatory to link to a project. It is also possible to select that no link to project should be possible to make.

#### Cost type
Here you see/select the type of cost in project to which this addition refers. The field is available if “Link to project” is set to Optional or Mandatory. The cost types are loaded from the Costs/Income tab in the Basic dataWith "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. ­­– Project procedure.

#### Cost
The hourly cost for the addition should be entered in the company currency. The cost is displayed with two decimals.

#### Visible
Determines if the cost should be shown and editable in the Recording terminal and Authorize/Adjust recording procedures.

#### Time bank
Here you determine if the addition should affect the selected time bank. It can for example be used in the procedure Authorize/Adjust recording for paying out saved comp time or for "emergency compensation" which for example should pay 2 hours + 1 hour in a time bank.
There are two additions included in the system. These are for Positive time bank adjustment and Negative time bank adjustment. These cannot be deactivated. They are used to automatically create transactions from the procedure Update time balances. They cannot be used in the Authorize/Adjust recording procedure.

#### Mandatory comment
With this checkbox you decide if it should be mandatory to enter a comment if the addition in question is selected.

#### Enter from/to
Here you determine if a From and To should be possible to enter for the addition when it is selected.

#### Inactive since
In this column you see the date when the addition was inactivated.

#### Deactivated by
In this column you can see the name of the user who deactivated the addition.
