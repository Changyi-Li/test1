### Settings

#### Document variant
Here you decide which document variant should be printed.

#### Number of copies
Here you select the number of copies that should be printed.

#### Linked files
With this setting you decide if external documents which have been linked under the External comment should be printed.

#### Show prices
Here you decide if the price should be shown on the document.

#### Price alternative
Here you decide if prices should be displayed on the document as Price/Invoicing interval or Price.

#### Show delivered rows
With this setting you decide if delivered rows should be shown on the document.

#### Show total amount
With this checkbox you decide if the total amount should be shown at the bottom on the document.

#### Show one-time costs
Here you decide if one-time costs should be displayed on the document.

#### Show description
Here you decide if the text in the Description box under the Header tab, should be shown on the document.

#### Show activities
Here you decide if activities from the Activities tab should be displayed on the document.
