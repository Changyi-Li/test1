### Settings
In this box you can configure different settings for the report.

#### Date
Here you select a date interval for the report. Vouchers which have been registered within the interval will be included in the report. When you enter a date interval you can select any date and create an interval for example in the middle of accounting periods. It is also possible to create intervals spanning over turn of the year.

#### Language
Here you select the language of the report. If you do not want the report to be printed in the language of your user, then you can code tables registered one of the languages registered in the system. This is useful for example if the report should be distributed to an external party.

#### Group by
With this setting it is possible for you to group the report by one of the registered dimensions.

#### Total printout
With this checkbox you determine if only total rows should be shown in the report.

#### Amount in thousands
With this checkbox you determine if amounts and balances should be displayed in thousands.

#### Activate links
With this checkbox you decide if balances should contain a hyperlink to the underlying accounts and vouchers. This means, that when you view the report under the Documents tab, you can from a balance in the report click your way down in the structure and see underlying vouchers on the affected accounts in the general ledger. From the general ledger you can click your way to see the separate vouchers in detail (a so-called drilldown function). From there you can open the vouchers in the procedure Register vouchers.

#### Use line break
This setting is activated by default. Then all columns will be printed in the report, including those that are too wide to fit the printout. A line break is then made on the printout for the columns that are too wide. If you deactivate this setting, only the columns that fit (to the width) will be printed.
Currency
If you’ve chosen to load the report in a currency other than the company currency, the currency and rate on which the values in the report are based are shown in the report header.

#### Currency
The company currency is default. If you choose a currency other than the company currency, the report will recalculate all monetary values (balances, budgets, calculating columns, etc.) to the selected currency, using the exchange rate.

#### Rate type
If you have chosen a currency other than the company currency, this field is activated. The default rate type is Current exchange rate, but you can also select AFS rate. If you choose AFS rate, the exchange rate in effect at the report’s To date is used.

#### Exchange rate
If you have chosen a currency other than the company currency, this field is activated.
