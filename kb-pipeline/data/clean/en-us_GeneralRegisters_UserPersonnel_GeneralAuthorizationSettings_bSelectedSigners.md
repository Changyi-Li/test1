### Selected signers
In this box you see all signers that you have added to the signer group.
You can add and remove signers from the group by using the buttons ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_goto_previous.png) and ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_goto_next.png) or by using the "drag and drop” function.
