## Report emissions manually
In this procedure you can report CO2e-emissions manually. The functionality was developed to manage emissions that cannot be linked to supplier invoices, but can be used to register all CO2e. The reported values are shown in Monitor BI along with the emissions reported via supplier invoices and vouchers.
You can only use emission codes that are registered with the reporting method Manual in the Basic data With "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Sustainability procedure.
