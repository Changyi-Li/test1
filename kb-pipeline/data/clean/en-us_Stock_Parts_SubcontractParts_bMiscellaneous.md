### Miscellaneous

#### Product group
Here you select the product group to which the subcontract part belongs. By default, it will get the same product group as the part in the BOM and routing to which the subcontract belongs.

#### Quantity/package
Here you see/enter the quantity per package for the subcontract part. This can be entered if the package size differs from the manufactured part.

#### Default transport label
Here you select the default label type used for the subcontract part.

#### Net weight
In this field you enter the net weight of the subcontract part. This weight refers to the net weight up until the subcontract (including the material linked to the subcontract). You must enter a weight when it should be reported in the IntrastatIntrastat is the system which gathers statistics relating to trade in products within the European Union. Gathering of Intrastat statistics is handled in the same way by all EU member states. report for products that are sent for wage processing abroad. (Only applies to transactions within EU.)

#### Transport cost
Here you enter the transport cost of the subcontract part.

#### CN code
Here you can choose a CN code (goods code) for the part. These codes are handled in the procedure Basic dataWith "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Part. When a subcontract part is created (takes place automatically via BOM and routing), the main part's CN codes will automatically be set on the subcontract part. This is made to include the CN code in the purchase order that is created. (It is the subcontract part and not the main part that is added to the purchase order.)

#### Purchase statistics
By clicking this button you can view the purchase statistics by month.

#### Units
Units that are added under the button Units are only used when reporting Intrastat. When needed it is possible to add alternative units to the part and enter conversion factor, in relation to the default unit. You might need alternative units when calculating subcontract purchase orders. Each CN code in the Intrastat report also has its own part unit.
