### Comment/Files
In this box you can enter a comment for the customer, and also link external files. These comments and linked files are not displayed or printed with any documents, but they will be accessible in e.g. the procedures Register quote, Register customer order, and Register invoice directly.

#### Comment
By clicking this button you access a text editor where you can write and format text, insert images and signature, and hyperlinks, etc. When a comment/text exists, the symbol on the button will change from an empty speech bubble ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_no_comment.png) to a filled speech bubble ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_comment.png).

#### Files
By clicking the Files button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_file_link.png), it is possible to link different files related to a comment or an instruction for the record in question. When the setting Automatic printout is available for activation, you can choose to get the linked file automatically printed. Read more in the topic [General features](../../../UserGuide/GeneralFeatures/GeneralFeatures.htm#LinkFiles) about how to link files, automatic printout, and where linked files can be automatically printed. If there are linked files, you will see this symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_file_linked.png) on the button.

#### Logotype
By clicking this button you can add an image file which will be used as the customer's company logotype on the delivery documents.
By using the Import button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_import.png) you can add an image file from your computer. The most common file types are supported, for example png, jpg, gif, and bmp. In connection with the import, you can crop the image proportionally according to the fixed width/height relation (1:4) set for logotypes on documents.
By using the Preview button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_preview.png) you can see how the logotype will look on the document.
By using the Delete button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_delete.png) you can delete the image file in question.
By clicking the Document settings button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_more_info.png) on a customer order type in the Order types procedure, you can configure that the header and footer on the delivery documents called Delivery note, delivered, Comprehensive delivery note, and Transport label, sales, should be loaded From customer info. Then the customer's logotype will be shown on the delivery documents for customer orders of that order type. You should also enter the customer's bank accounts by clicking the Bank accounts button in the Miscellaneous box. The bank information will then be displayed in the footer of those documents, together with other customer information. The purpose of this is to make it look like your deliveries have been shipped from the customer and not from you in cases where you ship the deliveries directly to the end customer (the customer's customer).
