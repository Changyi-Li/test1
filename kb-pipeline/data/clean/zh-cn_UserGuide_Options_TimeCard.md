# 考勤卡
![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/Options/TimeCard.png)
此选项非常适合钳工、修理工和其它在下班工作或不访问记录终端的字段。TimeCard 是一种方便的解决方案，适用于无限制的工作时间的员工，仅批准其已工作时间并报告缺勤等异常情况。你可以通过手机、平板电脑或计算机日志，任何时间使用 TimeCard。
Monitor ERP TimeCard 是一个基于网络的解决方案，使你能够轻松地报告工作和出勤，而无需直接访问MONITOR客户端或记录终端。您的录音将直接已保存到 Monitor ERP。
作为基本需求，那些使用 Monitor ERP TimeCard 必须具有时间记录模块 Monitor ERP。
登录用户的日程表安排 Monitor ERP 显示在 TimeCard 中的日历中。用户的参数组和员工记录中的设置决定了 TimeCard 中可访问的内容。
全部录音都直接已保存在 Monitor ERP。

#### 录音
TimeCard 中的全部工作记录都附有相应的出勤记录。这意味着用户每个记录一个时间单位的工作，日的出勤就会相应增加。请注意！时间已增加按照录音已登记的订单添加的。
