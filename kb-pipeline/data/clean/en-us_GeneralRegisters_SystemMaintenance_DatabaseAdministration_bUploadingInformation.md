### Uploading information
Here you enter how you want to upload a SQL Anywhere database including different log files to the Support Center at Monitor ERP System AB.
If it is an SQL Server database, you need to upload the file manually, via the link you have received from the Monitor Support Center. Or you may have to contact your IT department or ERP manager.

#### Link for uploading file to Monitor (link provided by the Monitor Support Center)
If you have received a code key (token) from the Monitor Support Center for uploading of your SQL Anywhere database, you paste the entire code in this field. The field contains a pre-filled web address to Monitor's file server. This cannot be deleted. The code key you have received is unique for your system. When you paste it in the field it will be added to the pre-filled web address. Press Tab or Enter when you have pasted the link (the code key) you have received from us. If the code key is correct, a symbol ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/StatusFinished.png) is shown next to the field.
![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/SubProjects/Database_upload.png)

#### FTP
You can choose this alternative if you have been assigned an FTP account by Monitor Support Center or if you already have such an account. You then enter your User name and Password for the account.
