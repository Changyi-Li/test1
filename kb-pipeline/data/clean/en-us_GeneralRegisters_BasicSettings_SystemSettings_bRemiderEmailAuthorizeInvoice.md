### Reminder via e-mail for authorization of invoices
This is a system setting that is specific for the mobile client.

#### Mobile client URL
Here you enter the address to the web server (please see [Install Monitor ERP mobile client app](../../../UserGuide/InstallConfig/InstallMONITORApp.htm)). This address is used to make it possible to provide a link to authorization of supplier invoices in the mobile client when you send a reminder via e-mail. For this to work, the setting called Send reminder via e-mail must be activated. You find this setting under the Scheduling tab in the Authorization settings – EIM procedure. Also, the user must have the setting called Allow login to mobile client activated. This setting is found under the Security tab in the Users procedure.
