### The Attendance settings list
In this list you find information about the attendance settings of the personnel. The list is sorted by employee number.
The list shows name, parameter group, schedule cycle, as of which date the cycle is valid, and who is the main signer for each person.
Schedule cycle and Valid from are not shown for employees who have Schedule management set to No schedule.
If you make the list possible to update (Ctrl + U), you can then change parameter group for each person. You register parameter groups in the Parameter groups procedure.
If site recording is activated (via the system setting called Activate site recording), you can also select a default site for clocking in and a default site for clocking out on break for each person. You register sites in the Basic dataWith "basic data" we refer to the static records in a database, for example parts, customers, users, work centers, etc. – Attendance procedure.
