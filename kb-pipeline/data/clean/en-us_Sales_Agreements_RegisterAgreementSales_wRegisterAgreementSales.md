## Register customer agreement
Here you can electronically register customer agreements and ensure they can be searched in the ERP system. Based on the agreements, the agreement bases (invoice bases) are created for invoicing.
A customer order is required i Monitor ERP for it to be possible to create an invoice basis. That is why the procedure will create a customer order at the same time as it created the agreement basis. There is a special order type for customer orders that is called Agreement. This is used to be able to separate these customer orders for agreements from the regular customer orders. This order type makes it possible to select by these orders in the Order inflow and Order list – Sales procedures.
Customer orders of the Agreement order type are not displayed in the Customer orders box under the Header tab. There you can link regular customer orders to the agreement, if needed.
You can add extra fields for this procedure in the Extra fields procedure. If such fields already have been created, these will be available under the Extra fields tab.
In the Extra fields procedure you can to add extra fields for order rows. If such fields already have been created, these will be available under the Extra fields button on order rows.
Save as
You can use the Save as button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_save_as.png) (Ctrl + Shift + S) for an existing agreement to copy it to a new agreement. You can choose order type and a new Valid from and Valid to for the new agreement. Today's date is selected by default in the Valid from field. By default, the agreement header, and agreement rows will be included in the new agreement. Please note! Suggested upward adjustment will not be copied to the new agreement.
Delete an agreement
You can choose to delete an agreement as long as it does not have status 3 (Active) or as long as an agreement basis has not been created for the agreement. A deleted agreement number cannot be reused.
