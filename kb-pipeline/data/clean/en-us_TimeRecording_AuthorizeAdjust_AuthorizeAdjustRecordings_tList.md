### List
Under the List tab you will to the left see a list containing the personnel you selected under the Selection tab. In the right section there is a calendar, a tab where you can adjust attendance, and a tab where you can adjust work.

#### Authorization interval
If an authorization interval was entered in the settings you will see this in the fields. It is for this interval the recording items will be authorized.

#### Authorize
Button to authorize the persons for which the Include box is checked in the list.

#### Recalculate
By using the Recalculate button ![](https://help.monitorerp.cn/CN-MONITOR_G5/en-us/Content/Resources/Images/button_calculate.png) you can do a recalculation of attendance recording items. This feature is useful if, e.g., a schedule or an absence code has been assigned a different salary type. Additions which have been modified will not be recalculated.
This button becomes activated when you have selected one or multiple employees using Include in the list. The recalculation is performed for marked days in the calendar which have not been authorized. When you click the button a dialog is shown where you confirm the recalculation.

#### Include
This checkbox in the list determines for which persons you should perform authorization or recalculation of attendance recording items.
