## Move stock balance
Here you can move a part's stock balance between different locations. If you have installed the Warehouse option, you can also move the balance between different warehouses.
The procedure is divided in two tabs: Manual mode and Scanning mode.
Under the Manual mode tab you can enter a part number (or name), batch, serial number, and location name, to search for parts. You then enter a quantity to move or you choose the complete balance for each of the parts in question.
Under the Scanning mode tab you use a bar code scanner connected to the computer. Here you scan parts to the procedure based on information on labels, transport labels, etc. to move a quantity to a different location.
You can move a quantity for multiple parts and locations at a time and you can distribute a quantity to multiple locations when you move it.
You can create a new location in connection with moving a quantity. This is done by entering a new location name in the To location column. You can also create multiple new locations. This is done by adding new rows and on those you enter new location names and then enter quantities to move to those locations.
It is also possible to select if the location is a pick location, a pick location for work center or both. You can then enter a reorder point and a suggested refill quantity.
You can also enter a priority for the location.
You can also, if needed, determine that the balance on a location should be excluded (from the net requirement calculation, requirement calculation, and check delivery times). Read more about this in the section [Locations](../../Parts/PartRegister/bStock.htm) in the online help function for the Part register procedure.
> Please note! If you enter a quantity to move to a location which has a different Last arrival date, the date on the location will be entered as the most recent of the two dates that exist on the location when you save. That is, the age analysis will remain the same for the quantity which has the latest arrival date, but it will stop applying for the quantity with the older arrival date.
Read more about [Warehouse](../../../UserGuide/Using/Warehouse/Warehouse.htm) under Using Monitor in the online help function.
