# Monitor 新闻
新闻部件 Monitor 新闻 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/UserGuide/MonitorNews.png) 显示简短的新闻帖子，其中包含对用户的重要信息和启发 Monitor ERP。这些帖子包括来自我们的支持中心和开发部门的通知，以及通知如何下班你 Monitor ERP以及培训资源信息和链接，例如 MONITOR学院、我们的网络研讨会、我们的选项、集成等等。
新闻部件预设为激活，但你可以选择你 Monitor 新闻 可视的​ ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/UserGuide/MonitorNews.png) 按钮。为了提醒你有未阅读新闻过账，屏幕上会显示一个橙色符号 ![](https://help.monitorerp.cn/CN-MONITOR_G5/zh-cn/Content/Resources/Images/UserGuide/MonitorNewsNewNotification.png) 按钮。
在里面 用户设置 程序，你可以基于角色和县选择你想要看到的新闻帖子的利息领域 Monitor 新闻。
