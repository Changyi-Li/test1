# RAG 知识库数据源抽取的范围与语言策略

本 ADR 记录 RAG 知识库数据源抽取流水线（wayfinder 地图「Monitor ERP help → RAG-ready 数据集：抽取流水线地图」）的四个范围决策：(1) 目的地到“RAG-ready 数据集规格 + Getting Started 试点”，RAG 运行时选型不包含；(2) 三层语言策略——英文主题页全入库为保真层，现有中文主题页全入库为参考层并作为中文问答主检索语料，中文精修是否启用由试点证据决定；(3) 输出平台无关中间格式（每主题 Markdown + JSONL 元数据 + 派生分块）；(4) 代码与文本产物进本仓库 kb-pipeline/，增量同步 + 定期全量对账，试点阶段手动触发，图片默认不入库仅记录 URL。原因：用户团队以中文问答为主，而官方英文文档更准确；数据格式需兼容未来任意 RAG 平台，因此不提前绑定平台。
